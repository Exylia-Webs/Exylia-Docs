At the end of this page ExyliaKillCam is running and recording. There is nothing to configure first.

## Before you start

| Plugin | What for |
|---|---|
| `ExyliaLib` | Required. Records the fights, moves the camera and keeps each player's choice. See [install ExyliaLib](/docs/exylialib/installation). |
| `PacketEvents` | Required to show a killcam. Install it next to ExyliaLib. |
| `ExyliaKillEffect` 1.9.0+ | Optional. The killer's kill effect plays again at the end. |

The plugin needs Paper or Folia 1.21 or newer and Java 21.

## Steps

<Steps>
  <Step title="Download">
    ExyliaKillCam is free. Download `ExyliaKillCam.jar` from the [GitHub releases](https://github.com/Exylia-Plugins/ExyliaKillCam/releases). The jar keeps the same name on every release.
  </Step>
  <Step title="Copy the jars">
    Put `ExyliaKillCam.jar` in `plugins/`, next to ExyliaLib and PacketEvents.
  </Step>
  <Step title="Start the server">
    The plugin writes its files and starts recording at once.
  </Step>
</Steps>

## Check that it works

The console shows ExyliaKillCam enabled and the folder `plugins/ExyliaKillCam/` exists. To see a killcam, follow [Your first killcam](/docs/exyliakillcam/first-steps).

If ExyliaLib is missing, the plugin stays off and the console says which version it needs and where to download it. Nothing is downloaded for you. Install it and restart.

If PacketEvents is missing, the plugin starts but no killcam is ever shown: `/killcam` answers "Killcams cannot be shown on this server. PacketEvents is missing."

## Files it creates

Everything lives in `plugins/ExyliaKillCam/`.

| File | What it holds |
|---|---|
| `config.yml` | The mode players start with, the length and shot, which deaths count, the recording. See [Configuration](/docs/exyliakillcam/configuration). |
| `lang/<code>/messages.yml` | Every line the plugin sends. See [Edit the messages and the skip button](/docs/exyliakillcam/messages). |
| `lang/<code>/hotbar.yml` | The skip button shown while watching. |
| `lang/<code>/menus/admin/` | The in-game settings menus of `/killcamadmin settings`. |

`<code>` is `en`, `es`, `pt`, `fr`, `ru`, `tr` or `de`. With `language: default` in `config.yml` it follows the language set in ExyliaLib's `config.yml`.

The plugin has no database. The mode each player chose is kept by ExyliaLib, and recordings live only in memory and are lost on restart.

## Updating

ExyliaLib watches this plugin's GitHub releases. A new release is announced in the console and to admins; nothing downloads on its own. `/exylialib plugins` downloads it and it applies on the next restart. To update by hand, replace the jar and restart. Your edits to `config.yml` and the lang files are kept.
