ExyliaKillCam shows a player how they died. After the respawn they watch the last seconds of the fight
again through their killer's eyes: the last moment slows down, the camera cuts to their body as it falls,
the killer's kill effect plays once more for them alone, and then they are back exactly where they were,
with a line saying who killed them, with what, from how far and how many hearts the killer had left. It is
free and open source, published under the GNU General Public License v3.0 on
[GitHub](https://github.com/Exylia-Plugins/ExyliaKillCam/releases).

There is no resource pack and no client mod: a killcam is built from what the server already knows.
ExyliaLib keeps the last seconds around every player in memory; when somebody is killed, the seconds
before the death are cut out, laid down on ExyliaLib's temporary world with the ground they were fought
on, and played back to the victim alone. The real world is never touched, and the fight goes on for
everybody else.

## Requirements

| Requirement | Detail |
|---|---|
| Server | Paper 1.21.4 or newer. Folia supported. |
| Java | 21 |
| Required dependencies | `ExyliaLib`; `PacketEvents`, to show a killcam |
| Optional dependency | `ExyliaKillEffect` 1.9.0 or newer, to see the killer's kill effect again at the end |

<Callout type="note" title="About ExyliaLib">
The recording, the temporary world the fight is staged on, the camera, the hotbar button, the player
settings, the configuration files and the teleports all come from ExyliaLib's replay, overlay and settings
modules. ExyliaKillCam is the part that decides which deaths get a killcam and how it is shot.
</Callout>

## Conventions

- Values marked as **default** are what the plugin writes the first time it starts. If the file already
  exists, your value is kept.
- Identifiers between `<` and `>` are variables. `/killcam mode <mode>` means `/killcam mode ask`.
- Times in `config.yml` are a bare number in the unit the key names (`seconds-before` in seconds,
  `rewatch-minutes` in minutes), or written out: `10s`, `5m`, `1m30s`.
- Colours use ExyliaLib palette tokens (`{primary}`, `{error}`, `{highlight}`), so recolouring the server
  never means editing these files.
