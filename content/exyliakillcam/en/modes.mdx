At the end of this page you know what each player gets after dying, what your server starts them on, and how they change it.

## The three modes

| Mode | What the player gets after respawning |
|---|---|
| `AUTO` | The killcam starts by itself. |
| `ASK` | A line in chat, "You were killed by (killer).", with a clickable **[▶ WATCH KILLCAM]**. |
| `OFF` | Nothing. |

In every mode `/killcam` still plays the last death while it is kept. The killcam is started or offered once, on the respawn that follows the death, and only when that respawn comes within a minute of it.

## Steps

<Steps>
  <Step title="Set the server default">
    In `plugins/ExyliaKillCam/config.yml` set `killcam.default-mode` to `AUTO`, `ASK` or `OFF` (default `AUTO`), or change **Default mode** in `/killcamadmin settings`, page **Playback**. Run `/killcamadmin reload`.
  </Step>
  <Step title="Tell players how to choose">
    A player runs `/killcam mode auto`, `/killcam mode ask` or `/killcam mode off`. The answer reads "Killcam after dying » offered in chat".
  </Step>
</Steps>

## Check that it works

Run `/killcam mode ask`, get killed, and respawn. You should see the chat line with **[▶ WATCH KILLCAM]** instead of a killcam starting.

## Going further

### The same choice on /settings

ExyliaLib's `/settings` screen shows it as **Killcam** (spyglass icon). That command only exists when the server turns it on in `plugins/ExyliaLib/config.yml` (`settings.command.enabled: true`, then a restart). See [Player settings](/docs/exylialib/player-settings). Both ways write the same value.

### Changing the default later

A player who never chose follows the server default, so changing `killcam.default-mode` and reloading changes it for all of them. A player who chose something else keeps their choice.

### Automatic respawn

With `killcam.auto-respawn` on (default), a player in `AUTO` whose death got a killcam respawns on their own a tenth of a second after dying, and the killcam follows without a click. Players in `ASK` or `OFF`, and deaths without a killcam, keep the death screen. Turn it off to keep the death screen for everyone: the killcam then starts when the player clicks **Respawn**, if that is within a minute of the death.

### Make killcams a rank perk

Deny `exyliakillcam.use` or `exyliakillcam.mode` to the default group. See [Decide who gets a killcam](/docs/exyliakillcam/who-gets-one).
