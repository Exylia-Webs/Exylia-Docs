At the end of this page only the deaths and players you want get a killcam.

## Which deaths get one

A death gets a killcam when all of these hold:

- the victim has `exyliakillcam.use` (everyone by default);
- a player killed them (a bow shot or a tamed wolf counts), or a mob, when `deaths.mobs` is on;
- it was not their own doing;
- the world is not in `deaths.disabled-worlds`;
- no other plugin is in charge of the player (see [Work alongside duels and events](/docs/exyliakillcam/compatibility));
- they are not already watching a killcam and no plugin cancelled the death.

## Steps

<Steps>
  <Step title="Open the settings">
    Run `/killcamadmin settings` and click **Deaths**.
  </Step>
  <Step title="Mob deaths">
    Click **Mob deaths** to switch whether a death to a mob gets a killcam (`deaths.mobs`, default off).
  </Step>
  <Step title="Disabled worlds">
    Click **Disabled worlds** to choose worlds where nobody gets a killcam (`deaths.disabled-worlds`, default none).
  </Step>
</Steps>

In the file the same looks like this. World names are not case sensitive; a death in those worlds is not kept, so `/killcam` cannot show it either.

```yaml title="plugins/ExyliaKillCam/config.yml"
deaths:
  mobs: true
  disabled-worlds:
    - lobby
    - minigames
```

## Check that it works

Die in a disabled world: no killcam, and `/killcam` answers "You have no recent death to watch."

## Going further

### Make killcams a rank perk

Everyone holds the player permissions by default. Deny one to the default group and grant it to the rank:

```text
/lp group default permission set exyliakillcam.use false
/lp group vip permission set exyliakillcam.use true
```

`exyliakillcam.use` removes the killcam entirely, `exyliakillcam.rewatch` removes only `/killcam`, `exyliakillcam.mode` removes the choice of mode. Skipping a killcam never needs a permission.

### A longer rewatch window for a rank

`killcam.rewatch-minutes` (default `5`) is how long `/killcam` can show a player's last death. Give a rank more with `exyliakillcam.rewatch.<n>`, where `<n>` is minutes:

```text
/lp group vip permission set exyliakillcam.rewatch.30 true
```

The highest number a player holds wins. It is read when they die. Only the last death is kept.
