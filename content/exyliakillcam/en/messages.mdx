At the end of this page the texts players read in a killcam say what you want, in your colours.

## Steps

<Steps>
  <Step title="Pick the language">
    In `plugins/ExyliaKillCam/config.yml` `language` is `default` (follows ExyliaLib) or one of `en`, `es`, `pt`, `fr`, `ru`, `tr`, `de`. Each one is a folder `plugins/ExyliaKillCam/lang/<code>/` you can edit.
  </Step>
  <Step title="Edit the file">
    Open `lang/<code>/messages.yml` for chat and title text, or `lang/<code>/hotbar.yml` for the skip button.
  </Step>
  <Step title="Reload">
    Run `/killcamadmin reload`. It reloads `config.yml`, `messages.yml` and `hotbar.yml`.
  </Step>
</Steps>

## Check that it works

Die to a player. The title, the line above the hotbar and the summary show your text.

## What you can edit

Colours are palette tokens such as `{primary}` or `{error}`, so recolouring the server never means editing this file. See [Colours](/docs/exylialib/colours) and [Messages and languages](/docs/exylialib/messages-and-languages). A message may start with `[sound:NAME|volume|pitch]` to play a sound. An empty message is not sent at all, which is how you turn one off.

| Key | Where | Values you can use |
|---|---|---|
| `title`, `subtitle` | Shown as the killcam starts | `%killer%` |
| `hud` | Line above the hotbar | `%killer%` `%time%` `%length%` `%bar%` |
| `bar-done`, `bar-left` | One step of the 16-step progress bar | |
| `hit` | Each hit the victim took | `%player%` `%damage%` `%number%` |
| `summary` | Lines after the killcam | `%killer%` `%health%` `%weapon%` `%distance%` |
| `fists` | Weapon name when the killer's hand was empty | |
| `offer` | Chat line for players in `ASK` | `%killer%` |
| `no-recent-death`, `unsupported`, `busy`, `failed` | Refusals of `/killcam` | |
| `mode-set`, `mode-auto`, `mode-ask`, `mode-off` | `/killcam mode` answer and the labels on `/settings` | `%mode%` |
| `reloaded` | `/killcamadmin reload` | |
| `prefix` | Opens every chat line as `%prefix%` | |

The **[▶ WATCH AGAIN]** and **[▶ WATCH KILLCAM]** buttons are MiniMessage `<click:run_command:'/killcam'>` tags inside `summary` and `offer`. Keep the tag when restyling them.

## The skip button

`lang/<code>/hotbar.yml` defines one item, `skip`, in slot 4 (slots 0 to 8 are the hotbar), a barrier named "Killcam ▸ Skip" whose action `exyliakillcam:skip` leaves the killcam. It is drawn on the client by ExyliaLib's overlays and never enters the inventory: the player's own items stay underneath and come back afterwards. `lock: FULL` freezes the inventory, `pickup: false` blocks picking up, `hide_rest: true` hides the other slots. See [Overlays](/docs/exylialib/overlays).

If the file is missing or broken the console says so and no button is shown; `/killcam skip` still works.
