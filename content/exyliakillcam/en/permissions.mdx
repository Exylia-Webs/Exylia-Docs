---
title: "Permissions"
description: "Every node the plugin declares, what each one gates, and their defaults."
---

Every node below is declared in `plugin.yml`. Killcams are for everyone by default; reloading is for
operators.

| Permission | Default | What it gates |
|---|---|---|
| `exyliakillcam.use` | everyone | Getting a killcam after dying, `/killcam`, `/killcam skip`, `/killcam mode` and the **Killcam** choice on `/settings`. Without it a death is not kept at all. |
| `exyliakillcam.admin` | operators | `/killcam reload`. |
| `exyliakillcam.*` | operators | Both of the above. |

## Examples

No killcams for a group, whose deaths then go on as usual:

```text
/lp group hardcore permission set exyliakillcam.use false
```

Letting a helper reload the plugin:

```text
/lp user Steve permission set exyliakillcam.admin true
```
