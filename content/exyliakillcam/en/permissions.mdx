Killcams work for everyone without any setup. Only reloading and the settings menu are for operators. Each player feature has its own node, so you can make one a rank perk by denying it to the default group.

## All permissions

<Permissions />

`/killcam skip` needs no permission: leaving a killcam always works.

## Examples

With LuckPerms:

```text
/lp group hardcore permission set exyliakillcam.use false
/lp group vip permission set exyliakillcam.rewatch.30 true
/lp user Steve permission set exyliakillcam.admin true
```

The first removes killcams for a group (their deaths go on as usual), the second gives a rank 30 minutes to rewatch (the highest number a player holds wins), the third lets a helper reload the plugin. See [Decide who gets a killcam](/docs/exyliakillcam/who-gets-one).
