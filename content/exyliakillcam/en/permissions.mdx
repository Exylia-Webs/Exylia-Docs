---
title: "Permissions"
description: "Every node the plugin declares, what each one gates, and their defaults."
---

Every node below is declared in `plugin.yml`. Killcams are for everyone by default; reloading and the
settings are for operators. Each player feature has its own node, so a server can make one a rank perk
by denying it to the default group.

| Permission | Default | What it gates |
|---|---|---|
| `exyliakillcam.use` | everyone | Getting a killcam after dying. Without it a death is not kept at all. |
| `exyliakillcam.rewatch` | everyone | `/killcam`, watching the last death again. |
| `exyliakillcam.mode` | everyone | `/killcam mode` and the **Killcam** choice on `/settings`. |
| `exyliakillcam.rewatch.<n>` | not declared | Rank value: `<n>` minutes `/killcam` can still show the last death. The highest one a player holds wins; without one, `killcam.rewatch-minutes` applies. |
| `exyliakillcam.admin` | operators | `/killcamadmin reload` and `/killcamadmin settings`. |
| `exyliakillcam.*` | operators | The four declared nodes above. |

`/killcam skip` needs no permission: getting out of a killcam always works.

## Examples

No killcams for a group, whose deaths then go on as usual:

```text
/lp group hardcore permission set exyliakillcam.use false
```

A longer rewatch window for a rank (the highest number wins):

```text
/lp group vip permission set exyliakillcam.rewatch.30 true
```

Letting a helper reload the plugin:

```text
/lp user Steve permission set exyliakillcam.admin true
```
