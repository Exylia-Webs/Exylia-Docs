Al terminar esta página los textos que leen los jugadores en una killcam dicen lo que quieras, con tus colores.

## Pasos

<Steps>
  <Step title="Elige el idioma">
    En `plugins/ExyliaKillCam/config.yml`, `language` es `default` (sigue a ExyliaLib) o uno de `en`, `es`, `pt`, `fr`, `ru`, `tr`, `de`. Cada uno es una carpeta `plugins/ExyliaKillCam/lang/<código>/` que puedes editar.
  </Step>
  <Step title="Edita el archivo">
    Abre `lang/<código>/messages.yml` para el chat y el título, o `lang/<código>/hotbar.yml` para el botón de saltar.
  </Step>
  <Step title="Recarga">
    Ejecuta `/killcamadmin reload`. Recarga `config.yml`, `messages.yml` y `hotbar.yml`.
  </Step>
</Steps>

## Comprueba que funciona

Muere a manos de un jugador. El título, la línea sobre la barra rápida y el resumen muestran tu texto.

## Qué puedes editar

Los colores son tokens de la paleta como `{primary}` o `{error}`, así que recolorear el servidor nunca obliga a editar este archivo. Mira [Colores](/docs/exylialib/colores) y [Mensajes e idiomas](/docs/exylialib/mensajes-e-idiomas). Un mensaje puede empezar con `[sound:NOMBRE|volumen|tono]` para reproducir un sonido. Un mensaje vacío no se envía, así es como se apaga uno.

| Clave | Dónde | Valores que puedes usar |
|---|---|---|
| `title`, `subtitle` | Al empezar la killcam | `%killer%` |
| `hud` | Línea sobre la barra rápida | `%killer%` `%time%` `%length%` `%bar%` |
| `bar-done`, `bar-left` | Un paso de la barra de progreso de 16 pasos | |
| `hit` | Cada golpe que recibió la víctima | `%player%` `%damage%` `%number%` |
| `summary` | Líneas tras la killcam | `%killer%` `%health%` `%weapon%` `%distance%` |
| `fists` | Nombre del arma si el asesino tenía la mano vacía | |
| `offer` | Línea de chat para jugadores en `ASK` | `%killer%` |
| `no-recent-death`, `unsupported`, `busy`, `failed` | Negativas de `/killcam` | |
| `mode-set`, `mode-auto`, `mode-ask`, `mode-off` | Respuesta de `/killcam mode` y etiquetas de `/settings` | `%mode%` |
| `reloaded` | `/killcamadmin reload` | |
| `prefix` | Abre cada línea de chat como `%prefix%` | |

Los botones **[▶ VER DE NUEVO]** y **[▶ VER KILLCAM]** son etiquetas MiniMessage `<click:run_command:'/killcam'>` dentro de `summary` y `offer`. Conserva la etiqueta al cambiarles el estilo.

## El botón de saltar

`lang/<código>/hotbar.yml` define un objeto, `skip`, en la casilla 4 (las casillas 0 a 8 son la barra rápida), una barrera llamada "Killcam ▸ Saltar" cuya acción `exyliakillcam:skip` sale de la killcam. Lo dibuja el cliente con los overlays de ExyliaLib y nunca entra en el inventario: los objetos del jugador siguen debajo y vuelven después. `lock: FULL` congela el inventario, `pickup: false` impide recoger objetos y `hide_rest: true` oculta las demás casillas. Mira [Overlays](/docs/exylialib/overlays).

Si el archivo falta o está roto, la consola lo avisa y no se muestra el botón; `/killcam skip` sigue funcionando.
