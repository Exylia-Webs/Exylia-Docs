Las killcams funcionan para todos sin configurar nada. Solo recargar y el menú de ajustes son para operadores. Cada función de jugador tiene su propio nodo, así que puedes hacer que una sea un extra de rango negándola al grupo por defecto.

## Todos los permisos

<Permissions />

`/killcam skip` no necesita permiso: salir de una killcam siempre funciona.

## Ejemplos

Con LuckPerms:

```text
/lp group hardcore permission set exyliakillcam.use false
/lp group vip permission set exyliakillcam.rewatch.30 true
/lp user Steve permission set exyliakillcam.admin true
```

La primera quita las killcams a un grupo (sus muertes siguen como siempre), la segunda da a un rango 30 minutos para repetir (gana el número más alto que tenga el jugador), la tercera deja a un ayudante recargar el plugin. Mira [Decide quién recibe una killcam](/docs/exyliakillcam/quien-la-recibe).
