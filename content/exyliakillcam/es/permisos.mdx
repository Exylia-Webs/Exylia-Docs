---
title: "Permisos"
description: "Cada nodo que declara el plugin, qué controla y sus valores por defecto."
---

Todos los nodos de abajo están declarados en `plugin.yml`. Las killcams son para todos por defecto;
recargar y los ajustes son para operadores. Cada función de jugador tiene su propio nodo, así que un
servidor puede convertir una en ventaja de rango negándola al grupo por defecto.

| Permiso | Por defecto | Qué controla |
|---|---|---|
| `exyliakillcam.use` | todos | Tener killcam al morir. Sin él la muerte no se guarda en absoluto. |
| `exyliakillcam.rewatch` | todos | `/killcam`, volver a ver la última muerte. |
| `exyliakillcam.mode` | todos | `/killcam mode` y la opción **Killcam** de `/settings`. |
| `exyliakillcam.rewatch.<n>` | no declarado | Valor de rango: `<n>` minutos que `/killcam` puede mostrar aún la última muerte. Gana el más alto que tenga el jugador; sin ninguno, vale `killcam.rewatch-minutes`. |
| `exyliakillcam.admin` | operadores | `/killcamadmin reload` y `/killcamadmin settings`. |
| `exyliakillcam.*` | operadores | Los cuatro nodos declarados anteriores. |

`/killcam skip` no necesita permiso: salir de una killcam siempre funciona.

## Ejemplos

Sin killcams para un grupo, cuyas muertes siguen entonces como siempre:

```text
/lp group hardcore permission set exyliakillcam.use false
```

Una ventana de repetición más larga para un rango (gana el número más alto):

```text
/lp group vip permission set exyliakillcam.rewatch.30 true
```

Dejar que un ayudante recargue el plugin:

```text
/lp user Steve permission set exyliakillcam.admin true
```
