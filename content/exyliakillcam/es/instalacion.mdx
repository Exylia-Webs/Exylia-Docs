Al terminar esta página, ExyliaKillCam funciona y está grabando. No hay nada que configurar antes.

## Antes de empezar

| Plugin | Para qué |
|---|---|
| `ExyliaLib` | Obligatorio. Graba las peleas, mueve la cámara y guarda la elección de cada jugador. Mira [instala ExyliaLib](/docs/exylialib/instalacion). |
| `PacketEvents` | Obligatorio para mostrar una killcam. Instálalo junto a ExyliaLib. |
| `ExyliaKillEffect` 1.9.0+ | Opcional. El efecto de kill del asesino se repite al final. |

El plugin necesita Paper o Folia 1.21 o superior y Java 21.

## Pasos

<Steps>
  <Step title="Descarga">
    ExyliaKillCam es gratis. Descarga `ExyliaKillCam.jar` de las [releases de GitHub](https://github.com/Exylia-Plugins/ExyliaKillCam/releases). El jar mantiene el mismo nombre en cada versión.
  </Step>
  <Step title="Copia los jars">
    Pon `ExyliaKillCam.jar` en `plugins/`, junto a ExyliaLib y PacketEvents.
  </Step>
  <Step title="Arranca el servidor">
    El plugin escribe sus archivos y empieza a grabar enseguida.
  </Step>
</Steps>

## Comprueba que funciona

La consola muestra ExyliaKillCam activado y existe la carpeta `plugins/ExyliaKillCam/`. Para ver una killcam sigue [Tu primera killcam](/docs/exyliakillcam/primeros-pasos).

Si falta ExyliaLib, el plugin se queda apagado y la consola dice qué versión necesita y dónde descargarla. No se descarga nada solo. Instálalo y reinicia.

Si falta PacketEvents, el plugin arranca pero nunca se muestra una killcam: `/killcam` responde que las killcams no se pueden mostrar en este servidor porque falta PacketEvents.

## Archivos que crea

Todo está en `plugins/ExyliaKillCam/`.

| Archivo | Qué contiene |
|---|---|
| `config.yml` | El modo con el que empiezan los jugadores, la duración y la toma, qué muertes cuentan, la grabación. Mira [Configuración](/docs/exyliakillcam/configuracion). |
| `lang/<código>/messages.yml` | Cada línea que envía el plugin. Mira [Edita los mensajes y el botón de saltar](/docs/exyliakillcam/mensajes). |
| `lang/<código>/hotbar.yml` | El botón de saltar que se ve mientras miras. |
| `lang/<código>/menus/admin/` | Los menús de ajustes de `/killcamadmin settings`. |

`<código>` es `en`, `es`, `pt`, `fr`, `ru` o `tr`. Con `language: default` en `config.yml` sigue el idioma de `config.yml` de ExyliaLib.

El plugin no tiene base de datos. El modo que elige cada jugador lo guarda ExyliaLib, y las grabaciones viven solo en memoria y se pierden al reiniciar.

## Actualizar

ExyliaLib vigila las releases de GitHub de este plugin. Una versión nueva se anuncia en la consola y a los admins; nada se descarga solo. `/exylialib plugins` la descarga y se aplica en el siguiente reinicio. Para actualizar a mano, cambia el jar y reinicia. Tus cambios en `config.yml` y en los archivos de lang se conservan.
