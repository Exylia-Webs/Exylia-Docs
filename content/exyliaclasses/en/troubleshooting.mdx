  - "Why does the class placeholder say Ninguna?"
  - "Why did a player lose their class?"

Find your symptom, then follow the fix.

## The plugin stays off

ExyliaClasses needs ExyliaLib. Without it the plugin loads, prints in the console where to get it and does nothing until it is installed. See [Install ExyliaClasses](/docs/exyliaclasses/installation).

## Nobody enters a class

Check three things in order:

1. The armour matches the class file in **every** slot the file lists.
2. The player holds the class's `permission`, unless it is `NONE`. Without it chat says "You don't have permission to use the class".
3. The console has no "Invalid material" warning from that file. A misspelled material is dropped from the requirements, which changes what the class asks for.

## Two classes fight over one armour set

Give them different sets. A player is matched against the classes in no fixed order, so two classes that ask for the same set hand out one or the other unpredictably.

## The warmup takes a second longer than I wrote

That is expected. The first countdown message arrives after one second and the class starts one second after the message that reads `1`, so `time: 5` lands at six seconds.

## A player lost their class

Death and disconnect end a class. So does any armour change that breaks the set: a piece breaking from durability, or another plugin swapping their gear.

## Ability items keep disappearing

Each successful use consumes one item, by design. A failed use (on cooldown, not enough energy) consumes nothing.

## An ability does nothing

If its `type` is `TO_ALLY`, that is why: that type reaches nobody, yet it still spends energy, starts the cooldown and consumes the item. Use `TO_CLAN`. See [Abilities](/docs/exyliaclasses/abilities).

## Clan abilities only reach the caster

No clan plugin is installed, or the caster is in no clan. With no clan plugin every player counts as clanless.

## Enemy abilities hit my own team

The same cause from the other side. Without a clan plugin nobody shares a clan, so `TO_ENEMY` means everyone in range. On a server without clans, keep enemy radii small.

## Marks do not add damage

They are not meant to. A mark level's `extra-damage` is a number shown in messages, the mark bar and `%exyliaclasses_classes_mark_extra_damage%`. Backstab `extra-damage` is different: that one is real damage. See [Weapons](/docs/exyliaclasses/weapons).

## Marks never expire

The mark bar times marks out. With `mark-bar.enabled: false` in `config.yml` nothing counts down, so marks last until the player dies, quits or leaves the class.

## Energy is stuck at zero

The class has no `energy` block, so an ability with an `energy-cost` can never be used, or the player just entered the class. Energy starts at zero and fills from there. See [Energy](/docs/exyliaclasses/energy).

## The class placeholder says "Ninguna"

That is the fixed answer `%exyliaclasses_classes_class%` gives when the player is in no class. Hide the line behind `%exyliaclasses_classes_in_class%`. See [Placeholders](/docs/exyliaclasses/placeholders).

## Placeholders show as text

PlaceholderAPI is missing, or the name has no plugin in front. Outside Exylia plugins use `%exyliaclasses_classes_class%`.

## My new class file does not appear in the web editor

The files the web editor lists are the ones present at server start. A file added later waits for a restart. `/classesadmin reload` still loads it as a class.
