At the end of this page you have worn a class, seen the warmup and used its first ability. You do not edit any file and there is no command for players: a class is a set of armour, and an ability is an item you right-click.

## Before you start

Install the plugin and ExyliaLib, then start the server once. See [Install ExyliaClasses](/docs/exyliaclasses/installation). The six classes are ready to use.

## Steps

<Steps>
  <Step title="Get the armour">
    The Archer wears a full leather set. Run these four commands, or take the pieces from creative:

    ```text
    /give @s minecraft:leather_helmet
    /give @s minecraft:leather_chestplate
    /give @s minecraft:leather_leggings
    /give @s minecraft:leather_boots
    ```
  </Step>
  <Step title="Put it on">
    Wear all four pieces. A countdown appears in chat: "Joining ARCHER in 5s". Keep the armour on until it finishes.
  </Step>
  <Step title="Check you are an Archer">
    Chat says "You are now ARCHER!". You now have Speed and Resistance for as long as you wear the set.
  </Step>
  <Step title="Get an ability item">
    The Archer's abilities are tied to items: sugar gives a burst of Speed and a feather gives a jump boost. Run `/give @s minecraft:sugar`.
  </Step>
  <Step title="Use it">
    Right-click with the sugar. You get a short burst of Speed, the item is used up and the ability goes on cooldown (30 seconds for sugar).
  </Step>
  <Step title="Leave the class">
    Take one armour piece off. Chat says you are no longer ARCHER and the effects stop.
  </Step>
</Steps>

## Check that it works

You should see the countdown, the "You are now ARCHER!" message and the effects in your status icons. If nothing happens, see [Common problems](/docs/exyliaclasses/troubleshooting).

## The six classes

| Class | Armour |
|---|---|
| Archer | Leather |
| Bard | Gold |
| Miner | Iron |
| Rogue | Chainmail |
| Sorcerer | Gold helmet and boots, chainmail chestplate and leggings |
| Tank | Turtle helmet, netherite chestplate, leggings and boots |

## Make your own class

A class is one file in `plugins/ExyliaClasses/lang/<language>/classes/`, and the file name is its id. Create `Medic.yml` next to the six that ship:

```yaml title="lang/en/classes/Medic.yml"
display-name: "<#63ff8a><bold>MEDIC</bold>"
permission: "NONE"

equipment:
  helmet: DIAMOND_HELMET
  chestplate: DIAMOND_CHESTPLATE
  leggings: DIAMOND_LEGGINGS
  boots: DIAMOND_BOOTS

passive-effects:
  - REGENERATION|1
  - SPEED|1
```

Run `/classesadmin reload` and put on a full diamond set: after the default five-second warmup you are a Medic. `permission: "NONE"` means anyone can wear it, and `REGENERATION|1` is Regeneration I.

<Callout type="warning" title="Two classes must not share an armour set">
A player is matched against every class until one fits, in no fixed order. If two classes ask for full diamond, which one a player gets is unpredictable.
</Callout>
