## Sell a class to a rank

Each class file names the node a player needs, in its `permission` key. The six shipped files use `exyliaclasses.class.<id>` (for example `exyliaclasses.class.bard`), which everyone holds by default. To sell a class, deny its node to the default group and grant it to the rank. With LuckPerms:

```text
/lp group default permission set exyliaclasses.class.bard false
/lp group default permission set exyliaclasses.class.rogue false
/lp group vip permission set exyliaclasses.class.bard true
/lp group vip permission set exyliaclasses.class.rogue true
```

A player who wears the armour without the node sees the `no-permission` message and no warmup starts. They are not in any class, and no other class is tried in its place.

## The `permission` key in a class file

| Value | Meaning |
|---|---|
| `"NONE"` | Anyone may wear the class. |
| Blank, or the key missing | The same as `NONE`. |
| Any other text | A node the player must hold, checked exactly as written. |

A server that already had class files keeps the `NONE` it had. Change the key in the file to gate that class. A node you invent for a custom class is registered by nothing, so pick a naming scheme and stay in it.

<Callout type="tip" title="Wildcards follow your naming">
`exyliaclasses.class.*` covers every class only if every class file uses that prefix. A file that says `permission: "ranks.premium"` is checked exactly as written.
</Callout>

<Callout type="warning" title="A gated class is a dead armour set">
A player without the node cannot enter the class, and cannot enter any other class in that armour either. If two classes could share a set, give the free one a different set.
</Callout>
