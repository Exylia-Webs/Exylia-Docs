## config.yml

```yaml title="config.yml"
language: default
debug: false

energy-bar:
  enabled: true
  colour: "YELLOW"
  overlay: "NOTCHED_20"

mark-bar:
  enabled: true
  colour: "RED"
  overlay: "PROGRESS"
```

| Clave | Por defecto | Qué hace |
|---|---|---|
| `language` | `default` | De qué carpeta de `lang/` se leen los mensajes. Ver abajo. |
| `debug` | `false` | Imprime en consola el estado de las integraciones y el detalle de carga. |
| `energy-bar` | ver arriba | La barra de energía. |
| `mark-bar` | ver arriba | La barra de marca. |

Las dos barras usan las mismas tres claves. Sus títulos son texto, así que viven en `messages.yml` bajo
`boss-bars`; los valores disponibles dentro de cada uno están en [Energía](/docs/exyliaclasses/energia).

### language

`default` sigue el `language` del propio `config.yml` de ExyliaLib, así que una línea allí cambia todos
los plugins de Exylia; `en`, `es`, `pt`, `fr` o `ru` fijan solo este plugin. Cada idioma es una carpeta
dentro de `plugins/ExyliaClasses/lang/` con su propio `messages.yml`, que puedes editar. Un `language`
cambiado entra con `/classes reload`.

<Callout type="note" title="Los servidores que venían de 1.0.0 conservan sus cambios">
En el primer arranque de 1.1.0 el `messages.yml` existente se adopta como `lang/custom/` y `config.yml`
apunta ahí con `language: custom`, así que no se pierde nada de lo que el servidor editó. Los dos títulos
de barra que antes eran `energy-bar.text` y `mark-bar.text` pasan a ese `messages.yml` como
`boss-bars.energy` y `boss-bars.mark`. Pon `language` en `default` o en un código para pasar a las
traducciones que vienen.
</Callout>

## messages.yml

Cada mensaje acepta tokens de paleta de Exylia (`{primary}`, `{success}`, `{error}`, `{muted}`,
`{highlight}`, `{warning}`), etiquetas de color, códigos `&` clásicos y placeholders. Un mensaje que
empiece por `[sound:NOMBRE|VOLUMEN|TONO]` reproduce ese sonido al enviarse. Vive en `lang/<language>/messages.yml`.

```yaml title="lang/en/messages.yml"
prefix: "{primary}&lEXYLIA CLASSES &8•&r"
no-permission: "[sound:ENTITY_VILLAGER_NO|1.0|1.0]{primary}&lEXYLIA CLASSES &8•&r {error}You don't have permission to use the class {highlight}%class%{error}."

warmup:
  timer: "..."
  ready: "..."
  canceled: "..."

class-section:
  removed: "..."

abilities:
  cooldown: "..."
  used: "..."
  clan: "..."
  enemy: "..."
  no-energy: "..."

weapons:
  mark:
    applied: "..."
    received: "..."
    expired: "..."
    same-class: "..."
  backstab:
    success: "..."
    victim: "..."
    no-cooldown: "..."
    cant-dead: "..."

command:
  reload: "..."
  no-permission: "..."

boss-bars:
  energy: "%energy_color%%symbol% %energy% / %max%"
  mark: "%mark_color%%mark_icon% +%extra_damage%% {muted}(%time%)"
```

### Cada mensaje y sus placeholders propios

| Mensaje | Se envía a | Acepta |
|---|---|---|
| `prefix` | — | El valor de `%prefix%` para el texto de este plugin. |
| `no-permission` | Al jugador, al ponerse la armadura de una clase bloqueada | `%class%` |
| `warmup.timer` | Al jugador, una vez por segundo durante el warmup | `%class%`, `%time%` (segundos enteros), `%duration%` (formateado, `5s`) |
| `warmup.ready` | Al jugador, cuando la clase se activa | `%class%` |
| `warmup.canceled` | Al jugador, cuando el warmup se interrumpe | — |
| `class-section.removed` | Al jugador, cuando la clase termina | `%class%` |
| `abilities.cooldown` | Al lanzador | `%ability%`, `%time%`, `%duration%` (formateado con décimas, `4.3s`) |
| `abilities.used` | Al lanzador, al acertar | `%ability%` |
| `abilities.clan` | A cada objetivo del clan que no sea el lanzador | `%player%`, `%ability%` |
| `abilities.enemy` | A cada objetivo enemigo | `%player%`, `%ability%` |
| `abilities.no-energy` | Al lanzador | `%needed%`, `%current%` |
| `weapons.mark.applied` | Al tirador | `%target%`, `%damage%` |
| `weapons.mark.received` | Al jugador marcado | `%attacker%`, `%damage%` |
| `weapons.mark.expired` | Al jugador marcado, cuando la barra se vacía | — |
| `weapons.mark.same-class` | Al tirador | — |
| `weapons.backstab.success` | Al atacante | — |
| `weapons.backstab.victim` | Al objetivo | `%attacker%` |
| `weapons.backstab.no-cooldown` | Al atacante | `%current%`, `%needed%` — los dos en porcentaje |
| `weapons.backstab.cant-dead` | Al atacante | — |
| `command.reload` | A quien ejecutó el comando | — |
| `command.no-permission` | A quien ejecutó el comando | — |
| `boss-bars.energy` | El título de la barra de energía | Ver [Energía](/docs/exyliaclasses/energia#valores-disponibles-en-cada-barra) |
| `boss-bars.mark` | El título de la barra de marca | Ver [Energía](/docs/exyliaclasses/energia#valores-disponibles-en-cada-barra) |

Cualquier [placeholder](/docs/exyliaclasses/placeholders) funciona también en todos ellos, resuelto
para quien recibe el mensaje.

<Callout type="note" title="%class% y %ability% llevan sus propios colores">
Se insertan como texto formateado, no como literales, así que el `<#c8c8c8><bold>ARCHER</bold>` escrito
en el archivo de clase se ve como color en vez de imprimir las etiquetas.
</Callout>

<Callout type="tip" title="El prefijo de sonido es parte del mensaje">
`[sound:ENTITY_VILLAGER_NO|1.0|1.0]` al principio de una línea reproduce ese sonido y se quita de lo
que lee el jugador. Bórralo y el mensaje sale en silencio.
</Callout>

## Lo que estos archivos no controlan

Las clases en sí no están en `config.yml`. Armadura, habilidades, armas, pasivas y energía viven en los
[archivos de clase](/docs/exyliaclasses/clases).
