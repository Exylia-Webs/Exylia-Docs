## El nodo propio del plugin

| Permiso | Da acceso a |
|---|---|
| `exyliaclasses.admin.reload` | `/classesadmin reload`. Solo op por defecto. |
| `exyliaclasses.admin.settings` | `/classesadmin settings`, y editar los archivos de clase en el juego y en el editor web. Solo op por defecto. |
| `exyliaclasses.class.archer`, `.bard`, `.miner`, `.rogue`, `.sorcerer`, `.tank` | Llevar esa clase. Se concede a todos por defecto; los archivos de clase incluidos los nombran. |

No hay nodo para entrar en una clase en general, ni para usar una
habilidad, ni para un arma.

## Nodos por clase

Una clase se limita a sí misma con la clave `permission` de su propio archivo, y el nodo es lo que tú
escribas ahí:

```yaml title="lang/es/classes/Rogue.yml"
permission: "exyliaclasses.class.rogue"
```

| Valor | Significado |
|---|---|
| `"NONE"` | Cualquiera puede usar la clase. |
| Vacío, o la clave ausente | Lo mismo que `NONE`. |
| Cualquier otra cosa | Un nodo de permiso que el jugador tiene que tener. |

Un jugador que lleve la armadura sin el nodo recibe el mensaje `no-permission` y ningún warmup.
Simplemente no está en ninguna clase — no se prueba otra clase en su lugar.

### Vender clases

Los seis archivos incluidos nombran `exyliaclasses.class.<id>`, que todos tienen por defecto, así que un
servidor vende una clase negando su nodo al grupo por defecto. Un servidor que ya tenía sus archivos
conserva el `NONE` que tenía; pon el nodo en el archivo para limitar una clase. Nada registra los nodos de
una clase propia, así que elige un esquema y mantente en él:

```text
/lp group default permission set exyliaclasses.class.archer true
/lp group default permission set exyliaclasses.class.miner true
/lp group vip permission set exyliaclasses.class.bard true
/lp group vip permission set exyliaclasses.class.rogue true
/lp group mvp permission set exyliaclasses.class.sorcerer true
```

<Callout type="tip" title="Los comodines funcionan porque el esquema lo eliges tú">
`exyliaclasses.class.*` solo cubre todo si cada archivo de clase usa ese prefijo. El plugin no lo
impone — un archivo que diga `permission: "ranks.premium"` se comprueba exactamente así.
</Callout>

<Callout type="warning" title="Una clase bloqueada sigue siendo una armadura muerta">
Un jugador sin el nodo no puede entrar en la clase, y tampoco en ninguna otra con esa armadura. Si dos
clases pudieran compartir un set, dale otro a la gratuita.
</Callout>
