---
title: "Placeholders"
description: "Cada placeholder que responde el plugin: las estadísticas, la vida y el kit actuales, la progresión, perks y mejoras, los valores por kit, las misiones, el némesis, las clasificaciones, los eventos, las temporadas y el grupo de red."
---

El plugin registra sus placeholders a través de ExyliaLib bajo el grupo `exyliarandomkits`, así que el nombre
es el mismo dentro de los archivos de los plugins de Exylia y a través de **PlaceholderAPI**:
`%exyliarandomkits_kills%`. No hay que descargar nada del eCloud. Cada valor se lee de memoria.

## Las estadísticas

| Placeholder | Valor |
|---|---|
| `%exyliarandomkits_kills%` | Kills. |
| `%exyliarandomkits_deaths%` | Muertes. |
| `%exyliarandomkits_assists%` | Asistencias. |
| `%exyliarandomkits_kdr%` | Kills por muerte. |
| `%exyliarandomkits_best_streak%` | La mejor racha de siempre. |
| `%exyliarandomkits_discovered%` | Cuántos kits ha tirado quien mira al menos una vez. |

## La vida actual

Vacíos fuera de una arena.

| Placeholder | Valor |
|---|---|
| `%exyliarandomkits_in_arena%` | Si quien mira está en una arena: `true` o `false`. |
| `%exyliarandomkits_arena%` | El id de la arena. |
| `%exyliarandomkits_streak%` | La racha de la vida. |
| `%exyliarandomkits_kit%` | El nombre del kit. |
| `%exyliarandomkits_kit_id%` | El id del kit. |
| `%exyliarandomkits_rarity%` | La rareza del kit, como la muestra `rarities.yml`. |
| `%exyliarandomkits_rarity_id%` | El id de la rareza del kit. |
| `%exyliarandomkits_rerolls_left%` | Rerolls que quedan en esta vida; `0` fuera de una arena. |

## Progresión

| Placeholder | Valor |
|---|---|
| `%exyliarandomkits_level%` | El nivel. |
| `%exyliarandomkits_xp%` | XP dentro del nivel actual. |
| `%exyliarandomkits_xp_needed%` | XP que necesita el nivel actual. |
| `%exyliarandomkits_prestige%` | El prestigio, como número. |
| `%exyliarandomkits_prestige_display%` | El prestigio como lo escribe `progression.prestige-display`. |
| `%exyliarandomkits_perk_slots%` | Huecos de perk. |
| `%exyliarandomkits_perks_equipped%` | Los nombres de los perks equipados, separados por comas. |
| `%exyliarandomkits_perks_equipped_count%` | Cuántos perks hay equipados. |
| `%exyliarandomkits_luck%` | El peso de rareza extra por rango de la mejora de suerte, en porcentaje. |
| `%exyliarandomkits_rewards_multiplier%` | El multiplicador de pagos y XP de mejoras y prestigio. |
| `%exyliarandomkits_missions_today%` | Misiones completadas hoy. |

## Por id

Todo lo que va después del nombre es el id, guiones bajos incluidos: `%exyliarandomkits_kit_level_void_walker%`.

| Placeholder | Valor |
|---|---|
| `%exyliarandomkits_upgrade_<id>%` | El nivel de una mejora de cuenta, como `%exyliarandomkits_upgrade_luck%`. |
| `%exyliarandomkits_perk_<id>%` | El nivel de un perk, como `%exyliarandomkits_perk_vampire%`. |
| `%exyliarandomkits_kit_level_<kit>%` | El nivel de un kit para quien mira. |
| `%exyliarandomkits_mastery_<kit>%` | El nivel de maestría de un kit para quien mira. |
| `%exyliarandomkits_mastery_title_<kit>%` | El título de ese nivel de maestría, de `progression.mastery-titles`. |
| `%exyliarandomkits_ascended_<kit>%` | Si el kit de quien mira es Ascended: `true` o `false`. |

## El némesis

| Placeholder | Valor |
|---|---|
| `%exyliarandomkits_nemesis%` | El némesis de quien mira; vacío si no hay. |
| `%exyliarandomkits_nemesis_kills%` | Cuántas veces mató el némesis a quien mira. |

## Clasificaciones

`<position>` cuenta desde 1. Sin `_value` el placeholder da el nombre del jugador (`-` para un puesto vacío);
con él, su valor (`0`). Cada clasificación guarda `stats.leaderboard-size` entradas (10).

| Placeholder | Valor |
|---|---|
| `%exyliarandomkits_top_kills_<position>%` | El nombre en ese puesto por kills. |
| `%exyliarandomkits_top_kills_<position>_value%` | Sus kills. |
| `%exyliarandomkits_top_kdr_<position>%` | El nombre en ese puesto por KDR. |
| `%exyliarandomkits_top_kdr_<position>_value%` | Su KDR. |
| `%exyliarandomkits_top_best_streak_<position>%` | El nombre en ese puesto por mejor racha. |
| `%exyliarandomkits_top_best_streak_<position>_value%` | Su mejor racha. |
| `%exyliarandomkits_top_level_<position>%` | El nombre en ese puesto por nivel. |
| `%exyliarandomkits_top_level_<position>_value%` | Su nivel. |
| `%exyliarandomkits_top_prestige_<position>%` | El nombre en ese puesto por prestigio. |
| `%exyliarandomkits_top_prestige_<position>_value%` | Su prestigio. |
| `%exyliarandomkits_top_season_kills_<position>%` | El nombre en ese puesto por kills esta temporada. |
| `%exyliarandomkits_top_season_kills_<position>_value%` | Sus kills esta temporada. |
| `%exyliarandomkits_top_season_kdr_<position>%` | El nombre en ese puesto por KDR esta temporada. |
| `%exyliarandomkits_top_season_kdr_<position>_value%` | Su KDR esta temporada. |
| `%exyliarandomkits_top_season_best_streak_<position>%` | El nombre en ese puesto por mejor racha esta temporada. |
| `%exyliarandomkits_top_season_best_streak_<position>_value%` | Su mejor racha esta temporada. |
| `%exyliarandomkits_top_season_xp_<position>%` | El nombre en ese puesto por XP esta temporada. |
| `%exyliarandomkits_top_season_xp_<position>_value%` | Su XP esta temporada. |

## El evento

El mismo en todos los servidores del grupo. Vacíos cuando no hay ninguno.

| Placeholder | Valor |
|---|---|
| `%exyliarandomkits_event_active%` | Si hay un evento en curso: `true` o `false`. |
| `%exyliarandomkits_event_id%` | Su id. |
| `%exyliarandomkits_event_name%` | Su nombre. |
| `%exyliarandomkits_event_type%` | Su tipo. |
| `%exyliarandomkits_event_time_left%` | El tiempo que le queda. |
| `%exyliarandomkits_event_next%` | El nombre del siguiente evento que lanza un horario o la rotación. |
| `%exyliarandomkits_event_next_in%` | Cuánto falta para que empiece. |
| `%exyliarandomkits_event_leader%` | King of the Arena: el nombre del líder. |
| `%exyliarandomkits_event_leader_kills%` | King of the Arena: las kills del líder (`0` si no hay). |
| `%exyliarandomkits_event_top_<position>%` | King of the Arena: el nombre en ese puesto (`-` si no hay). |
| `%exyliarandomkits_event_top_<position>_value%` | King of the Arena: sus kills (`0` si no hay). |
| `%exyliarandomkits_event_marked%` | Mythic Hunt: el jugador marcado en este servidor. |

## La temporada

| Placeholder | Valor |
|---|---|
| `%exyliarandomkits_season_id%` | El id de la temporada; vacío entre temporadas o con las temporadas desactivadas. |
| `%exyliarandomkits_season_name%` | Su nombre. |
| `%exyliarandomkits_season_number%` | Su número. |
| `%exyliarandomkits_season_time_left%` | El tiempo que le queda. |
| `%exyliarandomkits_season_kills%` | Las kills de quien mira esta temporada. |
| `%exyliarandomkits_season_deaths%` | Las muertes de quien mira esta temporada. |
| `%exyliarandomkits_season_kdr%` | El KDR de quien mira esta temporada. |
| `%exyliarandomkits_season_best_streak%` | La mejor racha de quien mira esta temporada. |
| `%exyliarandomkits_season_xp%` | La XP de quien mira esta temporada. |

## El grupo de red

De los últimos latidos de cada servidor del grupo. En un solo servidor, ese servidor.

| Placeholder | Valor |
|---|---|
| `%exyliarandomkits_network_players%` | Jugadores en todas las arenas del grupo. |
| `%exyliarandomkits_network_players_<arena>%` | Jugadores en esa arena, en todos los servidores del grupo. |
| `%exyliarandomkits_instances%` | Servidores del grupo que aceptan jugadores ahora. |

## Ejemplos

```text
%exyliarandomkits_kit% %exyliarandomkits_rarity%
%exyliarandomkits_top_kills_1%
%exyliarandomkits_top_kills_1_value%
%exyliarandomkits_mastery_title_warrior%
```
