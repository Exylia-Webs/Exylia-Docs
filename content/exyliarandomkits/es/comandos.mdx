Dos comandos: `/rk`, también `/randomkits`, para los jugadores, y `/rkadmin`, también `/randomkitsadmin`, para
el staff.

## Comandos de jugador

| Comando | Permiso | Qué hace |
|---|---|---|
| `/rk` | | El hub. |
| `/rk play [arena]` | `exyliarandomkits.play` | Entra en una arena: cualquiera lista, o la indicada. En una red, la del mejor servidor. |
| `/rk leave` | `exyliarandomkits.play` | Sale, devolviendo exactamente lo que traías. |
| `/rk draft` | `exyliarandomkits.play` | Vuelve a abrir las opciones del draft. |
| `/rk reroll` | `exyliarandomkits.play` | Vuelve a tirar el kit actual, mientras queden rerolls y la vida sea reciente. |
| `/rk kits` | `exyliarandomkits.play` | El catálogo de kits, con los que has descubierto. |
| `/rk layout` | `exyliarandomkits.play` | El editor de distribución. |
| `/rk layout save` | `exyliarandomkits.play` | Guarda dónde están los objetos de tu kit actual como tu distribución. Solo en una arena. |
| `/rk layout reset` | `exyliarandomkits.play` | Olvida tu distribución. |
| `/rk progress` | `exyliarandomkits.progress` | Nivel, prestigio y lo siguiente. |
| `/rk upgrades` | `exyliarandomkits.progress` | Mejoras de cuenta. |
| `/rk perks` | `exyliarandomkits.progress` | Desbloquear, subir y equipar perks. |
| `/rk missions` | `exyliarandomkits.progress` | Las misiones de hoy y de esta semana. |
| `/rk prestige` | `exyliarandomkits.progress` | Hace prestigio en el nivel máximo. |
| `/rk stats [jugador]` | `exyliarandomkits.stats` | Unas estadísticas: las tuyas, o las de ese jugador. |
| `/rk top [tabla]` | `exyliarandomkits.stats` | Una clasificación: `kills` (por defecto), `kdr`, `best_streak`, `level`, `prestige`, `season_kills`, `season_kdr`, `season_best_streak` o `season_xp`. |
| `/rk season` | `exyliarandomkits.stats` | La temporada, su clasificación y el archivo. |

`/rk stats <jugador>` y `/rk top` también funcionan desde la consola, como líneas de chat. `/rk stats <jugador>`
encuentra a los jugadores que el servidor ha visto; de cualquier otro dice que "nunca ha jugado a RandomKits".

Consulta [Jugar](/docs/exyliarandomkits/jugar).

<Callout type="note" title="Comandos en una arena">
En una arena solo funcionan los comandos de `allowed-commands`. La lista por defecto incluye `rk` y
`randomkits`, así que `/rk leave` siempre funciona.
</Callout>

## Comandos de admin

Todo lo que cuelga de `/rkadmin` necesita `exyliarandomkits.admin`, de los operadores por defecto. Los marcados
como **Jugador** necesitan que estés en el juego: leen dónde estás, tu selección o tu inventario.

| Comando | | Qué hace |
|---|---|---|
| `/rkadmin` | Jugador | El panel de admin: arenas, kits, rarezas, equilibrio de kits y recarga. |
| `/rkadmin setup` | Jugador | Un asistente guiado que construye una primera arena. Consulta [Arenas](/docs/exyliarandomkits/arenas#el-asistente-de-configuración). |
| `/rkadmin reload` | | Recarga los archivos, kits, arenas y menús. |
| `/rkadmin editor` | | Un enlace al editor web de este plugin. |
| `/rkadmin import <fuente> [file] [--apply] [--overwrite] [--enable]` | | Importa kits; una prueba sin `--apply`. Consulta [Importar kits](/docs/exyliarandomkits/editor-web-e-importacion#importar-kits). |

### Arenas

| Comando | | Qué hace |
|---|---|---|
| `/rkadmin arena create <id>` | Jugador | Crea una arena en tu mundo. |
| `/rkadmin arena delete <id>` | | Borra una; sus jugadores salen antes. |
| `/rkadmin arena setregion <id> <pvp\|safe>` | Jugador | Selecciona con la varita la caja de pelea o la caja segura. |
| `/rkadmin arena setspawn <id>` | Jugador | Hace de donde estás el único spawn. |
| `/rkadmin arena addspawn <id>` | Jugador | Añade un spawn donde estás. |
| `/rkadmin arena pool <id> <kits...\|all>` | | Los kits que tira la arena. |
| `/rkadmin arena mode <id> <RANDOM\|DRAFT>` | | Cómo se elige el kit de una vida. |
| `/rkadmin arena protection <id> <segundos>` | | La protección de spawn. |
| `/rkadmin arena schematic <id>` | | Guarda la caja de pelea como los bloques que pone cada reinicio. |
| `/rkadmin arena reset <id>` | | Reinicia ahora. |
| `/rkadmin arena interval <id> <segundos>` | | Reinicia cada cierto tiempo; `0` nunca. |

### Kits

| Comando | | Qué hace |
|---|---|---|
| `/rkadmin kit save <id> [rareza]` | Jugador | Guarda tu inventario como un kit, una ranura por objeto. |
| `/rkadmin kit delete <id>` | | Borra un kit, sin preguntar. |
| `/rkadmin kit name <id> <nombre>` | | Le cambia el nombre; puede tener espacios. |
| `/rkadmin kit rarity <id> <rareza>` | | Fija su rareza. |
| `/rkadmin kit weight <id> <peso>` | | Fija su peso, y reinicia sus números de balance. |
| `/rkadmin kit permission <id> <permiso\|none>` | | Fija el permiso necesario para tirarlo; `none` lo deja para todos. |
| `/rkadmin give <jugador> [kit]` | | Fuerza una tirada nueva, o un kit concreto, a un jugador que está en una arena. |

Las ranuras y variantes se editan en el panel o en el editor web.

### Eventos y temporadas

| Comando | Qué hace |
|---|---|
| `/rkadmin event start <id>` | Lanza un evento. |
| `/rkadmin event stop [id]` | Para el evento en curso. |
| `/rkadmin event status` | Qué hay ahora y qué viene después. |
| `/rkadmin season start` | Abre una temporada, si no hay ninguna abierta. |
| `/rkadmin season end` | Cierra la temporada y paga sus premios. |
| `/rkadmin season status` | La temporada y el tiempo que le queda. |

### Soporte a jugadores

El jugador tiene que estar conectado en ese servidor: los cambios se escriben como cualquier otro cambio del
perfil.

| Comando | Qué hace |
|---|---|
| `/rkadmin player <jugador> level <n>` | Fija el nivel; la XP pasa a 0. |
| `/rkadmin player <jugador> xp <n>` | Da XP. |
| `/rkadmin player <jugador> prestige <n>` | Fija el prestigio. |
| `/rkadmin player <jugador> upgrade <id> <nivel>` | Fija el nivel de una mejora de cuenta. |
| `/rkadmin player <jugador> kitlevel <kit> <nivel>` | Fija el nivel de un kit. |
| `/rkadmin player <jugador> perk <id> <nivel>` | Fija el nivel de un perk. |
| `/rkadmin player <jugador> mission complete <id>` | Completa una de las misiones del jugador. |
| `/rkadmin player <jugador> mission reset` | Reinicia las misiones del jugador. |

## Acciones de menú

Las pantallas se abren unas a otras con estas acciones, y los menús propios de un servidor también pueden
usarlas. Cada una comprueba su permiso por sí misma.

| Acción | Permiso | Qué hace |
|---|---|---|
| `exyliarandomkits:open_hub` | `exyliarandomkits.play` | Abre el hub. |
| `exyliarandomkits:play` | `exyliarandomkits.play` | Abre la lista de arenas. |
| `exyliarandomkits:join [arena]` | `exyliarandomkits.play` | Entra en una arena, como `/rk play`. |
| `exyliarandomkits:leave` | `exyliarandomkits.play` | Sale de la arena. |
| `exyliarandomkits:open_draft` | `exyliarandomkits.play` | Vuelve a abrir las opciones del draft. |
| `exyliarandomkits:open_catalogue` | `exyliarandomkits.play` | Abre el catálogo de kits. |
| `exyliarandomkits:open_layout` | `exyliarandomkits.play` | Abre el editor de distribución. |
| `exyliarandomkits:reroll` | `exyliarandomkits.play` | Vuelve a tirar el kit. |
| `exyliarandomkits:open_progress` | `exyliarandomkits.progress` | Abre la pantalla de progreso. |
| `exyliarandomkits:open_upgrades` | `exyliarandomkits.progress` | Abre las mejoras de cuenta. |
| `exyliarandomkits:open_kit_upgrades` | `exyliarandomkits.progress` | Abre las mejoras de kit. |
| `exyliarandomkits:open_perks` | `exyliarandomkits.progress` | Abre los perks. |
| `exyliarandomkits:open_missions` | `exyliarandomkits.progress` | Abre las misiones. |
| `exyliarandomkits:prestige` | `exyliarandomkits.progress` | Abre la confirmación de prestigio. |
| `exyliarandomkits:open_stats [jugador]` | `exyliarandomkits.stats` | Abre las estadísticas de quien mira, o las de ese jugador. |
| `exyliarandomkits:open_top [tabla]` | `exyliarandomkits.stats` | Abre una clasificación, `kills` por defecto. |
| `exyliarandomkits:open_season` | `exyliarandomkits.stats` | Abre la temporada. |
| `exyliarandomkits:open_season_archive` | `exyliarandomkits.stats` | Abre el archivo de temporadas. |
| `exyliarandomkits:open_panel` | `exyliarandomkits.admin` | Abre el panel de admin. |
| `exyliarandomkits:open_arenas` | `exyliarandomkits.admin` | Abre la lista de arenas. |
| `exyliarandomkits:open_kits` | `exyliarandomkits.admin` | Abre la lista de kits. |
| `exyliarandomkits:open_rarities` | `exyliarandomkits.admin` | Abre las rarezas. |
| `exyliarandomkits:open_balance` | `exyliarandomkits.admin` | Abre el equilibrio de kits. |

Las demás acciones (elegir en el draft, los clics de la distribución, los botones de arena, kit, ranura,
variante e importación) solo funcionan dentro de sus propias pantallas.
