Two commands: `/rk`, also `/randomkits`, for players, and `/rkadmin`, also `/randomkitsadmin`, for staff.

## Player commands

| Command | Permission | What it does |
|---|---|---|
| `/rk` | | The hub. |
| `/rk play [arena]` | `exyliarandomkits.play` | Joins an arena: any ready one, or the one named. On a network, the best server's. |
| `/rk leave` | `exyliarandomkits.play` | Leaves, giving back exactly what you came with. |
| `/rk draft` | `exyliarandomkits.play` | Reopens the draft picks. |
| `/rk reroll` | `exyliarandomkits.play` | Rerolls the current kit, while rerolls are left and the life is fresh. |
| `/rk kits` | `exyliarandomkits.play` | The kit catalogue, with the kits you have discovered. |
| `/rk layout` | `exyliarandomkits.play` | The layout editor. |
| `/rk layout save` | `exyliarandomkits.play` | Saves where your current kit's items are as your layout. In an arena only. |
| `/rk layout reset` | `exyliarandomkits.play` | Forgets your layout. |
| `/rk progress` | `exyliarandomkits.progress` | Level, prestige and what is next. |
| `/rk upgrades` | `exyliarandomkits.progress` | Account upgrades. |
| `/rk perks` | `exyliarandomkits.progress` | Unlock, level and equip perks. |
| `/rk missions` | `exyliarandomkits.progress` | Today's and this week's missions. |
| `/rk prestige` | `exyliarandomkits.progress` | Prestiges at the top level. |
| `/rk stats [player]` | `exyliarandomkits.stats` | A record: yours, or that player's. |
| `/rk top [board]` | `exyliarandomkits.stats` | A leaderboard: `kills` (the default), `kdr`, `best_streak`, `level`, `prestige`, `season_kills`, `season_kdr`, `season_best_streak` or `season_xp`. |
| `/rk season` | `exyliarandomkits.stats` | The season, its board and the archive. |

`/rk stats <player>` and `/rk top` also work from the console, as chat lines. `/rk stats <player>` finds
players the server has seen; anyone else "has never played RandomKits".

See [Playing](/docs/exyliarandomkits/playing).

<Callout type="note" title="Commands in an arena">
In an arena only the commands in `allowed-commands` run. The default list includes `rk` and `randomkits`, so
`/rk leave` always works.
</Callout>

## Admin commands

Everything under `/rkadmin` needs `exyliarandomkits.admin`, operators by default. The ones marked **Player**
need you in game: they read where you stand, your selection or your inventory.

| Command | | What it does |
|---|---|---|
| `/rkadmin` | Player | The admin panel: arenas, kits, rarities, kit balance and reload. |
| `/rkadmin setup` | Player | A guided wizard that builds a first arena. See [Arenas](/docs/exyliarandomkits/arenas#the-setup-wizard). |
| `/rkadmin reload` | | Reloads the files, kits, arenas and menus. |
| `/rkadmin editor` | | A link to the web editor for this plugin. |
| `/rkadmin import <source> [file] [--apply] [--overwrite] [--enable]` | | Imports kits; a dry run without `--apply`. See [Importing kits](/docs/exyliarandomkits/web-editor-and-import#importing-kits). |

### Arenas

| Command | | What it does |
|---|---|---|
| `/rkadmin arena create <id>` | Player | Creates an arena in your world. |
| `/rkadmin arena delete <id>` | | Deletes one; its players leave first. |
| `/rkadmin arena setregion <id> <pvp\|safe>` | Player | Selects the fight box or the safe box with the wand. |
| `/rkadmin arena setspawn <id>` | Player | Makes where you stand the only spawn. |
| `/rkadmin arena addspawn <id>` | Player | Adds a spawn where you stand. |
| `/rkadmin arena pool <id> <kits...\|all>` | | The kits the arena rolls. |
| `/rkadmin arena mode <id> <RANDOM\|DRAFT>` | | How a life's kit is chosen. |
| `/rkadmin arena protection <id> <seconds>` | | Spawn protection. |
| `/rkadmin arena schematic <id>` | | Saves the fight box as the blocks every reset puts back. |
| `/rkadmin arena reset <id>` | | Resets now. |
| `/rkadmin arena interval <id> <seconds>` | | Resets every so often; `0` never. |

### Kits

| Command | | What it does |
|---|---|---|
| `/rkadmin kit save <id> [rarity]` | Player | Saves your inventory as a kit, one slot per item. |
| `/rkadmin kit delete <id>` | | Deletes a kit, without asking. |
| `/rkadmin kit name <id> <name>` | | Renames it; the name may have spaces. |
| `/rkadmin kit rarity <id> <rarity>` | | Sets its rarity. |
| `/rkadmin kit weight <id> <weight>` | | Sets its weight, and restarts its balance numbers. |
| `/rkadmin kit permission <id> <permission\|none>` | | Sets the permission needed to roll it; `none` lets everyone. |
| `/rkadmin give <player> [kit]` | | Forces a new roll, or a given kit, on a player in an arena. |

Slots and variants are edited in the panel or the web editor.

### Events and seasons

| Command | What it does |
|---|---|
| `/rkadmin event start <id>` | Starts an event. |
| `/rkadmin event stop [id]` | Stops the running event. |
| `/rkadmin event status` | What runs now and what is next. |
| `/rkadmin season start` | Opens a season, when none is open. |
| `/rkadmin season end` | Closes the season and pays its rewards. |
| `/rkadmin season status` | The season and its time left. |

### Player support

The player must be online on that server: changes are written like every other change to the profile.

| Command | What it does |
|---|---|
| `/rkadmin player <player> level <n>` | Sets the level; XP goes to 0. |
| `/rkadmin player <player> xp <n>` | Gives XP. |
| `/rkadmin player <player> prestige <n>` | Sets the prestige. |
| `/rkadmin player <player> upgrade <id> <level>` | Sets an account upgrade's level. |
| `/rkadmin player <player> kitlevel <kit> <level>` | Sets a kit's level. |
| `/rkadmin player <player> perk <id> <level>` | Sets a perk's level. |
| `/rkadmin player <player> mission complete <id>` | Completes one of the player's missions. |
| `/rkadmin player <player> mission reset` | Resets the player's missions. |

## Menu actions

The screens open each other through these, and a server's own menus can use them too. Each checks its
permission itself.

| Action | Permission | What it does |
|---|---|---|
| `exyliarandomkits:open_hub` | `exyliarandomkits.play` | Opens the hub. |
| `exyliarandomkits:play` | `exyliarandomkits.play` | Opens the arena list. |
| `exyliarandomkits:join [arena]` | `exyliarandomkits.play` | Joins an arena, as `/rk play`. |
| `exyliarandomkits:leave` | `exyliarandomkits.play` | Leaves the arena. |
| `exyliarandomkits:open_catalogue` | `exyliarandomkits.play` | Opens the kit catalogue. |
| `exyliarandomkits:open_draft` | `exyliarandomkits.play` | Reopens the draft picks. |
| `exyliarandomkits:open_layout` | `exyliarandomkits.play` | Opens the layout editor. |
| `exyliarandomkits:reroll` | `exyliarandomkits.play` | Rerolls the kit. |
| `exyliarandomkits:open_progress` | `exyliarandomkits.progress` | Opens the progression screen. |
| `exyliarandomkits:open_upgrades` | `exyliarandomkits.progress` | Opens the account upgrades. |
| `exyliarandomkits:open_kit_upgrades` | `exyliarandomkits.progress` | Opens the kit upgrades. |
| `exyliarandomkits:open_perks` | `exyliarandomkits.progress` | Opens the perks. |
| `exyliarandomkits:open_missions` | `exyliarandomkits.progress` | Opens the missions. |
| `exyliarandomkits:prestige` | `exyliarandomkits.progress` | Opens the prestige confirmation. |
| `exyliarandomkits:open_stats [player]` | `exyliarandomkits.stats` | Opens the viewer's stats, or that player's. |
| `exyliarandomkits:open_top [board]` | `exyliarandomkits.stats` | Opens a leaderboard, `kills` by default. |
| `exyliarandomkits:open_season` | `exyliarandomkits.stats` | Opens the season. |
| `exyliarandomkits:open_season_archive` | `exyliarandomkits.stats` | Opens the season archive. |
| `exyliarandomkits:open_panel` | `exyliarandomkits.admin` | Opens the admin panel. |
| `exyliarandomkits:open_arenas` | `exyliarandomkits.admin` | Opens the arena list. |
| `exyliarandomkits:open_kits` | `exyliarandomkits.admin` | Opens the kit list. |
| `exyliarandomkits:open_rarities` | `exyliarandomkits.admin` | Opens the rarities. |
| `exyliarandomkits:open_balance` | `exyliarandomkits.admin` | Opens the kit balance. |

The other actions (draft picks, layout clicks, the arena, kit, slot, variant and import buttons) only work
inside their own screens.
