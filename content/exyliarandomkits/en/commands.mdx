Two commands: `/rk` (also `/randomkits`) for players and `/rkadmin` (also `/randomkitsadmin`) for staff. Most player features also have a short command, such as `/perks` or `/reroll`. Every command, with the permission it needs:

<Commands />

## Player commands

A command with its own permission also needs the root it sits under, `exyliarandomkits.play` or `exyliarandomkits.progress`. Resetting a layout and unequipping a perk never need a permission, so a player can always back out. See [Permissions](/docs/exyliarandomkits/permissions).

`/stats <player>` and `/rk top` also work from the console and answer in chat lines. `/stats <player>` finds players the server has seen; anyone else "has never played RandomKits".

<Callout type="note" title="Commands in the arena">
Inside the arena only the commands in `allowed-commands` of `config.yml` run. The default list includes `rk` and `randomkits`.
</Callout>

## Admin commands

Everything under `/rkadmin` needs `exyliarandomkits.admin`, operators by default. The server has one arena, so the `arena` commands need no id: they act on it. The ones that ask you to stand somewhere or to select a region work in game only.

The arena commands are explained step by step in [Arenas](/docs/exyliarandomkits/arenas). Changing a player's level, upgrades or perks is for support: the player must be online on that server.

<Details title="Menu actions">
Menus open each other through actions, and your own menus can use them too. Each one checks its permission itself, so copying a button into a screen players can open gives them nothing they did not already have.

| Action | Permission | What it does |
|---|---|---|
| `exyliarandomkits:open_hub` | `exyliarandomkits.play` | Opens the hub. |
| `exyliarandomkits:open_draft` | `exyliarandomkits.play` + `exyliarandomkits.draft` | Reopens the draft picks. |
| `exyliarandomkits:open_layout` | `exyliarandomkits.play` + `exyliarandomkits.layout` | Opens the layout editor. |
| `exyliarandomkits:reroll` | `exyliarandomkits.play` + `exyliarandomkits.reroll` | Rerolls the items. |
| `exyliarandomkits:open_progress` | `exyliarandomkits.progress` | Opens the progression screen. |
| `exyliarandomkits:open_upgrades` | `exyliarandomkits.progress` + `exyliarandomkits.upgrades` | Opens the account upgrades. |
| `exyliarandomkits:open_perks` | `exyliarandomkits.progress` + `exyliarandomkits.perks` | Opens the perks. |
| `exyliarandomkits:open_missions` | `exyliarandomkits.progress` + `exyliarandomkits.missions` | Opens the missions. |
| `exyliarandomkits:prestige` | `exyliarandomkits.progress` + `exyliarandomkits.prestige` | Opens the prestige confirmation. |
| `exyliarandomkits:open_stats [player]` | `exyliarandomkits.stats` | Opens the viewer's stats, or that player's. |
| `exyliarandomkits:open_top [board]` | `exyliarandomkits.stats` | Opens a leaderboard, `kills` by default. |
| `exyliarandomkits:open_season` | `exyliarandomkits.stats` | Opens the season. |
| `exyliarandomkits:open_season_archive` | `exyliarandomkits.stats` | Opens the season archive. |
| `exyliarandomkits:open_panel`, `open_arenas`, `open_rarities`, `open_editor`, `settings`, `setup`, `reload` | `exyliarandomkits.admin` | The admin panel and its buttons. |

The other actions (draft picks, layout clicks, buy and equip buttons, page buttons) only work inside their own screens.
</Details>
