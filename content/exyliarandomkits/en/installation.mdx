ExyliaRandomKitsCore is a premium plugin, bought on [BuiltByBit](https://builtbybit.com/resources/exylia-randomkitscore.134730/). It ships through the Lukittu loader, so the file you install is the loader jar, `Exylia-RandomKitsCore-Loader.jar`. Bought on BuiltByBit, the licence is embedded in that jar: there is no key to enter. The loader checks the licence on every start and then hands over to the plugin.

## Before you start

You need Paper 1.21.4 or newer on Java 21, and the loader jar. The only required plugin is `ExyliaLib` (the newest release), and the loader installs it for you.

<Callout type="note" title="ExyliaLib is listed as soft, and installed for you">
The loader's `plugin.yml` names ExyliaLib under `softdepend` on purpose: the loader is what installs it, so the loader has to be allowed to start without it. On a server without ExyliaLib it downloads the newest release into `plugins/` and asks for a restart. On a server running an older release it stages the newest one and says so in the console; restart once more to apply it.
</Callout>

### Optional plugins

| Plugin | What it adds |
|---|---|
| `packetevents` | Only the extras drawn with packets. Without it the plugin loads and plays normally. |
| `PlaceholderAPI` | The plugin's placeholders in other plugins: scoreboards, tab, holograms. See [Placeholders](/docs/exyliarandomkits/placeholders). |
| `FastAsyncWorldEdit` | Used to save and paste arena schematics when installed. Without it ExyliaLib's own engine does the same with the same files. |
| An economy | `ExyliaEconomy`, `Vault` with an economy plugin, or any currency ExyliaLib serves: the money rewards of `triggers.yml` and the costs of upgrades and perks. |
| `ExyliaDuels` | A **Random kit** option in its challenge screen. See [Network and ExyliaDuels](/docs/exyliarandomkits/network#exyliaduels). |
| `ExyliaProxyUtils` | On the proxy, to send players between the servers of a group. See [Network and ExyliaDuels](/docs/exyliarandomkits/network). |

## Steps

<Steps>
  <Step title="Drop in the loader">
    Put `Exylia-RandomKitsCore-Loader.jar` into `plugins/`, plus an economy if you want money rewards and paid upgrades.
  </Step>
  <Step title="Start the server">
    The loader checks the licence embedded in the jar and hands over to the plugin. It installs ExyliaLib if it is missing; if it had to, restart once more.
  </Step>
  <Step title="Let it generate">
    The plugin writes its files, messages and menus, and creates its tables. The console ends with `ExyliaRandomKitsCore enabled`.
  </Step>
  <Step title="Build the arena">
    Stand where the arena is built, run `/rkadmin setup` and follow the wizard: the PvP region, a spawn and the roll mode. `items.yml` ships ready, so lives roll items at once. See [Set up the arena](/docs/exyliarandomkits/arenas#the-setup-wizard).
  </Step>
  <Step title="Play">
    Nothing to do: the server has one arena and whoever connects is moved into it. There is no arena key to set in `config.yml`.
  </Step>
</Steps>

## Check that it works

Connect with a test account: you land in the arena with a title and items, and `/rk` opens the hub. If the plugin does not load, open the console: it names what is missing. See [Common problems](/docs/exyliarandomkits/troubleshooting).

## Updating

Replace the loader jar and restart, or leave `version: auto` in `loader.yml`. Your files, messages and player menus are kept; new keys are added with their defaults.

## Generated files

All of them live in `plugins/ExyliaRandomKitsCore/`. Every file is commented.

<Details title="Every generated file">
| File | Contents |
|---|---|
| `loader.yml` | Written by the loader: `license_key`, and `version` (`auto` keeps the plugin on the newest release). |
| `config.yml` | Language, network group, rolls, deaths, assists, streaks, evolution, anti-abuse, nemesis, default layout, arenas, stats, Duels and the command allowlist. See [Configuration](/docs/exyliarandomkits/configuration). |
| `play.yml` | The `/spawn` command, combat and rejoining. |
| `items.yml` | The item pool every life rolls from. See [Items and rarities](/docs/exyliarandomkits/kits). |
| `rarities.yml` | The rarities, from the most common to the rarest. See [Items and rarities](/docs/exyliarandomkits/kits#rarities). |
| `triggers.yml` | Rewards on kills, deaths, assists, streaks, rolls, joins, level-ups, prestige, missions, revenge and events. See [Configuration](/docs/exyliarandomkits/configuration#rewards-triggersyml). |
| `progression.yml` | Levels, XP, prestige, account upgrades, rerolls and the ceiling. See [Progression](/docs/exyliarandomkits/progression). |
| `perks.yml` | Perks: trigger, conditions, effects per level and costs. See [Progression](/docs/exyliarandomkits/progression#perks). |
| `missions.yml` | The daily and weekly mission pools. See [Progression](/docs/exyliarandomkits/progression#missions). |
| `events.yml` | Events, their timetable and the rotation. See [Events and seasons](/docs/exyliarandomkits/events-and-seasons). |
| `seasons.yml` | Season length or fixed dates, and rank rewards. See [Events and seasons](/docs/exyliarandomkits/events-and-seasons#seasons). |
| `database.yml` | Where rows are stored, and Redis for a network. Written by ExyliaLib. |
| `lang/<language>/messages.yml` | Every chat line, title, boss bar and label. See [Messages and languages](/docs/exylialib/messages-and-languages). |
| `lang/<language>/menus/user/` | The player screens: hub, arenas, draft, layout, stats, top, progress, upgrades, perks, missions, season and its archive. Yours to restyle: an update only adds what is missing. See [Edit menus](/docs/exylialib/edit-menus). |
| `lang/<language>/menus/admin/` | The admin screens. Regenerated from the jar on every start, so do not edit them. |
| `schematics/randomkits_<arena>.schem` | The arena's saved blocks, which its resets put back. |

Arenas, profiles, events and seasons live in the database, not in files.
</Details>

<Details title="The database">
The plugin keeps its rows in the database `database.yml` points at: H2 in a file by default, or MySQL, MariaDB, PostgreSQL or MongoDB through [ExyliaLib](/docs/exylialib/database).

| Table | Rows |
|---|---|
| `exyliarandomkits_arenas` | The arena: world, PvP and safe boxes, spawns, mode, spawn protection, reset interval, and the upgrades and perks switches. |
| `exyliarandomkits_players` | Each player's record, level, prestige, season stats and the rest of their profile: upgrades, perks, layout, bad luck counters, rivals. |
| `exyliarandomkits_event_state`, `exyliarandomkits_event_scores` | The running event and its scores. |
| `exyliarandomkits_season_state`, `exyliarandomkits_season_archive` | The open season and the ended ones. |
| `exyliarandomkits_payouts` | Season rewards owed to players, paid once wherever they are. |

With a `network-group` set, every table name starts with the group: `<group>_exyliarandomkits_arenas`. See [Network and ExyliaDuels](/docs/exyliarandomkits/network).

Profile changes are written as increments, never over each other, so a player moving between servers keeps every point. What a player carried before joining an arena is held by ExyliaLib's stays in the same database: a crash or a quit gives it back on their next join.
</Details>
