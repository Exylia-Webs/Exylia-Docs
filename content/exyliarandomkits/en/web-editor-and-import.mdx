## The web editor

`/rkadmin editor` (or `/exylialib editor ExyliaRandomKitsCore`) gives a link to ExyliaLib's browser editor on
this plugin. Every subject needs `exyliarandomkits.admin`. See
[ExyliaLib's web editor](/docs/exylialib/web-editor) for how a session works.

| Subject | What can be edited |
|---|---|
| **Kits** | Name, rarity, weight, permission, icon, effects, enabled, and every slot (role, slot, chance) and variant (item, weight, amounts, enchantment ranges, tier, minimum kit level). Kits can be added, duplicated and deleted. |
| **Arenas** | The pool, mode, spawn protection, reset interval, and the upgrades and perks switches. |
| **Settings** | `config.yml`. |
| **Rarities**, **Triggers**, **Progression**, **Perks**, **Missions**, **Events**, **Seasons**, **Balance** | `rarities.yml`, `triggers.yml`, `progression.yml`, `perks.yml`, `missions.yml`, `events.yml`, `seasons.yml` and `balance.yml`, each drawn as a form from its comments. |
| Messages and menus | Offered by ExyliaLib's discovery. |

- A kit is checked as the kit screens check it: a valid id, a rarity from `rarities.yml`, a weight from 0 to
  1000000, effects as `NAME|LEVEL|SECONDS`, an enabled kit with at least one slot, chances from 0 to 100,
  amounts with `1 <= min <= max`, enchantments as `key:level` or `key:min-max`. A deletion is shown first and
  needs `confirm`. A changed weight restarts that kit's balance numbers, as in game.
- Boxes and spawns are placed in game, so arenas are **created** in game too (`/rkadmin setup` or
  `/rkadmin arena create`). Deleting one sends its players out first. Spawn protection goes from 0 to 3600
  seconds.
- Changing a reward or perk that runs a console command, the allowed commands, or a season reward command is
  held for `confirm`.

`/exylialib editor apply <code>` writes the change and refreshes what reads it, without a reload: perks are
rebuilt, events and seasons rescheduled, the balance cycle restarted.

## Importing kits

Kits come in from four sources, from `/rkadmin` → **Kits** → **Import from a plugin**, or from the command
line:

```text
/rkadmin import <essentials|ffa|practice|duels> [file] [--apply] [--overwrite] [--enable]
```

| Source | Reads |
|---|---|
| `essentials` | EssentialsX `plugins/Essentials/kits.yml`, or another file inside `plugins/` given as `[file]`. Item strings with names, lore and enchantments, and `@` items serialised by `/createkit`. Command (`/...`) and money (`$...`) lines are listed and left out. |
| `ffa` | ExyliaFFA's kits. |
| `practice` | ExyliaPracticeCore's kits and their potion effects. |
| `duels` | ExyliaDuels' kits. |

EssentialsX is read from its file, so it does not need to be running. The Exylia plugins are read through
their own running database connection, so they must be enabled on the same server. Nothing of theirs is
changed.

### Dry run first

`/rkadmin import ffa` alone is a **dry run**: it lists the kits it would create, the ones it would keep
because their id exists, the ones with no item that are left out, and anything it could not carry over (an
unknown item or enchantment, an EssentialsX option such as `color:` that is not carried, an item that could
not be read). Nothing is written.

| Flag | What it does |
|---|---|
| `--apply` | Imports. |
| `--overwrite` | Replaces kits whose id exists. Without it they are **kept**. A player is asked to confirm before anything is replaced; the console is not asked. |
| `--enable` | Imports the kits enabled. Without it they come in **disabled**. |

- Every item becomes one slot with one variant, its role inferred the way `/rkadmin kit save` infers it
  (armour, weapon, bow, food, blocks...).
- Kits come in as `common` (or the most common rarity, when there is no `common`) with **weight 1**.
- Ids are cleaned to lowercase letters, digits, `-` and `_`, up to 32; names lose their colours.
- A replaced kit restarts its balance numbers.

Disabled imports are there to be reviewed: open each one, tune its variants, chance and enchantments, give it
a rarity and a weight, and enable it.

### The import screen

**Import from a plugin** shows the four sources. **Enabled on import** toggles whether kits come in enabled.
On a source, **left-click** imports new kits and **right-click** imports and overwrites existing ones. The
screen always shows the preview in chat and asks to confirm first; overwriting is asked as a dangerous
action.

Other random kit plugins are not imported: none of them documents its storage format.
