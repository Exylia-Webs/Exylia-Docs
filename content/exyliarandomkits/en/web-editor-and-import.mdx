---
title: "Web editor"
description: "Editing the item pool, arenas and every content file from the browser through ExyliaLib's web editor."
---

`/rkadmin editor` (or `/rkadmin` → **Items**, or `/exylialib editor ExyliaRandomKitsCore`) gives a link to
ExyliaLib's browser editor on this plugin. Every subject needs `exyliarandomkits.admin`. See
[ExyliaLib's web editor](/docs/exylialib/web-editor) for how a session works.

| Subject | What can be edited |
|---|---|
| **Arenas** | The roll mode, spawn protection, reset interval, and the upgrades and perks switches. |
| **Settings** | `config.yml`. |
| **Items** | `items.yml`: the categories, their item lines and the rarity of every enchantment level. |
| **Rarities**, **Triggers**, **Progression**, **Perks**, **Missions**, **Events**, **Seasons** | `rarities.yml`, `triggers.yml`, `progression.yml`, `perks.yml`, `missions.yml`, `events.yml` and `seasons.yml`, each drawn as a form from its comments. |
| Messages and menus | Offered by ExyliaLib's discovery. |

- Boxes and spawns are placed in game, so arenas are **created** in game too (`/rkadmin setup` or
  `/rkadmin arena create`). Deleting one sends its players out first. Spawn protection goes from 0 to 3600
  seconds.
- Changing a reward or perk that runs a console command, the allowed commands, or a season reward command is
  held for `confirm`.

`/exylialib editor apply <code>` writes the change and refreshes what reads it, without a reload: perks are
rebuilt and events and seasons rescheduled. `items.yml` is read on every roll, so a change reaches the next
life.

## Settings in game

`/rkadmin` → **Settings** edits the values an admin tunes while the server runs, on three hand-made pages,
without opening a file:

| Page | What it holds |
|---|---|
| **Playing** | The server's arena, the Random kit in ExyliaDuels, the draft size and timeout. |
| **Deaths and arenas** | What a death drops and for how long, the void margin, spawn protection, how long placed blocks last. |
| **Kills and rivals** | The assist share and damage window, the streak that counts as ended, the nemesis. |

A click edits a value (numbers and durations are typed in chat); shift-right-click puts the default back.
Everything else stays in `config.yml` or the web editor.
