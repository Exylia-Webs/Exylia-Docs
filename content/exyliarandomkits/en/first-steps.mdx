At the end of this page you have one working arena. Anyone who connects lands in it with freshly rolled items, fights, dies, and gets new items. You only use chat and one wizard.

The server has one arena. It needs two things before players can be sent in: a **PvP region** (the box they fight in) and at least one **spawn**. The wizard asks for both.

## Before you start

Install the plugin and its dependencies, and make sure you have `exyliarandomkits.admin` (operators have it). See [Install ExyliaRandomKitsCore](/docs/exyliarandomkits/installation). Build or pick the map first: the arena is a box in a world you already have.

## Steps

<Steps>
  <Step title="Start the wizard">
    Stand next to your map and run `/rkadmin setup`. It also starts when you click **Arena** in the `/rkadmin` panel and no arena exists yet.
  </Step>
  <Step title="Select the PvP region">
    The prompt says "Select the PvP region of the arena". Left-click one corner of the fighting area, right-click the opposite corner, then Shift + left-click to confirm. Include the whole map, walls and floor.
  </Step>
  <Step title="Mark the spawn">
    Stand where a life should start, facing the way players should look, and sneak-click. You add more spawns later.
  </Step>
  <Step title="Choose how players get their items">
    Pick **Random** (the plugin hands out a rolled set at once) or **Draft** (the player picks one of a few rolled sets). If you are unsure, pick **Random**. You can change it later.
  </Step>
  <Step title="Confirm the summary">
    The wizard shows everything before saving. On finish the arena is saved and its blocks are saved too, so a reset can put the map back.
  </Step>
</Steps>

## Check that it works

Within a few seconds you are moved into the arena at your spawn. If not, reconnect: whoever connects is sent into the arena automatically. You should see a title with the rarity of your life and a full set of items in your hotbar and armour slots.

1. Run `/rk` to open the hub: **Profile**, **Hotbar layout**, **Leaderboards**, **Progression**, **Reroll kit**, **Events** and **Seasons**.
2. Ask a friend to join, or use a second account, and kill each other. The loser is not really dead: they are healed and sent to a spawn with new items.
3. Run `/stats` to see the kill and death counted.

If you only wanted to build, run `/rkadmin exit` to step out of the fight, and the same command to step back in.

If you see "no arena ready" or nothing happens, see [Common problems](/docs/exyliarandomkits/troubleshooting).

## Good first steps

- Add a second spawn with `/rkadmin arena addspawn` so lives do not all start in the same spot.
- Run `/rkadmin arena schematic` after you finish building the map, so resets put your final version back.
- Leave `items.yml` as it is. It ships ready, with weapons, armour, food and blocks across the rarities.

<Details title="Technical details">
The wizard saves the arena with the id `main`. Run it again to redo the region, spawn and mode of the same arena. Every `/rkadmin arena ...` command acts on that arena, so none of them takes an id. An arena counts as ready once it has a PvP region and a spawn and its world is loaded. Every 10 seconds the plugin sweeps connected players who are not in the arena into it, so an arena that just became ready fills at once.
</Details>
