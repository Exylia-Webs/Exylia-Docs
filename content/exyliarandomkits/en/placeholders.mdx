Use these in scoreboards, tab lists and holograms. The plugin registers them through ExyliaLib under the name `exyliarandomkits`, so they are the same inside Exylia plugins' own files and through PlaceholderAPI: `%exyliarandomkits_kills%`. Nothing has to be downloaded from the eCloud, and every value is read from memory.

## All placeholders

<Placeholders />

## By id

Everything after the name is the id, underscores included: `%exyliarandomkits_perk_vampire%` is the level of the perk `vampire`, and `%exyliarandomkits_upgrade_luck%` the level of the account upgrade `luck`.

## Leaderboards

`<position>` counts from 1. Without `_value` the placeholder gives the player's name (`-` for an empty place); with it, their value (`0`). Each board keeps `stats.leaderboard-size` entries (10 by default).

## The event

The same on every server of the group. Empty when nothing runs.

## The network group

From the last heartbeats of every server of the group. On one server, that server alone.

## Examples

```text
%exyliarandomkits_rarity% %exyliarandomkits_streak%
%exyliarandomkits_top_kills_1%
%exyliarandomkits_top_kills_1_value%
%exyliarandomkits_upgrade_luck%
```

<Callout type="tip" title="A placeholder shows as text?">
PlaceholderAPI is not installed, or the name is misspelled. Inside Exylia plugins' own files they work without it. See [Common problems](/docs/exyliarandomkits/troubleshooting).
</Callout>
