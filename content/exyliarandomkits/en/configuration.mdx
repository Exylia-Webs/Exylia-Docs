RandomKits is tuned through a few YAML files in `plugins/ExyliaRandomKitsCore/`. This page maps them and documents `config.yml`, `play.yml` and the rewards of `triggers.yml` key by key. The arena itself is not in a file: it is built in game with `/rkadmin setup`.

## Before you start

Times are written `30s`, `5m` or `1h30m`. You need `exyliarandomkits.admin` to reload or open the editor.

| File | Documented in |
|---|---|
| `config.yml` | This page. |
| `play.yml` | [Combat, /spawn and rejoining](#play-playyml), below. |
| `triggers.yml` | [Rewards](#rewards-triggersyml), below. |
| `items.yml`, `rarities.yml` | [Items and rarities](/docs/exyliarandomkits/kits). |
| `progression.yml`, `perks.yml`, `missions.yml` | [Progression](/docs/exyliarandomkits/progression). |
| `events.yml`, `seasons.yml` | [Events and seasons](/docs/exyliarandomkits/events-and-seasons). |
| `database.yml` | [ExyliaLib's database](/docs/exylialib/database). |

## Change a value

<Steps>
  <Step title="Open the file">
    Edit the file on disk, or run `/rkadmin editor` and use the [web editor](/docs/exyliarandomkits/web-editor-and-import), which applies the change on its own. The values an admin tunes most are also in `/rkadmin` then **Settings**.
  </Step>
  <Step title="Change the key">
    Keep the YAML indentation and quote anything that starts with `%` or `{`.
  </Step>
  <Step title="Apply it">
    After a hand edit, run `/rkadmin reload`. The exception is `network-group`: restart the server.
  </Step>
</Steps>

## Check that it works

Look at the console after the reload for errors, then try the behaviour, for example kill a player after changing `on-kill` and read what the payout message says.

## Language

<Field name="language" type="string" defaultValue="default">
`default` follows the language set in ExyliaLib's `config.yml`; a code such as `en` or `es` sets this plugin alone. `en`, `es`, `fr`, `pt`, `ru` and `tr` ship, each a folder under `lang/` you can edit.
</Field>

<Field name="debug" type="boolean" defaultValue="false">
Explains in the console what the plugin is doing, refused kills included.
</Field>

## Network group

<Field name="network-group" type="string" defaultValue="">
Servers of a network that share arenas, stats and leaderboards write the same group here and point at one database, with Redis so edits reach the others at once. Blank keeps the plain tables. Lower case letters, digits and underscores, at most 24. See [Connect several servers](/docs/exyliarandomkits/network).
</Field>

## Rolls: `roll`

<Details title="Keys of roll">

| Key | Default | What it does |
|---|---|---|
| `roll.pity` | `{epic: 10, legendary: 40}` | Bad luck protection: after this many lives in a row below a rarity, the next life is at least that rarity. `0` turns a rule off. |
| `roll.draft-size` | `3` | Loadouts offered at once in Draft arenas (2 to 9). |
| `roll.draft-timeout` | `10s` | How long a draft waits for a pick before taking the first loadout. |
| `roll.draft.display` | `MENU` | `MENU` opens a menu with the loadouts, `CHAT` sends clickable buttons. |

</Details>

## Deaths: `death`

<Details title="Keys of death">

| Key | Default | What it does |
|---|---|---|
| `death.drops` | `CONSUMABLES` | What a death leaves on the floor: `NONE`, `CONSUMABLES` (the roles below) or `ALL`. |
| `death.consumable-roles` | `[FOOD, POTIONS, ARROWS, UTILITIES]` | Roles (`items.yml` category ids) that count as consumables. |
| `death.drop-lifetime` | `10s` | How long dropped items stay on the floor. |
| `death.void-margin` | `2` | Blocks below the arena's lowest box that still count as inside; lower is a fall out. |

</Details>

## Assists and streaks

<Details title="Keys of assists and streaks">

| Key | Default | What it does |
|---|---|---|
| `assists.minimum-percent` | `25.0` | Share of the damage a victim took, from 0 to 100, that earns an assist. |
| `assists.window` | `15s` | Only damage dealt this recently counts, for assists and for the kill itself. |
| `streaks.milestones` | `[5, 10, 15, 20, 25, 30, 50]` | Streaks announced to the arena. |
| `streaks.end-minimum` | `5` | Ending a streak at least this long runs `on-streak-end` for the killer. |

</Details>

## Evolution: `evolution`

At given streaks, what a player wears is upgraded in place. `evolution.steps` lists the steps every life follows; by default three steps, at 3, 5 and 10.

<Details title="A step and an example">

A step: `streak`, `upgrades` (gear pieces raised one rarity, each a random one that can still go up), `enchant-rolls` (extra enchantment rolls, each on a random gear piece with room for one), `items` (`item` as an ExyliaLib item source, `amount`, `role`), `effects` (`NAME|LEVEL|SECONDS`, until the next death) and `feedback` (ExyliaLib sequence lines). See [Playing](/docs/exyliarandomkits/playing#streaks-and-evolution).

```yaml
evolution:
  steps:
    - streak: 5
      enchant-rolls: 1
      items: []
      effects: []
      feedback:
        - '[SOUND] BLOCK_ANVIL_USE;0.7;1.4'
        - '[TITLE] ;{highlight}&lKIT EVOLVED {letters_black}» {info}+1 enchant;0.1;1.5;0.4'
```

</Details>

## Anti-abuse and nemesis

<Details title="Keys of anti-abuse and nemesis">

| Key | Default | What it does |
|---|---|---|
| `anti-abuse.same-address` | `true` | No rewards or stats for a kill when killer and victim share an address or account. |
| `anti-abuse.repeat-limit` | `3` | No rewards or stats once one killer killed the same victim more than this many times within the window. `0` turns it off. |
| `anti-abuse.repeat-window` | `10m` | The window of `repeat-limit`. |
| `anti-abuse.fresh-spawn` | `3s` | No rewards or stats for killing a player who spawned less than this long ago. |
| `anti-abuse.afk` | `60s` | No rewards or stats for killing a player who has not moved for this long. `0s` turns it off. |
| `nemesis.min-kills` | `2` | Kills on a player that make the killer their nemesis. The most kills wins, the most recent a tie. Killing your nemesis runs `on-revenge`. |
| `nemesis.tracked` | `5` | Rivals each player keeps track of; past that the one with the fewest kills is forgotten. |

</Details>

## Arenas: `arenas`

<Details title="Keys of arenas">

| Key | Default | What it does |
|---|---|---|
| `arenas.spawn-protection` | `3s` | Spawn protection a new arena starts with. |
| `arenas.placed-blocks` | `30s` | Blocks a player places in an arena disappear after this long. `0s` keeps them until the next reset. |
| `arenas.pvp-flags` | `pvp: true`, `player_build_only: true` | Region flags of the PvP box: `flag: true/false`, a number, or materials as `STONE,DIRT`. Edit them in game with `/rkadmin flags pvp`. A flag left out takes its default. |
| `arenas.safe-flags` | `pvp`, `build`, `break`, `item_drop`, `item_pickup` and `fall_damage`, all `false` | Region flags of the safe box, edited with `/rkadmin flags safe`. |
| `arenas.safe-containers` | `true` | In the safe box any container opens: ender chest, chests, vaults. Off, only vaults do. |
| `arenas.safe-commands` | `pv`, `pvs`, `playervault`, `playervaults`, `vault`, `vaults`, `ec`, `echest`, `enderchest`, `ender`, `trash`, `disposal` | Commands allowed in the safe box on top of `allowed-commands`, without the slash. |

Flags that exist include `pvp`, `build`, `break`, `interact`, `player_build_only`, `breakable_blocks_only`, `breakable_blocks`, `allowed_blocks_only`, `allowed_blocks`, `build_max_y`, `item_drop`, `item_pickup` and `fall_damage`. `/rkadmin flags` lists the rest.

</Details>

## Explosives and throwables

TNT and creeper eggs in an arena go off fast, with a countdown, and snowballs and eggs hit with knockback.

<Details title="Keys of explosives and throwables">

| Key | Default | What it does |
|---|---|---|
| `explosives.tnt-fuse` | `1s` | Placed TNT is lit at once and blows after this long. |
| `explosives.creeper-fuse` | `1s` | A creeper egg used on a block spawns a lit creeper that blows after this long. |
| `explosives.countdown` | `true` | A hologram over the TNT or creeper counts its fuse down. |
| `throwables.enabled` | `true` | Whether a snowball or an egg that hits a player hurts and knocks them back. |
| `throwables.damage` | `0.01` | Damage of each hit, in health points (2 is one heart), from 0 to 20. A tiny value is knockback alone. |

</Details>

## Stats: `stats`

<Details title="Keys of stats">

| Key | Default | What it does |
|---|---|---|
| `stats.save-interval` | `30s` | How often online players' stats are written to the database. |
| `stats.leaderboard-refresh` | `60s` | How often the leaderboards are read again. |
| `stats.leaderboard-size` | `10` | Entries kept per leaderboard. |

</Details>

## Balancing and Duels

`balancing` sends players who join a full server to another server of the group, and `duels` is the Random kit in ExyliaDuels (`duels.enabled`, on by default). Both are documented in [Connect several servers](/docs/exyliarandomkits/network).

## Permanent effects

<Field name="permanent-effects" type="list" defaultValue="[NIGHT_VISION]">
Effects every player keeps on this server, forever: given on join, and given back the moment a totem, milk, a death or a new life takes them off. Write `NAME` or `NAME:level`, such as `NIGHT_VISION` or `SPEED:2`. Empty for none.
</Field>

## Commands in an arena: `allowed-commands`

<Field name="allowed-commands" type="list" defaultValue="[rk, randomkits, msg, tell, w, whisper, m, r, reply]">
The only commands a player can use while in an arena, without the slash. Everything else is refused. Aliases with a plugin prefix (`essentials:msg`) are matched too. Changing it from the web editor is held for `confirm`.
</Field>

## Play: `play.yml`

The play loop around the fight: combat tags, `/spawn`, and what a reconnecting player keeps. See [Playing](/docs/exyliarandomkits/playing) for how it feels to a player.

<Details title="Keys of play.yml">

| Key | Default | What it does |
|---|---|---|
| `combat.window` | `15s` | How long a hit keeps both players in combat. `%exyliarandomkits_combat%` is the seconds left. |
| `combat.logout-is-death` | `true` | Leaving in combat counts as dying to the last player who hit you: they get the kill, the streak it ends and every reward, and the life is lost. |
| `combat.actionbar` | `true` | Shows the seconds left in combat on the action bar. |
| `spawn.enabled` | `true` | `/spawn` and `/rk spawn`: back to the safe box keeping everything. Refused in combat. |
| `spawn.warmup` | `5s` | How long to stand still first. Instant when already in the safe box. |
| `spawn.cancel-on-move` | `true` | Walking off the block calls the countdown off. |
| `spawn.cancel-on-damage` | `true` | Being hit calls the countdown off. |
| `rejoin.keep-life` | `true` | A player who leaves outside combat comes back with the same life: kit, armour, effects, health, streak and place. It never expires. Off: every join rolls a new kit. |
| `rejoin.protection` | `3s` | Spawn protection on coming back, so nobody is killed while the world loads. |

</Details>

## Rewards: `triggers.yml`

The plugin pays nothing by itself: everything it pays is a named list of ExyliaLib rewards in `triggers.yml`, run when something happens in an arena, through ExyliaLib's booster pipeline. By default a kill pays 10, an assist 3, ending a streak 25 and a revenge 15, each with a chat line, plus streak payouts of 25 at 5, 50 at 10, 75 at 15, 100 at 20, 150 at 30 and 250 at 50, all in the server's default currency.

<Details title="Every trigger">

| Trigger | Runs for |
|---|---|
| `on-kill` | The killer. |
| `on-death` | The victim. |
| `on-assist` | Each assisting player. |
| `on-streak-<n>` | The killer reaching that streak, such as `on-streak-5`. |
| `on-streak-end` | Whoever ended a streak of at least `streaks.end-minimum`. |
| `on-roll-<rarity>` | Rolling a life of that rarity, such as `on-roll-legendary`. |
| `on-first-join` | The first time the network sees the player. |
| `on-arena-join`, `on-arena-leave` | Joining and leaving an arena. |
| `on-level-up`, `on-level-<n>` | Every level-up, or reaching that level (`%level%`). |
| `on-prestige` | A prestige (`%prestige%`). |
| `on-mission-complete` | Every mission completed (`%mission%`, `%pool%`). |
| `on-revenge` | Killing your nemesis. |
| `on-nemesis-new` | The victim, when `%killer%` becomes their new nemesis. |
| `on-event-start-<id>`, `on-event-win-<id>` | See [Events](/docs/exyliarandomkits/events-and-seasons#rewards). |

</Details>

<Details title="Reward types and fields">

A reward has a `type` and what the type needs:

| Type | Needs |
|---|---|
| `COMMAND` | `command`, run by the console: `give %player% diamond 1`. |
| `MESSAGE` | `message`: `%prefix% {success}+10 coins`. |
| `ECONOMY` | `amount`, and `currency` (blank is the server's default). |
| `EXPERIENCE` | `amount`, in experience points. |
| `ITEM` | `item`, and optionally `min-amount` and `max-amount` for a random amount. |
| `POTION` | `effect`: `SPEED\|2\|10`. |

Optional on any of them: `chance` (0-100), `permission`, `condition` (`'%player_level% >= 10'`). Placeholders: `%player%`, `%killer%`, `%victim%`, `%streak%`, `%rarity%` (the life's rarity id), `%arena%`.

</Details>

`arenas` holds per-arena lists, by arena id, that replace the global list of the same trigger there:

```yaml
triggers:
  on-kill:
    - type: ECONOMY
      amount: '10'
arenas:
  ranked:
    triggers:
      on-kill:
        - type: ECONOMY
          amount: '25'
        - type: MESSAGE
          message: '%prefix% {success}+25 {letters}for a ranked kill'
```

The `rewards` upgrade and prestige raise what these pay (not in arenas with upgrades off), and so do `MULTIPLIER` events. Changing a `COMMAND` reward from the web editor is held for `confirm`.

## Messages

`lang/<language>/messages.yml` holds every chat line, title, boss bar and label, grouped as `arena`, `roll`, `fight`, `streak`, `stats`, `top`, `layout`, `progression`, `reroll`, `perks`, `missions`, `events`, `seasons`, `nemesis`, `network`, `duels`, `admin`, `prompts` and `labels`. Colours use palette tokens such as `{primary}`, so recolouring the server never means editing this file. How colours, messages and languages work is in ExyliaLib: [Colours](/docs/exylialib/colours) and [Messages and languages](/docs/exylialib/messages-and-languages).

<Details title="Details of messages.yml">

- `%prefix%` is replaced by the `prefix` value, `{primary}&lRANDOMKITS {letters_black}•<reset>`. An empty message is not sent.
- A message may open with an effect tag, which never reaches the screen: `[sound:NAME|volume|pitch]` plays a sound, `[center]` centres the line.
- `progression.prestige-display` is how each prestige is written, from prestige 0; the last one repeats.
- `labels` are the words injected into menus and messages (enabled, disabled, the roll modes), so one palette change restyles every screen.

</Details>

## Menus

The player screens under `lang/<language>/menus/user/` are yours to restyle: an update only adds what is missing. The admin screens under `menus/admin/` are regenerated from the jar on every start. See [Edit menus](/docs/exylialib/edit-menus) for the format.
