## Events

An event is a while of something different in the arenas, announced to everyone, with a boss bar counting
down for the players in them. **One event runs at a time on the whole network group**: a timetable firing on
every server starts it once, and every server shows the same one.

| Type | What happens |
|---|---|
| `KIT_OF_THE_HOUR` | Everyone fights with `kit`, or with one kit rolled at the start when `kit` is blank. No roll, no draft. |
| `RARITY_RUSH` | Each rarity's weight is multiplied by `rarities`; `0` takes a rarity out. |
| `MULTIPLIER` | Money and XP earned in the arenas are multiplied by `multiplier`. |
| `KING_OF_THE_ARENA` | Most kills wins. The live top is on the event placeholders. |
| `MYTHIC_HUNT` | One player per server is marked and glows for the others; their killer takes the bounty and the mark. |

### Rewards

Rewards live in `triggers.yml`, by event id:

- `on-event-start-<id>`: everyone in the event's arenas when it starts.
- `on-event-win-<id>`: the king when it ends, and the hunter on every bounty.

The king's rewards are owed once and paid wherever the player is, now or on their next join.

### `events.yml`

`events` maps an event id to:

| Key | What it does |
|---|---|
| `name` | How it is called in messages, the boss bar and menus. |
| `type` | One of the five types. |
| `duration` | How long it lasts. |
| `arenas` | The arena ids it runs in; empty is every arena. |
| `icon` | Its item in menus. |
| `kit` | `KIT_OF_THE_HOUR`: the kit id, or blank to roll one at the start. |
| `rarities` | `RARITY_RUSH`: rarity id to weight multiplier. |
| `multiplier` | `MULTIPLIER`: what money and XP are multiplied by. |
| `schedule.times` | Times it starts at, like `20:00`. |
| `schedule.days` | Days, like `FRIDAY`; empty is every day. |
| `schedule.min-players` | Players that must be online on this server for it to start. |

The bundled events:

| Id | Name | Type | Duration | Schedule |
|---|---|---|---|---|
| `hour_kit` | Kit of the Hour | `KIT_OF_THE_HOUR` | 30m | none |
| `rarity_rush` | Rarity Rush | `RARITY_RUSH` (common ×0, rare ×0.5, epic ×2, legendary ×3, mythic ×3) | 15m | none |
| `double_rewards` | Double Rewards | `MULTIPLIER` ×2 | 30m | 20:00 on Saturday and Sunday |
| `king` | King of the Arena | `KING_OF_THE_ARENA` | 15m | 21:00 on Friday, 4 players online |
| `mythic_hunt` | Mythic Hunt | `MYTHIC_HUNT` | 15m | none |

### The rotation

| Key | Default | What it does |
|---|---|---|
| `rotation.enabled` | `false` | Starts the listed events one after another on its own, an interval apart. |
| `rotation.interval` | `45m` | From the end of one event to the start of the next. |
| `rotation.events` | `[rarity_rush, double_rewards, king, mythic_hunt, hour_kit]` | The events, in order. |
| `rotation.min-players` | `4` | Players that must be online on the server that starts it. |

### By hand

| Command | What it does |
|---|---|
| `/rkadmin event start <id>` | Starts an event, unless one runs. |
| `/rkadmin event stop [id]` | Stops the running event; with an id, only that one. |
| `/rkadmin event status` | What runs now and what is next. |

Players see the running or next event in the `/rk` hub.

## Seasons

A season is a stretch of time with its own kills, deaths, best streak, KDR and XP, its own leaderboards
(`/rk season`) and rewards by final rank, paid **exactly once** wherever the player is. Lifetime records are
never touched. One server of the network group closes a season and opens the next; every server shows the
same one.

### `seasons.yml`

| Key | Default | What it does |
|---|---|---|
| `enabled` | `true` | Seasons on or off. |
| `name` | `Season %number%` | The name of a rolling season. |
| `length` | 30 days | How long a rolling season lasts. |
| `seasons` | `[]` | Fixed windows: `id`, `name`, `start`, `end`, written `yyyy-MM-dd HH:mm` in `timezone`. |
| `timezone` | `""` | The zone the fixed windows are written in (`Europe/Madrid`). Blank is the server's. |
| `rank-by` | `season_kills` | `season_kills`, `season_kdr`, `season_best_streak` or `season_xp`. |
| `rewards` | see below | By final position, `from`-`to` inclusive; the same rewards as `triggers.yml`. |
| `archive` | `12` | Past seasons kept in the archive. |

When none of the fixed windows covers the moment and `length` is above `0s`, seasons roll on their own: each
one `length` long, named by `name`.

| Positions | Default reward |
|---|---|
| 1 | 5000 money |
| 2 - 3 | 2500 money |
| 4 - 10 | 1000 money |
| 11 - 100 | 250 money |

```yaml
seasons:
  - id: winter
    name: Winter Season
    start: '2026-12-01 00:00'
    end: '2027-03-01 00:00'
timezone: Europe/Madrid
```

### The season screen

`/rk season` shows the season's name and time left, its board sorted by kills, KDR, best streak or XP, and
the **Archive** of past seasons with their final tops.

### By hand

| Command | What it does |
|---|---|
| `/rkadmin season start` | Opens a season now, when none is open. |
| `/rkadmin season end` | Closes the season now and pays its rewards; a rolling one is followed by the next at once. |
| `/rkadmin season status` | The season now and its time left. |
