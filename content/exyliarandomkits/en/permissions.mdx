title: "Permissions"
description: "Every node the plugin declares, what each one gates, and the numeric nodes that raise a ceiling."
---

Player features default to everyone, so a server makes one a rank perk by denying it to the default group. A
feature also needs the root it sits under (`play` or `progress`). Resetting a layout and
unequipping a perk never need a node.

| Permission | Default | What it gates |
|---|---|---|
| `exyliarandomkits.play` | everyone | Being in the arena: the hub, `/rk draft`, `reroll` and `layout`. |
| `exyliarandomkits.reroll` | everyone | `/rk reroll` and the reroll button, just after spawning. |
| `exyliarandomkits.draft` | everyone | Picking in a draft arena. Without it the draft takes the first option when the time runs out. |
| `exyliarandomkits.layout` | everyone | `/rk layout` and `layout save`, and arranging a hotbar layout. |
| `exyliarandomkits.progress` | everyone | `/rk progress`, `upgrades`, `perks`, `missions` and `prestige`. |
| `exyliarandomkits.prestige` | everyone | `/rk prestige`. |
| `exyliarandomkits.upgrades` | everyone | Opening and buying account upgrades. |
| `exyliarandomkits.perks` | everyone | Opening, buying and equipping perks. |
| `exyliarandomkits.missions` | everyone | The daily and weekly missions. |
| `exyliarandomkits.stats` | everyone | `/rk stats`, `top` and `season`, and the matching buttons. |
| `exyliarandomkits.admin` | operators | Every `/rkadmin` command and screen, and every web editor subject. |

Every menu action checks its node itself, so copying a button into a screen players can open hands them
nothing they did not already have.

## Numeric nodes

Two families replace a ceiling from `progression.yml`; the highest number a player holds wins, and nothing is
granted on its own.

| Permission | Replaces | Meaning |
|---|---|---|
| `exyliarandomkits.rerolls.<n>` | `ceiling.rerolls` | The most rerolls per life. |
| `exyliarandomkits.perkslots.<n>` | `ceiling.perk-slots` | The most perk slots. |

So `exyliarandomkits.rerolls.3` on a rank lets its players reroll three times a life, however far upgrades go.
