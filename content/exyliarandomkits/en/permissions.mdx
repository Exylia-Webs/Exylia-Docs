title: "Permissions"
description: "The four nodes the plugin declares, what each one gates, and per-kit permissions."
---

| Permission | Default | What it gates |
|---|---|---|
| `exyliarandomkits.play` | everyone | `/rk play`, `leave`, `draft`, `reroll`, `kits`, `layout` and its `save` and `reset`, and the matching buttons. |
| `exyliarandomkits.progress` | everyone | `/rk progress`, `upgrades`, `perks`, `missions` and `prestige`, and the matching buttons. |
| `exyliarandomkits.stats` | everyone | `/rk stats`, `top` and `season`, and the matching buttons. |
| `exyliarandomkits.admin` | operators | Every `/rkadmin` command and screen, and every web editor subject. |

Every menu action checks its node itself, so copying a button into a screen players can open hands them
nothing they did not already have.

## Per-kit permissions

A kit can ask for its own permission to be rolled: set it on the kit screen, with `/rkadmin kit permission
<id> <permission>`, or in the web editor. Players without it never roll that kit, and a rarity left with no
kit they may get is skipped for them. `none` clears it. These permissions are whatever you name them; the
plugin does not declare them.
