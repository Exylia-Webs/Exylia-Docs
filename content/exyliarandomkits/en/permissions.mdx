Players can use everything without any setup: every player permission is on by default, and only admins get `/rkadmin`. Use this page to take features away from the default group and give them back as rank perks.

## Make a feature a rank perk

A feature also needs the root it sits under, `exyliarandomkits.play` or `exyliarandomkits.progress`. To make a feature a perk, deny it to the default group and grant it to the rank. With LuckPerms:

```text
/lp group default permission set exyliarandomkits.reroll false
/lp group vip permission set exyliarandomkits.reroll true
```

A player who is refused sees the "feature locked" line from `messages.yml`. Resetting a layout and unequipping a perk never need a permission.

## Give a rank more rerolls or perk slots

`exyliarandomkits.rerolls.<n>` and `exyliarandomkits.perkslots.<n>` replace a ceiling of `progression.yml`. The highest number a player holds wins, and nothing is granted on its own. So `exyliarandomkits.rerolls.3` on a rank lets its players reroll three times a life, however far upgrades go:

```text
/lp group vip permission set exyliarandomkits.rerolls.3 true
/lp group vip permission set exyliarandomkits.perkslots.4 true
```

<Callout type="warning" title="Keep the admin node for staff">
`exyliarandomkits.admin` opens every `/rkadmin` command and screen, including forcing rolls and editing players' levels.
</Callout>
