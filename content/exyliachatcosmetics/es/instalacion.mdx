Al terminar esta página el plugin funciona y `/cc` abre el menú de cosméticos. Son unos dos minutos.

## Antes de empezar

Necesitas Paper 1.21.4 o superior, Java 21 y [ExyliaLib](/docs/exylialib/colours) en `plugins/`. El plugin no funciona sin ExyliaLib.

| Plugin | Para qué |
|---|---|
| PlaceholderAPI | Mostrar la etiqueta y el nombre en el formato de chat, el scoreboard o la lista de jugadores de otro plugin. No hace falta con el chat integrado. |
| LuckPerms | Colores de rango (sin él la pantalla sale vacía) y que los cambios de permisos se apliquen al momento, sin volver a entrar. |
| ExyliaEconomy o Vault | Precios en los cosméticos bloqueados. Sin ninguno no se muestra precio. |
| packetevents | Opcional, lo usan las funciones de paquetes de ExyliaLib. |

## Pasos

<Steps>
  <Step title="Pon el jar">
    Copia `Exylia-ChatCosmetics-Loader.jar` en `plugins/`, junto a ExyliaLib.
  </Step>
  <Step title="Arranca el servidor">
    El primer arranque escribe la configuración, la carpeta de idioma, el catálogo y los archivos del chat, y crea la base de datos. Puede tardar más de lo normal: los drivers de la base de datos se descargan una vez, así que el servidor necesita internet esa primera vez.
  </Step>
  <Step title="Mira la consola">
    Busca el banner del plugin con su versión. Si no aparece, falta ExyliaLib.
  </Step>
  <Step title="Abre el menú">
    Ejecuta `/cc`. Cualquier jugador puede usarlo.
  </Step>
</Steps>

<Callout type="warning" title="El plugin se hace cargo de tu chat desde el principio">
`modules.chat` es `true` en una instalación nueva, así que el chat integrado entrega cada mensaje y registra `/msg`, `/reply`, `/ignore` y los demás comandos de chat. Si otro plugin ya lleva tu chat, pon `modules.chat: false` en `plugins/ExyliaChatCosmetics/config.yml` y ejecuta `/cca reload`. El plugin pasa a solo dar estilo a los mensajes y deja a tu plugin de chat al mando.
</Callout>

## Comprueba que funciona

Ejecuta `/cc`: se abre una ventana con **Tu chat**, **Identidad**, **Mensaje**, **Favoritos**, **Conjuntos**, **Preajustes** y **Tu colección**. Escribe un mensaje: con el chat integrado activado ya usa el formato del plugin. Sigue con [Tu primer cosmético](/docs/exyliachatcosmetics/primeros-pasos).

## Compartir cosméticos entre servidores

Por defecto los datos están en una base de datos de archivo (H2) en la carpeta del plugin. Para compartirlos, apunta los servidores a la misma base MySQL, MariaDB, PostgreSQL o MongoDB en `plugins/ExyliaChatCosmetics/database.yml`. Ese archivo es de ExyliaLib, mira [Base de datos](/docs/exylialib/database). Para el chat entre servidores también necesitas Redis, mira [Canales](/docs/exyliachatcosmetics/canales).

## Actualizar

Cambia el jar y reinicia. Todo lo que tienen los jugadores está en la base de datos.

Las claves nuevas aparecen en `config.yml` con su valor por defecto. Una clave que la versión nueva ya no tiene se elimina y se avisa una vez en la consola como `UNKNOWN_KEY`: una errata en el nombre de una clave también se borra, así que lee la consola tras actualizar si editaste a mano. Los valores nuevos del catálogo, los menús y los archivos del chat esperan en `/exylialib updates` para aplicarlos o ignorarlos; tus ediciones se conservan.

## Recargar sin reiniciar

Ejecuta `/cca reload` (necesita `exyliachatcosmetics.admin`). Relee la configuración y los mensajes, el catálogo, los menús y el módulo de chat, y vuelve a probar LuckPerms. Un cambio en un interruptor de `modules` que no sea `chat` espera a un reinicio. `/cca chat reload` relee solo los archivos del módulo de chat. `/exylialib reload` recarga la paleta y el plugin la sigue.

<Details title="Archivos que escribe el primer arranque">
Todo está en `plugins/ExyliaChatCosmetics/`.

| Archivo | Contiene |
|---|---|
| `config.yml` | Idioma, módulos, valores por defecto, formato de etiqueta, caracteres de los colores de rango, reglas de cosméticos personalizados, límite de conjuntos, caducidad, tienda. Mira [Configuración](/docs/exyliachatcosmetics/configuracion). |
| `database.yml` | Ajustes de base de datos de ExyliaLib. H2 por defecto. |
| `lang/<idioma>/messages.yml` | Cada línea que leen los jugadores. |
| `lang/<idioma>/menus/*.yml` | Los 22 menús. Mira [Menús](/docs/exyliachatcosmetics/menus). |
| `lang/<idioma>/cosmetics/*.yml` | El catálogo: `tags`, `nick-colors`, `chat-colors`, `shadow-colors`, `rank-colors`, `fonts`, `modifiers`, `presets`, `animations`. |
| `chat/config.yml` | Los interruptores del módulo de chat. |
| `chat/filter/` | `config.yml`, `rules.yml`, `whitelist.yml`, `leet.yml`, `punishments.yml`. |
| `chat/text/` | `emojis.yml`, `grammar.yml`. |
| `lang/<idioma>/chat/` | `channels.yml`, `formats/` (`default.yml`, `msg.yml`), `messages.yml`, `announcements.yml`, y las copias traducidas de `filter/punishments.yml` y `text/emojis.yml`. |

`language` en `config.yml` elige la carpeta: `default` sigue a ExyliaLib, y vienen `en`, `es`, `pt`, `fr`, `ru` y `tr`. Con `modules.chat: false` no se escribe ningún archivo del chat. Tablas: `chatcosmetics_profiles`, `_entitlements`, `_custom`, `_loadouts`, `_tokens` y `_chat_players` cuando el módulo de chat funciona. Folia está soportado sin configurar nada.
</Details>
