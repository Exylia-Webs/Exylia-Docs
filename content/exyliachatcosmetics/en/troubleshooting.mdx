Find your symptom, check the cause, apply the fix. Each section stands on its own.

## The tag does not show in chat

You gave a player a tag and they wear it, but the chat line has no tag.

- **You use the built-in chat.** The line that ships with the plugin has a rank, a name and the message, and no tag. Add a `tag` piece with `text: '{tag}'` to a copy of `chat/formats/default.yml`. See [Your first cosmetic](/docs/exyliachatcosmetics/first-steps).
- **You use another chat plugin.** Set `modules.chat: false` in `config.yml`, run `/cca reload`, and put `%exyliachatcosmetics_tag%%exyliachatcosmetics_nick%` in that plugin's format. PlaceholderAPI must be installed. See [Integrations](/docs/exyliachatcosmetics/integrations).
- **The player does not own what they wear.** Run `/cca check <player> tag:<id>`. A cosmetic that is no longer owned is not drawn.

## Every cosmetic is locked for my players

A fresh install owns nothing. A player owns a cosmetic through a permission such as `exyliachatcosmetics.tag.item.heart`, through a grant from `/cca give`, or through a default you set. Give the permission to a group, or grant it. See [Permissions](/docs/exyliachatcosmetics/permissions) and [Give and take cosmetics](/docs/exyliachatcosmetics/entitlements).

The opposite problem, everybody owns everything, comes from a group with `*` or `exyliachatcosmetics.*`. Remove it from default groups.

## The rank colour screen is empty

Rank colours repaint the prefix and suffix that LuckPerms provides, so they need LuckPerms. Install it, and give the groups a prefix.

If the **staff** tab is empty for everybody, the groups its entries list (such as `owner`, `admin`, `mod`) do not match your LuckPerms group names. Edit the `groups` lists in `cosmetics/rank-colors.yml`, then run `/cca reload`.

## A placeholder shows as plain text

The text `%exyliachatcosmetics_tag%` appears in chat or on a scoreboard. Install PlaceholderAPI: it is what lets other plugins read the placeholders. Check the spelling against [Placeholders](/docs/exyliachatcosmetics/placeholders); there is only one spelling and no short alias.

## The tab list or nametags make the server lag

An animated tag is a different text every frame, and the tab list sends each change to every player. In the tab list, nametags and scoreboards use the `_still` placeholders, for example `%exyliachatcosmetics_nick_still%`.

## A command does not exist

`/cc shadows`, `/cc loadout` and similar commands only exist while their module is on in the `modules` section of `config.yml`. Turn the module on and restart: commands can only be added at startup. `/cca reload` warns when the file no longer matches what the server started with.

## A player cannot make a custom tag or colour

Making one costs a create token, and nobody starts with any. Give some:

```text
/cca tokens give <player> customtag create 3
```

The kinds are `customtag`, `customcolor`, `customnick` and `customrank`. A player also needs the matching permission, such as `exyliachatcosmetics.customtag.create`, which everybody has by default. See [Tokens](/docs/exyliachatcosmetics/tokens).

## A command only asks and does nothing

Deleting commands such as `/cca clear`, `/cca remove`, `/cca loadouts clear` and `/cc loadout delete <name>` show what they would do. Run the same command again with `confirm` at the end.

## Players cannot colour their own messages

Formatting a player types is shown as plain text so nobody breaks the chat. To let a rank use colour codes, give it `exyliachatcosmetics.chat.format`. To let anyone, set `chat.sanitize: false`.

## Some players do not see a message

Any change to a message body, a colour included, makes it "modified" for the game. A client with the option *Only Show Secure Chat* hides such messages. Set `enforce-secure-profile=false` in `server.properties`.

## The plugin does not start

ExyliaChatCosmetics needs ExyliaLib in `plugins/`, Paper 1.21.4 or newer and Java 21. Read the first error in the console: a missing ExyliaLib or an old Paper is almost always the reason. See [Install ExyliaChatCosmetics](/docs/exyliachatcosmetics/installation).
