Players pick a font and what they type is swapped for look-alike characters: `Welcome` in small caps reaches chat as `ᴡᴇʟᴄᴏᴍᴇ`. Eighteen fonts and five decorations ship, and no resource pack is needed.

A font changes the message only. The tag, the name and the rank keep their letters, because a line half in small capitals reads worse than either half. Instructions in the text are never rewritten: MiniMessage tags, `{primary}` palette tokens, `%placeholders%` and `&` colour codes pass through untouched.

## Let players use them

<Steps>
  <Step title="Give the permission">
    Give a group `exyliachatcosmetics.font.*` (every font), `exyliachatcosmetics.font.category.<tab>` (one tab: `classic`, `typeset`, `modern` or `script`) or `exyliachatcosmetics.font.<id>` (one font). Modifiers work the same with `modifier` instead of `font`. You can also hand one out with [`/cca give`](/docs/exyliachatcosmetics/entitlements).
  </Step>
  <Step title="Open the browser">
    Players run `/cc fonts` or `/cc modifiers`, or open `/cc`, click **Your chat**, then **Message ▸ Fonts** or **Message ▸ Modifiers**.
  </Step>
  <Step title="Pick one">
    Click a font to wear it. A right click on **Message ▸ Fonts** in the menu takes off the one you wear.
  </Step>
</Steps>

## Check that it works

Wear **SMALL CAPS** and write `hello` in chat: it shows as `ʜᴇʟʟᴏ`. Wear **BOLD** and **UNDERLINED** together: both apply, because modifiers are the one type worn as a set. Wearing a second font replaces the first.

## Going further

### Choose which fonts to offer

Twelve of the eighteen fonts (every tab except CLASSIC) are built from mathematical alphabets above `U+FFFF`. Current Java clients draw them from a fallback font, wider and heavier than chat; Bedrock and old clients can show a box per letter. If many of your players are on Bedrock, delete those entries or tabs from `lang/<language>/cosmetics/fonts.yml`. Nothing is hidden automatically, `safe` only reports it.

| Tab | Fonts |
|---|---|
| CLASSIC (drawn everywhere) | `small`, `accented`, `cyrillic`, `greek`, `wide`, `bubble` |
| TYPESET | `bold`, `italic`, `bold_italic`, `monospace` |
| MODERN | `sans`, `sans_bold`, `sans_italic`, `outline` |
| SCRIPT | `script`, `bold_script`, `fraktur`, `bold_fraktur` |

### Add your own font

<Steps>
  <Step title="Copy an entry">
    In `lang/<language>/cosmetics/fonts.yml`, copy an entry such as `wide`.
  </Step>
  <Step title="Write the letters">
    Replace `alphabet` with your glyphs: 26 for `a` to `z`, or 52 with the capitals after them. 26 gives both cases the same glyph, which is what small capitals are. Add `digits` with exactly 10 glyphs if you want numbers changed.
  </Step>
  <Step title="Reload">
    Run `/cca reload`. A wrong length is reported in the console with its path and the entry is skipped.
  </Step>
</Steps>

```yaml
fonts:
  wide:
    category: classic
    name: '{primary}&lWIDE'
    alphabet: 'ａｂｃｄｅｆｇｈｉｊｋｌｍｎｏｐｑｒｓｔｕｖｗｘｙｚＡＢＣＤＥＦＧＨＩＪＫＬＭＮＯＰＱＲＳＴＵＶＷＸＹＺ'
    digits: '０１２３４５６７８９'
    safe: true
    icon: BOOKSHELF
    priority: 5
```

Letters with no look-alike stay plain: GREEK has none for `j`, `r` and `v`, and that is deliberate.

### Modifiers

`lang/<language>/cosmetics/modifiers.yml` holds five decorations: `bold`, `italic`, `underlined`, `strikethrough` and `obfuscated`. Each entry has a `decoration` key that defaults to its id.

```yaml
modifiers:
  bold:
    category: style
    name: '{primary}&lBOLD'
    decoration: bold
    icon: IRON_BLOCK
    priority: 1
```

<Details title="Technical details">

| Key | What it does |
|---|---|
| `alphabet` | glyphs for `a` to `z`: 26 or 52 characters |
| `digits` | optional, exactly 10 glyphs for `0` to `9`; without it numbers are left alone |
| `map` | optional `character: glyph` pairs, one code point each side (`'!': '❗'`) |
| `safe` | whether every glyph is in the basic plane; default `true`; report only, nothing is withheld |
| `decoration` | modifiers only: `bold`, `italic`, `underlined`, `strikethrough`, `obfuscated` |

Any other length, `digits` that are not ten, or a `map` pair that is not one character to one glyph is reported and skipped. An entry with no glyphs at all is dropped ("declares no glyphs, so this font changes nothing"). The shared fields (`category`, `name`, `icon`, ...) are in [the catalogue](/docs/exyliachatcosmetics/catalogue).

The squared alphabets are not shipped: at chat size they read as boxes. An unclosed `<`, brace or lone `%` is text, as MiniMessage reads it.

</Details>
