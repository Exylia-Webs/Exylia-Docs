Use these to show what a player wears in a chat plugin, tab list, nametag or scoreboard. They work in every ExyliaLib text on their own, and in other plugins once PlaceholderAPI is installed. Click one to copy it.

## Pick the notation

Tags and coloured names come in three spellings. Pick the one your chat plugin reads:

- No suffix: MiniMessage (`<#ffd700>[MVP]`). The default.
- `_legacy`: `&` codes.
- `_section`: `§` codes, for plugins that send the string as it is.

A chat format for a MiniMessage chat plugin:

```text
%exyliachatcosmetics_tag%%exyliachatcosmetics_nick%<gray>: <white>%message%
```

For a plugin that reads legacy strings:

```text
%exyliachatcosmetics_tag_section%%exyliachatcosmetics_nick_section%§7: §f%message%
```

The message itself is coloured by the plugin's chat hook, not by a placeholder. Keep your chat plugin's own message placeholder.

<Callout type="tip" title="Tab list and nametags: use the _still forms">
An animated tag changes every frame, and anything that is sent again each time it changes would flood your players with packets. Use `%exyliachatcosmetics_tag_still%`, `nick_still`, `identity_still` and so on in the tab list, nametags and scoreboards: the same drawing held on its first frame.
</Callout>

## When there is nothing to show

Every placeholder here always answers. A player wearing nothing gets an empty text by default, so a chat format does not print the raw placeholder. To show a word instead, set `placeholders.none` in `config.yml`. A name that points at something that no longer exists in your files answers `placeholders.unknown` (`?` by default).

A chat line is drawn once, so an animated tag keeps the frame it had when the message was sent. A scoreboard or a hologram asks again on every refresh and does animate.
