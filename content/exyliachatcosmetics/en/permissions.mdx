A fresh install works without any permission setup: everybody can open `/cc`, whisper and show their item, and only operators get `/cca`. Cosmetics are the other way round: nobody owns anything until you give it.

## Give a permission with LuckPerms

```text
/lp group vip permission set exyliachatcosmetics.tag.item.mvp true
/lp group vip permission set exyliachatcosmetics.chat_color.category.premium true
/lp group vip permission set exyliachatcosmetics.loadouts.5 true
```

The first line gives the `mvp` tag to the `vip` group. The second gives every chat colour in the `premium` tab. The third lets the rank keep five loadouts.

<Callout type="warning" title="Never give a default group exyliachatcosmetics.*">
`exyliachatcosmetics.*` owns every cosmetic of every type. A group with `*` or this node makes grants, expiry and purchases pointless.
</Callout>

## All permissions

The `<type>`, `<id>` and `<n>` rows are patterns: replace them with the real value. Nodes written like this are not declared in `plugin.yml`, so they default to operators only, which is what keeps cosmetics locked.

## How ownership nodes work

The types are `preset`, `tag`, `nick_color`, `rank_color`, `chat_color`, `shadow_color`, `font` and `modifier`. A shadow is owned as `shadow_color` wherever it is worn; `nick_shadow` and `rank_shadow` only say where it is put.

A preset node gives the preset itself and nothing inside it. Wearing a preset puts on the pieces the player already owns, so grant the pieces together with the preset.

Custom tags and colours belong to whoever made them and have no node. An entry marked `permission: false` in its file ignores these nodes and is owned only through [grants](/docs/exyliachatcosmetics/entitlements). Rank colours are the exception: they are owned by being in one of the LuckPerms groups the entry lists, so a player in `vip` can wear the VIP colour without any node.

<Details title="Technical details">
The chat module also reads `exyliachatcosmetics.chat.channel.<id>` and `exyliachatcosmetics.chat.format.<name>` when a channel or format file sets a `permission`, and `exyliachatcosmetics.chat.emoji.<name>` for gated emojis. Numeric nodes pick a winner among those a player holds: the highest for `loadouts`, `customtag.length` and `customcolor.stops`, the lowest for `chat.cooldown`.
</Details>
