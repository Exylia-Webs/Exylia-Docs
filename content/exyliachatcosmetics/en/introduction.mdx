ExyliaChatCosmetics lets players wear a tag, a coloured name, a coloured message and a font in your server chat. It also runs the chat itself: channels, private messages, a word filter, mentions, emojis and an announcer. In ten minutes you will have a player wearing a tag that everyone sees in chat.

## What you will have in 10 minutes

<Steps>
  <Step title="Install">
    Put the jar next to ExyliaLib and start the server. See [Install ExyliaChatCosmetics](/docs/exyliachatcosmetics/installation).
  </Step>
  <Step title="Give a tag and wear it">
    Run `/cca give <player> tag:heart`, then the player opens `/cc` and clicks it. See [Your first cosmetic](/docs/exyliachatcosmetics/first-steps).
  </Step>
  <Step title="Read it in chat">
    Write a message. The tag and the coloured name show in front of it.
  </Step>
</Steps>

## What ships

Nothing needs writing before you start: the catalogue is already full. Delete what you do not want, or write your own, and run `/cca reload`.

| What | How many |
|---|---|
| Tags | 180, in seven tabs |
| Nick colours (the name) | 90 |
| Chat colours (the message) | 96 |
| Shadow colours (under the message) | 90 |
| Rank colours (your rank's prefix and suffix) | 77 |
| Fonts | 18 |
| Presets (a whole look in one click) | 12 |
| Animations | 18 |

Players own a cosmetic only when you give it to them or give them its permission. A few are free: the flat rank colours, and anything you set as a default. Every tag is a single symbol, never a word, so nobody can pass one off as a rank.

## Does it replace my chat plugin?

Both work. The built-in chat is on by default, so the plugin delivers every message and draws the tag and the name itself. If another plugin already runs your chat, set `modules.chat: false` in `config.yml`, run `/cca reload`, and put the placeholders in that plugin's format. See [The chat module](/docs/exyliachatcosmetics/chat).

## What you need

- Paper 1.21.4 or newer, and Java 21. Folia is supported.
- [ExyliaLib](/docs/exylialib/colours), required.
- Optional: PlaceholderAPI (to use the tag in another chat plugin), LuckPerms (required for rank colours), ExyliaEconomy or Vault (prices), Redis (several servers).

<Callout type="note" title="Sprites and heads need 1.21.9 on the client">
Tags drawn as sprites, particles or head skins need a 1.21.9 client. An older client sees the text they are written as. Symbol tags, colours, fonts and the chat work on every version from 1.21.4.
</Callout>

<Details title="Conventions used in these pages">
- A cosmetic is named `type:id`, for example `tag:heart` or `chat_color:aurora`.
- Ids are lowercase `a-z 0-9 _ -`; `MVP` and `mvp` are the same id.
- Colours are ExyliaLib palette tokens such as `{primary}`, so they follow your server's colours. See [Colours](/docs/exylialib/colours).
- Durations are `30m`, `2h`, `14d`, `1w`.
- The files the plugin writes on first start are never overwritten by a new version.
</Details>
