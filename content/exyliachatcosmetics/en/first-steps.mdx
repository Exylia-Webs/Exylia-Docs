At the end of this page one player owns a tag, wears it from the menu, and everybody sees it in chat. You use `/cca`, `/cc` and one small file.

Nothing is owned at first. The catalogue ships with about 180 tags and 350 colours, and a player owns an entry only when you grant it or give them its permission. A few things are free: the flat rank colours, and anything you set as a [default](/docs/exyliachatcosmetics/configuration).

## Before you start

Install the plugin and ExyliaLib, start the server, and make sure you are an operator or have `exyliachatcosmetics.admin`. See [Install ExyliaChatCosmetics](/docs/exyliachatcosmetics/installation).

## Steps

<Steps>
  <Step title="Open the menu">
    Run `/cc`. The window is called **Chat cosmetics**. It shows **Your chat** (a live preview of your line), **Identity** (tags, nick colours, rank colours), **Message** (chat colours, shadows, fonts, modifiers), **Favorites**, **Loadouts**, **Presets** and **Your collection**. Rows you do not own read as locked.
  </Step>
  <Step title="Give yourself a tag">
    Run `/cca give <your name> tag:heart`. Add a time to make it temporary: `/cca give <your name> tag:heart 14d`. With no time it is permanent.
  </Step>
  <Step title="Wear it">
    In `/cc`, click **Identity**, then **Tags**, and click the heart. Or type `/cc equip tag:heart`. The preview line in **Your chat** changes at once.
  </Step>
  <Step title="Show the tag in the chat line">
    The chat line that ships with the plugin has a rank, a name and the message, but no tag. Copy `plugins/ExyliaChatCosmetics/chat/formats/default.yml` to `tag.yml` in the same folder. Set `weight: 1` and add this piece under `components`:

    ```yaml
      tag:
        priority: 5
        text: '{tag}'
    ```

    Run `/cca chat reload`. Leave `default.yml` alone: the plugin replaces it when a new version ships.
  </Step>
  <Step title="Send a message">
    Write something in chat. You should see the heart before your name.
  </Step>
</Steps>

## Check that it works

Run `/cca check <your name> tag:heart`. It answers whether the player owns it and until when. Run `/cca render <your name>` to get the tag, the coloured name and a sample message in chat.

## Use another chat plugin instead

If another plugin writes your chat line, turn the built-in chat off with `modules.chat: false` in `config.yml`, run `/cca reload`, and put `%exyliachatcosmetics_tag%%exyliachatcosmetics_nick%` in that plugin's format. You need PlaceholderAPI for that. See [Placeholders](/docs/exyliachatcosmetics/placeholders) and [Integrations](/docs/exyliachatcosmetics/integrations).

## Give cosmetics to a whole rank

Do not run a command per player. Give the permission to the group in your permission plugin, for example `exyliachatcosmetics.tag.item.heart` or `exyliachatcosmetics.tag.category.symbols` for a whole tab. See [Permissions](/docs/exyliachatcosmetics/permissions).
