ExyliaShields has four things you can sell. All of them are permissions, so any permission plugin can hand them out, and a rank that expires takes them back.

## What each rank can have

| Perk | Permission | Without it |
|---|---|---|
| More saved designs | `exyliashields.max_slots.<n>` | 1 slot |
| Deeper designs | `exyliashields.layers.<n>` | `max_layers` in `shields.yml`, 6 |
| A pattern | `exyliashields.pattern.<id>` or `exyliashields.pattern.*` | Locked |
| A colour | `exyliashields.color.<id>` or `exyliashields.color.*` | Locked |
| More crate openings at once | `exyliashields.crate.multi.<n>` | `crate.max-at-once`, 4 (7 at most) |

When a player holds several numbers of the same kind, the highest wins. Giving a rank `max_slots.5` on top of `max_slots.1` is an upgrade, never a conflict.

<Callout type="warning" title="Start with a palette">
A normal player owns no pattern or colour until a permission, a crate or a purchase gives one. Operators hold them all. Decide what your free rank gets first.
</Callout>

## Example with LuckPerms

<Steps>
  <Step title="Free rank">
    All colours and a few plain patterns:
    ```text
    /lp group default permission set exyliashields.color.* true
    /lp group default permission set exyliashields.pattern.stripe_top true
    ```
  </Step>
  <Step title="Paid rank">
    More slots, more layers and every pattern:
    ```text
    /lp group vip permission set exyliashields.max_slots.5 true
    /lp group vip permission set exyliashields.layers.8 true
    /lp group vip permission set exyliashields.pattern.* true
    ```
  </Step>
  <Step title="Check it">
    Log in as a player of that rank, open `/shields` and see the extra slots and unlocked rows. Staff can read the ids from `shields.yml`.
  </Step>
</Steps>

A pattern won in the [crate](/docs/exyliashields/crate) or bought in the shop is saved on the player's account, not as a permission, so it stays when their rank ends. Slots and layers come from permissions and go with the rank.

## When a rank ends

Designs are stored on the player, not on the rank, so ending a rank does not delete them. The player just cannot create more than their new limit allows.

The full list of nodes is in [Permissions](/docs/exyliashields/permissions).
