## A design is a stack of layers

Each layer is a **pattern** plus a **colour**, applied in order: the last one added sits on top. The stack is limited to `max_layers` in `shields.yml` (six by default). A rank raises it with `exyliashields.layers.<n>`, the highest one held winning. Raising it is a cost for every client that sees the shield, so keep it sensible.

## Slots

Designs live in numbered slots, and the **active** slot is the one drawn on the player's shield. `/shields` opens **MY SHIELDS**.

| Click or button | What it does |
|---|---|
| **Shields ▸ New shield** | Starts a design in a free slot and opens the editor. |
| Left-click a slot | Edit it. |
| Right-click a slot | Wear it (make it the active one). |
| **Shields ▸ Import by ID** | Brings in a library design. |
| **Shields ▸ Community browser** | Browse shared designs. |
| **Shields ▸ Shield crate** | Open the crate. |

The slot count is the highest `exyliashields.max_slots.<n>` a player holds. With none, everybody has one slot. When the limit is reached the button reads **Slot limit reached**. See [Sell slots, layers and colours](/docs/exyliashields/ranks).

## The editor

| Button | What it does |
|---|---|
| **Design ▸ Base color** | Picks the colour of the shield itself. |
| **Design ▸ Dye color** | Picks the colour the next layer is added in. |
| **Pattern ▸ name** | Adds that pattern on top, in the selected dye. |
| **Layer N ▸ pattern** | Click to remove that layer. |
| **Design ▸ Pattern preview** | Turns the live preview on or off. |
| **Design ▸ Reset design** | Removes every layer, keeps the slot. Asks to confirm. |
| **Design ▸ Delete design** | Removes the slot. Asks to confirm. |
| **Design ▸ Set as active** | Wears this design. |
| **Back ▸ My shields** | Returns to the slot list. |

The same editor also comes as a [3D designer](/docs/exyliashields/3d-menus), with the same rules.

## Patterns and colours

43 patterns and 16 colours ship in `shields.yml`. Both are locked by permission, crate or purchase: a player builds only with what they own.

```text
exyliashields.pattern.stripe_bottom
exyliashields.pattern.*
exyliashields.color.red
exyliashields.color.*
```

A pattern won in the crate or bought in the editor counts the same as a permission. See [The crate and the shop](/docs/exyliashields/crate).

## Where a design is stored

In the database, against the player: their slots and which one is active. Not on the shield item.

- A shield that breaks and is replaced comes back decorated.
- A shield dropped and picked up by somebody else does not carry the design.
- Changing the active slot changes every shield that player holds.

## When it is drawn

Whenever the player's held items change: swapping hands, an inventory click, scrolling the hotbar, or any inventory slot changing. That last one covers a shield arriving from a kit, a crate or another plugin.
