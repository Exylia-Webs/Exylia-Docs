title: "War tools"
description: "Focus, camp, rally and regroup: the four things a clan points at something, and the boss bars that track them."

Four commands exist for the fight itself, each behind its own rank permission: `FOCUS`, `CAMP`, `RALLY`
and `REGROUP`. The shipped ranks give `FOCUS` to everybody, `CAMP` and `RALLY` to officers and leaders,
and `REGROUP` to officers and leaders — see [Roles](/docs/exyliaclans/roles).

## Focus

```
/clan focus <player>
/clan focus
```

Marks one enemy for the whole clan: they are made to **glow** for every online member, and a boss bar
shows their health. It is how a clan calls a target in the middle of a fight without typing a name into
chat.

Setting and clearing both need `FOCUS`. There are three ways to take it off: `/clan focus` with **no name at all**, `/clan focus` on the player
who is already focused, or letting it clear itself when the target dies, disconnects, or is found
offline or dead on a bar tick. The clan is told with `clan.focus-cleared`; a clan focusing nobody is
told `clan.focus-none`.

<Callout type="note" title="Red needs a visibility mode; the rest of the focus does not need anything">
The **red** colour is a scoreboard team, and `visibility-mode` ships as `DISABLED`, which never creates
one — so out of the box a focused player glows without turning red. Set any other mode on the
[Relations](/docs/exyliaclans/relations#how-a-player-is-coloured) page to get the colour.

Without **PacketEvents** the outline is what goes quiet, not the command: the boss bar and the call to
the whole clan still work.
</Callout>

| Refused when | Message |
|---|---|
| The target is you | `errors.cannot-target-self` |
| The target is in your clan | `errors.cannot-target-own-clan` |
| The target is in an allied clan | `errors.cannot-target-ally` |

```yaml
bossbars:
  focus:
    enabled: true
    config:
      color: RED
      style: NOTCHED_20
```

What the bar says is in `messages.yml`, under `bossbars.focus`:
`{warning}⚔ %player%  {error}❤ %health%/%max_health%`.

Clearing a focus repaints the target for each viewer according to the visibility rules, so they go back
to whatever colour they should have been — not to whatever colour they had before.

## Camp

```
/clan camp <clan>
```

Puts a marker on another clan's **home**, for your whole clan: a red waypoint on clients that draw them
(with a camp icon on the map where the client has icons), and a boss bar counting the distance down.
Running it again on the same clan clears the marker. Needs `CAMP`.

It is refused if that clan has no home set, and also if their home is **on another server** or in a
world that is not loaded here — a clan home carries the server it was set on, so a network can have a
home this server cannot point at. It is not restricted to rivals: you can camp anyone.

```yaml
bossbars:
  camp:
    enabled: true
    max-distance: 500
    duration-seconds: 0
    config:
      color: RED
      style: PROGRESS
```

`max-distance` is where the bar reads empty, not a range limit. `duration-seconds` is how long the marker
stays: `0`, the shipped value, keeps it until somebody runs `/clan camp` on the same clan again; any other
value clears it on its own and tells the clan with `clan.camp-cleared`. The bar's text is
`bossbars.camp` in `messages.yml`.

A member who leaves the clan loses its camp and rally markers at once — they belong to the clan, not to
whoever was in it when they were called.

## Rally

```
/clan rally
/clan rally clear
```

Drops a marker at your feet for the whole clan — yellow waypoint, yellow bar, coordinates broadcast in
chat. It is a "come here", not a teleport: nobody is moved. Both forms need `RALLY`; a new rally replaces
the clan's previous one, and `/clan rally clear` takes it down for everybody (`errors.rally-not-found`
when there is none).

On the SurvivalCore client the rally is drawn natively — a beam, a sound and an on-screen call — and
every other client that draws waypoints gets a waypoint with the same name for the same time. A member
who logs in while a rally is up is shown it with the time it has left.

```yaml
bossbars:
  rally:
    enabled: true
    max-distance: 500
    duration-seconds: 120
    config:
      color: YELLOW
      style: PROGRESS
```

A rally expires after `duration-seconds` (120 s) and the clan is told when it does. `0` keeps it up until
`/clan rally clear`. The bar's text is `bossbars.rally` in `messages.yml`.

## Regroup

```
/clan regroup
/clan regroup join
```

The teleport version. `/clan regroup` needs the `REGROUP` rank permission and broadcasts a **clickable**
message to the whole clan; clicking it — or typing `/clan regroup join` — walks the member through a
warmup and then teleports them to the point.

| Setting | Default | What it does |
|---|---|---|
| `regroup-warmup-seconds` | 5 | Countdown before the teleport. `0` is instant. |
| `regroup-cancel-on-move` | `true` | Moving cancels it |
| `regroup-cancel-on-damage` | `true` | Taking damage cancels it |
| `regroup-warmup-tick-sound` | `UI_BUTTON_CLICK\|0.6\|1.3` | Played each second. Blank for silence. |
| `regroup-cooldown-seconds` | 60 | Per clan, between calls. `0` disables. |
| `regroup-expire-seconds` | 60 | How long the point stays joinable. `0` never expires. |

The countdown is drawn by `regroup-effects`.

When the point expires, every countdown still running towards it is cancelled — nobody is teleported to
a point that no longer exists. A new `/clan regroup` from the same clan, or the clan disbanding, also
cancels them.

The regroup point carries the server it was called on. On a network sharing one database and Redis,
clanmates on other servers see the call too, and joining it hands them over to that server.

```yaml
regroup-effects:
  warmup-title:
    fade-in: 0
    stay: 10
    fade-out: 0
  teleport-title:
    fade-in: 10
    stay: 50
    fade-out: 15
```

Only the timings live in `config.yml`, in ticks (twenty to a second). The words are in `messages.yml`
under `teleport.regroup`: `warmup-actionbar`, `warmup-title`, `warmup-subtitle`, `arrival-title` and
`arrival-subtitle`, with `%time%` as the seconds left.

<Callout type="note" title="Rally and regroup are two different things">
Rally is a marker nobody is moved by. Regroup is a teleport, with a clan-wide cooldown on top of its
rank permission. A clan can have both up at once.
</Callout>

## The clan home

Not a war tool as such, but it shares the machinery. `/clan home` runs the same kind of warmup, timed by
`home-effects` and worded by `teleport.home` in `messages.yml`, with `home-warmup-seconds`,
`home-cancel-on-move`, `home-cancel-on-damage` and `home-warmup-tick-sound` in `settings`. The home is
also a permanent waypoint for members and allies, with a home icon where the client draws icons.

## Keys on the SurvivalCore client

A player on the SurvivalCore client finds two entries in the game's controls screen: **Clan menu** and
**Clan rally**. Both ship unbound. Pressing one runs exactly `/clan` or `/clan rally`, permission checks
included.

## Turning the bars off

Each of the three boss bars has its own `enabled`. Turning one off leaves the waypoint and the chat
broadcast in place — only the bar goes.

| Key | Accepts |
|---|---|
| `color` | `PINK`, `BLUE`, `RED`, `GREEN`, `YELLOW`, `PURPLE`, `WHITE` |
| `style` | `PROGRESS`, `NOTCHED_6`, `NOTCHED_10`, `NOTCHED_12`, `NOTCHED_20` |
