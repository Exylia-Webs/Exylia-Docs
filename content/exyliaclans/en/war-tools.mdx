Call a target, mark an enemy base, drop a meeting point or teleport the whole clan to you, with four commands: `/clan focus`, `/clan camp`, `/clan rally` and `/clan regroup`.

## Before you start

- Each tool sits behind its own rank permission: `FOCUS`, `CAMP`, `RALLY`, `REGROUP`. The shipped ranks give `FOCUS` to every member, and `CAMP`, `RALLY` and `REGROUP` to officers and leaders. Change that in [Ranks](/docs/exyliaclans/roles).
- Players also need the command permission, for example `exyliaclans.commands.focus`: see [Permissions](/docs/exyliaclans/permissions).
- `/clan regroup` needs the `regroup` module on: see [Turn clan systems on and off](/docs/exyliaclans/modules).

## Steps

<Steps>
  <Step title="Call a target with focus">
    Run `/clan focus <player>`. That player glows for every online clan member and a boss bar shows their health.
  </Step>
  <Step title="Mark an enemy base with camp">
    Run `/clan camp <clan>`. The clan gets a red waypoint on the other clan's home and a boss bar with the distance.
  </Step>
  <Step title="Drop a meeting point with rally">
    Stand where you want the clan and run `/clan rally`. A yellow marker appears at your feet for everybody and the coordinates go to clan chat. Nobody is moved.
  </Step>
  <Step title="Teleport the clan with regroup">
    Run `/clan regroup`. Every member gets a clickable message; clicking it, or running `/clan regroup join`, starts a 5 second warmup and then teleports them to you.
  </Step>
</Steps>

## Check that it works

With a second player in your clan: run `/clan focus <someone from another clan>` and the second player should see that person glow and a red boss bar with their health. Run `/clan rally` and the second player should see a yellow bar and the coordinates in chat. Run `/clan regroup`, click the message as the second player, stand still and wait for the teleport.

## Focus

```
/clan focus <player>
/clan focus
```

Setting and clearing both need `FOCUS`. There are three ways to take a focus off: `/clan focus` with no name, `/clan focus` on the player who is already focused, or let it clear itself when the target dies, disconnects or is found offline or dead on a bar tick. The clan is told with `clan.focus-cleared`; a clan focusing nobody is told `clan.focus-none`.

<Callout type="note" title="Red needs a visibility mode; the rest does not">
The **red** colour is a scoreboard team, and `visibility-mode` ships as `DISABLED`, which never creates one, so out of the box a focused player glows without turning red. Set any other mode on the [Relations](/docs/exyliaclans/relations#how-a-player-is-coloured) page to get the colour.

Without **PacketEvents** the outline goes quiet, not the command: the boss bar and the call to the whole clan still work.
</Callout>

You cannot focus yourself (`errors.cannot-target-self`), a member of your own clan (`errors.cannot-target-own-clan`) or a member of an allied clan (`errors.cannot-target-ally`). Clearing a focus repaints the target for each viewer according to the visibility rules.

## Camp

```
/clan camp <clan>
```

Needs `CAMP`. Running it again on the same clan clears the marker. It is refused if that clan has no home set, if their home is on another server or if it is in a world that is not loaded here. It is not restricted to rivals: you can camp anyone.

`max-distance` is where the bar reads empty, not a range limit. `duration-seconds` is how long the marker stays: `0`, the shipped value, keeps it until somebody runs `/clan camp` on the same clan again; any other value clears it on its own and tells the clan with `clan.camp-cleared`. A member who leaves the clan loses its camp and rally markers at once.

## Rally

```
/clan rally
/clan rally clear
```

Both forms need the `RALLY` rank permission; only `/clan rally` also needs a command permission (`/clan rally clear` has none). A new rally replaces the clan's previous one, and `/clan rally clear` takes it down for everybody (`errors.rally-not-found` when there is none). A rally expires after `duration-seconds` (120 s) and the clan is told when it does; `0` keeps it until `/clan rally clear`.

A client that draws waypoints gets a waypoint with the same name for the same time. A member who logs in while a rally is up is shown it with the time it has left.

## Regroup

```
/clan regroup
/clan regroup join
```

`/clan regroup` needs the `REGROUP` rank permission and broadcasts a **clickable** message to the whole clan. A new `/clan regroup` from the same clan, the point expiring or the clan disbanding cancels every countdown still running, so nobody is teleported to a point that no longer exists.

The regroup point carries the server it was called on. On a network sharing one database and Redis, clanmates on other servers see the call too, and joining it hands them over to that server.

<Callout type="note" title="Rally and regroup are two different things">
Rally is a marker nobody is moved by. Regroup is a teleport, with a clan-wide cooldown on top of its rank permission. A clan can have both up at once.
</Callout>

## The clan home

Not a war tool as such, but it shares the machinery. `/clan home` runs the same kind of warmup, timed by `home-effects` and worded by `teleport.home` in `messages.yml`, with `home-warmup-seconds`, `home-cancel-on-move`, `home-cancel-on-damage` and `home-warmup-tick-sound` in `settings`. The home is also a permanent waypoint for members and allies, with a home icon where the client draws icons.

## Turn the boss bars off

Each of the three boss bars has its own `enabled`. Turning one off leaves the waypoint and the chat broadcast in place; only the bar goes.

<Details title="config.yml: boss bars and regroup keys">

```yaml
bossbars:
  focus:
    enabled: true
    config:
      color: RED
      style: NOTCHED_20
  camp:
    enabled: true
    max-distance: 500
    duration-seconds: 0
    config:
      color: RED
      style: PROGRESS
  rally:
    enabled: true
    max-distance: 500
    duration-seconds: 120
    config:
      color: YELLOW
      style: PROGRESS
```

| Key | Accepts |
|---|---|
| `color` | `PINK`, `BLUE`, `RED`, `GREEN`, `YELLOW`, `PURPLE`, `WHITE` |
| `style` | `PROGRESS`, `NOTCHED_6`, `NOTCHED_10`, `NOTCHED_12`, `NOTCHED_20` |

The bar texts are `bossbars.focus`, `bossbars.camp` and `bossbars.rally` in `messages.yml`; the focus one ships as `{warning}⚔ %player%  {error}❤ %health%/%max_health%`.

Regroup settings, under `settings`:

| Setting | Default | What it does |
|---|---|---|
| `regroup-warmup-seconds` | 5 | Countdown before the teleport. `0` is instant. |
| `regroup-cancel-on-move` | `true` | Moving cancels it |
| `regroup-cancel-on-damage` | `true` | Taking damage cancels it |
| `regroup-warmup-tick-sound` | `UI_BUTTON_CLICK\|0.6\|1.3` | Played each second. Blank for silence. |
| `regroup-cooldown-seconds` | 60 | Per clan, between calls. `0` disables. |
| `regroup-expire-seconds` | 60 | How long the point stays joinable. `0` never expires. |

The countdown is drawn by `regroup-effects`; only the timings live in `config.yml`, in ticks (twenty to a second):

```yaml
regroup-effects:
  warmup-title:
    fade-in: 0
    stay: 10
    fade-out: 0
  teleport-title:
    fade-in: 10
    stay: 50
    fade-out: 15
```

The words are in `messages.yml` under `teleport.regroup`: `warmup-actionbar`, `warmup-title`, `warmup-subtitle`, `arrival-title` and `arrival-subtitle`, with `%time%` as the seconds left.
</Details>
