At the end of this page you have one clan with money in its bank, a claimed area and a home. You only use chat and the clan menu.

## Before you start

Install the plugin, see [Install ExyliaClans](/docs/exyliaclans/installation). Player commands are allowed by default, so there is nothing to grant to start playing. For staff, give the `exyliaclans.admin` node, see [Permissions](/docs/exyliaclans/permissions).

<Callout type="warning" title="Keep the bypass node for staff only">
`exyliaclans.claim.bypass` ignores every claim protection on the server and is not covered by `exyliaclans.commands.*`.
</Callout>

## Steps

<Steps>
  <Step title="Create the clan">
    Run `/clan create Vanguard`. Names use letters, digits and underscores, from 3 to 16 characters, and are unique. You become the leader, and the clan starts with three ranks: Leader, Officer and Member.
  </Step>
  <Step title="Fund the bank">
    Run `/clan deposit 5000`. The money comes from your own balance. Land is paid from the bank, so do this before claiming.
  </Step>
  <Step title="Claim the land">
    Run `/clan claim` and you receive a golden hoe. Left-click a block for corner 1, right-click another block for corner 2, then Shift + click in the air to pay. The price is shown before you confirm. Run `/clan claim` again to cancel.
  </Step>
  <Step title="Set the home">
    Stand inside your claim and run `/clan sethome`. Members then use `/clan home`, which teleports after a short warmup that moving or taking damage cancels.
  </Step>
  <Step title="Set up the ranks">
    Open `/clan`, go to **Settings** and then **Roles**. Create ranks, set their weight and tick what each one may do. See [Ranks and permissions](/docs/exyliaclans/roles).
  </Step>
</Steps>

## Check that it works

`/clan` opens the clan menu with your clan name at the top. Walk out of your claim and back in: the claim border should show. Run `/clan home` from somewhere else and you should arrive at the home. If something fails, see [Common problems](/docs/exyliaclans/troubleshooting).

## What a claim costs

The price is the base price plus the price per block for every block of the rectangle. With the shipped values (500 and 1.0), a 20 x 20 rectangle is 400 blocks, so 500 + 400 = **900**. The rectangle is refused when it is too small or too large, when it touches another clan's land, when it overlaps a WorldGuard region or when the bank cannot pay.

A clan owns one claim. To change its shape, use `/clan reclaim` and redraw inside the current bounds. To move it, use `/clan unclaim` and claim again. Unclaiming also clears the home.

## Good first values

- **Protection mode** (`claims.protection-mode`): ships as `WORLDGUARD`. Use `BUILTIN` on a server without WorldGuard.
- **Claim prices** (`claims.base-price`, `claims.price-per-block`): set them against your own economy.
- **Max members** (`settings.max-members`): 30 by default, before level bonuses.
- **Quick chat prefixes**: the default prefixes swallow the start of a normal chat line, so check them in [Chat and mail](/docs/exyliaclans/chat-and-mail).

All of these are in the admin settings menu, see [Configuration](/docs/exyliaclans/configuration).

## Recruit members

Run `/lfp` to post what your clan is looking for, and `/lfc` as a player without a clan to be found. See [Recruitment](/docs/exyliaclans/recruitment).

<Details title="Technical details">
The leader passes every rank permission check and cannot `/clan leave`, only `/clan transferleader` or `/clan disband`. A member can only kick, ban, promote or demote someone whose rank weight is lower than their own. With the claims module on, `/clan sethome` only works inside the clan's claim.
</Details>
