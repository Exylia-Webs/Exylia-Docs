Use these in any plugin that reads PlaceholderAPI (scoreboards, TAB, chat formats, holograms). They need PlaceholderAPI installed. Click a row to copy it.

Nothing here resolves to an empty string. A player with no clan answers with the `placeholders.none` text from `messages.yml` (`{muted}None` by default), and an empty roster slot or an unranked clan answers with `placeholders.na` (`{muted}N/A`). Change them there and every placeholder follows. Colours are handed out as legacy codes, so a TAB line or hologram shows the colour instead of `{muted}`.

## The online roster

Up to thirty slots each, sorted by rank weight (heaviest first), then by name. Replace `<n>` with the slot, from 1 to 30. A slot nobody fills shows `placeholders.na`. Online counts the whole network when servers are linked with Redis. The roster is rebuilt at most once a second, so a scoreboard that asks four times a second costs one rebuild.

## Leaderboards

`<stat>` is one of `online`, `members`, `kills`, `deaths`, `kdr`, `playtime` or `balance`. Anything unranked shows `placeholders.na`.

## Relational

These need a viewer and a target, so they belong in nametags and TAB sorting, where one player is drawn to another. They use the `%rel_...%` form.

<Placeholders group="relational" />

The labels come from `messages.yml` (`relations.member`, `ally`, `enemy`, `none`) and follow the [language](/docs/exyliaclans/configuration#language); the colours come from `config.yml`:

```yaml
relational-placeholders:
  color-member: "&a"
  color-ally: "&b"
  color-enemy: "&c"
  color-none: "&7"
```

## Formats and fallbacks

Every placeholder accepts the shared format and fallback syntax:

```text
%exyliaclans_clan_balance:comma%       1,250,000
%exyliaclans_clan_kills:compact%       12.4k
%exyliaclans_clan_ff:yesno%            Yes
%exyliaclans_clan_name|No clan%        fallback when there is no value
```

Formats: `comma`, `compact` (or `short`), `percent`, `upper`, `lower`, `yesno`, `time`, `fixed1`, `fixed2`.

<Callout type="tip" title="A placeholder nobody answers stays on screen">
This is deliberate: a typo shows as `%exyliaclans_clan_nmae%` instead of a blank, and the console reports the name once. If a line looks wrong, check the console first.
</Callout>
