Turn parts of ExyliaClans off (claims, DTR, bank, wars and more) and see what stays behind when you do. All thirteen systems ship on.

## Before you start

You need access to `plugins/ExyliaClans/config.yml` on the server. Decide first what you really want to disable: some switches change how others behave, see [What the switches do to each other](#what-the-switches-do-to-each-other).

## Steps

<Steps>
  <Step title="Open config.yml">
    Open `plugins/ExyliaClans/config.yml` and find the `modules` section.
  </Step>
  <Step title="Switch the system off">
    Set the one you want to `false`, for example `claims: false`. Leave the rest as they are.
  </Step>
  <Step title="Reload">
    Run `/clanadmin reload`. A module turned off is stopped and one turned on is started, no restart needed.
  </Step>
</Steps>

## Check that it works

Run a command of the system you turned off, for example `/clan claim`. It answers that the module is disabled, and the menu buttons that open it refuse the click with the same message. The text of that message is `errors.module-disabled`, see [Messages](/docs/exylialib/messages-and-languages).

## What each one covers

| Module | Turns off |
|---|---|
| `claims` | `/clan claim`, `/clan unclaim`, `/clan reclaim`, `/clan map`, the claim tool, the corner pillars, the protection and the WorldGuard regions. See [Claim land](/docs/exyliaclans/claims). |
| `dtr` | The whole deaths-till-raidable pool: regeneration, the freeze, the death broadcast and the raidable state. See [DTR](/docs/exyliaclans/dtr). |
| `clan-home` | `/clan home`, `/clan sethome` and the home waypoints. |
| `bank` | `/clan deposit`, `/clan withdraw` and the **Bank** menu. |
| `allies` | `/clan ally` (all four forms) and the **Allies** menu. |
| `levels` | EXP, level-ups, kill-streak bonuses and the caps each level grants. See [Levels](/docs/exyliaclans/levels). |
| `lfc` | `/lfc`, its menus and its expiry task. See [Recruitment](/docs/exyliaclans/recruitment). |
| `lfp` | `/lfp`, its menus, applications and expiry task. |
| `rivals` | `/clan rival`, the **Rivals** menu and the rival EXP and kill multipliers. |
| `regroup` | `/clan regroup` and `/clan regroup join`. |
| `logs` | The audit trail, the **Logs** menu and `/clanadmin logs`. |
| `mail` | `/clan mail`, the inbox, the unread count on join and the expiry purge. See [Chat and mail](/docs/exyliaclans/chat-and-mail). |
| `wars` | `/clan war`, `/clanadmin war`, the war screens and every war in progress. See [Clan wars](/docs/exyliaclans/clan-wars). |

The clan [Discord webhook](/docs/exyliaclans/webhooks) is not a module: its switch is `webhooks.enabled`.

## What the switches do to each other

<Callout type="warning" title="Turning off claims moves the clan home">
`/clan sethome` only works inside the clan's own claim while `claims` is on. With claims off, a clan home can be set anywhere.
</Callout>

<Callout type="warning" title="Turning off dtr makes claims permanent">
A claim only stops protecting its land when its clan is raidable, which is a DTR state. With DTR off nothing ever opens a claim, so territory stays until it is unclaimed. `/clan unclaim` and `/clan disband` also stop checking the DTR.
</Callout>

<Callout type="note" title="Turning off levels freezes the caps">
`max-members`, `max-alliances` and `max-rivals` are the plain numbers in `settings`, with no level bonus. `/clanadmin setlevel` and `/clanadmin setexp` answer that the module is disabled.
</Callout>

Going further:

- Turning off `bank` does not empty balances or remove land already claimed, but no new claim can be paid for.
- Turning off `rivals` keeps the existing rivalries; they stop being read and come back when you turn it on again.
- `lfc` and `lfp` are independent. With only `lfp` clans post job offers; with only `lfc` players list themselves and clans invite from the list. The `MANAGE_LFP` rank permission matters only when `lfp` is on.

<Details title="Technical details">
```yaml
modules:
  claims: true
  dtr: true
  clan-home: true
  bank: true
  allies: true
  levels: true
  lfc: true
  lfp: true
  rivals: true
  regroup: true
  logs: true
  mail: true
  wars: true
```

A disabled module has no running manager, its commands answer `errors.module-disabled`, and the buttons that open it refuse the click. A clan home stores the server it was set on, so `/clan home` crosses a network; the waypoint is skipped for a home on another server. Turning `wars` off on reload ends running wars without recording them. Existing rows in `clan_relations` are not touched by `rivals` or `allies` being off.
</Details>
