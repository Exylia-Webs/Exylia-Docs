Players can use ExyliaClans without any setup: every player command is allowed by default, and what a member may do is decided by their rank inside the clan. Only staff nodes need granting. Use this page to restrict commands, to give staff access and to give ranks bigger limits.

Two systems answer two questions, and both must say yes. A server permission (below) says whether a player may run a command at all. A clan [rank permission](/docs/exyliaclans/roles) says whether their rank may do it inside the clan. Granting `exyliaclans.commands.kick` does not let anyone kick anybody; the command then checks their rank for `KICK`.

## Make a command a rank perk

Each command node also guards the menu buttons that do the same thing. To make a feature a perk, deny the node to the default group and grant it to the rank. With LuckPerms:

```text
/lp group default permission set exyliaclans.commands.webhook false
/lp group vip permission set exyliaclans.commands.webhook true
```

Leaving, declining, cancelling and removing are never gated: `/clan leave`, `disband`, `unclaim`, `ally decline`, `ally remove`, `rival remove`, `rally clear`, `style reset`, `webhook remove`, `war decline` and `war leave` always work.

The nodes `exyliaclans.commands.roles`, `level` and `bank` guard menu screens only; there is no `/clan roles` command.

## Style nodes

These decide what a clan leader may use in `/clan style`. Unlike the command nodes they default to `op`: a leader can run the command but cannot colour anything until a rank gets one of these.

| Node | Allows |
|---|---|
| `exyliaclans.style.color` | One named colour, such as `&b` or `<aqua>` |
| `exyliaclans.style.hex` | Hex colours (includes `style.color`) |
| `exyliaclans.style.gradient` | Several colours or a gradient (includes `style.hex`) |
| `exyliaclans.style.format` | Bold, italic, underlined, strikethrough |

`exyliaclans.style.*` grants all four. Obfuscated text, clicks, hovers and placeholders are always refused.

## Per-rank numbers

Seven limits change per rank when you grant a node that ends in a number. They are not declared one by one: grant the exact number you want, for example `exyliaclans.members.50`.

```text
/lp group vip permission set exyliaclans.members.50 true
/lp group vip permission set exyliaclans.claimarea.20000 true
```

| Node | Replaces in `config.yml` | Which number wins | Read from |
|---|---|---|---|
| `exyliaclans.members.<n>` | `settings.max-members` | highest | the clan leader |
| `exyliaclans.allies.<n>` | `settings.max-alliances` | highest | the clan leader |
| `exyliaclans.rivals.<n>` | `settings.max-rivals` | highest | the clan leader |
| `exyliaclans.claimarea.<n>` | `claims.max-area` | highest | the clan leader |
| `exyliaclans.regroupcooldown.<n>` | `settings.regroup-cooldown-seconds` | lowest | the clan leader |
| `exyliaclans.createcooldown.<n>` | `settings.create-cooldown-seconds` | lowest | the player creating |
| `exyliaclans.homewarmup.<n>` | `settings.home-warmup-seconds` | lowest | the player teleporting |

The first five apply to the whole clan and are read from the leader at the moment the limit is checked. While the leader is offline, the value in `config.yml` applies. [Level](/docs/exyliaclans/levels) bonuses and extra slots from `/clanadmin setslots` still add on top.

## Staff setup

`exyliaclans.admin` is the parent of every admin node: granting it alone gives all of `/clanadmin`. For a narrower rank, grant it and set the subcommands that rank must not have to `false`:

```text
/lp group helper permission set exyliaclans.admin true
/lp group helper permission set exyliaclans.admin.disband false
/lp group helper permission set exyliaclans.admin.setbalance false
/lp group helper permission set exyliaclans.admin.reload false
```

That helper keeps `info`, `logs` and the rest.

<Callout type="tip" title="Keep economy and moderation apart">
`setbalance`, `setexp` and `setlevel` hand out progression, and `stats` rewrites the leaderboards. Give them to whoever you trust with the economy, which is not always whoever handles reports.
</Callout>

<Callout type="danger" title="Staff only: exyliaclans.claim.bypass">
It lets a player build, break and open things in anybody's claim under the built-in protection. It is not included in `exyliaclans.commands.*`. It does not get past WorldGuard: with `protection-mode: WORLDGUARD` the region refuses the build, and you need a WorldGuard bypass.
</Callout>
