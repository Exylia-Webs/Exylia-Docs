A mob can wear a Blockbench model instead of its vanilla body. The model is drawn from block, item and head
displays, so players need no resource pack. How cubes become blocks, how animations are matched to states
and what a model may cost are ExyliaLib's, on [Mobs and models](/docs/exylialib/mobs-and-models#models).

## The models folder

Save a Blockbench project (`.bbmodel`) into `plugins/ExyliaMobs/models/`. Its name is the file name in
lower case. Saving it again in Blockbench reloads it; `/mobsadmin models reload`, or **RELOAD MODELS** on
the models page, reads the folder at once.

`/mobsadmin` → **MODELS**, or `/mobsadmin models`, lists every model with its cubes, its animations and
whether it reads whole. A model with problems (meshes, locators or Molang, which are left out) shows how
many, and the first five of them. From the console the same command prints the list in chat.

### The showcase

Three models ship, each worn by a ready mob of the same name:

| Mob | Type under it | Body | What it does |
|---|---|---|---|
| `stone_golem` | Iron golem | Heavy | 120 health. A 160° slam every 4 s that knocks back, and a plain blow. |
| `crawler` | Spider | Climber, faster | 40 health. A bite every 1.1 s; climbs walls. |
| `wisp` | Allay | Hover, keeps 7 blocks away | 30 health. Throws a small fireball every 2.2 s from up to 14 blocks. |

Each is handed over once. A showcase model or mob you delete does not come back on the next start: what
was handed over is noted in `models/.bundled` and `showcase-mobs.txt`. A model file of the same name you
made yourself is never overwritten. On a network, a showcase mob another server already stored is not
stored again.

## The model screen

**3D MODEL** on a mob's screen opens it.

| Button | What it sets |
|---|---|
| Header | The model, its cubes and its animations. |
| **MODEL** | Which model it wears, from the folder, or the vanilla body. A mob picking its first model gets a walker body, so the model is not just a disguise over the vanilla mob. A model with problems says so in chat. |
| **SCALE** | How big it is drawn, `0.1` to `16`. `1` is the size it was modelled at; it also grows with the mob's own `scale` attribute. |
| **ANIMATIONS** | Which animation plays for each state: idle, walk, run, attack, hurt, death, spawn and one cast per skill. Left alone, a state plays the animation found by its name (an animation called `walk` plays as it walks). Pick one to override it. |
| **DEATH** | Automatic, animation then fade, comes apart, animation then apart, or the vanilla reaction. |
| **HEAD FOLLOWS** | A bone called `head` turns towards its target or the nearest player. On by default. |
| **TWEAKS** | Bones hidden or drawn in another block, size and place, speeds per state and the hitbox, with the model standing in front of you as a preview. |
| **BODY** | How it moves and thinks. |
| **ATTACKS** | Its own blows and throws, each landing on its animation's beat. |
| **SOUNDS** | Its own voice. |
| **BACK** | The mob's screen. |

### Body

The body decides what carries the model, so the mob's TYPE no longer matters once it has one: TYPE on its
screen opens the body instead.

| Body | How it moves |
|---|---|
| Vanilla mob | The vanilla mob's own body, AI and box, wearing the model. |
| Walker | Walks: people, beasts. |
| Heavy | Walks slowly, steps up whole blocks, shrugs off knockback and falls: golems, giants. |
| Climber | Walks, and climbs straight up walls: spiders, crawlers. |
| Flyer | Flies anywhere, at its target's height when hunting. |
| Hover | Floats a little above the ground and drifts: wisps, spirits. |
| Swimmer | Swims; stranded on land it dries out. |
| Static | Never moves: turrets, totems, plants. It still turns and strikes. |

The body form also sets its speed, how far it keeps from its target, when it flees and how high it hovers.

### Attacks

A list of attacks, each melee or a projectile, with its reach, arc, damage, cooldown, knockback, animation
and wind-up. With none the mob uses a plain blow.

### Sounds

Ambient, step, hurt, death and attack sounds, and how often the ambient one plays. The body under the model
is silent; with none set, the mob makes no sound.
