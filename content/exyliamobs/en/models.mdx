You end up with a mob drawn as a Blockbench model instead of its vanilla body. The model is drawn from block, item and head displays, so players need no resource pack. How cubes become blocks and what a model may cost are on [Mobs and models](/docs/exylialib/mobs-and-models#models).

## Before you start

Create the mob first. See [Create a mob](/docs/exyliamobs/building-mobs). Want to see one working? Run `/mobsadmin spawn stone_golem`.

## Steps

<Steps>
  <Step title="Save the model">
    Save your Blockbench project (`.bbmodel`) in `plugins/ExyliaMobs/models/`. Its name is the file name in lower case.
  </Step>
  <Step title="Read the folder">
    Run `/mobsadmin models reload`, or click **Reload models** on the models page. Saving the file again in Blockbench reloads it too.
  </Step>
  <Step title="Check the model">
    Run `/mobsadmin models`, or click **Models** on `/mobsadmin`. Each model shows its cubes, its animations and whether it reads whole. A model with problems (meshes, locators or Molang, which are left out) shows how many.
  </Step>
  <Step title="Dress the mob">
    Open the mob, click **3D model**, then **Model** and pick it. A mob that picks its first model gets a walker body so it is not just a disguise over the vanilla mob.
  </Step>
</Steps>

## Check that it works

Click **Spawn one here** on the mob's screen. It appears as the model. If it does not, see [Common problems](/docs/exyliamobs/troubleshooting#a-model-does-not-show-or-shows-problems).

## The model screen

| Button | What it sets |
|---|---|
| **Model** | Which model it wears, or the vanilla body. A model with problems says so in chat. |
| **Scale** | How big it is drawn, `0.1` to `16`. `1` is the size it was modelled at. |
| **Animations** | Which animation plays for each state: idle, walk, run, attack, hurt, death, spawn and one per skill cast. Left alone, a state plays the animation found by its name (one called `walk` plays as it walks). Pick one to override it. |
| **Death** | Automatic, animation then fade, comes apart, animation then apart, or the vanilla reaction. |
| **Head follows** | A bone called `head` turns towards its target or the nearest player. On by default. |
| **Tweaks** | Bones hidden or drawn in another block, size and place, speeds per state and the hitbox, with the model standing in front of you as a preview. |
| **Body** | How it moves and thinks. |
| **Attacks** | Its own blows and throws, each landing on its animation's beat. |
| **Sounds** | Its own voice. |

## Body

The body decides what carries the model, so the mob's **Type** no longer matters once it has one: **Type** on the mob's screen opens the body instead.

| Body | How it moves |
|---|---|
| Vanilla mob | The vanilla mob's own body, AI and box, wearing the model. |
| Walker | Walks: people, beasts. |
| Heavy | Walks slowly, steps up whole blocks, shrugs off knockback and falls: golems, giants. |
| Climber | Walks and climbs straight up walls: spiders, crawlers. |
| Flyer | Flies anywhere, at its target's height when hunting. |
| Hover | Floats a little above the ground and drifts: wisps, spirits. |
| Swimmer | Swims; stranded on land it dries out. |
| Static | Never moves: turrets, totems, plants. It still turns and strikes. |

## Attacks and sounds

**Attacks** is a list, each melee or a projectile, with its reach, arc, damage, cooldown, knockback, animation and wind-up. With none the mob uses a plain blow. **Sounds** sets ambient, step, hurt, death and attack sounds and how often the ambient one plays. The body under the model is silent: with no sound set, the mob makes no sound.

## The showcase mobs

Three models ship, each worn by a ready mob of the same name.

| Mob | Type under it | Body | What it does |
|---|---|---|---|
| `stone_golem` | Iron golem | Heavy | 120 health. A 160 degree slam every 4 seconds that knocks back, and a plain blow. |
| `crawler` | Spider | Climber, faster | 40 health. A bite every 1.1 seconds; climbs walls. |
| `wisp` | Allay | Hover, keeps 7 blocks away | 30 health. Throws a small fireball every 2.2 seconds from up to 14 blocks. |

Each is handed over once. A showcase model or mob you delete does not come back on the next start, and a model file of the same name that you made is never overwritten. To get one back, see [Frequently asked questions](/docs/exyliamobs/faq#i-deleted-a-showcase-mob-and-it-did-not-come-back).
