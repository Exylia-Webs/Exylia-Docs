You end up with a mob that has the name, strength, skills and look you want. Every mob is built in game from `/mobsadmin`, saved in the database and shared by every server on it. Nothing is written in a file.

## Before you start

You need the `exyliamobs.admin` permission. See [Install ExyliaMobs](/docs/exyliamobs/installation).

## Steps

<Steps>
  <Step title="Open the mob list">
    Run `/mobsadmin` and click **Mobs**.
  </Step>
  <Step title="Create the mob">
    Click **Create mob**. Type an id of up to 64 characters, unique across the network, for example `frost-knight`. If another server already stored it, the chat says "A mob called … already exists."
  </Step>
  <Step title="Pick its type">
    Choose from the searchable list of creatures the server can spawn (players and armour stands are left out). The mob is saved as a vanilla mob of that type and its screen opens.
  </Step>
  <Step title="Dress it up">
    Use the buttons below. Each one saves as soon as you confirm. Mobs already alive keep what they were spawned with; new ones use the change.
  </Step>
  <Step title="Try it">
    Click **Spawn one here**. It appears where you stand.
  </Step>
</Steps>

## The mob list

Left-click a mob to open it, shift-click to spawn one where you stand and right-click to delete it. Each mob shows its name, its type and how many are alive on this server.

## The mob screen

| Button | What it sets |
|---|---|
| **Name** | The name over its head, up to 256 characters. `%health%` and `%max_health%` stay current on every hit; in hits mode they are its hits. |
| **Type** | The creature it is. On a mob wearing a model with a body, this button opens the body instead, see [Give a mob a 3D model](/docs/exyliamobs/models#body). |
| **Equipment** | Armour, the offhand, and the first hotbar slot as its main hand. Equipment never drops. |
| **Flags** | Glowing, baby, silent, fire immune, no vanilla drops, no vanilla experience, no item pickup, no sun burn, aggressive, wanders, no interaction, passive and a boss bar. |
| **Look** | Coat or variant, body armour or carpet, outline colour and an aura. **Cycle** walks through the options, **Random** picks one. Also how it enters, takes hits, dies and looks when nearly done, and its floating numbers. A mob wearing a model only gets the reactions. |
| **Attributes** | Health, damage, speed, armour, toughness, knockback resistance, follow range, attack knockback and size. Blank keeps the vanilla value. |
| **Potion effects** | Effects applied as it spawns. |
| **Skills** | What it does: pick from the skill library or build your own, each with a trigger, a cast and a style you can preview. |
| **Fight** | A pause between attacks, rotation groups and phases that change it as its health drops. |
| **Behaviour** | Hits instead of health, how long it stays, and how far it may wander from where it spawned. |
| **3D model** | A Blockbench model it wears instead of its body. See [Give a mob a 3D model](/docs/exyliamobs/models). |
| **Rewards** | Its ten reward lists. See [Reward players for kills](/docs/exyliamobs/rewards). |
| **Item delivery** | Whether each list's items burst out where it dies or go to the player. |
| **Booster source** | The source boosters see its rewards as. `mobs` unless set. |
| **Spawn one here** | One where you stand. |
| **Back** | The mob list. |
| **Delete** | Deletes it after a confirmation. |

Skills, phases, reactions, flags and attributes belong to ExyliaLib: their triggers, types, presets and limits are on [Mobs and models](/docs/exylialib/mobs-and-models#custom-mobs).

<Callout type="tip" title="Hits mode: the piñata">
A mob in hits mode ignores health. Only players' melee counts, one hit per player per cooldown, and the last hit breaks it. It pays only when broken. Set it in **Behaviour**. See [Hits mode](/docs/exylialib/mobs-and-models#hits-mode).
</Callout>

## Check that it works

Click **Spawn one here** or run `/mobsadmin spawn frost-knight`. If the server refuses the spot, the chat says "… could not spawn here. The spot may be blocked or protected."

## Going further

### Roll a random mob

**Random mob** in the list rolls a mob: an elite, a champion or, rarely, a boss, with a random type, gear, stats, flags, skills and phases. It is saved as `random_` plus four characters like any other mob, so you can change it or delete it. Right-click rolls one and spawns it at your feet. It never uses hits mode, rewards or a model.

### Add an aura

**Look** offers the auras named under `auras` in `config.yml`. Six ship: `confetti`, `sparks`, `galaxy`, `firestorm`, `waterworks` and `ender`. You can add your own, see [Configuration](/docs/exyliamobs/configuration#auras).

### Spawn and remove mobs

| Way | What it does |
|---|---|
| **Spawn one here**, or shift-click in the list | One at your feet. |
| `/mobsadmin spawn <mob> [amount]` | Up to 50 at your feet. |
| A generator | Waves in an area while players are near. See [Keep mobs alive with a generator](/docs/exyliamobs/generators). |
| **Remove all** on `/mobsadmin`, or `/mobsadmin killall` | Removes every custom mob alive on this server. |

### Delete a mob

Deleting asks first. Mobs of it already alive stay until they die or are removed, and generators listing it skip it from then on.

<Details title="Technical details">
New mobs start named `{primary}&l<ID> &8[{success}%health%&8/{info}%max_health%&8]`. A mob is called a template in the code and the API. A mob whose type this server does not know (stored by a newer server version) shows "Unknown type" and its editors say "… has a type this server does not know. Change its type first." Pick a type with **Type** and it works again. A part of a row that cannot be read is left out and named in the console instead of failing the whole mob.
</Details>
