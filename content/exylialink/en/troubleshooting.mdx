Find your symptom, then follow the fix. Run `/linkadmin status` first: it shows the connection, role, network, server id, latency and last error.

## The console says "Not connected to Exylia Link"

This server or proxy has no network secret yet. Run `/linkadmin connect`, open the link it shows, sign in with Discord, pick the network and approve. Do it once on every server and proxy. Until then the plugin stays idle and nothing else breaks. See [Install ExyliaLink](/docs/exylialink/installation).

## "A connection code is already waiting for approval" or "The code expired"

`/linkadmin connect` has one code at a time. Approve it in the browser, or wait for it to expire and run the command again.

## /link says Discord linking is unavailable

The connection to Exylia Link is down or did not answer in time. Check `/linkadmin status`. If the last error mentions the gateway, your host may block outgoing connections to `link-gateway.exylia.net`. When the gateway cannot be reached, the plugin tries again every 10 minutes and logs why.

## The state says "Update ExyliaLink" or the secret was revoked

- **Update ExyliaLink**: Exylia Link no longer accepts this plugin version. Update the jar and restart. See [Updates](/docs/exylialink/updates).
- **Secret revoked**: someone revoked the network's secret on the web. Admins online are told, and `/linkadmin connect` links it again.

## Two servers show as one on the dashboard

They share a `server-id`. Give each server and proxy a different one in `config.yml` and run `/linkadmin reload`. ExyliaLib's shipped `server-1` is never reused as a fallback for this reason. See [Configuration](/docs/exylialink/configuration).

## Players are told to link but cannot use some commands

The network's requirements are in restrict mode: the commands the network listed are refused until the player links. `/link` is never blocked. Staff who should be exempt need `exylialink.requirements.bypass`. See [Requirements](/docs/exylialink/requirements).

## No requirement warnings after the gateway went down

By design: while the gateway is unreachable ExyliaLink keeps the last requirements and statuses it knew and blocks nothing.

## "No DiscordSRV links found"

The import looks in three places: DiscordSRV's API when it runs on the same server, then `plugins/DiscordSRV/accounts.aof`, then the SQL table named in DiscordSRV's config. Run it on the game server that has DiscordSRV. It does not run on proxies. See [Import from DiscordSRV](/docs/exylialink/import-discordsrv).

## A reward did not run

A reward that needs the player online is refused and comes back the next time they join. Rewards the plugin already ran are recorded in `grants.log` and are not run twice. Check `/linkadmin status` for rewards in progress, and the console for lines starting with `Reward`. See [Rewards](/docs/exylialink/rewards).

## ExyliaLink did not update itself

- `auto-update` is `false` in `config.yml`: it only tells you.
- The new version is a new major: install it by hand.
- The release is a pre-release, or older than the running version: ignored.
- The new jar is waiting for a restart. On Paper, Spigot and Folia it sits in the server's update folder (`plugins/update/` by default).

See [Updates](/docs/exylialink/updates).
