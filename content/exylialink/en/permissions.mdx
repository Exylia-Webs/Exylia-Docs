Players need no setup: everyone can link and unlink their own account. Use this page to give someone admin access or to exempt a rank from the network's requirements.

## All permissions

<Permissions />

## Give admin access

`exylialink.admin` is op-only by default. Admins also get told on join when a new version is installed or available.

```text
/lp group admin permission set exylialink.admin true
```

On a proxy use the permission plugin of that proxy (LuckPerms for Velocity or BungeeCord).

## Exempt a rank from the requirement

When the network requires a LuckPerms group to have a linked account, players in it are warned, reminded and may have commands blocked. `exylialink.requirements.bypass` skips all of that. Nobody has it by default.

```text
/lp group staff permission set exylialink.requirements.bypass true
```

See [Requirements](/docs/exylialink/requirements) for how the requirements are set.

## Deny linking to someone

`exylialink.link` is `true` for everyone. To stop a group from using `/link` and `/unlink`, set it to `false` for that group. On a proxy only an explicit deny counts.
