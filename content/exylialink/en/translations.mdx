You pick the language of every ExyliaLink message, edit any line, or add a language of your own. ExyliaLink ships English (`en`), Spanish (`es`), French (`fr`), Portuguese (`pt`), Russian (`ru`) and Turkish (`tr`).

## Before you start

Find `plugins/ExyliaLink/lang/` on your server or proxy. Each language is a folder with one `messages.yml`.

## Steps

<Steps>
  <Step title="Choose the language">
    Open `config.yml` and set `language` to `en`, `es`, `fr`, `pt`, `ru` or `tr`.
  </Step>
  <Step title="Reload">
    Run `/linkadmin reload`.
  </Step>
  <Step title="Edit a line">
    Open `lang/<code>/messages.yml`, change the text and reload. The next time it is sent, the new text shows.
  </Step>
</Steps>

## Check that it works

Set `language: es`, reload and run `/link status`: the block reads **VÍNCULO CON DISCORD**.

## Your edits are safe

The bundled language files are copied to the plugin folder once and never overwritten. A key missing from your file is read from the jar, in the same language and then in English, so an update that adds a message works without touching your edits.

## Message format

A key holds one line or a list of lines. An empty line is not sent; `&r` sends a blank one. `%prefix%` inserts the `prefix` key.

| You want | Write |
|---|---|
| A colour | `<#rrggbb>`, an `&` code or a palette name such as `{primary}` |
| A click | `<click:run_command:/link>text</click>`, also `open_url`, `suggest_command` and `copy_to_clipboard` |
| A hover | `<hover:show_text:'text'>…</hover>` |

Lines can start with a block of directives:

- `[sound:entity.experience_orb.pickup|0.6|1.4]` plays a sound (key, volume, pitch) to that player, on game servers.
- `[center]` centres the line.
- Both in one block, separated by `;`: `[sound:block.note_block.pling|0.5|1.2;center]`.

A colour code clears bold and the other styles, as in the game, so `<#8a51c4>&lTITLE` reads as written. A backslash keeps the next character literal.

Palette names are the Exylia colours: `primary`, `secondary`, `secondary_light`, `letters`, `letters_black`, `error`, `success`, `success_light`, `warning`, `warning_light`, `info`, `info_light`, `accent`, `neutral`, `highlight` and `muted`.

<Details title="Add a language">

Copy `lang/en` to `lang/<code>`, translate it and set `language` to that code. A key you leave out falls back to English. Messages for players read the placeholders in each message's comment (for example `%code%`, `%url%`, `%time%` in `link.code`), so keep them.

</Details>
