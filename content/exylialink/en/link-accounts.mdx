Players link their accounts with `/link`, check them with `/link status` and remove the link with `/unlink`. Staff can unlink anyone with `/linkadmin unlink`.

## Before you start

The server or proxy must be [connected](/docs/exylialink/first-steps). While it is not, players get "Discord linking is unavailable right now". Everyone has `exylialink.link` by default.

## Link from the game

<Steps>
  <Step title="Run /link">
    A block titled **LINK YOUR DISCORD** shows a 6-character code and how long it lasts.
  </Step>
  <Step title="Use the code">
    Run `/link <code>` in the network's Discord server, or click the link in the block and enter the code on the network's link page. The page defaults to `https://link.exylia.net` when the network has none of its own.
  </Step>
  <Step title="See the confirmation">
    The game says you are linked to your Discord name.
  </Step>
</Steps>

## Link from Discord

Run `/link` in Discord to get a code, then run `/link <code>` in the game. A valid code links the account at once. A wrong one says "That code is not valid".

## Check the link

`/link status` shows a **DISCORD LINK** block with **Linked** and the Discord name, or **Not linked**.

## Unlink

<Steps>
  <Step title="Run /unlink">
    ExyliaLink asks "Unlink your account from `<Discord name>`?" with an **[✔ UNLINK]** button.
  </Step>
  <Step title="Confirm">
    Click the button, or run `/unlink confirm`, within 30 seconds.
  </Step>
</Steps>

The network can turn unlinking off on the dashboard. Players then read "Unlinking is disabled on this network. Ask a staff member."

## Unlink someone else

Staff with `exylialink.admin` run `/linkadmin unlink <player>`. The unlink is recorded under the staff member's name in Link's activity log; from the console it is recorded as Console.

- On a **game server** the name can be an online player, anyone who has played there, or a UUID.
- On a **proxy** the name must be an online player; a UUID works too.

If the player was not linked, the answer is "`<player>` was not linked".

<Details title="Messages players may see">

| Message | Meaning |
|---|---|
| You are already linked. Run /unlink first. | The account or the UUID is already linked. |
| That Discord account is already linked to another Minecraft account. | One Discord account links to one Minecraft account. |
| You can link again in ... | A cooldown from the network's rules is running. |
| Slow down, try again in ... | Too many requests in a short time. |

</Details>
