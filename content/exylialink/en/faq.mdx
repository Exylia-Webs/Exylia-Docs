## Is ExyliaLink free?

Yes. It is free and open source under GPL-3.0. The source and the releases are on [GitHub](https://github.com/Exylia-Plugins/ExyliaLink/releases).

## What does it do?

It is the Minecraft side of Exylia Link: it links Minecraft accounts to Discord accounts for a whole network, reports who is online (and in which LuckPerms groups), and runs the rewards Link grants. See [Introduction](/docs/exylialink/introduction).

## Which platforms and versions?

One jar for all of them, Java 17 or newer: Paper, Spigot 1.17+ and Folia as game servers, Velocity 3 as a proxy, and BungeeCord or Waterfall as a proxy. See [Introduction](/docs/exylialink/introduction).

## Do I need ExyliaLib?

No. ExyliaLink is standalone so it runs on proxies, on Spigot and on servers older than ExyliaLib supports. If ExyliaLib is installed, ExyliaLink only reads its `database.redis.server-id` to name the server.

## Proxy, game servers or both?

Any of them. When a proxy of the network is connected, it talks to players (link messages, reminders, command blocking) and the game servers stay silent but keep reporting and running rewards. See [Proxies and servers](/docs/exylialink/proxies-and-servers).

## Do I need LuckPerms, PlaceholderAPI or DiscordSRV?

All three are optional. LuckPerms lets Link know players' groups, for requirements and rewards. PlaceholderAPI enables the [placeholders](/docs/exylialink/placeholders). DiscordSRV is only needed to [import its links](/docs/exylialink/import-discordsrv).

## Which languages are included?

English, Spanish, French, Portuguese, Russian and Turkish (`en`, `es`, `fr`, `pt`, `ru`, `tr`). Set `language` in `config.yml`. See [Configuration](/docs/exylialink/configuration) and [Translations](/docs/exylialink/translations).

## Where is the data stored?

Links live on Exylia Link, not on your server. Each install keeps only its network secret in `network.dat` and the reward grants it already ran in `grants.log`. A player's status is cached in memory while they are online.

## Can players unlink themselves?

Yes, with `/unlink`, unless the network disabled it. Staff can use `/linkadmin unlink <player>`.

## Does the plugin update itself?

Yes: it checks GitHub releases shortly after start and every 6 hours, and installs a newer release of the same major version for the next restart. Set `auto-update: false` to only be told. See [Updates](/docs/exylialink/updates).

## Where do I download it?

Download it from the [GitHub releases](https://github.com/Exylia-Plugins/ExyliaLink/releases).

## Does it work on Folia?

Yes. Folia is supported.
