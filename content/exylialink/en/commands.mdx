Every ExyliaLink command with the permission it needs. They work the same on Paper, Spigot, Folia, Velocity and BungeeCord. ExyliaLink has no aliases: the three commands are `/link`, `/unlink` and `/linkadmin`.

<Commands />

## Confirmations

`/unlink` and `/linkadmin disconnect` ask before they act. Click the button in chat, or run the command again with `confirm` within 30 seconds (`/unlink confirm`, `/linkadmin disconnect confirm`). After 30 seconds you have to start again.

## Good to know

- `/link`, `/link <code>`, `/link status` and `/unlink` are for players. Run from the console they answer that only players can do that.
- `/linkadmin disconnect` only forgets the network on the server or proxy where you run it. The others stay connected.
- `/linkadmin unlink <player>` accepts online players, a UUID, or, on game servers, anyone who has played there.
- `/linkadmin import discordsrv` only works on game servers. See [Import from DiscordSRV](/docs/exylialink/import-discordsrv).

<Callout type="note" title="Permissions on proxies">
On a proxy, `exylialink.link` is given to everyone unless your permission plugin denies it explicitly. `exylialink.admin` and `exylialink.requirements.bypass` need a grant (LuckPerms, for example).
</Callout>
