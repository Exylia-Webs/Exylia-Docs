ExyliaLink's `config.yml` is tiny on purpose: what Link does (rewards, requirements, bot, roles) is set on the dashboard at [link.exylia.net](https://link.exylia.net). The file only holds what a server must know before it can reach it. After editing, run `/linkadmin reload`.

The files below live in the plugin's own folder (`plugins/ExyliaLink/` on Paper, Spigot, Folia and BungeeCord; Velocity gives each plugin its own data folder under `plugins/`).

## config.yml

| Key | Default | What it does |
|---|---|---|
| `language` | `en` | Language of the messages. See below. |
| `server-id` | empty, filled on first start | This install's name on the Link dashboard. Keep it stable and different on every server and proxy. |
| `gateway-url` | `https://link-gateway.exylia.net` | Where the plugin connects. Leave it unless Exylia support says otherwise. A blank value falls back to the default. |
| `requirements-reminder-minutes` | `10` | How often a player who must link is reminded. `0` warns only once. Not a number, or below 0, reads as `10` and `0` respectively. |
| `auto-update` | `true` | Install new releases for the next restart. `false` only tells admins and the console. See [Updates](/docs/exylialink/updates). |
| `debug` | `false` | Logs connection retries and other details to the console. |

### server-id

Every server and proxy of the network is known on the dashboard by its `server-id`. Left empty, the first start writes one for you and keeps it across restarts:

1. ExyliaLib's `database.redis.server-id`, when ExyliaLib is installed and it is set to something other than its shipped `server-1`.
2. `proxy` on a proxy.
3. Otherwise a random one such as `server-k3m9ab`.

With more than one proxy, give each its own id. See [Proxies and servers](/docs/exylialink/proxies-and-servers).

## Language

`language` accepts the six bundled languages:

| Value | Language |
|---|---|
| `en` | English |
| `es` | Spanish |
| `fr` | French |
| `pt` | Portuguese |
| `ru` | Russian |
| `tr` | Turkish |

You can also write any other code, for example `de`, after creating `lang/de/messages.yml` yourself. A line missing from your file reads from English. A blank value means `en`.

See [Translations](/docs/exylialink/translations) to translate or edit a language.

## Messages

Every line the plugin says lives in `lang/<code>/messages.yml`. The first start copies all six bundled languages. After that the files are yours: an update never overwrites them, and a key missing from your file reads from the jar's file of the same language, then from English. Open the file for the full list of keys and the placeholders each one takes.

A line can use:

- Colours as `<#rrggbb>`, `&` codes or palette names such as `{primary}`.
- `<click:...>` and `<hover:show_text:'...'>` on every platform.
- A leading `[sound:<key>|<volume>|<pitch>]` (game servers) and `[center]`.
- `%prefix%` for the shared `LINK •` prefix.

If a language file cannot be read, ExyliaLink logs a warning and uses the bundled messages.

## Other files

| File | What it holds |
|---|---|
| `network.dat` | This install's network secret, sealed with AES-GCM and readable only by its owner. Never share it. `/linkadmin disconnect confirm` deletes it. |
| `grants.log` | The reward grants already run on this install, so one is never run twice. |

<Callout type="warning" title="Do not copy network.dat between servers">
Every server and proxy keeps its own secret and gets it with `/linkadmin connect`. Linking one never disconnects the others.
</Callout>

<Details title="Technical details">
`grants.log` records each grant id before the reward is acknowledged, is compacted on start and daily, and entries are kept for 90 days. A line torn by a crash is dropped. Nothing is stored in ExyliaLib's database: ExyliaLink is standalone and does not need ExyliaLib.
</Details>
