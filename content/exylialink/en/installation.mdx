You download one jar, put it in `plugins/`, restart, and ExyliaLink writes its files and waits to be connected to your network.

## Downloading

ExyliaLink is free. Every release is published on [GitHub](https://github.com/Exylia-Plugins/ExyliaLink/releases) with the same jar for every platform: `ExyliaLink-<version>.jar`, and `ExyliaLink.jar`, which keeps the same name on every release. Either file works.

## Before you start

| Plugin | What for |
|---|---|
| `LuckPerms` | Optional, on servers and proxies. Reports each player's groups to the dashboard, which [linked-account requirements](/docs/exylialink/requirements) need. |
| `PlaceholderAPI` | Optional, on game servers. Lets other plugins read the [`%exylialink_...%` placeholders](/docs/exylialink/placeholders). |
| `DiscordSRV` | Optional, on game servers. Only for [importing its links](/docs/exylialink/import-discordsrv). |

You also need a network on [link.exylia.net](https://link.exylia.net). Without one the plugin stays idle and logs "Not connected to Exylia Link"; nothing else breaks.

## Install

<Steps>
  <Step title="Choose where it goes">
    Put the jar on the proxy, on every game server, or on both. Read [Proxies and game servers](/docs/exylialink/proxies-and-servers) if you are unsure.
  </Step>
  <Step title="Drop in the jar">
    Copy it into `plugins/` on each server or proxy. It is the same file everywhere.
  </Step>
  <Step title="Start once">
    The plugin writes `config.yml`, the `lang/` folder and, if `server-id` is empty, a `server-id` of its own.
  </Step>
  <Step title="Connect it">
    Follow [Your first linked account](/docs/exylialink/first-steps) on each server and proxy.
  </Step>
</Steps>

## Generated files

All of them live in `plugins/ExyliaLink/`.

| File | Contents |
|---|---|
| `config.yml` | `language`, `server-id`, `gateway-url`, `requirements-reminder-minutes`, `auto-update`, `debug`. See [Configuration](/docs/exylialink/configuration). |
| `lang/<code>/messages.yml` | Every message, one folder per shipped language. Copied once and never overwritten. See [Translations](/docs/exylialink/translations). |
| `network.dat` | This install's network secret, sealed and readable only by its owner. Never share it. |
| `grants.log` | The reward grants already run here. See [Rewards](/docs/exylialink/rewards). |

Every server and proxy keeps its own `network.dat`. To disconnect one, run `/linkadmin disconnect`: that deletes its file and leaves the others connected.

## Updating

ExyliaLink updates itself from the GitHub releases. See [Updates](/docs/exylialink/updates). To update by hand, replace the jar and restart.
