You connect this server to your network, then run `/link` and see your own account linked. It takes a couple of minutes.

## Before you start

- ExyliaLink is [installed](/docs/exylialink/installation) and the server has started once.
- You own a network on [link.exylia.net](https://link.exylia.net) and can sign in with Discord.
- You have the permission `exylialink.admin` (operators have it by default).

## Steps

<Steps>
  <Step title="Connect the server">
    Run `/linkadmin connect`. The chat shows a code and an approval link, and the code expires after a few minutes.
  </Step>
  <Step title="Approve it on the web">
    Open the link, sign in with Discord, pick your network and approve. The server collects its secret by itself and says **Connected to** your network name.
  </Step>
  <Step title="Check the connection">
    Run `/linkadmin status`. **Connection** should read **Connected** and **Network** should show your network.
  </Step>
  <Step title="Get a code">
    Run `/link`. A block titled **LINK YOUR DISCORD** shows a 6-character code, click it to copy.
  </Step>
  <Step title="Use the code">
    Run `/link <code>` in your Discord server, or type the code on the network's link page.
  </Step>
  <Step title="Confirm in game">
    Within a moment the game says you are linked to your Discord name. Run `/link status` to see it again.
  </Step>
</Steps>

## Check that it works

`/link status` shows **Status » Linked** and your Discord name. The dashboard lists your account as linked. If the status stays on **Connecting…** or the code is refused, see [Common problems](/docs/exylialink/troubleshooting).

## Going further

- **Every server and proxy connects once.** Run `/linkadmin connect` on each of them. Each install keeps its own secret, and connecting one never disconnects the others.
- **Disconnect one.** `/linkadmin disconnect` asks first and deletes only this server's `network.dat`.
- **Unlink yourself.** Run `/unlink` and confirm. See [Link and unlink accounts](/docs/exylialink/link-accounts).
