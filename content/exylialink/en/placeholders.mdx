ExyliaLink adds four placeholders to PlaceholderAPI so other plugins (scoreboards, tab lists, chat formats) can show who a player is on Discord.

## How they work

- They need [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) on the game server. The expansion is built into ExyliaLink: there is nothing to download or `/papi ecloud download`.
- They exist on game servers only, not on Velocity or BungeeCord.
- They read the status ExyliaLink already has in memory for each online player, so they never slow the server. A player who is not online reads as not linked.
- Before the server is connected to Exylia Link (see [Installation](/docs/exylialink/installation)), `%exylialink_linked%` reads `false` and the others are empty.

<Placeholders />

## Example

In any plugin that supports PlaceholderAPI, such as a scoreboard line:

```text
Discord: %exylialink_discord_name%
```

To branch on the state, compare `%exylialink_linked%` with `true` or `false` in the plugin's condition syntax.
