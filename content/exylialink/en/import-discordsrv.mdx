You run one command on the game server that has DiscordSRV, and its links become Exylia Link links.

## Before you start

- The server is [connected](/docs/exylialink/first-steps) to your network.
- You run the command on a **game server**. On a proxy it answers "DiscordSRV runs on game servers: run this on the server that has it."
- You have `exylialink.admin`.

## Steps

<Steps>
  <Step title="Run the import">
    Run `/linkadmin import discordsrv`.
  </Step>
  <Step title="Watch the progress">
    The chat says how many links were found and where from, then shows progress in batches of 1,000: new, skipped and conflicts.
  </Step>
  <Step title="Read the summary">
    A **DISCORDSRV IMPORT DONE** block shows **Links read**, **Imported**, **Already linked** and **Conflicts**.
  </Step>
</Steps>

## Where the links come from

ExyliaLink looks in this order and uses the first that works:

1. DiscordSRV itself, when it runs on this server, whatever storage it uses.
2. `plugins/DiscordSRV/accounts.aof`.
3. The SQL table DiscordSRV's `config.yml` points at, when a JDBC backend is configured.

If none has links, you read "No DiscordSRV links found".

## Check that it works

In game, an imported player's `/link status` shows **Linked**.

## Going further

- **Safe to repeat.** Links that already exist are counted as **Already linked** and skipped. If an import stops, "Running it again is safe."
- **Conflicts.** A pair that clashes with an existing link is not imported. Conflicts are listed on the dashboard and in the console.
- **One at a time.** A second import while one runs says "An import is already running."
