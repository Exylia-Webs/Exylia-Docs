Los jugadores no necesitan configurar nada: todos pueden vincular y desvincular su propia cuenta. Usa esta página para dar acceso de admin o para eximir a un rango de los requisitos de la red.

## Dar acceso de admin

`exylialink.admin` es solo para operadores por defecto. Los admins también reciben un aviso al entrar cuando hay una versión nueva instalada o disponible.

```text
/lp group admin permission set exylialink.admin true
```

En un proxy usa el plugin de permisos de ese proxy (LuckPerms en Velocity o BungeeCord).

## Eximir a un rango del requisito

Cuando la red exige que un grupo de LuckPerms tenga la cuenta vinculada, sus jugadores reciben avisos y recordatorios, y puede que se les bloqueen comandos. `exylialink.requirements.bypass` se salta todo eso. Por defecto no lo tiene nadie.

```text
/lp group staff permission set exylialink.requirements.bypass true
```

Mira [Requisitos](/docs/exylialink/requirements) para saber cómo se configuran.

## Impedir que alguien vincule

`exylialink.link` es `true` para todos. Para que un grupo no pueda usar `/link` ni `/unlink`, ponlo a `false` en ese grupo. En un proxy solo cuenta una denegación explícita.
