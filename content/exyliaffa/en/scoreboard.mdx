The sidebar shows inside an arena: arena name, players, kills, deaths, KDR, streak and the time to the next map regeneration. You change it by editing one file per language.

## Edit the scoreboard

<Steps>
  <Step title="Open the file">
    Edit `plugins/ExyliaFFA/lang/en/scoreboards.yml`, or the folder of the language you use.
  </Step>
  <Step title="Change the lines">
    Edit `title` and `lines`. A line can use the tokens below, colours and any PlaceholderAPI placeholder. Up to 15 lines show.
  </Step>
  <Step title="Reload">
    Run `/ffaadmin reload`. Players see the new sidebar on their next refresh.
  </Step>
</Steps>

## Tokens you can use

| Token | What it shows |
|---|---|
| `%arena%` | Name of the arena the player is in |
| `%players%` | Players inside that arena |
| `%kills%` | The player's kills in that arena |
| `%deaths%` | Their deaths in that arena |
| `%kdr%` | Their KDR |
| `%streak%` | Their current streak |
| `%regen%` | Time until the next regeneration |

With PlaceholderAPI, placeholders from other plugins work too, along with [ExyliaFFA's own](/docs/exyliaffa/placeholders).

## Colours

`{primary}`, `{highlight}`, `{muted}`, `{letters}`, `{success}`, `{error}`, `{info}` and `{warning}` come from ExyliaLib's palette, so editing it recolours every Exylia plugin at once. See [Colours](/docs/exylialib/colours). Legacy codes (`&a`), hex (`<#ff5c8a>`) and MiniMessage gradients also work. `{server-ip}` on the last line is the address set once in ExyliaLib.

## Turn it off, or let players hide it

To remove it for everyone, set `ffa.enabled` to `false` in `scoreboards.yml`. Players cannot switch it back on. To let each player decide, leave it on: they use **Scoreboard** in `/ffa settings`, see [Player settings](/docs/exyliaffa/player-settings).

<Callout type="tip" title="Refresh rate">
The sidebar refreshes every 15 ticks (0.75 s), which suits a countdown. If no line changes every second, raising `update.interval` to `20` or `40` saves work with no visible difference.
</Callout>

<Details title="Technical details">
Structure of `lang/<code>/scoreboards.yml` under `scoreboards.ffa`: `enabled` (true, master switch), `scoreboard.enabled` (true, keeps the section written but off), `title` (list; several titles animate, one per refresh), `lines` (top first, at most 15), `update.interval` (15 ticks, 20 ticks is one second), `update.smart` (true, sends only the lines that changed, and nothing when none did), `update.cache` (true, read and ignored: text caching is always on). A server that already had the file keeps whatever its last line said.
</Details>
