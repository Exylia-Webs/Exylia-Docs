Use these to show live ExyliaFFA data in other plugins that support PlaceholderAPI, such as holograms, tab lists and chat. Click a placeholder to copy it.

<Placeholders />

## Leaderboards

Replace `<stat>` with one of: `kills`, `deaths`, `kdr`, `best_streak`, `assists`, `damage_dealt`, `play_time`, `alive_time`, `kills_per_minute`. Replace `<position>` with a number from 1 up to the leaderboard size (50 by default). Add an arena name at the end to rank only that arena.

```text
%exyliaffa_stats_top_kills_1%                     first by kills, all arenas
%exyliaffa_stats_top_kills_1_nodebuff%            first by kills in "nodebuff"
%exyliaffa_stats_top_value_kills_1_nodebuff%      their kills, instead of their name
%exyliaffa_stats_top_best_streak_3%               third by best streak
```

While a leaderboard is loading the first time it shows `---`. A position past the end of the list, or an unknown arena, shows nothing.

## Show a fallback when empty

Add `|text` before the closing `%` to show that text when there is no answer:

```text
%exyliaffa_stats_top_kills_3|nobody%
```

## Inside the arena scoreboard

The sidebar has its own short names, without the `exyliaffa_` prefix. They are listed in [Edit the scoreboard](/docs/exyliaffa/scoreboard).

<Details title="Technical details">
Arena names with underscores work: `%exyliaffa_arena_players_the_pit%` is read as one arena. The arena name ignores capitals. The leaderboard size is `leaderboard.max-entries` in `config.yml`. A placeholder that shows as raw text usually means PlaceholderAPI is missing, the arena name is misspelled, or the position is above that limit. Outside PlaceholderAPI, the same names work without the prefix inside this plugin's own menus, for example `%total_players%`.
</Details>
