After this page ExyliaFFA is running on your server and `/ffaadmin` opens the admin panel.

## Before you start

You need a Paper server (1.21.1 or newer) or a Folia server (1.21.4 or newer), running Java 21. Put these plugins in `plugins/` before the first start. Without any one of them, the server turns ExyliaFFA off and names the missing plugin in the console.

| Plugin | Why it is needed |
|---|---|
| ExyliaLib | Menus, messages, database and colours. Version 1.448.0 or newer. |
| FastAsyncWorldEdit | Saves and restores the arena map. |
| packetevents | Shows the glow on the player you are fighting. |

These are optional:

- **PlaceholderAPI** lets you use ExyliaFFA placeholders in other plugins.
- **ViaVersion** lets older game versions join.
- **ExyliaPracticeCore**, **ExyliaEvents** and **ExyliaSandBox**: when installed, a player who is queued, in an event or in the sandbox cannot join an FFA arena. PracticeCore kits can also be used in arenas, see [Kits](/docs/exyliaffa/kits#use-practicecore-kits).

## Steps

<Steps>
  <Step title="Add the plugin">
    Copy `ExyliaFFA.jar` into the server's `plugins/` folder, next to the three required plugins.
  </Step>
  <Step title="Start the server">
    The first start creates the settings files and the database.
  </Step>
  <Step title="Check the console">
    You should see ExyliaFFA load without errors. If a plugin is missing, the console says which.
  </Step>
  <Step title="Open the admin panel">
    Make yourself an admin (you need the permission `exyliaffa.admin`, which operators have by default) and run `/ffaadmin`. A menu opens.
  </Step>
</Steps>

## Where things are saved

Everything is in `plugins/ExyliaFFA/`. You rarely need to open it, because the admin panel edits most things for you.

- Arenas, kits, spawns, stats and player settings are saved in the **database**, not in a file. By default that is a small file inside the plugin folder, which is fine for one server.
- To share them between servers or move to MySQL, follow [Set up the database](/docs/exylialib/database-setup).
- Messages, the scoreboard and the menus are in `lang/<language>/`. Change the language and the text with [Messages and languages](/docs/exylialib/messages-and-languages).
- Colours are shared with every Exylia plugin: see [Colours](/docs/exylialib/colours).

## Update the plugin

Replace the jar and restart. Your settings are kept, and the plugin upgrades its own files on the first start.

<Details title="Technical details">
The plugin writes `config.yml`, `killstreaks.yml`, `database.yml` and a `lang/<code>/` folder (`messages.yml`, `scoreboards.yml`, `menus/`) on first start. An unknown key in `config.yml` is reported once as `UNKNOWN_KEY`. English, Spanish, Portuguese, French, Russian and Turkish ship with the plugin. Admin menus are regenerated on every start, so edit the player menus instead of the admin ones; see [Edit menus](/docs/exylialib/edit-menus). Every setting is listed in [Configuration](/docs/exyliaffa/configuration).
</Details>
