## Reset a player's data

`/ffaadmin resetstats` and `/ffaadmin resetlayout` ask you to confirm. In game a confirmation menu opens. From the console, the command only describes what would be deleted until you run it again with `confirm` at the end. Both work on players who are offline.

To wipe more at once (every player, or everything one player has), use ExyliaLib's commands: see [ExyliaLib commands](/docs/exylialib/commands#moving-and-wiping-data).

## What reload does

`/ffaadmin reload` reloads the files: settings, messages, scoreboards, kill streaks and menus. Arenas, kits, spawns and stats are in the database and always up to date, so they need no reload. Changing the database type needs a server restart.

<Details title="Technical details">
Leaving an arena, cancelling a kit edit and resetting your own layout never need a permission, so a player can always back out. `kick` also requires that you invited the player, unless you have `exyliaffa.kick-bypass`. `invite` and `kick` accept a per-arena permission, see [Permissions](/docs/exyliaffa/permissions). The player nodes are also checked on menu buttons, so a player without a permission cannot reach the feature from a menu either.
</Details>
