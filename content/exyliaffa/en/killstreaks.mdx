A kill streak is the number of kills a player gets without dying. ExyliaFFA announces it and can run commands at the numbers you choose, so you can pay a coin bonus at 10 or give a kit for 25.

## Turn streaks on or off, and set when they break

<Steps>
  <Step title="Open the settings">
    Run `/ffaadmin`, click **Settings**, then **Kills**.
  </Step>
  <Step title="Change what you need">
    Click **Kill streaks** to switch them on or off. Click **Reset on death** to decide if dying returns the streak to zero. Click **Shortest announced** and type the shortest streak whose ending is worth announcing (the default is 3).
  </Step>
</Steps>

Shift + right-click a card to put it back to its default. Changes apply at once.

When a streak of that length or more ends, everyone in the arena sees who ended it. The text lives in `lang/<code>/messages.yml` under `kill-streaks.break-message` and accepts `%killer%`, `%player%` and `%streak%`.

## Choose the rewards

The ladder is a file, not a menu. Open `plugins/ExyliaFFA/killstreaks.yml`, edit it, then run `/ffaadmin reload`. Each rung fires when a player reaches exactly that number of kills:

```yaml title="killstreaks.yml"
streaks:
  - streak: 10
    enabled: true
    broadcast: true
    message: "<#ff7a7a>%player%</#ff7a7a> <#b9a5cc>is on</#b9a5cc> <bold>10 kills</bold>"
    commands:
      - "eco give %player% 500"
```

- `streak` is the kill count. `message` is what everyone sees.
- `broadcast: true` tells everyone in the arena, `false` only the player.
- `commands` run from the console, so any command of any plugin works. `%player%` is the player on the streak.
- `enabled: false` switches a rung off without deleting it.

Nine rungs come ready: 3, 5, 7, 10, 15, 20, 25, 35 and 50. Order in the file does not matter, and a rung with a mistake is skipped (the console says which) while the rest keep working.

<Callout type="tip" title="Rewards for every kill">
For a reward on each kill instead of a streak, use **Kill commands** in the same Kills settings page. Details in [Configuration](/docs/exyliaffa/configuration#kill-commands).
</Callout>

## Check that it works

Join an arena, get kills, and type `/ffa streak`. You see your current streak. Reaching a rung shows its message and runs its commands. With the `exyliaffa.commands.streak.others` permission, `/ffa streak <player>` shows someone else's. The number is also the placeholder `%exyliaffa_current_streak%`, see [Placeholders](/docs/exyliaffa/placeholders).

## Players can mute it

Each player can hide their own streak notices and other players' streak announcements from `/ffa settings`, without affecting anyone else. See [Player settings](/docs/exyliaffa/player-settings).

<Details title="Technical details">
`config.yml`: `kill-streaks.enabled` (true), `kill-streaks.reset-on-death` (true), `kill-streaks.break-min-streak` (3). Ladder keys: `streak` (required, greater than zero), `enabled` (true), `broadcast` (true), `message` (empty), `commands` (empty). The ladder sorts itself from lowest to highest. It used to live in `kill-streaks.streaks` of `config.yml`; the first boot of the new version moves it to `killstreaks.yml`. A break message edited in `config.yml` is moved to `messages.yml` too.
</Details>
