Players can use ExyliaFFA without any setup: everything a player does is allowed by default, and only admins get `/ffaadmin`. Use this page to restrict things.

## Restrict an arena, kit or spawn

You can write your own permission on an arena, a kit or a spawn. It does not exist until you type it, and the plugin does not force any prefix.

| Where | Effect |
|---|---|
| **Permission** button in an arena's settings | Only holders can join that arena. |
| **Set permission** on a kit (middle-click it in the kit list) | Only holders can use the kit. In random mode it is left out of their draw. |
| **Set permission** on a spawn (middle-click it in the spawn list) | Only holders can choose that spawn. |

Leave it empty for no restriction. In the arena and kit menus, typing `none` removes it.

Name each permission after what it unlocks, not after the rank. Ranks change, what they unlock does not:

```text
exyliaffa.arena.vip       the VIP arena
exyliaffa.kit.premium     the premium kit
exyliaffa.spawn.tower     the elevated spawn
```

With LuckPerms:

```text
/lp group vip permission set exyliaffa.arena.vip true
/lp group vip permission set exyliaffa.kit.premium true
```

<Callout type="tip" title="Temporary access">
A kill streak reward can run `lp user %player% permission settemp exyliaffa.kit.premium true 10m` to unlock a kit for ten minutes. See [Reward kill streaks](/docs/exyliaffa/killstreaks).
</Callout>

## Make a feature a rank perk

Players hold every player permission by default. To make one a perk, deny it to the default group and grant it to the rank:

```text
/lp group default permission set exyliaffa.commands.kiteditor false
/lp group vip permission set exyliaffa.commands.kiteditor true
```

A player who is refused sees "Your rank cannot do that." You can change that text in [Messages and languages](/docs/exylialib/messages-and-languages).

<Callout type="warning" title="Two permissions to keep for staff">
`exyliaffa.admin` gives the whole panel, including deleting arenas and resetting stats. `exyliaffa.bypass.blocked-commands` lets a player run any command inside an arena, such as `/fly`, which is a combat advantage.
</Callout>
