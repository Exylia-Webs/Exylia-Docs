---
title: "Permissions"
description: "The plugin's own nodes, and the ones you define on arenas, kits and spawns."
---

There are two kinds of permission: the ones the plugin declares, and the ones you write into each
arena, kit or spawn.

## Plugin nodes

Every node below is declared in `plugin.yml`, so permission plugins list and suggest it.

| Permission | Default | Description |
|---|---|---|
| `exyliaffa.admin` | op | `/ffaadmin` and every admin menu and action. |
| `exyliaffa.commands.ffa` | everyone | `/ffa`, the arena selector. |
| `exyliaffa.commands.join` | everyone | Joining an arena, from `/ffa join` or the selector. |
| `exyliaffa.commands.spectate` | everyone | Watching an arena, from `/ffa spectate` or the selector. |
| `exyliaffa.commands.stats` | everyone | `/ffa stats`, own and others', and the leaderboards. |
| `exyliaffa.commands.streak` | everyone | `/ffa streak` |
| `exyliaffa.commands.streak.others` | everyone | `/ffa streak <player>` |
| `exyliaffa.commands.settings` | everyone | `/ffa settings`, opening and changing your settings. |
| `exyliaffa.commands.kiteditor` | everyone | `/ffa kiteditor` and editing a kit's layout from the menus. |
| `exyliaffa.commands.savekit` | everyone | `/ffa savekit` |
| `exyliaffa.commands.invite` | everyone | `/ffa invite` in any arena |
| `exyliaffa.commands.invite.<arenaId>` | not declared | `/ffa invite` in that arena only |
| `exyliaffa.commands.kick` | everyone | `/ffa kick` in any arena |
| `exyliaffa.commands.kick.<arenaId>` | not declared | `/ffa kick` in that arena only |
| `exyliaffa.kick-bypass` | op | Removing players you did not invite |
| `exyliaffa.bypass.blocked-commands` | op | Ignoring the command whitelist inside an arena |
| `exyliaffa.commands.leave` | everyone | Kept for compatibility: leaving an arena is never gated. |
| `exyliaffa.commands.cancelkit` | everyone | Kept for compatibility: cancelling a kit edit is never gated. |
| `exyliaffa.commands.resetkit` | everyone | Kept for compatibility: resetting your own kit layout is never gated. |

The player nodes are checked on the menu buttons as well as on the command, so a player without
`exyliaffa.commands.kiteditor` cannot reach the editor from a menu either. A
refused button answers "Your rank cannot do that." (`ffa.feature-locked` in `messages.yml`).

<Callout type="note" title="The per-arena nodes">
`invite` and `kick` accept an arena identifier as a suffix. Give the general node to administration
and the per-arena node to whoever should only manage their own: deny the plain node, grant the arena.
</Callout>

## Permissions you define

These do not exist until you write them. The plugin imposes no prefix: the node is literally the text
you put in the field.

| Where it is written | Effect |
|---|---|
| An arena's `permission` field | Only holders may join that arena. |
| A kit's `permission` field | Only holders may use that kit. In `RANDOM` mode it is left out of their draw. |
| A spawn's `permission` field | Only holders may choose that spawn. |

Leaving the field empty means "no restriction", which is the default in all three cases.

## A scheme that works

Name the nodes after what they grant, not after the rank receiving them. Ranks change; contents do
not.

```text
exyliaffa.arena.vip          the "vip" arena
exyliaffa.arena.events       the events arena, enabled only when it runs
exyliaffa.kit.premium        the premium kit in any arena
exyliaffa.spawn.tower        the elevated spawn of the main arena
```

With LuckPerms:

```text
/lp group vip permission set exyliaffa.arena.vip true
/lp group vip permission set exyliaffa.kit.premium true
```

<Callout type="tip" title="Temporary permissions">
A time-limited kit permission makes an excellent streak reward:

```yaml
commands:
  - "lp user %player% permission settemp exyliaffa.kit.premium true 10m"
```
</Callout>

## Turning a feature into a rank perk

Every player node is held by everyone by default, so nothing needs granting for the plugin to work.
To make one a perk, deny it to the default group and grant it to the rank:

```text
/lp group default permission set exyliaffa.commands.kiteditor false
/lp group vip permission set exyliaffa.commands.kiteditor true
```

Leaving an arena, cancelling a kit edit and resetting your own layout never need a node, so a player
can always get out of something they started.

<Callout type="warning" title="exyliaffa.bypass.blocked-commands">
It lets a player run any command inside an arena, skipping the whitelist. On a server with `/fly` or
`/heal` that is effectively a combat advantage: give it to staff only.
</Callout>

<Callout type="warning" title="exyliaffa.admin">
It grants the entire panel, deleting arenas, editing the settings and resetting statistics included. Give it to actual
administration, not to moderation.
</Callout>
