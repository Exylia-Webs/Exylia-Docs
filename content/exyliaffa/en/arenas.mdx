An arena is one place to fight, with its own area, kits, spawns, rules and limits. You can have as many as you like. This page covers creating one and every setting in its menu. For a first walk-through, see [Your first arena](/docs/exyliaffa/first-steps).

## Create an arena

<Steps>
  <Step title="Open the arena list">
    Run `/ffaadmin` and click **Arenas**.
  </Step>
  <Step title="Create it">
    Click **Create arena**. Type an id in chat (letters, numbers, `-` and `_`, no spaces, for example `nodebuff`), then the name players will see. The id cannot be changed later and is what you type in `/ffa join nodebuff`.
  </Step>
  <Step title="Fill it in">
    The arena's settings menu opens. Set the area, add spawns and kits, then click **Toggle arena**. See the steps in [Your first arena](/docs/exyliaffa/first-steps).
  </Step>
</Steps>

To change an arena later, open `/ffaadmin`, **Arenas**, and left-click it. Right-click an arena to delete it, after a confirmation.

## What each button does

| Button | What it does |
|---|---|
| **Name** and **Icon** | What players see in the arena list. |
| **Max players** | How many can fight at once. Left-click adds 5, right-click removes 5, Shift-click lets you type a number. New arenas start at 50. |
| **Kit mode** | Players choose their kit, or get a random one. See [Kits](/docs/exyliaffa/kits). |
| **Spawn mode** | Players choose where to appear, or the game picks the emptiest spawn. See [Spawns](/docs/exyliaffa/spawns). |
| **Reset kit after kill** | A kill refills the killer's kit. |
| **Manage kits**, **Manage spawns** | Open their lists. |
| **Set bounds** | Marks the fighting area and saves the map. |
| **Schematic** | Left-click saves the map again, right-click restores it. |
| **Regeneration time** | How often the map is restored, such as `5m`. `0s` is off. See [Regeneration](/docs/exyliaffa/regeneration). |
| **Rules** | Building, fall damage, cooldowns and more. See [Rules](/docs/exyliaffa/rules). |
| **Priority** | Arenas with a higher number show first. |
| **Save inventory on leave** | Players get back the items they had before joining. |
| **Permission** | Only players with this permission can join. |
| **Toggle arena** | Turns it on or off. A switched-off arena cannot be joined or watched. |
| **Expel all players** | Sends everyone back to the lobby, after a confirmation. |
| **Force regenerate** | Restores the map now. |

## Make an arena for VIPs

Click **Permission** and type a permission such as `exyliaffa.arena.vip`. Only players with it can join. The arena still shows in the list. Give the permission to the rank in your permissions plugin, see [Permissions](/docs/exyliaffa/permissions#restrict-an-arena-kit-or-spawn). Type `none` to remove the restriction.

## Protect players when they appear

Set **Protected radius** to a number of blocks around each spawn where fighting is not allowed. 3 to 5 is enough. A large radius turns the spawn into a shelter. `0` is off.

Two buttons change how the radius is measured:

- **Protected shape**: a sphere, or a box. A box suits a square spawn platform.
- **Protected mode**: normal, or the full height from floor to sky. Full height stops players standing above the spawn to hit whoever appears.

## Turn an arena off

Click **Toggle arena** to switch it off. Everyone inside returns to the lobby. Your settings, kits and spawns are kept, and you can switch it on again. To remove the arena for good, delete it from the arena list.

<Details title="Technical details">
Arenas are rows in the database. An arena that is enabled and has an area becomes a live session when the server starts, and the session holds the players, the spectators, the regeneration timer and the scoreboard. The area is drawn as a world border that only that arena's players see; `world-border.enabled` in `config.yml` turns the drawing off. Protected mode values are `NORMAL` and `EXPANDED_VERT`, shape values are `SPHERE` and `CUBOID`. Defaults: max players 50, icon diamond sword, protected radius 0, priority 0, regeneration off, disabled.
</Details>
