ExyliaFFA counts nine numbers per player and per arena. Players see them in a menu, you can show them on holograms and scoreboards, and you can reset them when a season ends.

## See stats and the leaderboard

<Steps>
  <Step title="Open the menu">
    Run `/ffa stats`. There is one card per arena with your numbers in it. `/ffa stats <player>` shows someone else's.
  </Step>
  <Step title="Open a leaderboard">
    Click an arena card. The leaderboard opens, and the **Sort** buttons re-rank it by any of the nine counters.
  </Step>
</Steps>

Stats are kept per arena, so a player has a separate row in each arena they played. Leaderboard placeholders can read one arena or all of them together.

## What is counted

| Counter | Meaning |
|---|---|
| Kills, deaths | Totals. |
| KDR | Kills divided by deaths. A player with no deaths shows their kills, so it still sorts. |
| Best streak | The longest kill streak, see [Reward kill streaks](/docs/exyliaffa/killstreaks). |
| Assists | Damage to a victim in the last 10 seconds before they died, without landing the final blow. Several players can get one for the same death. |
| Damage dealt | All damage in the session, including hits that did not kill. It separates fighters from kill collectors. |
| Play time | Time spent in the arena. |
| Alive time | Time spent alive. |
| Kills per minute | Kills divided by alive minutes, so being dead or spectating does not lower it. |

Kills refused by [anti-farmkill](/docs/exyliaffa/combat) are not counted.

## Show rankings on a hologram or scoreboard

Rankings are PlaceholderAPI placeholders. The size is set by **Leaderboard size** (default 50): in `/ffaadmin`, click **Settings**, then **Arena**. A placeholder beyond that position shows nothing.

```text
%exyliaffa_stats_top_kills_1%              first by kills, in every arena together
%exyliaffa_stats_top_kills_1_nodebuff%     first by kills in the arena "nodebuff"
%exyliaffa_stats_top_value_kills_1%        their kill count instead of their name
```

The full list is in [Placeholders](/docs/exyliaffa/placeholders).

## Reset stats

<Steps>
  <Step title="One player, one arena">
    Run `/ffaadmin`, click **Data management**, then **Player**, pick the player, click **Reset stats** and choose the arena. You are asked to confirm. The command form is `/ffaadmin resetstats <player> <arena>`.
  </Step>
  <Step title="One player, everywhere">
    Run `/exylialib resetplayer <player> ExyliaFFA`. It also clears their kit layouts.
  </Step>
  <Step title="Everyone (new season)">
    Run `/exylialib wipe ExyliaFFA ffa_player_stats`.
  </Step>
</Steps>

The two ExyliaLib commands ask for a typed code and save a dump before deleting. See [ExyliaLib commands](/docs/exylialib/commands#moving-and-wiping-data).

<Callout type="warning" title="There is no undo">
A wipe deletes every player's stats. Back up the database before doing it on a live server.
</Callout>

<Details title="Technical details">
Identifiers (used by placeholders and as sort columns): `kills`, `deaths`, `kdr`, `best_streak`, `assists`, `damage_dealt`, `play_time`, `alive_time`, `kills_per_minute`. Formats: integers, KDR and kills per minute with two decimals, damage with one, times as `1h 5m 3s`. Decimals always use a point, whatever the server locale, so scoreboards and comparisons that read them do not break. Formulas: `kdr = deaths == 0 ? kills : kills / deaths`; `kills_per_minute = alive_minutes <= 0 ? 0 : kills / alive_minutes`. Both are stored, not computed on read, because the database sorts the leaderboards. Config: `leaderboard.max-entries` (50) in `config.yml`.
</Details>
