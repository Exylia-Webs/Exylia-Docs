For setup and error problems start with [Common problems](/docs/exyliaffa/troubleshooting). These are the quick answers.

## Players and kills

### Why are kills not counting?
Most likely [anti-farmkill](/docs/exyliaffa/combat). By default it ignores more than 3 kills on the same victim within 2 minutes, and any kill between two players on the same IP. Change it in `/ffaadmin`, **Settings**, **Fair play**.

### The kit does not refill after a kill
Refilling is an arena setting, not a kit one. Open the arena in `/ffaadmin` and turn on **Reset kit after kill**. See [Create a kit](/docs/exyliaffa/kits).

### A player says the scoreboard does not show
They may have it off in `/ffa settings`. If nobody sees it, check `ffa.enabled` in `scoreboards.yml`: when it is `false` the sidebar is off for everyone and no player can switch it on. See [Customise the scoreboard](/docs/exyliaffa/scoreboard).

### How do I reset every player's stats?
Run `/exylialib wipe ExyliaFFA ffa_player_stats`. For one player run `/exylialib resetplayer <player> ExyliaFFA`. See [Statistics](/docs/exyliaffa/stats#reset-stats).

## Arenas and messages

### The arena does not show in `/ffa`
It shows once it is enabled. To be playable it also needs an area, at least one spawn and at least one kit. The arena's settings flag what is missing.

### Players appear and are thrown out of the arena
The spawn is outside the area. Stand inside the marked zone and create the spawn again. See [Add spawns](/docs/exyliaffa/spawns).

### The arena does not regenerate
The regeneration time must be above 0 and the arena needs a saved schematic. Without one the timer runs and nothing is restored. See [Regenerate the map](/docs/exyliaffa/regeneration).

### A placeholder shows as text on screen
In order of likelihood: PlaceholderAPI is not installed, the arena id is misspelled, or the position is above the leaderboard size (default 50). See [Placeholders](/docs/exyliaffa/placeholders).

### `%players%` stopped working in my scoreboards
That was fixed in 1.0.6: the plugin registered a global name so generic it swallowed every `%players%`. The arena count is now `%exyliaffa_arena_players_<arena>%` and `scoreboards.yml` is rewritten on update. Other plugins' `%players%` lines work again.

### My messages show `%prefix%` as text
It happens when a message does not go through the plugin's prefix. Every text in `messages.yml` does. After editing the prefix run `/ffaadmin reload`.

## Server

### The plugin does not start
Read the console. If ExyliaLib, FastAsyncWorldEdit or packetevents is missing, ExyliaFFA disables itself and names it. All three are required, see [Installation](/docs/exyliaffa/installation).

### Does it work on Folia?
Yes, on Folia 1.21.4 or newer (Paper from 1.21.1).

### Can I share arenas between servers?
Yes. Point every server's `database.yml` at the same MySQL, MariaDB or PostgreSQL. Arenas, kits, spawns, stats and settings are shared. Saved schematics stay on each server's disk.

### I changed `database.yml` and nothing happened
The database is opened at startup. Restart the server; `/ffaadmin reload` does not replace it. See [Database setup](/docs/exylialib/database-setup).

### Where do I get support?
On the [Exylia Discord](https://discord.exylia.net). Licences are handled there too.
