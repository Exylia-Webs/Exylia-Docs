Los jugadores pueden usar ExyliaFFA sin configurar nada: todo lo que hace un jugador está permitido por defecto y solo los admins tienen `/ffaadmin`. Usa esta página para limitar cosas.

## Limitar una arena, un kit o un spawn

Puedes escribir tu propio permiso en una arena, un kit o un spawn. No existe hasta que lo escribes y el plugin no impone ningún prefijo.

| Dónde | Efecto |
|---|---|
| Botón **Permiso** en los ajustes de la arena | Solo quien lo tenga puede entrar en esa arena. |
| El **Permiso** de un kit (clic central sobre él en la lista de kits) | Solo quien lo tenga puede usar el kit. En modo aleatorio queda fuera de su sorteo. |
| El **Permiso** de un spawn (clic central en la lista de spawns) | Solo quien lo tenga puede elegir ese spawn. |

Déjalo vacío para no limitar nada. En los menús de arena y de kit, escribir `none` lo quita.

Pon a cada permiso el nombre de lo que desbloquea, no del rango. Los rangos cambian, lo que desbloquean no:

```text
exyliaffa.arena.vip       la arena VIP
exyliaffa.kit.premium     el kit premium
exyliaffa.spawn.tower     el spawn elevado
```

Con LuckPerms:

```text
/lp group vip permission set exyliaffa.arena.vip true
/lp group vip permission set exyliaffa.kit.premium true
```

<Callout type="tip" title="Acceso temporal">
La recompensa de una racha puede ejecutar `lp user %player% permission settemp exyliaffa.kit.premium true 10m` para desbloquear un kit diez minutos. Mira [Premia las rachas de kills](/docs/exyliaffa/killstreaks).
</Callout>

## Convertir una función en ventaja de rango

Los jugadores tienen por defecto todos los permisos de jugador. Para hacer de uno una ventaja, niégalo al grupo por defecto y dáselo al rango:

```text
/lp group default permission set exyliaffa.commands.kiteditor false
/lp group vip permission set exyliaffa.commands.kiteditor true
```

Al jugador al que se le niega le sale "Your rank cannot do that." (su equivalente en tu idioma). Puedes cambiar ese texto en [Mensajes e idiomas](/docs/exylialib/mensajes-e-idiomas).

<Callout type="warning" title="Dos permisos solo para el staff">
`exyliaffa.admin` da todo el panel, incluido borrar arenas y reiniciar estadísticas. `exyliaffa.bypass.blocked-commands` deja ejecutar cualquier comando dentro de una arena, como `/fly`, y eso es una ventaja en combate.
</Callout>
