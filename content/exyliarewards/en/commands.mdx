title: "Commands"

---

Each module registers its commands only while it runs; a command of a module switched off answers that the
module is off on this server. Commands whose description says "opens" run for players only.

## Rewards

| Command | Permission | What it does |
|---|---|---|
| `/rewards` | `exyliarewards.use` | Opens the rewards hub. |
| `/rewards claim <id>` | `exyliarewards.use` | Claims a reward. With `exyliarewards.bypass`, ignores its wait and its claim limit. A calendar claims the day due today. |
| `/rewards preview <id>` | `exyliarewards.use` | Opens what a reward gives. |
| `/rewards freeze` | `exyliarewards.use` | Shows how many streak freezes you hold, and the price of one. |
| `/rewards freeze buy [amount]` | `exyliarewards.use` | Buys freezes, `1` to `100`, default `1`, at `streak-freezes.price`. Stops at `streak-freezes.max`. |
| `/playtime` | `exyliarewards.use` | Opens your playtime rewards. |
| `/playtime <player>` | `exyliarewards.use` and `exyliarewards.admin` | Says how long a player has played. Without the admin node it opens your own playtime rewards. Runs from the console. |
| `/redeem <code>` | `exyliarewards.redeem` | Redeems a code. See [Redeem codes](/docs/exyliarewards/codes). |

`/rewardsadmin`, also `/playtimeadmin` and `/pta`, needs `exyliarewards.admin`.

| Command | Console | What it does |
|---|---|---|
| `/rewardsadmin` | | Opens the reward editor. |
| `/rewardsadmin give <player> <id>` | yes | Gives an online player a reward now, ignoring its wait, its claim limit and one per address. Its requirements still apply. |
| `/rewardsadmin reset <player> <id>` | yes | Forgets one player's claims, wait and streak for one reward. |
| `/rewardsadmin resetall <player> [confirm]` | yes | The same for every reward. Without `confirm` it asks you to run it again with it. |
| `/rewardsadmin presets` | yes | Adds the [preset rewards](/docs/exyliarewards/installation#the-preset-rewards) whose IDs are free. One already there, edited or not, is left alone. |
| `/rewardsadmin stats` | yes | Works out and prints every reward's claims, claims this week, players, active streaks and best streak. |
| `/rewardsadmin freeze give <player> <amount>` | yes | Gives a player `1` to `1000` streak freezes, online or not. |
| `/rewardsadmin codes` | | Opens the redeem codes screen. |
| `/rewardsadmin reload` | yes | Reloads `config.yml`, `messages.yml`, `discord.yml`, `votes.yml`, `referrals.yml` and the menus. Switching a module on or off needs a restart. |

## AFK zones

| Command | Permission | What it does |
|---|---|---|
| `/afkzone` | `exyliarewards.afkzones.use` | Opens the AFK zones of this server. |
| `/afkzone preview <zone>` | `exyliarewards.afkzones.use` | Opens a zone's tiers. |
| `/afkzonesadmin` | `exyliarewards.afkzones.admin` | Opens the zone editor. |

## Votes

| Command | Permission | Console | What it does |
|---|---|---|---|
| `/vote`, `/votes` | `exyliarewards.votes.use` | | Opens the vote sites and your votes. |
| `/voteadmin`, `/votea` | `exyliarewards.votes.admin` | | Opens the vote party editor. |
| `/voteadmin fake <player> [service]` | `exyliarewards.votes.admin` | yes | Sends a test vote for that name, from `service` (default `Test`), down the whole path: rewards, streak and party. |
| `/voteadmin party` | `exyliarewards.votes.admin` | yes | Starts the vote party being filled now, whatever its count. |
| `/voteadmin pinata [id]` | `exyliarewards.votes.admin` | yes | Sends a piñata now: the one named, or one by weight, to one of this server's spawn points, or where you stand. |
| `/voteadmin pinata stop` | `exyliarewards.votes.admin` | yes | Takes every piñata on this server away, paying nothing. |

## Referrals

| Command | Permission | Console | What it does |
|---|---|---|---|
| `/referral`, `/ref`, `/referrals` | `exyliarewards.referrals.use` | | Shows who invited you and who you brought. |
| `/referral <player>` | `exyliarewards.referrals.use` | | Names who invited you. |
| `/referraladmin reset <player> [confirm]`, `/refadmin reset` | `exyliarewards.referrals.admin` | yes | Forgets who a player named, while nobody was paid for it. Without `confirm` it asks you to run it again with it. |

## Menu actions

For a server's own menus and NPCs, under the namespace `exyliarewards`:

| Action | What it does |
|---|---|
| `exyliarewards:open_hub` | Opens the rewards hub. |
| `exyliarewards:open_category <periodic\|playtime\|calendar>` | Opens one list of rewards. |
| `exyliarewards:claim <id>` | Claims a reward, as `/rewards claim`; a calendar opens its grid. |
| `exyliarewards:preview <id>` | Opens a reward's contents. |
| `exyliarewards:open_calendar <id>` | Opens a calendar's grid. |
| `exyliarewards:calendar_claim <id> <day>` | Claims one day of a calendar, or catches it up. |
| `exyliarewards:open_afk` | Opens the AFK zones. |
| `exyliarewards:afk_preview <zone>` | Opens a zone's tiers. Needs `exyliarewards.afkzones.use`. |
| `exyliarewards:open_votes` | Opens `/vote`. |
| `exyliarewards:votes_link <site>` | Sends a vote site's link. Needs `exyliarewards.votes.use`. |
| `exyliarewards:open_referrals` | Shows the `/referral` summary. |

The actions of the admin editors check the admin node of their module, so copying a button into a screen
players can open hands them nothing.
