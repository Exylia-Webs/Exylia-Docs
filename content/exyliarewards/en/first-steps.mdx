You will create a daily reward called `welcome-gift`, open `/rewards` as a player and claim it. Everything happens in game, in menus.

## Before you start

- ExyliaRewards is installed and the console ended with `ExyliaRewards enabled`. See [Installation](/docs/exyliarewards/installation).
- You are an operator, or you hold `exyliarewards.admin`. See [Permissions](/docs/exyliarewards/permissions).
- A fresh install already writes seven preset rewards, so `/rewards` is not empty. You will add one of your own next to them.

## Steps

<Steps>
  <Step title="Open the reward editor">
    Run `/rewardsadmin`. It lists every reward on the server. Click **Rewards ▸ Create reward**.
  </Step>
  <Step title="Choose when it can be claimed">
    The first question is "When can it be claimed?". Pick **Daily**: once a day, from the reset hour. The other choices are Weekly, Monthly, Cooldown, Once, Playtime, Condition and Calendar. See [Rewards](/docs/exyliarewards/rewards).
  </Step>
  <Step title="Name it">
    Type the ID `welcome-gift`: lowercase, no spaces. Players never see it. Then type the display name, for example `Welcome gift`, and confirm the summary.
  </Step>
  <Step title="Pick an icon">
    Choose the item that represents the reward in menus, for example a chest.
  </Step>
  <Step title="Add what it gives">
    The contents editor opens. Click add and choose **What does it give?**: an item, money, commands, experience or a potion. For a first test, add a diamond or two. Money needs an economy plugin; see [Installation](/docs/exyliarewards/installation). Save when you are done.
  </Step>
  <Step title="Check the overview">
    The reward screen shows a card for each part: Status, General, When, Requirements, Rewards, Options, Stats and Player view. A new reward starts enabled, with unlimited claims. Nothing else is required.
  </Step>
</Steps>

## Check that it works

<Steps>
  <Step title="Open the hub as a player">
    Run `/rewards`. Click **Rewards ▸ Periodic rewards**. Your `Welcome gift` is drawn as ready.
  </Step>
  <Step title="Claim it">
    Left-click it. What you added lands in your inventory and the reward turns to used, with a countdown to the next reset. Right-click shows what it gives without claiming.
  </Step>
  <Step title="Test again">
    As an admin, run `/rewardsadmin reset <your name> welcome-gift` to forget your claim and claim again. Or run `/rewardsadmin give <your name> welcome-gift` to be paid at once.
  </Step>
</Steps>

If a player sees nothing, the reward may be disabled, locked behind a permission, or still loading. See [Common problems](/docs/exyliarewards/troubleshooting).

## Going further

- **Make it a streak.** Open the reward, then **Options**, and set a streak cycle: a bonus on day 7, for example. See [Rewards](/docs/exyliarewards/rewards#streak-freezes).
- **Make it a rank perk.** In **Requirements** set a permission and give it only to VIP with your permissions plugin.
- **Show it on a scoreboard.** `%exyliarewards_welcome-gift_cooldown%` shows the time left. See [Placeholders](/docs/exyliarewards/placeholders).
