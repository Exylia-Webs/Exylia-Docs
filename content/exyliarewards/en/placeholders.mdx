---
title: "Placeholders"
description: "Every placeholder the plugin answers: rewards, playtime, AFK zones, votes, the vote party, piñatas and referrals."
---

The plugin registers its placeholders through ExyliaLib, so the name is the same inside Exylia plugins'
own files and through **PlaceholderAPI**: `%exyliarewards_ready%`. Nothing has to be downloaded from the
eCloud. Every value is read from memory. Each group is registered while its module runs, and the viewer's
own numbers read as zero or none until their data is read on join.

## Rewards

| Placeholder | Value |
|---|---|
| `%exyliarewards_ready%` | Rewards the viewer can claim right now. |
| `%exyliarewards_freezes%` | Streak freezes the viewer holds. |
| `%exyliarewards_playtime%` | The viewer's playtime, formatted. |
| `%exyliarewards_playtime_hours%` | The same, in whole hours. |
| `%exyliarewards_<id>_state%` | That reward for the viewer: `ready`, `waiting`, `used`, `locked` or `disabled`. |
| `%exyliarewards_<id>_cooldown%` | Time until it can be claimed, or the **Ready** label. |
| `%exyliarewards_<id>_streak%` | The viewer's streak on it, `0` once the run can no longer continue. |
| `%exyliarewards_<id>_best_streak%` | Their best streak on it. |
| `%exyliarewards_<id>_claims%` | Claims they have **left**, or the **Unlimited** label. |

`<id>` is a reward's ID and may hold underscores: `%exyliarewards_vip_daily_cooldown%` works. An ID that
names no reward answers the **None** label.

<Callout type="warning" title="IDs that start like another placeholder">
The longest placeholder name that matches wins. A reward whose ID starts with another name of this group
followed by `_` — `playtime`, `ready`, `freezes`, or `afk_`, `votes_` and `referrals_` names — is answered by
that placeholder instead. The preset playtime rewards (`playtime_1h` and the rest) are in that case: give a
reward an ID such as `pt_1h` if you need its per-reward placeholders.
</Callout>

## Playtime

Kept under the bare `playtime` name, the spelling boards and menus on a survival server already use.

| Placeholder | Value |
|---|---|
| `%playtime%` | The viewer's playtime, formatted. |
| `%playtime_seconds%`, `%playtime_millis%`, `%playtime_hours%` | The same in seconds, milliseconds or whole hours. |
| `%playtime_rewards_claimed%` | Playtime reward claims they made. |
| `%playtime_next_reward%` | The name of the playtime reward they will reach first, or the **All claimed** label. |
| `%playtime_next_reward_remaining%` | Playtime until it, the **Ready** label, or `—`. |

## AFK zones

| Placeholder | Value |
|---|---|
| `%exyliarewards_afk_in_zone%` | Whether the viewer is in a zone: `true` or `false`. |
| `%exyliarewards_afk_zones%` | AFK zones on this server. |
| `%exyliarewards_afk_zone%` | The name of the zone they are in, or **Not in a zone**. |
| `%exyliarewards_afk_zone_id%` | Its ID, or empty. |
| `%exyliarewards_afk_tier%` | The tier they are on. |
| `%exyliarewards_afk_session%` | How long they have been in the zone. |
| `%exyliarewards_afk_next_reward%` | Time to the next payout. |
| `%exyliarewards_afk_time%` | Their paid AFK time, network-wide. |
| `%exyliarewards_afk_top_<n>_name%` | Name at place `<n>` of the AFK top, `1` to `10`; **None** past the end. |
| `%exyliarewards_afk_top_<n>_value%` | Their paid AFK time; `—` past the end. |

## Votes

| Placeholder | Value |
|---|---|
| `%exyliarewards_votes_total%` | Votes the viewer has cast. |
| `%exyliarewards_votes_streak%` | Their vote streak, `0` once a day passed without a vote. |
| `%exyliarewards_votes_best_streak%` | Their best vote streak. |
| `%exyliarewards_votes_voted_today%` | The **Yes** or **Not yet** label. |
| `%exyliarewards_votes_party_count%` | Votes towards the vote party being filled. |
| `%exyliarewards_votes_party_target%` | The party's target. |
| `%exyliarewards_votes_party_left%` | Votes it still needs. |
| `%exyliarewards_votes_pinata_active%` | Whether a piñata stands on this server: the **Out now** or **None** label. |
| `%exyliarewards_votes_pinata_hits_left%` | Hits left on this server's piñata, `0` with none. |

## Referrals

| Placeholder | Value |
|---|---|
| `%exyliarewards_referrals_count%` | Players the viewer brought who settled in. |
| `%exyliarewards_referrals_inviter%` | Who invited them, or **Nobody**. |
| `%exyliarewards_referrals_next%` | Their next referral milestone, or **None left**. |

The labels (**Ready**, **None**, **Unlimited**, **Yes**, …) are in `messages.yml`, so they follow your language and
palette.

## Examples

```text
%exyliarewards_daily_streak%
%exyliarewards_daily_cooldown%
%playtime_next_reward_remaining%
%exyliarewards_afk_top_1_name%
%exyliarewards_votes_party_left%
```
