---
title: "Placeholders"
description: "Cada placeholder que responde el plugin: recompensas, tiempo de juego, zonas AFK, votos, la fiesta de votos, piñatas y referidos."
---

El plugin registra sus placeholders a través de ExyliaLib, así que el nombre es el mismo dentro de los
archivos de los plugins de Exylia y a través de **PlaceholderAPI**: `%exyliarewards_ready%`. No hay que
descargar nada del eCloud. Cada valor se lee de memoria. Cada grupo se registra mientras su módulo funciona,
y los números propios de quien mira valen cero o ninguno hasta que sus datos se leen al entrar.

## Recompensas

| Placeholder | Valor |
|---|---|
| `%exyliarewards_ready%` | Recompensas que quien mira puede reclamar ahora mismo. |
| `%exyliarewards_freezes%` | Congelaciones de racha que tiene. |
| `%exyliarewards_playtime%` | Su tiempo de juego, con formato. |
| `%exyliarewards_playtime_hours%` | Lo mismo, en horas enteras. |
| `%exyliarewards_<id>_state%` | Esa recompensa para quien mira: `ready`, `waiting`, `used`, `locked` o `disabled`. |
| `%exyliarewards_<id>_cooldown%` | Tiempo hasta que se pueda reclamar, o la etiqueta **Lista**. |
| `%exyliarewards_<id>_streak%` | Su racha en ella, `0` cuando ya no puede continuar. |
| `%exyliarewards_<id>_best_streak%` | Su mejor racha en ella. |
| `%exyliarewards_<id>_claims%` | Reclamos que le **quedan**, o la etiqueta **Ilimitado**. |

`<id>` es el ID de una recompensa y puede tener guiones bajos: `%exyliarewards_vip_daily_cooldown%`
funciona. Un ID que no nombra ninguna recompensa responde la etiqueta **Ninguno**.

<Callout type="warning" title="IDs que empiezan como otro placeholder">
Gana el nombre de placeholder más largo que coincida. Una recompensa cuyo ID empieza por otro nombre de este
grupo seguido de `_` — `playtime`, `ready`, `freezes`, o nombres `afk_`, `votes_` y `referrals_` — la
responde ese placeholder. Las recompensas predefinidas de tiempo de juego (`playtime_1h` y las demás) están
en ese caso: dale a una recompensa un ID como `pt_1h` si necesitas sus placeholders por recompensa.
</Callout>

## Tiempo de juego

Con el nombre `playtime` a secas, la forma que ya usan los marcadores y menús de un servidor survival.

| Placeholder | Valor |
|---|---|
| `%playtime%` | El tiempo de juego de quien mira, con formato. |
| `%playtime_seconds%`, `%playtime_millis%`, `%playtime_hours%` | Lo mismo en segundos, milisegundos u horas enteras. |
| `%playtime_rewards_claimed%` | Reclamos de recompensas de tiempo de juego que ha hecho. |
| `%playtime_next_reward%` | El nombre de la recompensa de tiempo de juego que alcanzará primero, o la etiqueta **Todo reclamado**. |
| `%playtime_next_reward_remaining%` | Tiempo de juego hasta ella, la etiqueta **Lista**, o `—`. |

## Zonas AFK

| Placeholder | Valor |
|---|---|
| `%exyliarewards_afk_in_zone%` | Si quien mira está en una zona: `true` o `false`. |
| `%exyliarewards_afk_zones%` | Zonas AFK de este servidor. |
| `%exyliarewards_afk_zone%` | El nombre de la zona en la que está, o **Fuera de una zona**. |
| `%exyliarewards_afk_zone_id%` | Su ID, o vacío. |
| `%exyliarewards_afk_tier%` | El nivel en el que está. |
| `%exyliarewards_afk_session%` | Cuánto lleva en la zona. |
| `%exyliarewards_afk_next_reward%` | Tiempo hasta el siguiente pago. |
| `%exyliarewards_afk_time%` | Su tiempo AFK pagado, en toda la red. |
| `%exyliarewards_afk_top_<n>_name%` | Nombre en el puesto `<n>` del top AFK, de `1` a `10`; **Ninguno** pasado el final. |
| `%exyliarewards_afk_top_<n>_value%` | Su tiempo AFK pagado; `—` pasado el final. |

## Votos

| Placeholder | Valor |
|---|---|
| `%exyliarewards_votes_total%` | Votos que ha emitido quien mira. |
| `%exyliarewards_votes_streak%` | Su racha de votos, `0` cuando ha pasado un día sin votar. |
| `%exyliarewards_votes_best_streak%` | Su mejor racha de votos. |
| `%exyliarewards_votes_voted_today%` | La etiqueta **Sí** o **Aún no**. |
| `%exyliarewards_votes_party_count%` | Votos de la fiesta de votos que se está llenando. |
| `%exyliarewards_votes_party_target%` | El objetivo de la fiesta. |
| `%exyliarewards_votes_party_left%` | Votos que todavía necesita. |
| `%exyliarewards_votes_pinata_active%` | Si hay una piñata en este servidor: la etiqueta **Activa ahora** o **Ninguna**. |
| `%exyliarewards_votes_pinata_hits_left%` | Golpes que le quedan a la piñata de este servidor, `0` si no hay. |

## Referidos

| Placeholder | Valor |
|---|---|
| `%exyliarewards_referrals_count%` | Jugadores que trajo quien mira y que se asentaron. |
| `%exyliarewards_referrals_inviter%` | Quién le invitó, o **Nadie**. |
| `%exyliarewards_referrals_next%` | Su siguiente hito de referidos, o **No quedan**. |

Las etiquetas (**Lista**, **Ninguno**, **Ilimitado**, **Sí**, …) están en `messages.yml`, así que siguen tu idioma y
tu paleta.

## Ejemplos

```text
%exyliarewards_daily_streak%
%exyliarewards_daily_cooldown%
%playtime_next_reward_remaining%
%exyliarewards_afk_top_1_name%
%exyliarewards_votes_party_left%
```
