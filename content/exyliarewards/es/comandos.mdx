Cada módulo registra sus comandos solo mientras funciona; un comando de un módulo desactivado responde que
el módulo está apagado en este servidor. Los comandos cuya descripción dice "abre" son solo para jugadores.

## Recompensas

| Comando | Permiso | Qué hace |
|---|---|---|
| `/rewards` | `exyliarewards.use` | Abre el panel de recompensas. |
| `/rewards claim <id>` | `exyliarewards.use` | Reclama una recompensa. Con `exyliarewards.bypass`, ignora su espera y su límite de reclamos. Un calendario reclama el día que toca hoy. |
| `/rewards preview <id>` | `exyliarewards.use` | Abre lo que da una recompensa. |
| `/rewards freeze` | `exyliarewards.use` | Muestra cuántas congelaciones de racha tienes y el precio de una. |
| `/rewards freeze buy [amount]` | `exyliarewards.use` | Compra congelaciones, de `1` a `100`, por defecto `1`, a `streak-freezes.price`. Se detiene en `streak-freezes.max`. |
| `/playtime` | `exyliarewards.use` | Abre tus recompensas de tiempo de juego. |
| `/playtime <player>` | `exyliarewards.use` y `exyliarewards.admin` | Dice cuánto ha jugado un jugador. Sin el nodo de admin abre tus propias recompensas de tiempo de juego. Funciona desde la consola. |
| `/redeem <code>` | `exyliarewards.redeem` | Canjea un código. Consulta [Códigos canjeables](/docs/exyliarewards/codigos). |

`/rewardsadmin`, también `/playtimeadmin` y `/pta`, necesita `exyliarewards.admin`.

| Comando | Consola | Qué hace |
|---|---|---|
| `/rewardsadmin` | | Abre el editor de recompensas. |
| `/rewardsadmin give <player> <id>` | sí | Da ahora una recompensa a un jugador conectado, ignorando su espera, su límite de reclamos y la regla de una por dirección. Sus requisitos siguen aplicándose. |
| `/rewardsadmin reset <player> <id>` | sí | Olvida los reclamos, la espera y la racha de un jugador en una recompensa. |
| `/rewardsadmin resetall <player> [confirm]` | sí | Lo mismo con todas las recompensas. Sin `confirm` te pide ejecutarlo otra vez con él. |
| `/rewardsadmin presets` | sí | Añade las [recompensas predefinidas](/docs/exyliarewards/instalacion#las-recompensas-predefinidas) cuyo ID esté libre. Una que ya existe, editada o no, se deja como está. |
| `/rewardsadmin stats` | sí | Calcula y muestra los reclamos, los reclamos de esta semana, los jugadores, las rachas activas y la mejor racha de cada recompensa. |
| `/rewardsadmin freeze give <player> <amount>` | sí | Da a un jugador de `1` a `1000` congelaciones de racha, esté conectado o no. |
| `/rewardsadmin codes` | | Abre la pantalla de códigos canjeables. |
| `/rewardsadmin reload` | sí | Recarga `config.yml`, `messages.yml`, `discord.yml`, `votes.yml`, `referrals.yml` y los menús. Activar o desactivar un módulo necesita reiniciar. |

## Zonas AFK

| Comando | Permiso | Qué hace |
|---|---|---|
| `/afkzone` | `exyliarewards.afkzones.use` | Abre las zonas AFK de este servidor. |
| `/afkzone preview <zone>` | `exyliarewards.afkzones.use` | Abre los niveles de una zona. |
| `/afkzonesadmin` | `exyliarewards.afkzones.admin` | Abre el editor de zonas. |

## Votos

| Comando | Permiso | Consola | Qué hace |
|---|---|---|---|
| `/vote`, `/votes` | `exyliarewards.votes.use` | | Abre las webs de votación y tus votos. |
| `/voteadmin`, `/votea` | `exyliarewards.votes.admin` | | Abre el editor de la fiesta de votos. |
| `/voteadmin fake <player> [service]` | `exyliarewards.votes.admin` | sí | Envía un voto de prueba para ese nombre, desde `service` (por defecto `Test`), por todo el camino: recompensas, racha y fiesta. |
| `/voteadmin party` | `exyliarewards.votes.admin` | sí | Inicia ahora la fiesta de votos que se está llenando, tenga los votos que tenga. |
| `/voteadmin pinata [id]` | `exyliarewards.votes.admin` | sí | Envía una piñata ahora: la indicada, o una por peso, a uno de los puntos de aparición de este servidor, o a donde estás. |
| `/voteadmin pinata stop` | `exyliarewards.votes.admin` | sí | Quita todas las piñatas de este servidor, sin pagar nada. |

## Referidos

| Comando | Permiso | Consola | Qué hace |
|---|---|---|---|
| `/referral`, `/ref`, `/referrals` | `exyliarewards.referrals.use` | | Muestra quién te invitó y a quién trajiste. |
| `/referral <player>` | `exyliarewards.referrals.use` | | Indica quién te invitó. |
| `/referraladmin reset <player> [confirm]`, `/refadmin reset` | `exyliarewards.referrals.admin` | sí | Olvida a quién indicó un jugador, mientras no se haya pagado a nadie por ello. Sin `confirm` te pide ejecutarlo otra vez con él. |

## Acciones de menú

Para los menús y NPCs propios del servidor, en el espacio de nombres `exyliarewards`:

| Acción | Qué hace |
|---|---|
| `exyliarewards:open_hub` | Abre el panel de recompensas. |
| `exyliarewards:open_category <periodic\|playtime\|calendar>` | Abre una lista de recompensas. |
| `exyliarewards:claim <id>` | Reclama una recompensa, como `/rewards claim`; un calendario abre su cuadrícula. |
| `exyliarewards:preview <id>` | Abre el contenido de una recompensa. |
| `exyliarewards:open_calendar <id>` | Abre la cuadrícula de un calendario. |
| `exyliarewards:calendar_claim <id> <day>` | Reclama un día de un calendario, o lo recupera. |
| `exyliarewards:open_afk` | Abre las zonas AFK. |
| `exyliarewards:afk_preview <zone>` | Abre los niveles de una zona. Necesita `exyliarewards.afkzones.use`. |
| `exyliarewards:open_votes` | Abre `/vote`. |
| `exyliarewards:votes_link <site>` | Envía el enlace de una web de votación. Necesita `exyliarewards.votes.use`. |
| `exyliarewards:open_referrals` | Muestra el resumen de `/referral`. |

Las acciones de los editores de administración comprueban el nodo de admin de su módulo, así que copiar un
botón a una pantalla que pueden abrir los jugadores no les da nada.
