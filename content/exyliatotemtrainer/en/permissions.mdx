---
title: "Permissions"
description: "The eight nodes the plugin declares, what each one gates, and their defaults."
---

Eight nodes, all declared in the plugin. Seven are granted to everyone by default; the admin node is for
operators.

## Plugin nodes

| Permission | Default | What it gates |
|---|---|---|
| `exyliatotemtrainer.use` | everyone | `/totem` itself, the main menu, and the tick picker on the training screen. |
| `exyliatotemtrainer.train` | everyone | `/totem train`. |
| `exyliatotemtrainer.duel` | everyone | `/totem duel`, `/totem accept` and `/totem deny`: sending, accepting and declining requests. |
| `exyliatotemtrainer.leave` | everyone | `/totem leave`. |
| `exyliatotemtrainer.profile` | everyone | `/totem profile` and `/totem stats`, own and others'. |
| `exyliatotemtrainer.leaderboard` | everyone | `/totem leaderboard` and `/totem top`. |
| `exyliatotemtrainer.history` | everyone | `/totem history`. |
| `exyliatotemtrainer.admin` | operators | `/totemtraineradmin`, `/ttadmin` and every screen behind them, including `reload`. |

## Menus check the same nodes

Every menu action carries the node of the command it stands for, so a button edited into a file is no
way around it. A click without the node does nothing.

| Permission | Actions |
|---|---|
| `exyliatotemtrainer.use` | `select_ticks`, `cycle_ticks` |
| `exyliatotemtrainer.train` | `train`, `train_again` |
| `exyliatotemtrainer.duel` | `duel_open`, `duel_send`, `select_format`, `cycle_format`, `rematch` |
| `exyliatotemtrainer.leave` | `leave` |
| `exyliatotemtrainer.leaderboard` | `leaderboard_mode`, `leaderboard_sort`, `leaderboard_category`, `leaderboard_speed` |
| `exyliatotemtrainer.admin` | every `admin_*` action |

`open` checks the node of the screen it opens: `training` needs `train`, `opponents` needs `duel`,
`profile` and `records` need `profile`, `history` needs `history`, `leaderboard_modes` and `leaderboard`
need `leaderboard`, and anything else needs `use`.

<Callout type="note" title="Nothing per mode, nothing per arena">
There are no permission nodes for individual modes, tick speeds, formats or arenas. A player who may
train may train every configured mode at every configured speed. Gating a mode behind a rank is not
something this plugin does.
</Callout>

## Examples

Taking duels away from a group while leaving solo training in place:

```text
/lp group default permission set exyliatotemtrainer.duel false
```

Handing the admin screens to staff who are not operators:

```text
/lp group staff permission set exyliatotemtrainer.admin true
```

Without the permission, a command answers with the configured `no-permission` line from `messages.yml`.
