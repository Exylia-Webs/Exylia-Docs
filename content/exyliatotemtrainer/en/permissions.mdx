Everything players do is allowed by default. Only `/totemtraineradmin` is for operators. Use this page to take features away from a group or hand the admin menu to staff.

## Turn a feature into a rank perk

Everybody holds the player permissions, so to make one a perk you deny it to the default group and allow it to the rank. With LuckPerms:

```text
/lp group default permission set exyliatotemtrainer.duel false
/lp group vip permission set exyliatotemtrainer.duel true
```

Hand the admin menu to staff who are not operators:

```text
/lp group staff permission set exyliatotemtrainer.admin true
```

Leaving training or a duel, and declining a duel request, never need a permission, so a player who lost a rank can always get out.

<Callout type="note" title="Nothing per mode, nothing per arena">
There are no permissions for individual modes, speeds, formats or arenas. A player who may train can train every configured mode at every speed. To keep a mode away from a rank, the plugin has no switch for it.
</Callout>

<Details title="Menus check the same permissions">
Every menu button carries the permission of the command it stands for, so a button edited into a menu file is no way around it. A click without the permission does nothing.

| Permission | Buttons |
|---|---|
| `exyliatotemtrainer.use` | The speed picker (`select_ticks`, `cycle_ticks`) |
| `exyliatotemtrainer.train` | `train`, `train_again` |
| `exyliatotemtrainer.duel` | `duel_open`, `duel_send`, `select_format`, `cycle_format`, `rematch` |
| `exyliatotemtrainer.leaderboard` | `leaderboard_mode`, `leaderboard_sort`, `leaderboard_category`, `leaderboard_speed` |
| `exyliatotemtrainer.admin` | every `admin_*` action |

The `open` button checks the permission of the screen it opens: the solo screen needs `train`, the opponent picker `duel`, profile and records `profile`, history `history`, the leaderboards `leaderboard`, and anything else `use`.
</Details>
