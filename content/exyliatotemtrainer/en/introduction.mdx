ExyliaTotemTrainer turns totem pops into a practice mode. Players train alone at a speed they pick, or challenge another player to a best-of duel. Every pop is graded, every best is kept, and every mode has its own leaderboard.

You set it up from menus: no arena files, no command line. In about ten minutes you can have one arena ready and a first session running.

## How a session works

Every few ticks the plugin deals a hit that a totem in either hand absorbs. The player has to put the next totem in a hand before the next hit. The time that takes is the reaction, graded from Perfect to Slow. With no totem in hand when a hit lands the session ends, or in a duel the round is lost. No death screen is shown.

- **Solo training**: pick a mode and a speed, from 25 ticks (slow) down to 5 (very fast). Six modes ship: Normal, Infinite, Random, Chaos, Acceleration and Blackout.
- **Duels**: challenge a player, choose the mode, speed and best-of length. Both play the same rules at once, and the round goes to whoever keeps a totem in hand.
- **Stats**: profile, personal records, duel history and one leaderboard per mode.

## What you need

| Requirement | Detail |
|---|---|
| Server | Paper 1.21.1 or newer, or Folia 1.21.4 or newer |
| Java | 21 |
| Required plugin | ExyliaLib |
| Optional plugins | PlaceholderAPI (placeholders in other plugins), PacketEvents (hides players of other sessions) |
| Languages | English, Spanish, Portuguese, French, Russian and Turkish |

ExyliaLib provides the menus, database, colours and messages shared by every Exylia plugin. See [Install ExyliaTotemTrainer](/docs/exyliatotemtrainer/installation).

<Details title="How to read the values on these pages">
- A value marked as default is what the plugin writes the first time it starts. If the file already exists, your value is kept.
- Words between `<` and `>` are variables: `/totem train <mode>` means `/totem train chaos`.
- Times are seconds with decimals unless a key says ticks. 20 ticks are one second.
- Colours use ExyliaLib palette tokens such as `{primary}`. See [Colours](/docs/exylialib/colours).
</Details>
