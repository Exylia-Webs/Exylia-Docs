---
title: "Scoreboard"
description: "The two sidebars in scoreboards.yml: when each shows, their default lines and the refresh block."
---

`scoreboards.yml` defines two sidebars: `training`, shown to a player in a solo session, and `match`,
shown to a duellist. Outside both, the plugin shows nothing, and whatever board a lobby plugin had
underneath comes back on its own.

## The file

```yaml title="plugins/ExyliaTotemTrainer/scoreboards.yml"
training:
  enabled: true
  title:
    - "{primary}&lTOTEM TRAINER"
  lines:
    - ""
    - "{secondary}Session:"
    - " {letters_black}▎ {letters}%exyliatotemtrainer_mode% {muted}· {letters}%exyliatotemtrainer_interval% ticks"
    - " {letters_black}▎ {letters}Time {letters_black}» {info}%exyliatotemtrainer_session_time%"
    - ""
    - "{secondary}Performance:"
    - " {letters_black}▎ {letters}Pops {letters_black}» {info}%exyliatotemtrainer_pops%"
    - " {letters_black}▎ {letters}Best {letters_black}» {success}%exyliatotemtrainer_best%"
    - " {letters_black}▎ {letters}Average {letters_black}» {info}%exyliatotemtrainer_average%"
    - " {letters_black}▎ {letters}Streak {letters_black}» {highlight}%exyliatotemtrainer_streak%"
    - " {letters_black}▎ {letters}Last {letters_black}» %exyliatotemtrainer_grade%"
    - ""
    - "{muted}exylia.net"
  update:
    interval: 10
    smart: true
    cache: true
match:
  enabled: true
  title:
    - "{primary}&lTOTEM TRAINER"
  lines:
    - ""
    - "{secondary}Duel: {muted}· {letters}%exyliatotemtrainer_format%"
    - " {letters_black}▎ {letters}vs {highlight}%exyliatotemtrainer_opponent%"
    - " {letters_black}▎ {letters}Round {letters_black}» {info}%exyliatotemtrainer_round%"
    - " {letters_black}▎ {letters}Score {letters_black}» {success}%exyliatotemtrainer_score%"
    - " {letters_black}▎ {letters}%exyliatotemtrainer_match_state%"
    - ""
    - "{secondary}Round:"
    - " {letters_black}▎ {letters}Pops {letters_black}» {info}%exyliatotemtrainer_pops% {muted}· {letters}%exyliatotemtrainer_opponent_pops%"
    - " {letters_black}▎ {letters}Best {letters_black}» {success}%exyliatotemtrainer_best%"
    - " {letters_black}▎ {letters}Average {letters_black}» {info}%exyliatotemtrainer_average%"
    - " {letters_black}▎ {letters}Streak {letters_black}» {highlight}%exyliatotemtrainer_streak%"
    - ""
    - "{muted}exylia.net"
  update:
    interval: 10
    smart: true
    cache: true
```

| Key | Default | What it does |
|---|---|---|
| `enabled` | `true` | `false` keeps the section written but shows no board for that context. |
| `title` | one line | A list. With several entries they animate: each refresh shows the next. |
| `lines` | see above | The lines, top first. At most 15; extra lines are dropped. |
| `update.interval` | `10` | **Ticks** between refreshes. 20 ticks is one second. |
| `update.smart` | `true` | Sends only the lines that changed instead of the whole board. |
| `update.cache` | `true` | Read for compatibility with older files: parsed text is cached by ExyliaLib for every plugin at once. |

## What the lines can say

Nothing is pushed into a board. The library renders it on its own interval and asks the placeholders,
so a line is any text carrying this plugin's own `%exyliatotemtrainer_<name>%` placeholders, and any other
placeholder ExyliaLib resolves works too. This file is read by the plugin itself, so the names here go
without the plugin name in front; the full list, in the form other plugins read them, is on
[Placeholders](/docs/exyliatotemtrainer/placeholders). The ones the defaults use:

| Placeholder | Board | Value |
|---|---|---|
| `%exyliatotemtrainer_mode%` | training | The mode's display name |
| `%exyliatotemtrainer_interval%` | training | The current interval in ticks, which an accelerating mode keeps moving |
| `%exyliatotemtrainer_session_time%` | training | Time since the drill began |
| `%exyliatotemtrainer_pops%` | both | Pops of the running session, this round's in a duel |
| `%exyliatotemtrainer_best%` | both | Fastest reaction of the running session, this round's in a duel |
| `%exyliatotemtrainer_average%` | both | Average reaction of the running session, this round's in a duel |
| `%exyliatotemtrainer_streak%` | both | Pops in a row of the running session, this round's in a duel |
| `%exyliatotemtrainer_grade%` | training | The last pop's grade, `—` before the first |
| `%exyliatotemtrainer_format%` | match | `BO3` |
| `%exyliatotemtrainer_opponent%` | match | The opponent's name |
| `%exyliatotemtrainer_opponent_pops%` | match | The opponent's pops this round |
| `%exyliatotemtrainer_round%` | match | The round being played |
| `%exyliatotemtrainer_score%` | match | Rounds won, yours first: `2 - 1` |
| `%exyliatotemtrainer_match_state%` | match | `waiting`, `starting`, `active`, `round_end`, `ending` or `finished` |

<Callout type="note" title="The grade line never goes blank">
`%exyliatotemtrainer_grade%` answers `—` between the start of a session and its first pop, so the line reads
"Last » —" instead of showing the placeholder's own name.
</Callout>

## Reloading

`/totemtraineradmin reload` re-reads the file and rebuilds the board of every player currently in a
session or a duel.
