ExyliaTotemTrainer has two commands: `/totem` for players and `/totemtraineradmin` for staff. Almost everything is also a menu, so players rarely need to type more than `/totem`.

`/tt` and `/totemtrainer` are aliases of `/totem`. `/ttadmin` is an alias of `/totemtraineradmin`. To give or take a permission, see [Permissions](/docs/exyliatotemtrainer/permissions).

<Callout type="note" title="Arenas have no commands">
You create, rename, position, enable and delete arenas from `/totemtraineradmin`, and cancel duels or reset a player from the same menu, each behind a confirmation. See [Create an arena](/docs/exyliatotemtrainer/arenas). The only admin command is `reload`, because the console has to be able to run it.
</Callout>

## What the optional arguments default to

| Argument | Default | Refused when |
|---|---|---|
| `ticks` | `training.default-ticks` (20) | The value is not in `training.ticks` (25, 20, 15, 10 and 5 by default). The message names the speed. |
| `mode` (duel) | The first mode listed in `training.modes` (`normal`) | The mode does not exist. |
| `bestOf` | `match.default-format` (3) | The length is not in `match.formats`. |
| `category` | `rating` | Never: an unknown category falls back to `rating`. |
| `mode` (leaderboard) | none | An unknown mode opens the mode picker instead of an empty board. |

The categories are `rating`, `best_pops`, `fastest_average`, `best_streak` and `longest_run`. Tab completion suggests the configured modes, speeds, formats and categories.

`/totem profile <player>` works for players the server already knows, online or not. A name the server has never seen answers that the player was not found.

<Details title="What /totemtraineradmin reload does">
Reload runs named steps: `configs` (`config.yml`, `messages.yml`, `scoreboards.yml`, the prefix and the debug switch), `performance` (the grading thresholds are rebuilt), `scoreboards` (every sidebar on screen is redrawn) and `menus` (every screen is compiled again). The success line says how many steps ran and how long it took; a failure asks you to check the console.

Reload does not touch arenas or player data: both live in the database.

The same reload is the **Reload** button of the admin menu. Without the `exyliatotemtrainer.admin` permission the command answers with the `no-permission` line of `messages.yml`.
</Details>
