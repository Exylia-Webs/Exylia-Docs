Todo lo que hacen los jugadores está permitido por defecto. Solo `/totemtraineradmin` es para operadores. Usa esta página para quitar funciones a un grupo o dar el menú de admin al staff.

## Convierte una función en ventaja de rango

Todo el mundo tiene los permisos de jugador, así que para hacer de uno una ventaja se lo niegas al grupo por defecto y se lo das al rango. Con LuckPerms:

```text
/lp group default permission set exyliatotemtrainer.duel false
/lp group vip permission set exyliatotemtrainer.duel true
```

Da el menú de admin a staff que no es operador:

```text
/lp group staff permission set exyliatotemtrainer.admin true
```

Salir del entrenamiento o de un duelo, y rechazar una petición de duelo, nunca necesitan permiso, así que un jugador que perdió un rango siempre puede salir.

<Callout type="note" title="Nada por modo, nada por arena">
No hay permisos para modos, velocidades, formatos ni arenas concretos. Un jugador que puede entrenar puede entrenar todos los modos configurados a todas las velocidades. Para apartar un modo de un rango, el plugin no tiene interruptor.
</Callout>

<Details title="Los menús comprueban los mismos permisos">
Cada botón de menú lleva el permiso del comando al que representa, así que un botón añadido a mano en un archivo de menú no sirve para saltárselo. Un clic sin el permiso no hace nada.

| Permiso | Botones |
|---|---|
| `exyliatotemtrainer.use` | El selector de velocidad (`select_ticks`, `cycle_ticks`) |
| `exyliatotemtrainer.train` | `train`, `train_again` |
| `exyliatotemtrainer.duel` | `duel_open`, `duel_send`, `select_format`, `cycle_format`, `rematch` |
| `exyliatotemtrainer.leaderboard` | `leaderboard_mode`, `leaderboard_sort`, `leaderboard_category`, `leaderboard_speed` |
| `exyliatotemtrainer.admin` | toda acción `admin_*` |

El botón `open` comprueba el permiso de la pantalla que abre: la pantalla individual necesita `train`, el selector de rivales `duel`, perfil y récords `profile`, historial `history`, las clasificaciones `leaderboard`, y cualquier otra `use`.
</Details>
