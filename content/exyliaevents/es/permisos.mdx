Los jugadores pueden usar ExyliaEvents sin configurar nada: entrar, espectar y elegir equipo están permitidos por defecto. Iniciar eventos y `/eventsadmin` son para el staff hasta que los concedas. Usa esta página para cambiarlo.

## Dejar que un rango inicie eventos

`exyliaevents.start` permite iniciar cualquier evento desde `/events start`, el menú de inicio y el creador de gauntlets. No es `exyliaevents.admin`, que además permite crear, editar y borrar configuraciones. No los mezcles.

Para que un rango inicie solo algunos eventos, dale `exyliaevents.start.<config>` de cada uno en lugar del general. El menú de inicio y el autocompletado solo mostrarán esas configuraciones, `/events start` rechazará el resto, y el creador de gauntlets solo iniciará una serie cuyas fases pueda iniciar todas. `<config>` es el id que diste a la configuración al crearla.

```text
/lp group vip permission set exyliaevents.start.tntrun1 true
/lp group vip permission set exyliaevents.start.spleef1 true
```

## Esperas y límites por rango

| Permiso | Qué fija |
|---|---|
| `exyliaevents.cooldown.<segundos>` | El tiempo de espera para iniciar del rango, como `exyliaevents.cooldown.60`. Gana el más bajo que tenga el jugador. Sin ninguno, se aplica `settings.start-cooldown` de `config.yml`. |
| `exyliaevents.max-events.<n>` | Cuántos eventos puede tener iniciados a la vez un jugador. Gana el más alto y `0` es ilimitado. Sin ninguno, se aplica `settings.max-events-per-player`. |
| `exyliaevents.cooldown.bypass` | Sin ninguna espera. |

También puedes poner tus propios permisos en `settings.start-cooldown-permissions` como `permiso:segundos`. Mira [Flujo de juego](/docs/exyliaevents/flujo-de-juego#límites).

## Hacer de una función una ventaja de rango

Los jugadores tienen todos los permisos de jugador por defecto. Para convertir uno en ventaja, niégalo al grupo por defecto y concédelo al rango:

```text
/lp group default permission set exyliaevents.spectate false
/lp group vip permission set exyliaevents.spectate true
```

Salir de un evento nunca necesita permiso, así que un jugador siempre puede irse.

<Callout type="warning" title="Dos permisos que son solo para el staff">
`exyliaevents.admin` da todo el panel y todos los menús de configuración. `exyliaevents.bypass.blocked-commands` deja usar cualquier comando dentro de un evento, como `/fly`, que da ventaja en la mayoría de juegos.
</Callout>
