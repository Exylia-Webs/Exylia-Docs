These show live ExyliaEvents data in other plugins that support PlaceholderAPI, such as holograms, tab lists and hub scoreboards. They need [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) installed. Click a placeholder to copy it.

<Placeholders />

## How to read the ids

`<event>`, `<arena>` and `<type>` are the id you gave the configuration (such as `koth`) or the event type (such as `tnt_run`). Ids with underscores work as they are. `<pool>` takes what [`/events play`](/docs/exyliaevents/commands#play-from-a-pool-of-arenas) takes: one arena, an event type for all its arenas, or a comma-separated list of both.

```text
%exyliaevents_state_pillars_1%
%exyliaevents_players_pillarsoffortune%
%exyliaevents_event_stats_kills_koth%
%exyliaevents_event_top_name_wins_3_koth%
```

`%exyliaevents_waiting%` and `%exyliaevents_in_progress%` never overlap: an event counting down can be joined, one that is playing cannot.

## The reader's team

`%exyliaevents_team_color%` is the colour code of the team the reader belongs to in a team event (`&c`, `&9`, `&a`, `&e`), and empty for anyone not in one, so you can put it straight into a chat or tab format. `%rel_exyliaevents_team_color%` answers for the other player, the one whose name tag or tab entry is drawn, so a name tag plugin can colour each name by its owner's team.

## Leaderboards

Every board shows the top ten (`<position>` from 1 to 10). `<stat>` is `kills`, `deaths`, `wins` or `games`; `kdr` and `winrate` are worked out per player, so nothing can be ranked by them. A board is read at most once a minute and kept in memory between reads, so a hologram that refreshes every second costs nothing extra.

While a board or a statistic is still being read the placeholder shows `-`, and a position nobody has reached yet shows `---`. Both fix themselves on the next refresh.

Statistics placeholders belong to the player who reads them. There is none for another player.

<Callout type="note" title="The plugin's own files use different tokens">
The sidebars in `scoreboards.yml` and the boss bars in `messages.yml` are filled with tokens the running event provides, such as `%time%`, not with these. These placeholders are for other plugins to read the state of ExyliaEvents.
</Callout>
