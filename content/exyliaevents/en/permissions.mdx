Players can use ExyliaEvents without any setup: joining, spectating and picking a team are allowed by default. Hosting events and `/eventsadmin` are for staff until you grant them. Use this page to change that.

## Let a rank host events

`exyliaevents.start` lets a player start any event from `/events start`, the start menu and the gauntlet builder. It is not `exyliaevents.admin`, which also lets them create, edit and delete configurations. Do not merge the two.

To let a rank host only some events, give it `exyliaevents.start.<config>` for each one instead. The start menu and tab completion then show only those configurations, `/events start` refuses the rest, and the gauntlet builder only starts a series whose every stage they may host. `<config>` is the id you gave the configuration when you created it.

```text
/lp group vip permission set exyliaevents.start.tntrun1 true
/lp group vip permission set exyliaevents.start.spleef1 true
```

## Cooldowns and limits per rank

| Permission | What it sets |
|---|---|
| `exyliaevents.cooldown.<seconds>` | The start cooldown for the rank, such as `exyliaevents.cooldown.60`. The lowest one a player holds wins. Without one, `settings.start-cooldown` in `config.yml` applies. |
| `exyliaevents.max-events.<n>` | How many events one player may have started at once. The highest wins and `0` is unlimited. Without one, `settings.max-events-per-player` applies. |
| `exyliaevents.cooldown.bypass` | No cooldown at all. |

You can also name your own permissions in `settings.start-cooldown-permissions` as `permission:seconds`. See [Game flow](/docs/exyliaevents/game-flow#limits).

## Make a feature a rank perk

Players hold every player permission by default. To make one a perk, deny it to the default group and grant it to the rank:

```text
/lp group default permission set exyliaevents.spectate false
/lp group vip permission set exyliaevents.spectate true
```

Leaving an event never needs a permission, so a player can always get out.

<Callout type="warning" title="Two permissions to keep for staff">
`exyliaevents.admin` gives the whole panel and every setup menu. `exyliaevents.bypass.blocked-commands` lets a player run any command inside an event, such as `/fly`, which is an advantage in most games.
</Callout>
