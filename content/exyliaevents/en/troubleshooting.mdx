Find what you see, then follow the fix.

## I cannot enable an event

Click the switch on the setup screen and the plugin refuses, naming how many problems it found. Hover over the switch to read each one. A configuration needs a **Lobby spawn**, a **Spectator spawn**, at least one point in **Spawn points** (as many as **Max players** for Pillars of Fortune and Survival Games, and one per team on team types), complete bounds from **Set bounds**, every marker its type asks for in **Arena markers**, and a saved **Schematic**. See [Arenas](/docs/exyliaevents/arenas#validation).

## An enabled event turned itself off

When the server starts, ExyliaEvents switches off every enabled configuration that is no longer complete and writes the reason to the console. The usual cause is a missing schematic: the `.schem` files live in `plugins/ExyliaEvents/schematics/` on each server's disk, not in the database. After moving the server or the database, copy that folder, or open **Schematic** on the setup screen and left-click to save it again, then enable the event.

## The event will not start

- **"the main lobby is not set"**: run `/eventsadmin` and click **Set main lobby**.
- **A limit refused it**: `max-events-total`, `max-events-waiting` and `max-events-per-player` in `config.yml`, and the start cooldown, can all stop a start. `exyliaevents.cooldown.bypass` skips the cooldown. See [Game flow](/docs/exyliaevents/game-flow#limits).
- **It is waiting for players**: the countdown starts only with **Min players** inside (2 by default).
- **A host is holding it**: the player who started it ran `/events hold`. They run `/events begin`, or you use `/eventsadmin forcestart <id>`.

## A player cannot join

- **The sign-up list is open** for that event, so only listed players can enter. Run `/eventsadmin inscriptions close <id>`. See [Sign-ups](/docs/exyliaevents/inscriptions).
- **Private mode, blacklist or a blocked rank** applies. Check `/eventsadmin access`.
- **They are busy in another Exylia plugin**: a player in an ExyliaFFA arena, an ExyliaPracticeCore queue or the ExyliaSandBox is held by that plugin until they leave it.
- **Their world is restricted** by `world-restrictions` in `config.yml`. `exyliaevents.world.bypass` ignores the rule.
- **They lack a permission**: `exyliaevents.commands.join`, or `exyliaevents.join.random` for joining without an id. See [Permissions](/docs/exyliaevents/permissions).

## Players cannot use their commands inside an event

`command-whitelist` in `config.yml` is on by default and blocks every command that is not listed. Add the ones you want, or give staff `exyliaevents.bypass.blocked-commands`.

## The arena is not restored between games

Save the schematic with a left-click on **Schematic** on the setup screen, and use right-click to restore it by hand. Restoring pastes `event_bounds_<id>` back over the bounds. Brackets, Sumo and Build Battle also clone the arena from it: when the copies cannot be made, the console says so and the event falls back to the configuration's own spawns.

## Spleef or TNT Run does nothing when I break a block

Those types look for specific materials: Spleef breaks `SNOW_BLOCK`, and TNT Run removes a floor block only when there is `TNT` directly under it. See [Arenas](/docs/exyliaevents/arenas#materials-each-type-expects).

## Players are not eliminated when they fall

Most falling games eliminate on contact with water, not on the void. Put water under the arena.

## A placeholder shows as text or as a dash

Install PlaceholderAPI. A `-` means the value is still being read and fixes itself; `---` means nobody holds that leaderboard position yet. See [Placeholders](/docs/exyliaevents/placeholders).

## I changed a file and nothing happened

Run `/eventsadmin reload`. Changing `database.yml` needs a restart instead. See [Commands](/docs/exyliaevents/commands#reload-export-and-import).
