By the end of this page you have one working arena, enabled and started, with a friend inside it. Everything happens in the `/eventsadmin` menus: event configurations are stored in the database, so there is no file to edit.

## Before you start

- ExyliaEvents and ExyliaLib are installed and the server has booted once. See [Installation](/docs/exyliaevents/installation).
- You have `exyliaevents.admin`. See [Permissions](/docs/exyliaevents/permissions).
- Pick an easy first game. **Spleef** and **TNT Tag** need one open room and normal spawn points. Spleef breaks `SNOW_BLOCK`, so build the floor from snow blocks. Some types need special blocks or marked places, listed in [Arenas](/docs/exyliaevents/arenas#materials-each-type-expects).

## Steps

<Steps>
  <Step title="Set the main lobby">
    Stand where players should return after an event, run `/eventsadmin` and click **Set main lobby**. It is stored once for the whole server, and no event can start without it.
  </Step>
  <Step title="Create the configuration">
    In `/eventsadmin` click **Configurations**, open a category, then click **Create event**. Choose the type, then type an id in chat (lower case, numbers, `_` or `-`, such as `spleef1`) and a display name. The id is what commands and placeholders use. The type cannot be changed afterwards. The setup screen opens, titled with the id.
  </Step>
  <Step title="Set the two spawns">
    Stand in the waiting room and left-click **Lobby spawn**. Stand where eliminated players and spectators should watch and left-click **Spectator spawn**. Right-click either one to teleport there and check it.
  </Step>
  <Step title="Add spawn points">
    Stand where players should start and left-click **Spawn points**; repeat for each place. Right-click clears them. One is enough for most types. Pillars of Fortune and Survival Games need one per player: as many as **Max players**.
  </Step>
  <Step title="Mark the arena bounds">
    Click **Set bounds** and select the two corners of the box the game happens in. Leaving it counts as leaving the arena.
  </Step>
  <Step title="Mark what the type asks for">
    Types with goals, flags or capture points add an **Arena markers** button that lists what is missing. See [Arenas](/docs/exyliaevents/arenas#markers).
  </Step>
  <Step title="Save the schematic">
    Left-click **Schematic** to save the arena as it is now. After every game the plugin pastes it back, and it cannot enable the configuration without it. Right-click restores it by hand.
  </Step>
  <Step title="Enable it">
    Click the switch (**Disabled** turns into **Enabled**). If something is missing, it refuses and lists what; hover over the switch to read the list.
  </Step>
</Steps>

Leave **Countdown**, **Duration**, **Min players** and **Max players** at their defaults (30 seconds, 5 minutes, 2 and 32) for now. Each type also has an **Type settings** screen: see [Event types](/docs/exyliaevents/event-types).

## Check that it works

<Steps>
  <Step title="Start it">
    Run `/eventsadmin forcestart spleef1` (your id). The event opens for joining.
  </Step>
  <Step title="Join with two players">
    You and a friend run `/events join spleef1`, or click it in `/events`. With 2 players in, the countdown starts and the game begins.
  </Step>
  <Step title="Stop it if you need to">
    `/eventsadmin forcestop spleef1` ends it and sends everyone back to the main lobby.
  </Step>
</Steps>

You should see the sidebar of the event, the countdown and then the game. After it ends, the arena is pasted back from the schematic.

## Let players start it themselves

Players start events with `/events start <id>` once you give their rank `exyliaevents.start` (or `exyliaevents.start.spleef1` for this one only). See [Permissions](/docs/exyliaevents/permissions#let-a-rank-host-events).
