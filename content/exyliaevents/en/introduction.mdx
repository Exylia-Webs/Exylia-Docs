ExyliaEvents runs minigame events on your server: **53 event types** (forty-five games and eight team variants), each with its own rules, settings screen, scoreboard and messages. In about ten minutes you can have one arena open and players inside it.

An *event configuration* is one arena of one type: its lobby, spawns, bounds, settings, kits and rewards. You can have as many as you like and several can run at the same time. Everything is created from `/eventsadmin`, and configurations live in the database, not in a file.

## Before you start

| You need | Detail |
|---|---|
| Server | Paper 1.21.1 or newer, or Folia 1.21.4 or newer. |
| Java | 21 |
| Required | `ExyliaLib`, installed before the first boot. |
| Optional | `FastAsyncWorldEdit`, `PlaceholderAPI`, `packetevents`, `ExyliaPracticeCore`, `ExyliaProxyUtils`, `Worlds`, `WorldGuard` and others, listed in [Installation](/docs/exyliaevents/installation). |

<Callout type="note" title="FastAsyncWorldEdit is optional">
Arena schematics restore an arena after a game and let Brackets, Sumo and Build Battle clone themselves. With FAWE installed they go through it; without it, ExyliaLib's built-in engine saves and pastes the same `.schem` files, so adding or removing FAWE never means saving arenas again.
</Callout>

## Steps

<Steps>
  <Step title="Install">
    Put `ExyliaEvents.jar` and ExyliaLib in `plugins/` and start the server. See [Installation](/docs/exyliaevents/installation).
  </Step>
  <Step title="Open the panel">
    Run `/eventsadmin` and set the main lobby, where players return when they leave an event.
  </Step>
  <Step title="Create an event">
    Pick a type, build its arena and open it. [Your first event](/docs/exyliaevents/first-steps) walks through every click.
  </Step>
  <Step title="Tune it">
    Settings, kits and rewards per event: [Arenas](/docs/exyliaevents/arenas), [Teams, kits and loot](/docs/exyliaevents/teams-and-kits), [Rewards](/docs/exyliaevents/rewards).
  </Step>
</Steps>

## Check that it works

Run `/events` as a player. You should see your event listed and, once it is open, be able to join it and land in its lobby. If nothing shows up, see [Common problems](/docs/exyliaevents/troubleshooting).

<Details title="Where things live">

| Thing | Where |
|---|---|
| Event configurations, arenas, settings, rewards | Database (`event_configurations`) |
| Kits, loot tables, sign-ups, pending rewards | Database |
| Gauntlet series | Database (`event_gauntlets`) |
| Player statistics, global and per event | Database |
| Language, timers, limits, cooldowns, music | `config.yml` |
| Sidebars, one per event type | `lang/<code>/scoreboards.yml` |
| Every message, boss bar and title, and each type's name, description and category | `lang/<code>/messages.yml` |
| Build Battle themes | `lang/<code>/buildbattle-themes.yml` |
| Trivia questions | `lang/<code>/trivia-questions.yml` |
| Menu layouts | `lang/<code>/menus/` |

Menus, messages and sidebars ship in English, Spanish, Portuguese and French (Russian and Turkish folders also exist) and follow the language set in ExyliaLib: see [Configuration · language](/docs/exyliaevents/configuration#language) and [Messages and languages](/docs/exylialib/messages-and-languages).

</Details>
