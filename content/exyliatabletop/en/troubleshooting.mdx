Find your symptom, then follow the fix.

## The plugin does not start

`packetevents` is required: without it the server does not load ExyliaTabletop at all. ExyliaLib is required too; the loader installs it or stages a newer one and asks for a restart, so restart once more. See [Install ExyliaTabletop](/docs/exyliatabletop/installation).

## Tables are free and no stake is asked

A table is free when `wager.enabled` is `false` in `config.yml`, or when the player has no currency to play for: no economy plugin is installed, or `wager.currencies` lists only currencies they cannot use. Install ExyliaEconomy, Vault with an economy plugin or PlayerPoints, and check the ids in `wager.currencies` (empty offers every currency). A stake in a currency the player typed but cannot use answers that it can't be staked here.

## "Tables are closed for a moment"

After a restart the plugin first refunds every stake the last run left held, and takes no new one until it is done. Try again a few seconds later.

## "Your rank does not include ..."

The player's `exyliatabletop.game.<id>` node is denied for that game. Grant it to their rank, or remove the denial. See [Permissions](/docs/exyliatabletop/permissions).

## "... is not available on this server"

The game has `enabled: false` in its `modules/<id>/config.yml`, or it was switched off from the admin settings. Set it back and run `/tabletopadmin reload`.

## "Your Minecraft version can't show the tables"

Match screens need Minecraft 1.20.2 or newer. A player on an older client, including one through ViaBackwards, must join with 1.20.2 or newer. Bedrock players cannot play.

## Players cannot see the match screen, or are stuck after a crash

Check that PacketEvents is installed and up to date: every match screen is drawn with packets. If a player is stuck after a crash, `play-spot.yml` brings them back on their next join.

## "Slow down. Try again in ..."

Two attempts to open or join a table came inside `matches.join-cooldown` (1 second by default). It stops a double click from charging a stake twice.

## A match ended by itself

A match is called off and every stake refunded when a player leaves during the start countdown, when it outlasts its game's time limit, or when an admin calls it off. A player who quits, dies, uses a teleport command or changes world forfeits instead. See [Playing a match](/docs/exyliatabletop/playing).

## A command is refused during a match

Commands are blocked while playing, except the game's own commands and those in `arena.allowed-commands` (`msg`, `r`, `tell` by default). The player reads "Leave the match with /ttt leave first."

## A placeholder shows as text

PlaceholderAPI is not installed, or the game id is misspelled. Use the id, such as `tictactoe`, not the name. See [Placeholders](/docs/exyliatabletop/placeholders).
