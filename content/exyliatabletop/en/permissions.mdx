Players can use ExyliaTabletop without any setup: opening a lobby, opening a table, inviting players and every game are allowed by default. Only `/tabletopadmin` needs a grant, and operators have it. Use this page to restrict games or to give ranks different limits.

## All permissions

<Permissions />

Leaving never needs a permission: declining an invitation, closing your own table and leaving a match work for everybody, so a rank can never trap a player at a table.

## Make a game a rank perk

Every game has its own node, `exyliatabletop.game.<id>`, held by everyone. Deny it to the default group and grant it to a rank. With LuckPerms:

```text
/lp group default permission set exyliatabletop.game.chess false
/lp group vip permission set exyliatabletop.game.chess true
```

A player without the node cannot open that game's lobby, take a seat or accept an invitation, and reads "Your rank does not include Chess." The ids are listed in [Commands](/docs/exyliatabletop/commands). To close a game for everyone, set `enabled: false` in its `modules/<id>/config.yml` instead. Clicking a table placed in the world does not check any permission, so keep tables where only the players you want can reach them.

## Stake limits and fees per rank

Both numbers go at the end of the node. Neither exists until you grant it, and neither is listed in `plugin.yml`.

| Node | Effect |
|---|---|
| `exyliatabletop.wager.max.500` | This player may stake at most 500. The highest one a player holds wins. `exyliatabletop.wager.max.0` lifts the cap. |
| `exyliatabletop.fee.2` | The server keeps 2% of this player's wins, instead of `wager.fee-percent`. The lowest one a player holds wins. |

`wager.max.<n>` replaces `wager.maximum` for that player, and does nothing while `wager.maximum` is `0`, because then nobody has a cap. To use it, set `wager.maximum` to the lowest cap in `config.yml` first. `exyliatabletop.bypass.fee` always wins over `fee.<n>` and pays no fee.

<Callout type="warning" title="Keep for staff">
`exyliatabletop.admin` can call matches off, which refunds every stake, and place or remove tables. `exyliatabletop.bypass.fee` removes the money sink the fee creates, so give it with care.
</Callout>
