ExyliaTabletop is a set of board, card and dice games players play **against each other**. A player opens
a table for a stake in one of the server's currencies, or invites someone directly; every player who sits
down puts in the same stake, and the winner takes the pot. The game is drawn in front of each player as a 3D
board: pieces glide, cards are dealt and flipped, dice tumble. While they play, a dark room is drawn round
each of them, only for them, so they see the board and nothing of the world behind it.

Nobody is moved: a match is played wherever each player stands when it starts. Or an admin sets a table
down in the world, with chairs round it: players click it and sit down, and the match is played there in
sight of whoever stands round, with hands, dice under a cup and fleets hidden from them. Every game is
played player against player; there is no game against the server.

It is a **premium** plugin, installed through a licence loader. See
[Installation](/docs/exyliatabletop/installation).

## The games

Twenty-two games, each a module of its own with its own file, command and messages. Every one can be switched
off, renamed or retuned without touching the others. See [Games](/docs/exyliatabletop/games) for the rules
and settings of each.

| Kind | Games |
|---|---|
| Board | Tic-Tac-Toe, Four in a Row, Gomoku, Reversi, Checkers, Chess, Dots and Boxes, Battleship, Memory, Ludo |
| Cards | Pick a Card, High Card, Twenty-One, Poker, Truco, Escoba |
| Dice | Liar's Dice, Dice Duel, Generala |
| Quick duels | Rock Paper Scissors, Reflexes, Hot Potato |

Most are played by two. Pick a Card seats up to 8, Poker, Generala and Hot Potato up to 6, Liar's Dice and
Ludo up to 4: the host picks how many a table seats, and may start it before it is full. Truco is played by
two, or by four in pairs. An invitation may go to several players at once.

## Requirements

| Requirement | Detail |
|---|---|
| Server | Paper 1.21.4 or newer, or a fork of it. Folia supported. |
| Java | 21 |
| Required dependencies | `packetevents`, and `ExyliaLib` 1.376.0 or newer — installed for you if it is missing |
| An economy | `ExyliaEconomy`, or `Vault` with an economy plugin, or `PlayerPoints`: stakes are taken in their currencies |
| Optional dependencies | `PlaceholderAPI`, for the placeholders in other plugins |

<Callout type="note" title="About ExyliaLib">
Configuration, menus and prompts, the lobby of tables and invitations, the escrow that holds every stake,
the economy, the database, the stage the boards are drawn on, the room, effects and the shared games
catalogue all come from ExyliaLib. ExyliaTabletop is written on top of it and does not run without it,
which is why the loader installs it on a server that lacks it.
</Callout>

## Shared with other plugins

ExyliaTabletop meets other Exylia plugins in ExyliaLib:

- **One games catalogue.** Every enabled game has a card under the Tabletop category of ExyliaLib's games
  screen, which other plugins can list their own modes in too. `/tabletop` opens that screen on this
  plugin's games alone.
- **One announcements screen.** Every table opened for anybody is announced to the whole server on the
  `tabletop-tables` channel, which each player can mute in ExyliaLib's `/settings`.
- **One busy state.** A player seated at a table is busy for every other plugin, and a player another
  plugin holds is refused a seat here before any stake is taken.

## Languages

The plugin ships English, Spanish, Russian, Turkish, French and Portuguese (`en`, `es`, `ru`, `tr`, `fr`,
`pt`): every message, every game's texts and every menu. See [Configuration](/docs/exyliatabletop/configuration#language).
