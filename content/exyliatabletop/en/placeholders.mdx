---
title: "Placeholders"
description: "Every placeholder the plugin answers: whether the viewer is in a match, their record at each game, and the open tables and matches of each game."
---

The plugin registers its placeholders through ExyliaLib under the group `exyliatabletop`, so the name is the
same inside Exylia plugins' own files and through **PlaceholderAPI**: `%exyliatabletop_in_match%`. Nothing
has to be downloaded from the eCloud. Every value is read from memory.

`<game>` is a game's id: `tictactoe`, `rps`, `fourinarow`, `cards`, `battleship`, `memory`, `gomoku`,
`dotsandboxes`, `reversi`, `checkers`, `liarsdice`, `highcard`, `ludo`, `diceduel`, `reflexes`, `poker`,
`twentyone` or `hotpotato`. The id never changes when the game's commands or name do. Pick a Card's id is
`cards`.

## The viewer

| Placeholder | Value |
|---|---|
| `%exyliatabletop_in_match%` | Whether the viewer is in a match that has left the lobby (starting or being played): `true` or `false`. |
| `%exyliatabletop_<game>_wins%` | Matches of that game the viewer won. |
| `%exyliatabletop_<game>_losses%` | Matches they lost. |
| `%exyliatabletop_<game>_draws%` | Matches that ended in a draw. |
| `%exyliatabletop_<game>_played%` | Wins, losses and draws together. |
| `%exyliatabletop_<game>_win_rate%` | Wins out of matches played, as a percentage. |

A forfeit counts as a win for the winner and a loss for the player who left. A match called off counts for
nobody.

## The server

| Placeholder | Value |
|---|---|
| `%exyliatabletop_<game>_offers%` | Open tables of that game anybody may take right now. |
| `%exyliatabletop_<game>_playing%` | Matches of that game being played right now. |

## Examples

```text
%exyliatabletop_checkers_wins%
%exyliatabletop_poker_win_rate%
%exyliatabletop_tictactoe_offers%
```
