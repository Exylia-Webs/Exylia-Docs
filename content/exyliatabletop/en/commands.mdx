Three kinds of command: each game has a command of its own, `/games` and `/tabletop` open the games
catalogue, and `/tabletopadmin`, also `/tta`, is for staff. Every name can be changed: `games-command`,
`tabletop-command` and `admin-command` in `config.yml`, and `commands` in each game's module file. Renaming
needs a restart.

## Game commands

Every game command runs for players only. `<game>` stands for any of the game commands below.

| Command | Permission | What it does |
|---|---|---|
| `/<game>` | `exyliatabletop.play` | Opens the game's lobby: its open tables, your record and the button to open a table. |
| `/<game> create [amount] [currency]` | `exyliatabletop.create` | Opens a table anybody may take, asking for whatever is left out. A game for more than two first asks how many players the table seats. |
| `/<game> duel <player> [player...] [amount] [currency]` | `exyliatabletop.duel` | Invites one player or several to a table that seats them and the host, asking for whatever is left out. |
| `/<game> accept [player]` | `exyliatabletop.play` | Accepts an invitation from that player; alone, the newest. |
| `/<game> deny [player]` | `exyliatabletop.play` | Declines an invitation from that player; alone, the newest. |
| `/<game> start` | `exyliatabletop.play` | Starts your table before it is full, once the game's minimum is seated. |
| `/<game> cancel` | `exyliatabletop.play` | Closes your open table while it waits, refunding every stake. |
| `/<game> leave` | `exyliatabletop.play` | Leaves a waiting table at once; in a match being played, asks to confirm and forfeits it. |

`[currency]` takes a currency's ExyliaLib id and is suggested from the currencies you may use; `[player]` on
`accept` and `deny` is suggested from the players whose invitations wait for you. An amount accepts the
economy's short forms, such as `2.5k`. On `duel`, every online name typed is invited, and the first word
that is not one is the amount; inviting more players than the game seats answers "… seats at most …
players." Examples: `/ttt create 500`, `/poker duel Steve 1k`, `/poker duel Steve Alex Sam 1k`,
`/checkers accept Steve`.

With `tables.only` on, `create` and `duel` send players to the tables in the world instead: "Matches are
played at the tables: walk up to one and click it."

## /games and /tabletop

| Command | Permission | What it does |
|---|---|---|
| `/games` | `exyliatabletop.play` | Opens ExyliaLib's games catalogue, where every enabled game has a card under **Tabletop**. |
| `/tabletop` | `exyliatabletop.play` | Opens the same screen on this plugin's games alone. |

## Admin commands

Every command here needs `exyliatabletop.admin`, operators by default.

| Command | Console | What it does |
|---|---|---|
| `/tabletopadmin` | | Opens the admin hub: the matches on the server, those waiting for players and those being played, followed live; the list of live matches; and a reload button. |
| `/tabletopadmin reload` | yes | Reads `config.yml`, every module file and the messages again, re-registers the games in the catalogue and reloads the menus. Matches under way keep going. Answers with how many parts were reloaded and how long it took. |
| `/tabletopadmin cancel <id>` | yes | Calls a match off and refunds every stake. The id is suggested from the live matches. |
| `/tabletopadmin table create <game> [id]` | | Sets a table down for a game, by clicking its chairs (below). Without an id it is named after the game, as `chess-1`; naming an existing table sets it down anew. |
| `/tabletopadmin table edit [id]` | | Sets that table down anew, its chairs clicked again. Without an id, the nearest table within 8 blocks. |
| `/tabletopadmin table remove [id]` | with an id | Takes a table away. Without an id, the nearest within 8 blocks. |
| `/tabletopadmin table list` | yes | Every table: its id, game, world and block, and whether it is free, waiting (seated out of seats) or being played. |

From the hub, **LIVE MATCHES** lists every match waiting or being played, with its game, stake, kind (open
table or invitation), players, pot, state and time; a click opens one match's screen, where **CALL OFF
MATCH** asks to confirm and refunds it.

### Setting a table down

`table create` and `table edit` turn the admin's hotbar into the tools for a while; nothing in their
inventory moves.

| Tool | What it does |
|---|---|
| **SEAT** (slots 1 to 7, an oak stair) | Left-click a block (a stair, a slab, any block) to make it a seat, or to take it back. Right-click a block to put the board there: every seat faces it. With no board clicked, the seats face their middle. |
| **DONE** (slot 8) | Sets the table down, with as many seats as were clicked, and saves it in `tables.yml`. |
| **CANCEL** (slot 9) | Stops without setting anything. |

A table seats as many players as it has chairs, up to what its game seats and down to a count the game
plays with. One whose chairs the game cannot be played with (fewer than two, or three for Truco) answers
"This table is not ready to be played yet." A hologram stands over each table, and a mark over each free
chair.

## Menu actions

For a server's own menus and NPCs. Each checks its permission itself.

| Action | Permission | What it does |
|---|---|---|
| `tabletop:lobby <game>` | `exyliatabletop.play` | Opens that game's lobby, by its id (such as `tictactoe`). |
| `tabletop:create <game>` | `exyliatabletop.create` | Asks how many players it seats (games for more than two) and the stake, opens a table, then shows the lobby. Refused with `tables.only` on. |
| `tabletop:join <id>` | `exyliatabletop.play` | Asks to confirm and takes a seat at that table; on your own table, closes it. |
| `tabletop:cancel` | `exyliatabletop.play` | Closes your open table and refunds it. |
| `tabletop:leave` | `exyliatabletop.play` | Asks to confirm and leaves your match, as `/<game> leave`. The leave button in the hotbar during a match runs it. |
| `tabletop:games` | `exyliatabletop.play` | Opens the games catalogue. |
| `tabletop:admin_hub`, `tabletop:admin_matches` | `exyliatabletop.admin` | The admin hub, and the list of live matches. |
| `tabletop:admin_match <id>`, `tabletop:admin_cancel <id>` | `exyliatabletop.admin` | One match's screen, and calling it off after a confirmation. |
| `tabletop:admin_reload` | `exyliatabletop.admin` | Reloads, as `/tabletopadmin reload`. |
