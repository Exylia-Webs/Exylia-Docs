ExyliaTabletop has one command per game, two commands that open the games catalogue, and one admin command. Game commands are for players only. Admin commands need `exyliatabletop.admin`; see [Permissions](/docs/exyliatabletop/permissions).

## Game commands

`<game>` stands for the command of any game, such as `/ttt`, `/poker` or `/chess`. Playing a game also needs its own node, `exyliatabletop.game.<id>`, which everyone has unless you deny it. Declining, cancelling and leaving never need a permission.

The first name is the command and the rest are aliases. Every game's command is registered even when the game is switched off; it then answers that the game is not available. To rename a command, change `commands` in the game's file under `plugins/ExyliaTabletop/modules/<id>/config.yml` and restart.

In `/<game> duel`, every online player name you type is invited. The first word that is not a player is the amount. Inviting more players than the game seats is refused.

## Admin commands

`/tabletopadmin` and its alias `/tta`. Rename them with `adminCommand` in `config.yml`; `gamesCommand` and `tabletopCommand` rename `/games` and `/tabletop`. A rename needs a restart.

### Setting a table down

A table in the world is a block or an NPC players click to open a game's lobby. A hologram over it says which game it is.

<Steps>
  <Step title="Start the wizard">
    Run `/tabletopadmin table create <game>`, for example `/tabletopadmin table create chess`.
  </Step>
  <Step title="Click where it goes">
    The wizard shows **PLACE TABLE**: click the block or the NPC where the table goes. One block or NPC holds one table.
  </Step>
  <Step title="Adjust it">
    The table's screen opens. From there you can change its game, move it, turn its hologram on or off, teleport to it or remove it. Open it again any time with `/tabletopadmin table edit <id>`.
  </Step>
</Steps>

Tables are saved in `tables.yml`. A player who clicks a table opens that game's lobby; the click checks no permission, and the game's own rules apply from there.

<Details title="Menu actions">
For your own menus and NPCs. Each action checks its own permission.

| Action | Permission | What it does |
|---|---|---|
| `tabletop:lobby <game>` | `exyliatabletop.play` | Opens that game's lobby, by its id such as `tictactoe`. |
| `tabletop:create <game>` | `exyliatabletop.create` | Asks the seats and the stake, opens a table and shows the lobby. |
| `tabletop:join <id>` | `exyliatabletop.play` | Asks to confirm and takes a seat at that table; on your own table, closes it. |
| `tabletop:cancel` | none | Closes your open table and refunds it. |
| `tabletop:leave` | none | Asks to confirm and leaves your match, like `/<game> leave`. |
| `tabletop:games` | `exyliatabletop.play` | Opens the games catalogue. |
| `tabletop:admin_hub`, `tabletop:admin_matches`, `tabletop:admin_tables` | `exyliatabletop.admin` | The admin hub, the live matches and the list of tables. |
| `tabletop:admin_match <id>`, `tabletop:admin_cancel <id>` | `exyliatabletop.admin` | One match's screen, and calling it off after a confirmation. |
| `tabletop:admin_reload` | `exyliatabletop.admin` | Reloads, like `/tabletopadmin reload`. |
</Details>
