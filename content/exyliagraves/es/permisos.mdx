---
title: "Permisos"
description: "Cada nodo que declara el plugin, qué controla cada uno, sus valores por defecto e hijos, y los nodos con número que suben los límites y la caducidad por rango."
---

Cada nodo fijo de abajo está declarado en `plugin.yml`. Recibir una tumba, la lista, las vistas previas y
el teletransporte son para todo el mundo por defecto; el teletransporte gratis, abrir la tumba de
cualquiera y las herramientas de staff son para operadores.

## Nodos del plugin

| Permiso | Por defecto | Qué controla |
|---|---|---|
| `exyliagraves.use` | todos | Recibir una tumba al morir. Sin él, lo que se suelta cae como siempre. |
| `exyliagraves.menu` | todos | `/graves`. |
| `exyliagraves.preview` | todos | Mirar dentro de una tumba que puedes abrir: una copia con un clic configurado como `PREVIEW` (ver [Recoger](/docs/exyliagraves/tumbas#recoger)), o clic derecho en `/graves`. |
| `exyliagraves.teleport` | todos | Teletransportarte a tus tumbas desde `/graves`, cuando `teleport.enabled` está activo. |
| `exyliagraves.teleport.free` | operadores | Ese teletransporte sin pagar `teleport.cost`. |
| `exyliagraves.bypass.protection` | operadores | Abrir la tumba de cualquiera, protegida o no. |
| `exyliagraves.admin.view` | operadores | `/gravesadmin list`; mirar dentro de cualquier tumba y teletransportarse a cualquiera, gratis. |
| `exyliagraves.admin.restore` | operadores | Devolver tumbas, desde `/gravesadmin list` o con `/gravesadmin restore`. Incluye `admin.view`. |
| `exyliagraves.admin.remove` | operadores | Eliminar una tumba con todo su contenido, desde `/gravesadmin list`. Incluye `admin.view`. |
| `exyliagraves.admin.reload` | operadores | `/gravesadmin reload`. |
| `exyliagraves.admin` | operadores | Todos los nodos de admin de arriba, y las pantallas de ajustes en el juego. |
| `exyliagraves.*` | operadores | Todo: `use`, `menu`, `preview`, `teleport`, `teleport.free`, `bypass.protection` y `admin`. |

## Nodos con número

Cinco nodos llevan un número. No están declarados en `plugin.yml`; se conceden con tu plugin de permisos.

| Permiso | Qué hace |
|---|---|
| `exyliagraves.limit.<n>` | Cuántas tumbas puede tener en pie el jugador en este servidor. Sin ninguno, `graves.max-per-player`. |
| `exyliagraves.expire.<minutes>` | Cuántos minutos duran sus tumbas. Sin ninguno, `graves.expire-time`. |
| `exyliagraves.protection.<minutes>` | Cuántos minutos solo el dueño puede abrir sus tumbas. Sin ninguno, `graves.protection-time`. |
| `exyliagraves.experience.<percent>` | El porcentaje de experiencia que guardan sus tumbas (máximo 100). Sin ninguno, `contents.experience-percent`. |
| `exyliagraves.teleport.cost.<amount>` | Lo que cuesta teletransportarse a sus tumbas. Gana el número **más bajo** que tenga el jugador, y solo puede bajar `teleport.cost`. |

En los cuatro primeros gana el número más alto que tenga el jugador, y solo pueden **subir** el valor
configurado: un número por debajo se ignora. Cuando el valor configurado es `-1` (sin límite, nunca caduca,
solo el dueño para siempre) esos nodos no cambian nada. `exyliagraves.*` no concede ninguno de ellos.

## Ejemplos

Tumbas más largas y más tumbas para un rango:

```text
/lp group vip permission set exyliagraves.expire.180 true
/lp group vip permission set exyliagraves.limit.10 true
```

Sin tumbas para un grupo, cuyo contenido cae entonces como siempre:

```text
/lp group hardcore permission set exyliagraves.use false
```

Dejar que los moderadores vean las tumbas de cualquiera sin poder devolverlas ni eliminarlas:

```text
/lp group mod permission set exyliagraves.admin.view true
```
