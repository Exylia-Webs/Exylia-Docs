Los jugadores no necesitan configuración: tener una tumba, la lista, las vistas previas y el teletransporte están permitidos por defecto. Los teletransportes gratis, abrir la tumba de cualquiera y las herramientas de staff son para operadores. Concede un permiso con tu plugin de permisos, por ejemplo `/lp group vip permission set <nodo> true` en LuckPerms.

## Nodos con número

Los cinco nodos con `<n>`, `<minutes>`, `<percent>` o `<amount>` los escribes tú con el número en el nombre, por ejemplo `exyliagraves.expire.180`. No están en `plugin.yml` y `exyliagraves.*` no los concede.

- En límite, caducidad, protección y experiencia gana el número **más alto** que tenga el jugador, y solo puede subir el valor de `config.yml`; un número menor se ignora.
- En el coste del teletransporte gana el número **más bajo**, y solo puede bajar `teleport.cost`.
- Cuando el valor configurado es `-1` (sin límite, nunca caduca, solo el dueño para siempre) los nodos no cambian nada.

```text
/lp group vip permission set exyliagraves.expire.180 true
/lp group vip permission set exyliagraves.limit.10 true
```

Mira [Da a los rangos tumbas más largas o más tumbas](/docs/exyliagraves/rangos) para un ejemplo completo.

## Configuraciones habituales

Sin tumbas para un grupo: su contenido cae entonces como siempre.

```text
/lp group hardcore permission set exyliagraves.use false
```

Moderadores que pueden ver las tumbas de cualquiera pero no devolverlas ni eliminarlas:

```text
/lp group mod permission set exyliagraves.admin.view true
```

<Callout type="warning" title="Resérvalos para el staff">
`exyliagraves.bypass.protection` abre cualquier tumba protegida, y `exyliagraves.admin.remove` borra una tumba con todo lo que contiene.
</Callout>
