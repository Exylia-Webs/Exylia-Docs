Without touching `config.yml`, you give each rank its own numbers with permissions. They only improve on the configured values; they never make them worse.

## Steps

<Steps>
  <Step title="Pick the values you want to improve">
    Look at `graves.expire-time` (60 minutes), `graves.max-per-player` (5), `graves.protection-time` (15 minutes), `contents.experience-percent` (100) and `teleport.cost` (0) in [Configuration](/docs/exyliagraves/configuration).
  </Step>
  <Step title="Grant the numbered nodes">
    With LuckPerms: `/lp group vip permission set exyliagraves.expire.180 true`, `exyliagraves.limit.10`, `exyliagraves.protection.60`, `exyliagraves.experience.100` and `exyliagraves.teleport.cost.50`. The number is part of the node name.
  </Step>
  <Step title="Do not use wildcards">
    `exyliagraves.*` does not include these nodes: write each one.
  </Step>
</Steps>

## Check that it works

Log in as a VIP and die: the hologram's countdown starts at 180 minutes instead of 60. Players without the node still get the configured 60.

## Going further

### What if a player holds several

For limit, expire, protection and experience the largest number wins; for teleport cost the smallest. A number worse than the configured value is ignored, so a rank can never get less than a default player.

### When the configured value is -1

No limit, never expires and owner only forever are already the best values, so these nodes change nothing there.
