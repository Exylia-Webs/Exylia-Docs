title: "Permissions"
description: "Every node the plugin declares, what each one gates, their defaults and children, and the numbered nodes that raise limits and expiry by rank."
---

Every fixed node below is declared in `plugin.yml`. Getting a grave, the list, previews and the teleport
are for everyone by default; free teleports, opening anybody's grave and the staff tools are for
operators.

## Plugin nodes

| Permission | Default | What it gates |
|---|---|---|
| `exyliagraves.use` | everyone | Getting a grave when you die. Without it the drops fall as usual. |
| `exyliagraves.menu` | everyone | `/graves`. |
| `exyliagraves.preview` | everyone | Looking inside a grave you may open: sneak-click it, or right-click it in `/graves`. |
| `exyliagraves.teleport` | everyone | Teleporting to your graves from `/graves`, when `teleport.enabled` is on. |
| `exyliagraves.teleport.free` | operators | That teleport without paying `teleport.cost`. |
| `exyliagraves.bypass.protection` | operators | Opening anybody's grave, protected or not. |
| `exyliagraves.admin.view` | operators | `/gravesadmin list`; looking inside any grave, and teleporting to any grave, free. |
| `exyliagraves.admin.restore` | operators | Handing graves back, from `/gravesadmin list` or with `/gravesadmin restore`. Includes `admin.view`. |
| `exyliagraves.admin.remove` | operators | Removing a grave and everything in it, from `/gravesadmin list`. Includes `admin.view`. |
| `exyliagraves.admin.reload` | operators | `/gravesadmin reload`. |
| `exyliagraves.admin` | operators | Every admin node above. |
| `exyliagraves.*` | operators | Everything: `use`, `menu`, `preview`, `teleport`, `teleport.free`, `bypass.protection` and `admin`. |

## Numbered nodes

Two nodes carry a number. They are not declared in `plugin.yml`; grant them with your permissions plugin.

| Permission | What it does |
|---|---|
| `exyliagraves.limit.<n>` | How many graves the player may have standing on this server. Without one, `graves.max-per-player`. |
| `exyliagraves.expire.<minutes>` | How many minutes their graves last. Without one, `graves.expire-time`. |

For both, the largest number a player holds wins, and they can only **raise** the configured value: a
number below it is ignored. When the configured value is `-1` (no limit, never expires) the nodes change
nothing. `exyliagraves.*` does not grant any of them.

## Examples

Longer graves and more of them for a rank:

```text
/lp group vip permission set exyliagraves.expire.180 true
/lp group vip permission set exyliagraves.limit.10 true
```

No graves for a group, whose drops then fall as usual:

```text
/lp group hardcore permission set exyliagraves.use false
```

Letting moderators look at anybody's graves without handing them back or removing them:

```text
/lp group mod permission set exyliagraves.admin.view true
```
