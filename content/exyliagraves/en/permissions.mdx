Players need no setup: getting a grave, the list, previews and the teleport are allowed by default. Free teleports, opening anybody's grave and the staff tools are for operators. Give a permission with your permissions plugin, for example `/lp group vip permission set <node> true` in LuckPerms.

## Numbered nodes

The five nodes with `<n>`, `<minutes>`, `<percent>` or `<amount>` are written by you with the number in the name, for example `exyliagraves.expire.180`. They are not in `plugin.yml`, and `exyliagraves.*` does not grant them.

- For limit, expire, protection and experience the **largest** number a player holds wins, and it can only raise the value in `config.yml`; a lower number is ignored.
- For teleport cost the **smallest** number wins, and it can only lower `teleport.cost`.
- When the configured value is `-1` (no limit, never expires, owner only forever) the nodes change nothing.

```text
/lp group vip permission set exyliagraves.expire.180 true
/lp group vip permission set exyliagraves.limit.10 true
```

See [Give ranks longer or more graves](/docs/exyliagraves/ranks) for a full example.

## Common setups

No graves for a group: their drops then fall as usual.

```text
/lp group hardcore permission set exyliagraves.use false
```

Moderators who can look at anybody's graves but not hand them back or remove them:

```text
/lp group mod permission set exyliagraves.admin.view true
```

<Callout type="warning" title="Keep these for staff">
`exyliagraves.bypass.protection` opens any protected grave, and `exyliagraves.admin.remove` deletes a grave with everything in it.
</Callout>
