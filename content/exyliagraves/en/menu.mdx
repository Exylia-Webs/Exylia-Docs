## /graves

`/graves` (alias `/grave`, permission `exyliagraves.menu`, everybody by default) opens a paginated screen
with every grave the player has standing — read from the database, so graves on other servers of the
network are there too, with the server they are on. With none, the screen says *"Nothing of yours is
lying around."*

Each grave is a head with:

| Line | Value |
|---|---|
| Name | The world it is in. |
| Server | The server it stands on. |
| Where | Its block coordinates. |
| Items, Experience | How many stacks and how many points it holds. |
| Died | How long ago. |
| Expires in | The time left, or *forever*. Ticks while the screen is open. |
| Protection | Who may open it, as on the hologram. |
| Click hints | Only the actions this viewer may use. |

| Click | What it does |
|---|---|
| Left | Teleport to the grave, when teleporting is on. |
| Right | Look inside, with `exyliagraves.preview`. Same rules as a sneak-click on the head: see [Looking inside](/docs/exyliagraves/graves#looking-inside). |

The screen is `lang/<code>/menus/user/graves.yml`, yours to restyle; its values are listed on
[Configuration](/docs/exyliagraves/configuration#menus).

## Teleporting to a grave

Off by default. Turn it on in `config.yml`:

```yaml title="plugins/ExyliaGraves/config.yml"
teleport:
  enabled: true
  cost: 250
```

A player then left-clicks one of their graves in `/graves` and is taken one block above it, on whichever
server it stands. They need `exyliagraves.teleport` (everybody by default) and must not be in combat.

| Situation | Answer |
|---|---|
| `teleport.enabled` is `false` | *"You cannot teleport to a grave; you have to walk."* |
| No `exyliagraves.teleport` | *"You do not have permission to do that."* |
| Tagged in combat | *"You cannot teleport while in combat. Wait 12s."* |
| Cannot pay | *"Teleporting to a grave costs $250."* |
| It worked | *"Taking you to your grave. Cost: $250."* |

Combat is ExyliaLib's combat tag, which reads DeluxeCombat, PvPManager or a bridge another plugin
registers.

### The cost

`teleport.cost` is charged in ExyliaLib's default currency, the one set as `default-currency` in
`plugins/ExyliaLib/economy.yml`, and written the way that currency writes amounts. `0` is free, and
`exyliagraves.teleport.free` (operators by default) skips it. With a cost above zero and no economy
available, the teleport is refused as if the player could not pay.

The money is taken **before** the teleport starts and given back when it does not arrive — *"The teleport
did not happen, so $250 was refunded."* — followed by why:

| Why | Message |
|---|---|
| The grave is on another server that cannot be reached | *"That server cannot be reached right now."* |
| Its world is not loaded | *"That world is not loaded."* |
| No safe place to land, or any other failure | *"The teleport failed."* |

A teleport to another server goes through ExyliaLib's cross-server teleports, which need Redis. A refund
that itself fails is written to the console with the player and the amount.

Staff with `exyliagraves.admin.view` teleport to anybody's grave from
[`/gravesadmin list`](/docs/exyliagraves/staff), free, whether teleporting is on or not and whether they
are in combat or not.
