Find your symptom, then follow the fix.

## The plugin does not start

`packetevents` is required: without it the server never loads ExyliaCasino. ExyliaLib 1.592.0 or newer is required too; the loader installs it and asks for a restart, and may ask for a second one. A licence error in the console means the key in `loader.yml` is wrong. See [Install ExyliaCasino](/docs/exyliacasino/installation).

## "There is no currency you can bet with"

No economy plugin is installed, or `wager.currencies` in `config.yml` lists none the player may use. Install ExyliaEconomy, Vault with an economy plugin, or PlayerPoints. An empty `wager.currencies` offers every currency. See [Configuration](/docs/exyliacasino/configuration#stakes-wager).

## "Betting is closed for a moment"

The plugin is still reading the bank and the held stakes after a start. It clears itself within seconds. If it stays, check the console for a database error and `database.yml`. See [House bank](/docs/exyliacasino/bank).

## A typed stake or bet is ignored

Roulette, Live Roulette, Sic Bo, Baccarat, Blackjack, Wheel of Fortune, Keno, Horse Race and Crash are shared tables. Their command opens the table screen, and the stake is the chips the player puts on the felt. A stake or option typed in the command does nothing there. See [Tables](/docs/exyliacasino/tables).

## Players cannot play away from a table

**Tables only** is on (`tables.only: true`). Game commands and `/casino` send players to a table. Turn it off under `/casinoadmin`, **Settings**, **Tables**, or place a table for every game. See [Tables](/docs/exyliacasino/tables).

## A table does nothing when clicked

The game of that table is switched off, or the player lacks `exyliacasino.game.<game>`. Open the table in `/casinoadmin` **World tables** and check its game. Someone else playing a solo game makes the table busy. See [Permissions](/docs/exyliacasino/permissions).

## I cannot find `/cadmin`

The admin command is `/casinoadmin` only. The `cadmin` alias is not set on new installs, because ExyliaClans uses it. Servers that had it keep it until they remove it. See [Commands](/docs/exyliacasino/commands).

## Boards are cut at the edges, or too large

Lower `screen.zoom` in `config.yml` to draw every board smaller. On a field of view under 90, lower `screen.max-wide` and `screen.max-tall` (95 and 65 fit every board at 70). See [Configuration](/docs/exyliacasino/configuration#size-screen).

## A player cannot type a command during a round

Only the game's own command and `arena.allowed-commands` work during a round. Add the ones they need, without the slash.

## A win was smaller than expected

The house bank is on and cut the win to its limit. Chat says so. See [House bank](/docs/exyliacasino/bank).

## A change to a command name did nothing

Command names (`casino-command`, `admin-command`, each game's `commands`) need a restart. `/casinoadmin reload` does not apply them.
