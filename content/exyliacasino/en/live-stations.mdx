A live station is a large board standing in the world. It runs one game round after round for everyone near it. Players click the line under the board, choose a stake and a bet, and walk around freely.

## Place one

Look at the block it should stand on and run:

```text
/casinoadmin live create roulette
```

The games are `roulette`, `moneywheel`, `dice` and `coinflip`. Add a size to draw it larger: `/casinoadmin live create dice 2`. The number says how many times a player's own casino screen the board is drawn.

Roulette is the shared roulette table: it opens the same table screen as [Live Roulette](/docs/exyliacasino/games).

## Change one

Stand next to a station, or add its id:

| Command | What it does |
|---|---|
| `/casinoadmin live size [id] <size>` | Redraw it larger or smaller. |
| `/casinoadmin live glow [id]` | Switch the glow of its frame and buttons. |
| `/casinoadmin live remove [id]` | Take it away. Open bets are refunded. |
| `/casinoadmin live list` | List every station. |

## Settings

`live/config.yml` holds the settings of every station.

| Key | Default | What it does |
|---|---|---|
| `enabled` | `true` | Whether stations run. |
| `max-bets` | `3` | Bets one player may have on one round. |
| `radius` | `32` | How near a player must be to see a station. A station nobody is near, with no bet open, stops until someone walks up. |
| `board.magnify` | `1.6` | The default size, used when you give none. |
| `board.history` | `10` | How many last results show under the board. |
| `board.glow` | `true` | Whether frames and buttons glow. |

The sections `money-wheel`, `dice` and `coin` set the times and the look of each game. The `roulette` section is not used any more.

A reload with `/casinoadmin reload` refunds open bets and starts every station again.

<Details title="Technical details">
Stations are saved in `stations.yml`, and each one's size and glow in `stations-look.yml`. The commands write both. Messages are in `live/messages.yml`.
</Details>
