---
title: "Permissions"
description: "The nodes the plugin declares: play, admin, one per game and the largest stake per rank."
---

| Permission | Default | What it gates |
|---|---|---|
| `exyliacasino.play` | everyone | `/casino`, every game's command, `/<game> leave`, and the `casino:play` menu action. |
| `exyliacasino.admin` | operators | `/casinoadmin`, `/casinoadmin reload` and the buttons of the admin hub. |

Every menu action checks its node itself, so copying a button into a screen players can open hands them
nothing they did not already have.

## Per game

Every game has a node, `exyliacasino.game.<id>`, and `exyliacasino.game.*` holds them all. They are `true`
for everyone by default, so nothing changes until you deny one: that is how a game becomes a rank perk.

| Permission | Default | What it gates |
|---|---|---|
| `exyliacasino.game.<id>` | everyone | Starting a round of that game, from its command, `/casino` or `casino:play`. `<id>` is one of `baccarat`, `blackjack`, `coinflip`, `crash`, `doubleornothing`, `hilo`, `horserace`, `keno`, `limbo`, `liveroulette`, `mines`, `plinko`, `roulette`, `scratch`, `sicbo`, `slots`, `tower`, `videopoker`, `wheel`. |
| `exyliacasino.game.*` | everyone | All of the above. |

To make Crash a VIP perk, set `exyliacasino.game.crash` to `false` for the default group and `true` for VIP.
Leaving a round never needs a game node, so a player who loses access mid-round can still walk out.

## Largest stake per rank

| Permission | Default | What it does |
|---|---|---|
| `exyliacasino.maxbet.<n>` | not held | Replaces `wager.maximum` with `<n>` for the player. The highest one held wins, so `exyliacasino.maxbet.5000` in a rank group raises that rank's cap. `exyliacasino.maxbet.0` lifts the cap altogether. |

To keep a game from everybody, switch it off with `enabled: false` in its module file.
