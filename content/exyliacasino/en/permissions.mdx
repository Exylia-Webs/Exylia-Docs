Players can use the casino without any setup: everything a player does is allowed by default. Only `/casinoadmin` is limited to operators. Use this page to restrict games or raise limits.

## Make a game a rank perk

Every game has its own node and everybody holds them. Deny the node to your default group and give it to the rank.

With LuckPerms, to make Crash a VIP game:

```text
/lp group default permission set exyliacasino.game.crash false
/lp group vip permission set exyliacasino.game.crash true
```

A player without the node sees a message that the game is locked. They can still leave a round they are in.

To switch a game off for everyone, set `enabled: false` in `modules/<game>/config.yml` and run `/casinoadmin reload`.

## Raise the largest stake for a rank

`wager.maximum` in `config.yml` is the largest stake for everyone. `exyliacasino.maxbet.<n>` replaces it with `<n>` for the player who holds it, and the highest one held wins.

```text
/lp group vip permission set exyliacasino.maxbet.5000 true
/lp group owner permission set exyliacasino.maxbet.0 true
```

`exyliacasino.maxbet.0` lifts the cap altogether.
