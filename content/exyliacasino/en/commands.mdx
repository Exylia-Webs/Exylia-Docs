Every command, with the permission it needs. Players need `exyliacasino.play`, which everyone has by default. `/casinoadmin` needs `exyliacasino.admin`.

## Solo games

Each solo game has its own command. Type only what you know and the game asks for the rest: `/mines 500 5` starts Mines with a stake of 500 and 5 mines. A stake accepts short forms such as `2.5k`.

<Commands group="player" />

## Shared tables

Roulette, Live Roulette, Sic Bo, Baccarat, Blackjack, Wheel of Fortune, Keno, Horse Race and Crash are played at a table that every player shares. The command sits you at the table. You put chips on the felt there, so a stake typed after the command is not used.

<Commands group="tables" />

## Admin

`/casinoadmin` opens the admin hub. Tables, live stations and the play spot are set with a click in the world: see [Tables](/docs/exyliacasino/tables) and [Live stations](/docs/exyliacasino/live-stations).

<Commands group="admin" />

## Rename a command

`casino-command` and `admin-command` in `config.yml` rename the two main commands. Each game's own names are `commands` in `modules/<game>/config.yml`. The first name is the command, the rest are aliases. Renaming needs a restart.

<Callout type="note">
The admin command has no `cadmin` alias by default, because another plugin uses that name. Servers that had it before keep it unless they remove it.
</Callout>

## Menu actions

For your own menus and NPCs, `casino:play <game>` closes the menu and starts the game like `/<game>` typed alone. It needs `exyliacasino.play`.

<Details title="Technical details">
Leaving never needs a game permission, so a player who loses access mid-round can still walk out. A game that is switched off answers that it is off instead of opening.
</Details>
