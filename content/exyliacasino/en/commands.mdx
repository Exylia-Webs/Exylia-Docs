Three kinds of command: `/casino` opens every game, each game has a command of its own, and
`/casinoadmin`, also `/cadmin`, is for staff. Every name can be changed: `casino-command` and
`admin-command` in `config.yml`, and `commands` in each game's module file. Renaming needs a restart.

## Player commands

Every command here needs `exyliacasino.play`, which everybody has by default, and runs for players only.

| Command | What it does |
|---|---|
| `/casino` | Opens the casino category of the games screen: every game the server has on, with its RTP and the players at it. |
| `/<game>` | Starts the game, asking for the currency, the stake and the game's option. |
| `/<game> <stake>` | Starts it at that stake, asking only for the option. |
| `/<game> <stake> <option>` | Starts it with nothing left to ask. |
| `/<game> leave` | Leaves the round as it stands: a round under way is forfeited, one not yet started is refunded. |

`/doubleornothing` takes no stake: the stake is the item in the player's main hand.

| Game | Commands | Option |
|---|---|---|
| Mines | `/mines` | mines on the board, `1` to `24` |
| Tower | `/tower` | `easy`, `medium`, `hard`, `expert` |
| Crash | `/crash` | optional auto cash-out, such as `2.5` |
| Hi-Lo | `/hilo`, `/highlow` | — |
| Double or Nothing | `/doubleornothing`, `/don` | — |
| Blackjack | `/blackjack`, `/bj` | — |
| Baccarat | `/baccarat`, `/punto` | `player`, `banker`, `tie` |
| Video Poker | `/videopoker`, `/vpoker` | — |
| Roulette | `/roulette` | `0`–`36`, `red`, `black`, `even`, `odd`, `low`, `high`, `dozen_1`–`3`, `column_1`–`3` |
| Live Roulette | `/liveroulette`, `/lroulette` | as Roulette |
| Wheel of Fortune | `/wheel`, `/fortune` | — |
| Coinflip | `/coinflip`, `/cf` | `heads`, `tails` |
| Slots | `/slots`, `/slot` | — |
| Plinko | `/plinko` | `low`, `medium`, `high` |
| Keno | `/keno` | — |
| Scratch Card | `/scratch`, `/scratchcard` | — |
| Horse Race | `/horserace`, `/race` | the horse's number or name |

Examples: `/mines 500 5`, `/roulette 100 red`, `/crash 250 3`, `/horserace 100 Comet`. A stake accepts the
economy's short forms, such as `2.5k`. See [Games](/docs/exyliacasino/games) for what each option means.

## Admin commands

Every command here needs `exyliacasino.admin`, operators by default.

| Command | Console | What it does |
|---|---|---|
| `/casinoadmin` | | Opens the admin hub: games switched on out of the total, players in a round right now, followed live, and a reload button. |
| `/casinoadmin reload` | yes | Reads `config.yml`, every module file and the messages again, re-registers the games on `/casino` and reloads the menus. Answers with how many parts were reloaded and how long it took. |

## Menu actions

For a server's own menus and NPCs:

| Action | What it does |
|---|---|
| `casino:play <game>` | Closes the menu and starts the game, as `/<game>` typed alone. Needs `exyliacasino.play`. |
