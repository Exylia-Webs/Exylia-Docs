A table is a block or an NPC that opens one game when a player clicks it. Players can also play from `/casino` without any table. Place tables when you want the casino to be a place on your server.

## Place a table

<Steps>
  <Step title="Open the table list">
    Run `/casinoadmin` and click **World tables**, or run `/casinoadmin tables`.
  </Step>
  <Step title="Pick the game">
    Click to place a table, then choose the game.
  </Step>
  <Step title="Click where it goes">
    Click the block or the NPC that should open the game. The chat confirms that the table is placed.
  </Step>
</Steps>

Or run `/casinoadmin table create <game>` and click the block. Add an id after the game to name the table: `/casinoadmin table create blackjack vip`.

A floating label shows the game, whether the table is free and "Click to play". It shows the player's name while the table is in use.

## Edit a table

Click a table in the list, or stand next to it and run `/casinoadmin table edit`. The screen lets you:

- **Move** the table to another block or NPC.
- Change its **Game**.
- Turn the **Hologram** on or off.
- **Teleport** to it.
- **Remove** it, after a confirmation. Games being played are not stopped.

## One player or everybody

A solo game such as Mines or Slots belongs to one player at a time. Anyone else who clicks it is told the table is taken.

Nine games are shared tables: Roulette, Live Roulette, Sic Bo, Baccarat, Blackjack, Wheel of Fortune, Keno, Horse Race and Crash. Everyone who sits at the table plays the same throw. A table placed in the world is its own table. Players who open the game from `/casino` or its command join one table that the whole server shares.

### How a round runs

1. The first chip a player puts down opens betting.
2. Each player presses **READY** when done. **REPEAT** puts down the chips of the last round again.
3. The throw goes as soon as everyone with chips down is ready, or when the `betting` time ends. That time starts when the first player presses READY.
4. The result shows for the `pause` time, then the next round opens.

A player who was not ready keeps their chips for the next round. Players without chips only watch. Every chip is held separately, so a chip taken off before the throw is refunded. If the server stops, the held chips are refunded on the next start.

The times and the chips on offer are in each game's `modules/<game>/config.yml`: `betting`, `pause`, `chips` and `max-chips` (20 by default). See [Games](/docs/exyliacasino/games).

## Only at tables

Turn on **Tables only** in the admin hub, under Settings, then Tables. You can also set `tables.only: true` in `config.yml`. Game commands and `/casino` then send players to a table. Use it when you have placed tables for every game you want to offer.

<Callout type="note">
`tables.reach`, `tables.watch-radius` and `tables.busy-lift` appear in `config.yml` but do nothing in this version. Leave them alone.
</Callout>

<Details title="Technical details">
Tables are saved in `plugins/ExyliaCasino/tables.yml`. The commands write it, so do not edit it by hand. The click spots come from ExyliaLib. `tables.ahead` is how far the label stands in front of the table.
</Details>
