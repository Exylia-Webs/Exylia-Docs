`config.yml` holds what every game shares. Each game's own settings are in `modules/<game>/config.yml`,
described on [Games](/docs/exyliacasino/games). Times are written `30s`, `5m` or `1h30m`; colours use
palette tokens such as `{primary}`, and glow colours take a token or `#rrggbb`. Apply a change with
`/casinoadmin reload`, except where a key says it needs a restart.

## Language

| Key | Default | What it does |
|---|---|---|
| `language` | `default` | `default` follows the language set in ExyliaLib's `config.yml`; a code such as `en`, `es`, `ru` or `tr` sets this plugin alone. Each is a folder under `lang/` you can edit. |
| `debug` | `false` | Explains in the console what the plugin is doing. |

## Stakes: `wager`

| Key | Default | What it does |
|---|---|---|
| `wager.currencies` | `[]` | Currencies a bet may use, by their ExyliaLib id. Empty offers every currency the player may use. |
| `wager.minimum` | `10` | Smallest stake a player may bet. |
| `wager.maximum` | `0` | Largest stake. `0` for no limit. |
| `wager.cooldown` | `1s` | Time between two rounds started, so a stake is never charged twice by a double click. |

<Callout type="warning" title="Only currencies earned by playing">
List only currencies players earn in game. Never offer a currency bought with real money.
</Callout>

## While they play: `arena`

| Key | Default | What it does |
|---|---|---|
| `arena.allowed-commands` | `[msg, r, tell]` | Commands a player may still type during a round, without the slash. The game's own command always works, so `/<game> leave` does. |
| `arena.freeze` | `true` | Holds players still where they play, so their table stays in front of them. |

## The table look: `casino`

Shared by every table.

| Key | Default | What it does |
|---|---|---|
| `casino.table-block` | `BLACK_CONCRETE` | The felt behind every board. |
| `casino.frame-block`, `casino.frame-glow` | `PURPLE_CONCRETE`, `{primary}` | The frame round it, and its neon outline. |
| `casino.button-block`, `casino.button-glow` | `GRAY_CONCRETE`, `{secondary_light}` | What buttons are made of, and their outline under the crosshair. |
| `casino.rain-item`, `casino.rain-count` | `GOLD_NUGGET`, `18` | A win rains this item over the board, this many. `0` for none. |
| `casino.fireworks`, `casino.win-colours` | `true`, `[{highlight}, {success}, {secondary}]` | A win sets off fireworks only the winner sees, in these colours. |
| `casino.marquee` | `true` | Casino bulbs round every table's frame, a wave of light running along them; they blink together on a win. Off draws no bulbs. |
| `casino.marquee-block`, `casino.marquee-glow` | `OCHRE_FROGLIGHT`, `{highlight}` | The bulb block and its glow. |
| `casino.marquee-spacing`, `casino.marquee-cycle` | `0.3`, `1400ms` | The space between two bulbs in blocks, and how long a crest of light takes to run six bulbs on. |
| `casino.verdict-block` | `BLACK_CONCRETE` | The plaque a finished game's verdict lands on, over the heading. |
| `casino.verdict-win`, `-lose`, `-draw` | `{success}`, `{error}`, `{warning}` | Its outline on a win, a loss and a draw. |

## When a round ends: `again`

| Key | Default | What it does |
|---|---|---|
| `again.enabled` | `true` | Shows AGAIN, CHANGE BET and LEAVE when a money round ends. Off sends the player away. |
| `again.delay` | `1500ms` | How long the result shows before the buttons come up. |
| `again.timeout` | `15s` | How long the buttons wait for an answer. |
| `again.distance`, `again.lift` | `1.7`, `-0.95` | Where they stand, in blocks: ahead of the eyes, and above eye level (negative is below). Under a board that reaches lower they drop until they clear its edge. |
| `again.hover-sound`, `again.press-sound` | `BLOCK_NOTE_BLOCK_HAT\|0.4\|1.8`, `UI_BUTTON_CLICK\|0.6\|1.2` | The crosshair over a button, and a button pressed. |

## Size: `screen`

One zoom for every board, so a server makes them all bigger or smaller at once.

| Key | Default | What it does |
|---|---|---|
| `screen.zoom` | `2.4` | How many times nearer, and so larger, every board is drawn than its game's own distance says. `1` draws them as each game's file places them. |
| `screen.max-wide`, `screen.max-tall` | `110`, `80` | A board never spans more than this many degrees across, or up and down: it stops growing there. The defaults fill a 90 FOV screen; on 70 the tallest boards are cut at the edges. Lower them (95 and 65) to fit every board at 70. |
| `screen.nearest` | `1.5` | The nearest a board may come to the eyes, in blocks. |

## The room: `booth`

A closed dark room drawn round a player while they play, only for them, so they see the board and nothing
of the world behind it. Other players are hidden from them meanwhile.

| Key | Default | What it does |
|---|---|---|
| `booth.enabled` | `true` | Draws the room. Off, the board stands in the open world; the blocks round the player are still cleared and other players still hidden. |
| `booth.block`, `booth.floor` | `BLACK_CONCRETE`, `true` | The block of its walls, ceiling and floor, and whether it has a floor (off shows the ground). |
| `booth.reach`, `booth.ceiling` | `4.5`, `3.5` | How far from the eyes the walls stand, and how far above the eyes the ceiling is. |
| `booth.stars`, `booth.star-colours`, `booth.star-scale` | `40`, `[{secondary}, {secondary_light}, {letters}]`, `0.32` | Faint twinkling stars on the walls and ceiling: how many (`0` for none), their colours and their size. |

## The guide: `guide`

How the game is played on the player's left and what it pays on their right, a turn of the head away.

| Key | Default | What it does |
|---|---|---|
| `guide.enabled` | `true` | Off shows no panels. |
| `guide.distance`, `guide.lift` | `1.9`, `0.05` | Where they stand: away from the eyes, and above eye level. |
| `guide.scale` | `0.42` | How big their text is drawn; titles are drawn larger. |

## Command names

| Key | Default | What it does |
|---|---|---|
| `casino-command` | `[casino]` | Names of the command that opens the casino. The first is the command. Needs a restart. |
| `admin-command` | `[casinoadmin, cadmin]` | Names of the admin command; the first is the command, the rest aliases. Needs a restart. |

Each game's command is set by `commands` in its own module file.

## Messages and menus

Every line a player reads is in `lang/<language>/messages.yml` (stakes, results, the heading over every
table, the AGAIN buttons, the `/casino` cards, the admin lines) and in each game's
`lang/<language>/modules/<game>/messages.yml`. Colours are palette tokens, so recolouring the server never
means editing them. A message may open with an effect tag that never reaches the screen:
`[sound:NAME|volume|pitch]` plays a sound, `[center]` centres the line. `%prefix%` is replaced by the
`prefix` value; an empty message is not sent.

The casino's card on the games screen is `catalog` in `messages.yml`: its `icon`, `name`, `description`,
and the `mode` line under every game's card, which takes `%rtp%`.
