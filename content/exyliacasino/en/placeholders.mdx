---
title: "Placeholders"
description: "Every placeholder the plugin answers: whether the viewer is playing, their record at each game, and the players at each game."
---

The plugin registers its placeholders through ExyliaLib under the group `exyliacasino`, so the name is the
same inside Exylia plugins' own files and through **PlaceholderAPI**: `%exyliacasino_playing%`. Nothing has
to be downloaded from the eCloud. Every value is read from memory.

`<game>` is a game's id: `mines`, `roulette`, `liveroulette`, `coinflip`, `doubleornothing`, `scratch`,
`horserace`, `crash`, `plinko`, `slots`, `wheel`, `blackjack`, `tower`, `keno`, `videopoker`, `hilo` or
`baccarat`. The id never changes when the game's commands or name do.

## The viewer

| Placeholder | Value |
|---|---|
| `%exyliacasino_playing%` | Whether the viewer is in a round: `true` or `false`. |
| `%exyliacasino_<game>_wins%` | Rounds of that game the viewer won. |
| `%exyliacasino_<game>_losses%` | Rounds they lost. |
| `%exyliacasino_<game>_played%` | Wins and losses together. |
| `%exyliacasino_<game>_win_rate%` | Wins out of rounds played, as a percentage. |

A round counts as a **win** when it paid more than the stake and as a **loss** when it paid less. A round
that gave the stake back counts as neither.

## The server

| Placeholder | Value |
|---|---|
| `%exyliacasino_<game>_playing%` | Players in a round of that game right now. |

## Examples

```text
%exyliacasino_blackjack_wins%
%exyliacasino_mines_win_rate%
%exyliacasino_liveroulette_playing%
```
