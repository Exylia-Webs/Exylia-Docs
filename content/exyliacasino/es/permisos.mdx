## Convertir un juego en ventaja de rango

Cada juego tiene su propio nodo y todos lo tienen. Niégalo al grupo por defecto y dáselo al rango.

Con LuckPerms, para que Crash sea un juego VIP:

```text
/lp group default permission set exyliacasino.game.crash false
/lp group vip permission set exyliacasino.game.crash true
```

Quien no tiene el nodo ve un mensaje de que el juego está bloqueado. Aun así puede salir de una ronda en la que ya esté.

Para apagar un juego para todos, pon `enabled: false` en `modules/<juego>/config.yml` y ejecuta `/casinoadmin reload`.

## Subir la apuesta máxima de un rango

`wager.maximum` en `config.yml` es la apuesta máxima para todos. `exyliacasino.maxbet.<n>` la sustituye por `<n>` para quien lo tenga, y gana el más alto.

```text
/lp group vip permission set exyliacasino.maxbet.5000 true
/lp group owner permission set exyliacasino.maxbet.0 true
```

`exyliacasino.maxbet.0` quita el límite por completo.
