## The plugin does not load at all

You need **Paper or Folia 1.21.9 or newer**; an older server refuses the jar with an `api-version` error. The plugin also needs ExyliaLib to run: without it you will not see `ExyliaPracticeBotV3 enabled!` in the console. See [Installation](/docs/exyliapracticebot/installation).

## Does the plugin need PacketEvents?

No. It is optional, and without it only the extras ExyliaLib draws with packets stay off.

## "You can't spawn a bot in this world"

The world is not in the `worlds` list in `config.yml`. The list ships with Exylia's `exylia_sandbox_*` worlds, so on any other server put your own world names there; an empty list allows nothing. Run `/botadmin reload` afterwards. See [Configuration](/docs/exyliapracticebot/configuration).

## "You already have a bot. Use /bot remove first."

A player's own `/bot` is limited to one bot. Run `/bot remove` or click the red button on the menu. Bots another plugin spawns for a match do not count against it.

## "The server is already running N bots"

That is `max-bots` (`16` by default). Every bot thinks and pathfinds every tick, so raise it only after watching your tick time with the current number running. See [Limits](/docs/exyliapracticebot/limits).

## My bot vanished on its own

It was removed because you died, changed worlds, or went more than `200` blocks from the player it was fighting; each one sends its own message. If you logged out or were kicked it goes silently. See [Behaviour](/docs/exyliapracticebot/behaviour).

## Do bots survive a restart?

No. Every bot is removed on shutdown, and none are saved with the world, so a crash cannot leave one behind.

## Do my settings survive a restart?

Yes. Mode, difficulty, gear and every slider are saved per player in the plugin's database table, and written the moment you change them. `/bot reset` puts them back to the server defaults. See [Configuration](/docs/exyliapracticebot/configuration).

## Can two players share a bot?

No. A bot fights its owner only, and only the owner can open its menu with shift right-click. Another plugin can retarget a bot through the [API](/docs/exyliapracticebot/api).

## Why did my bot come back after I killed it?

`respawn.enabled` is on, with a `2.0` second delay. Turn it off to keep a killed bot gone until you spawn another. See [Behaviour](/docs/exyliapracticebot/behaviour).

## Nothing I do kills it

`advanced.health.invincible` is on, or the totems are: `advanced.health.totems` is `-1`, which means unlimited. Both are on the fine-tuning screen of `/bot`. See [Difficulty](/docs/exyliapracticebot/difficulty).

## Where did the death message go when the bot killed me?

It is hidden on purpose: a training dummy killing someone is not server news.

## Does it work on Folia?

Yes, on Folia 1.21.9 or newer.

## Where do I get support?

On the [Exylia Discord](https://discord.exylia.net). Check [Common problems](/docs/exyliapracticebot/troubleshooting) first.
