title: "Configuración"
description: "config.yml clave por clave, qué contienen templates.yml, boosts.yml y messages.yml, los archivos de menú, y dónde se define la base de datos."
---

Todo se genera en `plugins/ExyliaMines/` en el primer arranque, con comentarios. Edita los archivos de ahí,
nunca las copias del jar, y aplícalos con `/minesadmin reload`. Cualquier duración acepta un número de
segundos a secas o la forma escrita: `300`, `5m`, `1h30m`.

Las minas en sí no están en ningún archivo: viven en la base de datos y se editan desde `/minesadmin`.

## config.yml

```yaml title="plugins/ExyliaMines/config.yml"
language: default
debug: false
settings:
  default-reset-interval-seconds: 300
  default-reset-warning-seconds: 10
  classic-tick-interval-seconds: 1
  realistic-tick-interval-seconds: 1
  default-realistic-regen-seconds: 60
  clean-entities-on-reset: true
sounds:
  reset: ENTITY_ENDER_DRAGON_GROWL|0.6|1.4
  enter: BLOCK_BEACON_ACTIVATE|1.0|1.4
  block-mined: ''
announcements:
  reset: NEARBY
  radius: 64
  lucky: NEARBY
  boosts: SERVER
fortune:
  mode: VANILLA
  target: ITEMS
  per-level: 0.25
  lucky-per-level: 0.0
  max-level: -1
  silk-touch: true
```

### Nivel superior

| Clave | Por defecto | Qué hace |
|---|---|---|
| `language` | `default` | El idioma de los menús y los mensajes. `default` sigue el idioma definido en el `config.yml` de ExyliaLib; `en`, `es` o `pt` lo fijan solo para este plugin. Cada uno es una carpeta bajo `lang/` que puedes editar. |
| `debug` | `false` | Explica en consola lo que hace el plugin, por ejemplo como quién se ejecuta un comando de botín. |

### settings

| Clave | Por defecto | Qué hace |
|---|---|---|
| `default-reset-interval-seconds` | `300` | El intervalo de reinicio con el que empieza una mina clásica nueva. Después cada mina tiene el suyo. |
| `default-reset-warning-seconds` | `10` | El aviso con el que empieza una mina clásica nueva. |
| `classic-tick-interval-seconds` | `1` | Cada cuánto se revisan las minas clásicas por si toca un relleno o se ha alcanzado el umbral. |
| `realistic-tick-interval-seconds` | `1` | Cada cuánto se revisan las minas realistas por si hay bloques que regenerar. |
| `default-realistic-regen-seconds` | `60` | El tiempo de regeneración con el que empieza un nivel nuevo de una mina realista. |
| `clean-entities-on-reset` | `true` | Quita los objetos tirados, orbes de experiencia, proyectiles, vagonetas, cristales del End y fuegos artificiales dentro de una mina clásica cuando se rellena. |

Los dos intervalos de tick son de al menos un segundo. Las cuentas atrás que leen los jugadores — barras de
jefe, hologramas — se redibujan cada segundo digan lo que digan.

### sounds

Cada uno se escribe `NOMBRE|volumen|tono`. Un valor vacío no reproduce nada.

| Clave | Por defecto | Suena |
|---|---|---|
| `reset` | `ENTITY_ENDER_DRAGON_GROWL\|0.6\|1.4` | A los jugadores dentro de una mina clásica cuando ha terminado de rellenarse. |
| `enter` | `BLOCK_BEACON_ACTIVATE\|1.0\|1.4` | Cuando un jugador entra en una mina clásica. |
| `block-mined` | `''` | A quien rompe un bloque de una mina realista. |

### announcements

| Clave | Por defecto | Qué hace |
|---|---|---|
| `reset` | `NEARBY` | A quién se le dice en el chat que una mina clásica se ha rellenado: `OFF`, `NEARBY` o `SERVER`. |
| `radius` | `64` | A qué distancia de la mina lo oye un jugador con `NEARBY`, en bloques. |
| `lucky` | `NEARBY` | A quién se le dice que alguien ha encontrado un premio de suerte. Se mide desde el bloque. |
| `boosts` | `SERVER` | A quién se le dice que un potenciador ha empezado o terminado. Se mide desde cada mina que cubre. |

### fortune

| Clave | Por defecto | Qué hace |
|---|---|---|
| `mode` | `VANILLA` | Cómo cambia Fortune el botín propio: `OFF`, `VANILLA`, `LINEAR` o `CHANCE`. |
| `target` | `ITEMS` | Qué multiplica el modo: `ITEMS`, `MONEY` o `BOTH`. |
| `per-level` | `0.25` | Lo que suma cada nivel con `LINEAR` y `CHANCE`. |
| `lucky-per-level` | `0.0` | Lo que suma cada nivel a la probabilidad de los premios de suerte. |
| `max-level` | `-1` | El nivel de Fortune más alto que cuenta en las minas. `-1` cualquiera, `0` ninguno. |
| `silk-touch` | `true` | Si Silk Touch funciona en las minas. |

Una mina puede sobrescribir `mode`, `max-level` y `silk-touch` para sí misma. Ver
[Fortuna](/docs/exyliamines/fortuna).

## templates.yml

Los puntos de partida que ofrece **Crear desde plantilla**, por id:

| Clave | Qué es |
|---|---|
| `name` | Cómo llama el menú a la plantilla, y el nombre que recibe la mina nueva. |
| `icon` | El material que muestra el menú, y el icono de la mina nueva. |
| `type` | `CLASSIC` o `REALISTIC`. |
| `blocks` | Material y peso. Una plantilla clásica se convierte en esta composición; una realista crea un nivel por material e ignora los pesos. |
| `regen` | El tiempo de regeneración de cada nivel de una plantilla realista. |

Vienen seis por defecto: `coal`, `iron`, `gold`, `diamond`, `nether` y `ores`. Ver
[Minas](/docs/exyliamines/minas).

## boosts.yml

Dos secciones: `boosts`, cada potenciador por id con su `name`, `drops`, `experience`, `money`, `duration` y
`mines`; y `schedule`, las entradas que los arrancan solos, cada una con `boost`, `days`, `times` y
`min-players`. Vienen dos potenciadores y una entrada de horario por defecto. Ver
[Potenciadores](/docs/exyliamines/potenciadores).

## messages.yml

`lang/<idioma>/messages.yml` contiene cada línea que envía el plugin. Las claves de nivel superior son las
líneas de chat y las etiquetas de los menús; después vienen las secciones:

| Sección | Qué contiene |
|---|---|
| `lucky` | El anuncio, el título de quien lo encuentra, cómo se llama un premio de comando, el título del editor. |
| `boosts` | Inicio, fin, detenido, las líneas de la lista, el nombre del potenciador personalizado, las etiquetas del menú y la barra de jefe dentro de una mina potenciada. |
| `potions` | El título del editor de efectos de poción. |
| `fortune` | Cómo se lee cada ajuste de Fortune en el menú de una mina. |
| `holograms` | Las líneas sobre una mina clásica y sobre una realista. Ver [Hologramas](/docs/exyliamines/hologramas). |
| `visuals` | El título de aviso de reinicio, la barra de jefe de la cuenta atrás, el título de entrada y la barra de "próximo reinicio". |

Los colores usan tokens de paleta como `{primary}`, `{error}` o `{highlight}`, así que recolorear el servidor
nunca obliga a editar este archivo. `%prefix%` se sustituye por el valor `prefix` de arriba. Una línea puede
empezar con una etiqueta de efecto que nunca llega a la pantalla: `[sound:NOMBRE|volumen|tono]` reproduce un
sonido a quien la recibe. Una línea vacía no envía nada, que es como se apaga; un título o una barra de jefe
con `text` vacío no se muestra.

Los valores que admite cada línea están escritos en el comentario que tiene encima. Dos que conviene saber:

- `visuals.bossbar` recibe `%next_reset%` como un número de **segundos** — el valor por defecto lo termina
  con `s` — mientras que el holograma y los menús lo reciben escrito, `4m 12s`.
- `visuals.reset-bossbar` cuenta atrás con `%time%`, y `visuals.reset-warning-title` con `%seconds%`.

## Menús

| Archivo | Pantalla |
|---|---|
| `lang/<idioma>/menus/user/mines.yml` | La lista `/mines` de los jugadores. Tuya para cambiarle el estilo. Ver [Menú de jugadores](/docs/exyliamines/menu-de-jugadores). |
| `lang/<idioma>/menus/admin/mine_list.yml` | La lista de minas de `/minesadmin`. |
| `lang/<idioma>/menus/admin/mine_templates.yml` | Las plantillas. |
| `lang/<idioma>/menus/admin/mine_setup_classic.yml` | La vista general de una mina clásica. |
| `lang/<idioma>/menus/admin/mine_setup_realistic.yml` | La vista general de una mina realista. |
| `lang/<idioma>/menus/admin/mine_setup_general.yml` | Nombre, icono, permiso. |
| `lang/<idioma>/menus/admin/mine_setup_area.yml` | Región, forma, holograma. |
| `lang/<idioma>/menus/admin/mine_setup_resets.yml` | Intervalo, aviso, umbral, reinicio forzado. |
| `lang/<idioma>/menus/admin/mine_setup_teleports.yml` | Teletransportes de entrada y seguro, liberar enterrados. |
| `lang/<idioma>/menus/admin/mine_setup_rewards.yml` | Premios de suerte, Fortune, potenciador. |
| `lang/<idioma>/menus/admin/mine_setup_mining.yml` | Autorrecoger, restringir rotura, efectos al romper y de poción. |
| `lang/<idioma>/menus/admin/mine_composition.yml` | La composición de una mina clásica. |
| `lang/<idioma>/menus/admin/mine_levels.yml` | Los niveles de una mina realista. |
| `lang/<idioma>/menus/admin/mine_level_detail.yml` | Un nivel. |
| `lang/<idioma>/menus/admin/mine_level_chain.yml` | La cadena de degradación de un nivel. |

Las pantallas de `admin/` se reescriben desde el jar en cada arranque; lo que edites ahí se pierde.

## Base de datos

`database.yml` es de ExyliaLib: H2 por defecto, o `mysql`, `mariadb`, `postgresql` y `mongodb`. Ver
[Instalación](/docs/exyliamines/instalacion) para las cinco tablas y la
[página de base de datos de la librería](/docs/exylialib/base-de-datos) para cada clave.
