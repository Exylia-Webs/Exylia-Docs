Every placeholder below is written in full, and clicking one copies it.

## How the name is written

The plugin registers its placeholders through ExyliaLib as the group `mine`. Inside an Exylia plugin's own
files — menus, `messages.yml`, another Exylia plugin's scoreboard — the registered name stands on its own:

```text
%mine_reset_coal%
```

Through **PlaceholderAPI**, for any other plugin, the plugin's name goes in front of it:

```text
%exyliamines_mine_reset_coal%
```

This page writes the PlaceholderAPI form throughout; drop `exyliamines_` for the in-plugin one. Nothing has
to be downloaded from the eCloud.

`<id>` is a mine's id. Ids may contain underscores — `%exyliamines_mine_reset_iron_cave%` reads the mine
`iron_cave` — and in the `top` placeholders the place is always the last number.

Durations are written out in full, `4m 12s`.

## About a mine

| Placeholder | Description |
|---|---|
| `%exyliamines_mine_name_<id>%` | Its display name; empty for an unknown id. |
| `%exyliamines_mine_reset_<id>%` | Time until it refills, or `-` for a realistic, disabled, unknown or unset mine. |
| `%exyliamines_mine_reset_seconds_<id>%` | The same in seconds, `-1` when there is no refill to count down to. |
| `%exyliamines_mine_remaining_<id>%` | The share still standing, `0` to `100`. |
| `%exyliamines_mine_blocks_<id>%` | Blocks everybody has mined there, as of the last minute's read. |
| `%exyliamines_mine_top_name_<id>_<place>%` | The player at that place of its top ten, from `1`, or `—`. |
| `%exyliamines_mine_top_blocks_<id>_<place>%` | Their blocks, or `0`. |
| `%exyliamines_mine_boost_<id>%` | The drop multiplier of every boost running on it combined, `1` when none is. |
| `%exyliamines_mine_boost_name_<id>%` | The name of the boost on it that ends last, or `—`. |
| `%exyliamines_mine_boost_time_<id>%` | Time left on that boost, or `—`. |
| `%exyliamines_mine_count%` | How many mines are enabled on this server. |

Only classic mines have a refill to count down to: a realistic mine grows each block back on its own, so
its countdown is `-` rather than a number that would never arrive.

## About the reader

These answer for the player looking at them.

| Placeholder | Description |
|---|---|
| `%exyliamines_mine_current%` | The display name of the mine they are standing in, or `—`. |
| `%exyliamines_mine_current_id%` | Its id, or `—`. |
| `%exyliamines_mine_time%` | Seconds they have been inside it, `0` outside. |
| `%exyliamines_mine_player_blocks%` | Blocks they have mined in every mine. |
| `%exyliamines_mine_player_blocks_<id>%` | Blocks they have mined in one mine. |

"Standing in" means a mine they have access to: a player inside a mine whose permission they lack is in
none, as far as these placeholders go.

## Examples

A leaderboard for the `coal` mine in a hologram plugin:

```text
#1 %exyliamines_mine_top_name_coal_1% — %exyliamines_mine_top_blocks_coal_1%
#2 %exyliamines_mine_top_name_coal_2% — %exyliamines_mine_top_blocks_coal_2%
#3 %exyliamines_mine_top_name_coal_3% — %exyliamines_mine_top_blocks_coal_3%
```

A scoreboard line that follows the player from mine to mine:

```text
Mine: %exyliamines_mine_current% (%exyliamines_mine_time%s)
```

<Callout type="note" title="The hologram over a mine does not use these">
The status hologram and the `/mines` menu fill their own values — `%mine_name%`, `%remaining%`,
`%next_reset%` — which are not placeholders and only work there. See
[Holograms](/docs/exyliamines/holograms#its-lines).
</Callout>
