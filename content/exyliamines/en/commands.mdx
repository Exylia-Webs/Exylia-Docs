Three roots. `/mines` and `/mine` are the players'; `/minesadmin` is staff's and opens the editor every mine
is built in.

## Player commands

| Command | Permission | What it does |
|---|---|---|
| `/mines` | `exyliamines.menu` | Opens the list of enabled mines. Players only. |
| `/mine <id>` | `exyliamines.teleport` | Sends the player to the mine's entry point. Tab completion suggests every enabled mine. Players only. |

`/mine` checks that the mine exists and is enabled, that the player may enter it, that it has an entry
point and that the player is not in combat, in that order. See
[Players' menu](/docs/exyliamines/players-menu#going-to-a-mine).

## Staff commands

Everything below needs `exyliamines.admin`.

| Command | What it does |
|---|---|
| `/minesadmin` | Opens the list of mines: create, edit, delete. Players only. |
| `/minesadmin reload` | Reloads the files. |
| `/minesadmin import <catamines\|realmines>` | Imports that plugin's mines. See [Migration](/docs/exyliamines/migration#from-catamines-or-realmines). |
| `/minesadmin boost start <id>` | Starts a boost from `boosts.yml`; one already running starts over. |
| `/minesadmin boost custom <multiplier> <duration> [mines]` | Starts a boost typed out: `1.2 30m gold,iron`. No mines means every mine. |
| `/minesadmin boost stop <id\|all>` | Ends one running boost, or all of them. |
| `/minesadmin boost list` | Lists the running boosts. |

Everything but the bare `/minesadmin` also runs from the console. Tab completion offers the boosts of
`boosts.yml` to `start`, the running ones and `all` to `stop`, and the enabled mines to `custom`. See
[Boosts](/docs/exyliamines/boosts).

### What reload does

`/minesadmin reload` runs five named steps and reports how many ran and in how many milliseconds:

| Step | What it does |
|---|---|
| `configs` | Reads `config.yml`, `templates.yml`, `boosts.yml` and `messages.yml` again, then the prefix and the debug switch. A changed `language` applies here. |
| `timers` | Restarts the mine clocks, so a changed `classic-tick-interval-seconds` or `realistic-tick-interval-seconds` applies. |
| `boosts` | Applies the schedule of `boosts.yml` again. |
| `holograms` | Redraws every hologram with the lines as they are now. |
| `menus` | Compiles every menu again. |

The `menus` step also runs when ExyliaLib itself is reloaded, so a recoloured palette reaches the menus.

Reload does **not** touch the mines. They live in the database and are edited from `/minesadmin`, where a
change applies the moment it is made.

<Callout type="note" title="Everything else is in the editor">
There is no command to create, edit, reset or delete a mine. All of it — the area, the composition, the
levels, the reset times, a forced reset — is a button in `/minesadmin`. See
[Mines](/docs/exyliamines/mines).
</Callout>
