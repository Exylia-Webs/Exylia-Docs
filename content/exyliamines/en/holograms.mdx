---
title: "Holograms"
description: "The status hologram over a mine: placing it, its lines, and what each value means."
---

Each mine can have a hologram over it that says what state it is in: how much of it is still standing and,
for a classic mine, when it refills next.

## Placing it

**Area** → **Hologram** on the setup screen, then stand where it should go and confirm. The text floats
about two blocks above the spot you stood on, at eye level. Shift-left-click on the same button takes it
down.

The hologram is drawn with packets through ExyliaLib, so it needs **packetevents** — which the plugin
requires anyway — and nothing else: no hologram plugin, no entities in the world. A disabled mine shows no
hologram.

## Its lines

The lines are in `messages.yml`, one list for each kind of mine:

```yaml title="plugins/ExyliaMines/lang/en/messages.yml"
holograms:
  classic:
    - '{primary}&l%mine_name%'
    - '{letters}Remaining {letters_black}» {info}%remaining%%'
    - '{letters}Next reset {letters_black}» {info}%next_reset% ⌚'
  realistic:
    - '{primary}&l%mine_name%'
    - '{letters}Standing {letters_black}» {info}%remaining%%'
    - '{letters}Blocks grow back one by one'
```

| Value | What it is |
|---|---|
| `%mine_name%` | The display name. |
| `%mine_id%` | The id. |
| `%mine_type%` | `type-classic` or `type-realistic` from `messages.yml`: "Classic", "Realistic". |
| `%remaining%` | The share of the mine still standing, from 0 to 100. |
| `%next_reset%` | Time until the next refill, written out: `4m 12s`. For a realistic mine, `per-block`, "Per block". |
| `%total_blocks%` | Blocks mined there by everybody, as of the last minute's read. |
| `%boost%` | The boost on the mine, as `boosts.menu-active` writes it, or `boosts.menu-none`. |

The lines are filled in once a second by the plugin itself, and a line is only re-sent to a viewer when its
text changed — so a countdown costs one small packet per viewer per second, and a mine nobody touches
costs nothing. `/minesadmin reload` redraws every hologram with the edited lines.

### What "remaining" counts

`%remaining%` compares what is gone with the number of blocks in the mine's shape:

- in a **classic** mine, the blocks broken through the mine since its last refill;
- in a **realistic** mine, the blocks waiting to grow back.

The shape's size counts every block of it, air included. A realistic mine selected around a cave with
plenty of air never reads far below 100%, and a classic mine that is partly air from the start reads 100%
until the first break all the same.
