At the end of this page you have one mine that fills with the blocks you chose, resets on its own every five minutes, and that players reach with `/mine coal`. You only use the editor and chat.

A classic mine needs three things before it can fill: an **area**, a **block composition** and a **reset**. The entry point is what lets players walk in.

## Before you start

Install the plugin and make sure you have the `exyliamines.admin` permission, which operators have by default. See [Install ExyliaMines](/docs/exyliamines/installation).

## Steps

<Steps>
  <Step title="Open the editor">
    Run `/minesadmin`. It opens the list of this server's mines, empty for now.
  </Step>
  <Step title="Create the mine">
    Click **Create ▸ Classic mine** and type an id in chat, for example `coal`. Use lowercase letters, digits, `-` and `_`, up to 64 characters, not starting or ending with `-` or `_`. The mine is created enabled and its setup screen opens.
  </Step>
  <Step title="Select the area">
    Click **Area**, then **Mine region**. You get ExyliaLib's selection wand: mark two opposite corners of the box and confirm. Every block between them is the mine.
  </Step>
  <Step title="Choose what it is made of">
    Back on the setup screen click **Composition**, then **Add block** and pick a block. Add stone, coal ore and iron ore.
  </Step>
  <Step title="Fill it">
    Click **Resets**, then **Force reset**. The area fills from the composition. From now on it refills on its own every five minutes.
  </Step>
  <Step title="Give it an entry point">
    Click **Teleports**, then **Entry teleport**. Stand where players should arrive and confirm.
  </Step>
</Steps>

## Check that it works

Run `/mine coal`: you arrive at the entry point inside a full mine. Break a few blocks, then run `/minesadmin reset coal` to see it refill at once, or wait for the interval. Any player with the default permissions can use `/mine coal` or open `/mines` and click the mine. If something does not work, see [Common problems](/docs/exyliamines/troubleshooting).

<Callout type="tip" title="Start from a template">
**Create ▸ From template** offers ready mixes from `templates.yml`. The new mine arrives with its name, icon and composition set, so only the area and the entry point are left. See [Mines](/docs/exyliamines/mines#templates).
</Callout>

## Going further: a realistic mine

A realistic mine never fills its area. It watches the blocks already standing there and grows each one back after it is broken, so it suits a natural cave or a hand-built ore wall. Click **Create ▸ Realistic mine**, select its area, then use **Regen levels** ▸ **Add level** for each block that should grow back. See [Realistic mines](/docs/exyliamines/realistic-mines).
