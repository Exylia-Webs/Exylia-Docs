ExyliaArrows registers its placeholders with PlaceholderAPI, so you need [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) installed. Use them in scoreboards, tab lists, chat formats and menus from other plugins. Click a placeholder to copy it.

<Placeholders />

The `bow_` placeholders answer about the item in the player's main hand instead of their menu choice. They show the same fields as the first group.

## When there is nothing to show

A player with no effect, or a bow with none, never shows an empty or broken line:

| Placeholder | Answer |
|---|---|
| `%exyliarrows_has_effect%` | `false` |
| `%exyliarrows_effect_description%` | Empty |
| `%exyliarrows_effect_material%` | `BARRIER` |
| `%exyliarrows_effect_tier_color%` | Empty |
| Everything else | The `placeholders.none` text in `messages.yml`, "None" by default |

A placeholder that names something that does not exist, such as an effect that was deleted, answers the `placeholders.unknown` text.

While a player is on random, `%exyliarrows_effect%` and `%exyliarrows_random%` answer `random`, and `%exyliarrows_effect_name%` answers the `menu.random-name` text.

## Example

A scoreboard that shows both the player's effect and the effect on the bow they hold:

```yaml
lines:
  - "Effect: %exyliarrows_effect_name%"
  - "Bow: %exyliarrows_bow_effect_name%"
```

<Callout type="tip" title="effect_material is made for menus">
It is the icon of the effect the player wears, so a menu from another plugin can draw it without knowing anything about ExyliaArrows.
</Callout>
