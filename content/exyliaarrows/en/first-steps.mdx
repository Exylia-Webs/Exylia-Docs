At the end of this page one player wears an arrow effect and you have seen all three moments of it in game: the flash when the arrow leaves the bow, the trail in the air and the impact.

## Before you start

Install the plugin and make sure ExyliaLib and `packetevents` are loaded. See [Install ExyliaArrows](/docs/exyliaarrows/installation). Operators already own every effect (`exyliarrows.effect.*` defaults to op), so you can test right away.

## Steps

<Steps>
  <Step title="Open the menu">
    Run `/arrows`. The categories are the tabs down the left and the effects of the open tab fill the grid. Use the buttons at the bottom for the next page.
  </Step>
  <Step title="Wear an effect">
    Left-click an effect. Right-click it to preview it instead. The classic menu shows a price on effects the player can buy and a lock on the ones they do not own.
  </Step>
  <Step title="Shoot">
    Shoot an arrow. It leaves with the launch flash, draws its trail in flight and ends in the impact. A snowball or an egg does not carry it by default, only arrows, spectral arrows and tridents.
  </Step>
  <Step title="Take it off">
    Click the **Your effect** button at the top of the menu, or run `/arrows clear`.
  </Step>
</Steps>

## Let your players use it

Players can open `/arrows` by default, but they own no effect yet. Give a rank one category, which holds twenty effects:

```text
/lp group vip permission set exyliarrows.category.ember true
```

The categories are `ember`, `frost`, `storm`, `void`, `prism` and `goofy`. For a single effect use `exyliarrows.effect.ember_trail`. See [Permissions](/docs/exyliaarrows/permissions).

## Set the preview stage

Previews need a place to play. Without it, right-clicking an effect or running `/arrows preview <effect>` tells the player previews are not set up.

<Steps>
  <Step title="Stand where previews should play">
    An empty room, a corner of the hub or a platform in the void. The effect plays in front of the player and a preview always faces north.
  </Step>
  <Step title="Run the wizard">
    Run `/arrowsadmin preview location` and confirm in the wizard it opens.
  </Step>
</Steps>

## Other ways to give effects

- **A key for the crate.** Run `/arrowsadmin keys give <player> 1`, then the player runs `/arrows crate` or clicks the **Crate** button in the menu. Effects they win are theirs for good. See [Set up the crate and the shop](/docs/exyliaarrows/crate).
- **A token for a bow.** Run `/arrowsadmin item give <player> ember_trail 1`. The player picks the token up with the cursor and clicks it onto a bow in their own inventory. The effect then travels with that bow. A **remover** (`/arrowsadmin item remover <player>`) takes it off again and hands the token back. See [Bind effects to bows](/docs/exyliaarrows/modes-and-tokens).

## Check that it works

Run `/arrows preview ember_trail`. All three moments should play in front of you. `/arrowsadmin list` prints every effect the server declares, and `/arrowsadmin player validate <player>` takes off an effect a player no longer qualifies for.
