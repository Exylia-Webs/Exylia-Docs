Players can use the player features without any setup: `plugin.yml` gives them to everyone. Staff tools, perks such as `/fly` and every bypass start for operators only. Use this page to change that.

To make a player feature a rank perk, deny it to the default group and grant it to the rank, for example `exyliasurvivalcore.homes.set` set to `false` on `default` and `true` on `vip`. Deleting a home, denying a request and cancelling a request never ask for a node.

<Callout type="warning" title="Two prefixes, both intentional">
Eight older admin nodes start with `survivalcore.` (`survivalcore.admin`, `survivalcore.admin.reload`, `survivalcore.admin.homes`, `survivalcore.rankup.admin`, `survivalcore.rankup.admin.set`, `survivalcore.farming.admin`, `survivalcore.farming.admin.set`, `survivalcore.portals.admin`). Every other node starts with `exyliasurvivalcore.`.
</Callout>

## Nodes that carry a number

<Permissions group="numbers" />


The last group is not declared in `plugin.yml`: each of those nodes ends in a value you choose, and nobody has them until you grant them. With LuckPerms:

```text
/lp group vip permission set exyliasurvivalcore.homes.max_homes.8 true
/lp group vip permission set exyliasurvivalcore.near.radius.500 true
/lp group vip permission set exyliasurvivalcore.tpa.warmup.1 true
/lp group vip permission set exyliasurvivalcore.repair.group.vip true
```

For the numbers that count homes and radius, the highest one a player holds wins. For warmups and cooldowns, written in seconds, the lowest one wins. A bypass node skips the warmup or cooldown entirely.

## Nodes you write yourself

Some things are gated by a node you choose, stored next to the thing it protects.

| Where | Key | Default |
|---|---|---|
| A warp | Its `permission`, set through `/warpadmin` | Empty, which falls back to `exyliasurvivalcore.warps.use` |
| A kit | Its `permission`, set through `/kitadmin` | Empty, which means every holder of `exyliasurvivalcore.kits` |
| A portal | Its `permission`, set through `/portalsadmin` | Empty, which means everybody |
| A reclaim section | `sections.<id>.permission` in `modules/reclaim/config.yml` | `exyliasurvivalcore.reclaim.<id>` |
| A join / leave group | `groups.<id>.permission` in `modules/join-leave/groups.yml` | The shipped `vip` group names `survivalcore.joinleave.vip` |
| A rank requirement | A `PERMISSION` requirement's `node`, in `ranks.yml` | None |

Reclaim sections are picked by priority: a player gets the highest-priority section whose permission they hold. A join / leave group works the same way.

The permissions of moved modules (economy, market, rewards, protections, crates and the rest) are on those plugins' pages, for example [ExyliaEconomy](/docs/exyliaeconomy/permissions) and [ExyliaMarket](/docs/exyliamarket/permissions).
