ExyliaSurvivalCore is the everyday survival layer of a server in one jar. Homes, warps, TPA, random
teleport, kits, rankup, farming milestones, statistics, missions and seasons, boosters, reputation and
community projects, plus the small utilities every survival server ends up wanting. Each of them is a
**module** you switch on or off in `config.yml`.

A module that is off registers nothing at all: no commands, no listeners, no database tables, no
placeholders. Turning one off is not a flag the code checks in a hundred places — it is a feature that
never loads.

There are **twenty-nine modules**, and almost everything an administrator configures is edited from an
in-game screen rather than a file.

<Callout type="note" title="Parts of it live in their own plugins now">
The economy, shop and market, protections, mines, crates, graves, vaults, the warzone features,
bounties, rewards and votes, and custom mobs are no longer modules of this plugin. The
[Modules](/docs/exyliasurvivalcore/modules#moved-to-other-plugins) page says where each one went.
</Callout>

## How a server is set up

<Steps>
  <Step title="Turn off what you do not want">
    Every module ships as `true`. Set the ones you do not need to `false` in `config.yml` and restart —
    module switches are the one thing a reload does not pick up, and `/survivalcoreadmin reload` names
    the ones still waiting for a restart.
  </Step>
  <Step title="Set the spawn">
    `/spawn set`. The spawn module can also force players there on first join, on every join and on
    respawn.
  </Step>
  <Step title="Build the content from menus">
    Warps, kits, item spawners, portals, jump pads, boosters and item updates are built from admin
    screens and stored in the database. There is no list to hand-edit.
  </Step>
  <Step title="Write the ladders in YAML">
    Ranks, farming categories, RTP worlds, repair groups, the stat list, missions and seasons are
    files, because they are ladders rather than objects.
  </Step>
</Steps>

## At a glance

| | |
|---|---|
| Version documented | 1.2.2 |
| Minecraft | Paper 1.21.1 or newer |
| Platforms | Paper and Folia |
| Required | `ExyliaLib` |
| Optional | `packetevents`, `ExyliaEconomy`, `ExyliaLobby`, `PlaceholderAPI`, `WorldGuard`, `Vault`, `Apollo`, `FeatherServerAPI`, the `Worlds` plugin on Folia |
