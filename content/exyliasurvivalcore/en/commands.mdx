---
title: "Commands"
description: "Every command every module registers, its arguments, its aliases, the node it checks and what it does."
---

Nothing is declared in `plugin.yml`: commands are registered at startup by the module that owns them,
so a module that is off has no commands at all. Changing a module switch in `config.yml` takes a restart
to add or remove its commands.

`<x>` is required, `[x]` optional. A permission written on a command applies to all its subcommands
unless the subcommand names its own. The nodes themselves are explained on
[Permissions](/docs/exyliasurvivalcore/permissions).

## Core

| Command | Aliases | Permission | What it does |
|---|---|---|---|
| `/survivalcore` | `/sc` | `survivalcore.admin` | Prints the usage line |
| `/survivalcore reload` | `/sc` | `survivalcore.admin.reload` | Reloads this plugin |

Runs from the console. It reloads the configs, the module settings and the menus — not the module
switches. When a switch in `config.yml` no longer matches what is running, the reply names those
modules as waiting for a restart.

without it.

### A command per currency

A currency with commands turned on and at least one alias gets a command of its own — `/coins`,
`/gems` — registered straight into the server rather than through the rest of the command system. The
node on it is `exyliasurvivalcore.economy`.

| Command | What it does | Extra node |
|---|---|---|
| `/<alias>` | Your balance in that currency | |
| `/<alias> <player>` | Somebody else's balance | `exyliasurvivalcore.economy.others` |
| `/<alias> pay <player> <amount>` | Sends that currency | `exyliasurvivalcore.economy.pay` |
| `/<alias> top [page]` | Its leaderboard | |
| `/<alias> history [player]` | Its ledger | `.economy.others` for somebody else |
| `/<alias> exchange <amount> <to>` | Swaps it for another currency | |
| `/<alias> give\|take\|set <player> <amount>` | Changes somebody's balance | `exyliasurvivalcore.economy.admin` |
| `/<alias> reset <player>` | Resets it | `exyliasurvivalcore.economy.admin` |

When another plugin already owns the name, the command answers as `/exyliasurvivalcore:<alias>` and the
console says so at startup.

<Callout type="warning" title="The per-currency commands fail silently">
`/<alias> pay` without `exyliasurvivalcore.economy.pay`, and `give`, `take`, `set` or `reset` without
`exyliasurvivalcore.economy.admin`, do nothing and send no message at all.
</Callout>

<Callout type="warning" title="`/autosell` without player settings">
`/autosell` flips a switch that lives in the player-settings module. With that module off, it replies
that autosell is on and changes nothing.
</Callout>

right.

## Tab completion

The arguments fill in live: AFK zone ids, bounty ids, crate ids, farming category ids, currency ids, the
player's own home names, another player's home names, kit ids, reward ids and playtime reward ids (a
player only sees the kits and rewards whose permission they hold), rank ids, reclaim section ids, RTP
world ids, warp ids, protection warp names and tier ids, the names of pending TPA requests to you and from
you, and online player names. A player argument that works offline suggests every name the server and
the network know.
