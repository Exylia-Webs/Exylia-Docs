<Callout type="note" title="Currencies moved to ExyliaEconomy">
ExyliaSurvivalCore no longer keeps currencies, balances, the ledger or `/balance`, `/pay`, `/baltop` and
`/wallet`. They belong to [ExyliaEconomy](/docs/exyliaeconomy/introduction). The shop, markets, trading and
sell wands belong to [ExyliaMarket](/docs/exyliamarket/introduction). The only economy feature left here is
**boosters**.
</Callout>

## Boosters

A booster multiplies **money**, **experience** or **drops** for one player or for everybody, for a time.
The module is `boosters` in `config.yml`. Multipliers are worked out through ExyliaLib's modifier
pipeline, so other Exylia plugins list their own payouts and honour the same boosters.

| Type | Multiplies |
|---|---|
| `money` | Money paid in the default currency |
| `xp` | Experience |
| `drops` | Items |

### Sources

A booster names the payout it applies to, or `*` for all of them.

| Source | What it multiplies |
|---|---|
| `mines` | A mine's blocks: loot tables, vanilla drops and their experience |
| `blocks` | Natural blocks outside mines, as listed under `drops.blocks` |
| `crops` | Grown crops outside mines, as listed under `drops.crops` |
| `mob-drops` | What a vanilla mob drops when a player kills it |
| `orbs` | Experience orbs picked up |
| `shop-sell` | Selling to the shop, by `/sell`, a sell wand or autosell |
| `worth-sell` | Selling what `worth.yml` prices, the same three ways |
| `farming` | The `money` of the farming categories |

The reward lists of `missions`, `votes`, `referrals`, `projects`, `playtime-rewards`, `afk-zones`,
`duel-rooms`, `power-ups`, `rewards`, `crates`, `seasons` and `mobs` are boosted too (a custom mob may
name its own source in `/mobsadmin`). In a reward list a money booster multiplies the money, an experience
booster the experience and a drops booster the items; commands are never multiplied. Several of those
payouts now come from [ExyliaRewards](/docs/exyliarewards/introduction) and the other plugins that took
those modules over.

Money counts in the default currency only. Refunds and transfers are never boosted. A multiplier that is
not whole rounds each drop at random, so x1.5 on one item gives two half of the time and the average is
exact. The source is free text: one that nothing pays under multiplies nothing.

### Personal and global

| | Given with | Starts |
|---|---|---|
| Personal | `/boostersadmin give <player> <money\|xp\|drops> <multiplier> <duration> [source]` | When the player clicks it in `/boosters` |
| Global | `/boostersadmin global <money\|xp\|drops> <multiplier> <duration> [source]` | At once, on every server |

A personal booster waits in `/boosters` until its owner starts it, so it can be given to somebody who is
offline or on another server, which is what a web store needs. The player is told when one arrives. A
global booster is announced on every server when it starts and when it ends. `/boostersadmin clear`
(with `confirm`) ends every running global booster without announcing it.

The multiplier must be above `1` and at most `100`. The duration is `30m`, `2h`, `1d`; a bare number is
seconds. No source means `*`.

### Presets

A **preset** is a booster ready to hand out: a name, an icon, a type, a source, a multiplier and a
duration. Giving one copies it, so editing or deleting a preset never changes a booster already given.

| Command | What it does |
|---|---|
| `/boostersadmin preset give <player> <preset>` | Gives a player a personal booster from a preset |
| `/boostersadmin preset global <preset>` | Starts the preset for everybody on the network |

Both work from the console, so a store can use them. Presets, and every setting below, are built from the
admin screen: `/boostersadmin` with no arguments opens it (presets, running boosters and settings).

### Stacking

Every running booster of a type that applies to a payout counts, the player's own and the global ones
together. `modules/boosters/config.yml`:

```yaml
settings:
  stacking: ADD
  max-multiplier: 5.0
  one-per-type: true
drops:
  excluded-from-all: [crates]
  blocks: ['*_ORE', ANCIENT_DEBRIS, '*_LOG', ...]
  crops: [WHEAT, CARROTS, POTATOES, ...]
```

| `stacking` | x2 and x1.5 make |
|---|---|
| `ADD` | x2.5 |
| `MULTIPLY` | x3 |
| `HIGHEST` | x2 |

The result is never below x1, and never above `max-multiplier`; `0` removes the cap. `one-per-type`
(default `true`) stops a player running a second personal booster of a type; global boosters do not count
against it.

`drops.excluded-from-all` lists sources a drops booster for `*` leaves alone (default `crates`): only a
booster naming them multiplies them. `drops.blocks` is what the `blocks` source multiplies (`*` matches
any part of a name, so `*_ORE` is every ore) and `drops.crops` what `crops` multiplies; seeded crops count
only fully grown and a block a player placed never counts, so placing and breaking multiplies nothing.

### Boss bar

A boss bar shows while any booster applies to the player, filling with the time left on the one that ends
last. Its text and style are the `bossbar` block of `modules/boosters/messages.yml`; `%money%`, `%xp%`,
`%drops%`, `%left%` and `%count%` work in the text, and an empty text hides it.

### Commands, permissions and placeholders

| Command | Permission |
|---|---|
| `/boosters` | `exyliasurvivalcore.boosters` |
| `/boostersadmin` (`/boostersa`): `give`, `global`, `clear`, `preset give`, `preset global` | `exyliasurvivalcore.boosters.admin` |

`/boosters` lists the global boosters running, then the player's own, running first, then waiting. Its
screens are in `modules/boosters/menus/`.

| Placeholder | What it returns |
|---|---|
| `%exyliasurvivalcore_boosters_money%` | The viewer's money multiplier, theirs and global together |
| `%exyliasurvivalcore_boosters_xp%` | The same for experience |
| `%exyliasurvivalcore_boosters_drops%` | The same for drops |
| `%exyliasurvivalcore_boosters_active%` | Personal boosters running |
| `%exyliasurvivalcore_boosters_stored%` | Personal boosters waiting to be started |
| `%exyliasurvivalcore_boosters_global_money%` | The global money multiplier |
| `%exyliasurvivalcore_boosters_global_xp%` | The global experience multiplier |
| `%exyliasurvivalcore_boosters_global_drops%` | The global drops multiplier |
| `%exyliasurvivalcore_boosters_global_left%` | Time left on the global booster that ends last, or `—` |
