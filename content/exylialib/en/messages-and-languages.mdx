You will choose the language your players see, edit any message a plugin sends, and reload it without restarting.

ExyliaLib is the library every Exylia plugin installs. The language setting lives in its folder, `plugins/ExyliaLib/`, and applies to all Exylia plugins at once. The messages themselves live in each plugin's own folder, so you edit them per plugin.

## Choose the language

<Steps>
  <Step title="Open the library config">
    Open `plugins/ExyliaLib/config.yml`.
  </Step>
  <Step title="Set the language">
    ```yaml title="plugins/ExyliaLib/config.yml"
    language: es
    ```
    The languages that ship are `en`, `es`, `pt`, `fr`, `ru` and `tr`.
  </Step>
  <Step title="Reload">
    Run `/exylialib reload` for the library's own lines, then the reload command of each plugin (for ExyliaFFA, `/ffaadmin reload`). The Commands page of each plugin lists it.
  </Step>
</Steps>

Every plugin whose own `language` is `default` follows this value. `default` is what a fresh install writes. To give one plugin a different language, set `language` in that plugin's own `config.yml` to a code such as `en`.

<Callout type="tip" title="Prefer clicking?">
`/exylialib setup` offers the same language choice in game. See [Setup wizard](/docs/exylialib/setup-wizard).
</Callout>

## Where the messages are

Each plugin keeps its text in a folder per language:

```text
plugins/ExyliaFFA/
├── config.yml
└── lang/
    └── en/
        ├── messages.yml
        └── menus/
```

Replace `ExyliaFFA` with the plugin you are editing, and `en` with the active language. `messages.yml` holds the chat messages. Menus are in `menus/`; see [Edit menus](/docs/exylialib/edit-menus).

- **English is the base.** A line a language has not translated yet still arrives, in English.
- **Any other code is yours.** Setting `language: de`, or any name with letters, digits, `-` and `_`, starts as English and you rewrite it.
- **Servers that predate languages** keep their files: they move to `lang/custom/` and the plugin's `language` becomes `custom`.

## Edit a message

<Steps>
  <Step title="Open the file">
    Open `plugins/<Plugin>/lang/<code>/messages.yml`. Each message is a key and a line of text.
  </Step>
  <Step title="Change the text">
    Edit only the text after the colon. Keep words between percent signs such as `%arena%`: the plugin replaces them with real values.

    ```yaml
    left: '%prefix% {warning}You left the FFA.'
    ```
  </Step>
  <Step title="Save and reload">
    Run the plugin's reload command. The next time the message appears it uses your text.
  </Step>
</Steps>

To switch a message off, make its text empty (`left: ''`). A blank message sends nothing.

## Change the prefix

Most messages begin with `%prefix%`, a short tag each plugin defines at the top of its `messages.yml`:

```yaml
prefix: '{primary}&lFFA {letters_black}•<reset>'
```

Change it there and every message of that plugin follows after a reload. The prefix belongs to the plugin, so each plugin has its own.

## Format the text

All of these can be mixed on one line:

| You write | You get |
|---|---|
| `{primary}`, `{error}`, `{success}` | A colour from your palette. See [Colours](/docs/exylialib/colours). |
| `&a`, `&l`, `&r` | Classic colour and style codes. |
| `&#8a51c4` or `<#8a51c4>` | A fixed hex colour. |
| `<gradient:{primary}:{info}>Text</gradient>` | A gradient. |
| `<bold>`, `<italic>`, `<underlined>` | Styles, written as tags. |
| `<click:run_command:'/ffa leave'>Leave</click>` | Text that runs a command when clicked. |
| `<hover:show_text:'Click to leave'>Leave</hover>` | A tooltip on hover. |

You can start a message with a block in square brackets to play a sound or centre it:

```yaml
joined: "[sound:ENTITY_PLAYER_LEVELUP|1.0|1.0]%prefix% {success}You joined!"
```

Other kinds are `particle`, `firework` and `center`. The block is never shown to the player.

<Callout type="note" title="Small capitals are on by default">
Exylia plugins draw their text in small capitals, and with a soft shadow. Names of players and numbers are left as they are. To turn it off for all plugins, set `small-text: false` in `plugins/ExyliaLib/config.yml` and run `/exylialib reload`.
</Callout>

## Check that it works

Trigger the message in game (for example join an arena for a join message). It should show your wording, colours and prefix. If it shows the old text, make sure you edited the file for the language that is active, and that you ran the plugin's reload command.

## Edit in the browser instead

`/exylialib editor` gives you a link to edit every Exylia plugin's settings, messages and menus in a web page, with a help text for each key. Save in the browser, then click **Apply** in game. It needs the permission `exylialib.editor`. See [Web editor](/docs/exylialib/web-editor).

## When a plugin updates

An update adds new messages to your file but never overwrites a line you changed. When a default changes, it waits in `/exylialib updates` (permission `exylialib.updates`): click a change to apply it or keep yours.

<Details title="Technical details">
`language: default` in a plugin follows ExyliaLib's `language`; any other code overrides it for that plugin. The library's own panel text is translated by `plugins/ExyliaLib/lang/<code>/phrases.yml`, where the English line is the key and the translation its value. Placeholders from PlaceholderAPI (`%player_name%`) also work in messages. Developer details: [Text and placeholders](/docs/exylialib/text) and [The library's own files](/docs/exylialib/library-config).
</Details>
