Vas a elegir el idioma que ven tus jugadores, editar cualquier mensaje que envía un plugin y recargarlo sin reiniciar.

ExyliaLib es la librería que instala cada plugin Exylia. El ajuste de idioma está en su carpeta, `plugins/ExyliaLib/`, y se aplica a todos los plugins Exylia a la vez. Los mensajes en sí están en la carpeta de cada plugin, así que los editas plugin por plugin.

## Elige el idioma

<Steps>
  <Step title="Abre la configuración de la librería">
    Abre `plugins/ExyliaLib/config.yml`.
  </Step>
  <Step title="Pon el idioma">
    ```yaml title="plugins/ExyliaLib/config.yml"
    language: es
    ```
    Los idiomas incluidos son `en`, `es`, `pt`, `fr`, `ru` y `tr`.
  </Step>
  <Step title="Recarga">
    Ejecuta `/exylialib reload` para los textos de la librería y luego el comando de recarga de cada plugin (en ExyliaFFA, `/ffaadmin reload`). La página de comandos de cada plugin lo indica.
  </Step>
</Steps>

Todo plugin cuyo `language` propio sea `default` sigue este valor. `default` es lo que escribe una instalación nueva. Para dar a un plugin otro idioma, pon `language` en el `config.yml` de ese plugin con un código como `en`.

<Callout type="tip" title="¿Prefieres hacer clic?">
`/exylialib setup` ofrece esta misma elección de idioma en el juego. Mira el [Asistente de configuración](/docs/exylialib/asistente-de-configuracion).
</Callout>

## Dónde están los mensajes

Cada plugin guarda su texto en una carpeta por idioma:

```text
plugins/ExyliaFFA/
├── config.yml
└── lang/
    └── es/
        ├── messages.yml
        └── menus/
```

Cambia `ExyliaFFA` por el plugin que estés editando y `es` por el idioma activo. `messages.yml` guarda los mensajes del chat. Los menús están en `menus/`; mira [Editar menús](/docs/exylialib/editar-menus).

- **El inglés es la base.** Una línea que un idioma aún no traduce llega igualmente, en inglés.
- **Cualquier otro código es tuyo.** Con `language: de`, o cualquier nombre con letras, números, `-` y `_`, empiezas con el inglés y lo reescribes tú.
- **Los servidores anteriores a los idiomas** conservan sus archivos: pasan a `lang/custom/` y el `language` del plugin pasa a `custom`.

## Edita un mensaje

<Steps>
  <Step title="Abre el archivo">
    Abre `plugins/<Plugin>/lang/<código>/messages.yml`. Cada mensaje es una clave y una línea de texto.
  </Step>
  <Step title="Cambia el texto">
    Edita solo el texto después de los dos puntos. Deja las palabras entre porcentajes como `%arena%`: el plugin las sustituye por valores reales.

    ```yaml
    left: '%prefix% {warning}Saliste del FFA.'
    ```
  </Step>
  <Step title="Guarda y recarga">
    Ejecuta el comando de recarga del plugin. La próxima vez que salga el mensaje usará tu texto.
  </Step>
</Steps>

Para apagar un mensaje, deja su texto vacío (`left: ''`). Un mensaje en blanco no envía nada.

## Cambia el prefijo

La mayoría de mensajes empiezan con `%prefix%`, una etiqueta corta que cada plugin define al principio de su `messages.yml`:

```yaml
prefix: '{primary}&lFFA {letters_black}•<reset>'
```

Cámbialo ahí y todos los mensajes de ese plugin lo siguen tras recargar. El prefijo es de cada plugin, así que cada uno tiene el suyo.

## Da formato al texto

Todo esto se puede mezclar en una misma línea:

| Escribes | Obtienes |
|---|---|
| `{primary}`, `{error}`, `{success}` | Un color de tu paleta. Mira [Colores](/docs/exylialib/colores). |
| `&a`, `&l`, `&r` | Códigos clásicos de color y estilo. |
| `&#8a51c4` o `<#8a51c4>` | Un color hex fijo. |
| `<gradient:{primary}:{info}>Texto</gradient>` | Un degradado. |
| `<bold>`, `<italic>`, `<underlined>` | Estilos, escritos como etiquetas. |
| `<click:run_command:'/ffa leave'>Salir</click>` | Texto que ejecuta un comando al hacer clic. |
| `<hover:show_text:'Clic para salir'>Salir</hover>` | Un texto flotante al pasar el ratón. |

Puedes empezar un mensaje con un bloque entre corchetes para reproducir un sonido o centrarlo:

```yaml
joined: "[sound:ENTITY_PLAYER_LEVELUP|1.0|1.0]%prefix% {success}¡Entraste!"
```

Otros tipos son `particle`, `firework` y `center`. El bloque nunca se muestra al jugador.

<Callout type="note" title="Las versalitas vienen activadas">
Los plugins Exylia dibujan su texto en versalitas y con una sombra suave. Los nombres de jugador y los números se dejan como están. Para desactivarlo en todos los plugins, pon `small-text: false` en `plugins/ExyliaLib/config.yml` y ejecuta `/exylialib reload`.
</Callout>

## Comprueba que funciona

Provoca el mensaje en el juego (por ejemplo, entra en una arena para ver el de entrada). Debe mostrar tus palabras, colores y prefijo. Si sale el texto antiguo, comprueba que editaste el archivo del idioma que está activo y que ejecutaste el comando de recarga del plugin.

## Edita desde el navegador

`/exylialib editor` te da un enlace para editar los ajustes, mensajes y menús de todos los plugins Exylia en una página web, con una ayuda para cada clave. Guarda en el navegador y pulsa **Apply** en el juego. Necesita el permiso `exylialib.editor`. Mira el [Editor web](/docs/exylialib/editor-web).

## Cuando un plugin se actualiza

Una actualización añade mensajes nuevos a tu archivo, pero nunca pisa una línea que cambiaste. Cuando cambia un valor por defecto, queda esperando en `/exylialib updates` (permiso `exylialib.updates`): pulsa un cambio para aplicarlo o conservar el tuyo.

<Details title="Detalles técnicos">
`language: default` en un plugin sigue el `language` de ExyliaLib; cualquier otro código lo sustituye para ese plugin. El texto propio de los paneles de la librería se traduce con `plugins/ExyliaLib/lang/<código>/phrases.yml`, donde la línea en inglés es la clave y la traducción el valor. Los placeholders de PlaceholderAPI (`%player_name%`) también funcionan en los mensajes. Detalles para desarrolladores: [Texto y placeholders](/docs/exylialib/texto) y [Los archivos de la librería](/docs/exylialib/config-de-la-libreria).
</Details>
