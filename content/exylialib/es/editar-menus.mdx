Cada menú de un plugin Exylia es un archivo de texto que puedes editar. Vas a encontrar el archivo, cambiar un título, un objeto o una casilla y ver el resultado en el juego.

Todos los plugins Exylia construyen sus menús igual, con ExyliaLib, la librería que instala cada plugin Exylia. Por eso esta página sirve para cualquier plugin.

## Encuentra el archivo del menú

Los menús están en la carpeta de cada plugin, dentro de la carpeta del idioma activo:

```text
plugins/ExyliaFFA/lang/es/menus/
├── user/
│   └── kit_selector.yml
└── admin/
    └── ...
```

Cambia `ExyliaFFA` por tu plugin y `es` por tu idioma (mira [Mensajes e idiomas](/docs/exylialib/mensajes-e-idiomas)). El nombre del archivo dice qué menú es.

<Callout type="warning" title="Mira la cabecera del archivo antes de editar">
Algunos archivos, normalmente los menús de administración, empiezan con un recuadro que dice "DO NOT EDIT THIS FILE MANUALLY". Esos se reescriben en cada arranque y pierdes tus cambios. Edita solo archivos sin ese recuadro; los menús de jugador no suelen llevarlo.
</Callout>

## Cambia un menú

<Steps>
  <Step title="Abre el archivo">
    Abre el `.yml` del menú en un editor de texto que entienda YAML. Respeta exactamente los espacios al inicio de las líneas: forman parte del formato.
  </Step>
  <Step title="Cambia lo que quieras">
    Mira los ejemplos de abajo. Cambia solo los valores a la derecha de los dos puntos.
  </Step>
  <Step title="Guarda y recarga">
    Ejecuta el comando de recarga del plugin (en ExyliaFFA, `/ffaadmin reload`). La próxima vez que alguien abra el menú usará tu archivo.
  </Step>
</Steps>

Si una parte del menú está mal, como una acción que no existe o un material mal escrito, ese botón queda inerte y la consola imprime una línea. El resto del menú se abre igualmente.

## Cambios habituales

### Cambia el título o el nombre de un botón

```yaml
title: "{primary}&lSELECT KIT {muted}%current_page%/%total_pages%"
```

`title` es el texto de la parte superior de la ventana. Los nombres de objeto usan el mismo formato de texto que los mensajes: nombres de color como `{primary}`, códigos `&`, hex y degradados. Mira [Colores](/docs/exylialib/colores). Deja `%current_page%` y palabras parecidas entre porcentajes; el plugin las rellena.

### Cambia un icono

```yaml
items:
  manage-arenas:
    slot: 11
    material: COMPASS
```

`material` es el objeto que se muestra. Usa el nombre de un objeto de Minecraft en mayúsculas, como `DIAMOND_SWORD`. Algunos menús escriben un valor entre porcentajes (`%kit_icon%`): el plugin elige el objeto de cada fila, así que déjalos como están.

### Mueve un botón

`slot` es la posición en la ventana, contando desde 0 arriba a la izquierda, de izquierda a derecha. Un cofre de 27 casillas tiene tres filas de nueve: de la 0 a la 8 es la fila de arriba, de la 9 a la 17 la del medio y de la 18 a la 26 la de abajo. Cambia `slot: 11` por `slot: 13` para llevar un botón al centro de la fila del medio.

### Cambia el tamaño

```yaml
size: 27
```

Un cofre tiene 9, 18, 27, 36, 45 o 54 casillas. Si lo haces más pequeño, mueve todo botón que estuviera en una casilla más allá del nuevo tamaño o ese botón se omite (la consola dice cuál).

### Cambia el texto bajo un nombre

```yaml
lore:
  - "{letters_black}Setup section"
  - ""
  - "{primary}{icon:click} Click to manage"
```

`lore` es la lista de líneas bajo el nombre del objeto. Un `""` vacío es una línea en blanco.

### Cambia el fondo

```yaml
filler:
  global:
    material: GRAY_STAINED_GLASS_PANE
    hide_tooltip: true
```

`global` rellena todas las casillas vacías. Cambia `material` para cambiar el color del cristal.

### Cambia los sonidos

```yaml
open_sounds:
  - "minecraft:block.ender_chest.open|1.0|1.4"
```

Cada línea es `sonido|volumen|tono`. Quita la línea para silenciarlo.

### Oculta o muestra un botón según una condición

```yaml
condition: "%lfc_state% == none"
```

El botón solo está cuando la condición se cumple. Un botón oculto no se puede pulsar. Deja las condiciones existentes como están salvo que sepas qué valor leen.

### Cambia lo que hace un botón

```yaml
actions:
  - "ffa:select_kit %arena_id% %kit_id% %spawn_id%"
```

Las acciones son las propias del plugin. No inventes nuevas: reutiliza una que el plugin ya use en un menú, o quita las líneas de `actions` para dejar un botón decorativo. Solo puedes lanzar otro comando si el plugin documenta una acción para ello.

## Comprueba que funciona

Recarga y abre el menú en el juego con el comando de la página de comandos del plugin. Debes ver tu título, tu icono y tu botón en la casilla nueva. Si el menú no se abre, lee la consola: dice qué línea falla.

## Si tu cambio desaparece o no se aplica

- **El archivo dice "do not edit".** Se reescribe en cada arranque. Edita otro archivo o pide que el plugin exponga el ajuste.
- **Editaste otro idioma.** Edita la carpeta del idioma activo; es el de `plugins/ExyliaLib/config.yml`, salvo que el plugin lo sustituya.
- **Una actualización cambió el archivo.** Un valor por defecto que no tocaste se actualiza. Un cambio que afecta a algo que editaste espera en `/exylialib updates`; al aplicarlo, tu archivo anterior se guarda como `<nombre>.v<versión anterior>`.

<Details title="Detalles técnicos">
`type` puede ser `SIMPLE`, `PAGINATION`, `MULTI_PAGINATION`, `ITEM_INPUT` o `STATIC` para ventanas de cofre, o un contenedor como `HOPPER` o `ANVIL`, que tiene un tamaño fijo propio. Un menú con lista lleva un bloque `pagination` (`slots`, `item_template`, `navigation`). Los clics se pueden escribir por tipo, como `left: comando` y `right: comando`. Un menú puede fijar `click_cooldown` en milisegundos. `menu-version` al inicio deja que un plugin sustituya un archivo sin tocar cuando cambia su diseño. Referencia completa: [Menús](/docs/exylialib/menus).
</Details>
