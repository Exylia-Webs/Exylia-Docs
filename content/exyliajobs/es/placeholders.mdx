---
title: "Placeholders"
description: "Los placeholders %exyliajobs_...%, mediante PlaceholderAPI y ExyliaLib."
---

Identificador `exyliajobs`. Se resuelven para el jugador que mira y leen de memoria, así que son para jugadores conectados. Los ids de trabajo van en minúsculas.

| Placeholder | Valor |
|---|---|
| `%exyliajobs_level_<job>%` | El nivel (1 si no se ha empezado). |
| `%exyliajobs_xp_<job>%` | Experiencia dentro del nivel, redondeada hacia abajo. |
| `%exyliajobs_needed_<job>%` | Experiencia necesaria para el siguiente nivel (0 en el máximo). |
| `%exyliajobs_prestige_<job>%` | Estrellas de prestigio como número. |
| `%exyliajobs_stars_<job>%` | El símbolo de estrella una vez por estrella. |
| `%exyliajobs_stars%` | Las estrellas de todos los trabajos sumadas. |
| `%exyliajobs_joined%` | Cuántos trabajos tiene el jugador. |
| `%exyliajobs_today%` | Dinero ganado hoy (UTC) en este servidor. |
| `%exyliajobs_today_<job>%` | Lo mismo para un trabajo. |
| `%exyliajobs_rate_<job>:<target>%` | La tasa de mercado del objetivo en porcentaje (100 cuando nada la cambia). |
| `%exyliajobs_top_<job>_<n>_<field>%` | El n-ésimo mejor jugador; `field` es `name` (por defecto), `level`, `prestige` o `xp`. |

`today` acepta los formatos numéricos de ExyliaLib como `:comma`.
