## Comandos de jugador

Solo para jugadores, todos requieren `exyliajobs.use`.

| Comando | Qué hace |
|---|---|
| `/jobs` | Abre la lista de trabajos. |
| `/jobs join <job>` | Te apunta a un trabajo (pregunta cuál dejar cuando las ranuras están llenas). |
| `/jobs leave <job>` | Deja un trabajo tras una confirmación. |
| `/jobs top <job>` | Abre la clasificación del trabajo. |
| `/jobs orders` | Abre el tablón de órdenes de trabajo. |
| `/jobs perks <job>` | Abre las mejoras del trabajo. |
| `/jobs prestige <job>` | Pide hacer prestigio en el trabajo. |

Un trabajo desactivado no existe para `join`, `leave` y `top`.

## Comandos de administración

Todos los comandos de aquí requieren `exyliajobs.admin`, operadores por defecto.

| Comando | Consola | Qué hace |
|---|---|---|
| `/jobsadmin` | | Abre el centro de administración. |
| `/jobsadmin reload` | sí | Vuelve a leer los archivos de configuración y los trabajos, e informa de cuántos problemas tenían los trabajos. |
| `/jobsadmin give xp <player> <job> <amount>` | sí | Añade experiencia como si se hubiera ganado: incluye subidas de nivel, efectos y recompensas de hito. El jugador debe estar conectado y cargado. |
| `/jobsadmin give level <player> <job> <level>` | sí | Fija un nivel directamente (de 1 al máximo del trabajo); sin recompensas ni efectos. |
| `/jobsadmin economy` | | Abre el panel de economía. |
| `/jobsadmin import <source> [-dry\|-confirm]` | sí | Consulta [Migración](/docs/exyliajobs/migracion). |

## Acciones de menú

Las pantallas se abren entre sí mediante acciones `exyliajobs:`, y los menús propios de un servidor pueden usarlas: `open_jobs`, `open_job`, `open_perks`, `open_orders`, `open_admin_hub`, `open_admin_jobs`, `open_admin_economy`, `open_admin_orders`, `open_admin_players`, `open_admin_migration` y `settings`. Las de administración requieren `exyliajobs.admin`.
