---

Todos los ajustes también se pueden editar en el juego desde `/jobsadmin` y luego **Settings**. Las duraciones se escriben como `5s`, `10m`, `3d`.

## config.yml

| Clave | Por defecto | Significado |
|---|---|---|
| `language` | `default` | Sigue la configuración de ExyliaLib; se incluyen `en`, `es`, `pt`, `fr`, `de`, `ru`, `tr`. |
| `debug` | false | Explica en la consola lo que hace el plugin. |
| `features` | `{}` | Una función puesta a `false` está apagada (reinicio). |
| `auto-join` | false | Todos tienen todos los trabajos. |
| `slots` | 2 | Trabajos que se tienen a la vez (1-64). |
| `leave.kept-xp` / `cooldown` / `fee` | 1.0 / 0s / 0 | Consulta [Niveles y ranuras](/docs/exyliajobs/niveles-y-ranuras). |
| `milestones.repeat-after-prestige` | false | Los hitos pagan de nuevo tras un prestigio. |
| `defaults.max-level` / `income-bonus` / `price-share` | 50 / 0.02 / 0.10 | Lo que recibe un archivo de trabajo que omite una clave. |
| `feedback.mode` / `window` | `TOAST` / 5s | `TOAST`, `BOSS_BAR`, `ACTION_BAR` o `NONE`; ventana de depósito. |
| `anti-exploit.*` | | `disabled-worlds`, `disabled-regions`, `placed-blocks` true, `tnt` false, `spawner-mobs` 0.0, `bone-meal` 0.25, `idle` false, `breed-cooldown` 5m, `place-cooldown` 10m. |
| `storage.flush-interval` / `top-refresh` | 30s / 1m | Escritura y actualización de la clasificación. |

## economy.yml

| Clave | Por defecto |
|---|---|
| `market.enabled` / `half-life` | true / 2h |
| `market.normal-per-player-hour` / `highest` / `lowest` / `hot-from` / `warm-up` | 1500 / 1.5 / 0.25 / 1.2 / 3 |
| `fatigue.enabled` / `free-actions` / `halves-every` / `floor` / `recovery` | true / 64 / 64 / 0.1 / 10m |
| `budget.mode` / `per-active-hour` / `daily` / `lowest` / `highest` | `per-active-hour` / 4000 / 200000 / 0.5 / 1.25 |
| `caps.enabled` / `soft-share` / `groups` | false / 0.5 / `default` 5000 y 50000, `vip` 7500 y 75000 |
| `report.enabled` / `webhook` / `message` | false / vacío / un embed por defecto |

## perks.yml

`swap-fee` (250), `prestige.enabled` (true), `max-stars` (10), `money-per-star` (0.02), `xp-per-star` (0.02), `keep-perks` (true), `star` (`★`).

## orders.yml

`tax` 1, `duration` 3d, `max-duration` 7d, `limit` 5, `max-quantity` 2304, `min-unit-price` 0.01, `delivery-xp` 0, `keep-finished` 3d, y `server-orders`: `enabled` true, `interval` 30m, `max-open` 5, `duration` 1d.

## integrations.yml

`pay-inside-protections` true, `pay-during-minigames` false, `pay-in-staff-mode` false, `network-handover` true, `handover-wait` 10s.

Los nombres de las claves son la forma con guiones de los campos de registro de arriba; los archivos generados llevan un comentario en cada una.
