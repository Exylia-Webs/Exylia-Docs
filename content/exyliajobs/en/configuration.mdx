title: "Configuration"
description: "Every key of config.yml, economy.yml, perks.yml, orders.yml and integrations.yml."
---

Every setting is also editable in game from `/jobsadmin` then **Settings**. Durations are written like `5s`, `10m`, `3d`.

## config.yml

| Key | Default | Meaning |
|---|---|---|
| `language` | `default` | Follows ExyliaLib's config; `en`, `es`, `pt`, `fr`, `de`, `ru` ship. |
| `debug` | false | Explains in the console what the plugin is doing. |
| `features` | `{}` | A feature set to `false` is off (restart). |
| `auto-join` | false | Everyone holds every job. |
| `slots` | 2 | Jobs held at once (1-64). |
| `leave.kept-xp` / `cooldown` / `fee` | 1.0 / 0s / 0 | See [Levels and slots](/docs/exyliajobs/levels-and-slots). |
| `milestones.repeat-after-prestige` | false | Milestones pay again after a prestige. |
| `defaults.max-level` / `income-bonus` / `price-share` | 50 / 0.02 / 0.10 | What a job file that leaves a key out gets. |
| `feedback.mode` / `window` | `TOAST` / 5s | `TOAST`, `BOSS_BAR`, `ACTION_BAR` or `NONE`; deposit window. |
| `anti-exploit.*` | | `disabled-worlds`, `disabled-regions`, `placed-blocks` true, `tnt` false, `spawner-mobs` 0.0, `bone-meal` 0.25, `idle` false, `breed-cooldown` 5m, `place-cooldown` 10m. |
| `storage.flush-interval` / `top-refresh` | 30s / 1m | Write and top list refresh. |

| Key | Default |
|---|---|
| `market.enabled` / `half-life` | true / 2h |
| `market.normal-per-player-hour` / `highest` / `lowest` / `hot-from` / `warm-up` | 1500 / 1.5 / 0.25 / 1.2 / 3 |

| `report.enabled` / `webhook` / `message` | false / empty / a default embed |

## perks.yml

`swap-fee` (250), `prestige.enabled` (true), `max-stars` (10), `money-per-star` (0.02), `xp-per-star` (0.02), `keep-perks` (true), `star` (`★`).

## orders.yml

`tax` 1, `duration` 3d, `max-duration` 7d, `limit` 5, `max-quantity` 2304, `min-unit-price` 0.01, `delivery-xp` 0, `keep-finished` 3d, and `server-orders`: `enabled` true, `interval` 30m, `max-open` 5, `duration` 1d.

## integrations.yml

`pay-inside-protections` true, `pay-during-minigames` false, `pay-in-staff-mode` false, `network-handover` true, `handover-wait` 10s.

Key names are the hyphenated form of the record fields above; the generated files carry a comment on each.
