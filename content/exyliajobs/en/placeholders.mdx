Use these in any plugin that reads PlaceholderAPI placeholders: scoreboards, tab lists, chat formats, holograms. They also work in ExyliaLib messages and menus. Job ids are lower case (`miner`, `woodcutter`), the same as the file name of the job.

<Placeholders />

## Examples

- Level of the player's Miner job on a scoreboard: `Miner %exyliajobs_level_miner%`.
- Chat prefix with the Hunter stars: `%exyliajobs_stars_hunter%`.
- Hologram line with the best Farmer: `1. %exyliajobs_top_farmer_1_name% (level %exyliajobs_top_farmer_1_level%)`.
- Money earned today, with thousands separators: `%exyliajobs_today:comma%`.

<Callout type="note" title="Online players only">
These placeholders read the progress of the player looking at them, held in memory. For an offline player they show the starting value. The top list works for anyone because it is read from the database every minute.
</Callout>

<Details title="Technical details">
The star symbol repeated by `%exyliajobs_stars_<job>%` is `prestige.star` in `perks.yml` (`★` by default). `%exyliajobs_today%` reads the economy guard, so it shows `0` when the economy feature is off. In `%exyliajobs_top_<job>_<n>_<field>%`, a place with nobody on it gives an empty name or `0`. In `%exyliajobs_rate_<job>:<target>%` the target is written like in the job file, for example `miner:diamond_ore`.
</Details>
