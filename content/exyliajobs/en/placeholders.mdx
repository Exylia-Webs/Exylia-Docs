---
title: "Placeholders"
description: "The %exyliajobs_...% placeholders, through PlaceholderAPI and ExyliaLib."
---

Identifier `exyliajobs`. They resolve for the player viewing and read memory, so they are for online players. Job ids are lower case.

| Placeholder | Value |
|---|---|
| `%exyliajobs_level_<job>%` | The level (1 when not started). |
| `%exyliajobs_xp_<job>%` | Experience into the level, rounded down. |
| `%exyliajobs_needed_<job>%` | Experience needed for the next level (0 at max). |
| `%exyliajobs_prestige_<job>%` | Prestige stars as a number. |
| `%exyliajobs_stars_<job>%` | The star symbol once per star. |
| `%exyliajobs_stars%` | Every job's stars added up. |
| `%exyliajobs_joined%` | How many jobs the player holds. |
| `%exyliajobs_today%` | Money earned today (UTC) on this server. |
| `%exyliajobs_today_<job>%` | The same for one job. |
| `%exyliajobs_rate_<job>:<target>%` | The target's market rate in percent (100 when nothing changes it). |
| `%exyliajobs_top_<job>_<n>_<field>%` | The n-th best player; `field` is `name` (default), `level`, `prestige` or `xp`. |

`today` accepts ExyliaLib number formats such as `:comma`.
