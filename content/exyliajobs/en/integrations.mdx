Each integration lights up when the other plugin is installed, so most servers change nothing. At the end of this page you know how to decide where jobs pay: inside protections, during minigames, in staff mode and in mines.

## Before you start

You only need this page to change a default. The three switches below are in game; the network ones are in `integrations.yml`.

## Steps

<Steps>
  <Step title="Open the integration settings">
    Run `/jobsadmin`, click **Settings**, then **Integrations**.
  </Step>
  <Step title="Decide where jobs pay">
    Switch **Inside protections** (on by default: pay inside an ExyliaProtections protection), **During minigames** (off by default: pay while an arena, duel, event, queue or sandbox holds the player) and **In staff mode** (off by default: pay staff in ExyliaStaff's staff mode, frozen players and staff spectators).
  </Step>
  <Step title="Allow a job inside a mine">
    Blocks inside an ExyliaMines mine pay nothing unless the job allows it. Add `integrations: {mines: true}` to the job file (or a mine id, or a list of mine ids) and run `/jobsadmin reload`. Mine breaks then pay `break` through the mine's own event.
  </Step>
</Steps>

## Check that it works

Break a block inside a protection with **Inside protections** on and off: pay appears and disappears. Switch on staff mode with **In staff mode** off: nothing is paid until you leave it.

## Going further

### Pay for custom blocks and mobs

Write targets with the plugin prefix in the job's actions: `nexo:ruby_ore` (also Oraxen, ItemsAdder, CraftEngine), `mythicmobs:<id>` and `exyliamobs:<id>`. See [Change what a job pays](/docs/exyliajobs/jobs-and-actions).

### Use mcMMO with jobs

Pay comes from the break, kill or catch itself, never from drops, so double drops never pay twice. Each log Tree Feller fells pays once.

### Block a WorldGuard region

Add it to `disabled-regions` in the anti-exploit settings: [Stop farms and exploits](/docs/exyliajobs/anti-exploit).

<Details title="Technical details">

`integrations.yml`:

| Key | Default | Meaning |
|---|---|---|
| `pay-inside-protections` | true | Pay inside an ExyliaProtections protection. |
| `pay-during-minigames` | false | Pay while an arena, duel, event, queue or sandbox holds the player. |
| `pay-in-staff-mode` | false | Pay staff in ExyliaStaff's staff mode, frozen players and staff spectators. |
| `network-handover` | true | See [Run it on a network](/docs/exyliajobs/network). |
| `handover-wait` | 10s | Longest a join waits for the previous server. |

| Plugin | Behaviour |
|---|---|
| ExyliaMines | Blocks inside a mine pay nothing unless the job allows it (`integrations: {mines: ...}` in its file). |
| ExyliaProtections | Governed by `pay-inside-protections`. |
| ExyliaStaff | Governed by `pay-in-staff-mode`. |
| ExyliaMarket | Its worth list prices targets paid by `price-share`. |
| MythicMobs, ExyliaMobs | Kill targets `mythicmobs:<id>` and `exyliamobs:<id>` (MythicMobs 5, found through its API). |
| Nexo, Oraxen, ItemsAdder, CraftEngine | Custom block targets like `nexo:ruby_ore`. |
| ExyliaSpawners | Its classic spawner mobs count as spawner mobs. |
| mcMMO | Pay from the break, kill or catch, never from drops. |
| WorldGuard | `anti-exploit.disabled-regions`. |
| PlaceholderAPI | [Placeholders](/docs/exyliajobs/placeholders). |
| Vault / ExyliaEconomy | The default currency through ExyliaLib's economy. |
</Details>
