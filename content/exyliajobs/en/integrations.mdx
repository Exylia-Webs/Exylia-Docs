---
title: "Integrations"
description: "How ExyliaJobs works next to other plugins, and what `integrations.yml` switches."
---

`integrations.yml`:

| Key | Default | Meaning |
|---|---|---|
| `pay-inside-protections` | true | Pay inside an ExyliaProtections protection. |
| `pay-during-minigames` | false | Pay while an arena, duel, event, queue or sandbox holds the player. |
| `pay-in-staff-mode` | false | Pay staff in ExyliaStaff's staff mode, frozen players and staff spectators. |
| `network-handover` | true | See [Network](/docs/exyliajobs/network). |
| `handover-wait` | 10s | Longest a join waits for the previous server. |

| Plugin | Behaviour |
|---|---|
| ExyliaMines | Blocks inside a mine pay nothing unless the job allows it: `integrations: {mines: true}` (or a mine id, or a list) in its file. Mine breaks pay `break` through the mine's own event. |
| ExyliaProtections | Governed by `pay-inside-protections`. |
| ExyliaStaff | Governed by `pay-in-staff-mode`. |
| ExyliaMarket | Its worth list prices targets paid by `price-share`. |
| MythicMobs, ExyliaMobs | Kill targets `mythicmobs:<id>` and `exyliamobs:<id>` (MythicMobs 5, found through its API). |
| Nexo, Oraxen, ItemsAdder, CraftEngine | Custom block targets like `nexo:ruby_ore`. |
| ExyliaSpawners | Its classic spawner mobs count as spawner mobs. |
| ExyliaSurvivalCore | Its farming module stays off while ExyliaJobs is installed. |
| mcMMO | Pay comes from the break, kill or catch itself, never from drops, so double drops never pay twice; each log Tree Feller fells pays once. |
| WorldGuard | `anti-exploit.disabled-regions`. |
| PlaceholderAPI | [Placeholders](/docs/exyliajobs/placeholders). |
| Vault / ExyliaEconomy | The default currency through ExyliaLib's economy. |
