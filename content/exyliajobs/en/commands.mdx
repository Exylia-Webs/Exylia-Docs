## Player commands

Players only, all need `exyliajobs.use`.

| Command | What it does |
|---|---|
| `/jobs` | Opens the Jobs list. |
| `/jobs join <job>` | Joins a job (asks which to leave when slots are full). |
| `/jobs leave <job>` | Leaves a job after a confirmation. |
| `/jobs top <job>` | Opens the job's top list. |
| `/jobs orders` | Opens the work order board. |
| `/jobs perks <job>` | Opens the job's perks. |
| `/jobs prestige <job>` | Asks to prestige the job. |

A disabled job does not exist for `join`, `leave` and `top`.

## Admin commands

Every command here needs `exyliajobs.admin`, operators by default.

| Command | Console | What it does |
|---|---|---|
| `/jobsadmin` | | Opens the admin hub. |
| `/jobsadmin reload` | yes | Re-reads the configuration files and the jobs, and reports how many problems the jobs had. |
| `/jobsadmin give xp <player> <job> <amount>` | yes | Adds experience as if earned: level-ups, effects and milestone rewards included. The player must be online and loaded. |
| `/jobsadmin give level <player> <job> <level>` | yes | Sets a level outright (1 to the job's max); no rewards or effects. |
| `/jobsadmin economy` | | Opens the economy dashboard. |
| `/jobsadmin import <source> [-dry\|-confirm]` | yes | See [Migration](/docs/exyliajobs/migration). |

## Menu actions

Screens open each other through `exyliajobs:` actions, and a server's own menus can use them: `open_jobs`, `open_job`, `open_perks`, `open_orders`, `open_admin_hub`, `open_admin_jobs`, `open_admin_economy`, `open_admin_orders`, `open_admin_players`, `open_admin_migration` and `settings`. The admin ones need `exyliajobs.admin`.
