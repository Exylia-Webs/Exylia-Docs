At the end of this page the same jobs, levels, budget and work orders are shared by every server of your network.

## Before you start

You need a shared database (MySQL, MariaDB, PostgreSQL or MongoDB) and Redis. Without Redis each server keeps its own market and budget. There is no network switch in ExyliaJobs: it follows ExyliaLib's database configuration. See [Database](/docs/exylialib/database).

## Steps

<Steps>
  <Step title="Share the database">
    In ExyliaLib's `database.yml` on every server, point to the same database.
  </Step>
  <Step title="Enable Redis">
    On every server enable `database.redis` and give each one its **own** `server-id`.
  </Step>
  <Step title="Restart every server">
    The jobs, levels, work orders, budget and market are now shared. Turn `network-handover` off in `integrations.yml` on a server whose jobs are not shared.
  </Step>
</Steps>

## Check that it works

Level up on one server, switch to another and run `/jobs`: the level is the same. Post a work order on one server: it shows on the board of the other. Run `/jobsadmin economy` on both: the budget and the pay factor match.

## Going further

### What follows the player

- **Jobs follow the player.** The server holding a player keeps a cross-server lock on them from join to the end of their quit write; a join anywhere waits for it (at most `handover-wait`, 10 seconds) so the last write is always read.
- **Earnings are seeded from the ledger** on join (this hour and today, every server), so caps survive moving between servers.
- **Top lists, perks and pauses** come from the shared database; a pause is read again on join.

### What is shared

- **Market and budget** are shared over Redis: each server sends what it added every few seconds, so the market rate and the pay factor reflect the whole network.
- **Work orders** live in the database, every change takes a cross-server row lock, and other servers are told over Redis (a network without Redis converges within a minute).
- **Server orders** are posted by every server on its own; the maximum is per server.

Dashboard figures such as "today" placeholders are this server only.
