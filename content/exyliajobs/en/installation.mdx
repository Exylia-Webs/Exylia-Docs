## Getting the plugin

ExyliaJobs is a premium plugin, bought on [BuiltByBit](https://builtbybit.com/resources/exylia-jobs.136377/). It ships through the Lukittu loader, so the file you install is the
loader jar, `Exylia-Jobs-Loader.jar`. Bought on BuiltByBit, the licence is embedded in that jar: there is no key to enter. The loader checks the licence on every start and then
hands over to the plugin.

## Before you start

| Requirement | What for |
|---|---|
| Paper 1.21.1+ or Folia 1.21.4+ | The server. Folia is supported: every action is credited on the thread that owns it. |
| Java 21 | The runtime. |
| `ExyliaLib` | Required, **1.480.0** or newer (inferred: the first release with the jobs API, persistent escrow holds and the decaying counter). It provides the database, economy, prices, menus, rewards, abilities and the ledger. |
| `packetevents` | Required by ExyliaLib. |
| An economy | `ExyliaEconomy` or `Vault`. Without one the console warns once and job money is not paid. |

<Callout type="note" title="ExyliaLib is installed for you">
The loader's `paper-plugin.yml` does not require ExyliaLib on purpose: the loader installs it. On a server without ExyliaLib it downloads the newest
release into `plugins/` and a fresh install needs one more restart.
</Callout>

### Optional plugins

Each one lights up when it is installed; none is needed to start.

| Plugin | What it adds |
|---|---|
| `PlaceholderAPI` | The `%exyliajobs_...%` placeholders everywhere. See [Placeholders](/docs/exyliajobs/placeholders). |
| `WorldGuard` | `anti-exploit.disabled-regions`: regions where no job pays. |
| `MythicMobs`, `ExyliaMobs` | Kill targets `mythicmobs:<id>` and `exyliamobs:<id>`. |
| `ExyliaMarket` | Its worth list prices targets that pay by `price-share`. |
| `ExyliaMines` | Blocks inside a mine pay nothing unless a job allows it. |
| `ExyliaProtections`, `ExyliaStaff` | Land and staff mode do not pay by default. See [Integrations](/docs/exyliajobs/integrations). |

## Installing

<Steps>
  <Step title="Drop in the jar">
    `Exylia-Jobs-Loader.jar` into `plugins/`, next to `packetevents` and an economy plugin.
  </Step>
  <Step title="Start the server">
    The loader checks the licence and hands over to the plugin. If it had to install ExyliaLib, restart once more.
  </Step>
  <Step title="Let it generate">
    The plugin writes its configuration files, the twelve job files under `lang/<language>/jobs/` (a shipped job that is missing is installed again) and the `lang/` folder.
  </Step>
  <Step title="Try it">
    Run `/jobs`, join Miner and break some stone. See [First steps](/docs/exyliajobs/first-steps).
  </Step>
</Steps>

## Generated files

All of them live in `plugins/ExyliaJobs/`.

| File | Contents |
|---|---|
| `loader.yml` | Written by the loader: `license_key` and `version` (`auto` follows the newest release). |
| `config.yml` | Language, features, auto-join, slots, leaving, defaults, feedback, anti-exploit and storage. |
| `economy.yml` | The economy guard and the weekly report. |
| `perks.yml` | Swap fee and prestige. |
| `orders.yml` | Work orders and server orders. |
| `integrations.yml` | Pay inside protections, minigames, staff mode and the network handover. |
| `lang/<language>/jobs/<id>.yml` | One job per file. See [Jobs and actions](/docs/exyliajobs/jobs-and-actions). |
| `lang/<language>/` | Messages (one file per feature) and `menus/`; `menus/admin/` is written again from the jar on every start. |
| `imports/backup/` | Copies of job files an import merged into. |

English, Spanish, Portuguese, French, German and Russian ship. The `features` map in `config.yml` turns a whole feature off by name (`menus`, `orders`,
`placeholders`, `perks`, `economy`, `editor`, `integrations`, `importer`); it applies on restart.

## Updating

Replace the loader jar and restart, or leave `version: auto`. Configuration is kept and new keys are added with their defaults. Job files you edited are kept; new keys are added and changed defaults wait in `/exylialib updates`. A shipped job you delete is set aside as `<id>.yml.deleted` so it does not come back; rename it to restore it.
