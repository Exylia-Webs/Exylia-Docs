---
title: "Permissions"
description: "Every node ExyliaJobs checks and its default."
---

| Node | Default | What it allows |
|---|---|---|
| `exyliajobs.use` | everyone | Open `/jobs`, join and leave jobs, deliver to work orders and **be paid**. Without it nothing pays. |
| `exyliajobs.admin` | op | Every `/jobsadmin` command and the admin screens. |
| `exyliajobs.orders.post` | everyone | Post work orders. |
| `exyliajobs.orders.limit.unlimited` | op | No cap on open work orders. |
| `exyliajobs.orders.limit.<n>` | none | Raises the open order cap to `n` (highest wins, never lowers `orders.yml`'s `limit`). |
| `exyliajobs.slots.<n>` | none | Raises job slots to `n` (highest wins, never lowers `slots`). |
| `exyliajobs.caps.<group>` | none | Puts the player in a cap group of `economy.yml`; the most generous group wins. |

Only the first four are declared in `paper-plugin.yml`; the numbered nodes and the cap groups are checked by name.
