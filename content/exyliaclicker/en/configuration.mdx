`plugins/ExyliaClicker/config.yml` holds the settings for the whole plugin. The settings you tune while the server runs are also on screens in `/clickeradmin settings`. Run `/clickeradmin reload` after editing a file.

## config.yml

| Key | Default | Meaning |
|---|---|---|
| `language` | `default` | Language of the messages and menus. |
| `debug` | `false` | Writes extra detail to the console. |
| `theme` | `harvest` | The folder under `themes/`. Needs a restart. |
| `profiles` | `default` | Where farmers' progress is kept: `default`, `global`, `server` or the name of a network group. |
| `save-interval` | `1m` | How often profiles are saved. |
| `max-clicks-per-second` | `15` | Clicks above this are ignored, from 1 to 40. |
| `remote-sell-cooldown` | `5m` | Wait between `/clicker sell` away from a sell point. |
| `min-income-per-minute` | `20` | A floor for income so a new farmer never earns nothing. |
| `menu-style` | `SCREEN` | `SCREEN`, `CLASSIC` or `DEFAULT`. Bedrock and old clients always get chest windows. |
| `store-url` | `https://store.example.net` | The link shown where a message says `%store_url%`. |

### Luck

`variants` holds one block per rare variant. `chance` reads as 1 in N before luck, `multiplier` is the pay compared with a normal harvest, `pity` is how many of a player's own harvests without one end bad luck (0 is never) and `first` is the same for a player's very first one.

| Variant | Chance | Pay | Pity | First |
|---|---|---|---|---|
| `golden` | 1/50 | x10 | 150 | 40 |
| `rainbow` | 1/1000 | x50 | 3000 | none |
| `galactic` | 1/25000 | x250 | 75000 | none |

### Tailwind, combo and resets

| Key | Default | Meaning |
|---|---|---|
| `tailwind.enabled` | `true` | Catch-up bonus for farmers behind the pack. |
| `tailwind.max-bonus` | `100` | Biggest bonus, in percent. |
| `combo.enabled` | `true` | Fast clicks build a combo. |
| `combo.window` | `2s` | Time to land the next hit before the combo drops. |
| `combo.frenzy-hits` | `60` | Hits in a row that start Frenzy. |
| `combo.frenzy-time` | `10s` | How long Frenzy lasts. |
| `combo.frenzy-multiplier` | `2` | Pay multiplier during Frenzy. |
| `resets.timezone` | empty | Timezone of the day and week start. Empty is the server's. |
| `resets.hour` | `0` | Hour a new day starts. |
| `resets.week-start` | `MONDAY` | First day of the week. |
| `index.stat` | `coin_multiplier` | The stat each index page raises. |
| `index.per-zone` | `5%` | The bonus per completed zone. |

Give every server of a network the same `resets`, so daily rewards, streaks and weekly tops line up.

## Other files

| File | What it is for |
|---|---|
| `layout.yml` | The area of each zone and of the AFK zone. Written by the wizard, not by hand. |
| `spots.yml` | Sell points and the story speaker. Edited in the Spots screen. |
| `interface.yml` | The sidebar, the HUD, the tab list, the hotbar buttons, the no-zone name, the goals lines and the chat tag. |
| `messages.yml`, `menu-text.yml` | Every message and screen text, per language under `lang/<code>/`. |
| `themes/<theme>/` | The game's content. See [Theme files](/docs/exyliaclicker/theme-files). |

The HUD and the tab list have an `enabled` switch in `interface.yml`. The hotbar buttons (tool, quests, boosts, passes, shop, rebirth, zones, helpers, menu) each have a slot and a command, so you can move or remove them.

<Callout type="info" title="Colours">
Colours in messages are written as palette tokens such as `{primary}`, so one palette change restyles every screen.
</Callout>
