## Install

<Steps>
  <Step title="Install the dependencies">
    Put ExyliaLib and PacketEvents in `plugins/`. Add PlaceholderAPI if you want placeholders in other plugins. ExyliaLib needs a database for player data; if you have not set one, follow [Database setup](/docs/exylialib/database-setup).
  </Step>
  <Step title="Add ExyliaClicker">
    Put the ExyliaClicker jar in `plugins/` and start the server.
  </Step>
  <Step title="Check the console">
    ExyliaClicker loads after ExyliaLib. If ExyliaLib is missing, the server says so by name.
  </Step>
</Steps>

## Files it creates

In `plugins/ExyliaClicker/`:

| File | What it holds |
|---|---|
| `config.yml` | Server-wide settings: language, theme, click cap, variants, combo, resets. See [Configuration](/docs/exyliaclicker/configuration). |
| `layout.yml` | Where each zone and the AFK area are. Written by the wizards, not by hand. |
| `spots.yml` | The sell spots. Written by the spots editor. |
| `interface.yml` | The sidebar, the corner texts, the tab list, the hotbar and the chat tag. |
| `messages.yml`, `menu-text.yml` and the other message files | What players read. |
| `themes/harvest/` | The content pack: zones, nodes, upgrades, tools, rebirth, enchants, helpers, eras, shop, quests, rewards and releases. See [Theme files](/docs/exyliaclicker/theme-files). |

The menu and message files are translated; see [Messages and languages](/docs/exylialib/messages-and-languages) for how the language is chosen.

## Reload

`/clickeradmin reload` reads the files again. Changing `theme` in `config.yml` needs a restart.

## Several servers

`profiles` in `config.yml` decides which servers share a player's profile: `default` follows the network group set in ExyliaLib, `global` shares everything, `server` keeps this server alone, or you write a group's name. Give every server of a network the same `resets` clock so days and weeks start together.
