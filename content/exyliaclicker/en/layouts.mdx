ExyliaClicker has two map layouts. Both work on a fresh install with a ready-made build, you can switch between them at any time, and you can let them take turns by season.

## The two layouts

| | Zones (default) | Plot |
|---|---|---|
| Shape | Several zones along the hub's avenue, each with its own area. | One farm with a farmhouse in the middle and one section per zone around it. |
| Buying | Each zone is bought with coins, as in [Upgrades, tools and zones](/docs/exyliaclicker/upgrades-tools-zones). | The same: each section is a zone and opens the same way. |
| Who sees it | Everyone shares the zones. | Players only see their own plot. Other players are hidden inside it. |
| Feels like | A busy farm with lots of players. | A private farm that grows with every rebirth. |

Pick **zones** for a lively server where players farm side by side. Pick **plot** for a personal, calmer game with something to show off. The hub, garden, AFK area, bosses and arenas stay on the main island in both layouts, so those moments stay shared.

## It works out of the box

On a fresh install the plugin builds a starter map with the zones layout and also a starter plot beside the island. The plot has a farmhouse in the middle (sell, shop, upgrades, enchanting and rebirth stalls, and a pad back to the hub) and one section per zone in a spiral around it, in the order players unlock them. You do not need to place anything to try plot mode.

## Switch the layout

<Steps>
  <Step title="Open the settings">
    Run `/clickeradmin settings` and click the **Layout** card. It shows the current layout and the next scheduled switch.
  </Step>
  <Step title="Confirm">
    Click it and confirm. Or run `/clickeradmin mode plot` (or `/clickeradmin mode zones`).
  </Step>
</Steps>

The switch happens at once. Every online player is sent to the new layout's spawn and sees a message. Nothing is lost: zone ids are the same as section ids, so every player keeps the zones they have opened, their coins and their rebirths.

If the starter plot is missing and you switch to plot mode, the plugin tells you there is no plot yet. Place one as described below.

<Callout type="note" title="Changing the layout by hand">
A manual switch writes the new mode to `config.yml` and drops the scheduled switches that already passed, so they do not undo it.
</Callout>

## Switch by season

To change the layout on a date, add a schedule in `config.yml`:

```yaml
layout:
  mode: zones
  schedule:
    - { from: '2026-12-01', mode: plot }
    - { from: '2027-01-01', mode: zones }
```

The plugin checks every minute. The latest entry whose date has started wins over `mode`. `from` is `yyyy-MM-dd` or `yyyy-MM-dd HH:mm`, quoted, on the time zone of the reset clock (`resets.timezone`). When a switch starts, it behaves like a manual one.

## What the plot shows

- **Only to its owner.** The plot is drawn for each player with packets, so other players do not see your sections or your decor. Inside the plot other players are hidden. In the hub you see everyone as usual.
- **Locked sections look like wild ground.** A section you have not opened is drawn as grass and a few bushes, with a low fence and a hologram with its price and rebirths. Entering is refused or offered for purchase, as in zones mode.
- **Unlocking reveals it.** The wild ground clears outward over about a second, with a quiet sound, only for the player who opened it.
- **Plot levels from rebirths.** The plot grows with a player's total rebirths. Each level can add decor and buildings (the default theme has flower beds, a barn, a scarecrow, a mill, a greenhouse and beehives) and a bonus. The rebirth screen shows what the next rebirth adds. Nothing is stored: the level is read from the rebirths.

The bonuses of plot levels count in **both** layouts, so switching is fair. Only how they look is plot-only. Levels are listed in `plot.yml` of each theme, see [Theme files](/docs/exyliaclicker/theme-files).

## Visits and likes

In plot mode, `/clicker visit <player>` sends you to a player's plot. You see their nodes, buildings and decor, and you cannot farm them. The owner must be online. A visit ends with `/clicker plot`, by walking out, by teleporting away, when the owner leaves or when the layout switches.

`/clicker like` likes the plot you are visiting, once a day per plot. Likes are counted on the owner's profile and in `%exyliaclicker_plot_likes%`. In zones mode the same two commands visit and like gardens.

## Moving between hub and plot

- `/clicker plot` takes you to your own plot. `/clicker hub` takes you to the hub.
- On the starter map the farmhouse has a pad that returns you to the hub, and the hub plaza has a pad to the plot (it works in plot mode only).

## Place or edit the plot

If you build your own plot, use the wizards. They need `exyliaclicker.admin`.

<Steps>
  <Step title="Place the whole plot">
    Run `/clickeradmin plot`. You select the plot's area, stand where players arrive, then select one section per zone. Confirm to save. The plugin rebuilds every farm.
  </Step>
  <Step title="Fix one section">
    Run `/clickeradmin plot section <zone>` and select that zone's section again.
  </Step>
</Steps>

Both write to `layout.yml`, as the wizards for zones do. Do not edit that file by hand.

## Settings

| Key in `config.yml` | What it does | Default |
|---|---|---|
| `layout.mode` | `zones` or `plot`, while no scheduled switch has started. | `zones` |
| `layout.schedule` | Dated switches, each `{ from, mode }`. | empty |
