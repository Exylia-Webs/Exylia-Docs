Every ExyliaClicker command, with the permission it needs. Zones, upgrades, passes and players complete as you type. Players use `/clicker`; staff use `/clickeradmin`.

<Commands />

## Notes

- `/clicker` alone opens the main menu. Every other `/clicker` command opens its own screen, or does the action when you give it an argument, such as `/clicker upgrade <upgrade> 10`.
- Amounts are written 500, 15K, 2.5M and so on, with K, M, B, T and larger suffixes.
- `/clicker sell` works anywhere for farmers with the Remote Sell pass, and otherwise at a sell point or after the `remote-sell-cooldown` wait. See [Farming](/docs/exyliaclicker/farming).
- `/clicker rebirth <count>` rebirths several times at once when the farmer can afford it. Everything else about a rebirth is in [Rebirth, perks and eras](/docs/exyliaclicker/rebirth-and-eras).
- `/clickeradmin reload` reads every file again and rebuilds the farms. A new `theme` in `config.yml` needs a restart instead.
- `/clickeradmin code create <code> <minutes> <gems> [uses] [expires]` makes a code that pays that many minutes of income and gems. Without `uses` and `expires` it never runs out.
- `/clickeradmin boost give` gives a boost to one online player; `boost global` runs one for everyone on this server.
- `/clickeradmin zone area` and `afk area` open the area wizard.
