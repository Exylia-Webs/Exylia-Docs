ExyliaClicker does not ship a map. You build the zones, then tell the plugin where they are. Do this in game as an admin with `exyliaclicker.admin`.

## Build each zone's floor

A zone grows a node on every block of the right floor inside its area, with air above it. Each node names the floor blocks it grows on in `nodes.yml`, so build each zone's floor from the blocks its nodes name. A zone's slots are found again from the world on every start, so a rebuilt zone needs no new setup.

## Set the zones

<Steps>
  <Step title="Open the zones screen">
    Run `/clickeradmin`, then open Zones. Or run `/clickeradmin zone area <zone>` with the zone's id.
  </Step>
  <Step title="Select the area">
    The area wizard asks you to select the corners. Players stand above the floor you select, so the height does not matter when they move.
  </Step>
  <Step title="Confirm">
    The plugin saves the area to `layout.yml`, counts the slots and rebuilds every farm. The message tells you how many slots the zone has.
  </Step>
</Steps>

Do this for every zone of the theme, starting with the first one, which is open to new players.

## Add sell points

Open `/clickeradmin spots` and add a sell spot. A player who clicks it sells their whole backpack. Away from a sell point, `/clicker sell` works too, with a cooldown of `remote-sell-cooldown` (5 minutes by default) unless the player owns the Remote Sell pass. Set it to `0s` to let players sell anywhere.

## Set the AFK area

Run `/clickeradmin afk area` and select the area. Players who stand in it earn gems. See [Rewards](/docs/exyliaclicker/rewards).

## Check that it works

- Stand in the first zone: you see crops that only you can hit.
- Hit a ripe crop. It goes into the backpack.
- Click a sell spot. The backpack turns into coins.

If a zone shows no crops, see [Troubleshooting](/docs/exyliaclicker/troubleshooting).
