Everything the game is made of lives in a theme: a folder of files under `plugins/ExyliaClicker/themes/<theme>/`. The default theme is `harvest`. The files are written the first time the plugin starts, with comments above each key, so you can read them as documentation.

Edit them in the [web editor](/docs/exyliaclicker/admin-panel) or by hand, then run `/clickeradmin reload`. A bad entry costs that entry only, and the problems are listed.

| File | What it holds |
|---|---|
| `zones.yml` | The zones in order. The first one is open from the start. Each has a price, the rebirths it needs, a multiplier, luck, its nodes with how often each shows up, and an optional pass. See [Upgrades, tools and zones](/docs/exyliaclicker/upgrades-tools-zones). |
| `nodes.yml` | What grows or sits on the farm: crop, block or search type, the floor blocks it needs, regrow time, health and its drops, each with a chance such as `1/60`, a rarity and an announcement. |
| `upgrades.yml` | The base stats and the upgrades: per-level gain, soft cap and falloff, cost and cost growth, the zone that unlocks each and its icon. |
| `tools.yml` | The tool tiers with their power, harvest speed, area, price, zone and rebirths needed, and the stars. |
| `rebirth.yml` | Cost, cost growth, multiplier, tokens, milestones, the token shop perks and the cards. See [Rebirth, perks and eras](/docs/exyliaclicker/rebirth-and-eras). |
| `enchants.yml` | Farmer XP, the enchanting table, the anvil, book chance and the enchants. See [Enchants](/docs/exyliaclicker/enchants). |
| `helpers.yml` | Offline rate and hours, upgrade tracks, milestones and one helper per zone. See [Helpers](/docs/exyliaclicker/helpers). |
| `eras.yml` | Each era: the rebirths it needs, time, weather, particle and the block swaps that reskin the farm. |
| `shop.yml` | Passes and boosts. See [Shop, boosts and passes](/docs/exyliaclicker/shop-and-passes). |
| `quests.yml` | Daily and weekly quests, reroll price, the speaker and the story. See [Quests and story](/docs/exyliaclicker/quests-and-story). |
| `rewards.yml` | Gifts, streak, roulette, AFK and visitors. See [Rewards](/docs/exyliaclicker/rewards) and [Tops and visitors](/docs/exyliaclicker/tops-and-visitors). |
| `releases.yml` | Scheduled updates: when, name, news, and the zones and eras held back until then. |

## Eras

An era swaps blocks of the same shape for others, so a swap that would change a block's shape is left out and written to the log. Preview an era with `/clickeradmin era <era>`, and go back with `/clickeradmin era`.

## Make your own theme

1. Stop the server, copy `themes/harvest` to `themes/<your-theme>`.
2. Set `theme: <your-theme>` in `config.yml`.
3. Start the server, edit the files, and reload.

Changing the `theme` needs a restart. A theme is shared by the whole server; the player data belongs to the `profiles` setting, not to the theme. See [Configuration](/docs/exyliaclicker/configuration).

<Callout type="warning" title="After a change">
Run [the pace simulator](/docs/exyliaclicker/balancing) after changing prices, costs or multipliers. A small change to a growth value compounds over hundreds of levels.
</Callout>
