Dos comandos: `/spawners` para los jugadores y `/spawnersadmin` para el staff.

## Comandos de jugador

Solo para jugadores.

| Comando | Permiso | Qué hace |
|---|---|---|
| `/spawners` | `exyliaspawners.use` | Abre **TUS GENERADORES**: todos los spawners que tienes, en toda la red en modo red. |
| `/spawners sell` | `exyliaspawners.remote` | Vende el almacén de todos los spawners que tienes en este servidor, con un solo recibo. |
| `/spawners hologram` | `exyliaspawners.hologram` | Oculta o muestra los hologramas de los spawners para ti. |
| `/spawners trust <player>` | `exyliaspawners.use` | Hace jugador de confianza a alguien en el spawner que miras (a seis bloques como mucho). Solo el dueño o el staff. |
| `/spawners untrust <player>` | `exyliaspawners.use` | Le quita la confianza. |

Todo lo demás que un jugador hace con un spawner ocurre en el bloque y sus pantallas: colocar, apilar, abrir,
picar y purificar. Consulta [Spawners](/docs/exyliaspawners/spawners).

## Comandos de administración

Todos los comandos de aquí necesitan `exyliaspawners.admin`, que tienen los operadores por defecto.

| Comando | Consola | Qué hace |
|---|---|---|
| `/spawnersadmin` | | Abre el panel de administración. |
| `/spawnersadmin give <player> <type> [amount] [tier]` | sí | Da un objeto que contiene `amount` spawners (1 por defecto, 100.000 como mucho) de ese tipo y tier (1 por defecto). Lo que no cabe en el inventario cae a los pies del jugador. |
| `/spawnersadmin booster give <player> <id> [amount]` | sí | Da objetos de potenciador de `boosters.yml`, hasta 64. |
| `/spawnersadmin corrupt` | | Corrompe el spawner que miras (a ocho bloques como mucho). |
| `/spawnersadmin repair` | | Purifica gratis el spawner que miras. |
| `/spawnersadmin editor` | | Abre el editor de tipos de spawner; `editor types` hace lo mismo. |
| `/spawnersadmin editor tiers` | | Abre el editor de tiers. |
| `/spawnersadmin editor web` | sí | Abre los archivos del plugin en el editor web de ExyliaLib. |
| `/spawnersadmin dashboard` | | Abre el panel de economía. |
| `/spawnersadmin import <source> [-dry]` | sí | Importa spawners de `smartspawner`, `virtualspawner`, `wildstacker`, `rosestacker` o `litspawners`. Consulta [Importar](/docs/exyliaspawners/importar). |
| `/spawnersadmin reload` | sí | Vuelve a leer todos los archivos e informa de los problemas encontrados en los tipos y los tiers. |

`give` sugiere los ids de los tipos activados; `booster give` sugiere los ids de los potenciadores. Una tienda o una
caja reparte spawners y potenciadores ejecutando estos dos comandos desde la consola.

## Acciones de menú

Las pantallas se abren unas a otras con estas acciones, y los menús propios de un servidor también pueden usarlas.
Las acciones sobre un spawner actúan sobre el spawner para el que se abrió la pantalla.

| Acción | Qué hace |
|---|---|
| `exyliaspawners:open_hub` | El panel del spawner. |
| `exyliaspawners:open_storage` | Su almacén. |
| `exyliaspawners:open_upgrades` | Sus mejoras. |
| `exyliaspawners:open_boosters` | Sus potenciadores. |
| `exyliaspawners:open_trust` | Sus jugadores de confianza. |
| `exyliaspawners:open_corruption` | Su pantalla de corrupción. |
| `exyliaspawners:open_my_spawners` | **TUS GENERADORES**. |
| `exyliaspawners:sell_all` | Vende el almacén. |
| `exyliaspawners:pickup` | Pide confirmación y luego recoge la pila entera. |
| `exyliaspawners:take <one\|stack\|all>`, `sell_item` | En una fila del almacén: saca o vende ese objeto. |
| `exyliaspawners:take_all`, `claim_xp`, `collect_all` | Saca todo, reclama la experiencia, o las dos cosas. |
| `exyliaspawners:toggle_autosell` | Activa o desactiva la autoventa. |
| `exyliaspawners:upgrade <speed\|amount\|storage\|xp>` | Compra el siguiente nivel de una línea de mejora. |
| `exyliaspawners:booster <speed\|loot\|xp\|money>` | Mete o saca ese potenciador. |
| `exyliaspawners:trust_add`, `trust_remove` | Pide un nombre al que dar confianza; en una fila de confianza, se la quita. |
| `exyliaspawners:corruption_cleanse` | Cierra la pantalla y explica cómo purificar. |
| `exyliaspawners:remote_sell` | En una fila de **TUS GENERADORES**: vende ese spawner. |

Las acciones de administración comprueban `exyliaspawners.admin` por sí mismas: `open_admin_hub`, `open_admin_types`,
`open_admin_tiers`, `open_admin_loot` y `open_admin_dashboard`.
