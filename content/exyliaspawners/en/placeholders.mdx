---
title: "Placeholders"
description: "The values spawner screens, the hologram and the items can show, for restyling them. ExyliaSpawners registers no PlaceholderAPI placeholders."
---

ExyliaSpawners registers no `%exyliaspawners_...%` placeholders with PlaceholderAPI or ExyliaLib: its values are
about one spawner, and they live on the screens, the hologram and the items that show that spawner. This page lists
them so you can restyle those files. Values that move (stack, storage, countdowns) update while a screen is open.

## Spawner screens

The hub (`menus/hub.yml`), the storage (`menus/storage.yml`) and every row of **My spawners**
(`menus/my_spawners.yml`) can show:

| Placeholder | Value |
|---|---|
| `%spawner_type%`, `%spawner_type_upper%` | Its type's display name, as written or upper case. |
| `%spawner_id%` | Its id. |
| `%spawner_tier%` | Its tier. |
| `%spawner_stack%`, `%spawner_limit%` | Spawners in the stack, and the type's or tier's stack limit. |
| `%spawner_owner%` | The owner's name, or "None". |
| `%spawner_mode%` | `Virtual` or `Classic`, from `labels` in `messages.yml`. |
| `%spawner_state%` | "Producing" while a player is in range, else "Waiting for a player". |
| `%next_cycle%` | Time until the next cycle, or `-` while waiting. |
| `%level_speed%`, `%level_amount%`, `%level_storage%`, `%level_xp%` | The level of each track. |
| `%storage_items%`, `%storage_capacity%`, `%storage_fill%` | Items stored, the cap, and how full as a percentage. |
| `%storage_xp%`, `%storage_xp_capacity%` | Experience stored and its cap. |
| `%spawner_world%`, `%spawner_location%` | Its world and `x, y, z`. |
| `%feature_lines%` | Every value below as ready lore lines, `▎ Label » value`. |

Every feature adds its own values by name:

| Placeholder | Value |
|---|---|
| `%corruption_state%`, `%corruption_effect%`, `%corruption_time%` | Corruption state, the tier's effect, and the time left on its timer. Only where corruption applies. |
| `%booster_speed%`, `%booster_loot%`, `%booster_xp%`, `%booster_money%` | That booster's multiplier and time left, or "None". |
| `%booster_count%`, `%booster_active%`, `%booster_remaining%` | Boosters running, "Active" or "None", and the time until the first one ends. |
| `%autosell%`, `%autosell_state%` | Autosell as "On"/"Off", and as `on`/`off`. |
| `%money_per_hour%` | What its sales paid in the last hour. |

`%feature_lines%` lists every one of these values, the track levels included. Its labels come from
`menus.feature-labels` in `messages.yml`, empty by default, so each name shows in title case (`corruption_state`
reads "Corruption state", in every language). Add the ones you show, for example `corruption_state: Corruption`,
or replace `%feature_lines%` in `hub.yml` with the single values you want.

The storage screen adds `%can_sell%` and `%bedrock%` (`true`/`false`), and on each row `%item_material%`,
`%item_name%`, `%item_amount%` and `%can_sell_line%`. **My spawners** adds `%owned_count%` and, on each row,
`%remote_line%`, which hides its line for players without `exyliaspawners.remote`.

The upgrades screen has, per track (`speed`, `amount`, `storage`, `xp`), `%<track>_level%`, `%<track>_max%`,
`%<track>_value%`, `%<track>_next%`, `%<track>_cost%` and `%<track>_prompt%`. The boosters screen has, per kind,
`%<kind>_state%` and `%<kind>_prompt%`. The corruption screen adds `%corruption_effect_info%`, `%cleanse_cost%`,
`%cleanse_range%`, `%cleanse_time%` and `%cleanse_grace%`. The trust screen has `%trusted_count%`, `%can_manage%`, and
on each row `%player_name%`, `%trusted_since%` and `%manage_line%`.

## Holograms

`lines` and `optional-lines` in `hologram.yml`:

| Placeholder | Value |
|---|---|
| `%type%`, `%type_upper%`, `%type_id%` | Display name, upper case, and the type id. |
| `%stack%`, `%stack_limit%`, `%tier%`, `%mode%` | Stack, its limit, tier and mode. |
| `%stored%`, `%capacity%`, `%fill%`, `%bar%` | Items stored, the cap, percent full (0-100) and the storage bar. |
| `%xp%`, `%xp_capacity%` | Experience stored and its cap. |

Plus every feature value above (`%corruption_state%`, `%booster_active%`, ...) and any PlaceholderAPI placeholder.

## Items

`spawner-item.yml`: `%type%`, `%type_upper%`, `%tier%`, `%stack%`, `%mode%`. `booster-item.yml`: `%kind%`,
`%kind_upper%`, `%multiplier%`, `%time%`.
