---
title: "Permissions"
description: "Every permission node of ExyliaSpawners, its default, and the numbered nodes for stack size, placement limit and mining chance."
---

| Permission | Default | Grants |
|---|---|---|
| `exyliaspawners.use` | everybody | Placing, stacking, opening, mining and cleansing spawners; `/spawners`, `/spawners trust` and `/spawners untrust`. |
| `exyliaspawners.mine.<type>` | everybody (`mine.*`) | Mining that type. Checked only with `mining.require-type-permission`. |
| `exyliaspawners.place.<type>` | everybody (`place.*`) | Placing that type, and changing a spawner to it with an egg. Checked only with `placement.require-type-permission`. |
| `exyliaspawners.egg` | everybody | Changing a spawner's type with a spawn egg, when `egg-change.enabled` is on. |
| `exyliaspawners.hologram` | everybody | `/spawners hologram`. |
| `exyliaspawners.autosell` | nobody | Turning autosell on; autosell keeps running only while the owner holds it. |
| `exyliaspawners.remote` | nobody | Selling from **My spawners** and `/spawners sell`, and selling spawners on other servers. |
| `exyliaspawners.admin` | operators | Every `/spawnersadmin` command and admin screen, and passing the trust check on every spawner. |

<Callout type="note" title="Per-type permissions start granted">
`exyliaspawners.mine.*` and `exyliaspawners.place.*` are granted to everybody, so turning on
`require-type-permission` changes nothing by itself. To gate types, negate the wildcard for the group and grant
`exyliaspawners.mine.<type>` or `exyliaspawners.place.<type>` per type, for example `exyliaspawners.mine.blaze`.
</Callout>

## Numbered permissions

The highest number a player holds wins.

| Permission | What the number is |
|---|---|
| `exyliaspawners.stack.<n>` | Most spawners in one stack. It raises the type's or tier's stack limit, never lowers it. |
| `exyliaspawners.limit.<n>` | Most spawner blocks the player may have placed. When the player holds one, it replaces `placement.player-limit`. |
| `exyliaspawners.chance.<n>` | Percent chance that mining drops the spawner. It raises `mining.chance`, never lowers it. |

A player limit counts **blocks**, not spawners: a stack of 64 is one block. In network mode it counts the
player's blocks on every server.
