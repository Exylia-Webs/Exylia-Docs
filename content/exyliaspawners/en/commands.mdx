Two commands: `/spawners` for players and `/spawnersadmin` for staff.

## Player commands

Players only.

| Command | Permission | What it does |
|---|---|---|
| `/spawners` | `exyliaspawners.use` | Opens **My spawners**: every spawner you own, across the network in network mode. |
| `/spawners sell` | `exyliaspawners.remote` | Sells the storage of every spawner you own on this server, with one receipt. |
| `/spawners hologram` | `exyliaspawners.hologram` | Hides or shows spawner holograms for you. |
| `/spawners trust <player>` | `exyliaspawners.use` | Trusts a player on the spawner you look at (within six blocks). Owner or staff only. |
| `/spawners untrust <player>` | `exyliaspawners.use` | Stops trusting them. |

Everything else a player does with a spawner happens on the block and its screens: placing, stacking, opening,
mining and cleansing. See [Spawners](/docs/exyliaspawners/spawners).

## Admin commands

Every command here needs `exyliaspawners.admin`, operators by default.

| Command | Console | What it does |
|---|---|---|
| `/spawnersadmin` | | Opens the admin hub. |
| `/spawnersadmin give <player> <type> [amount] [tier]` | yes | Gives one item holding `amount` spawners (1 by default, at most 100,000) of that type and tier (1 by default). What does not fit in the inventory drops at the player's feet. |
| `/spawnersadmin booster give <player> <id> [amount]` | yes | Gives booster items from `boosters.yml`, up to 64. |
| `/spawnersadmin corrupt` | | Corrupts the spawner you look at (within eight blocks). |
| `/spawnersadmin repair` | | Cleanses the spawner you look at, free. |
| `/spawnersadmin editor` | | Opens the spawner type editor; `editor types` does the same. |
| `/spawnersadmin editor tiers` | | Opens the tier editor. |
| `/spawnersadmin editor web` | yes | Opens the plugin's files in ExyliaLib's web editor. |
| `/spawnersadmin dashboard` | | Opens the economy dashboard. |
| `/spawnersadmin import <source> [-dry]` | yes | Imports spawners from `smartspawner`, `virtualspawner`, `wildstacker`, `rosestacker` or `litspawners`. See [Importing](/docs/exyliaspawners/importing). |
| `/spawnersadmin reload` | yes | Reads every file again and reports the problems found in the types and tiers. |

`give` suggests the enabled type ids; `booster give` suggests the booster ids. A shop or crate hands out spawners
and boosters by running these two commands from the console.

## Menu actions

The screens open each other through these, and a server's own menus can use them too. Actions about a spawner work
on the spawner the screen was opened for.

| Action | What it does |
|---|---|
| `exyliaspawners:open_hub` | The spawner's hub. |
| `exyliaspawners:open_storage` | Its storage. |
| `exyliaspawners:open_upgrades` | Its upgrades. |
| `exyliaspawners:open_boosters` | Its boosters. |
| `exyliaspawners:open_trust` | Its trusted players. |
| `exyliaspawners:open_corruption` | Its corruption screen. |
| `exyliaspawners:open_my_spawners` | **My spawners**. |
| `exyliaspawners:sell_all` | Sells the storage. |
| `exyliaspawners:pickup` | Asks to confirm, then picks the whole stack up. |
| `exyliaspawners:take <one\|stack\|all>`, `sell_item` | On a storage row: takes or sells that item. |
| `exyliaspawners:take_all`, `claim_xp`, `collect_all` | Takes everything, claims the experience, or both. |
| `exyliaspawners:toggle_autosell` | Turns autosell on or off. |
| `exyliaspawners:upgrade <speed\|amount\|storage\|xp>` | Buys the next level of a track. |
| `exyliaspawners:booster <speed\|loot\|xp\|money>` | Inserts or takes out that booster. |
| `exyliaspawners:trust_add`, `trust_remove` | Asks for a name to trust; on a trust row, stops trusting them. |
| `exyliaspawners:corruption_cleanse` | Closes the screen and explains how to cleanse. |
| `exyliaspawners:remote_sell` | On a **My spawners** row: sells that spawner. |

Admin actions check `exyliaspawners.admin` themselves: `open_admin_hub`, `open_admin_types`, `open_admin_tiers`,
`open_admin_loot` and `open_admin_dashboard`.
