Use these to show live ExyliaCombat data in any plugin that supports PlaceholderAPI, such as scoreboards, tab lists, holograms and chat. Click a placeholder to copy it.

The plugin registers them through ExyliaLib, so the same names work inside other Exylia plugins' own files, and through PlaceholderAPI with no download from the eCloud. Every value is about the player who sees it. A placeholder of a module that is off is not registered.

<Placeholders />

## Leaderboards

Replace `<stat>` with `kills`, `deaths`, `kdr`, `streak`, `beststreak` or `points`, and `<rank>` with a place starting at 1. The boards are the cached ones behind `/combattop`, refreshed every `leaderboard.refresh-interval` and holding `leaderboard.size` players.

```text
%exyliacombat_top_kills_1_name%      who is first by kills
%exyliacombat_top_kills_1_value%     how many kills they have
%exyliacombat_top_points_3_value%    points of the third player
```

Leaving the last part out gives the name.

## Bounties

Put a player's name where the table says `<player>`. The name must belong to a player the server already knows: a name that is not loaded gives zero. `<n>` is a place starting at 1.

```text
%exyliacombat_bounty_total_Steve%    money on Steve's head
%exyliacombat_bounty_top_name_1%     the most wanted player
```

<Details title="Technical details">
A placeholder that shows as raw text usually means PlaceholderAPI is missing, the module is off or the stat name is misspelled.
</Details>
