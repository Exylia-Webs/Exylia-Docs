`config.yml` holds what every server needs. Each module keeps its settings in `modules/<module>/config.yml`,
documented on that module's page. Times are written `15s`, `5m` or `1h30m`; colours use palette tokens such
as `{primary}`. Apply a change with `/combatadmin reload`, except module switches and command names, which
are read at startup.

## Language

| Key | Default | What it does |
|---|---|---|
| `language` | `default` | `default` follows the language set in ExyliaLib's `config.yml`; `en`, `es`, `pt`, `fr`, `ru` or `tr` set this plugin alone. Each is a folder under `lang/` you can edit. |

## Commands

| Key | Default | What it does |
|---|---|---|
| `commands.combat-time` | `[combat, ct]` | `/combat`: how long the player's tag still lasts. |
| `commands.admin` | `[combatadmin]` | The admin command every `reload`, `settag`, `cooldown`, `pvp`... hangs from. |

## Player record

| Key | Default | What it does |
|---|---|---|
| `player-data.save-interval` | `5m` | How often changed records of online players are written, besides on quit. Never less than 30 seconds. |

## Combat: `combat`

| Key | Default | What it does |
|---|---|---|
| `combat.provider` | `AUTO` | Who decides the tag: `AUTO`, `BUILTIN`, `MANUAL`, `DELUXECOMBAT`, `CELESTCOMBAT` or `PVPMANAGER`. See [Providers](/docs/exyliacombat/combat-tag#providers). |
| `combat.duration` | `15s` | How long a built-in tag lasts. A new hit never shortens a running tag. |
| `combat.logout-punishment` | `KILL` | `KILL`, `DROP_INVENTORY` or `NOTHING`. See [Logging out](/docs/exyliacombat/logging-out#the-punishment). |
| `combat.punish-on-kick` | `false` | Punishes a tagged player who is kicked. Timeouts are always punished. |
| `combat.untag-on-kill` | `true` | Untags the killer when they kill their opponent. |
| `combat.blacklisted-worlds` | `[]` | Worlds where nobody is ever tagged. |
| `combat.commands-on-logout` | `[]` | Commands run when a tagged player logs out and is punished. `%player%`; `console:` (default) or `player:`. |
| `combat.commands-on-player-death` | `[]` | Commands run when a combat logger is killed as punishment. `%player%`; `console:` (default) or `player:`. |
| `combat.logout.exempt-permission` | `exyliacombat.bypass.logout` | Players with it are never punished for logging out. Empty: nobody is exempt. |
| `combat.logout.exempt-worlds` | `[]` | Worlds where logging out in combat is never punished. |
| `combat.logout.webhook.url` | empty | A Discord webhook for every combat log. Empty: none. |
| `combat.logout.webhook.message` | a `COMBAT LOG` card | The message, in ExyliaLib's template format. See [Discord webhook](/docs/exyliacombat/logging-out#discord-webhook). |
| `combat.notifications.on-tag` | `true` | Tells the player in chat when they enter combat. |
| `combat.notifications.on-untag` | `true` | Tells them when they leave it. |

## Safe zones: `safe-zones`

Where PvP counts as refused, for the PvP barrier and the safe-zone rules of combat restrictions, and the
region ids read by kill rewards and item cooldowns. Each source is only asked when its plugin is installed.
Read again on `/combatadmin reload`.

| Key | Default | Source |
|---|---|---|
| `safe-zones.worldguard` | `true` | WorldGuard regions with `pvp deny`, the global region included. |
| `safe-zones.exylia-regions` | `true` | ExyliaLib regions declaring `pvp: false`. |
| `safe-zones.lands` | `true` | Lands areas where the player's role may not attack players. |
| `safe-zones.grief-prevention` | `true` | GriefPrevention claims its own config protects from PvP. |
| `safe-zones.towny` | `true` | Towny town blocks, and wilderness, with PvP off. |
| `safe-zones.superior-skyblock` | `true` | SuperiorSkyblock2 islands without the `PVP` island flag. |

## Messages

`lang/<language>/messages.yml` holds the core text. Lines may start with a sound tag such as
`[sound:ENTITY_VILLAGER_NO|1.0|1.0]`; `%prefix%` is replaced by `prefix`, and an empty line sends nothing.

| Section | What it holds |
|---|---|
| `prefix` | `{primary}&lCOMBAT {letters_black}•<reset>`, put in every `%prefix%`. |
| `combat` | `tagged`, `untagged`, the refusals `region-blocked`, `teleport-blocked`, `command-blocked`, `flight-blocked`, `elytra-blocked`, `elytra-removed`, `inventory-blocked`, `teleport-denied`, the logout NPC's `logout-npc-spawned`, `logout-npc-name` and `logout-npc-tag`, and `logout-broadcast`. |
| `timer` | `/combat`: `tagged` (`%time%`, `%opponent%`), `not-tagged` and `no-opponent`. |
| `actionbar` | `separator`, `combat-format`, `format` and `format-limited`. See [Action bar](/docs/exyliacombat/combat-tag#action-bar). |
| `admin` | What `/combatadmin settag`, `untag` and `cooldown` answer, and the panel's prompts, confirmations and states. |

Each module's own text is in `lang/<language>/modules/<module>/messages.yml`, listed on its page.
