The `bounties` module lets players put their own money on somebody's head. The player who kills the target collects
everything on it. It is separate from the [shutdown bounty](/docs/exyliacombat/kill-rewards#bounty-for-ending-a-streak),
which the server pays for ending a streak.

The module is on for new installs (`modules.bounties` in `config.yml`). A server that already had a `config.yml`
when the module arrived gets it switched **off** by a migration: turn it on once you are happy with the limits. The
module moved here from ExyliaSurvivalCore and reads the same table (`sc_bounties`), so bounties already open come
along.

## Placing and cancelling

| Command | Permission | What it does |
|---|---|---|
| `/bounty`, `/bounties` | `exyliacombat.bounties.use` | Opens the bounty board: every player with money on their head, biggest first. |
| `/bounty place <player> [amount]` | `exyliacombat.bounties.use` | Puts money on a player. Without an amount, a screen asks for it. |
| `/bounty cancel <player>` | none | Cancels your own bounties on that player after a confirmation. |

The command names are the `commandLabels` list of `modules/bounties/config.yml`: the first is the command, the rest aliases
(read at startup).

Rules, all set in `modules/bounties/config.yml`:

- **Money.** The `currency` is an id of ExyliaLib's `economy.yml` (empty: the default currency). A bounty must be at
  least `min-amount` (`25`) and at most `max-amount` (`100000`, `0` for no limit); the whole pool on one head is capped
  by `max-target-pool` (`0`: no cap).
- **Limits.** A placer can have a bounty on `max-per-placer` players at once (`5`, `0` for no limit). A rank changes
  that with `exyliacombat.bounties.max.<n>`; the highest number held wins.
- **Yourself.** `allow-self-bounty` (`false`) decides whether a player can put a bounty on themselves.
- **Cancelling.** `cancel-penalty-percent` (`10`) is the share of a cancelled bounty
  that is not refunded; `0` refunds everything.
- **Expiry.** `expiry` (`0s`, until collected) is how long a bounty stays open; when it runs out the placer is refunded
  in full.
- **Anonymous.** With `allow-anonymous` (`true`), players with `exyliacombat.bounties.anonymous` (operators by default)
  can hide their name when placing.
- **Login boss bar.** A player with money on their head sees a boss bar on joining (`login-bar`: `enabled`,
  `duration` `10s`, `colour` `RED`, `overlay` `NOTCHED_12`).

## Collecting

Whoever kills the target collects every open bounty on them. Only kills the
[kill-abuse](/docs/exyliacombat/kill-rewards#kill-abuse) module lets through collect: a farmed kill leaves every
bounty where it is. A killer never collects their own bounty, nor one placed by an account that shares their address
or the victim's. Payouts and refunds are transfers between players, so boosters and permission-group multipliers never
touch them.

## Admin

| Command | Permission | What it does |
|---|---|---|
| `/combatadmin bounty` | `exyliacombat.admin.bounties` | Opens the board with admin buttons. |
| `/combatadmin bounty add <player> <amount>` | `exyliacombat.admin.bounties` | Puts money on a player from nowhere: nobody is refunded for it. |
| `/combatadmin bounty clear <player>` | `exyliacombat.admin.bounties` | Removes every bounty on a player after a confirmation (from the console it clears at once). |

The admin panel's player list has a **Bounties** card for the same board. `exyliacombat.admin` includes
`exyliacombat.admin.bounties`.

## Screens and text

The board and a player's bounty list are native screens (`screens/bounties.html` with its words in
`lang/<language>/screens/bounties.yml`); if a screen cannot be read, the chest menus in
`lang/<language>/modules/bounties/` (`list.yml`, `target.yml`) open instead. Chat text is in
`lang/<language>/modules/bounties/messages.yml`. Files are yours to restyle; an update only adds what is missing.

## Placeholders

| Placeholder | Value |
|---|---|
| `%exyliacombat_bounty_total_<player>%` | Money on that player's head, formatted. |
| `%exyliacombat_bounty_count_<player>%` | How many bounties are on that player. |
| `%exyliacombat_bounty_has_<player>%` | `true` or `false`. |
| `%exyliacombat_bounty_count_all%` | Bounties open on the server. |
| `%exyliacombat_bounty_top_name_<n>%`, `%exyliacombat_bounty_top_amount_<n>%` | The player in place `n` (default 1) with the most on their head, and how much; `—` and zero when there is none. |
| `%exyliacombat_my_bounty_total%`, `_count`, `_has` | The same for the reader. |
| `%exyliacombat_my_placed_count%`, `%exyliacombat_my_placed_total%` | How many bounties the reader has placed and their total. |

`<player>` is a name already known to the server or a UUID.
