Players can use ExyliaCombat without any setup: stats, leaderboards, the PvP switch and bounties are allowed to everyone, and only admins get `/combatadmin`. Use this page to restrict features or to give staff and ranks exceptions.

## Make a feature a rank perk

Everyone holds the player permissions by default. To make one a perk, deny it to the default group and grant it to the rank. With LuckPerms:

```text
/lp group default permission set exyliacombat.pvptoggle false
/lp group vip permission set exyliacombat.pvptoggle true
```

`/combat` (time left), `/newbie` and `/bounty cancel` never need a permission. The console always passes.

## Numbers per rank

Two permissions end in a number that you choose:

```text
/lp group vip permission set exyliacombat.pvpcooldown.10 true
/lp group vip permission set exyliacombat.bounties.max.10 true
```

- `exyliacombat.pvpcooldown.<n>`: seconds between two `/pvp` switches. The lowest number a player holds wins, so `exyliacombat.pvpcooldown.0` removes the wait. Without one, the module's `cooldown` (30 seconds by default) applies.
- `exyliacombat.bounties.max.<n>`: how many players a placer can have a bounty on at once. The highest number wins. Without one, `max-per-placer` applies (5 by default).

## Change which permission a feature checks

- `/pvp` checks `exyliacombat.pvptoggle` while `permission` in `modules/pvp-toggle/config.yml` is empty. A node written there replaces it.
- Logout exemption is `combat.logout.exempt-permission` in `config.yml` (`exyliacombat.bypass.logout` by default).
- Kill-abuse alerts use `notify-permission` of the `kill-abuse` module, and its `bypass-permission` (empty by default) exempts a player's kills from its checks.

<Callout type="warning" title="Operators bypass the restrictions">
`exyliacombat.bypass` is on for operators, so an operator testing the plugin is never restricted and sees no barrier. Test with a normal player, or deny the node to yourself.
</Callout>
