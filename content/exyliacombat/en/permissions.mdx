description: "Every node the plugin declares, what it gates and who has it by default."
---

| Permission | Default | What it gates |
|---|---|---|
| `exyliacombat.*` | operators | Every admin, bypass and notify node below. The player nodes are everyone's anyway; `exyliacombat.rewards.vip` and the old `exyliaspecials.combat.bypass` are not included. |
| `exyliacombat.admin` | operators | `/combatadmin`, the admin panel, its `SETTINGS` button and `/combatadmin reload`. |
| `exyliacombat.admin.tag` | operators | `/combatadmin settag` and `untag`, and the panel's combat tag card. |
| `exyliacombat.admin.cooldown` | operators | `/combatadmin cooldown set`, `add`, `decrease` and `remove`, and the panel's cooldowns. |
| `exyliacombat.admin.pvp` | operators | `/combatadmin pvp <player>` and `/combatadmin pvp global`, and the panel's PvP card. |
| `exyliacombat.admin.newbie` | operators | `/combatadmin newbie give` and `remove`, and the panel's newbie card. |
| `exyliacombat.bypass` | operators | Ignores every combat restriction and the PvP barrier. The player is still tagged. |
| `exyliaspecials.combat.bypass` | operators | The old name of `exyliacombat.bypass`, from when combat lived in ExyliaSpecials. Still honoured. |
| `exyliacombat.bypass.logout` | operators | Never punished for logging out in combat. The node is `combat.logout.exempt-permission` in `config.yml`. |
| `exyliacombat.notify.killabuse` | operators | Told about kills flagged by `kill-abuse`. The node is `notify-permission` of that module. |
| `exyliacombat.rewards.vip` | nobody | The example `vip` group of `kill-rewards`. Each group names its own permission. |

## Player nodes

Everybody holds these by default, so a server makes one a rank perk by denying it to the default group.
`/combat` and `/newbie` never need a node.

| Permission | Default | What it gates |
|---|---|---|
| `exyliacombat.stats` | everyone | `/pvpstats` and the stats screen, for one's own stats and anybody else's. |
| `exyliacombat.top` | everyone | `/combattop` and the leaderboard screen. |
| `exyliacombat.pvptoggle` | everyone | `/pvp`, while `permission` of `modules/pvp-toggle/config.yml` is left empty. A node written there replaces it. |

A player missing `exyliacombat.stats` or `exyliacombat.top` is told `no-permission` of the stats messages.
The console always passes.

## Per-rank numbers

| Pattern | What it sets |
|---|---|
| `exyliacombat.pvpcooldown.<n>` | Seconds between two `/pvp` switches, instead of the module's `cooldown`. The lowest `<n>` a player holds wins, so `exyliacombat.pvpcooldown.0` removes the wait. |

The `bypass-permission` of `kill-abuse` (empty by default) exempts a player's kills from its checks.

## Resetting a player

Resetting a player's data is done by ExyliaLib, not by a node of this plugin: the panel's stats card opens
the library's player reset, which needs `exylialib.admin.wipe`. See
[ExyliaLib's commands](/docs/exylialib/commands#moving-and-wiping-data).

<Callout type="warning" title="Operators bypass the restrictions">
`exyliacombat.bypass` is on for operators by default, so an operator testing the plugin is never restricted
and sees no barrier. Test with a normal player, or deny the node.
</Callout>
