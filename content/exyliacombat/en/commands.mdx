Every name can be changed: `commands.combat-time` and `commands.admin` in `config.yml`, and each module's
`command-labels` (or `stats-command` and `top-command`). The first name is the command, the rest aliases; an
empty list registers no command. Renaming needs a restart. A module that is off registers none of its
commands.

## Player commands

| Command | Module | Permission | What it does |
|---|---|---|---|
| `/combat`, `/ct` | core | none | How long the tag still lasts, and the opponent. |
| `/pvp`, `/togglepvp` | `pvp-toggle` | `exyliacombat.pvptoggle`, or `permission` of the module when set | Switches PvP. Also `/pvp on`, `off`, `toggle` and `status`. |
| `/newbie`, `/protection` | `newbie-protection` | none | The protection left. `/newbie disable` drops it after a confirmation. |
| `/pvpstats [player]` | `stats` | `exyliacombat.stats` | The stats screen of a player, or in chat. Works from the console with a name. |
| `/combattop [stat] [page]`, `/pvptop` | `stats` | `exyliacombat.top` | A leaderboard. Stats `kills`, `deaths`, `kdr`, `streak`, `beststreak`, `points` (default). Works from the console. |

The three player nodes are everyone's by default; see [Permissions](/docs/exyliacombat/permissions#player-nodes).
See [Protection](/docs/exyliacombat/protection) and [Stats](/docs/exyliacombat/stats).

## Admin commands

All under `/combatadmin`. Every one but the panel also runs from the console.

| Command | Permission | What it does |
|---|---|---|
| `/combatadmin` | `exyliacombat.admin` | Opens the admin panel. Players only. |
| `/combatadmin reload` | `exyliacombat.admin` | Reads `config.yml`, every module's settings and text, the safe-zone sources and the admin menus again, and switches provider if `combat.provider` changed. Module switches and command names need a restart. |
| `/combatadmin settag <seconds> <player>` | `exyliacombat.admin.tag` | Sets the player's tag to exactly that long (at least `0.1`, decimals allowed). Refused under an external provider. |
| `/combatadmin untag <player>` | `exyliacombat.admin.tag` | Ends the player's tag. |
| `/combatadmin cooldown set <player> <id\|ALL> <seconds>` | `exyliacombat.admin.cooldown` | Sets an item cooldown, `0` to `86400` seconds. Needs `vanilla-cooldowns`. |
| `/combatadmin cooldown add <player> <id\|ALL> <seconds>` | `exyliacombat.admin.cooldown` | Adds to it. |
| `/combatadmin cooldown decrease <player> <id\|ALL> <seconds>` | `exyliacombat.admin.cooldown` | Takes from it. |
| `/combatadmin cooldown remove <player> [id]` | `exyliacombat.admin.cooldown` | Clears one cooldown, or all of them. |
| `/combatadmin pvp <player> <on\|off>` | `exyliacombat.admin.pvp` | Sets a player's PvP switch. Needs `pvp-toggle`. |
| `/combatadmin pvp global <on\|off>` | `exyliacombat.admin.pvp` | Switches PvP for the whole server and tells every player. Saved as `global-pvp`. Needs `pvp-toggle`. |
| `/combatadmin newbie give <player> [time]` | `exyliacombat.admin.newbie` | Gives newbie protection, for `time` (`30m`, `1h30m`, `2d`) or the module's `duration`. Needs `newbie-protection`. |
| `/combatadmin newbie remove <player>` | `exyliacombat.admin.newbie` | Takes it away. |
| `/combatadmin bounty` | `exyliacombat.admin.bounties` | Opens the bounty board with admin buttons. Needs `bounties`. |
| `/combatadmin bounty add <player> <amount>` | `exyliacombat.admin.bounties` | Puts money on a player from nowhere. |
| `/combatadmin bounty clear <player>` | `exyliacombat.admin.bounties` | Removes every bounty on a player after a confirmation. |

Players use `/bounty`: see [Bounties](/docs/exyliacombat/bounties).
The players these commands take must be online.

There is no reset command of the plugin's own. ExyliaLib resets a player's ExyliaCombat data with
`/exylialib resetplayer <player> ExyliaCombat`, and empties its tables with
`/exylialib wipe ExyliaCombat <table|*>`; both tables are player progress, so a new-season wipe clears
them too. See [ExyliaLib's commands](/docs/exylialib/commands#moving-and-wiping-data).

## The admin panel

`/combatadmin` opens a list of every online player with their combat state. Its `SETTINGS` button (a comparator
at the bottom centre) opens ExyliaLib's settings screens, where every key of `config.yml` and of each
module's `config.yml` can be changed in game (`/exylialib config ExyliaCombat` opens the same screens);
messages and menus stay in their files. The back button returns to the list. A click on a player opens
that player:

| Card | Click | What it does |
|---|---|---|
| Combat tag | left, right | Asks how long to tag them for (prefilled with what is left), or untags them. |
| Cooldowns | click | Opens their item cooldowns: left set, right add, shift-left decrease, shift-right remove, and a `REMOVE ALL` button after a confirmation. |
| Newbie protection | left, right | Asks how long to protect them for (prefilled with `duration`), or removes it. |
| PvP | click | Switches their PvP. |
| Stats | click | Opens ExyliaLib's player reset for ExyliaCombat: their stats, PvP switch, newbie protection and pending combat log are deleted after a confirmation, and they are kicked while it runs. Needs `exyliacombat.admin` and `exylialib.admin.wipe`. |

Cards of modules that are off are not drawn, and the rest re-centre. Every value on screen keeps itself up
to date while the panel is open. Each button checks the same permission as its command. The panel's files
under `lang/<language>/admin/` are regenerated from the jar on every start.

## Menu actions

For a server's own menus and NPCs:

| Action | What it does |
|---|---|
| `exyliacombat:leaderboard <stat>` | Opens the leaderboard screen of that stat. |
| `exyliacombat:stats` | Opens the clicker's stats screen, or, on a leaderboard row, that player's. |
| `exyliacombat:admin_players` | Opens the admin panel. Needs `exyliacombat.admin`. |
| `exyliacombat:admin_settings` | Opens the settings screens. Needs `exyliacombat.admin`. |
