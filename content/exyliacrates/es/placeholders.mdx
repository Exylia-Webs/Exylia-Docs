Cada placeholder de abajo está escrito completo, y al hacer clic en uno se copia.

## Cómo se escribe el nombre

El plugin registra sus placeholders a través de ExyliaLib como el grupo `crate`. Dentro de los archivos de un
plugin de Exylia — menús, `messages.yml`, el scoreboard de otro plugin de Exylia — el nombre registrado va
solo:

```text
%crate_keys_vote%
```

A través de **PlaceholderAPI**, para cualquier otro plugin, delante va el nombre del plugin:

```text
%exyliacrates_crate_keys_vote%
```

Esta página usa siempre la forma de PlaceholderAPI; quita `exyliacrates_` para la del plugin. No hay que
descargar nada del eCloud.

`<crate>` y `<key>` son ids. Los ids pueden tener guiones bajos — `%exyliacrates_crate_keys_daily_reward%` lee
la caja `daily_reward`.

Todos responden para el jugador que los lee.

## Los placeholders

| Placeholder | Descripción |
|---|---|
| `%exyliacrates_crate_keys_<crate>%` | Llaves que quien lee puede gastar en esa caja: ítems de llave que lleva más saldo, de la primera llave que lista el coste de la caja. `0` para una caja que no pide llave; sin valor para una caja desconocida. |
| `%exyliacrates_crate_key_<key>%` | Lo mismo para una llave, por el id de la llave. Sin valor para una llave desconocida. |
| `%exyliacrates_crate_keys_total%` | Todas las llaves que tiene quien lee, ítems y saldo, sumadas. |
| `%exyliacrates_crate_pity_<crate>%` | Aperturas que faltan para la garantía de la caja, `0` cuando la siguiente está garantizada. Sin valor si la caja no tiene garantía o no existe. |

En los archivos de Exylia, a un placeholder sin valor se le puede dar un valor alternativo con la forma `|` de
ExyliaLib: `%crate_pity_vote|-%`.

Los contadores de llaves son con los que se escribe el holograma de cada caja, así que un scoreboard y el
holograma nunca dicen cosas distintas. Leen el saldo de quien lee tal como lo tiene este servidor; hasta que se
carga tras su entrada, solo cuentan los ítems de llave que lleva encima.

<Callout type="note" title="crate_keys_total es una palabra, no una caja">
`%exyliacrates_crate_keys_total%` siempre significa el total. Una caja cuyo id sea `total` no se puede leer con
`crate_keys`; léela por su llave con `crate_key_<key>`.
</Callout>

## Valores en los archivos del propio plugin

Estos los rellena el propio plugin y solo funcionan en el archivo indicado.

### messages.yml

| Línea | Valores |
|---|---|
| `hologram-lines` | `%crate%` el nombre de la caja, `%keys%` el número de llaves suyas que tiene quien lee |
| `opened`, `opened-many` | `%crate%`, `%reward%`, `%count%` |
| `opened-line`, `opened-line-many` | `%reward%`, `%amount%` |
| `broadcast` | `%player%`, `%reward%`, `%crate%`, `%tier%` |
| `keys-line` | `%crate%` las cajas que abre la llave, `%key%` su nombre, `%keys%` |
| `keys-received`, `keys-while-away`, `keys-removed`, `keys-changed` | `%amount%`, `%crate%`, `%key%` |
| `keys-given`, `keys-taken`, `keys-set` | `%player%`, `%amount%`, `%crate%` (el id de la llave) |
| `keys-given-all` | `%amount%`, `%crate%`, `%key%`, `%count%` |
| `missing-keys` | `%crate%`, `%amount%`, `%key%` |
| `missing-money` | `%crate%`, `%amount%` escrita en su moneda |
| `reveal-self`, `reveal-other` | `%tier%`, `%reward%`, `%player%`, `%crate%` |
| `reveal-count` | `%amount%` |
| `pick-title`, `pick-subtitle` | `%seconds%` |
| `speed-up-hint` | `%speed%` |
| `key-lore` | `%crate%` las cajas que abre la llave, `%key%` su nombre |
| `wand-name` / `wand-lore` | `%id%` / `%crate%` |
| `rewards-claimed` | `%amount%` |

### Menús

| Archivo | Valores |
|---|---|
| `menus/user/preview.yml` | `%crate_id%`, `%crate_name%`, `%crate_icon%`, `%crate_keys%`, `%crate_pity%`; por recompensa `%reward_name%`, `%reward_icon%`, `%reward_chance%`, `%reward_tier%`, `%reward_color%` |
| `menus/user/history.yml` | `%history_title%`; por fila `%opening_player%`, `%opening_crate%`, `%opening_reward%`, `%opening_icon%`, `%opening_tier%`, `%opening_color%`, `%opening_ago%`; `%back%` en el botón de volver |

Cada archivo lista sus propios valores en el comentario de arriba.

### Fases de animación y celebraciones

`%reward%`, `%tier%`, `%tier_color%`, `%player%`, `%crate%` y `%amount%`, más `{item:reward}` para el icono del
premio. Ver [Animaciones](/docs/exyliacrates/animaciones#cómo-funcionan-todas).
