El agente tiene un solo comando, con un nombre distinto en cada plataforma para que el del proxy nunca
tape el de los backends:

| Plataforma | Comando |
|---|---|
| Paper, Spigot, Folia | `/analytics` |
| Velocity | `/analyticsv` |

Los dos aceptan los mismos subcomandos y los autocompletan.

## Subcomandos

| Comando | Qué hace |
|---|---|
| `/analytics` o `/analytics status` | Muestra el estado del agente. Cualquier subcomando desconocido también lo muestra. |
| `/analytics link` | Pide un código de vinculación y te lo muestra a ti y en la consola. Se rechaza, con el nombre del espacio de trabajo, si el servidor ya está vinculado. Ver [Vincular un servidor](/docs/exyliaanalytics/vinculacion). |
| `/analytics unlink` | Olvida el token: borra `data/credentials.json`, la cola y el spool. No se envía nada más. El token sigue funcionando hasta que se revoque el servidor en el panel. |
| `/analytics reload` | Vuelve a leer `config.yml` y descarga otra vez los ajustes del panel. Los cambios de modo siguen necesitando reiniciar. |

## La lectura del estado

```text
EXYLIA ANALYTICS v1.1.0
 ▎ State » Active
 ▎ Workspace » ExyliaMC
 ▎ Mode » standalone
 ▎ Waiting » 12 events · 0 batches
 ▎ Last send » ok at 18:42:07
 ▎ Economy » ExyliaLib, PlayerPoints
```

| Línea | Valores |
|---|---|
| State | **Active**; **Not linked** — ejecuta el comando de vinculación; **Waiting** — otro servidor tiene este token; **Disabled from the dashboard** — el servidor está pausado. |
| Workspace | El espacio de trabajo al que está vinculado. No aparece si no está vinculado. |
| Mode | `proxy`, `backend` o `standalone`. |
| Waiting | Eventos en memoria y lotes en el spool, aún sin entregar. |
| Last send | `ok at` y una hora; `retrying in Ns:` y el motivo; `paused: workspace suspended or over quota`; `waiting: another server holds this token`; `not linked`; o `nothing sent yet`. |
| Economy | Paper y Spigot. Las fuentes de economía enganchadas: ExyliaLib (o *ExyliaLib (flows only)* cuando es demasiado antiguo para contar lo que se tiene), Vault, VaultUnlocked, PlayerPoints, ExcellentEconomy — o *no sources*. |
| Vault, VaultUnlocked | Paper y Spigot, cuando esa economía está instalada: *watching* el plugin que hay detrás, o por qué no se vigila (desactivado en `config.yml`, ExyliaSurvivalCore informa a través de ExyliaLib, o la economía tiene la prioridad más alta). |

## Permiso

| Permiso | Por defecto | Concede |
|---|---|---|
| `exyliaanalytics.admin` | op | Todos los subcomandos de `/analytics` y `/analyticsv`. |

En Velocity nadie salvo la consola lo tiene hasta que un plugin de permisos como LuckPerms lo concede.

## Mensajes de consola que conviene conocer

| Mensaje | Significado |
|---|---|
| `Link this server at https://analytics.exylia.net/link — code …` | Sin vincular; introduce el código. |
| `The link code expired. Run /analytics link for a new one.` | Se acabaron los diez minutos. |
| `Linked to the workspace ….` | Se aprobó el código. |
| `Could not reach Exylia Analytics (…); events are kept and retried.` | No se puede llegar al ingest. Se registra una vez por corte. |
| `This server's token was revoked. Run /analytics link to link it again.` | Revocado en el panel. |
| `The workspace is suspended or over its plan quota; events are kept and retried every 15 minutes.` | El espacio de trabajo está suspendido. |
| `Another running server holds this token (a copied plugin folder?)…` | Dos procesos comparten un token. Ver [Instalación](/docs/exyliaanalytics/instalacion#copiar-la-carpeta-de-un-servidor). |
| `The spool is full (50 MiB); dropped the N oldest batch(es).` | Hace mucho que no se puede llegar al ingest. |
| `The installed loader is outdated: the economy API is disabled until it is updated.` | Sustituye el jar del loader. Los eventos personalizados siguen funcionando. |
| `More than 100000 events are waiting; new events are dropped until the queue drains.` | Algo satura el agente más rápido de lo que puede enviar. |
