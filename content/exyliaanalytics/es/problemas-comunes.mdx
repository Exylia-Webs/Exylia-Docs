Ejecuta primero `/analytics status` (`/analyticsv status` en Velocity). Sus líneas **State** y **Last send** te dicen cuál de los problemas de abajo tienes. Están explicadas en [Comandos](/docs/exyliaanalytics/comandos#la-lectura-del-estado).

## La consola nunca muestra un código de vinculación

- El loader se detuvo en la licencia y lo dice antes de que arranque el agente. Un jar comprado en BuiltByBit lleva su licencia, así que no hay clave que añadir: pregunta en el [Discord de Exylia](https://discord.exylia.net).
- El servidor ya está vinculado. Existe `data/credentials.json`, quizá copiado de otro servidor. `/analytics status` muestra el espacio de trabajo; ejecuta `/analytics unlink` y luego `/analytics link` si es el equivocado.
- No se llega al ingest. La consola dice *"Could not request a link code (…); retrying"*. Mira el siguiente problema.
- El código caducó. Un código dura diez minutos: ejecuta `/analytics link` para uno nuevo.

## "Could not reach Exylia Analytics"

El servidor no puede abrir una conexión HTTPS con `analytics-ingest.exylia.net`. Las causas habituales son un host que bloquea el tráfico saliente, un cortafuegos que solo permite algunos puertos o un fallo de DNS. Mientras tanto no se pierde nada: los eventos esperan en `data/spool/` (hasta 50 MiB) y salen, los más antiguos primero, cuando vuelve la conexión. **Last send** en el estado muestra el próximo reintento.

## La página de vinculación rechaza el código

*"That code is unknown, expired or already used."* Los códigos sirven una vez y duran diez minutos. Si el espacio de trabajo que quieres no sale en la lista, tu rol no puede vincular servidores ahí. Mira [Conecta tu servidor](/docs/exyliaanalytics/vinculacion).

## El estado dice Waiting: "Another running server holds this token"

Dos procesos envían con un mismo token, casi siempre porque se copió una carpeta de plugin con `data/credentials.json` dentro. El ingest acepta uno y rechaza el otro, que guarda sus eventos y reintenta cada minuto. En la copia, ejecuta `/analytics unlink`, luego `/analytics link` y aprueba el código nuevo. Mira [Instalación](/docs/exyliaanalytics/instalacion#copiar-la-carpeta-de-un-servidor).

## El estado dice "Disabled from the dashboard"

El servidor está en pausa en la página **Servidores**. Un agente en pausa no envía nada, así que nunca se entera de que lo reanudaron: tras pulsar **Reanudar**, ejecuta `/analytics reload` en él (o `/analyticsv reload` en el proxy), o reinícialo.

## El servidor está vinculado pero las gráficas están vacías

| Comprueba | Dónde |
|---|---|
| El servidor informa | **Servidores**: estado **Online** con un latido reciente. |
| No está en pausa | **Servidores**: no **Disabled**. |
| El rango tiene datos | Elige un rango más largo. La mayoría de gráficas necesitan al menos un día completo de sesiones. |
| Una red tiene su proxy | Sin un proxy Velocity vinculado nadie informa de sesiones, así que jugadores, retención y adquisición quedan vacíos. Los backends solos solo llenan Rendimiento, Economía y Placeholders. |
| El módulo está activo | **Ajustes → Agente**. Con Sesiones desactivado casi todo queda vacío. |
| Puedes ver la página | Quizá tu rol no la incluye. |

## Economía no muestra nada

El módulo de Economía debe estar activo y el servidor debe ser Paper o Spigot. `/analytics status` lista las fuentes enganchadas en la línea **Economy**. Con solo una economía de Vault, mira la línea **Vault**: el envoltorio puede estar desactivado en `config.yml`, o la economía puede tener ella misma la prioridad más alta. Los plugins que tomaron la economía antes del primer tick no se ven: mira [Economía](/docs/exyliaanalytics/economia#el-proxy-de-vault).

## "The installed loader is outdated"

El jar del loader es más antiguo que la API de economía o de mercado. Los eventos personalizados siguen funcionando. Sustituye `Exylia-Analytics-Loader.jar` por el actual; el agente se actualiza solo con un reinicio normal.

## "The workspace is suspended"

El panel rechazó los eventos del servidor porque el espacio de trabajo está suspendido. El texto de la consola también dice "plan quota", pero el panel no tiene cuotas. Los eventos se guardan y se reintenta cada 15 minutos. Pregunta en el [Discord de Exylia](https://discord.exylia.net).
