## The console never prints a link code

The loader may have stopped at the licence (ask on the [Exylia Discord](https://discord.exylia.net); a BuiltByBit jar carries its own), the server may already be linked through `data/credentials.json`, or the ingest may be unreachable. A code lives ten minutes, so run `/analytics link` for a new one. See [Link your server](/docs/exyliaanalytics/linking) and [Common problems](/docs/exyliaanalytics/troubleshooting).

## "Could not reach Exylia Analytics"

The server cannot open an HTTPS connection to `analytics-ingest.exylia.net`: usually a host that blocks outgoing traffic, a firewall or a DNS failure. Nothing is lost: events wait in `data/spool/` (up to 50 MiB) and go out oldest first once the connection is back, and `/analytics status` shows the next retry under **Last send**.

## The code is refused on the link page

Codes are single-use, live ten minutes and never contain `0`, `O`, `1`, `I` or `L`. If your workspace is not in the list, your role cannot manage servers there.

## The server is linked but the charts are empty

Check that the server is **Online** and not paused under **Servers**, that the range has data (most charts need a full day of sessions), and that **Sessions** is on in **Settings → Agent**. A network also needs a linked Velocity proxy: backends alone only fill Performance, Economy and Placeholders. Your role may also not include the page.

## Economy shows nothing

The Economy module must be on and the server must be Paper or Spigot. `/analytics status` lists the hooked sources on the **Economy** line; with only a Vault economy, check the **Vault** line. See [Economy](/docs/exyliaanalytics/economy#the-vault-proxy).

## I resumed a server and it still collects nothing

A paused agent never hears it was resumed. Run `/analytics reload` on it (`/analyticsv reload` on the proxy), or restart it. See [Servers](/docs/exyliaanalytics/servers#pause-and-resume).

## "Another running server holds this token"

Two processes send with the same token, almost always because a plugin folder was copied with `data/credentials.json` inside. On the copy, run `/analytics unlink` then `/analytics link` and approve the new code; the refused server keeps its events meanwhile. See [Installation](/docs/exyliaanalytics/installation#copying-a-server-folder).

## "The installed loader is outdated"

The loader jar predates the economy API: custom events still work, the economy API stays off. Replace `Exylia-Analytics-Loader.jar` with a current one; agent updates arrive with a plain restart.

## Does it run on Folia?

Yes, on the global region, and every event it listens to still counts. TPS and MSPT describe the global region, so they read as idle, and entity and chunk counts are not reported.

## Does it run on Spigot?

Yes, from 1.17. Spigot has no tick-duration event, so Performance shows TPS without MSPT, and client brands need Paper 1.19.4 or newer.

## Is BungeeCord or Waterfall supported?

Not as a proxy: there is no agent for them. Backends behind one report presence, performance and the economy, but nobody reports the network sessions most pages are built on. See [Installation](/docs/exyliaanalytics/installation#installing-on-a-network).

## Why are playtime and AFK different?

Playtime is time connected minus AFK time. A player counts as AFK after the AFK time in **Settings → Agent** (five minutes by default) with no movement, chat, command or interaction. See [Control what the agent collects](/docs/exyliaanalytics/remote-config).

## A server shows Silent while it is running

It missed three heartbeats, which a server lagging below roughly 7 TPS for several minutes can cause; its open sessions are closed as timed out. It turns Online again with its next heartbeat. See [Servers](/docs/exyliaanalytics/servers).

## Can players opt out?

The agent has no per-player switch. What it collects is listed on [Privacy](/docs/exyliaanalytics/privacy), and modules turn whole kinds of data off for everyone.

## Does it slow the server down?

Collecting an event is a queue insert on the game thread; compressing, writing and sending run on a background thread, and the agent never waits on the network from a game thread. See [What the agent collects](/docs/exyliaanalytics/data).

## Where do I get help?

On the [Exylia Discord](https://discord.exylia.net). Licences are handled there too.
