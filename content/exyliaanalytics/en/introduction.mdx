ExyliaAnalytics is the **agent** of [Exylia Analytics](https://analytics.exylia.net), a web dashboard
that answers one question about a Minecraft server or network: *is it growing or decaying, and why?*
The agent runs inside your servers and your proxy, watches what happens — players joining and
leaving, idling, lag, bans, votes, ranks, money moving — and sends it as batches of events to
`analytics-ingest.exylia.net`. The dashboard turns those events into charts, cohorts, player profiles
and an economy report.

The agent has no web server, opens no port and needs no other plugin. Everything it sends leaves over
HTTPS from the server; nothing ever connects back in.

## Two halves

| | Where it runs | What it does |
|---|---|---|
| The agent | Your proxy and your servers, as a plugin | Collects events, keeps them on disk until they are delivered, and takes its settings from the dashboard. |
| The dashboard | `https://analytics.exylia.net`, in the browser | Signs you in with Discord, holds your **workspace** (one network), links servers to it and draws every chart. |

These pages cover both: how to install and link the agent, what every page of the dashboard shows
and which of the agent's events feed it, and exactly what the agent collects.

## One jar, three roles

The same loader jar goes on a Velocity proxy and on a Paper or Spigot server. Each install is one
**server** in the dashboard, and each server plays one of three roles:

| Role | What it is | What it reports |
|---|---|---|
| `proxy` | A Velocity proxy. | The **network session**: who connected, from which address and hostname, with which client, and which backend they moved to. Heartbeats, proxy CPU and memory, the proxy's server list. |
| `backend` | A Paper/Spigot server behind a proxy. | **Presence**: who was on this server, for how long, how much of it AFK, and what they did there. TPS, MSPT, entities and chunks. Economy and PlaceholderAPI values. |
| `standalone` | A Paper/Spigot server players join directly. | Both of the above: it owns the network session *and* the presence. |

The role is detected on start and can be forced in `config.yml`; see
[Installation](/docs/exyliaanalytics/installation#the-servers-role).

## What it reports

| Area | Source |
|---|---|
| Sessions, hostnames, client brand, language, protocol version | The server itself; ViaVersion for the client version on a standalone Paper server. |
| Java or Bedrock | Floodgate, or the shape of the player's UUID. |
| AFK time and activity counters (chat, commands, deaths, player kills) | The server itself. Counts only, never content. |
| TPS, MSPT, CPU, memory, entities, chunks, uptime, restarts, crashes | The server itself. |
| Punishments | LiteBans, LibertyBans or AdvancedBan. |
| Votes | NuVotifier (or classic Votifier on Paper). |
| Rank changes and the primary group | LuckPerms. |
| Any value a placeholder shows | PlaceholderAPI, for the placeholders you list. |
| Money created, destroyed and held | ExyliaLib, Vault, VaultUnlocked, PlayerPoints, ExcellentEconomy and any plugin calling the API. |
| Your own events | Other plugins, through `ExyliaAnalytics.track(...)`. |

The full list, event by event, is in [Collected data](/docs/exyliaanalytics/data); what never leaves
the server is in [Privacy](/docs/exyliaanalytics/privacy).

## How it goes

<Steps>
  <Step title="Install the jar">
    The loader jar in `plugins/` of the proxy and of every server, and your licence key in the
    loader's file.
  </Step>
  <Step title="Link each server">
    An unlinked agent prints a code in the console. You type it at `analytics.exylia.net/link` and
    approve it into your workspace. The agent collects a token and starts sending.
  </Step>
  <Step title="Read the dashboard">
    Charts fill in within a minute. What is collected, how often, and whether a server is collecting
    at all is decided from the dashboard, without a restart.
  </Step>
</Steps>

## Requirements

| Requirement | Detail |
|---|---|
| Java | 21, which the loader itself is built for. |
| Server | Paper or Spigot 1.17 or newer. Folia is supported with the limits in the [FAQ](/docs/exyliaanalytics/faq#does-it-run-on-folia). |
| Proxy | Velocity 3. BungeeCord and Waterfall are not supported as proxies. |
| Network | Outgoing HTTPS to `analytics-ingest.exylia.net`. No incoming port. |
| Account | A Discord account to sign in to the dashboard. |
| Optional | LiteBans, LibertyBans, AdvancedBan, NuVotifier, LuckPerms, PlaceholderAPI, ViaVersion, Floodgate, ExyliaLib, Vault or VaultUnlocked, PlayerPoints, ExcellentEconomy. Each is used when present and ignored when not. |
