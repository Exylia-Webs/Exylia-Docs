Every integration is optional and looked up when the agent starts. A plugin that is not installed costs
nothing, and none of them is needed for the agent to run. Each one reports into a generic event, so the
dashboard's charts do not care which plugin fed them.

| Plugin | Paper / Spigot | Velocity | Adds | Module |
|---|---|---|---|---|
| LiteBans | ✓ | ✓ | Punishments issued and lifted | Punishments |
| LibertyBans | ✓ | ✓ | Punishments issued and lifted | Punishments |
| AdvancedBan | ✓ | — | Punishments issued and lifted | Punishments |
| NuVotifier | ✓ (classic Votifier too) | ✓ | Votes | Votes |
| LuckPerms | ✓ | ✓ | Rank changes, and the group a session starts with | Ranks, Sessions |
| PlaceholderAPI | ✓ | — | Values of the placeholders you list | Placeholders |
| ViaVersion | ✓ | — | The client's real version on a standalone server | Sessions |
| Floodgate | ✓ | ✓ | Bedrock players, including linked accounts | Sessions |
| ExyliaLib | ✓ | — | Balance changes and holdings of every ExyliaLib currency | Economy |
| Vault / VaultUnlocked | ✓ | — | Balance changes and balances of any Vault economy | Economy |
| PlayerPoints | ✓ | — | Point changes and balances | Economy |
| ExcellentEconomy | ✓ | — | Currency changes and balances | Economy |

## Punishments

LiteBans, LibertyBans and AdvancedBan all report each punishment as it is **issued** and as it is
**lifted**: the player, the kind (ban, mute, kick, warn), who did it, the reason, the duration and
whether it is an IP ban, plus the plugin's own entry id.

- **Run on the proxy and the backends at once?** Both report the same entry; the dashboard counts each
  plugin's id once.
- **The console** is reported as no staff member, and shows as **Console**.
- **Address-only punishments** — an IP ban that names no player — are not reported by any of the three.
- **LibertyBans** gives an IP ban on a player (a composite victim) as that player, marked as an IP ban.
- **AdvancedBan** is read on Paper and Spigot only. Its events do not say who lifted a punishment, so a
  revoke never has a staff member, and it names staff by name: a staff member who is offline when it
  fires is recorded as the console. Notes are not punishments and are not reported. Temporary kinds
  count as their base kind (a temp-ban is a ban).

## Votes

NuVotifier's vote event, on whichever side runs it: the proxy or a server. Each vote carries the site
name as Votifier reports it and the username. The player's UUID is attached when they are online on the
side that received the vote; otherwise the vote is kept with the name alone. Votes appear on
Acquisition and in a player's timeline.

## LuckPerms

- **The group a session starts with.** Every `session.start` carries the player's LuckPerms **primary
  group** at that moment. The Ranks page uses it to split active players by rank.
- **Rank changes.** The agent compares a player's groups before and after every change, so
  `parent set` (a clear and an add) comes out as one add and one removal, and renewing a temporary group
  counts as a new add. The same group held in several contexts counts once, with its latest expiry.
- A change is reported where it was made — the proxy or the server where the command ran — so a network
  reports it once.
- A temporary group that expires on its own is not reported.

## PlaceholderAPI

Paper and Spigot only. See [Placeholders](/docs/exyliaanalytics/community#placeholders) for how to list
them and how the dashboard charts them.

## ViaVersion

On a standalone Paper server, ViaVersion lets in clients of other versions, and Paper then reports its
own version for all of them. When ViaVersion is installed the agent asks it for each player's real
version instead. On a network the proxy reports the version, so ViaVersion on a backend changes
nothing.

## Floodgate

When the Floodgate API is present, the agent asks it whether each player is on Bedrock. Without it, an
unlinked Bedrock player is still recognised by their UUID (`00000000-0000-0000-…`); a Bedrock player
linked to a Java account keeps the Java UUID, and only Floodgate can recognise them.
