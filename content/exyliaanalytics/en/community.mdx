These three pages read what the agent's integrations report. None of them follows the server filter:
a punishment, a rank or a placeholder value belongs to the network. How each integration is detected
is on [Integrations](/docs/exyliaanalytics/integrations).

## Moderation

Punishments from LiteBans, LibertyBans and AdvancedBan: how many, what kind, and who hands them out.

| Section | Shows |
|---|---|
| KPIs | Punishments in the range (split by kind), players punished, their share of active players, and punishments lifted (unbans and unmutes). |
| Punishments over time | Issued per period, stacked by kind: ban, mute, kick, warn. |
| Staff | Punishments issued by each staff member, by kind; the console as **Console**. |

A punishment is counted once by its plugin and its id. LiteBans running on the proxy and on a backend
both report the same ban; the dashboard keeps one.

The page is empty until a punishment plugin runs on a linked server or proxy with the **Punishments**
module on.

## Ranks

LuckPerms groups: who gains a rank, who renews it, and how each rank plays.

| Metric | Definition |
|---|---|
| Rank grants | A group added to a player, including a renewal: a temporary group whose expiry changed. |
| First-time grants | The first time a player gets that group. |
| Renewals | Grants that are not first-time. |
| Removals | Groups taken away. A temporary group that simply expires is not reported. |
| Players granted a rank | Unique players with a grant in the range. |

| Chart | Shows |
|---|---|
| Rank grants over time | Grants per period, by rank. |
| Active players by rank | Each active player once per period, under the rank they had when their latest session started. |
| By rank | Players, share of active players, sessions per player and average session length per rank. |
| Time to first rank | Days from a player's first session to their first rank: median and buckets from the same day to over 90 days. |

- The `default` group is never counted: LuckPerms gives it back whenever a player loses every other one.
- The rank a player *plays as* is their LuckPerms **primary group** at the moment their session starts.
  Without LuckPerms, or before LuckPerms has loaded the player, it is **Unknown**.
- Grants are recorded from the moment the agent sees them. History from before is not imported.
- A change is reported by the one server or proxy where it was made, so a network counts it once.

## Placeholders

Any PlaceholderAPI value you choose to collect: balances, levels, kills, anything a placeholder shows.

### Choosing what to collect

Placeholders are listed per server, in that server's [`config.yml`](/docs/exyliaanalytics/configuration),
up to 16:

```yaml
placeholders:
  - '%vault_eco_balance%'
  - '%statistic_mob_kills%'
```

Each time a player **leaves a Paper or Spigot server**, the agent resolves every listed placeholder for
them and sends the results. A placeholder PlaceholderAPI cannot resolve (it answers with the
placeholder itself) is left out, colour codes are stripped, and a value is cut to 200 characters. A
proxy has no PlaceholderAPI and sends none.

<Callout type="tip" title="Use the raw variant">
The dashboard charts a value only when it is a plain number: `1520.25`, `-3`, `1,520.25` or `1 000`.
Formatted values such as `1.5k`, `12 coins` or `1.520,25` are kept as text. Most expansions offer a raw
variant; list that one.
</Callout>

### The page

Pick a placeholder; the list shows how many players each one has values for. Every statistic uses
**each player's latest value** in the period, so a player who left ten times counts once.

| A numeric placeholder | Shows |
|---|---|
| Median, average, p90 | Of the players' latest values, over time. |
| Sum | Of the players' latest values — only the players seen in the period, so it is not a server-wide total. |

A placeholder is treated as numeric when at least half of its values are numbers. A text placeholder
shows players by their latest value instead.
