ExyliaAnalytics has a single permission. Players need none: the agent collects data without any player doing anything. Only the people who link and check the server need it.

## Give it to your staff

Operators have it by default on Paper and Spigot. For a rank, grant it with your permissions plugin. With LuckPerms:

```text
/lp group admin permission set exyliaanalytics.admin true
```

On Velocity nobody has it by default, operators included: only the console can run `/analyticsv` until a permissions plugin such as LuckPerms on the proxy grants `exyliaanalytics.admin`.

What your team can see in the dashboard is separate. It follows the roles of the workspace: see [Team and settings](/docs/exyliaanalytics/team).
