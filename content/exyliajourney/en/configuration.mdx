title: "Configuration"
description: "Every key of config.yml with its default: timings, feedback, the plugin's own NPCs, the guidance look and cinematic playback, plus the language files."
---

`config.yml` holds what is not a journey, a cinematic or a route. Times are written `30s`, `5m` or `1h30m`;
colours are palette tokens such as `{primary}` or `#rrggbb`; blocks and icons are material names; sounds
are `key|volume|pitch`. Apply a change with `/journeyadmin reload`.

## General

| Key | Default | What it does |
|---|---|---|
| `language` | `default` | `default` follows the language set in ExyliaLib's `config.yml`; a language code (`en`, `es`, `pt`, `fr`, `ru` or `tr`) sets this plugin alone. Each language is a folder under `lang/`. |
| `debug` | `false` | Explains in the console what the plugin is doing: starts, refusals, objectives counted. |
| `save-interval` | `5s` | How long changes wait before they are written, so a burst of progress costs one write. Players are always saved when they leave. |
| `first-join-delay` | `3s` | How long after a new player's first join their `FIRST_JOIN` journeys start, so the world has loaded. |
| `hint-after` | `45s` | Idle time on a step before its hint shows, for steps that do not set their own `hint-after`. `0s` turns default hints off. |
| `abandon-after` | `7d` | A step with no progress this long counts once as abandoned in the funnel and ExyliaAnalytics. Offline players are checked once an hour. `0s` turns it off. See [Analytics](/docs/exyliajourney/analytics#abandoned-steps). |
| `permission-check` | `5s` | How often `PERMISSION` triggers are checked for each online player. |

## Feedback

What plays on every completed step and journey, on top of each file's own effect lines.

| Key | Default | What it does |
|---|---|---|
| `feedback.step-sound` | `minecraft:entity.experience_orb.pickup\|0.7\|1.4` | Played when a step is completed, unless the player turned journey sounds off. |
| `feedback.step-toast` | `GOAL` | The toast frame for a completed step: `TASK`, `GOAL` or `CHALLENGE`. |
| `feedback.step-toast-icon` | `LIME_DYE` | The toast icon. |
| `feedback.step-effects` | a burst of `HAPPY_VILLAGER` particles | Sequence lines played at the player when a step is completed. |
| `feedback.journey-effects` | a short chime and a ring of particles, with no fireworks (below) | Sequence lines played at the player when a journey is completed. |

```yaml
feedback:
  journey-effects:
    - '[SOUND] ENTITY_PLAYER_LEVELUP;0.7;1.2'
    - '[CIRCLE] END_ROD;radius:1.6;points:28;y:0.2'
    - '[DELAY] 0.3'
    - '[SOUND] BLOCK_NOTE_BLOCK_CHIME;0.7;1.6'
    - '[PARTICLE] END_ROD;count:12;offset:0.4,0.6,0.4;y:1.2'
```

## NPCs

`npcs` is a map of NPCs this plugin places itself, by id, each one usable as an `INTERACT_NPC` target or an
`NPC_CLICK` trigger. Empty by default; `/journeyadmin demo` adds `demo-guide`. They need PacketEvents.

| Key | Default | What it does |
|---|---|---|
| `npcs.<id>.location` | `world,0,64,0,0` | `world,x,y,z[,yaw[,pitch]]`. |
| `npcs.<id>.skin` | `''` | A player name whose skin it wears; blank for the default. |
| `npcs.<id>.glow` | `''` | An outline colour as `#rrggbb`; blank for none. |
| `npcs.<id>.name` | `''` | The name floating over its head, written with palette tokens; blank for none. |

## Guide

How [guidance](/docs/exyliajourney/guidance) looks. The beacon's colour, label and the trail's route are
per step; these are the shared defaults.

### Text

| Key | Default | What it does |
|---|---|---|
| `guide.bar-color` | `PURPLE` | The step tracker boss bar at the top of the screen: `PINK`, `BLUE`, `RED`, `GREEN`, `YELLOW`, `PURPLE` or `WHITE`. |
| `guide.step-text` | `PANEL` | Where the step's text shows: `PANEL`, `TRACKER` or `CHAT`. See [Guidance](/docs/exyliajourney/guidance#text). |
| `guide.panel-screen-y` | `0.25` | `PANEL`: where its bottom edge sits as a share of the screen height from the bottom. `0.25` clears the hotbar, hearts and experience bar. |
| `guide.panel-scale` | `0.2` | Its size; `0.2` matches a cinematic subtitle. |
| `guide.panel-line-width` | `300` | Width in pixels before a line wraps. |
| `guide.panel-background` | `#000000` | Its backing colour. |
| `guide.panel-background-opacity` | `0` | Its opacity, `0` (no panel, the default) to `255`. |
| `guide.text-background` | `#000000` | The anchored sign's background colour. |
| `guide.text-background-opacity` | `0` | Its opacity, `0` (no panel) to `255`. |
| `guide.text-line-width` | `220` | Width in pixels before a line wraps. |
| `guide.text-shadow` | `true` | Text shadow. |
| `guide.text-see-through` | `true` | The anchored sign shows through blocks. |
| `guide.anchored-scale` | `1.0` | The anchored sign's size. |
| `guide.anchored-height` | `2.4` | How high over the target it floats when the step names no anchor. |
| `guide.anchored-max-scale` | `8.0` | How much it may grow with distance so it stays readable (full size up to 8 blocks away). `1` keeps it fixed. |

### Beacon

| Key | Default | What it does |
|---|---|---|
| `guide.beacon-block` | `PURPLE_STAINED_GLASS` | The beam's block. Stained glass reads best. The outline colour is the step's. |
| `guide.beacon-height` | `48` | The beam's height. |
| `guide.beacon-width` | `0.35` | Its width. |
| `guide.beacon-marker-distance` | `30` | How far ahead the stand-in is drawn while the target is out of sight. |
| `guide.beacon-label-max-scale` | `24` | The distance label keeps its size on screen as the player walks away, growing up to this many times. |
| `guide.npc-beacon-lift` | `2.6` | For a step that targets an NPC, how far above its feet the beam starts, so it stands over the NPC's head and name. |

### Trail

| Key | Default | What it does |
|---|---|---|
| `guide.trail-block` | `PURPLE_CONCRETE` | The trail's markers. |
| `guide.trail-color` | `{secondary_light}` | Their outline. |
| `guide.trail-spacing` | `1.5` | Blocks between markers. |
| `guide.trail-off-route` | `6` | How far off the route a player must stray for the way back to show. |
| `guide.trail-way-back-block` | `ORANGE_CONCRETE` | The way-back markers. |
| `guide.trail-way-back-color` | `{warning}` | Their outline. |
| `guide.auto-trail` | `PATH` | Footprints for a step with a target but no recorded route. `PATH`: the way a player can actually walk (doors, stairs, around walls and water), worked out again when they stray; where none is found within 128 blocks only the beacon shows the way. `STRAIGHT`: a straight line. `OFF`: only recorded routes. |
| `guide.route-simplify` | `0.4` | How much recorded routes are thinned before drawing, in blocks. `0` keeps every point. |

### Glow and hints

| Key | Default | What it does |
|---|---|---|
| `guide.glow-color` | `{primary}` | The outline of a glowing target NPC or block. |
| `guide.hint-sound` | `minecraft:block.note_block.bell\|0.7\|1.6` | Played when a hint shows, unless the player turned journey sounds off. |

## Cinematics

| Key | Default | What it does |
|---|---|---|
| `cinematics.move-viewer-beyond` | `96` | A viewer farther than this many blocks from a cinematic's first keyframe is moved next to it first and put back exactly where they stood when it ends. `0` never moves anybody. |
| `cinematics.subtitle-style`, `cinematics.title-style` | no backing panel | How subtitles and title cards look unless a cinematic or a line says otherwise: `background`, `opacity` (0 to 1), `shadow`, `width`, `scale`, `see-through`, `gap`, `speaker` and `speaker-format`. |
| `cinematics.hide-hud` | `BOSSBAR`, `SCOREBOARD`, `CHAT`, `ACTIONBAR`, `TITLES`, `PLAYERS` | What of the viewer's screen is hidden while watching: `PLAYERS` hides other players from the shot, `CHAT` is held back and delivered after. |
| `cinematics.reading-speed`, `cinematics.min-subtitle` | `15`, `1.5` | A subtitle with no duration stays as long as reading it takes (characters a second), and at least this many seconds. |
| `cinematics.typewriter`, `cinematics.scene-typewriter` | `0`, `42` | Characters a second subtitles, and subtitles of a cinematic written as scenes, are written out at. `0` shows them whole. |
| `cinematics.typewriter-sound`, `cinematics.continue-sound` | a quiet hat, a click | Played while a line is written out and when the viewer goes on from a stop, as `sound;volume;pitch`. Empty for none. |
| `cinematics.wait-timeout` | `45` | A cinematic stopped for a click goes on by itself after this many seconds. `0` waits for ever. A stop's own timeout wins. |
| `cinematics.hold-drift` | `0.04` | How far the camera breathes during a stop, in blocks. `0` stands still. |

## Settings in game

An admin does not have to edit the file for the settings worth changing. The **Settings** card on the
journey list in `/journeyadmin` opens a hub with three pages, each card explaining what the value does,
showing the current value and its default, and editing it on click (numbers and durations are typed;
shift-right-click resets):

| Page | Settings |
|---|---|
| General | `language`, `first-join-delay`, `hint-after`, `abandon-after`, `feedback.step-toast`. |
| Guidance | `guide.bar-color`, `guide.step-text`, `guide.auto-trail`. |
| Cinematics | `cinematics.move-viewer-beyond`, `cinematics.typewriter`, `cinematics.wait-timeout`. |

Everything else stays in `config.yml`. The cards are on screens the plugin ships in `menus/admin/`.

## Language files

The plugin ships `en`, `es`, `pt`, `fr`, `ru` and `tr`. Under `lang/<language>/`:

| File | Contents |
|---|---|
| `messages.yml` | The prefix, every player and admin line, the panel and beacon label, the chat and action bar fallback lines, cinematic subtitles, the editor's prompts, labels, and the names of the guidance switches in `/settings`. |
| `editor.yml` | The editor's words. |
| `menus/user/journey.yml` | The `/journey` chest menu, used when screen menus are off. Yours to restyle: an update only adds what is missing. |
| `screens/journey.html`, `theme.css`, `components/` | The `/journey` screen menu: a side bar with your progress, the steps or the guidance switches on the right. One file for every language (the words come from `lang/<language>/screens/journey.yml`); put your own rules in `screens/custom.css` and the file keeps updating with the plugin. `/exylialib screens check` lists anything wrong with it. |
| `dialogues/<id>.yml` | One [dialogue](/docs/exyliajourney/dialogues) per file. |
| `menus/admin/` | The editor's screens. Regenerated from the plugin on every start. |
| `overlays/cinematic_recorder.yml` | The recorder's hotbar. |
