By the end of this page you will have played a complete journey and built a second one yourself. You need ExyliaJourney [installed](/docs/exyliajourney/installation) and to be an operator (or have `exyliajourney.admin`).

## The demo, in one command

Stand somewhere open and run:

```
/journeyadmin demo
```

The plugin writes a complete example around you and starts it for you at once:

| File | What it is |
|---|---|
| `journeys/demo.yml` | *First steps*, six steps, one of every common kind. |
| `cinematics/demo-orbit.yml` | Eight shots circling you, three subtitles and two sounds. |
| `routes/demo-path.yml` | A curved path from where you stand to the guide. |
| `config.yml` → `npcs.demo-guide` | A guide NPC about twenty blocks ahead of you. |

The journey then walks you through:

1. **Watch the introduction**: the cinematic plays (`WATCH_CINEMATIC`).
2. **Follow the trail**: footprints and a beacon lead to the guide (`REACH` with a trail).
3. **Talk to the guide**: right-click the NPC, which glows for you (`INTERACT_NPC`).
4. **Break three blocks**: any block counts (`BREAK_BLOCK`).
5. **Open your journey**: type `/journey` (`RUN_COMMAND`).
6. **Take a breath**: five seconds you cannot skip (`WAIT`).

Finishing it pays 50 experience and plays the celebration. The demo journey is repeatable and starts only from a command or the `demo:start` key, so it never reaches your players on its own. Run the command again to rebuild it where you stand.

<Callout type="note" title="Without PacketEvents">
The demo still runs, with chat and particle guidance, but the guide NPC cannot be shown: the plugin tells you so and gives you the command that finishes that step, `/journeyadmin trigger <you> npc:demo-guide`.
</Callout>

## Your first journey

<Steps>
  <Step title="Create it">
    Run `/journeyadmin`, click **Create journey**, then type an id (`welcome`) and a name. The journey is created switched on, with one step, *Find the meeting point*: a `REACH` objective where you are standing.
  </Step>
  <Step title="Add the steps">
    Open the journey, click **Steps**, then **Add step**. Pick an objective type and fill it from its screen: **Place** (left-click uses where you stand), **NPC**, **Filter** for blocks or items, **Amount**. Use **Go here step** for a quick "walk to this spot" step with a beacon and a trail.
  </Step>
  <Step title="Show the way">
    On each step, click **Guidance**: the text panel, the beacon, the trail along a recorded route, the waypoint, the glow and a cinematic that opens the step. See [Guidance](/docs/exyliajourney/guidance).
  </Step>
  <Step title="Decide when it starts">
    Click **Start & access**, then **Add trigger**. For onboarding pick `FIRST_JOIN`. A new journey has no trigger, so nobody gets it until you add one.
  </Step>
  <Step title="Reward it">
    **Rewards & effects** on the journey, and **Effects & rewards** on each step.
  </Step>
  <Step title="Test it">
    Click **Test run** on the journey, or run `/journeyadmin test welcome`. You play the live version from the first step; nothing is saved, counted or paid. Run `/journeyadmin test stop` to end it.
  </Step>
</Steps>

Every click is written back to `journeys/<id>.yml` and goes live at once, with no reload.

## Check that it works

1. Run `/journeyadmin test welcome`. The step appears in chat and as floating text, with a beacon over the place you chose.
2. Walk into the place. The step completes and the next one starts.
3. When it ends, run `/journeyadmin test stop` if you are still in the test, then `/journey` to see how a player sees their journeys.

To see what a real player gets, start it for them: `/journeyadmin start <player> welcome`. `FIRST_JOIN` only starts for players who have never joined the server before, so it will not fire for you.

## What a fresh install does

Nothing reaches players until you say so: `journeys/example.yml` ships with `enabled: false`, and the demo only starts from a command. Once a journey is enabled and has a trigger, players get it.

| What | Default |
|---|---|
| Who can open `/journey` | Everybody (`exyliajourney.use`) |
| Who can edit | Operators (`exyliajourney.admin`) |
| First-join journeys start | 3 seconds after joining, so the world has loaded |
| Hints | After 45 seconds idle on a step |
| A step counts as abandoned | After 7 days with no progress |
| Cinematic viewers far away | Moved next to the scene beyond 96 blocks, then put back |
