---
title: "Placeholders"
description: "Every %journey_...% placeholder: the tracked journey and step, progress, counts and per-journey state."
---

Registered with ExyliaLib's placeholder registry and, when it is installed, with PlaceholderAPI. Each one is
about the player viewing it and is read from memory, so it is cheap on scoreboards.

## The tracked journey

These describe the journey the player is following now — the one the guidance shows — and resolve to
nothing when the player has none.

| Placeholder | Value |
|---|---|
| `%journey_current%` | The journey's name, without colours. |
| `%journey_current_id%` | Its id. |
| `%journey_step%` | The current step's title, without colours. |
| `%journey_step_id%` | The current step's id. |
| `%journey_step_number%` | The current step's number, from 1. |
| `%journey_steps%` | How many steps the journey has. |
| `%journey_progress%` | The current step's count, as `3/10`. |
| `%journey_progress_percent%` | The current step's progress, `0` to `100`. |
| `%journey_journey_percent%` | The whole journey's progress, `0` to `100`, counting the current step's share. |

## Counts

| Placeholder | Value |
|---|---|
| `%journey_active%` | How many journeys the player has active. |
| `%journey_completed%` | How many journeys the player has completed. |

## One journey

Replace `<id>` with a journey's id.

| Placeholder | Value |
|---|---|
| `%journey_state_<id>%` | `ACTIVE`, `COMPLETED`, `SKIPPED`, `STOPPED` or `NONE`. |
| `%journey_completions_<id>%` | How many times the player completed it. |

```yaml
# a scoreboard line
- '{letters}Journey {letters_black}» {info}%journey_current%'
- '{letters}Step {letters_black}» {info}%journey_step_number%/%journey_steps%'
```
