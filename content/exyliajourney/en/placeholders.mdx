Registered with ExyliaLib's placeholder registry and, when it is installed, with PlaceholderAPI, so they work in any plugin that reads placeholders. Each one is about the player viewing it and is read from memory, so it is cheap on scoreboards.

The ones under "tracked" describe the journey the player is following now, the one the guidance shows. They are empty when the player has none.

<Placeholders />

## Example: a scoreboard

```yaml
- '{letters}Journey {letters_black}» {info}%journey_current%'
- '{letters}Step {letters_black}» {info}%journey_step_number%/%journey_steps%'
```
