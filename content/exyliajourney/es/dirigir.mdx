Al terminar esta página tu cinemática se para donde quien la ve debe leer, escribe sus líneas letra a letra, y
puede poner actores en escena y hacer una pregunta cuya respuesta decide lo que pasa después. Todo vive en el
mismo archivo `cinematics/<id>.yml` que [lo básico](/docs/exyliajourney/cinematicas), y todo es solo para quien
la ve.

## Antes de empezar

Necesitas una cinemática con unos cuantos subtítulos: consulta [Crear una cinemática](/docs/exyliajourney/cinematicas).
Los dos ajustes que casi todos quieren están en el editor; el resto se escribe en el archivo y se aplica con
`/journeyadmin reload` o en la siguiente reproducción.

## Pasos

<Steps>
  <Step title="Abre la cinemática">
    Ejecuta `/journeyadmin`, pulsa **Cinemáticas** y luego tu cinemática.
  </Step>
  <Step title="Haz que espere a quien la ve">
    Pulsa **Ritmo**. El clic izquierdo alterna entre **automático** (se reproduce seguida) y **espera** (una
    parada tras cada subtítulo, hasta que quien la ve hace clic).
  </Step>
  <Step title="Escribe las líneas letra a letra">
    Haz clic derecho en **Ritmo** para cambiar la velocidad del texto: apagado (líneas enteras) y luego cada vez
    más rápido.
  </Step>
  <Step title="Ve más lejos en el archivo">
    Las sacudidas, las escenas, los actores y las respuestas no tienen botón. Añádelos a `cinematics/<id>.yml`
    como se muestra en [Ir más allá](#ir-más-allá) y míralo con **Verla**.
  </Step>
</Steps>

## Comprueba que funciona

Pulsa **Verla** en la cinemática (o ejecuta `/journeyadmin cinematic play <id>`). Con la espera activada, la
cámara se mantiene tras cada línea, se desplaza un poco y muestra un aviso pulsante; un clic termina una línea
que aún se escribe, el siguiente continúa. Si nadie hace clic, sigue sola a los 45 segundos. **Ritmo** también
muestra las paradas y cuál pierde más espectadores.

## Ir más allá

### Paradas

Una parada congela la cinemática en un momento hasta que quien la ve hace clic. La cámara se mantiene, se
desplaza un poco (`hold-drift`) para que la imagen siga viva, y un aviso pulsante invita al clic. La primera
pulsación termina una línea que aún se está escribiendo; la siguiente continúa. Los subtítulos, los rótulos, los
actores y el reloj de la cinemática esperan con la cámara.

Cuatro formas de hacer una parada en el archivo:

```yaml
advance: CLICK                 # una parada tras cada subtítulo
keyframes:
  - { at: 'world,0.00,70.00,0.00', time: 4.0, wait: true }       # se para cuando la cámara se ha asentado
  - { at: 'world,5.00,70.00,0.00', time: 9.0, wait: { timeout: 20 } }
waits:
  - { time: 12.0, timeout: 30, text: '{letters}Pulsa para continuar' }
  - { at: { keyframe: 3, offset: 1.0 } }
```

`timeout` son los segundos hasta que la cinemática sigue sola. Sin él se aplica `cinematics.wait-timeout` (45 s
por defecto); `0` espera para siempre. Así nadie se queda congelado lejos del teclado. `text` en una parada es
una línea que se mantiene en pantalla mientras espera; los colores siguen [Colores](/docs/exylialib/colores). El
último subtítulo que empezó antes de una parada también se mantiene en pantalla hasta que quien la ve continúa,
así la línea sobre la que se le pregunta nunca ha desaparecido ya. Dos paradas a menos de 0,3 segundos son una.
Cada parada a la que llega un espectador, desde la que sigue (pulsando o por tiempo) o en la que se va se
cuenta en las estadísticas del plugin.

<Details title="Claves de las paradas">

| Clave | Qué hace |
|---|---|
| `advance` | `AUTO` (por defecto) se reproduce seguida; `CLICK` pone una parada al final de cada subtítulo. |
| `wait` en un fotograma | `true` o una sección con `timeout`: se para cuando la cámara se ha asentado allí (se queda al menos 0,2 s). `wait: false` es ninguna. |
| `waits` | Una lista de paradas: `time`, o `at: { keyframe, offset }` para seguir a un fotograma al reajustar tiempos; `timeout`; `text`. |

</Details>

### Líneas escritas

Las líneas pueden aparecer como si se escribieran, a `typewriter` caracteres por segundo:

```yaml
typewriter: 30     # esta cinemática; 0 muestra las líneas enteras
drift: 0.08        # bloques que respira la cámara en una parada; 0 se queda quieta
```

Suena un sonido suave mientras se escribe una línea, y otro cuando quien la ve continúa. Sin `typewriter` se
aplica el de `config.yml`.

### Sacudidas

```yaml
shakes:
  - { time: 6.0, length: 0.8, strength: 0.4 }
```

La cámara se sacude durante `length` segundos (al menos 0,05), apagándose; `strength` va en bloques, de 0 a 3,
`0.25` por defecto.

### Escenas

`scenes` es una forma de escribir una cinemática sin tiempos. Cada escena es un movimiento de cámara y las
líneas que se dicen sobre él; el plugin calcula los fotogramas, los tiempos de las líneas, las paradas y los
fundidos, y los compila en los mismos fotogramas, subtítulos y paradas de que se componen todas las demás
cinemáticas.

```yaml
typewriter: 35
scenes:
  - title: '{highlight}&lLa capital'
    from: { at: 'world,100.5,80.0,40.5', yaw: 140, pitch: 20 }
    to:   { at: 'world,120.5,74.0,60.5', yaw: 160, pitch: 15 }
    lines:
      - 'Guía: Bienvenido a la capital.'
      - '-: La ciudad nunca duerme.'
    sounds:
      - { sound: BLOCK_AMETHYST_BLOCK_CHIME, after: 0.5 }
  - from: { at: 'world,0.5,70.0,0.5', yaw: 0, pitch: 10 }
    look-at: 'npc:guide'
    lines: ['Guía: Aquí es donde empieza todo.']
    wait: false
```

Una cinemática de escenas escribe sus líneas a `cinematics.scene-typewriter` (42 caracteres por segundo) salvo
que `typewriter` diga otra cosa. Las escenas pueden ir junto a `keyframes` normales. El editor vuelve a escribir
un archivo de escenas como fotogramas.

<Details title="Claves de las escenas">

| Clave | Por defecto | Qué hace |
|---|---|---|
| `from` | ninguno | `{ at, yaw, pitch }`: dónde empieza la cámara. Una escena sin ella se omite. |
| `to` | ninguno | Dónde acaba. Sin ella la escena es un plano fijo. |
| `lines` | ninguno | `Speaker: línea`; `-: línea` es narración. Cada una se muestra durante su tiempo de lectura, más el de escribirla. |
| `title`, `title-seconds` | ninguno, `2.2` | Un rótulo primero. Las líneas empiezan después. |
| `seconds` | hasta leer la primera línea | Cuánto dura el movimiento. |
| `easing` | `SMOOTH` | Cómo llega a `to`. |
| `look-at` | ninguno | `world,x,y,z` o `npc:<id>`: apunta ahí durante la escena. |
| `fade` | `0.8` | Negro alrededor del corte hacia esta escena. Las escenas después de la primera son cortes. |
| `wait` | `true` | Una parada tras cada línea. `false` para ninguna, o `{ timeout }`. |
| `sounds` | ninguno | `{ sound, after, volume, pitch }`, con `after` contado desde el inicio de la escena. |
| `run` | ninguno | Líneas de interacción que se ejecutan al empezar la escena. |

</Details>

### Actores

Un actor es un cuerpo en escena que solo ve quien mira la cinemática: no queda nada en el mundo.

```yaml
actors:
  - id: guide
    name: '{highlight}Guía'
    skin: viewer              # la skin del espectador; un valor de textura; o vacío para la de por defecto
    at: 'world,10.5,70.0,3.5'
    yaw: 180
    held: DIAMOND_SWORD
    cues:
      - { time: 1.0, walk-to: 'world,14.5,70.0,3.5', seconds: 3 }
      - { time: 4.5, look: camera }
      - { time: 5.0, swing: true }
      - { time: 6.0, pose: LYING }
      - { time: 8.0, hide: true }
```

Los actores siguen el reloj de la propia cinemática, así que se quedan quietos mientras espera en una parada.

<Details title="Claves de actores y señales">

| Clave | Qué es |
|---|---|
| `id`, `name` | Su nombre en el archivo, y el nombre dibujado sobre él (vacío para ninguno). |
| `skin` | `viewer`, un valor de textura, o vacío. |
| `at`, `yaw` | Dónde está y hacia dónde mira al empezar. `at` es obligatorio. |
| `held` | Un material en la mano. |
| `cues` | Lo que hace, en orden de tiempo. |

Cada señal tiene un `time` y una de estas: `walk-to` (con `seconds`; por defecto 3 bloques por segundo), `look`
(`camera` o `world,x,y,z`), `pose` (`STANDING`, `LYING`, `CRAWLING`, `SNEAKING` o `SPINNING`), `swing: true`,
`hurt: true` o `hide: true`. Una señal que no dice ninguna se avisa y se omite.

</Details>

### Respuestas y ramas

Una cinemática puede terminar con una pregunta:

```yaml
choice-prompt: '{letters}¿Qué haces?'
choices:
  - { text: '{success}Seguir al guía', next: follow-guide, key: followed }
  - { text: '{error}Quedarte atrás', key: stayed }
```

La pantalla se oscurece tras la pregunta. Cerrarla toma la primera respuesta, así nadie se queda fuera de la
historia. Un paso puede esperar una respuesta con un objetivo `CUSTOM` sobre `choice:followed`, de modo que las
dos respuestas lleven a cosas distintas (consulta [Añadir pasos y objetivos](/docs/exyliajourney/pasos)). A los
jugadores de Bedrock, que no pueden dibujar la cámara, no se les pregunta.

<Details title="Claves de las respuestas">

| Clave | Qué hace |
|---|---|
| `text` | La respuesta. Una sin texto se omite. |
| `next` | Otra cinemática que se reproduce al instante. Sin ella, el `next` de la propia cinemática, y si no, nada. |
| `key` | Dispara la clave personalizada `choice:<key>` para el jugador. |
| `choice-prompt` | La pregunta; si no, la de `messages.yml`. Consulta [Mensajes e idiomas](/docs/exylialib/mensajes-e-idiomas). |

</Details>

### Valores por defecto

En `config.yml`, bajo `cinematics`:

<Details title="Valores por defecto de la dirección">

| Clave | Por defecto | Qué hace |
|---|---|---|
| `typewriter` | `0` | Caracteres por segundo a los que se escriben las líneas; `0` las muestra enteras. |
| `scene-typewriter` | `42` | Lo mismo para las escenas. |
| `typewriter-sound` | `BLOCK_NOTE_BLOCK_HAT;0.12;1.9` | Un sonido suave al escribir, `sonido;volumen;tono`; vacío para ninguno. |
| `continue-sound` | `UI_BUTTON_CLICK;0.25;1.5` | Cuando quien la ve continúa desde una parada; vacío para ninguno. |
| `wait-timeout` | `45` | Segundos antes de que una parada siga sola; `0` espera para siempre. El `timeout` propio de una parada manda. |
| `hold-drift` | `0.04` | Bloques que respira la cámara en una parada; `0` se queda quieta. |

</Details>

Tres de ellos (`typewriter`, `wait-timeout` y la distancia de traslado `move-viewer-beyond`) también se cambian
en el juego: pulsa **Ajustes** en la lista de travesías, luego **Cinemáticas**, y **Mover espectador**,
**Máquina de escribir** o **Espera de parada**.
