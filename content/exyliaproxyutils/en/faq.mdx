## Is it free?

Yes. Download it from [GitHub releases](https://github.com/Exylia-Plugins/ExyliaProxyUtils/releases);
there is no licence key and nothing to buy.

## Velocity or BungeeCord?

Either, with the same jar. Everything works on both, except that AdvancedBan exists only for BungeeCord,
and the kick and ban screens use MiniMessage on Velocity and `§` codes on BungeeCord.

## Do I need it on a single server?

No. It is only for a network behind a proxy: proxy commands, cross-server teleports, lookups and kicks
across servers. A single server runs every Exylia plugin without it.

## I am upgrading from 1.x

1.x talked over plugin messages; 2.x talks over Redis. Update ExyliaLib on every backend to 1.106.0 or
newer, enable Redis in a `database.yml` on each, replace the proxy jar, start it once, fill in
`config.properties`, and restart. A new major is never installed by the updater on its own.

## Teleports say no server "lobby-1"

The proxy has no server by that name. A backend's name in the proxy's server list must be exactly its
`server-id`. See [Installation](/docs/exyliaproxyutils/installation).

## The backends say no proxy bridge answered

The two sides are not on the same Redis, the same numbered database, or the same `key-prefix`; or the
proxy failed to start (look for `could not start` in its console). See
[First steps](/docs/exyliaproxyutils/first-steps#when-nothing-answers).

## Redis went down and came back. Do I need to restart?

Not if the proxy started while Redis was up: the listener reconnects every two seconds. If Redis was
down when the proxy started, yes — the plugin does not retry a failed start.

## Is it safe?

Players cannot reach the bridge: nothing they send travels over Redis. Whoever can publish on your
Redis can, though, including `console-proxy:` commands. Keep Redis off the public internet and behind a
password.

## A /ban on the proxy does not show up in ExyliaStaff

Check the proxy console for `Recording <ORIGIN> punishments made on this proxy.` at startup. Without it
the ban plugin was not found (or failed to hook). Address-only bans are never recorded. See
[Punishments](/docs/exyliaproxyutils/punishments).

## Where do I get help?

On the [Exylia Discord](https://discord.exylia.net).
