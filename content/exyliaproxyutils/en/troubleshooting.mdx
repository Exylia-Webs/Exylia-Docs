Find your symptom, then follow the fix.

## `could not start` on the proxy

Check `redis.host`, `redis.port`, `redis.password` and `redis.database` in `config.properties`. A `redis.port` that is not a number also stops the start. See [Configuration](/docs/exyliaproxyutils/configuration).

## The servers say no proxy bridge answered

The two sides are not on the same Redis, the same numbered database or the same `key-prefix`; or the proxy failed to start. Compare the proxy's `config.properties` with the server's `database.redis` section, then check the proxy console.

## Requests time out after five seconds

The proxy started before Redis was up. The connection is tested once at start, so restart the proxy.

## Teleports say `no server "<name>"`

The proxy has no server by that name. A server's name in `velocity.toml` (or BungeeCord's `config.yml`) must be exactly its `server-id`. See [Install ExyliaProxyUtils](/docs/exyliaproxyutils/installation).

## `UNKNOWN_MODULE`

A server asks for a module this proxy version does not have. Update the proxy jar; see [Modules](/docs/exyliaproxyutils/modules).

## A command with `player-proxy:` does nothing

The player needs permission for that command on the proxy, and the proxy must have the command. A refusal such as `the proxy did not run "/<command>"` is logged on the server. See [Permissions](/docs/exyliaproxyutils/permissions).

## A ban on the proxy does not show in ExyliaStaff

The console must show `Recording <ORIGIN> punishments made on this proxy.` at startup. Without it the ban plugin was not found or failed to hook (`Could not hook <ORIGIN>: <error>`). Bans that name only an address are never recorded. See [Punishments](/docs/exyliaproxyutils/punishments).

## A banned player still gets in

The login check only reads bans ExyliaStaff has made. If Redis is down at that moment the player is let in, and the servers check their own database. See [Block banned players at login](/docs/exyliaproxyutils/login-bans).

## I changed the config and nothing happened

`config.properties` is read once, at startup. Restart the proxy.
