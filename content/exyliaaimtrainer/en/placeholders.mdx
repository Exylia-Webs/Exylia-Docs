Every placeholder below is written in full, and clicking one copies it.

## How the name is written

A placeholder is the plugin name followed by the placeholder's own name, written the same way
everywhere: through PlaceholderAPI, and inside the plugin's own files — `scoreboards.yml`, `menus/`,
`messages.yml`.

```text
%exyliaaimtrainer_wins%
```

<Callout type="warning" title="Renamed after 1.0.1">
Up to `v1.0.1` every name carried the group `aim`: `%exyliaaimtrainer_aim_wins%` through PlaceholderAPI
and `%aim_wins%` inside the plugin's files. Neither form resolves any more. Write
`%exyliaaimtrainer_<name>%`, and update a `scoreboards.yml` or `menus/main.yml` already generated on the
server.
</Callout>

Every placeholder resolves for the player looking at it. Most answer something whatever the moment: `0`,
or `—` (the `menu.none` text in `messages.yml`) where a number or a name does not apply. The exceptions
are noted in their rows.

### A run, a session, a duel

Three words matter in the tables below.

- A **run** is one drill being played, from the first live target to the end. It does not exist during
  the countdown, while resting after a drill, or between two rounds of a duel. In a duel, each round is
  a run.
- A **session** is the whole solo stay in the arena: countdown, run, rest and every replay.
- A **duel** is the whole series, from the teleport to the result.

## Lifetime

Read from the player's profile. Until the profile has loaded after joining, each answers `0`, or `—` for
the times.

| Placeholder | Description |
|---|---|
| `%exyliaaimtrainer_total_rating%` | The overall rating: the sum of the player's best rating in every drill. |
| `%exyliaaimtrainer_sessions%` | Solo runs stored. |
| `%exyliaaimtrainer_total_hits%` | Lifetime hits, solo runs and duels. |
| `%exyliaaimtrainer_total_shots%` | Lifetime shots, solo runs and duels: hits plus misses. |
| `%exyliaaimtrainer_best_flick%` | The fastest time between two hits ever: `183ms`. `—` when none. |
| `%exyliaaimtrainer_best_reaction%` | The fastest reaction ever: `201ms`. `—` when none. |

## Duel record

| Placeholder | Description |
|---|---|
| `%exyliaaimtrainer_wins%` | Duels won. |
| `%exyliaaimtrainer_losses%` | Duels lost. |
| `%exyliaaimtrainer_winrate%` | Wins over duels played, with its sign: `50%`. Decimals follow ExyliaLib's number format. |
| `%exyliaaimtrainer_win_streak%` | Duels won in a row right now. |
| `%exyliaaimtrainer_best_win_streak%` | Best run of duels won in a row. |

## Live or lifetime

These four mean the running run while there is one and the lifetime profile otherwise, so a sidebar line
and a lobby hologram can share a name. With no run and no profile loaded they leave the text unchanged.

| Placeholder | Description |
|---|---|
| `%exyliaaimtrainer_hits%` | Hits of the running run; lifetime hits outside one. |
| `%exyliaaimtrainer_misses%` | Misses of the running run; lifetime shots minus lifetime hits outside one. |
| `%exyliaaimtrainer_shots%` | Hits plus misses of the running run; lifetime shots outside one. |
| `%exyliaaimtrainer_accuracy%` | Accuracy of the running run (time on target in a TRACK drill, which has no shots), or lifetime accuracy, one decimal and **no** `%` sign: `87.5`. |

## The running run

Each of these answers `0`, `0.0` or `—` when there is no run.

| Placeholder | Description |
|---|---|
| `%exyliaaimtrainer_score%` | The live score. |
| `%exyliaaimtrainer_rating%` | The live score times the difficulty. |
| `%exyliaaimtrainer_streak%` | Hits in a row. A miss, an expired target or a false start ends it. |
| `%exyliaaimtrainer_best_streak%` | The longest streak of this run. |
| `%exyliaaimtrainer_combo%` | The current combo, in a COMBO drill. |
| `%exyliaaimtrainer_best_combo%` | The longest combo of this run. |
| `%exyliaaimtrainer_time_left%` | Seconds left, rounded up: `30`, `1:30`. For a REACTION drill, what is left of its cap. |
| `%exyliaaimtrainer_targets_left%` | Lights still to answer in a REACTION drill; `0` in any other. |
| `%exyliaaimtrainer_grade%` | The grade of the last graded hit: `Perfect`, `Excellent`, `Good`, `Ok` or `Slow`. `—` before the first. |
| `%exyliaaimtrainer_avg_flick%` | The average time between two hits: `312ms`. `—` before the second hit. |
| `%exyliaaimtrainer_avg_reaction%` | The average reaction: `245ms`. `—` before the first. |
| `%exyliaaimtrainer_on_target%` | Percent of the run spent on target, in a TRACK drill, one decimal and no sign: `64.2`. |
| `%exyliaaimtrainer_precision%` | How central the hits were, as a percent, one decimal and no sign. |
| `%exyliaaimtrainer_ping%` | The ping the run last measured. Outside a run, the player's current ping. |

## What the player is doing

| Placeholder | Description |
|---|---|
| `%exyliaaimtrainer_state%` | `none`, `training` or `match`. |
| `%exyliaaimtrainer_state_label%` | The same in the words of `menu.state-none`, `state-training` and `state-match`: `None`, `Drill`, `Duel`. |
| `%exyliaaimtrainer_phase%` | In a solo session, `countdown`, `running` or `resting`. `none` outside one, and during a duel. |
| `%exyliaaimtrainer_drill%` | The display name of the drill of the session or duel. `—` outside both. |
| `%exyliaaimtrainer_drill_id%` | The drill's id from `config.yml`: `gridshot`. Empty outside a session or duel. |
| `%exyliaaimtrainer_kind%` | The drill's kind in the words of `menu.kinds`: `Flicking`, `Reaction`, `Tracking`, `Combo`. `—` outside. |
| `%exyliaaimtrainer_difficulty%` | The difficulty multiplier of the session or duel, two decimals: `1.35`. `1.00` outside. |

## The running duel

| Placeholder | Description |
|---|---|
| `%exyliaaimtrainer_format%` | The series length: `BO3`. `—` outside a duel. |
| `%exyliaaimtrainer_opponent%` | The opponent's name. `—` outside a duel. |
| `%exyliaaimtrainer_opponent_score%` | The opponent's live score this round; `0` between rounds and outside a duel. |
| `%exyliaaimtrainer_opponent_hits%` | The opponent's hits this round; `0` between rounds and outside a duel. |
| `%exyliaaimtrainer_round%` | The round being played. `0` outside a duel. |
| `%exyliaaimtrainer_series%` | Rounds won, yours first: `2 - 1`. `0 - 0` outside a duel. |
| `%exyliaaimtrainer_match_state%` | `waiting`, `starting`, `active`, `round_end`, `ending` or `finished`. `none` outside a duel. |

## Server-wide

These need no viewer, so a lobby hologram can show them.

| Placeholder | Description |
|---|---|
| `%exyliaaimtrainer_training_count%` | Players in a solo session, whatever its phase: countdown, run or rest. |
| `%exyliaaimtrainer_match_count%` | Players in a duel, not duels: one duel counts `2`. A duel that is `ending` or `finished` no longer counts. |
| `%exyliaaimtrainer_playing_count%` | The two added up: every player in a drill or a duel. |

## Leaderboards

A board is about one drill and sorted by one category, and both go in the name. Every board placeholder
comes in two forms: the plain one answers the name of the player at position `n`, and the one ending in
`_value` the number that put them there.

`<drill>` is a drill id from `config.yml` — in the file the plugin ships: `gridshot`, `scatter`,
`sixshot`, `microshot`, `spidershot`, `flick`, `precision`, `decay`, `switch`, `strafe`, `reaction`,
`tracking`, `evasive`, `combo`, `combo_19` and `axe` — and `<n>` is the position, counting from 1.

| Placeholder | Sorted by | What it answers |
|---|---|---|
| `%exyliaaimtrainer_top_<drill>_rating_<n>%` | Best rating, highest first | The name of the player at that position. |
| `%exyliaaimtrainer_top_<drill>_rating_<n>_value%` | The same board | Their rating: `1284`. |
| `%exyliaaimtrainer_top_<drill>_score_<n>%` | Best score, highest first | The name of the player at that position. |
| `%exyliaaimtrainer_top_<drill>_score_<n>_value%` | The same board | Their score, without a unit: `950`. |
| `%exyliaaimtrainer_top_<drill>_accuracy_<n>%` | Best accuracy over runs with enough shots, highest first | The name of the player at that position. |
| `%exyliaaimtrainer_top_<drill>_accuracy_<n>_value%` | The same board | Their accuracy, with its sign: `92.4%`. |
| `%exyliaaimtrainer_top_<drill>_streak_<n>%` | Longest streak, highest first | The name of the player at that position. |
| `%exyliaaimtrainer_top_<drill>_streak_<n>_value%` | The same board | Their streak: `41`. |
| `%exyliaaimtrainer_top_<drill>_hits_<n>%` | Most hits in one run, highest first | The name of the player at that position. |
| `%exyliaaimtrainer_top_<drill>_hits_<n>_value%` | The same board | Their hits: `96`. |
| `%exyliaaimtrainer_top_<drill>_reaction_<n>%` | Fastest single reaction, **lowest** first | The name of the player at that position. |
| `%exyliaaimtrainer_top_<drill>_reaction_<n>_value%` | The same board | Their reaction: `178ms`. |
| `%exyliaaimtrainer_top_<drill>_combo_<n>%` | Longest combo, highest first | The name of the player at that position. |
| `%exyliaaimtrainer_top_<drill>_combo_<n>_value%` | The same board | Their combo: `12`. |

The overall board goes in place of a drill as `overall`, and sorts by two categories only:

| Placeholder | Sorted by | What it answers |
|---|---|---|
| `%exyliaaimtrainer_top_overall_rating_<n>%` | Overall rating, highest first | The name of the player at that position. |
| `%exyliaaimtrainer_top_overall_rating_<n>_value%` | The same board | Their overall rating: `9120`. |
| `%exyliaaimtrainer_top_overall_accuracy_<n>%` | Lifetime accuracy, highest first | The name of the player at that position. |
| `%exyliaaimtrainer_top_overall_accuracy_<n>_value%` | The same board | Their accuracy, with its sign: `81.3%`. |

Any other category written after `overall` reads the rating board.

Written out, with a drill and a position in place:

```text
%exyliaaimtrainer_top_gridshot_rating_1%
%exyliaaimtrainer_top_gridshot_rating_1_value%
%exyliaaimtrainer_top_reaction_reaction_3_value%
%exyliaaimtrainer_top_combo_19_combo_1%
%exyliaaimtrainer_top_overall_rating_1_value%
```

A drill id with underscores in it is matched whole, longest id first:
`%exyliaaimtrainer_top_combo_19_combo_1%` is the `combo` board of `combo_19`, not something about
`combo`. Until a board has been read once, both forms answer the `menu.loading` text, *Loading…*, and
kick the read off; after that they keep showing the last board read while a newer one loads. A position
past the end of the board, an unknown drill, an unknown category or a position that is not a number
leaves the text unchanged. See [Statistics](/docs/exyliaaimtrainer/stats) for how a board is built and
how long it is cached.
