Cada evento lleva su propia lista de horarios, editable desde las pantallas de horarios de
`/captureadmin`. El horario en sí es el [módulo de horarios](/docs/exylialib/horarios) de ExyliaLib:
el mismo editor, los mismos campos y las mismas reglas que cualquier otro plugin de Exylia que arranca
cosas con reloj.

## Qué contiene un horario

| Campo | Significado |
|---|---|
| `name` | Una etiqueta para la entrada. En blanco muestra las horas en su lugar. |
| `enabled` | Si puede disparar. Activado por defecto. |
| `days` | Nombres de días, o `*` para todos. Una lista vacía también significa todos. |
| `times` | Las horas `HH:mm` en que dispara, como lista. Un `time` suelto se sigue leyendo. |
| `every` | Repetir con esta frecuencia en vez de a horas fijas, como `2h` o `90m`. |
| `from` / `to` | La ventana dentro de la que corre la repetición, como `HH:mm`. |
| `min-players` | Jugadores que deben estar conectados para que dispare. Por defecto `0`. |
| `max-players` | Máximo de jugadores conectados para que dispare. `0` es sin límite. |
| `condition` | Una comparación de Exylia que debe cumplirse, como `%server_tps% >= 18`. |
| `cooldown` | El tiempo mínimo entre dos disparos de esta entrada. |
| `requires` | Condiciones con nombre, listadas abajo. |

Un evento puede tener tantos horarios como quieras: tres horas entre semana y una el sábado son dos
entradas, una con tres horas y otra con una. Una repetición se ancla a la apertura de su ventana, no a
cuándo arrancó el servidor: cada dos horas desde las `10:00` dispara a las 10:00, 12:00 y 14:00 sea
cual sea la hora a la que se reinició.

## Cómo dispara

Cuando toca una entrada, se comprueba cada condición y el inicio se salta — no se reintenta más tarde
— si alguna falla:

- Ese evento ya está corriendo. Esto se comprueba siempre, diga lo que diga `requires`.
- Hay menos jugadores conectados que `min-players` o más que `max-players`.
- La `condition` no se cumple, o no ha pasado el `cooldown`.
- Una condición de `requires` no se cumple.

Un disparo que llega más de dos minutos tarde, tras un servidor congelado, también se salta. Los
saltos se escriben en el log de depuración de la consola en vez de quedar en silencio.

### Las condiciones que ofrece este plugin

| Condición | Se cumple cuando |
|---|---|
| `event-inactive` | El evento que arranca esta entrada no está corriendo. |
| `nothing-running` | No hay ningún evento de captura corriendo en el servidor. |

`nothing-running` es lo que la configuración sola no puede expresar: "arranca este, pero no mientras
haya otro evento en marcha". Un nombre que el plugin no ofrece nunca se cumple, así que una errata
impide que la entrada dispare en vez de ignorarse.

## Zona horaria

Todos los horarios se leen contra un mismo reloj:

```yaml title="config.yml"
scheduler:
  timezone: ""
```

Vacío — el valor por defecto — usa el ajuste `timezone` de ExyliaLib, que es donde una red lo fija una
sola vez para todos los plugins. Si no, acepta un identificador de zona como `America/New_York` o
`Europe/Madrid`, y sustituye a aquel solo para este plugin.

<Callout type="warning" title="Un identificador inválido cae al de ExyliaLib">
Un valor que no es un identificador IANA real — una abreviatura como `CET`, o una errata — se registra
como error al cargar, y se usa en su lugar la zona horaria de ExyliaLib. Revisa la consola después de
cambiarlo.
</Callout>

## Cuánto falta para el siguiente

El tiempo hasta el próximo disparo de un evento, entre todas sus entradas, es lo que alimenta:

- `%exyliacapture_<id>_time_until_start%` para un evento concreto.
- `%exyliacapture_next_event_time_until_start%` para el evento más próximo de todo el servidor.
- El estado `SCHEDULED` que muestra un holograma cuando el evento no corre pero tiene horario.

Un evento sin horarios no responde nada en vez de cero, y así un holograma distingue "no está
corriendo, pero viene" de "no está corriendo y ya está".

## Lanzar a mano

El horario no es obligatorio. `/captureadmin start <id>` lanza el evento al momento, y respeta la
misma regla de no iniciar uno que ya está corriendo.
