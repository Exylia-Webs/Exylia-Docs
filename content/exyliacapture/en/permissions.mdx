Players can use ExyliaCapture without any setup. Everyone can open the event list and both leaderboards, and only operators get `/captureadmin`. Use this page to change that.

## All permissions

<Permissions />

There is no permission per event: anyone standing in a running event's zone takes part.

## Give staff the admin panel

```text
/lp group admin permission set exyliacapture.admin true
```

<Callout type="warning" title="One node covers everything">
`exyliacapture.admin` also lets someone create, edit and delete event configurations, not only start and stop them. Give it to administration, not to moderation.
</Callout>

## Make a feature a rank perk

Everyone holds the three player permissions by default. To make one a perk, deny it to the default group and grant it to the rank:

```text
/lp group default permission set exyliacapture.leaderboard.clan false
/lp group vip permission set exyliacapture.leaderboard.clan true
```

A player who clicks a feature their rank lacks sees "Your rank does not include this." You can change that text in the `events.no-permission` line of `messages.yml`; see [Messages and languages](/docs/exylialib/messages-and-languages).
