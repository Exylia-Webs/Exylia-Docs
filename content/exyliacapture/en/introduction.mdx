ExyliaCapture adds zone-capture events to your server: King of the Hill, Conquest, Payload and more. You build each event from an in-game menu, give it a zone and a reward, and start it by hand or on a schedule.

It is not one configurable KOTH. It ships **eight event types**, each with its own rules, and a server can run as many configured events as it likes, of different types, at the same time. You never edit a file to create an event: `/captureadmin` opens a panel where you create it, mark its zone with a selection wand, set rewards and schedule it. Events are saved in the database, not in a file.

## What you need

| Requirement | Detail |
|---|---|
| Server | Paper 1.21.1 or newer, or Folia 1.21.4 or newer (the minimums of ExyliaLib; ExyliaCapture declares API 1.21 and supports Folia). |
| Java | 21 |
| Required plugin | `ExyliaLib` |
| Optional | `packetevents`, `PlaceholderAPI`, `ViaVersion`, a clan plugin, Apollo, Feather or SurvivalCore, `ExyliaStaff` |

A clan plugin is only required for Conquest and for clan mode. ExyliaLib brings the menus, database, zone wand, holograms, boss bars, scoreboards and rewards; without it ExyliaCapture does not start. Details are in [Install ExyliaCapture](/docs/exyliacapture/installation).

## What you will have in ten minutes

<Steps>
  <Step title="Install">
    Drop two jars in `plugins/` and start the server. See [Install ExyliaCapture](/docs/exyliacapture/installation).
  </Step>
  <Step title="Create a King of the Hill">
    Run `/captureadmin`, create an event, mark its zone and add a reward. See [Your first event](/docs/exyliacapture/first-steps).
  </Step>
  <Step title="Capture it yourself">
    Run `/captureadmin start <id>`, stand in the zone and win your own reward.
  </Step>
</Steps>

After that, [schedule it](/docs/exyliacapture/scheduling) so it starts without you.

## The event types

<Cards>
  <Card title="KOTH" href="/docs/exyliacapture/event-types#koth">
    Hold the zone until the capture timer runs out. Can end the event or reset and run forever.
  </Card>
  <Card title="KOTH Points" href="/docs/exyliacapture/event-types#koth-points">
    Points every second while inside. Exclusive gives them to one holder; multi gives them to everyone in the zone.
  </Card>
  <Card title="KOTH Capture Points" href="/docs/exyliacapture/event-types#koth-capture-points">
    Each completed capture is worth one point and frees the zone again. First to the target wins.
  </Card>
  <Card title="Conquest" href="/docs/exyliacapture/event-types#conquest">
    Several zones at once, each worth its own points, disputed by clans. Needs a clan plugin.
  </Card>
  <Card title="Payload" href="/docs/exyliacapture/event-types#payload">
    Escort a minecart along a rail path. It advances, stalls when disputed and rolls back when left.
  </Card>
  <Card title="Destroy The Core" href="/docs/exyliacapture/event-types#destroy-the-core">
    Break a core block for points. It regenerates on a timer and the race is to the target.
  </Card>
  <Card title="Bounty" href="/docs/exyliacapture/event-types#bounty">
    No zone: one player is the target. Whoever kills them wins; if they survive the clock, they do.
  </Card>
</Cards>

That makes eight types, because KOTH Points comes in an exclusive and a multi variant.

<Details title="Type identifiers and where everything is stored">
The eight identifiers are `koth`, `koth_points_exclusive`, `koth_points_multi`, `koth_capture_points`, `conquest`, `payload`, `dtc` and `bounty`.

| Thing | Where |
|---|---|
| Event configurations, zones, settings, rewards, schedules | Database (`capture_event_configs`) |
| Player and clan statistics | Database, global and per event |
| Rewards owed to an offline player | Database (`capture_pending_rewards`) |
| Language, particles, hologram look, leaderboard look, Discord webhook | `config.yml` |
| Sidebars | `lang/<code>/scoreboards.yml` |
| Every message, boss bar and hologram line | `lang/<code>/messages.yml` |
| Menu layouts | `lang/<code>/menus/` |
</Details>
