For problems that stop something working, start with [Common problems](/docs/exyliacapture/troubleshooting). These are the quick answers.

## Events

### Which event types are there?
KOTH, KOTH Points, KOTH Capture Points, Conquest, Payload, Destroy The Core and Bounty. See [Event types](/docs/exyliacapture/event-types).

### Can several events run at the same time?
Yes. Each event configuration runs once at a time, but different ones can run together. With more than one running, the sidebar switches to a shared layout that shows up to four of them.

### Does the KOTH timer reset when someone else walks in?
No. The holder is whoever entered the empty zone first, and progress resets only when that holder leaves. To take the hill you have to push the holder out.

### How do I start an event on a schedule?
Add a schedule to the event in `/captureadmin`. Times are read in ExyliaLib's timezone unless you set one for this plugin. See [Schedule events](/docs/exyliacapture/scheduling).

### The chat is flooded during Destroy The Core
Raise `broadcast-every` in that event's type settings. It only changes how often breaks are announced; every break still counts. See [Event types](/docs/exyliacapture/event-types#destroy-the-core).

## Clans and rewards

### Do I need a clan plugin?
Only for Conquest, which is always played by clans. Every other type scores per player unless you turn on **Clan mode**, and without a detected clan plugin it falls back to individual scoring. See [Clans](/docs/exyliacapture/clans).

### Which clan plugins work?
Those ExyliaLib detects at startup: FactionsUUID, HuskTowns, ZelTeams, RunithClans, UltimateClans, Kingdoms and KingdomsX, SimpleClans and ExyliaClans. The console names the one it picked. ZentriTeams is listed as an optional dependency but ExyliaLib has no clan provider for it, so do not count on it for clan mode.

### What happens to the reward of a player who is offline?
It is saved and handed over the next time they join. Items that did not fit in a full inventory wait there too. See [Rewards](/docs/exyliacapture/rewards#offline-winners-and-full-inventories).

## Stats and display

### Why does the leaderboard not update right after a win?
The top is a snapshot refreshed every 60 seconds. Wait a minute or reopen the menu. See [Statistics](/docs/exyliacapture/stats).

### Can I use ExyliaCapture without PlaceholderAPI?
Yes. PlaceholderAPI is optional and only needed if you show Capture values in other plugins. See [Placeholders](/docs/exyliacapture/placeholders).

### Why does a placeholder show as text?
A name the plugin does not know is left as written, which makes typos visible. Placeholders of an event created after the last reload need `/captureadmin reload` first.

### Can I send event results to Discord?
Yes, with a webhook. See [Discord webhooks](/docs/exyliacapture/webhooks).

## Server

### Does it work on Folia?
Yes. The plugin declares Folia support and runs its work through ExyliaLib's scheduler.

### Can servers share their event configurations?
Yes, through the `events-scope` key of `config.yml`. See [Configuration](/docs/exyliacapture/configuration#events-scope).

### Where do I get support?
On the [Exylia Discord](https://discord.exylia.net). Licences are handled there too.
