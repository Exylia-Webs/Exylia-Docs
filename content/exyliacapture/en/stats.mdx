By the end of this page players can open a player and a clan leaderboard, you decide how many rows it shows and how much a win is worth, and you can print the numbers on any scoreboard or hologram.

## Before you start

Statistics are saved by the plugin on their own; there is nothing to enable. Players need `exyliacapture.leaderboard` for `/capture top` and `exyliacapture.leaderboard.clan` for `/capture clantop`; both are on for everyone by default. See [Permissions](/docs/exyliacapture/permissions).

## Steps

<Steps>
  <Step title="Open the leaderboards">
    Run `/capture top` for players or `/capture clantop` for clans. You can also run `/capture` and use the tab bar at the bottom to switch between events, players and clans.
  </Step>
  <Step title="Filter by event">
    Click **Filter ▸ By event** and pick one event to rank only its own results. Click **Filter ▸ Global** to go back to all events combined.
  </Step>
  <Step title="Change what a win is worth">
    Run `/captureadmin`, click **Configurations**, click the event, then **Leaderboard points**. Left-click adds 1, right-click removes 1, shift-click lets you type a number. The default is 1 point per win.
  </Step>
  <Step title="Change the size and look">
    Run `/captureadmin`, click **Settings**, then **Leaderboard**. **Rows** sets how many positions are listed (default 50) and **Player heads** switches between each player's head and a plain block.
  </Step>
</Steps>

## Check that it works

Win an event, wait up to a minute, then run `/capture top`. Your name is in the list with your points, wins and captures. The top is cached and refreshed every 60 seconds (and once at startup), so a win is not shown instantly.

## Going further

### How the ranking is sorted

Leaderboards rank by **leaderboard points**, not by wins or points earned. That value belongs to each event: it is 1 per win by default, so an event that should matter more can give 3 or 5 without touching the others.

### What is counted

Statistics are kept in four places at once: per player globally, per player per event, per clan globally and per clan per event.

| Counter | Player | Clan | When it moves |
|---|---|---|---|
| Wins | Yes | Yes | On winning an event |
| Leaderboard points | Yes | Yes | On winning, by the event's leaderboard points |
| Captures | Yes | Yes | On each capture, core break or payload win |
| Points earned | Yes | Yes | As points are scored during an event |
| Time captured | Yes | No | While holding a zone |

<Details title="What each event type records">
| Type | Records |
|---|---|
| KOTH | Capture and capture time on each capture; win and leaderboard points on the win |
| KOTH Points (exclusive and multi) | Points earned and one second of capture time per scoring second |
| KOTH Capture Points | Capture, one point and the capture time per completed capture |
| Conquest | Capture and the zone's points on each zone capture |
| Payload | Win and capture on delivery |
| Destroy The Core | Capture and the break's points on each break |
</Details>

## Leaderboard appearance

Rows and player heads are in **Settings ▸ Leaderboard** in game. The materials are only in `config.yml`:

```yaml title="plugins/ExyliaCapture/config.yml"
leaderboard:
  top-limit: 50
  use-player-heads: true
  rank-materials:
    first: GOLD_BLOCK
    second: IRON_BLOCK
    third: COPPER_BLOCK
    default-player: PLAYER_HEAD
    default-clan: SHIELD
  filter-materials:
    active: LIME_CONCRETE
    inactive: RED_CONCRETE
```

<Details title="Leaderboard keys">
| Key | Default | What it does |
|---|---|---|
| `top-limit` | `50` | How many rows a leaderboard holds, from 1 to 500. |
| `use-player-heads` | `true` | Draw each row as that player's head. Heads are fetched once and cached. |
| `rank-materials` | see above | The items the top three rows and the rest are drawn with. |
| `filter-materials` | see above | The chosen and unchosen event filters. |

The top is served from a memory snapshot so a scoreboard that reads `%exyliacapture_top_...%` every refresh never queries the database per line.
</Details>
