By the end of this page you know which ExyliaCapture event type fits your server, how to create it, and where each of its settings lives in the menu. The type is chosen when the event is created and cannot be changed afterwards. To switch, create a new event.

## Before you start

ExyliaCapture and [ExyliaLib](/docs/exylialib/introduction) are installed, and you have the `exyliacapture.admin` permission. If you have never made an event, do [Your first event](/docs/exyliacapture/first-steps) first. It takes five minutes.

## Steps

<Steps>
  <Step title="Pick the type that fits">
    | You want | Use |
    |---|---|
    | One zone, first to hold it wins | [KOTH](#koth) |
    | One zone, points that build up while you stand in it | [KOTH Points](#koth-points) |
    | One zone, several captures in a row | [KOTH Capture Points](#koth-capture-points) |
    | Several zones fought over by clans | [Conquest](#conquest) |
    | A minecart pushed along rails | [Payload](#payload) |
    | A block everyone breaks again and again | [Destroy The Core](#destroy-the-core) |
    | One player hunted by everyone else | [Bounty](#bounty) |
  </Step>
  <Step title="Create the event">
    Run `/captureadmin`, click **Configurations**, then **Create**. Type an id in the chat (no spaces, it cannot change later), then click the type in the **Select event type** screen.
  </Step>
  <Step title="Mark where it happens">
    Every type except Bounty needs a zone, a route or a block. See [Zones](/docs/exyliacapture/zones).
  </Step>
  <Step title="Tune the type">
    In the event's setup screen, click **Type settings**. The screen that opens depends on the type, and each section below lists its buttons. **Back** returns to the setup screen.
  </Step>
  <Step title="Enable it">
    In the setup screen click the status button until it reads **ENABLED**. A disabled event cannot start, by hand or by [schedule](/docs/exyliacapture/scheduling).
  </Step>
</Steps>

## Settings every type has

These sit directly on the event's setup screen, not under **Type settings**.

- **Max duration**: how long the event may run. Click it and type `10m`, `1h30m` or `2h`. Middle-click it to toggle infinite. Default is 10 minutes for every type except KOTH, which has no limit.
- **Leaderboard points**: what a win adds to the ranking. Left-click adds 1, right-click removes 1, shift-click types a number. Default is 1.
- **Scoreboard** and **Bossbar**: click to turn the sidebar or the boss bar off for this event. Both are on by default.
- **Event color**: used for the waypoints and visuals of the event.

## KOTH

One zone, one timer. The first player to enter an empty zone becomes the holder and the timer starts. It keeps running while they stay inside, and it resets only when **they** leave. Then any player still inside takes over with a fresh timer.

Open **Type settings** and use:

- **Capture time**: how long the zone must be held. Default 30 seconds.
- **Infinite mode**: after a capture the zone resets and the event keeps running. Use it for a KOTH that is always available. Off by default.
- **Glow effect**: the holder glows near the end of a capture. Off by default.
- **Glow threshold**: how long before the end the glow starts. Default 10 seconds.

<Callout type="note" title="Others entering does not stop the timer">
Holding is not exclusive. A second player walking in neither takes the zone nor resets the progress. Fighting them off matters only because the holder losing the zone means leaving it.
</Callout>

With infinite mode on, each capture announces the winner, pays the winner reward, records the win and resets the zone.

## KOTH Points

Players earn points every second they are in the zone, and the first to the target wins. The type menu lists it twice:

- **KOTH Points (Multi)**: everyone inside the zone scores at the same time.
- **KOTH Points (Exclusive)**: only the holding group scores. The holder is the first group in the zone and keeps it while any of it remains inside. When it is gone, the next group takes over.

**Type settings** has **Target points** (default 100, left-click +10, right-click -10, shift-click to type), **Points per second** (default 1) and **Clan mode**. In clan mode the score goes to clans, and every member of the holding clan scores together. A player with no clan is skipped, and without a clan plugin the mode falls back to individual scoring.

## KOTH Capture Points

A capture is worth one point, then the zone frees up again and the next capture starts. The first to the target wins.

**Type settings** has **Capture time** (default 30 seconds per point), **Target points** (default 5), **Clan mode**, **Glow effect** and **Glow threshold**. Holding works like [KOTH](#koth). In clan mode the capture survives one member leaving as long as another member of the same clan is still inside.

## Conquest

Several zones in one event, held by clans. It is the only type with more than one zone and the only one that needs a clan plugin.

1. Open **Type settings** and set **Target points** (default 10), the score a clan needs to win.
2. Click **Manage zones**, then **Add zone**, and mark each area. See [Zones](/docs/exyliacapture/zones#conquest-zones).
3. Click a zone to set its **Rename**, **Color**, **Points per capture** (default 1) and **Capture time** (default 30 seconds).

A zone is held by a clan tag: the first clan member inside claims it, and it survives members leaving while another member of that clan remains. Points add up per clan across every zone.

<Callout type="warning" title="No clan plugin, no capture">
Conquest reads the capturer's clan. With no clan plugin detected, a zone never registers a capturer and the event cannot progress. Players without a clan are ignored the same way.
</Callout>

## Payload

A minecart travels a rail path from a start point to an end point. Players near the cart push it forward, and it rolls back when pushed by the other side or abandoned.

In **Type settings** click **Spawn location** and **End location** and mark both rails (see [Zones](/docs/exyliacapture/zones#payload-rails)). Then adjust:

- **Capture radius**: how close a player must be to push. Default 5 blocks.
- **Minecart type**: click to cycle the cart. Default is the TNT minecart.
- **Clan mode**: group pushers by clan.
- **Capture speed**: blocks per second forward. Default 0.5.
- **Recapture speed**: blocks per second backwards when the other side pushes. Default 1.5.
- **Return speed**: blocks per second backwards when nobody is near. Default 0.3.

Reaching the end wins. Rolling all the way back to the start clears the capturing side and the cart becomes idle again.

<Details title="The five cart states">

| State | When | What the cart does |
|---|---|---|
| `IDLE` | Nobody in range, and no progress made | Stands still |
| `CAPTURING` | One group in range | Moves forward at the capture speed |
| `DISPUTED` | Two or more groups in range | Stops |
| `RECAPTURING` | Only the other side is in range | Moves back at the recapture speed |
| `RETURNING` | Nobody in range after progress was made | Rolls back at the return speed |

Cart types: `MINECART`, `CHEST_MINECART`, `FURNACE_MINECART`, `TNT_MINECART`, `HOPPER_MINECART`.
</Details>

## Destroy The Core

One block, broken over and over. It comes back after a short wait, and every break scores.

In **Type settings**:

- **Core block**: click, then click the block in the world.
- **Target points**: default 50 (left-click +5, right-click -5).
- **Points per break**: default 1.
- **Regen time**: how long the block takes to come back. Default 5 seconds.
- **Broadcast every**: announce only every Nth break. Default 1. On a busy core, 5 or 10 keeps the chat readable and does not change the score.
- **Clan mode**: the points go to the breaker's clan. A player with no clan scores nothing.

### Make the core change block

Click **Core blocks** to give the core a list of blocks to roll from. **Add block** asks you to pick one, and it starts with weight 10. Left-click a block to add 1 to its weight, right-click to remove 1, shift-left-click to type an exact weight, shift-right-click to remove it. Each row shows its chance.

- With the list empty the core keeps the block you placed.
- With blocks listed, a block is rolled by weight when the event starts.
- **Rotate on regen** rolls again every time the core heals.
- **Idle block** is what the core rests as between events, for example bedrock. Hold the block and left-click to set it, right-click to clear it. It only applies when **Core blocks** has at least one entry.

## Bounty

No zone at all: one player is the target and everyone else hunts them. It needs nothing configured, and the zone button on its setup screen opens its settings instead.

When it starts, a random online player who counts as playing becomes the target, and the whole server is told who and what the reward is. **Type settings** has:

- **Extra hearts**: absorption hearts the target starts with. Default 2, `0` gives none.
- **Resistance**: resistance level the target is given. Default 1, `0` gives none.
- **Glowing target**: the target glows through walls. On by default.
- **Live marker**: hunters on Lunar with Apollo or Feather get a waypoint that follows the target. On by default.
- **Reveal every**: how often the target's coordinates are announced. Default 60 seconds, `0` never.
- **Replace on quit**: a target who logs out is replaced instead of ending the hunt. On by default.

How it ends:

- **A hunter kills the target.** That hunter wins and is paid the winner reward.
- **The clock runs out with the target alive.** The target wins and is paid the winner reward.
- **The target quits, or dies to nobody** (lava, a fall, a mob, their own hand, or staff on duty). With **Replace on quit** on another player becomes the target. With it off the event ends with no winner.

If nobody can be picked when it starts, the event says so and ends at once.

## Check that it works

Start the event with `/captureadmin start <id>` and play it from a survival account. KOTH types show a boss bar that fills. Payload shows a moving cart, Destroy The Core shows the block breaking and coming back, and Bounty announces the target. `/captureadmin list` shows what is running and lets you stop it.
