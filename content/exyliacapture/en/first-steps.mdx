By the end of this page you have a King of the Hill (KOTH) event on your server and you have captured it yourself. Everything happens in game; you do not edit any file.

## Before you start

ExyliaCapture and ExyliaLib are installed and the server has started once. See [Install ExyliaCapture](/docs/exyliacapture/installation). You need the `exyliacapture.admin` permission (operators have it).

## Steps

<Steps>
  <Step title="Open the panel and create an event">
    Run `/captureadmin`, click **Configurations**, then **Create**. Type an id in the chat, for example `hill`. It has no spaces, it cannot be changed later, and it is what `/captureadmin start hill` takes.
  </Step>
  <Step title="Pick KOTH">
    Click **KOTH**. It is the simplest type: players stand in a zone until the timer fills. The other types are in [Event types](/docs/exyliacapture/event-types).
  </Step>
  <Step title="Mark the zone">
    In the setup screen click **Capture zone**. Stand where you want one corner, left-click; go to the opposite corner, right-click. The zone is a box, so choose both corners at different heights if you want it tall. See [Zones](/docs/exyliacapture/zones).
  </Step>
  <Step title="Add a reward">
    Click **Commands**, then **Winner reward**, and add what the winner gets. See [Rewards and commands](/docs/exyliacapture/rewards).
  </Step>
  <Step title="Enable it">
    Click the **DISABLED** button so it reads **ENABLED**. If the chat says the event is not configured well enough, the zone is missing. A disabled event cannot start, by hand or by schedule.
  </Step>
  <Step title="Start it">
    Run `/captureadmin start hill`. The server announces the event.
  </Step>
</Steps>

## Check that it works

Switch to survival mode and walk into the zone. Creative and spectator players do not count, and neither do dead players or staff on duty with ExyliaStaff. Stand still for 30 seconds, which is the default capture time. You should see the boss bar at the top fill, then the win announcement, and the reward arrives. The event ends on the first capture.

To see it from the other side, run `/capture` for the list of events and `/captureadmin list` to open the running events menu.

<Callout type="tip" title="Nothing happens when you stand in the zone?">
Check your game mode first. Then see [Common problems](/docs/exyliacapture/troubleshooting).
</Callout>

## Going further

- Make it run on its own every day: [Schedule events](/docs/exyliacapture/scheduling).
- Change how long a capture takes, or let it run until a timer ends: open the event, then **Type settings**, then **Capture time** or **Infinite mode**.
- Show a countdown on a hologram or scoreboard: [Placeholders](/docs/exyliacapture/placeholders).
