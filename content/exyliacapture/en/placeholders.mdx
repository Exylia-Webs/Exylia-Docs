Use these to show live ExyliaCapture data in other plugins that support PlaceholderAPI, such as holograms, tab lists and chat. Click a placeholder to copy it.

<Placeholders />

## Per event: replace `<id>`

`<id>` is the id you gave the event when you created it, for example `hill`. `%exyliacapture_hill_status%` answers for that event only. A new event answers after you run `/captureadmin reload`.

Anything with no value shows an em dash (`—`) instead of an empty space. An event that is not running has no leader, podium or capturer.

## The next event

`%exyliacapture_next_event_<stat>%` takes any per-event stat and answers it for the event that starts soonest. The usual one is `%exyliacapture_next_event_time_until_start%` for a "Next event in" line, with `%exyliacapture_next_event_display_name%` beside it.

## Leaderboards

Replace `<position>` with `1`, `2`, `3` and so on.

```text
%exyliacapture_top_player_1_name%
%exyliacapture_top_player_1_leaderboard_points%
%exyliacapture_top_clan_3_wins%
```

A position past the end of the list shows an em dash for `name` and `0` for the numbers. Leaderboard rows come from a snapshot refreshed every 60 seconds, so a win can take up to a minute to show.

<Callout type="note" title="These are not the sidebar tokens">
The `%capture_...%` tokens in `scoreboards.yml` and the `%event_...%` tokens in hologram lines only work inside ExyliaCapture's own screens. See [On-screen visuals](/docs/exyliacapture/visuals).
</Callout>
