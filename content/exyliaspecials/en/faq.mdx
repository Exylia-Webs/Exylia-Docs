## Is ExyliaSpecials free?

No. It is a premium plugin, bought on [BuiltByBit](https://builtbybit.com/resources/exyliaspecials.49406/) and
installed as a loader jar that checks the licence on every start. See
[Installation](/docs/exyliaspecials/installation).

## The plugin does not start

`packetevents` is a hard dependency: without it the server never loads the plugin. ExyliaLib 1.299.1 or newer is
needed too; the loader installs it, or stages a newer one, and asks for a restart. If the console reports a licence
error, check that `Exylia-Specials-Loader.jar` is the jar from your purchase.

## I updated from 3.x and my items stopped working

Version 4 is a rewrite: items handed out by 3.x are plain items now, and the old configuration is not read. Start
from a clean folder and give the items again. See [Installation](/docs/exyliaspecials/installation#coming-from-3x).

## Where are the item files?

In `plugins/ExyliaSpecials/lang/<language>/items/` — `lang/en/items/` in English. Change `language` and another
folder is read. See [Installation](/docs/exyliaspecials/installation#languages).

## I deleted an item's file and it came back

Bundled files that are missing are written again on every start and reload. To take an item out of play, give it a
`permission:` nobody has.

## I changed an item's uses but players' items did not change

The number of uses is written on each copy when it is given. Every other change — numbers, lore, features,
cooldowns — reaches existing copies on their next use; a new `uses` applies to copies given from then on.

## My ability says nothing and does nothing on a hit

Hit triggers are silent: a cooldown, a region rule, PvP being off where either player stands, or a combo that is not
complete yet all fail quietly. Try the same item on a right-click to see the message. See
[How a use is checked](/docs/exyliaspecials/items#how-a-use-is-checked).

## My damage ability does not hurt mobs

`damage`, `target_radius` and `target_chain` take players only unless you write `only-players: false` on each. See
[Action language](/docs/exyliaspecials/actions#damage).

## A HELD ability ignores its cooldown

Abilities on `HELD` never start their cooldown or spend uses: they run every second while held. Use a state or a
`stack` with a window if it must not fire that often. See
[Triggers](/docs/exyliaspecials/items#triggers).

## %targets_found% shows up as text in my message

Step variables are not filled in `message` text or `play` effect lines. Use them in `require` checks, numbers and
potion lines instead. See [Action language](/docs/exyliaspecials/actions#numbers-and-variables).

## Compressor Mint and Compressor Vault do nothing

They ship without recipes, meant for your own currency items. Open the item in `/specialsadmin` and add recipes
with its editor. See [Tools](/docs/exyliaspecials/tools#in-game-editors).

## Can I use DeluxeCombat instead of the built-in combat tag?

Yes. With `combat.provider: AUTO` an installed DeluxeCombat, CelestCombat or PvPManager is used automatically. Logout
NPCs, the barrier and the restrictions are then that plugin's business. See
[Combat](/docs/exyliaspecials/combat#choosing-a-provider).

## The elytra firework cooldown applies inside my arena too

The default `__global__` region rule on `FIREWORK_ROCKET` never matches. Set the material's `cooldown` itself, or add
rules for your real regions. See [Cooldowns](/docs/exyliaspecials/cooldowns#the-defaults).

## The 1v1 item says there is no arena

At least one arena must be enabled with both spawns set. See [Duels](/docs/exyliaspecials/duels#building-an-arena).

## Can only one duel run per arena?

Without a snapshot, yes. Take one with `/specialsadmin arena snapshot` and install FastAsyncWorldEdit: each duel then
gets its own copy, up to 16 per arena. See [Duels](/docs/exyliaspecials/duels#copies-and-snapshots).

## /msg is blocked during a duel even though it is allowed

`duels.allowed-commands` takes names without the slash: write `msg`, not `/msg`.
