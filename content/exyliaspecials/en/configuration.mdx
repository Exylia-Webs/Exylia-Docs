Everything is generated in `plugins/ExyliaSpecials/` on first start, with comments. Edit the files there and run
`/specialsadmin reload`.

| File | What it holds |
|---|---|
| `config.yml` | Language, combat, action bar, states, duels, vanilla cooldowns. Below. |
| `lang/<language>/messages.yml` | Every line the plugin sends. |
| `lang/<language>/items/*.yml` | The items. See [Special items](/docs/exyliaspecials/items). |
| `lang/<language>/trackers/*.yml` | The trackers. See [Stat trackers](/docs/exyliaspecials/trackers). |
| `lang/<language>/menus/admin/*.yml` | The admin screens, rewritten from the jar on every start and reload. |
| `arenas.yml` | The duel arenas. See [Duels](/docs/exyliaspecials/duels). |
| `database.yml` | ExyliaLib's database connection. |

## config.yml

```yaml
language: default

combat:
  provider: AUTO
  duration: 15s
  logout-punishment: KILL
  punish-on-kick: false
  untag-on-kill: true
  disable-flight: true
  disable-elytra: true
  blacklisted-worlds: []
  blocked-inventories: [ENDER_CHEST]
  blocked-teleport-causes: [COMMAND]
  allowed-commands: [/msg, /tell, /w, /r, /reply, /discord]
  commands-on-logout: []
  commands-on-player-death: []
  notifications:
    on-tag: true
    on-untag: true
    on-region-blocked: true
    on-command-blocked: true
    on-flight-blocked: true
    on-elytra-blocked: true
    on-inventory-blocked: true
  logout-npc:
    enabled: true
    reset-combat-timer: true
    only-player-damage: true
    commands-on-npc-death: []
    blacklisted-worlds: []
  barrier:
    enabled: true
    material: RED_STAINED_GLASS
    height: 6
    preview-distance: 10
    update-interval-ticks: 3
    air-only: true
    push-back: {enabled: true, trigger-distance: 2.5, strength: 0.55, cooldown-ticks: 2}
    particles: {enabled: true, color: FF2222, size: 1.2, density: 20, interval-ticks: 6}

actionbar:
  enabled: true
  update-ticks: 2

states:
  clear-on-death: true
  flight-landing-grace: 4s
  reveal-on-attack: true
  undying-effects:
    - '[PARTICLE] TOTEM_OF_UNDYING;count:60;offset:0.6,1,0.6;speed:0.4;y:1'
    - '[RING_PULSE] END_ROD;radius:1.6;rings:2;spacing:0.4;points:18;y:0.1;ticks:4;interval:0.04'
    - '[SOUND] BLOCK_BEACON_POWER_SELECT;0.8;1.6'

duels:
  allowed-commands: [msg, tell, w, r, reply]
  broadcast-results: true
  copies:
    enabled: true
    max-per-arena: 16

vanilla-cooldowns:
  ENDER_PEARL:
    trigger: LAUNCH
    cooldown: 4.0
    combat-cooldown: 14.0
    display-name: '{primary}Ender Pearl'
    regions: {...}
  # ENCHANTED_GOLDEN_APPLE, TOTEM_OF_UNDYING, GOLDEN_APPLE, FIREWORK_ROCKET
```

### language

| Value | |
|---|---|
| `default` | Follows the language in ExyliaLib's `config.yml`. |
| `en`, `es`, `fr`, `pt`, `ru` | This plugin only. |
| anything else | A language of your own, started as a copy of English. |

The language also picks the folder items and trackers are read from — see
[Installation](/docs/exyliaspecials/installation#languages).

### combat

| Key | Default | |
|---|---|---|
| `provider` | `AUTO` | `AUTO`, `BUILTIN`, `MANUAL`, `DELUXECOMBAT`, `CELESTCOMBAT` or `PVPMANAGER`. |
| `duration` | `15s` | How long a tag lasts. |
| `logout-punishment` | `KILL` | `KILL` or `NOTHING`. |
| `punish-on-kick` | `false` | |
| `untag-on-kill` | `true` | |
| `disable-flight` | `true` | |
| `disable-elytra` | `true` | |
| `blacklisted-worlds` | `[]` | Nobody is tagged there. |
| `blocked-inventories` | `[ENDER_CHEST]` | Inventory types. |
| `blocked-teleport-causes` | `[COMMAND]` | Teleport causes. |
| `allowed-commands` | `/msg`, `/tell`, `/w`, `/r`, `/reply`, `/discord` | |
| `commands-on-logout` | `[]` | |
| `commands-on-player-death` | `[]` | |
| `notifications.*` | all `true` | Which refusals send a message. |
| `logout-npc.*` | | See [Logout NPCs](/docs/exyliaspecials/combat#logout-npcs). |
| `barrier.*` | | See [The barrier](/docs/exyliaspecials/combat#the-barrier). |

Everything except `provider` applies to the built-in tag only. Full behaviour on
[Combat](/docs/exyliaspecials/combat).

## messages.yml

`lang/<language>/messages.yml` holds every line, grouped:

| Section | |
|---|---|
| `prefix` | `%prefix%` in every other line. |
| `combat` | Tagging, refusals, the logout NPC's name and tag line. |
| `actionbar` | The action bar's layout. |
| `items` | Refusals when using an item, used up, expired, and the `ON`/`OFF` of `%status%`. |
| `tools` | Crowbar, compressor, filter and prospector replies. |
| `stattrack` | Applying trackers, and the empty victim slot. |
| `delivery` | Items received, or waiting for the next join. |
| `states` | The bar of each state, the last stand celebration, flight ending, vanish broken. |
| `duels` | Challenges, refusals, countdown, boss bars, results, broadcasts and every arena editor line. |
| `admin` | Replies of every command and editor. |

A line may start with `[sound:NAME|volume|pitch]` to play a sound. An empty line sends nothing. State bars and duel
titles are ExyliaLib effects: a title, action bar, boss bar, sound, particle and firework each.

## The admin menus

`lang/<language>/menus/admin/` has the eight screens: `root`, `items`, `tools`, `item`, `stattracks`,
`cooldowns`, `arenas` and `arena`. They are **rewritten from the jar on every start and every reload**: an edit
does not survive.
