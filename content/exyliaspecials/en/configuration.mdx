ExyliaSpecials writes all its files, with comments, to `plugins/ExyliaSpecials/` on first start. Edit them there and run `/specialsadmin reload`, or change `config.yml` and the messages in game from **Settings** in `/specialsadmin` (see [Commands](/docs/exyliaspecials/commands#the-admin-menu)).

| File | What it holds |
|---|---|
| `config.yml` | Language, action bar, states, duels. |
| `lang/<language>/messages.yml` | Every line the plugin sends. |
| `lang/<language>/items/*.yml` | The items. See [Special items](/docs/exyliaspecials/items). |
| `lang/<language>/trackers/*.yml` | The trackers. See [Stat trackers](/docs/exyliaspecials/trackers). |
| `lang/<language>/menus/admin/*.yml` | The `/specialsadmin` screens. Rewritten from the jar on every start and reload. |
| `arenas.yml` | The duel arenas. See [Duels](/docs/exyliaspecials/duels). |
| `database.yml` | ExyliaLib's database connection. See [Database](/docs/exylialib/database). |

## config.yml

Four settings, and most servers change only the first:

- **Language** (`language`, default `default`): `default` follows the language in ExyliaLib's `config.yml`; `en`, `es`, `fr`, `pt`, `ru` or `tr` set it for this plugin only. Any other name starts a language of your own as a copy of English. The language also picks the folder items and trackers are read from, see [Installation](/docs/exyliaspecials/installation#languages).
- **Action bar** (`actionbar.enabled`, default `true`): the cooldown readout above the hotbar. See [Cooldowns](/docs/exyliaspecials/cooldowns#the-action-bar).
- **States**: what happens to flight, vanish and last stand on death and on landing. See [States](/docs/exyliaspecials/states#settings).
- **Duels**: allowed commands, result broadcasts and arena copies. See [Duels](/docs/exyliaspecials/duels#settings).

<Details title="Every key and its default">

```yaml
language: default

actionbar:
  enabled: true

states:
  clear-on-death: true
  flight-landing-grace: 4s
  reveal-on-attack: true
  undying-effects:
    - '[PARTICLE] TOTEM_OF_UNDYING;count:60;offset:0.6,1,0.6;speed:0.4;y:1'
    - '[RING_PULSE] END_ROD;radius:1.6;rings:2;spacing:0.4;points:18;y:0.1;ticks:4;interval:0.04'
    - '[SOUND] BLOCK_BEACON_POWER_SELECT;0.8;1.6'

duels:
  allowed-commands: [msg, tell, w, r, reply]
  broadcast-results: true
  copies:
    enabled: true
    max-per-arena: 16
```

`flight-landing-grace` is 0 to 60 seconds, `copies.max-per-arena` 1 to 64. `undying-effects` are sequence lines like an item's `play` step. `allowed-commands` takes names without the slash.

Older versions also had `combat` and `vanilla-cooldowns` here. They moved to ExyliaCombat; on the first start a copy goes to `exyliacombat-export.yml`. See [Combat](/docs/exyliaspecials/combat#moving-from-an-older-version).

</Details>

## messages.yml

`lang/<language>/messages.yml` holds every line the plugin sends. Colours and placeholders work as in the rest of Exylia: see [Colours](/docs/exylialib/colours) and [Messages and languages](/docs/exylialib/messages-and-languages). A line may start with `[sound:NAME|volume|pitch]` to play a sound, and an empty line sends nothing.

<Details title="Sections of messages.yml">

| Section | |
|---|---|
| `prefix` | `%prefix%` in every other line. |
| `actionbar` | The action bar's layout. |
| `items` | Refusals when using an item, used up, expired, the `ON`/`OFF` of `%status%`, and the `limit-*` and `badge-*` lines of `%limit%` and `%limit_badge%`. |
| `tools` | Crowbar, compressor, filter and prospector replies. |
| `stattrack` | Applying trackers, and the empty victim slot. |
| `delivery` | Items received, or waiting for the next join. |
| `states` | The bar of each state, the last stand celebration, flight ending, vanish broken. |
| `duels` | Challenges, refusals, countdown, boss bars, results, broadcasts and every arena editor line. |
| `admin` | Replies of every command and editor. |

State bars and duel titles are ExyliaLib effects: a title, action bar, boss bar, sound and particle each. None ships a firework.

</Details>

## The admin menus

`lang/<language>/menus/admin/` has the `/specialsadmin` screens. They are **rewritten from the jar on every start and every reload**, so an edit does not survive. The other Exylia menus are editable; see [Edit menus](/docs/exylialib/edit-menus).

<Details title="Menu files">

`root`, `items`, `tools`, `item`, `stattracks`, `cooldowns`, `arenas`, `arena`, `settings`, `settings_states` and `settings_duels`.

</Details>
