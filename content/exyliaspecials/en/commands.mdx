One root, `/specialsadmin`, with no aliases. Players have no command: they use items. Every subcommand has its
own permission, all granted to operators by default — see [Permissions](/docs/exyliaspecials/permissions).

Subcommands that name a player run from the console; those marked **player only** do not. Suggestions follow
what is typed: item ids, tracker ids, arena ids and cooldown ids.

## Menu and reload

| Command | Permission | |
|---|---|---|
| `/specialsadmin` | `exyliaspecials.admin` | Player only. Opens the admin menu. |
| `/specialsadmin reload` | `exyliaspecials.admin` | Re-reads `config.yml`, messages, the combat provider, states, vanilla cooldowns, `arenas.yml`, items, trackers, the action bar and the menus. |

## Items

| Command | Permission |
|---|---|
| `/specialsadmin give item <id> [player] [amount] [limit] [value]` | `exyliaspecials.admin.give.item` |
| `/specialsadmin giveall item <id> [amount]` | `exyliaspecials.admin.giveall.item` |
| `/specialsadmin getall item [player]` | `exyliaspecials.admin.getall.item` |
| `/specialsadmin list item` | `exyliaspecials.admin.list.item` |

- `give` without a player gives to you; from the console a player is required.
- `amount` is 1 to 2304, split into stacks of the item's `max-stack-size`.
- `limit` overrides the item's: `INFINITE`, `USES` or `TIMED`. `value` is the uses, or the seconds for `TIMED`;
  without it the item's own amount is used.
- `giveall` gives every online player; `getall` one of every item.
- `list` shows each item's id, name and limit.

What does not fit waits for the player's next join.

## Stat trackers

| Command | Permission |
|---|---|
| `/specialsadmin give stattrack <tracker> [player] [amount]` | `exyliaspecials.admin.give.stattrack` |
| `/specialsadmin giveall stattrack <tracker> [amount]` | `exyliaspecials.admin.giveall.stattrack` |
| `/specialsadmin getall stattrack [player]` | `exyliaspecials.admin.getall.stattrack` |
| `/specialsadmin list stattrack` | `exyliaspecials.admin.list.stattrack` |
| `/specialsadmin stattrack remove <tracker\|all> [player]` | `exyliaspecials.admin.stattrack.manage` |
| `/specialsadmin stattrack reset <tracker\|all> [player]` | `exyliaspecials.admin.stattrack.manage` |

`give`, `giveall` and `getall` hand out appliers. `remove` and `reset` act on the item in the player's main
hand. See [Stat trackers](/docs/exyliaspecials/trackers#removing-and-resetting).

## Cooldowns

| Command | Permission |
|---|---|
| `/specialsadmin cooldown set <player> <id> <seconds>` | `exyliaspecials.admin.cooldown` |
| `/specialsadmin cooldown add <player> <id> <seconds>` | `exyliaspecials.admin.cooldown` |
| `/specialsadmin cooldown decrease <player> <id> <seconds>` | `exyliaspecials.admin.cooldown` |
| `/specialsadmin cooldown remove <player> [id]` | `exyliaspecials.admin.cooldown` |

`<id>` is a special item id, `vanilla:<material>` or `ALL`; seconds go up to 86400. An item with several
features has all its timers changed. See [Cooldowns](/docs/exyliaspecials/cooldowns#commands).

## The admin menu

`/specialsadmin` opens six buttons:

| Button | Opens |
|---|---|
| **Special items** | Every item without a tool feature. Left-click gives one; right-click opens the item. |
| **Tools** | Every item with a tool feature, the same way. |
| **Trackers** | Every tracker; a click gives you an applier. |
| **Duel arenas** | The arenas, and **New arena**. See [Duels](/docs/exyliaspecials/duels#arena-commands). |
| **Your cooldowns** | Your own running special item cooldowns; a click clears one, **Clear all** clears all, vanilla ones too. |
| **Reload** | The same as `/specialsadmin reload`. |

An item's screen shows its limit, cooldown, permission and features, and buttons to give one, a stack, an
unlimited copy, a copy with a number of uses (asked in chat) or a timed copy (a length asked in chat). Below them
are the **Settings** form and one editor per compressor or void filter.

<Callout type="warning" title="The menu checks one permission">
Everything inside the menu — giving items and appliers, editing arenas — only needs `exyliaspecials.admin`, the
node that opens it. `exyliaspecials.admin.give.item` and `exyliaspecials.admin.arena` gate the commands only.
Give `exyliaspecials.admin` only to staff trusted with all of it.
</Callout>
