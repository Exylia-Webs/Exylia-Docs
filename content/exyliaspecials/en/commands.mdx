One root, `/specialsadmin`, with no aliases. Players have no command: they use items. Every subcommand has its
own permission, all granted to operators by default — see [Permissions](/docs/exyliaspecials/permissions).

Subcommands that name a player run from the console; those marked **player only** do not. Suggestions follow
what is typed: item ids, tracker ids, arena ids and cooldown ids.

## Items

<Commands group="items" />

- `give` without a player gives to you; from the console a player is required.
- `amount` is 1 to 2304, split into stacks of the item's `max-stack-size`.
- `limit` overrides the item's: `INFINITE`, `USES` or `TIMED`. `value` is the uses, or the seconds for `TIMED`;
  without it the item's own amount is used.
- `giveall` gives every online player; `getall` one of every item.
- `list` opens the **Special items** screen (tools are on **Tools**) for a player with `exyliaspecials.admin`; from the console, or
  without it, it prints each item's id, name and limit.

What does not fit waits for the player's next join.

## Stat trackers

<Commands group="trackers" />

`list stattrack` opens the trackers screen for a player with `exyliaspecials.admin`, and prints the list
otherwise. `give`, `giveall` and `getall` hand out appliers. `remove` and `reset` act on the item in the player's main
hand. See [Stat trackers](/docs/exyliaspecials/trackers#removing-and-resetting).

## Cooldowns

<Commands group="cooldowns" />

`<id>` is a special item id, `vanilla:<material>` (a cooldown ExyliaCombat put on) or `ALL` (every special item); seconds go up to 86400. An item with several
features has all its timers changed. See [Cooldowns](/docs/exyliaspecials/cooldowns#commands).

## Arenas

<Commands group="arenas" />

`arena list` opens the arenas screen for a player with `exyliaspecials.admin`, and prints the list otherwise.
All need `exyliaspecials.admin.arena`. See [Duels](/docs/exyliaspecials/duels#arena-commands).

## The admin menu

`/specialsadmin` opens seven buttons:

| Button | Opens |
|---|---|
| **Special items** | Every item without a tool feature. Left-click gives one; right-click opens the item. |
| **Tools** | Every item with a tool feature, the same way. |
| **Trackers** | Every tracker; a click gives you an applier. |
| **Duel arenas** | The arenas, and **New arena**. See [Duels](/docs/exyliaspecials/duels#arena-commands). |
| **Your cooldowns** | Your own running special item cooldowns; a click clears one, **Clear all** clears all of them. |
| **Settings** | A hub of hand-written pages: **States** (landing grace, clear on death, reveal on attack, cooldown bar) and **Duels** (broadcast results, arena copies, copies per arena). Values are typed or toggled in game and saved to `config.yml`; everything else stays in the files. Back returns to this menu. |
| **Reload** | The same as `/specialsadmin reload`. |

An item's screen shows its limit, cooldown, permission and features, and buttons to give one, a stack, an
unlimited copy, a copy with a number of uses (asked in chat) or a timed copy (a length asked in chat). Below them
are the **Settings** form and one editor per compressor or void filter.

<Callout type="note" title="Buttons check the command's node">
`exyliaspecials.admin` opens the menu and grants every `exyliaspecials.admin.*` node. Each button checks the node of
the matching command (`exyliaspecials.admin.give.item`, `.give.stattrack`, `.cooldown`, `.arena`), so a player who
was given only some of those nodes can use only those buttons. The menu's actions (`exyliaspecials:admin_*`,
`exyliaspecials:settings`) check their node themselves, so a button in another menu that names one does nothing
for a player without it.
</Callout>
