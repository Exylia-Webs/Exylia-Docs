---
title: "Placeholders"
description: "Every %exyliaspecials_...% placeholder: combat, the held item, cooldowns, stat trackers and states."
---

Placeholders work through PlaceholderAPI as `%exyliaspecials_<name>%`, and in any Exylia plugin's text without it.
They are read for the viewing player; without one they are empty.

## Combat

| Placeholder | Value |
|---|---|
| `%exyliaspecials_in_combat%` | `true` or `false`. |
| `%exyliaspecials_combat_time%` | Time left on the tag, such as `12s`. |

Read from whichever combat plugin is installed (ExyliaCombat, DeluxeCombat or PvPManager); `false` without one.

## The held item

The item in the main hand.

| Placeholder | Value |
|---|---|
| `%exyliaspecials_item_id%` | Its id; empty when it is not a special item. |
| `%exyliaspecials_current_uses%` | Uses left; `∞` without a limit. |
| `%exyliaspecials_max_uses%` | Uses it started with; `∞` without a limit. |
| `%exyliaspecials_stattrack_<tracker>%` | That tracker's count on it, e.g. `%exyliaspecials_stattrack_kills_tracker%`; empty when it has none. |

## Cooldowns

| Placeholder | Value |
|---|---|
| `%exyliaspecials_cooldown_<id>%` | Time left. A special item id gives its longest timer; `vanilla:ender_pearl` a vanilla cooldown ExyliaCombat put on. |
| `%exyliaspecials_oncooldown_<id>%` | `true` or `false`. |

```text
%exyliaspecials_cooldown_freeze%
%exyliaspecials_oncooldown_vanilla:ender_pearl%
```

## States

| Placeholder | Value |
|---|---|
| `%exyliaspecials_state_<state>%` | `true` or `false`. |
| `%exyliaspecials_state_<state>_remaining%` | Time left; `∞` for a state without an end. |

`<state>` is one of `invulnerable`, `frozen`, `no_build`, `no_item_use`, `effect_immunity`, `unstoppable`,
`silenced`, `lifesteal`, `flight`, `no_fall_damage`, `vanished` and `undying`. See
[States](/docs/exyliaspecials/states). An unknown state returns nothing.

## Inside the plugin

Item names and lore have their own placeholders, such as `%uses%` and `%time_remaining%` — see
[Special items](/docs/exyliaspecials/items#lore-and-name-placeholders). Steps have variables such as
`%targets_found%` — see [Action language](/docs/exyliaspecials/actions#numbers-and-variables).
