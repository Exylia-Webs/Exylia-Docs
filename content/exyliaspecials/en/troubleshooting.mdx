Find your symptom, read the cause, apply the fix. For anything not here, check the console first: the plugin prints
`Loaded 70 special items` and `ExyliaSpecials enabled` when it starts cleanly.

## The plugin does not start

**Cause:** ExyliaLib 1.448.0 or newer is missing, or the licence check failed.

**Fix:** start the server once with `Exylia-Specials-Loader.jar`; the loader downloads ExyliaLib, or stages a newer
one, and asks for a restart. Without network access, put `ExyliaLib.jar` in `plugins/` by hand. If the console reports
a licence error, check that the jar is the one from your purchase. See
[Installation](/docs/exyliaspecials/installation).

## My item does nothing when I hit with it

**Cause:** hit triggers are silent. A cooldown, a region rule, PvP being off where either player stands, or a combo
that is not complete yet all fail without a message.

**Fix:** try the same item on a right-click to see the message. See
[How a use is checked](/docs/exyliaspecials/items#how-a-use-is-checked).

## My damage ability does not hurt mobs

**Cause:** `damage`, `target_radius` and `target_chain` take players only.

**Fix:** write `only-players: false` on each step. See [Action language](/docs/exyliaspecials/actions#damage).

## My ability on HELD ignores its cooldown

**Cause:** abilities on the `HELD` trigger run every second while held; they never start the cooldown or spend uses.

**Fix:** use a state, or a `stack` with a window, if it must not fire that often. See
[Triggers](/docs/exyliaspecials/items#triggers).

## %targets_found% shows up as text in my message

**Cause:** step variables are not filled in `message` text or `play` effect lines.

**Fix:** use them in `require` checks, numbers and potion lines instead. See
[Action language](/docs/exyliaspecials/actions#numbers-and-variables).

## I changed an item's uses but players' items did not change

**Cause:** the number of uses is written on each copy when it is given.

**Fix:** a new `uses` applies to copies given from then on. Every other change, such as numbers, lore, features and
cooldowns, reaches existing copies on their next use.

## I deleted an item's file and it came back

**Cause:** bundled files that are missing are written again on every start and reload.

**Fix:** to take an item out of play, give it a `permission:` nobody has. See
[Special items](/docs/exyliaspecials/items#permission).

## Compressor Mint and Compressor Vault do nothing

**Cause:** they ship without recipes, meant for your own currency items.

**Fix:** open the item in `/specialsadmin` and add recipes with its editor. See
[Tools](/docs/exyliaspecials/tools#in-game-editors).

## I updated from 3.x and my items stopped working

**Cause:** version 4 is a rewrite. Items handed out by 3.x are plain items now, and the old configuration is not read.

**Fix:** start from a clean `plugins/ExyliaSpecials/` folder and give the items again. See
[Installation](/docs/exyliaspecials/installation#coming-from-3x).

## The 1v1 item says there is no arena

**Cause:** no arena is enabled with both spawns set.

**Fix:** create one, set spawns 1 and 2 and enable it. See
[Duels](/docs/exyliaspecials/duels#building-an-arena).

## Only one duel runs per arena

**Cause:** without a snapshot, each duel is played in place, one at a time.

**Fix:** take one with `/specialsadmin arena snapshot <arena>` and install FastAsyncWorldEdit: each duel then gets
its own copy, up to 16 per arena. See [Duels](/docs/exyliaspecials/duels#copies-and-snapshots).

## /msg is blocked during a duel even though it is allowed

**Cause:** `duels.allowed-commands` takes names without the slash.

**Fix:** write `msg`, not `/msg`, then run `/specialsadmin reload`.

## The combat tag or the ender pearl cooldown is gone

**Cause:** they moved to ExyliaCombat. ExyliaSpecials only reads the tag of ExyliaCombat, DeluxeCombat or PvPManager.

**Fix:** install ExyliaCombat. Old settings are copied to `exyliacombat-export.yml` for it to import. See
[Combat](/docs/exyliaspecials/combat).
