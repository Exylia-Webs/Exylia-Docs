Every node defaults to operators.

| Permission | Gates |
|---|---|
| `exyliaspecials.admin` | `/specialsadmin`, the whole admin menu, and `/specialsadmin reload`. |
| `exyliaspecials.admin.give.item` | `/specialsadmin give item`. |
| `exyliaspecials.admin.giveall.item` | `/specialsadmin giveall item`. |
| `exyliaspecials.admin.getall.item` | `/specialsadmin getall item`. |
| `exyliaspecials.admin.list.item` | `/specialsadmin list item`. |
| `exyliaspecials.admin.give.stattrack` | `/specialsadmin give stattrack`. |
| `exyliaspecials.admin.giveall.stattrack` | `/specialsadmin giveall stattrack`. |
| `exyliaspecials.admin.getall.stattrack` | `/specialsadmin getall stattrack`. |
| `exyliaspecials.admin.list.stattrack` | `/specialsadmin list stattrack`. |
| `exyliaspecials.admin.stattrack.manage` | `/specialsadmin stattrack remove` and `reset`. |
| `exyliaspecials.admin.cooldown` | `/specialsadmin cooldown`. |
| `exyliaspecials.admin.arena` | `/specialsadmin arena`. |
| `exyliaspecials.duel.bypass` | Any command during a duel. |

`exyliaspecials.admin.combat` and `exyliaspecials.combat.bypass` are gone: combat moved to ExyliaCombat. See
[Combat](/docs/exyliaspecials/combat).

## Wildcards

| Node | Includes |
|---|---|
| `exyliaspecials.*` | `exyliaspecials.admin.*` and `exyliaspecials.duel.bypass`. |
| `exyliaspecials.admin.*` | Every `exyliaspecials.admin...` node above. |

## Using items

No permission is needed to use special items. To restrict one, give it a `permission:` — on the item, or on a
single feature or step. See [Special items](/docs/exyliaspecials/items#permission).

## The menu

The admin menu only checks `exyliaspecials.admin`. Its buttons give items and appliers and edit arenas without
checking `exyliaspecials.admin.give...` or `exyliaspecials.admin.arena`. See
[Commands](/docs/exyliaspecials/commands#the-admin-menu).
