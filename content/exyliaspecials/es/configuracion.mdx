Todo se genera en `plugins/ExyliaSpecials/` al primer arranque, con comentarios. Edita los archivos de ahí y
ejecuta `/specialsadmin reload`.

| Archivo | Qué contiene |
|---|---|
| `config.yml` | Idioma, combate, barra de acción, estados, duelos, cooldowns vanilla. Abajo. |
| `lang/<language>/messages.yml` | Cada línea que envía el plugin. |
| `lang/<language>/items/*.yml` | Los ítems. Ver [Ítems especiales](/docs/exyliaspecials/items). |
| `lang/<language>/trackers/*.yml` | Los contadores. Ver [Contadores](/docs/exyliaspecials/contadores). |
| `lang/<language>/menus/admin/*.yml` | Las pantallas de administración, reescritas desde el jar en cada arranque y recarga. |
| `arenas.yml` | Las arenas de duelo. Ver [Duelos](/docs/exyliaspecials/duelos). |
| `database.yml` | La conexión a la base de datos de ExyliaLib. |

## config.yml

```yaml
language: default

combat:
  provider: AUTO
  duration: 15s
  logout-punishment: KILL
  punish-on-kick: false
  untag-on-kill: true
  disable-flight: true
  disable-elytra: true
  blacklisted-worlds: []
  blocked-inventories: [ENDER_CHEST]
  blocked-teleport-causes: [COMMAND]
  allowed-commands: [/msg, /tell, /w, /r, /reply, /discord]
  commands-on-logout: []
  commands-on-player-death: []
  notifications:
    on-tag: true
    on-untag: true
    on-region-blocked: true
    on-command-blocked: true
    on-flight-blocked: true
    on-elytra-blocked: true
    on-inventory-blocked: true
  logout-npc:
    enabled: true
    reset-combat-timer: true
    only-player-damage: true
    commands-on-npc-death: []
    blacklisted-worlds: []
  barrier:
    enabled: true
    material: RED_STAINED_GLASS
    height: 6
    preview-distance: 10
    update-interval-ticks: 3
    air-only: true
    push-back: {enabled: true, trigger-distance: 2.5, strength: 0.55, cooldown-ticks: 2}
    particles: {enabled: true, color: FF2222, size: 1.2, density: 20, interval-ticks: 6}

actionbar:
  enabled: true
  update-ticks: 2

states:
  clear-on-death: true
  flight-landing-grace: 4s
  reveal-on-attack: true
  undying-effects:
    - '[PARTICLE] TOTEM_OF_UNDYING;count:60;offset:0.6,1,0.6;speed:0.4;y:1'
    - '[RING_PULSE] END_ROD;radius:1.6;rings:2;spacing:0.4;points:18;y:0.1;ticks:4;interval:0.04'
    - '[SOUND] BLOCK_BEACON_POWER_SELECT;0.8;1.6'

duels:
  allowed-commands: [msg, tell, w, r, reply]
  broadcast-results: true
  copies:
    enabled: true
    max-per-arena: 16

vanilla-cooldowns:
  ENDER_PEARL:
    trigger: LAUNCH
    cooldown: 4.0
    combat-cooldown: 14.0
    display-name: '{primary}Ender Pearl'
    regions: {...}
  # ENCHANTED_GOLDEN_APPLE, TOTEM_OF_UNDYING, GOLDEN_APPLE, FIREWORK_ROCKET
```

### language

| Valor | |
|---|---|
| `default` | Sigue el idioma del `config.yml` de ExyliaLib. |
| `en`, `es`, `fr`, `pt`, `ru`, `tr` | Solo para este plugin. |
| cualquier otro | Un idioma propio, que empieza como copia del inglés. |

El idioma también elige la carpeta de la que se leen ítems y contadores — ver
[Instalación](/docs/exyliaspecials/instalacion#idiomas).

### combat

| Clave | Por defecto | |
|---|---|---|
| `provider` | `AUTO` | `AUTO`, `BUILTIN`, `MANUAL`, `DELUXECOMBAT`, `CELESTCOMBAT` o `PVPMANAGER`. |
| `duration` | `15s` | Cuánto dura el combate. |
| `logout-punishment` | `KILL` | `KILL` o `NOTHING`. |
| `punish-on-kick` | `false` | |
| `untag-on-kill` | `true` | |
| `disable-flight` | `true` | |
| `disable-elytra` | `true` | |
| `blacklisted-worlds` | `[]` | Ahí nadie entra en combate. |
| `blocked-inventories` | `[ENDER_CHEST]` | Tipos de inventario. |
| `blocked-teleport-causes` | `[COMMAND]` | Causas de teletransporte. |
| `allowed-commands` | `/msg`, `/tell`, `/w`, `/r`, `/reply`, `/discord` | |
| `commands-on-logout` | `[]` | |
| `commands-on-player-death` | `[]` | |
| `notifications.*` | todo `true` | Qué rechazos envían un mensaje. |
| `logout-npc.*` | | Ver [NPCs de desconexión](/docs/exyliaspecials/combate#npcs-de-desconexión). |
| `barrier.*` | | Ver [La barrera](/docs/exyliaspecials/combate#la-barrera). |

Todo salvo `provider` se aplica solo al combate integrado. El comportamiento completo en
[Combate](/docs/exyliaspecials/combate).

### actionbar

`enabled` (`true`) y `update-ticks` (2). Ver [Cooldowns](/docs/exyliaspecials/cooldowns#la-barra-de-acción).

### states

Ver [Estados](/docs/exyliaspecials/estados#ajustes).

### duels

Ver [Duelos](/docs/exyliaspecials/duelos#ajustes).

### vanilla-cooldowns

Una entrada por material. Ver [Cooldowns](/docs/exyliaspecials/cooldowns#ítems-vanilla).

## messages.yml

`lang/<language>/messages.yml` contiene cada línea, agrupada:

| Sección | |
|---|---|
| `prefix` | `%prefix%` en todas las demás líneas. |
| `combat` | Entrar en combate, rechazos, el nombre y la línea del NPC de desconexión. |
| `actionbar` | El formato de la barra de acción. |
| `items` | Rechazos al usar un ítem, agotado, caducado, y el `ON`/`OFF` de `%status%`. |
| `tools` | Respuestas de la palanca, el compresor, el filtro y el prospector. |
| `stattrack` | Aplicar contadores, y el hueco de víctima vacío. |
| `delivery` | Ítems recibidos, o en espera de la siguiente entrada. |
| `states` | La barra de cada estado, la celebración de la última resistencia, el fin del vuelo, el fin de la invisibilidad. |
| `duels` | Desafíos, rechazos, cuenta atrás, boss bars, resultados, anuncios y cada línea del editor de arenas. |
| `admin` | Respuestas de cada comando y editor. |

Una línea puede empezar por `[sound:NAME|volume|pitch]` para reproducir un sonido. Una línea vacía no envía nada.
Las barras de los estados y los títulos de los duelos son efectos de ExyliaLib: un título, barra de acción, boss
bar, sonido, partícula y fuego artificial cada uno.

## Los menús de administración

`lang/<language>/menus/admin/` tiene las ocho pantallas: `root`, `items`, `tools`, `item`, `stattracks`,
`cooldowns`, `arenas` y `arena`. Se **reescriben desde el jar en cada arranque y en cada recarga**: una edición no
sobrevive.
