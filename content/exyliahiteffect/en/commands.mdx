Every command, with the permission it needs. Effect ids and player names complete as you type. Players use `/hiteffect` (also `/hiteffects`); admins use `/hiteffectsadmin` (also `/hiteffectadmin`).

<Commands />

## What the admin command does

Typed bare, `/hiteffectsadmin` opens the admin hub (players only, not the console). Every subcommand under it is a shortcut for something the hub can do, and works from the console unless it needs a place (`crate block add`, `showcase add`, `spatial place`, `preview location`, `preview mannequin add`).

`player clear`, `crate block clear` and `showcase clear` only describe what they would delete until you run them again with `confirm` at the end.

`/hiteffectsadmin reload` re-reads this plugin's own files. It does not reload ExyliaLib: see [ExyliaLib commands](/docs/exylialib/commands).

<Details title="Technical details">
`none` is reserved: it is never an effect id, and it is what a rank default uses to give a group nothing. Taking an effect off, turning random off and emptying favourites never need a permission, so a player can always back out. `/hiteffect visibility`, `random`, `favourite` and `preview` check their own permission and answer "Your rank does not include that feature." when it is denied. See [Permissions](/docs/exyliahiteffect/permissions).
</Details>
