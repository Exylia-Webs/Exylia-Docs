Los jugadores pueden abrir el menú, el vestidor, la caja y la tienda sin configurar nada. Los patrones y materiales están bloqueados hasta que un permiso, un desbloqueo de la caja o una compra los entregue. Usa LuckPerms (o cualquier plugin de permisos) para repartirlos.

## Todos los permisos

<Permissions />

Una función rechazada por su nodo responde con `feature-locked` de `messages.yml`. Quitarse un trim nunca necesita permiso.

## Vende patrones y materiales

Un trim es un patrón más un material, y el jugador tiene cada mitad por separado. Los ids van en minúsculas y son las claves de `trims.yml`, por ejemplo `sentry` y `netherite`. Un trim se lleva cuando el jugador tiene **las dos** mitades.

`exyliaarmortrims.pattern.*` funciona aunque los patrones no estén declarados uno a uno en `plugin.yml`: el plugin pregunta por el nodo y, si no lo tiene, por el comodín de su nivel.

```text
# Un par de mitades para todos
/lp group default permission set exyliaarmortrims.pattern.sentry true
/lp group default permission set exyliaarmortrims.material.iron true

# El rango más alto, con todas las combinaciones
/lp group mvp permission set exyliaarmortrims.pattern.* true
/lp group mvp permission set exyliaarmortrims.material.* true
```

## Convierte una función en extra de rango

Todas las funciones de jugador las tiene todo el mundo por defecto. Para hacer de una un extra, niégala al grupo por defecto y concédela al rango.

```text
# El vestidor 3D como extra VIP (los demás usan el menú clásico)
/lp group default permission set exyliaarmortrims.wardrobe false
/lp group vip permission set exyliaarmortrims.wardrobe true

# Los VIP abren hasta cinco cajas a la vez
/lp group vip permission set exyliaarmortrims.crate.multi.5 true
```

`exyliaarmortrims.crate.multi.<n>` es un número por rango: gana el más alto que tenga el jugador. Sin ninguno se aplica `crate.max-at-once` de `config.yml`, y la pantalla admite siete como máximo.

## Permisos y desbloqueos

Un permiso es una forma de tener una mitad; un desbloqueo de la caja o una compra en la tienda es la otra. Lo que una caja, una compra o `/armortrimsadmin unlocks grant` haya desbloqueado se tiene sin ningún permiso, y se conserva cuando el rango caduca. El menú, el vestidor, `hide-without-permission` y la API preguntan por ambos.

## Cuando un permiso desaparece

No se borra nada. Lo que cambia es lo que se ve:

| Dónde | Efecto |
|---|---|
| El menú y el vestidor | Siempre preguntan. Una mitad que el jugador no tiene se dibuja bloqueada, o a la venta si la tienda le pone precio. |
| Objetos de trim | Nunca preguntan. Tener uno es la prueba de que es tuyo. |
| `hide-without-permission: true` | La armadura que ya lleva un trim que su portador no tiene se muestra sin él. |

El valor sigue en la armadura y en la fila del jugador, así que el aspecto vuelve entero el día que vuelve el rango. Los comandos nunca miran la propiedad.
