## Funciones

Cada función del jugador tiene un nodo que **todo el mundo tiene por defecto**. Un servidor convierte
una en ventaja de rango negándosela al grupo por defecto y dándosela al rango. Quitarse un trim nunca
necesita ninguno.

| Permiso | Por defecto | Qué concede |
|---|---|---|
| `exyliaarmortrims.command.armortrim` | todos | `/armortrim` y sus subcomandos. |
| `exyliaarmortrims.wardrobe` | todos | El [vestidor 3D](/docs/exyliaarmortrims/vestidor). Sin él `/armortrim` abre el menú clásico, y `/armortrim wardrobe` responde con `feature-locked`. |
| `exyliaarmortrims.buy` | todos | Comprar patrones y materiales en la tienda, desde el menú o el vestidor. Sin él las entradas bloqueadas no muestran precio. |
| `exyliaarmortrims.crate` | todos | Abrir la caja: el botón del menú, `/armortrim crate`, el icono de la caja del vestidor y un bloque de caja enlazado. |
| `exyliaarmortrims.crate.multi.<n>` | — | Abrir hasta `<n>` cajas de una vez en vez de `crate.max-at-once`. Gana el más alto que se tenga; la pantalla admite siete. |
| `exyliaarmortrims.admin` | op | Todo `/armortrimsadmin`: trims, cajas, llaves y vestidores. |

Una función rechazada por su nodo responde con `feature-locked` de `messages.yml`.

## Patrones y materiales

Lo que se vende: nadie salvo op los tiene hasta que un rango, una caja o una compra los entrega.

| Permiso | Qué concede |
|---|---|
| `exyliaarmortrims.pattern.<patrón>` | Ese patrón. |
| `exyliaarmortrims.pattern.*` | Todos los patrones. |
| `exyliaarmortrims.material.<material>` | Ese material. |
| `exyliaarmortrims.material.*` | Todos los materiales. |

Los ids van en minúsculas y son las claves de `trims.yml` — `sentry`, `netherite`. Un trim se lleva en
cuanto el jugador tiene **las dos** mitades.

<Callout type="note" title="Los nodos de presets ya no existen">
`exyliaarmortrims.trim.<preset>`, sus variantes por pieza y `exyliaarmortrims.custom` eran de los
presets que se quitaron en la 1.5.0 y ya no se leen. Ver
[Trims](/docs/exyliaarmortrims/trims#si-vienes-de-los-presets).
</Callout>

## Nodos y desbloqueos

Un nodo es una forma de tener una mitad; un desbloqueo de caja es la otra. Lo que desbloqueó una caja,
una compra o `/armortrimsadmin unlocks grant` es suyo sin nodo ninguno, y lo sigue siendo cuando caduca
un rango. Todas las comprobaciones preguntan las dos cosas: el menú, el vestidor,
`hide-without-permission` y la API.

| Se tiene por | Cubre |
|---|---|
| `exyliaarmortrims.pattern.<patrón>` o `pattern:<patrón>` desbloqueado | Ese patrón. |
| `exyliaarmortrims.material.<material>` o `material:<material>` desbloqueado | Ese material. |

Ver [La caja](/docs/exyliaarmortrims/caja).

## Los comodines se preguntan a mano

`exyliaarmortrims.pattern.*` funciona para todos los patrones aunque no estén declarados uno a uno en
`plugin.yml`. El plugin pregunta el nodo y, si no lo tiene, pregunta el comodín de su nivel — porque un
comodín de Bukkit solo se expande cuando todos sus hijos son permisos registrados, y estos se llaman
como entradas de un archivo que tú editas.

## Cuando el permiso se va

Nada se borra. Lo que cambia es lo que se ve:

| Dónde | Efecto |
|---|---|
| El menú y el vestidor | Siempre preguntan. Una mitad que el jugador no tiene se dibuja bloqueada, o en venta si la tienda le pone precio. |
| Objetos de trim | Nunca preguntan. Tenerlo en la mano es la prueba de que es suyo: se compró, se cambió o se ganó como cualquier otro objeto. |
| `hide-without-permission: true` | La armadura que ya llevaba un trim que el portador no tiene se muestra pelada. |

El valor sigue en la armadura y en la fila del jugador, así que el aspecto vuelve entero el día que
vuelva el rango. Los comandos nunca miran si se tiene.

## Ejemplos

```text
# Un par de mitades para todo el mundo
/lp group default permission set exyliaarmortrims.pattern.sentry true
/lp group default permission set exyliaarmortrims.material.iron true

# El vestidor 3D como ventaja VIP
/lp group default permission set exyliaarmortrims.wardrobe false
/lp group vip permission set exyliaarmortrims.wardrobe true

# Los VIP abren hasta cinco cajas a la vez
/lp group vip permission set exyliaarmortrims.crate.multi.5 true

# El rango de arriba, con todas las combinaciones
/lp group mvp permission set exyliaarmortrims.pattern.* true
/lp group mvp permission set exyliaarmortrims.material.* true
```
