---
title: "Placeholders"
description: "Seven placeholders about one piece of armor, and four about the crate."
---

Every placeholder is written out in full, and clicking one copies it.

Each names a **piece** first and then what you want to know:

```text
%exyliaarmortrims_<piece>_<value>%
```

Pieces: `helmet`, `chestplate`, `leggings`, `boots`.

| Placeholder | Description |
|---|---|
| `%exyliaarmortrims_<piece>_trim%` | The stored value: a preset id, or `pattern/material`. |
| `%exyliaarmortrims_<piece>_name%` | The trim's display name. |
| `%exyliaarmortrims_<piece>_pattern%` | The pattern's key. |
| `%exyliaarmortrims_<piece>_pattern_name%` | The pattern's display name, from `trims.yml`. |
| `%exyliaarmortrims_<piece>_material%` | The material's key. |
| `%exyliaarmortrims_<piece>_material_name%` | The material's display name. |
| `%exyliaarmortrims_<piece>_has_trim%` | `true` or `false`. |

## The crate

| Placeholder | Description |
|---|---|
| `%exyliaarmortrims_keys%` | The crate keys the player holds on their account. |
| `%exyliaarmortrims_unlocked%` | How many prizes they unlocked that the catalogue still offers. |
| `%exyliaarmortrims_unlocked_<id>%` | `true` or `false`: whether they unlocked that prize — a preset id, `pattern:<id>` or `material:<id>`. |
| `%exyliaarmortrims_tier_count_<tier>%` | How many prizes a rarity holds. |

They count what the crate unlocked only, not what a permission grants. See
[The crate](/docs/exyliaarmortrims/crate).

## Examples

```text
%exyliaarmortrims_helmet_name%
%exyliaarmortrims_boots_pattern_name%
%exyliaarmortrims_chestplate_has_trim%
```

```yaml
lines:
  - " {muted}❙ {letters}Helmet: {highlight}%exyliaarmortrims_helmet_name%"
  - " {muted}❙ {letters}Boots: {highlight}%exyliaarmortrims_boots_name%"
```

## What they actually answer

They answer with what the player **chose in the menu**, not with what they happen to be wearing: a
scoreboard saying "Helmet » SHOGUN" keeps saying it while its owner swims without a helmet on.

| Situation | Answer |
|---|---|
| A piece with no choice | `placeholders.none` from `messages.yml` — `None` by default. `has_trim` returns `false`. |
| A mistyped piece name | The same fallback, rather than leaving the placeholder on screen. |
| An unknown value after the `_` | The same fallback. |
| Mode `item` | Always the fallback: in that mode there is no menu choice to ask about. |

<Callout type="note" title="A trim engraved on armor does not show up here">
These placeholders read the player's choice. The trim a particular piece carries travels on the item,
and that is what the API is for — see [API](/docs/exyliaarmortrims/api).
</Callout>
