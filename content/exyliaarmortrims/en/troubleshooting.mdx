Find your symptom, check the cause, apply the fix.

## The plugin will not start

`packetevents` is required and must be in `plugins/`. `ExyliaLib` is a soft dependency: if it is missing, the loader installs it on the first start. See [Install ExyliaArmorTrims](/docs/exyliaarmortrims/installation).

## The menu opens but everything is locked

A trim needs both halves, the pattern and the material, each by its permission, a crate unlock or a purchase. Grant `exyliaarmortrims.pattern.<id>` and `exyliaarmortrims.material.<id>` (or the `*` wildcards). See [Permissions](/docs/exyliaarmortrims/permissions).

## `/armortrim` says the menu is off

You are on `behaviour.mode: item`. In that mode trims travel as items and there is no menu. Set `menu` or `both` in `config.yml` and run `/armortrimsadmin reload`.

## The trim does not show

| Check | Detail |
|---|---|
| The mode | `item` ignores the menu choice; `menu` ignores what is engraved on the armor. |
| Ownership | With `hide-without-permission` on, a trim the wearer no longer owns stops being drawn. |
| Creative | A creative client sees its real armor. Everyone else still sees the trim. |
| Disabled worlds | `behaviour.disabled-worlds` lists worlds where no trim is shown. |
| A removed entry | A pattern or material deleted from `trims.yml` is not drawn until the entry comes back. |

If it still does not show, run `/armortrimsadmin refresh <player>` to recompute and re-send it.

## `/armortrim` opens the inventory menu, not the 3D wardrobe

`behaviour.menu-style` is `classic` by default: set it to `spatial`, or use `/armortrim wardrobe`. A player on a client older than 1.21.4, or without `exyliaarmortrims.wardrobe`, always gets the inventory menu. See [Place the 3D wardrobe](/docs/exyliaarmortrims/wardrobe).

## Shop entries show as locked with no price

A price only shows when `shop.enabled` is on, the entry has a price (its own, or its rarity's in `shop.tier-prices`), an economy serves the currency (ExyliaEconomy, or Vault with an economy plugin) and the player holds `exyliaarmortrims.buy`. See [Set up the crate](/docs/exyliaarmortrims/crate).

## A showcase stays empty

An `only` list written with preset ids from before 1.5.0 matches nothing. Rewrite it as `pattern/material` or empty it. See [Add trim showcases](/docs/exyliaarmortrims/showcases).
