Los jugadores pueden usar ExyliaDuels sin configurar nada: todas las funciones de jugador están permitidas por defecto y solo el staff tiene `/duelsadmin`. Usa esta página para restringir cosas o crear ventajas de rango.

## Convertir una función en ventaja de rango

Todos tienen los permisos de jugador, así que para hacer de uno una ventaja, niégalo al grupo por defecto y concédelo al rango. Con LuckPerms:

```text
/lp group default permission set exyliaduels.bet.money false
/lp group vip permission set exyliaduels.bet.money true
```

Las opciones del reto (`exyliaduels.mode.own`, `mode.risk`, `bet.money`, `bet.items`, `arena.choose` y los kits) se comprueban en quien envía el reto. Quien lo recibe responde a lo que le hayan enviado. Un retador que prueba una opción que su rango no tiene ve "Tu rango no incluye esa opción."

Rechazar un reto y salir de un duelo o una repetición que estás mirando nunca necesitan permiso, así que nadie se queda atascado.

## Bloquear un kit a un rango

Un kit sigue a `exyliaduels.kit.*`, que tienen todos. Para vender un solo kit, niega `exyliaduels.kit.*` al grupo por defecto y concede el nodo propio de ese kit al rango:

```text
/lp group default permission set exyliaduels.kit.* false
/lp group vip permission set exyliaduels.kit.nodebuff true
```

El nodo es `exyliaduels.kit.<id del kit>`, con el id que escribiste al crear el kit. Un kit que tiene su propio nodo definido sigue solo ese nodo. Un kit que el jugador no puede usar no aparece en su selector de kit. Los kits de otro plugin usan `<origen>:<id>` como id, por ejemplo `exyliaduels.kit.randomkits:random`.

## Números por rango

Escribe el número en el propio permiso. Si un jugador tiene varios, se aplica el ganador. Sin ninguno, se aplica el valor de `config.yml`.

| Permiso | El número es | Gana | Si no |
|---|---|---|---|
| `exyliaduels.cooldown.<n>` | Segundos entre dos retos. | El más bajo | `requests.cooldown` |
| `exyliaduels.bet.max.<n>` | Apuesta de dinero más alta. `0` es sin límite. | El más alto | `bets.money.maximum` |
| `exyliaduels.tax.<n>` | Porcentaje entero del bote ganado que se destruye (0 a 100), según el ganador. | El más bajo | `bets.money.tax-percent` |

```text
/lp group vip permission set exyliaduels.cooldown.3 true
/lp group vip permission set exyliaduels.bet.max.5000 true
/lp group vip permission set exyliaduels.tax.2 true
```

`exyliaduels.bypass.cooldown` y `exyliaduels.bypass.tax` quitan la espera y el impuesto sea cual sea el número del rango.

<Callout type="warning" title="Dos permisos para reservar al staff">
`exyliaduels.admin` abre todo el panel, incluido borrar arenas y kits, y deja entrar en una arena en uso. `exyliaduels.bypass.tax` no lo tiene nadie, ni siquiera los operadores, hasta que lo concedas.
</Callout>
