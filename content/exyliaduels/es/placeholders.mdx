---
title: "Placeholders"
description: "Todos los placeholders que responde el plugin: las estadísticas de duelos del jugador, las clasificaciones, su último duelo, y el duelo que está jugando."
---

El plugin registra sus placeholders a través de ExyliaLib bajo el grupo `exyliaduels`, así que el nombre es
el mismo en los archivos de los plugins de Exylia y a través de **PlaceholderAPI**: `%exyliaduels_wins%`. No
hay que descargar nada del eCloud. Todos los valores se leen de memoria.

## Las estadísticas

| Placeholder | Valor |
|---|---|
| `%exyliaduels_wins%` | Duelos ganados. |
| `%exyliaduels_losses%` | Duelos perdidos. |
| `%exyliaduels_streak%` | Racha actual de victorias. Una derrota la reinicia. |
| `%exyliaduels_best_streak%` | La mejor racha de victorias. |
| `%exyliaduels_games%` | Duelos terminados con ganador: victorias más derrotas. |
| `%exyliaduels_winrate%` | Porcentaje de esos duelos ganados, como `75%`, con el formato de números de ExyliaLib en el servidor. |
| `%exyliaduels_money_won%` | Dinero ganado en la moneda configurada, con formato. |
| `%exyliaduels_accepting%` | Si el jugador acepta retos: `true` o `false`. |
| `%exyliaduels_in_duel%` | Si el jugador está en un duelo, viendo uno o de camino a uno: `true` o `false`. |

## El último duelo

Vacíos antes del primer duelo del jugador. Se leen del historial, así que necesitan `history.enabled`.

| Placeholder | Valor |
|---|---|
| `%exyliaduels_last_opponent%` | El rival del último duelo terminado del jugador. |
| `%exyliaduels_last_result%` | Cómo fue: `win`, `loss` o `draw`. |

## Clasificaciones y el servidor

Iguales para todos los jugadores, así que sirven para hologramas.

| Placeholder | Valor |
|---|---|
| `%exyliaduels_active%` | Duelos que se están luchando ahora mismo en este servidor. |
| `%exyliaduels_top_name_<stat>_<n>%` | El nombre en la posición `n` (de 1 a 10) de una clasificación, `---` si no hay nadie. |
| `%exyliaduels_top_value_<stat>_<n>%` | El valor a su lado, `0` si no hay nadie. |

`<stat>` es `wins`, `streak` o `best_streak`. Cada clasificación guarda los diez primeros con un valor mayor
que cero y se lee de la base de datos una vez por minuto, así que un placeholder nunca la espera; durante los
primeros segundos tras arrancar están vacías.

## El duelo

Vacíos fuera de un duelo. Son los que usa el scoreboard del duelo.

| Placeholder | Valor |
|---|---|
| `%exyliaduels_opponent%` | El nombre del rival. |
| `%exyliaduels_opponent_health%` | La vida del rival, con un decimal, como `17.5`. |
| `%exyliaduels_time%` | Cuánto lleva el combate, como `1:35`. `0:00` durante la cuenta atrás. |
| `%exyliaduels_mode%` | El nombre del kit, o `Inventario propio` o `Riesgo`. |
| `%exyliaduels_pot%` | Lo que se lleva el ganador antes del impuesto: las dos apuestas de dinero, con formato, o `Ninguna`. |
| `%exyliaduels_hits%` | Golpes que ha dado el jugador. |
| `%exyliaduels_opponent_hits%` | Golpes que ha dado el rival. |
| `%exyliaduels_hits_to_win%` | Los golpes que ganan, con un kit de golpes para ganar; `0` si no. |
| `%exyliaduels_rounds_won%` | Rondas que ha ganado el jugador. |
| `%exyliaduels_opponent_rounds_won%` | Rondas que ha ganado el rival. |
| `%exyliaduels_rounds_to_win%` | Rondas que ganan el duelo; `1` para un solo combate. |
| `%exyliaduels_round%` | La ronda que se está luchando, o la siguiente entre dos rondas. |

Los placeholders de golpes y rondas son los que usan `hits-scoreboard` y `rounds-scoreboard`. Consulta
[Configuración](/docs/exyliaduels/configuracion#los-scoreboards-del-duelo-scoreboard-hits-scoreboard-rounds-scoreboard).

Las palabras `Inventario propio`, `Riesgo` y `Ninguna` son las claves `labels.board-*` de `messages.yml`.

## Ejemplos

```text
%exyliaduels_wins%
%exyliaduels_best_streak%
%exyliaduels_opponent_health%
%exyliaduels_winrate%
%exyliaduels_top_name_wins_1% %exyliaduels_top_value_wins_1%
```
