Two commands: `/duel` for players and `/duelsadmin`, also `/dueladmin`, for staff.

## Player commands

Players only.

| Command | Permission | What it does |
|---|---|---|
| `/duel <player>` | `exyliaduels.duel` | Opens the challenge screen. Works for players on other servers when the network is on. |
| `/duel accept [player]` | `exyliaduels.duel` | Accepts that player's challenge; without a name, the newest one. |
| `/duel decline [player]` | none | Declines it; without a name, the newest one. Never needs a permission. |
| `/duel toggle` | `exyliaduels.duel` | Stops or resumes receiving challenges. |
| `/duel stats [player]` | `exyliaduels.stats` | A duel record: yours, or that player's. |
| `/duel spectate <player>` | `exyliaduels.spectate` | Watches that player's duel on this server. |
| `/duel leave` | none | Stops watching a duel or a replay. Never needs a permission. |
| `/duel history` | `exyliaduels.history` | Your finished duels, newest first. See [Duelling](/docs/exyliaduels/dueling#history). |
| `/duel history <player>` | `exyliaduels.history.others` | That player's finished duels. |

`accept` and `decline` suggest the players with a challenge waiting for you; `spectate` suggests the players
fighting on this server. See [Duelling](/docs/exyliaduels/dueling).

Three more subcommands are hidden from tab completion, because they are what clickable buttons run:

| Command | Permission | Clicked from |
|---|---|---|
| `/duel inventory <view>` | `exyliaduels.duel` | **[INVENTORY]** and **[YOURS]** in the end-of-duel block. |
| `/duel rematch <match>` | `exyliaduels.duel` and `exyliaduels.rematch` | **[⟲ REMATCH]** in the end-of-duel block. |
| `/duel replay <id>` | `exyliaduels.replay` | **Watch replay** in a duel's screen of `/duel history`. Another player's duel also needs `exyliaduels.replay.others`. |

<Callout type="note" title="Commands during a duel">
From an accepted challenge until the player is home, and while spectating, only the commands in
`allowed-commands` run. The default list includes `duel`, so `/duel leave` always works.
</Callout>

## Admin commands

Every command here needs `exyliaduels.admin`, operators by default.

| Command | Console | What it does |
|---|---|---|
| `/duelsadmin` | | Opens the admin panel: arenas, kits, settings and every setting of the plugin. See [Arenas and kits](/docs/exyliaduels/arenas-and-kits). |
| `/duelsadmin reload` | yes | Reads `config.yml` and the messages again, reloads the kits from the database and recompiles the menus. |

## Menu actions

The admin screens open each other through these, and a server's own menus can use them too. Each checks
`exyliaduels.admin` itself.

| Action | What it does |
|---|---|
| `exyliaduels:open_panel` | Opens the admin panel. |
| `exyliaduels:open_arenas` | Opens the arena list. |
| `exyliaduels:open_kits` | Opens the kit list. |
| `exyliaduels:open_settings` | Opens the settings screen. |
| `exyliaduels:open_own_rules` | Opens the arena flags and rules of own inventory duels. |
| `exyliaduels:open_config` | Opens every setting of the plugin in game (ExyliaLib's settings screens), with BACK returning to the panel. |

The history screens' actions (`exyliaduels:history_entry`, `history_back`, `history_replay`), the
end-of-duel inventory view's (`duel_inventory`) and the replay hotbar's (`replay_*`) check
`exyliaduels.history`, `exyliaduels.duel` and `exyliaduels.replay` themselves. The challenge screen's own actions (`exyliaduels:challenge_mode`, `challenge_loadout`, `challenge_arena`,
`challenge_money`, `challenge_items`, `challenge_send`) only work inside that screen.
