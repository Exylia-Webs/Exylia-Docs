Two commands: `/duel` for players and `/duelsadmin`, also `/dueladmin`, for staff.

## Player commands

Players only.

| Command | Permission | What it does |
|---|---|---|
| `/duel <player>` | `exyliaduels.duel` | Opens the challenge screen. Works for players on other servers when the network is on. |
| `/duel accept [player]` | `exyliaduels.duel` | Accepts that player's challenge; without a name, the newest one. |
| `/duel decline [player]` | `exyliaduels.duel` | Declines it; without a name, the newest one. |
| `/duel toggle` | `exyliaduels.duel` | Stops or resumes receiving challenges. |
| `/duel stats [player]` | `exyliaduels.stats` | A duel record: yours, or that player's. |
| `/duel spectate <player>` | `exyliaduels.spectate` | Watches that player's duel on this server. |
| `/duel leave` | `exyliaduels.spectate` | Stops watching. |

`accept` and `decline` suggest the players with a challenge waiting for you; `spectate` suggests the players
fighting on this server. See [Duelling](/docs/exyliaduels/dueling).

<Callout type="note" title="Commands during a duel">
From an accepted challenge until the player is home, and while spectating, only the commands in
`allowed-commands` run. The default list includes `duel`, so `/duel leave` always works.
</Callout>

## Admin commands

Every command here needs `exyliaduels.admin`, operators by default.

| Command | Console | What it does |
|---|---|---|
| `/duelsadmin` | | Opens the admin panel: arenas, kits and settings. See [Arenas and kits](/docs/exyliaduels/arenas-and-kits). |
| `/duelsadmin reload` | yes | Reads `config.yml` and the messages again, reloads the kits from the database and recompiles the menus. |

## Menu actions

The admin screens open each other through these, and a server's own menus can use them too. Each checks
`exyliaduels.admin` itself.

| Action | What it does |
|---|---|
| `exyliaduels:open_panel` | Opens the admin panel. |
| `exyliaduels:open_arenas` | Opens the arena list. |
| `exyliaduels:open_kits` | Opens the kit list. |
| `exyliaduels:open_settings` | Opens the settings screen. |

The challenge screen's own actions (`exyliaduels:challenge_mode`, `challenge_loadout`, `challenge_arena`,
`challenge_money`, `challenge_items`, `challenge_send`) only work inside that screen.
