Every ExyliaDuels command with the permission it needs. Players use `/duel`, staff use `/duelsadmin` (also `/dueladmin`). Player names complete as you type: `accept` and `decline` suggest the players with a challenge waiting, `spectate` suggests the players fighting on this server.

## Buttons that run commands

Three more `/duel` subcommands are hidden from tab completion because clickable buttons run them. You never need to type them.

| Command | Clicked from | Needs |
|---|---|---|
| `/duel inventory <view>` | **[INVENTORY]** and **[YOURS]** in the end-of-duel message | `exyliaduels.duel` |
| `/duel rematch <match>` | **[⟲ REMATCH]** in the end-of-duel message | `exyliaduels.duel` and `exyliaduels.rematch` |
| `/duel replay <id>` | **Watch replay** in a duel of `/duel history` | `exyliaduels.replay`, and `exyliaduels.replay.others` for another player's duel |

## Commands during a duel

From an accepted challenge until a player is home again, and while spectating, only the commands in `allowed-commands` of `config.yml` work. The default list is `duel`, `msg`, `tell`, `w`, `whisper`, `m`, `r` and `reply`, so `/duel leave` always works. See [Configuration](/docs/exyliaduels/configuration).

## Reload

`/duelsadmin reload` reads `config.yml`, the messages and the menus again, and reloads the kits. It also works from the console. Arenas and kits are stored in the database, so changing them in `/duelsadmin` needs no reload.
