---
title: "Placeholders"
description: "Every placeholder the plugin answers: the viewer's duel record, leaderboards, their last duel, and the duel they are fighting."
---

The plugin registers its placeholders through ExyliaLib under the group `exyliaduels`, so the name is the
same inside Exylia plugins' own files and through **PlaceholderAPI**: `%exyliaduels_wins%`. Nothing has to
be downloaded from the eCloud. Every value is read from memory.

## The record

| Placeholder | Value |
|---|---|
| `%exyliaduels_wins%` | Duels won. |
| `%exyliaduels_losses%` | Duels lost. |
| `%exyliaduels_streak%` | Current win streak. A loss resets it. |
| `%exyliaduels_best_streak%` | Best win streak ever. |
| `%exyliaduels_games%` | Duels finished with a winner: wins plus losses. |
| `%exyliaduels_winrate%` | Share of those duels won, as a percentage such as `75%`, formatted the way ExyliaLib formats numbers on the server. |
| `%exyliaduels_money_won%` | Money won in the configured currency, formatted. |
| `%exyliaduels_accepting%` | Whether the viewer takes challenges: `true` or `false`. |
| `%exyliaduels_in_duel%` | Whether the viewer is in a duel, watching one or on their way to one: `true` or `false`. |

## The last duel

Empty before the viewer's first duel. Read from the history, so they need `history.enabled`.

| Placeholder | Value |
|---|---|
| `%exyliaduels_last_opponent%` | The opponent of the viewer's last finished duel. |
| `%exyliaduels_last_result%` | How it went: `win`, `loss` or `draw`. |

## Leaderboards and the server

The same for every viewer, so they fit holograms.

| Placeholder | Value |
|---|---|
| `%exyliaduels_active%` | Duels being fought on this server right now. |
| `%exyliaduels_top_name_<stat>_<n>%` | The name in position `n` (1 to 10) of a board, `---` when nobody holds it. |
| `%exyliaduels_top_value_<stat>_<n>%` | The value beside it, `0` when nobody holds it. |

`<stat>` is `wins`, `streak` or `best_streak`. Each board keeps the top ten with a value above zero and is
read from the database once a minute, so a placeholder never waits on it; the boards are empty for the first
seconds after a start.

## The duel

Empty outside a duel. These are the ones the duel scoreboard uses.

| Placeholder | Value |
|---|---|
| `%exyliaduels_opponent%` | The opponent's name. |
| `%exyliaduels_opponent_health%` | The opponent's health, with one decimal, such as `17.5`. |
| `%exyliaduels_time%` | How long the fight has lasted, as `1:35`. `0:00` during the countdown. |
| `%exyliaduels_mode%` | The kit's name, or `Own inventory` or `Risk`. |
| `%exyliaduels_pot%` | What the winner takes before tax: both money stakes, formatted, or `None`. |
| `%exyliaduels_hits%` | Hits the viewer has landed. |
| `%exyliaduels_opponent_hits%` | Hits the opponent has landed. |
| `%exyliaduels_hits_to_win%` | The hits that win, with a hits-to-win kit; `0` otherwise. |
| `%exyliaduels_rounds_won%` | Rounds the viewer has won. |
| `%exyliaduels_opponent_rounds_won%` | Rounds the opponent has won. |
| `%exyliaduels_rounds_to_win%` | Rounds that win the duel; `1` for a single fight. |
| `%exyliaduels_round%` | The round being fought, or the next one between two rounds. |

The hits and rounds placeholders are what `hits-scoreboard` and `rounds-scoreboard` use. See
[Configuration](/docs/exyliaduels/configuration#the-duel-scoreboards-scoreboard-hits-scoreboard-rounds-scoreboard).

The words `Own inventory`, `Risk` and `None` are the `labels.board-*` keys in `messages.yml`.

## Examples

```text
%exyliaduels_wins%
%exyliaduels_best_streak%
%exyliaduels_opponent_health%
%exyliaduels_winrate%
%exyliaduels_top_name_wins_1% %exyliaduels_top_value_wins_1%
```
