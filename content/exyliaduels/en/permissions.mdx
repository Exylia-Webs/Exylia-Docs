Players can use ExyliaDuels without any setup: every player feature is allowed by default, and only staff get `/duelsadmin`. Use this page to restrict things or to build rank perks.

## All permissions

<Permissions />

## Make a feature a rank perk

Everybody holds the player permissions, so to make one a perk, deny it to the default group and grant it to the rank. With LuckPerms:

```text
/lp group default permission set exyliaduels.bet.money false
/lp group vip permission set exyliaduels.bet.money true
```

The challenge options (`exyliaduels.mode.own`, `mode.risk`, `bet.money`, `bet.items`, `arena.choose` and the kits) are checked on the player who sends the challenge. The player who receives it answers whatever they were sent. A challenger who tries an option their rank lacks sees "Your rank does not include that option."

Declining a challenge and leaving a spectated duel or a replay never need a permission, so nobody gets stuck.

## Lock a kit to a rank

A kit follows `exyliaduels.kit.*`, which everybody holds. To sell one kit, deny `exyliaduels.kit.*` to the default group and grant that kit's own node to the rank:

```text
/lp group default permission set exyliaduels.kit.* false
/lp group vip permission set exyliaduels.kit.nodebuff true
```

The node is `exyliaduels.kit.<kit id>`, with the id you typed when you created the kit. A kit that has its own node set follows only that node. A kit a player may not use is not shown in their kit picker. Kits offered by another plugin use `<source>:<id>` as the id, for example `exyliaduels.kit.randomkits:random`.

## Numbers per rank

Write the number in the permission itself. When a player holds several, the winning one applies. Without any, the value in `config.yml` applies.

| Permission | The number is | Winner | Otherwise |
|---|---|---|---|
| `exyliaduels.cooldown.<n>` | Seconds between two challenges. | Lowest | `requests.cooldown` |
| `exyliaduels.bet.max.<n>` | Largest money stake. `0` means no limit. | Highest | `bets.money.maximum` |
| `exyliaduels.tax.<n>` | Whole percent of a won pot that is destroyed (0 to 100), read from the winner. | Lowest | `bets.money.tax-percent` |

```text
/lp group vip permission set exyliaduels.cooldown.3 true
/lp group vip permission set exyliaduels.bet.max.5000 true
/lp group vip permission set exyliaduels.tax.2 true
```

`exyliaduels.bypass.cooldown` and `exyliaduels.bypass.tax` remove the wait and the tax whatever number a rank has.

<Callout type="warning" title="Two permissions to keep for staff">
`exyliaduels.admin` opens the whole panel, including deleting arenas and kits, and lets a player walk into an arena that is in use. `exyliaduels.bypass.tax` is held by nobody, not even operators, until you grant it.
</Callout>
