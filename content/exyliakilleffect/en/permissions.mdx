Players can open `/killeffect`, preview, star favourites, buy and open the crate without any setup. What they cannot do is wear an effect: effects are sold with the permissions below, and only operators own all of them by default.

## Sell effects

Effects are unlocked by one of three permissions, from narrow to wide. Each id is written in lowercase, the way `effects.yml` and `config.yml` write it:

| Permission | Unlocks |
|---|---|
| `exyliakilleffect.effect.griddy` | One effect. |
| `exyliakilleffect.category.meme` | Every effect in a category. The five categories are `meme`, `void`, `cataclysm`, `lovestruck` and `cosmic`. |
| `exyliakilleffect.tier.legendary` | Every effect of a rarity. The rarities are the ones in `tiers` in `config.yml`: `common`, `rare`, `epic` and `legendary` by default. |

With LuckPerms:

```text
/lp group vip permission set exyliakilleffect.category.meme true
/lp group elite permission set exyliakilleffect.tier.legendary true
```

Effects a player wins in the crate or that you grant with `/killeffectsadmin unlocks grant` are saved on their account, so they stay after a rank expires. A permission is lost with the rank.

## Make a feature a rank perk

Players hold every player permission by default. To make one a perk, deny it to the default group and grant it to the rank:

```text
/lp group default permission set exyliakilleffect.random false
/lp group vip permission set exyliakilleffect.random true
```

The same works for `exyliakilleffect.crate`, `exyliakilleffect.favourites`, `exyliakilleffect.visibility`, `exyliakilleffect.preview` and `exyliakilleffect.buy`. A player who is refused sees "Your rank does not include that feature." Change the text in [Messages and languages](/docs/exylialib/messages-and-languages).

## Let a rank open more crates at once

By default a player opens `crate.max-at-once` crates in one go (4 by default, 7 at most). Give a rank a higher number by writing it at the end of the node:

```text
/lp group vip permission set exyliakilleffect.crate.max.7 true
```

If a player holds several, the highest one wins.

<Callout type="warning" title="Keep the admin node for staff">
`exyliakilleffect.admin` opens `/killeffectsadmin`: it can bind effects to any weapon, grant unlocks and keys, and delete crate blocks and showcases. Operators have it by default.
</Callout>
