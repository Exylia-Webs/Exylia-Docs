You will change what the 110 kill effects are called, what they cost and which weapons carry them, take some out, and add one of your own. All of it is one file, and a reload applies it.

## Before you start

Find the file: `plugins/ExyliaKillEffect/lang/<code>/effects.yml`, where `<code>` is the plugin's language (`en` by default, see [Messages and languages](/docs/exylialib/messages-and-languages)). Open it in the browser instead if you prefer: [the web editor](/docs/exylialib/web-editor) (`/exylialib editor`) checks the file before saving it and applies it with no reload.

The file has two blocks. `categories` are the tabs of the menu (Meme, Void, Cataclysm, Lovestruck, Cosmic). `kill_effects` are the effects, each under its id, for example `GRIDDY`.

## Steps

<Steps>
  <Step title="Rename an effect">
    Change its `name`. [Colours](/docs/exylialib/colours) tokens, MiniMessage and gradients all work. The id does not change, so permissions and tokens keep working.
  </Step>
  <Step title="Set a price">
    Add `price: 2500` to the effect. It is sold in the menu at that price in your default currency, or in another one with `price: {amount: 50, currency: gems}`. A price here wins over the rarity price. Prices only show when `shop.enabled` is on (it is by default) and an economy is installed, see [Configuration](/docs/exyliakilleffect/configuration#shop) and [Economy](/docs/exylialib/economy).
  </Step>
  <Step title="Limit it to some weapons">
    Add `weapons: [ SWORD, AXE ]`. It only matters when a player can bind effects to weapons, see [Modes and tokens](/docs/exyliakilleffect/modes-and-tokens). Without `weapons`, the effect fits any weapon.
  </Step>
  <Step title="Remove it from a tab">
    Delete its whole entry. Players who wore it play nothing; the choice is not erased, so the effect comes back for them if you add the same id again.
  </Step>
  <Step title="Apply the change">
    Run `/killeffectsadmin reload`.
  </Step>
</Steps>

## Check that it works

Run `/killeffect`: the new name and price show on the effect. Run `/killeffect preview <id>` to watch it (the [preview stage](/docs/exyliakilleffect/first-steps) must be set). If the console prints a line starting `effects.yml kill_effects.<id>`, that entry has a problem and the line says which; everything else still loaded.

## Going further

### Add your own effect

Copy an existing entry, give it a new id and a `category` that exists, then change its `effects` list. Each line is a step: a sound, a shape, a delay. The language is in [Sequences](/docs/exyliakilleffect/sequences), or let an assistant write it with [Create effects with AI](/docs/exyliakilleffect/create-with-ai). Then reload and preview it.

The effect id is its permission: `GRIDDY` is `exyliakilleffect.effect.griddy`. Ids are lowercased, so case does not matter. Renaming an id renames the permission, and everyone who had the old one loses the effect. Give a whole category with `exyliakilleffect.category.<category>`, see [Permissions](/docs/exyliakilleffect/permissions).

### Change a rarity

Set `tier` to a rarity declared under `tiers` in `config.yml` (`common`, `rare`, `epic` and `legendary` by default). It decides the colour and how often the [crate](/docs/exyliakilleffect/crate) lands on it. An entry with no `tier` is `common`.

### What an effect looks like

All 110 effects are built on a `[RAGDOLL]` step: the victim's own body, every joint kept and wearing the colours of their skin, moved frame by frame. In 41 of them a copy of the killer walks in and acts the death out, and in 20 the players watching nearby join in. Everything drawn is display-only: nothing can be hit, looted or collided with.

<Details title="Technical details: effect keys, weapon families, the catalogue">

```yaml title="lang/en/effects.yml"
categories:
  meme:
    material: JUKEBOX
    name: 'Meme'
    priority: 1

kill_effects:
  GRIDDY:
    category: meme
    tier: common
    name: "<gradient:#B8FF9E:#59A4FF><bold>HIT THE GRIDDY</bold></gradient>"
    material: NOTE_BLOCK
    description:
      - 'Two bars of the griddy, a spin, a dab, and'
      - 'then {highlight}the whole dance goes everywhere{neutral}.'
    priority: 1
    effects:
      - '[RAGDOLL] {victim};keys:0.18 up=-0.1 body=20 | 0.22 leg_l=48 … ease=smooth | …'
      - '[SOUND] BLOCK_NOTE_BLOCK_BIT;0.8;1.0'
      - '[DELAY] 0.28'
      - '[PARTICLE] NOTE;count:2;offset:0.7,0.3,0.7;speed:1.0;y:2.3;repeat:8;every:0.22'
```

| Key | What it does |
|---|---|
| `category` | Which tab it appears under. Must be declared under `categories`. An entry naming an undeclared category is kept (commands and tokens still give it) but has no tab. |
| `tier` | Its rarity: a key under `tiers` in `config.yml`. Default `common`. An undeclared rarity is reported and the effect is treated as the first rarity. |
| `name` | What menus and placeholders call it. |
| `material` | The item the row is drawn with. Default `BARRIER`. |
| `description` | A list is one line per entry; a single string breaks on `<nl>`. |
| `priority` | Where it sits in its tab; lower comes first. Default `999`. |
| `effects` | The steps drawn where the victim fell. An entry with none draws nothing and is reported. |
| `weapons` | Optional. What the effect may be bound to. Omit it and it fits anything. |
| `price` | Optional. A number in the default currency, or `{amount: 50, currency: gems}`. A price that is not above zero means not for sale. |
| `preview-facing` | Optional. The side the [3D selector](/docs/exyliakilleffect/3d-selector) shows it from: `AUTO`, `FRONT`, `SIDE` or degrees. Omit it for the layout's `preview.effect-facing`. |

A category takes `material` (default `PAPER`), `name` and `priority`. The id `none` is reserved and is refused. A missing `categories` or `kill_effects` section is reported and that section is dropped; the web editor refuses a save that would lose a section or an entry.

Sound volumes above `1.0` are lowered to `1.0` when the file is read: a higher volume does not play louder, it only widens the radius at which the sound is heard.

Weapon families:

| Family | Matches |
|---|---|
| `ANY` | Anything, including an empty hand. |
| `SWORD` | Every `_SWORD`. |
| `AXE` | Every `_AXE`. A pickaxe is not one. |
| `TRIDENT`, `MACE`, `BOW`, `CROSSBOW` | Just that item. |
| `MELEE` | Swords, axes, tridents and maces. |
| `RANGED` | Bows, crossbows and tridents. |

You can also list exact items such as `NETHERITE_SWORD`. A token that is neither is reported and ignored. Families match on the item's name, so a new sword in a later Minecraft version counts at once. None of the shipped effects declares `weapons`.
