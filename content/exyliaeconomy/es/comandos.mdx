Tres formas llegan a las mismas acciones. `/balance`, `/pay`, `/baltop` y `/wallet` son las palabras que
cualquier jugador ya conoce, siempre sobre la moneda por defecto. `/economy` lo hace todo para cualquier
moneda. Cada moneda almacenada recibe además un comando propio — `/shards`. Lo que cambia el dinero de otro
vive en `/economyadmin`.

Un argumento de jugador acepta a cualquiera que la red conozca, conectado, desconectado o en otro servidor;
las sugerencias ofrecen cada nombre que ha visto ExyliaLib. Un argumento de moneda sugiere solo las monedas
que puede usar quien escribe. Las cantidades se escriben como `100`, `2.5k`, `1m`.

## Comandos de jugador

| Comando | Alias | Permiso | Qué hace |
|---|---|---|---|
| `/balance [player]` | `/bal`, `/money` | `exyliaeconomy.use` | Tu saldo en la moneda por defecto, o el de otro. |
| `/wallet [player]` | `/balances` | `exyliaeconomy.use` | Cada moneda que puedes usar, en una pantalla; una línea por moneda en consola. |
| `/baltop [page]` | `/balancetop`, `/moneytop` | `exyliaeconomy.use` | La clasificación de la moneda por defecto: una pantalla para jugadores, diez líneas por página en consola. |
| `/pay <player> <amount> [currency] [confirm]` | | `exyliaeconomy.pay` | Envía dinero. `confirm` envía un pago que preguntó primero. |
| `/paytoggle` | | `exyliaeconomy.paytoggle` | Deja de recibir pagos, o vuelve a recibirlos. |
| `/withdraw <amount> [currency]` | | `exyliaeconomy.withdraw` | Convierte dinero en un billete. |
| `/deposit` | | `exyliaeconomy.use` | Canjea el billete que tienes en la mano. |

Todo lo que trate de otro jugador — un saldo, una billetera, un historial — necesita además
`exyliaeconomy.others`. `/pay`, `/paytoggle`, `/withdraw` y `/deposit` son solo para jugadores.

## /economy

`/economy` (`/eco`) necesita `exyliaeconomy.use`. Sin nada más abre tu billetera.

| Comando | Qué hace |
|---|---|
| `/economy balance [currency] [player]` | Un saldo. Una sola palabra que no es una moneda se lee como jugador, en la moneda por defecto. |
| `/economy wallet [player]` | La billetera. |
| `/economy currencies` | Cada moneda con su ID y su tipo. |
| `/economy pay <player> <amount> [currency]` | Lo mismo que `/pay`; necesita `exyliaeconomy.pay`. |
| `/economy top [currency] [page]` | Una clasificación. `/eco top 2` es la página 2 de la moneda por defecto. |
| `/economy history [currency] [player]` | El registro: una pantalla para jugadores, las últimas 15 líneas en consola. |
| `/economy exchange <amount> <from> <to>` | Cambia según la tasa de la moneda de origen. Solo jugadores. |

Las antiguas formas de administración siguen funcionando, con `exyliaeconomy.admin`, porque con ellas están
escritos los archivos de recompensas y cajas de los servidores en marcha:
`/eco give <player> <amount> [currency]`, `/eco take …`, `/eco set …`, `/eco reset <player> [currency]` y
`/eco import <from> <into> [again]`.

## Un comando por moneda

Cada moneda almacenada con **Comandos activados** tiene un comando con su primer nombre de comando, y el
resto como alias. `/shards` representa a cualquiera de ellos.

| Comando | Permiso | Qué hace |
|---|---|---|
| `/shards` | `exyliaeconomy.use` | Tu saldo. |
| `/shards <player>` | `+ exyliaeconomy.others` | El de otro. |
| `/shards pay <player> <amount>` | `+ exyliaeconomy.pay` | Paga en shards. |
| `/shards top [page]` | | Su clasificación. |
| `/shards history [player]` | | Su registro; el de otro jugador necesita `exyliaeconomy.others`. |
| `/shards exchange <amount> <to>` | | Cambia shards por otra moneda. Solo jugadores. |
| `/shards give\|take\|set <player> <amount>` | `exyliaeconomy.admin` | Cambia un saldo. |
| `/shards reset <player>` | `exyliaeconomy.admin` | Vuelve al saldo inicial. |

El permiso propio de una moneda se aplica encima de todos ellos. Un número de argumentos incorrecto responde
con la línea de uso. Un nombre que ya registró otro plugin responde como `/exyliaeconomy:<name>`.

## /economyadmin

`/economyadmin` (`/ecoadmin`, `/eadmin`) necesita `exyliaeconomy.admin`. Todos los subcomandos funcionan
desde consola salvo el propio editor.

| Comando | Qué hace |
|---|---|
| `/economyadmin` | Abre el editor de monedas. Solo jugadores. |
| `/economyadmin give <player> <amount> [currency]` | Ingresa. |
| `/economyadmin take <player> <amount> [currency]` | Retira; se rechaza si un jugador de aquí tiene menos. |
| `/economyadmin set <player> <amount> [currency]` | Fija el saldo. Acepta `0`. |
| `/economyadmin reset <player> [currency]` | Vuelve al saldo inicial. |
| `/economyadmin giveall <currency> <amount> [confirm]` | Da la cantidad a cada jugador de este servidor, tras una confirmación. |
| `/economyadmin import <from> <into> [again]` | Suma cada saldo conocido de una moneda a una moneda almacenada. |
| `/economyadmin currencies` | Cada moneda con su ID y su tipo. |
| `/economyadmin log <player> [currency] [page]` | Las líneas del registro de un jugador con sus IDs, diez por página. |
| `/economyadmin export <currency\|all> [days]` | Escribe líneas del registro en un CSV dentro de `exports/`. |
| `/economyadmin rollback <player> <window\|#id> [currency] [confirm]` | Revierte los movimientos de un jugador en un periodo (`1h`, `2d`) o una línea (`#42`), tras una confirmación. |
| `/economyadmin reload` | Recarga los archivos, las monedas y los menús. |

Con un jugador que no está en este servidor, `give`, `take`, `set` y `reset` quedan en cola y se aplican
donde esté el jugador. Ver [Pagos](/docs/exyliaeconomy/pagos#cambios-de-administración) y
[Registro](/docs/exyliaeconomy/registro).

### Qué hace reload

Tres pasos con nombre: `configs` (`config.yml` y `messages.yml`, después el prefijo y el interruptor de
depuración), `currencies` (se vuelven a leer de la base de datos, fuera del hilo del juego, y se reinstalan
los comandos de las monedas) y `menus` (cada pantalla se compila de nuevo; antes se reescriben desde el jar
las pantallas del editor). El paso `menus` también se ejecuta cuando se recarga la propia ExyliaLib, para
que un cambio de paleta llegue a las pantallas.

Una recarga no toca los saldos: los que están en memoria se quedan, y la base de datos ya los tiene.

## Qué valen por defecto los argumentos opcionales

| Argumento | Por defecto |
|---|---|
| `currency` | La moneda por defecto de ExyliaLib, `default-currency` en `plugins/ExyliaLib/economy.yml`. |
| `player` | Tú mismo. La consola debe nombrar uno, o recibe el comando que hay que escribir: `/economy balance <player>`. |
| `page` | `1`. |
| `days` (export) | `0`, todo. |
| `confirm` | Si falta, el comando pregunta primero. |
