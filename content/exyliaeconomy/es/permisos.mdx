Los jugadores pueden usar todo lo que necesitan sin configurar nada. Solo los permisos de staff (`others`, `admin`, `paytoggle.bypass`) están desactivados por defecto para jugadores. Usa esta página para restringir cosas o dar ventajas a rangos.

## Impuesto por rango

Una moneda puede cobrar un impuesto en las transferencias, cobrado encima de la cantidad que escribe quien envía. `exyliaeconomy.tax.<n>` lo baja para un rango a `n` por ciento, solo números enteros. Quien tenga varios recibe el más bajo, y un permiso nunca sube el impuesto propio de la moneda.

```text
/lp group vip permission set exyliaeconomy.tax.2 true
/lp group mvp permission set exyliaeconomy.tax.0 true
```

## Ejemplos

Impedir que un rango envíe dinero:

```text
/lp group default permission set exyliaeconomy.pay false
```

Dejar que los moderadores lean saldos e historial de otros jugadores sin el editor:

```text
/lp group mod permission set exyliaeconomy.others true
```

Ocultar al staff de `/baltop` y de todas las clasificaciones. Se aplica desde la siguiente entrada del jugador y los operadores no lo reciben automáticamente:

```text
/lp group staff permission set exyliaeconomy.top.exempt true
```

Una moneda solo para VIP: pon su permiso a `server.vip` en `/economyadmin` (las **Reglas** de la moneda) y luego

```text
/lp group vip permission set server.vip true
```
