Players can use everything they need without any setup. Only staff nodes (`others`, `admin`, `paytoggle.bypass`) are off by default for players. Use this page to restrict things or to give ranks a perk.

## All permissions

<Permissions />

Redeeming a banknote by right-clicking it needs no permission, so a banknote someone found still works.

## Tax by rank

A currency can charge a tax on transfers, charged on top of the amount the sender types. `exyliaeconomy.tax.<n>` lowers it for a rank to `n` percent, whole numbers only. A player who holds several gets the lowest, and a node never raises a currency's own tax.

```text
/lp group vip permission set exyliaeconomy.tax.2 true
/lp group mvp permission set exyliaeconomy.tax.0 true
```

## Examples

Stop a rank from sending money:

```text
/lp group default permission set exyliaeconomy.pay false
```

Let moderators read other players' balances and history without the editor:

```text
/lp group mod permission set exyliaeconomy.others true
```

Hide staff from `/baltop` and every board. It applies from the player's next join, and operators do not get it automatically:

```text
/lp group staff permission set exyliaeconomy.top.exempt true
```

A VIP-only currency: set its permission to `server.vip` in `/economyadmin` (the currency's **Rules**), then

```text
/lp group vip permission set server.vip true
```
