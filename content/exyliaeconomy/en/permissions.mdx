description: "Every node the plugin declares, what each one gates, their defaults and children, the ExyliaSurvivalCore names that still work, and a currency's own permission."
---

Every node below is declared in `plugin.yml`. Most are granted to everyone by default; reading other
players' money, bypassing `/paytoggle` and the admin commands are for operators.

## Plugin nodes

| Permission | Default | What it gates |
|---|---|---|
| `exyliaeconomy.use` | everyone | `/balance`, `/wallet`, `/baltop`, `/economy`, `/deposit` and every currency command. |
| `exyliaeconomy.pay` | everyone | `/pay`, `/economy pay` and every currency's `pay`. |
| `exyliaeconomy.paytoggle` | everyone | `/paytoggle`. |
| `exyliaeconomy.paytoggle.bypass` | operators | Paying players who turned payments off. |
| `exyliaeconomy.withdraw` | everyone | `/withdraw`. |
| `exyliaeconomy.interest` | everyone | Earning interest while online. See [Interest](/docs/exyliaeconomy/interest). |
| `exyliaeconomy.top.exempt` | nobody, operators included | Being left off every leaderboard, from the player's next join. |
| `exyliaeconomy.others` | operators | Reading another player's balance, wallet or history. |
| `exyliaeconomy.admin` | operators | `/economyadmin`, the editor and every button in it, the old `/eco give`… spellings, and `give`, `take`, `set`, `reset` on the currency commands. |
| `exyliaeconomy.*` | operators | Everything: its child is `exyliaeconomy.admin`. |

`exyliaeconomy.admin` includes `use`, `pay`, `paytoggle`, `paytoggle.bypass`, `withdraw` and `others`. It
does not include `interest` or `top.exempt`.

Right-clicking a banknote to redeem it needs no node; `/deposit` needs `exyliaeconomy.use`. A missing node
answers with the plugin's *"You don't have permission to do that."*, or the server's own refusal for a
root command.

## The ExyliaSurvivalCore names

What staff were granted while the economy lived in ExyliaSurvivalCore keeps working. Each old node is
declared again with its new node as a child:

| Old node | Grants | Default |
|---|---|---|
| `exyliasurvivalcore.economy` | `exyliaeconomy.use` | everyone |
| `exyliasurvivalcore.economy.pay` | `exyliaeconomy.pay` | everyone |
| `exyliasurvivalcore.economy.others` | `exyliaeconomy.others` | operators |
| `exyliasurvivalcore.economy.admin` | `exyliaeconomy.admin` | operators |

## A currency's own permission

Any stored currency can name a permission of your choosing in its **Rules**. A player without it:

- does not see the currency in `/wallet`, in command suggestions or in other plugins' currency pickers;
- is refused by every command that names it: *"You may not use Gems."*;
- cannot redeem its banknotes, is skipped by `giveall`, and earns no interest in it.

Blank, the default, means nobody needs one.

## Examples

Keeping a group from paying while leaving balances readable:

```text
/lp group default permission set exyliaeconomy.pay false
```

Letting moderators read other players' balances and history without the editor:

```text
/lp group mod permission set exyliaeconomy.others true
```

Hiding the staff from `/baltop`:

```text
/lp group staff permission set exyliaeconomy.top.exempt true
```

A VIP-only currency: set its permission to `server.vip` in `/economyadmin`, then

```text
/lp group vip permission set server.vip true
```
