With PlaceholderAPI installed, every placeholder starts with `%exyliaeconomy_economy_`. Inside the plugin's own files and other Exylia plugins the short form (`%economy_balance_dollars%`) works too. Write `<currency>` as a currency id such as `dollars`. A balance without a currency uses the default currency.

<Placeholders />

Amounts are already written the way the currency writes them, so most lines need nothing else.

<Callout type="warning" title="Currency ids cannot contain an underscore">
Placeholder arguments are split at underscores, so `netherite_ingots` cannot be read this way. Name a currency with letters and digits only (`ingots`) if you want it in a scoreboard.
</Callout>

## Leaderboards

Only stored currencies with **Leaderboard** on are ranked. The board is cached for a minute and holds the first 100 places. Until a board has been read once after a start, `top_name` answers `—` and amounts answer zero while the read starts. `top_name` and `rank` answer `—` rather than nothing, so a fallback never replaces them.

```text
%exyliaeconomy_economy_top_name_1_dollars% - %exyliaeconomy_economy_top_amount_1_dollars%
%exyliaeconomy_economy_rank_shards%
```
