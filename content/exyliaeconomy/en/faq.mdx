## Is it free?

Yes. ExyliaEconomy is free and open source, under the GNU General Public License v3.0. Download it from
[GitHub releases](https://github.com/Exylia-Plugins/ExyliaEconomy/releases); the source is in the same
repository. There is no licence key and nothing to buy.

## I used the economy of ExyliaSurvivalCore. What changes?

Nothing for your players. Install ExyliaEconomy on every server before the next start, with
ExyliaSurvivalCore's folder still in place: the first start copies `database.yml`, so it opens the
database your balances are already in, then copies the currencies, the settings, the messages and the
players' menus. The commands keep their names, the old `exyliasurvivalcore.economy…` permissions still
grant the new ones, and only the placeholders change prefix, from `%exyliasurvivalcore_economy_…%` to
`%exyliaeconomy_economy_…%`. See [Migration](/docs/exyliaeconomy/migration).

## Will my shop / jobs / auction plugin see the money?

Yes, if it uses Vault and Vault is installed. One stored currency — `dollars` on a fresh server — is
published as the Vault economy. If EssentialsX or CMI is also installed, it keeps serving Vault and your
currency sits beneath it; turn **Vault on top** on in `/economyadmin` → **Economy settings**, or remove the
other economy, and import its balances first with `/economyadmin import vault dollars`. See
[Vault](/docs/exyliaeconomy/vault).

## /balance shows nothing, or the wrong currency

`/balance`, `/pay` and `/baltop` use ExyliaLib's `default-currency`, which ships as `vault`: whichever
currency serves Vault. Without Vault installed, or with another economy plugin serving it, set
`default-currency: dollars` (or your own id) in `plugins/ExyliaLib/economy.yml` and run
`/exylialib reload`.

## "Your balance is still loading"

For a moment after a player joins, their balance is being claimed from the database — and, when they came
from another server, handed over by it. Anything that would spend money waits for that. If it lasts more
than a few seconds, the database is slow or unreachable; the console says so.

## A player's balance looks wrong on another server

Check that every server has its own `server-id` under `redis` in `database.yml`. Two servers on the same
database with the default `server-1` both think they hold the player and write over each other; the console
warns about it once at start. Then check the currency is **Shared across servers**: a per-server currency
is meant to differ between servers. See [Network](/docs/exyliaeconomy/network).

## I edited a currency and the other servers did not notice

Without Redis, servers do not hear about each other's edits. Run `/economyadmin reload` on the others, or
configure Redis in `database.yml` so edits travel at once.

## The "shared across servers" switch refuses to change

It is locked as soon as the currency holds any balance other than the starting one, because those balances
would be left behind under the other key. Create a new currency with the setting you want,
`/economyadmin import` the old one into it, then delete the old one — an import adds, it does not move.

## A placeholder for xp_points or netherite_ingots shows nothing

Placeholder arguments are split at underscores, so a currency id that contains one cannot be named in a
placeholder. Use ids without underscores for anything you want on a scoreboard. See
[Placeholders](/docs/exyliaeconomy/placeholders).

## My edits to the admin menus disappeared

Everything under `lang/<code>/menus/admin/` is replaced from the jar on every start and every reload. Edit
the players' screens under `menus/user/` instead — those are yours and never overwritten.

## Can I undo what a player did?

`/economyadmin rollback <player> 1h` reverts their movements of the last hour, line by line, after a
confirmation. Payments, exchanges and banknotes are left out because their other side is somebody else's
balance or a note still in circulation. See [Ledger](/docs/exyliaeconomy/ledger#rollback).
