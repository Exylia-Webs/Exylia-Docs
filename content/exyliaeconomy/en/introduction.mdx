ExyliaEconomy is the economy of an Exylia server: currencies the server keeps itself, in its own
database, edited in game and shared across every server that points at the same database. It is free
and open source, published under the GNU General Public License v3.0 on
[GitHub](https://github.com/Exylia-Plugins/ExyliaEconomy/releases).

A server can run as many currencies as it wants — dollars, shards, gems — each with its own name,
symbol, decimals, format, starting balance, ceiling and rules. One of them can be published as the
server's **Vault** economy, so every shop, jobs or auction plugin that only speaks Vault runs on it
without EssentialsX or CMI underneath. Every Exylia plugin reaches the same currencies through
ExyliaLib, by id.

It used to be the `economy` module of ExyliaSurvivalCore. It is its own plugin now, and a server that
ran the module keeps its balances, its currencies and its permissions on the first start — see
[Migration](/docs/exyliaeconomy/migration).

## What is included

<Cards>
  <Card title="Currencies" href="/docs/exyliaeconomy/currencies">
    Stored balances, item currencies and experience, created and edited from `/economyadmin`. No
    currency file to maintain.
  </Card>
  <Card title="Payments" href="/docs/exyliaeconomy/payments">
    `/pay` with a minimum, a tax, a confirmation above an amount, a per-player toggle and a notice for
    whoever was paid while away.
  </Card>
  <Card title="Banknotes" href="/docs/exyliaeconomy/banknotes">
    `/withdraw` prints money as paper. Each note is a row in the database, so a copied note pays once.
  </Card>
  <Card title="Interest" href="/docs/exyliaeconomy/interest">
    A percentage of a balance paid at every interval, once per player across the network.
  </Card>
  <Card title="Network" href="/docs/exyliaeconomy/network">
    One balance across every server, or one per server. Only the server a player is on writes it.
  </Card>
  <Card title="Ledger and rollback" href="/docs/exyliaeconomy/ledger">
    Every movement written down with its reason, exported to CSV, and reverted line by line.
  </Card>
</Cards>

## Requirements

| Requirement | Detail |
|---|---|
| Server | Paper 1.21 or newer. Folia supported. |
| Java | 21 |
| Required dependency | `ExyliaLib` 1.236.0 or newer — installed automatically when missing |
| Optional dependencies | `Vault`, `PlaceholderAPI`, `ExyliaAnalytics` |

<Callout type="note" title="About ExyliaLib">
Typed configuration, the YAML menus, the database and Redis, placeholders, the in-game editors and the
economy facade every Exylia plugin pays through all come from ExyliaLib. ExyliaEconomy is one of the
economies that facade serves: its currencies register there, and any plugin that asks ExyliaLib for
money by id reaches them.
</Callout>

## Conventions

- Values marked as **default** are what the plugin writes the first time it starts. If the file
  already exists, your value is kept.
- Identifiers between `<` and `>` are variables. `/pay <player> <amount>` means `/pay Steve 100`.
- Amounts are typed the way players type them everywhere: `100`, `2.5k`, `1m`, `3b`. Commas are
  ignored, exponents are refused.
- A currency is named by its **id**, the lowercase key it was created with: `dollars`, `shards`.
- Colours use ExyliaLib palette tokens (`{primary}`, `{success}`, `{highlight}`); MiniMessage tags
  such as `<click>` and `<hover>` work too, as the confirmation buttons show.
