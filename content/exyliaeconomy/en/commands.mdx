Three spellings reach the same actions. `/balance`, `/pay`, `/baltop` and `/wallet` are the words every
player already knows, always on the default currency. `/economy` does everything for any currency.
Each stored currency also gets a command of its own — `/shards`. What changes somebody else's money lives
in `/economyadmin`.

A player argument accepts anybody the network knows, online, offline or on another server; suggestions
offer every name ExyliaLib has seen. A currency argument suggests only the currencies the sender may use.
Amounts are typed as `100`, `2.5k`, `1m`.

## Player commands

| Command | Aliases | Permission | What it does |
|---|---|---|---|
| `/balance [player]` | `/bal`, `/money` | `exyliaeconomy.use` | Your balance in the default currency, or somebody else's. |
| `/wallet [player]` | `/balances` | `exyliaeconomy.use` | Every currency you may use, on one screen; one line each for the console. |
| `/baltop [page]` | `/balancetop`, `/moneytop` | `exyliaeconomy.use` | The default currency's leaderboard: a screen for players, ten lines a page for the console. |
| `/pay <player> <amount> [currency] [confirm]` | | `exyliaeconomy.pay` | Sends money. `confirm` sends a payment that asked first. |
| `/paytoggle` | | `exyliaeconomy.paytoggle` | Stops receiving payments, or starts again. |
| `/withdraw <amount> [currency]` | | `exyliaeconomy.withdraw` | Turns money into a banknote. |
| `/deposit` | | `exyliaeconomy.use` | Redeems the banknote in your hand. |

Anything about another player — a balance, a wallet, a history — also needs `exyliaeconomy.others`.
`/pay`, `/paytoggle`, `/withdraw` and `/deposit` are for players only.

## /economy

`/economy` (`/eco`) needs `exyliaeconomy.use`. On its own it opens your wallet.

| Command | What it does |
|---|---|
| `/economy balance [currency] [player]` | One balance. A single word that is not a currency is read as a player, in the default currency. |
| `/economy wallet [player]` | The wallet. |
| `/economy currencies` | Every currency with its id and kind. |
| `/economy pay <player> <amount> [currency]` | The same as `/pay`; needs `exyliaeconomy.pay`. |
| `/economy top [currency] [page]` | A leaderboard. `/eco top 2` is page 2 of the default currency. |
| `/economy history [currency] [player]` | The ledger: a screen for players, the last 15 lines for the console. |
| `/economy exchange <amount> <from> <to>` | Swaps at the source currency's rate. Players only. |

The old admin spellings still work, with `exyliaeconomy.admin`, because reward and crate files on live
servers are written with them: `/eco give <player> <amount> [currency]`, `/eco take …`, `/eco set …`,
`/eco reset <player> [currency]` and `/eco import <from> <into> [again]`.

## A command per currency

Every stored currency with **Commands enabled** has a command named by its first command name, with the
rest as aliases. `/shards` stands for any of them.

| Command | Permission | What it does |
|---|---|---|
| `/shards` | `exyliaeconomy.use` | Your balance. |
| `/shards <player>` | `+ exyliaeconomy.others` | Somebody else's. |
| `/shards pay <player> <amount>` | `+ exyliaeconomy.pay` | Pays in shards. |
| `/shards top [page]` | | Its leaderboard. |
| `/shards history [player]` | | Its ledger; another player's needs `exyliaeconomy.others`. |
| `/shards exchange <amount> <to>` | | Swaps shards for another currency. Players only. |
| `/shards give\|take\|set <player> <amount>` | `exyliaeconomy.admin` | Changes a balance. |
| `/shards reset <player>` | `exyliaeconomy.admin` | Back to the starting balance. |

A currency's own permission applies on top of all of these. A wrong number of arguments answers with the
usage line. A name another plugin already registered answers as `/exyliaeconomy:<name>`.

## /economyadmin

`/economyadmin` (`/ecoadmin`, `/eadmin`) needs `exyliaeconomy.admin`. Every subcommand works from the
console except the editor itself.

| Command | What it does |
|---|---|
| `/economyadmin` | Opens the currency editor. Players only. |
| `/economyadmin give <player> <amount> [currency]` | Deposits. |
| `/economyadmin take <player> <amount> [currency]` | Withdraws; refused when a player here holds less. |
| `/economyadmin set <player> <amount> [currency]` | Sets the balance. `0` is accepted. |
| `/economyadmin reset <player> [currency]` | Back to the starting balance. |
| `/economyadmin giveall <currency> <amount> [confirm]` | Gives every player on this server the amount, after a confirmation. |
| `/economyadmin import <from> <into> [again]` | Adds every known balance of one currency to a stored one. |
| `/economyadmin currencies` | Every currency with its id and kind. |
| `/economyadmin log <player> [currency] [page]` | A player's ledger lines with their ids, ten a page. |
| `/economyadmin export <currency\|all> [days]` | Writes ledger lines to a CSV under `exports/`. |
| `/economyadmin rollback <player> <window\|#id> [currency] [confirm]` | Reverts a player's movements in a window (`1h`, `2d`) or one line (`#42`), after a confirmation. |
| `/economyadmin reload` | Reloads the files, the currencies and the menus. |

On a player who is not on this server, `give`, `take`, `set` and `reset` are queued and land where the
player is. See [Payments](/docs/exyliaeconomy/payments#admin-changes) and
[Ledger](/docs/exyliaeconomy/ledger).

### What reload does

Three named steps: `configs` (`config.yml` and `messages.yml`, then the prefix and the debug switch),
`currencies` (read again from the database, off the game thread, and the currency commands reinstalled)
and `menus` (every screen compiled again; the editor's screens are rewritten from the jar first). The
`menus` step also runs when ExyliaLib itself is reloaded, so a palette change reaches the screens.

Balances are not touched by a reload: the ones in memory stay, and the database already has them.

## What the optional arguments default to

| Argument | Default |
|---|---|
| `currency` | ExyliaLib's default currency, `default-currency` in `plugins/ExyliaLib/economy.yml`. |
| `player` | Yourself. The console must name one, or is answered with the command to type: `/economy balance <player>`. |
| `page` | `1`. |
| `days` (export) | `0`, everything. |
| `confirm` | Absent: the command asks first. |
