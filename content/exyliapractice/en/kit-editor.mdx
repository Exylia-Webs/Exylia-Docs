The kit editor lets a player rearrange a kit's own items into a named, saved layout. It never adds anything: it is the same items in a different order, which is the point on a practice server. By the end of this page players can open it, save layouts, and use them in matches.

## Before you start

- At least one kit with items: see [Kits](/docs/exyliapractice/kits).
- The lobby spawn is set: `/epc` → **Set lobby spawn**.
- You have `exyliapractice.admin`. Players need `exyliapractice.kiteditor`, which everybody holds by default.

## Steps

<Steps>
  <Step title="Set the kit editor spawn">
    Stand where players should edit, away from the busy lobby, and use `/epc` → **Set kit editor spawn**. Without it the editor refuses to open and tells the player the spawn is not set. The lobby spawn is also required: it is where they return to.
  </Step>
  <Step title="Open the editor as a player">
    Run `/kiteditor` (or `/ke`, or use the lobby hotbar item). Pick a category, then a kit. The slots screen lists the player's saved layouts and **Create new slot**.
  </Step>
  <Step title="Edit a layout">
    Click **Create new slot**, or a saved slot and then **Edit items**. The player is teleported to the kit editor spawn, set to adventure mode, and given the slot's items (the kit's defaults for a new slot). They move items around, then finish with one of:

    | Command | What it does |
    |---|---|
    | `/ke save` | Saves the inventory into the slot, returns to the lobby and reopens the slots screen |
    | `/ke cancel` | Discards the changes and returns to the lobby |
    | `/ke reset` | Puts the kit's default items back, without leaving |

    The chat message that opens the session has **Save** and **Cancel** buttons you can click instead of typing.
  </Step>
  <Step title="Rename, re-icon or delete a slot">
    On the slots screen, click a saved slot to open its management screen: **Edit name**, **Edit icon**, **Edit items** and **Delete slot**. Deleting asks for confirmation.
  </Step>
  <Step title="Sell more slots with a permission">
    Give ranks the node below. The highest number among the nodes a player holds wins, so `max_slots.5` on top of `max_slots.1` is an upgrade, not a conflict.

    ```
    exyliapractice.kits.max_slots.<n>
    ```

    With no node at all the player still gets one slot. The permission only sells more.
  </Step>
</Steps>

<Callout type="warning" title="Only a rearrangement can be saved">
On save, the layout is checked against the kit's items. If an item was added, picked up, eaten or left in the crafting grid, the save is refused, a message says so, and the player stays in the editor to fix it. Nothing is lost, and a bad layout is never handed out in matches.
</Callout>

## Check that it works

- `/ke` opens the category list. If it says a spawn is not set, redo step 1.
- Saving returns the player to the lobby with the slots screen open and the new slot listed.
- Queue or duel with that kit: with one slot it is used silently, with two or more a **slot picker** opens and the player chooses. See below.

## Going further

<Details title="Which slot a match uses">
Decided when the kit is handed out, from how many slots the player has for that kit:

| Slots saved | What happens |
|---|---|
| 0 | The kit's own default loadout |
| 1 | That slot, silently |
| 2 or more | A slot picker opens and the player chooses |

If the countdown ends before they choose, the first slot is used, so nobody starts with an empty inventory.
</Details>

<Details title="Where the editor cannot be used">
`/ke` needs the player to be free: not queued, in a match, spectating, in a party or inside a PvP zone. While editing, the player is claimed and cannot be queued, challenged or taken by another system. If they leave the server mid-edit, the session is dropped.
</Details>

<Details title="Storage and clearing layouts">
A slot is a row in `practice_player_kits`: a player, a kit, an index, a name, an icon and 41 item positions. From `/epc` → **Data management**, **Clear kit loadouts** deletes every player's slots for one kit. It is irreversible and asks for confirmation.

One player's slots for one kit go with `/epc kits clear <player> <kit>`. Every kit of one player goes with ExyliaLib's `/exylialib resetplayer`, and every slot of every player with `/exylialib wipe ExyliaPracticeCore practice_player_kits`. See [Database](/docs/exyliapractice/database).
</Details>
