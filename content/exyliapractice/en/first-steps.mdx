You will end with a kit and an arena that two players can queue into, ranked or unranked, and play to the end. Everything is built from the admin menu: `/epc` opens it, so there are no setup commands to memorise.

## Before you start

- ExyliaPracticeCore is installed and the server has booted once: see [Installation](/docs/exyliapractice/installation).
- You have `exyliapractice.admin` (operators do).
- The lobby spawn is set: `/epc` → **Set lobby spawn**. Players return there after every match.

## Steps

<Steps>
  <Step title="Create a category">
    Kits are grouped in categories, and every player screen (queue, duels, parties, stats, history) opens on the category list first. You need at least one.

    Run `/epc`, click **Manage kits**, then **Categories**, then **Create**. Chat asks for an id, then a display name.
  </Step>
  <Step title="Create a kit">
    **Manage kits** → **All kits** → **Create**. The kit screen has ten buttons:

    | Button | What it sets |
    |---|---|
    | **Name** / **Icon** / **Description** | How the kit looks in menus |
    | **Status** | Enabled. A disabled kit is invisible everywhere. |
    | **Categories** | Which categories list it. Pick the one you just made. |
    | **Compatible arenas** | Which arenas it may be played in |
    | **Loadout** | The items: armour, offhand, inventory and hotbar |
    | **Kit rules** | [40+ toggles and numbers](/docs/exyliapractice/kit-rules) |
    | **Playability & ranked** | Where the kit may be used. Turn on **Queue**, and **Ranked** if you want ELO. |
    | **Priority** | Sort order in menus |

    Fill **Loadout** with a sword, armour and food, then set **Status** to enabled.
  </Step>
  <Step title="Create an arena">
    `/epc` → **Manage arenas** → **Create**. Chat asks for an id and a display name, then the arena setup screen opens. Set, in this order:

    1. **Spawn 1** and **Spawn 2**: where the two sides start. Both are required.
    2. **Playable region**: a selection wizard. This is the area a match happens in. Stepping outside it kills you.
    3. **Copy region**: a second, larger selection with the walls and floor. It is what [clones](/docs/exyliapractice/clones) are pasted from.
    4. **Status**: enable it. The arena refuses to enable while something is missing, and tells you what.

    The regions save their schematics as soon as you set them.
  </Step>
  <Step title="Link the kit to the arena">
    On the kit, open **Compatible arenas** and pick your arena. It is one list, so it also shows from the arena's **Kits** button.
  </Step>
  <Step title="Queue and play">
    Go to the lobby and run `/queue`. Pick the category, then the kit. When a second player queues for the same kit, both of you are teleported to the arena and the match starts. For a match without matchmaking, one player runs `/duel <player>` and the other accepts.

    The match ends when one side wins. ELO moves only if the kit has **Ranked** on.
  </Step>
</Steps>

<Callout type="warning" title="Two accounts on one IP will never match">
The anti-boost check refuses to match two players from the same address, and it is on by default. When testing alone, use two real connections, use `/duel`, or set `elo-security.same-ip-protection` to `false` while you work.
</Callout>

## Check that it works

- `/queue` lists your category and the kit. If it does not, the kit is disabled, has no category, or **Queue** is off.
- Two players queueing for the kit get put into the arena together. If they keep waiting, see [Common problems](/docs/exyliapractice/troubleshooting).
- After the match, both players are back at the lobby and `/stats` shows the result.

Optional on the arena screen: **Spectator spawn**, **Party FFA spawn**, **Extra regions**, **Spawn protection** and **Extra region protection**.
