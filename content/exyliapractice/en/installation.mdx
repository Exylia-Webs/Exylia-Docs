## Requirements

| Requirement | Detail |
|---|---|
| Server | Paper 1.21 or newer. Folia supported. |
| Java | 21 |
| Required | `ExyliaLib`, `FastAsyncWorldEdit`, `packetevents` |
| Optional | `PlaceholderAPI`, `ViaVersion`, `Worlds`, `Apollo`, `FeatherServerAPI`, `floodgate` |

<Callout type="warning" title="FastAsyncWorldEdit and packetevents are hard dependencies">
Both are listed under `depend`, not `softdepend` — the server refuses to load the plugin without either.
Cloning an arena is a schematic paste and regenerating one is a schematic restore; neither has a
fallback.
</Callout>

## Install

<Steps>
  <Step title="Drop in the dependencies">
    `ExyliaLib`, `FastAsyncWorldEdit` and `packetevents` in `plugins/`. ExyliaLib must be the same copy every Exylia
    plugin sees — never shade it, never run two.
  </Step>
  <Step title="Drop in the jar">
    `ExyliaPracticeCore` in `plugins/` and restart. The plugin ships through the Lukittu loader, so
    the file you install is the loader jar. Bought on BuiltByBit, the licence is embedded in that jar:
    there is no key to enter.
  </Step>
  <Step title="Let it generate">
    First boot writes the files below and creates the clone world. Nothing is playable yet — there is
    no arena and no kit.
  </Step>
  <Step title="Give yourself the admin node">
    `exyliapractice.admin` is the only node an operator needs. `/epc` then opens the admin menu.
  </Step>
  <Step title="Set the lobby spawn">
    `/epc` → **Data Management** → **Set Lobby**. Until this is set, `teleportToLobby` does nothing
    and players stay wherever they log in.
  </Step>
</Steps>

## What gets generated

| Path | What it is |
|---|---|
| `config.yml` | Every setting: language, arenas, queue, ELO, party, duel, lobby, jumpads, web API, chat, borders, replays. [Reference](/docs/exyliapractice/configuration) |
| `ranks.yml` | The nine ranks, their divisions and their K-factors. [Reference](/docs/exyliapractice/elo) |
| `lang/<language>/messages.yml` | 33 sections of player-facing text, titles, action bars and boss bars included |
| `lang/<language>/scoreboards.yml` | 19 sidebars. [Reference](/docs/exyliapractice/scoreboards) |
| `lang/<language>/items/lobby.yml` | The lobby hotbar |
| `lang/<language>/items/party.yml` | The hotbar while in a party |
| `lang/<language>/items/queue.yml` | The hotbar while queued |
| `lang/<language>/overlays/replay.yml` | The hotbar a replay viewer drives the playback from |
| `lang/<language>/menus/admin/**` | 34 admin screens |
| `lang/<language>/menus/player/**` | 31 player screens |

`<language>` is what `language` in `config.yml` resolves to. English, Spanish, Portuguese, French and
Russian ship complete; see [Configuration](/docs/exyliapractice/configuration#language).

<Callout type="note" title="Which files you can edit">
`config.yml`, `messages.yml` and `scoreboards.yml` are generated from typed records and keep your
values. The **admin** screens are rewritten from the jar on every start, so a screen added or changed
in a release always reaches the server — do not edit them. The **player** screens, the hotbar items
and the replay controls are yours: a file you have not touched is updated, one you edited is kept and
the new version is offered next to it.
</Callout>

## The clone world

Clones are pasted into ExyliaLib's shared temporary world, `exylialib_temporary`: void, no structures,
no mobs, no weather, frozen at noon, no random ticks and no autosave. It is created the first time a
clone is needed, every plugin that pastes arena copies shares it, and its folder is deleted when
ExyliaLib starts and again when it stops. It holds nothing worth keeping: every clone is re-pasted from
the arena's schematic on demand.

<Callout type="note" title="On Folia the world comes from the Worlds plugin">
Folia cannot create a world through `WorldCreator`, so the library asks
[Worlds](https://repo.thenextlvl.net) instead. Without it there is no temporary world: no arena can be
cloned, and a match that finds every copy of its arena busy sends its players back to the lobby.
Install Worlds on Folia.
</Callout>

## Load order and what needs the database

The plugin reads its arenas, kits, seasons and settings out of the database ExyliaLib is configured
with. Configure that first — see the [ExyliaLib database docs](/docs/exylialib/database). The 17
tables are created automatically; they are listed [here](/docs/exyliapractice/database).

On the very first boot with an existing pre-season database, a one-shot migration copies every row of
`practice_player_stats` into season 1 and into the lifetime tier. It runs in the background, is
resumable, and only ever reads the legacy table.
