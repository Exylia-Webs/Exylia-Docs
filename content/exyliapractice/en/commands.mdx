## Admin commands

The staff root is `/practiceadmin`. `/exyliapracticecore` and `/epc` are aliases, so every `/epc ...` in these docs is the same as `/practiceadmin ...`.

### ELO boosts

Durations are `1d`, `12h`, `30m`, `90s`, or combinations like `1d12h`. The multiplier must be above 1. See [ELO and ranks](/docs/exyliapractice/elo#boosts).

### Statistics

To clear every kit of a player, or all of their data, use [`/exylialib resetplayer`](/docs/exylialib/commands). In game, the admin menu's **Data management** → **Player data** also looks up one player to view and edit their stats per kit.

## What reload does

`/epc reload` runs five steps. One that fails is reported by name while the rest still run.

| Step | Re-reads |
|---|---|
| `configs` | `config.yml`, `messages.yml`, `scoreboards.yml`, and the message prefix |
| `ranks` | `ranks.yml` |
| `lobby-items` | `items/lobby.yml`, `items/party.yml`, `items/queue.yml` |
| `scoreboards` | Shows every sidebar again from the layouts just re-read |
| `menus` | Every menu file |

The `menus` step also runs on `/exylialib reload`, because a compiled menu holds parsed items and a colour change would otherwise leave every screen on the old colours.

<Callout type="note" title="What a reload does not re-read">
Arenas, kits and categories live in the database, not in a file, and are always live. `duel.request-expiry-seconds` is read once at startup and needs a restart. Everything else in `config.yml` is read fresh on every access, so a reload is enough.
</Callout>

## Command whitelist

While a player is **in a match**, **queued**, or **inside a PvP zone**, only the commands listed in `command-whitelist.commands` are allowed. Anything else is cancelled with a message.

The shipped list is:

```
msg  message  tell  w  whisper
reply  r  respond
leave  lq  leavequeue
practiceadmin  epc  exyliapracticecore  kitsave
```

A command matches by its own name or by a `plugin:command` form of it. `exyliapractice.bypass.command-whitelist` skips the check, and `command-whitelist.enabled: false` turns the whole thing off. `/party cancelgame` (or `/p cancelgame`) is always let through, so a party leader can end a match whatever the list says.
