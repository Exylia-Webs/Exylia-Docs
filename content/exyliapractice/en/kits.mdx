You will end with a kit players can pick: a loadout, the arenas it is played in, a category that lists it and the places it is allowed (queue, duels, parties, ranked). A kit is a row in `practice_kits`; its [rules](/docs/exyliapractice/kit-rules) are stored on the same row.

## Before you start

- You have `exyliapractice.admin` (operators do).
- An arena to play it in is optional while you build the kit, but a kit with none cannot start a match: see [Set up arenas](/docs/exyliapractice/arenas).

## Steps

<Steps>
  <Step title="Create a category">
    Every player-facing kit screen opens on the category list first, so a kit needs one. Run `/epc`, click **Manage kits**, then **Categories**, then **Create**. Chat asks for an id, then a display name. On the category screen set **Name**, **Icon**, **Description**, **Status** and **Priority**.
  </Step>
  <Step title="Create the kit">
    **Manage kits** → **All kits** → **Create**. Chat asks for an id, then a display name. The kit screen (titled **KIT: your-id**) opens.
  </Step>
  <Step title="Fill the loadout">
    Left click **Loadout** to open the grid, laid out the way a player reads an inventory: armour, offhand, inventory and hotbar. Right click **Loadout** to receive the kit in your own inventory.
  </Step>
  <Step title="Pick categories and arenas">
    **Categories** and **Compatible arenas** list every category and arena; click one to toggle it. A kit can be in several categories. The arena list is the same one as the arena's **Kits** button.
  </Step>
  <Step title="Choose where it can be played">
    Click **Playability & ranked** and set the switches (see below). Turn on **Queue**, and **Ranked** if you want ELO to move.
  </Step>
  <Step title="Enable it">
    Click **Status**. A disabled kit is skipped everywhere, including by a match that was already being set up.
  </Step>
</Steps>

## Check that it works

- `/queue` lists the category, then the kit. If it does not, the kit is disabled, has no category, or **Queue** is off.
- `/duel <player>` offers the kit when **Duel** is on.
- Starting a match gives you the loadout you placed. If the kit has no compatible arena, players are told there are no arenas available.

## The kit screen

`/epc` → **Manage kits** → **All kits** → a kit.

| Button | What it sets |
|---|---|
| **Name** | Display name |
| **Icon** | The material shown in menus |
| **Status** | Enabled. A disabled kit is skipped everywhere. |
| **Description** | Lore |
| **Categories** | Toggle each category on or off |
| **Compatible arenas** | Toggle each arena on or off |
| **Loadout** | Left click opens the loadout grid; right click hands you the kit. |
| **Kit rules** | [The rules screen](/docs/exyliapractice/kit-rules) |
| **Playability & ranked** | The six switches below, and **Bot practice**, which links the kit to a bot combat mode. See [Bot PvP](/docs/exyliapractice/bot-pvp) |
| **Priority** | Sort order |

Kits and categories are drawn in priority order. It is a plain integer with no special meaning beyond sorting: left click adds 1, right click removes 1, Shift adds or removes 10. Set the ones you want at the top of `/queue` higher.

## Playability

Six independent switches decide where a kit may be used:

| Switch | Effect when off |
|---|---|
| **Queue** | Not offered in `/queue` |
| **Duel** | Not offered in `/duel` |
| **Party FFA** | Not offered for a party free-for-all |
| **Party split** | Not offered for split teams |
| **Party duel** | Not offered when one party queues against another |
| **Ranked** | Matches are played, ELO is not applied |

<Callout type="note" title="Ranked is not the same as queue">
A kit can be queueable and unranked, a fun kit that people want to matchmake without touching their rating. It can also be ranked and duel-only, which makes `/duel` the only way to gain LP with it.
</Callout>

## Categories

Categories are rows in `practice_kit_categories` and they exist for one reason: queue, duels, party games, stats, leaderboards, match history and the kit editor all page through categories before they show a kit.

| Button | What it does |
|---|---|
| **Name** | The label in menus |
| **Icon** | The material shown |
| **Description** | Lore under the name |
| **Status** | A disabled category is hidden everywhere |
| **Manage kits** | Pick which kits belong to this category |
| **Priority** | Sort order |

Right click a category in the list to delete it. Deleting a category rewrites every kit that named it, so no kit is left pointing at a filter that matches nothing.

## Going further

### Compatible arenas

A kit with no compatible arenas cannot start a match at all: players are told there are no arenas available. A kit with several picks a free instance from any of them, preferring one that is already pasted over cloning a new one.

For a duel the player may name a preferred arena; it is moved to the front of the list and the rest is shuffled behind it, so a preferred arena that is busy still falls back rather than failing.

### The loadout

41 slots: 36 inventory, 4 armour, 1 offhand. Whatever you place is what every player is handed at the start of a match, before their own [kit editor slot](/docs/exyliapractice/kit-editor) rearranges it.

<Callout type="warning" title="Leather armour and coloured blocks are recoloured per team">
In a party split or a party duel, the kit is dyed on the way in: leather armour takes the team colour and any block whose material name starts with a Minecraft colour (`RED_WOOL`, `BLUE_CONCRETE`, and so on) is swapped for the team's version. Team A is red, team B is blue. In a 1v1 or an FFA nothing is recoloured.
</Callout>

<Details title="Deleting a kit">
Right click the kit in the list and confirm. Deleting removes the row. Player loadouts saved against that kit id in `practice_player_kits` are not removed by the delete; clear them from **Data management** → **Clear kit loadouts** if you want them gone.
</Details>
