Find your symptom, then follow the fix. Questions about stats, seasons and the website are in the [FAQ](/docs/exyliapractice/faq).

## The plugin does not start

The console names what is missing. FastAsyncWorldEdit and packetevents are required. ExyliaLib is installed by the loader jar. See [Installation](/docs/exyliapractice/installation).

## `/queue` says there are no arenas available

The kit's **Compatible arenas** list is empty, or every arena in it is disabled or not fully configured. Open the kit and check the list, then open each arena and look at **Status**: it names what is missing. See [Play your first match](/docs/exyliapractice/first-steps).

## An arena refuses to enable

The arena lists what it lacks: Spawn 1, Spawn 2, Playable region, Copy region or a schematic. If a schematic is missing even though you set the regions, FastAsyncWorldEdit is not installed or did not load: a server without it always answers that the file does not exist. The real reason is logged once at startup. See [Arenas](/docs/exyliapractice/arenas).

## My two test accounts never get matched

Same-IP protection refuses to pair two players from one address, and it is on by default. Set `elo-security.same-ip-protection` to `false` while you test, or use `/duel <player>`, which does not check it.

## Nothing teleports to the lobby

The lobby spawn is not set. Run `/epc` and click **Set lobby spawn**. The kit editor has its own: **Set kit editor spawn**, on the same menu.

## I edited a config and nothing changed

Run `/epc reload`. It re-reads the config files, `ranks.yml`, the `items/` files and every menu. It cannot pick up arenas and kits, which live in the database and are already live, or `duel.request-expiry-seconds`, which needs a restart. If a step fails, the reload names it and still runs the rest. See [Commands](/docs/exyliapractice/commands#what-reload-does).

## Players cannot run commands in a match

While a player is in a match, queued or inside a PvP zone, only the commands in `command-whitelist.commands` work. Add the command to the list, give staff `exyliapractice.bypass.command-whitelist`, or set `command-whitelist.enabled` to `false`. See [Commands](/docs/exyliapractice/commands#command-whitelist).

## Blocks are not restored between matches

Regeneration only runs when the kit allows building or block breaking. If it does and blocks still stay, press **Schematic** on the arena again: a regeneration restores the saved file, not what is standing. See [Clones and regeneration](/docs/exyliapractice/clones).

## Arenas are never cloned on Folia

Folia cannot create a world through Bukkit, so without the Worlds plugin there is nowhere to paste clones, and a match whose arena is busy sends its players back to the lobby. Install Worlds and restart.

## Nobody can spectate a match

One of the players in it has spectators turned off in `/settings`, and one player's choice covers the whole match. Staff with `exyliapractice.spectate.bypass` can still watch. If nobody has it off, the arena needs a **Spectator spawn**. See [Spectating](/docs/exyliapractice/spectating).

## A placeholder shows as text

The placeholder is written wrong, or PlaceholderAPI is not installed. Copy the full name from [Placeholders](/docs/exyliapractice/placeholders). A leaderboard placeholder shows `-` for a moment while the board loads, and `---` when nobody holds that position.

## A player has fewer loadout slots than I gave them

Everybody gets one slot with no node, and `exyliapractice.kits.max_slots.<n>` counts up to the highest node the player holds. Check the player's groups and any wildcard. See [Permissions](/docs/exyliapractice/permissions).
