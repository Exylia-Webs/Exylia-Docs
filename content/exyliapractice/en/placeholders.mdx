Placeholders let you show a player's stats, rank, leaderboard and live counts in scoreboards, holograms, tab lists and chat. They need [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) for other plugins to read them; the plugin's own sidebars and menus read them without it.

Every placeholder is written in full, and clicking one copies it. The short identifier `practice` answers the same names, so `%practice_stats_elo%` and `%exyliapracticecore_stats_elo%` are the same placeholder.

## The player's stats

All of these read the player's **global** row for the current season.

## Rank

<Placeholders group="rank" />

`%exyliapracticecore_stats_rank_position%` reads the leaderboard cache and never waits on the database. It answers `-` while the board is loading, and `#51+` (one past `leaderboard.max-entries`) for anybody outside the board.

## Leaderboards

<Placeholders group="leaderboard" />

Positions run from **1 to 10**; anything else answers nothing. These read the **global** leaderboard. A board that has not been loaded yet answers `-` and warms itself in the background, so a hologram fills in on its second render rather than stalling the first. A position nobody holds yet answers `---`.

```
%exyliapracticecore_stats_top_kills_1%              → the top killer's name
%exyliapracticecore_stats_top_kills_1_value%        → their kill count
%exyliapracticecore_stats_top_win_rate_3_value%     → third place's win rate
%exyliapracticecore_stats_top_rank_1_value%         → the top player's rank and LP
```

## Placeholders from other plugins

Sidebars and menus in this plugin resolve the whole server's placeholders, not just its own. The shipped lobby sidebar uses `%exyliaffa_total_players%` and `%exyliasandbox_total_players%`. Remove those lines if you do not run those plugins, or they render as raw text.
