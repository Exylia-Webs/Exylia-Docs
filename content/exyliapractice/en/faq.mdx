## Setup

### `/queue` says there are no arenas available

The kit's **compatible arenas** list is empty, or none of the arenas in it is enabled and fully set up. A kit that lists no arenas is never offered one. Open the kit and check the list, then open each arena and read its status. See [Kits](/docs/exyliapractice/kits) and [Arenas](/docs/exyliapractice/arenas).

### Nothing teleports players to the lobby, or `/ke` refuses to open

The lobby spawn is not set, and the kit editor also needs its own spawn. Run `/epc` and set both. See [Installation](/docs/exyliapractice/installation) and [Kit editor](/docs/exyliapractice/kit-editor).

### My two test accounts never get matched

Same-IP protection. Set `elo-security.same-ip-protection` to `false` while you test, or use `/duel`, which does not run that check. See [ELO and ranks](/docs/exyliapractice/elo).

## Running it

### I edited a config and nothing changed

Run `/epc reload`. It re-reads the config files, `ranks.yml`, the lobby item files, the scoreboards and every menu. Arenas and kits are not touched, and `duel.request-expiry-seconds` is read once, so it needs a restart. See [Configuration](/docs/exyliapractice/configuration).

### Ender pearls have a huge cooldown

The `ender-pearl-cooldown` kit rule is in seconds, so `16` means sixteen seconds. See [Kit rules](/docs/exyliapractice/kit-rules).

### Clones are eating the server

Lower `arena.max-clones-per-arena`; each clone is a permanent copy of the arena. See [Clones](/docs/exyliapractice/clones).

## Gameplay

### A player's points are stuck at zero

The `LOSS_POINT` special condition never takes a player below zero. See [Special conditions](/docs/exyliapractice/special-conditions).

### A match has no spectators

Spectating is a per-player setting: a fighter with **spectators** turned off in their settings keeps the match closed. See [Spectating](/docs/exyliapractice/spectating).

### Hits to win seems backwards

It counts hits received, not dealt: a player is eliminated after taking that many hits. See [Kit rules](/docs/exyliapractice/kit-rules).

## Stats and ELO

### Did a season rotation delete everybody's stats?

No. A rotation closes the current season and opens a new one; the old rows stay in the database. See [Seasons](/docs/exyliapractice/seasons) and [Database](/docs/exyliapractice/database).

### A high-rated player loses very few points

That is the asymmetric reduction, which applies when a loss comes with a large rating gap. The thresholds are in `elo.*`. See [ELO and ranks](/docs/exyliapractice/elo#the-asymmetric-reduction).

### Two players farm each other with duels

The anti-boost checks run in matchmaking, and `/duel` bypasses them. See [Duels](/docs/exyliapractice/duels).

## Integration

### Matches are not reaching the website

Matches wait in an outbox table and are retried with backoff, so nothing is lost while the web API is down. Check that `web-api.enabled` is `true` and the key is set, then restart. See [Web API](/docs/exyliapractice/web-api).
