`config.yml` is version 4 and carries the `language` key and twenty sections. Every one is generated on
first boot with the defaults below.

Every value here is read fresh on each access, so `/epc reload` is enough to apply an edit — with the
one exception noted under `duel` below.

<Callout type="note" title="The text a player reads lives in messages.yml">
Titles, action bars, boss bars and item names are not in this file. They sit in the language's
`messages.yml`, under `effects` (`countdown-title`, `fight-title`, `you-won-title`, `you-lost-title`,
`draw-title`, `match-actionbar`, `bot-actionbar`, `in-queue-actionbar`, `match-found-title`,
`match-found-actionbar`, `teaser-bossbar`, `round-won-title`, `round-lost-title`, `round-draw-title`,
`combat-tag-bossbar`, `season-progress-bossbar`) and `labels` (`spectators-hidden`,
`spectators-visible`). A server coming from version 2 has its edited blocks moved there on the first
start, so nothing it wrote is lost.
</Callout>

## `language`

```yaml
language: default
```

Which folder under `plugins/ExyliaPracticeCore/lang/` the menus, messages, scoreboards, hotbar items
and replay controls are read from. `default` follows the `language` set in ExyliaLib's own
`config.yml`; `en`, `es`, `pt`, `fr` or `ru` set this plugin alone. A server that ran the plugin before
languages existed has its own files moved to `lang/custom/` and is pointed at it with
`language: custom`, so nothing it edited is lost.

## `chat`

| Key | Default | What it does |
|---|---|---|
| `isolation` | `true` | Keep a match's chat inside that match: whoever is fighting or watching it reads that match and nothing else, party members always read each other, and the lobby reads none of it. `false` leaves chat as the server's chat plugin delivers it. |

## `world-border`

| Key | Default | What it does |
|---|---|---|
| `enabled` | `true` | Draw a border around arenas and combat-tagged PvP zones. It is only drawn: `false` saves client FPS in small arenas, and arena bounds are still enforced. |

## Migration from ExyliaCommons

A `config.yml` with no `config-version` is treated as version 1 — the ExyliaCommons layout — and
migrated in place. Every title, action bar and boss bar block is moved into the nested section the
library expects, title durations are converted from ticks to seconds, and the obsolete
`%time_decimal%` token is rewritten to `%time%`.

The six sections ExyliaCommons registered against this same file — `debug`, `formatters`, `text`,
`tasks`, `chat-input`, `discord` — were the library's own settings and are removed on first load, each
reported once as `UNKNOWN_KEY`. They live in ExyliaLib's files now.
