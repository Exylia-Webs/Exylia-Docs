## The permission path

<Steps>
  <Step title="Let players open the menu">
    ```text
    /lp group default permission set exyliaemotes.command.emote true
    ```
    Without this `/emote` cannot be run at all — and a player who cannot see the catalogue cannot want
    anything in it.
  </Step>
  <Step title="Give them something to perform">
    ```text
    /lp group default permission set exyliaemotes.emote.wave true
    /lp group vip permission set exyliaemotes.category.meme true
    ```
    One emote for everybody, a whole tab for a rank.
  </Step>
  <Step title="Open it">
    `/emote`. The tabs are down the left, the emotes beside them, and the first tab is the player's
    own favourites.
  </Step>
  <Step title="Click one">
    Left click closes the window and performs it. The player watches from the camera; any key, any
    click or a hit ends it.
  </Step>
</Steps>

<Callout type="note" title="The chat way">
`/emote play wave` performs the same emote without the menu, and tab completion only offers the ones
the player owns. `/emote list` prints them.
</Callout>

## The crate path

<Steps>
  <Step title="Put the crate somewhere">
    ```text
    /emotesadmin crate block add
    ```
    Binds the block you are looking at, so clicking it opens the crate. The button in the menu and
    `/emote crate` open the same screen.
  </Step>
  <Step title="Hand over a key">
    ```text
    /emotesadmin keys give <player> 1
    ```
    Every new player already starts with one (`crate.start-keys`). For a key they can hold, sell and
    give away instead, `item key <player> 1`.
  </Step>
  <Step title="Open it">
    One key, one reel. What comes out is theirs for good — see
    [The crate](/docs/exyliaemotes/crate).
  </Step>
</Steps>

## A duet

<Steps>
  <Step title="Invite somebody">
    ```text
    /emote play handshake Steve
    ```
    Steve has to be within `duet.max-distance` blocks — three by default.
  </Step>
  <Step title="They accept">
    Steve clicks **Accept** in chat, types `/emote accept`, or right-clicks whoever invited him.
  </Step>
  <Step title="Both bodies start on the same tick">
    Placed on the line between them and turned towards each other, so the hands meet in the middle.
  </Step>
</Steps>

Both players must be able to perform it: owning it, off cooldown, out of combat, in a world that
allows emotes. See [Duets](/docs/exyliaemotes/duets).

## Checking it works

| Question | How to answer it |
|---|---|
| Is the emote there? | `/emote preview <id>` plays it on the preview stage. Set one first with `/emotesadmin preview location`. |
| Does a player own it? | `%exyliaemotes_owns_<id>%`, or have them run `/emote list`. |
| Is somebody stuck? | `/emotesadmin cancel <player>` ends their emote; with no player, everybody's. |
| Did the file load? | A mistake in `emotes.yml` is logged with the entry it came from, and the rest still loads. |
