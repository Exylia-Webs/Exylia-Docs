At the end of this page one player performs an emote from the menu, watched from a camera outside their body. You only use LuckPerms (or your permissions plugin) and a few commands.

## Before you start

Install the plugin, including PacketEvents. See [Install ExyliaEmotes](/docs/exyliaemotes/installation). Nobody except operators owns an emote until you grant one, so an op can test right away and everyone else needs step 1.

## Steps

<Steps>
  <Step title="Give everybody an emote">
    ```text
    /lp group default permission set exyliaemotes.emote.wave true
    ```
    That gives the default group Wave. To give a rank a whole tab, use `exyliaemotes.category.meme`. See [Permissions](/docs/exyliaemotes/permissions).
  </Step>
  <Step title="Open the menu">
    Run `/emote`. The tabs are on the left, the emotes beside them, and the first tab is the player's own favourites. Emotes the player does not own are shown locked.
  </Step>
  <Step title="Perform it">
    Left click **WAVE**. The window closes, the player is hidden and an animated body waves while the camera shows it from outside. A click, a key press or a hit ends it. In chat, `/emote play wave` does the same and `/emote list` prints what the player owns.
  </Step>
  <Step title="Set a preview stage (optional)">
    Right click an emote in the menu to preview it, even a locked one. Run `/emotesadmin preview location` and confirm where you stand first, or the preview answers that it is unavailable.
  </Step>
</Steps>

## Check that it works

Run `/emote play wave` as a player who owns it. You should see the body from the outside. Another player nearby sees it too. `/emote cancel` ends it. If nothing happens, read [Common problems](/docs/exyliaemotes/troubleshooting).

## Going further

### Open a crate

Run `/emotesadmin crate block add` and confirm the block. Clicking it now opens the crate. Every new player already starts with one key; give more with `/emotesadmin keys give <player> 1`, or a key item with `/emotesadmin item key <player> 1`. What comes out stays theirs. See [The crate](/docs/exyliaemotes/crate).

### Try a duet

Run `/emote play handshake <player>`. The other player has to be within three blocks (`duet.max-distance`). They click **Accept** in chat or run `/emote accept`, and both bodies start together. Both must own the emote. See [Duets](/docs/exyliaemotes/duets).
