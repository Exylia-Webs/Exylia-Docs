---
title: "Placeholders"
description: "What a player owns and is performing, their keys, and any emote's fields by id."
---

Registered with PlaceholderAPI under the identifier `exyliaemotes` when PlaceholderAPI is installed.
Every placeholder below is written in full, and clicking one copies it.

## About the player

| Placeholder | Description |
|---|---|
| `%exyliaemotes_owned_count%` | How many emotes they may perform, by permission or unlock. |
| `%exyliaemotes_unlocked_count%` | How many emotes the crate has unlocked for them. |
| `%exyliaemotes_keys%` | How many crate keys they hold on their account. |
| `%exyliaemotes_favourites_count%` | How many emotes they have starred. |
| `%exyliaemotes_owns_<id>%` | `true` or `false` for one emote — `%exyliaemotes_owns_wave%`. |
| `%exyliaemotes_favourite_<id>%` | `true` or `false` for one emote — `%exyliaemotes_favourite_wave%`. |
| `%exyliaemotes_favorite_<id>%` | The same answer, without the `u`. |
| `%exyliaemotes_playing%` | `true` while they are performing an emote, `false` otherwise. |
| `%exyliaemotes_playing_id%` | The id of what they are performing. |
| `%exyliaemotes_playing_name%` | Its display name. |

## About the server

These answer without a player, so they work in a hologram.

| Placeholder | Description |
|---|---|
| `%exyliaemotes_catalogue_count%` | How many emotes the server declares. |
| `%exyliaemotes_total%` | The same count, under the shorter name. |
| `%exyliaemotes_playing_count%` | How many emotes are being performed right now. A duet counts once. |

## About one emote

`%exyliaemotes_emote_<id>_<field>%` answers about any emote by id, whoever is asking — which is what
lets a menu in another plugin draw a row for an emote it knows nothing about.

| Placeholder | Description |
|---|---|
| `%exyliaemotes_emote_<id>_name%` | Its display name — `%exyliaemotes_emote_wave_name%`. |
| `%exyliaemotes_emote_<id>_id%` | Its id. |
| `%exyliaemotes_emote_<id>_description%` | Its description, on one line. |
| `%exyliaemotes_emote_<id>_material%` | The material it is drawn with. |
| `%exyliaemotes_emote_<id>_category%` | Its tab's id. |
| `%exyliaemotes_emote_<id>_kind%` | `solo` or `duet`. |
| `%exyliaemotes_emote_<id>_tier%` | Its rarity's id. |
| `%exyliaemotes_emote_<id>_tier_name%` | The rarity's display name. |
| `%exyliaemotes_emote_<id>_tier_color%` | The colour that rarity is written in. |
| `%exyliaemotes_emote_<id>_tier_colour%` | The same colour, with the `u`. |

An id that names no emote, or a field that is not in the table, answers `placeholders.unknown` —
`Unknown` by default.

<Callout type="warning" title="Ids with an underscore cannot be reached here">
The id is read up to the first `_` after `emote_`, so `%exyliaemotes_emote_six_seven_name%` asks for an
emote called `six` and answers `Unknown`. The thirteen shipped ids with an underscore — `thumbs_up`,
`blow_kiss`, `point_laugh`, `sip_tea`, `slow_clap`, `air_guitar`, `six_seven`, `robot_walk`,
`default_dance`, `take_the_l`, `orange_justice`, `nae_nae`, `chicken_dance` — have no working
`emote_<id>_<field>` placeholder. `%exyliaemotes_owns_<id>%` and `%exyliaemotes_favourite_<id>%` read the whole rest of the name and
are not affected.
</Callout>

## With nothing to answer

| Case | Answer |
|---|---|
| A player placeholder asked with no player | `placeholders.none` — `None` by default |
| `%exyliaemotes_playing_id%` or `%exyliaemotes_playing_name%` while nothing is playing | `placeholders.none` |
| `%exyliaemotes_owns_<id>%` for an id that names no emote | `false` |
| Any other name this plugin does not know | Left untouched, as PlaceholderAPI does |

```yaml
lines:
  - " {muted}❙ {letters}Emotes: {highlight}%exyliaemotes_owned_count%{muted}/%exyliaemotes_catalogue_count%"
  - " {muted}❙ {letters}Keys: {highlight}%exyliaemotes_keys%"
  - " {muted}❙ {letters}Now: {highlight}%exyliaemotes_playing_name%"
```
