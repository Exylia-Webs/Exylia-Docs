Por defecto todos pueden abrir `/emote`, pero nadie salvo los operadores tiene un emote hasta que le concedes uno. Usa esta página para decidir quién recibe qué.

## Todos los permisos

<Permissions />

`exyliaemotes.cooldown.<segundos>` y `exyliaemotes.endless.<segundos>` son números que escribes tú, por ejemplo `exyliaemotes.cooldown.1`. No están declarados en `plugin.yml`, así que nadie los tiene hasta que los concedes.

## Vender emotes por permiso

El id del emote es el nodo. No hay una clave `permission` en `emotes.yml`; la clave del archivo, en minúsculas, es el id:

```text
wave         ->  exyliaemotes.emote.wave
meme         ->  exyliaemotes.category.meme
legendary    ->  exyliaemotes.tier.legendary
```

Un jugador tiene un emote si se cumple cualquiera de los cuatro nodos: el suyo, `exyliaemotes.emote.*`, el de su pestaña o el de su rareza. Con LuckPerms:

```text
/lp group default permission set exyliaemotes.emote.wave true
/lp group vip     permission set exyliaemotes.category.meme true
/lp group mvp     permission set exyliaemotes.emote.handshake true
/lp group elite   permission set exyliaemotes.tier.legendary true
/lp group legend  permission set exyliaemotes.emote.* true
```

El permiso es la mitad de tener un emote. La otra mitad es un desbloqueo ganado en [la caja](/docs/exyliaemotes/crate) o concedido con `/emotesadmin unlocks grant`, que se guarda en la cuenta del jugador. El menú, los comandos, los placeholders y el escenario de vista previa hacen la misma pregunta, así que no pueden contradecirse.

Renombrar la clave de un emote le da otro nodo, y quien tenía el antiguo lo pierde.

<Callout type="tip" title="Deja el menú abierto a todos">
Sin `exyliaemotes.command.emote` un jugador no puede abrir el catálogo, y quien no ve lo que se vende no lo quiere. Los emotes bloqueados se muestran bloqueados y se pueden previsualizar.
</Callout>

## Rangos que juegan más

Dos números, en segundos, pueden ir en un rango:

```text
/lp group vip   permission set exyliaemotes.cooldown.1 true     # 1 segundo entre emotes
/lp group mvp   permission set exyliaemotes.cooldown.0 true     # sin espera compartida
/lp group vip   permission set exyliaemotes.endless.600 true    # los emotes sin fin duran hasta 10 minutos
```

Un jugador sin ninguno recibe `behaviour.cooldown` (3 segundos) y `behaviour.endless-limit` (5 minutos) de `config.yml`. Si tiene varios números de `cooldown` gana el más bajo; con varios de `endless`, el más alto. El nodo de cooldown solo sustituye la espera compartida: el `cooldown` propio de un emote en `emotes.yml` sigue aplicándose. En un dueto cada jugador espera su propio cooldown, y el límite sin fin es el del que invita.

## Para qué se comprueban los nodos

| Momento | Sin el nodo |
|---|---|
| Hacer un emote desde el menú o `/emote play` | Se rechaza con `no-permission`, mientras `behaviour.require-permission` esté activo. |
| Aceptar un dueto | Los dos jugadores deben tenerlo, o se rechaza al aceptar. |
| El menú | `behaviour.hide-without-permission` decide entre ocultar el emote o mostrarlo bloqueado. La pestaña de favoritos siempre lo muestra. |
| Autocompletado de `/emote play` | Solo se ofrecen los emotes que tienes. |

Con `behaviour.require-permission: false` cualquiera que pueda ejecutar `/emote` puede hacer cualquier emote, y nada del menú aparece bloqueado. Previsualizar y marcar favoritos nunca piden el nodo del emote. `/emotesadmin play` tampoco.
