## Los nodos

| Permiso | Por defecto | Concede |
|---|---|---|
| `exyliaemotes.command.emote` | todos | `/emote` y todo lo que cuelga de él, el menú clásico y el selector 3D. |
| `exyliaemotes.admin` | op | Todos los subcomandos de `/emotesadmin`, el panel de administración con su botón SETTINGS, el catálogo en los editores, y el aviso de cómo fijar un escenario de previsualización. |
| `exyliaemotes.emote.<id>` | op | Un emote, por su id. |
| `exyliaemotes.emote.*` | op | Todos los emotes. |
| `exyliaemotes.category.<id>` | op | Todos los emotes de esa pestaña. |
| `exyliaemotes.tier.<id>` | op | Todos los emotes de esa rareza. |
| `exyliaemotes.cooldown.<segundos>` | — | La espera compartida entre dos emotes, en lugar de `behaviour.cooldown`. Gana el más bajo que tenga. |
| `exyliaemotes.endless.<segundos>` | — | Cuánto puede durar un emote sin fin, en lugar de `behaviour.endless-limit`. Gana el más alto que tenga. |

`exyliaemotes.command.emote`, `exyliaemotes.admin` y `exyliaemotes.emote.*` están declarados en
`plugin.yml`. Los nodos de emote se venden, así que solo un operador los tiene hasta que un rango o una
compra los conceda.

Un emote se tiene si se cumple **cualquiera** de los cuatro nodos de emote: el suyo, el comodín, el de
su pestaña o el de su rareza. Un permiso es solo la mitad de tener uno — la otra mitad es un
desbloqueo de [la caja](/docs/exyliaemotes/caja), que se escribe en la cuenta del jugador. El menú, los
comandos, los placeholders y el escenario hacen la misma pregunta, así que no pueden contradecirse.

## El id es el nodo

No hay clave `permission` en `emotes.yml`. El nodo es la clave, en minúsculas:

```text
wave         →  exyliaemotes.emote.wave
meme         →  exyliaemotes.category.meme
legendary    →  exyliaemotes.tier.legendary
```

Renombrar una clave es un nodo distinto, y todos los que tenían el antiguo pierden el emote.

## Venderlo

```text
/lp group default permission set exyliaemotes.command.emote true
/lp group default permission set exyliaemotes.emote.wave true
/lp group vip     permission set exyliaemotes.category.meme true
/lp group mvp     permission set exyliaemotes.emote.handshake true
/lp group elite   permission set exyliaemotes.tier.legendary true
/lp group legend  permission set exyliaemotes.emote.* true
```

La primera línea ya es el valor por defecto; solo importa en un servidor que lo quitó.

<Callout type="tip" title="Regala el menú">
Sin `exyliaemotes.command.emote` el catálogo no se puede abrir, y un jugador que no ve lo que está a la
venta no puede quererlo. Los emotes bloqueados se ven bloqueados, y se pueden previsualizar.
</Callout>

## Rangos que juegan más

Dos números que puede llevar un rango, en segundos:

```text
/lp group vip   permission set exyliaemotes.cooldown.1 true     # 1 segundo entre emotes
/lp group mvp   permission set exyliaemotes.cooldown.0 true     # sin espera compartida
/lp group vip   permission set exyliaemotes.endless.600 true    # los emotes sin fin duran hasta 10 minutos
```

Un jugador sin ninguno de los dos recibe `behaviour.cooldown` y `behaviour.endless-limit` de
`config.yml`. El nodo de cooldown solo sustituye la espera compartida: el `cooldown` propio de un emote
en `emotes.yml` sigue aplicándose. En un dueto cada jugador espera su propio cooldown, y el límite sin
fin es el de quien invitó.

## Para qué se comprueban los nodos

| Momento | Qué pasa sin uno |
|---|---|
| Hacer un emote, desde el menú o `/emote play` | Se rechaza con `no-permission`, mientras `behaviour.require-permission` esté activo. |
| Aceptar un dueto | Los dos jugadores tienen que tenerlo, o se rechaza al aceptar. |
| Dibujarlo | `behaviour.hide-without-permission` decide si un emote bloqueado se oculta en el menú o se muestra bloqueado. En la pestaña de favoritos siempre se muestra. |
| Autocompletar `/emote play` | Solo se ofrecen los emotes que tiene. |

Con `behaviour.require-permission: false` cualquiera que pueda ejecutar `/emote` puede hacer todos los
emotes, y nada del menú está bloqueado.

Previsualizar y marcar favoritos nunca necesitan el nodo del emote. `/emotesadmin play` tampoco — se
salta la propiedad a propósito.
