---
title: "Placeholders"
description: "Lo que tiene y está haciendo un jugador, sus llaves, y los campos de cualquier emote por id."
---

Se registran en PlaceholderAPI con el identificador `exyliaemotes` cuando PlaceholderAPI está
instalado. Cada placeholder de abajo está escrito completo, y al hacer clic se copia.

## Sobre el jugador

| Placeholder | Descripción |
|---|---|
| `%exyliaemotes_owned_count%` | Cuántos emotes puede hacer, por permiso o desbloqueo. |
| `%exyliaemotes_unlocked_count%` | Cuántos emotes le ha desbloqueado la caja. |
| `%exyliaemotes_keys%` | Cuántas llaves de caja tiene en la cuenta. |
| `%exyliaemotes_favourites_count%` | Cuántos emotes tiene marcados. |
| `%exyliaemotes_owns_<id>%` | `true` o `false` para un emote — `%exyliaemotes_owns_wave%`. |
| `%exyliaemotes_favourite_<id>%` | `true` o `false` para un emote — `%exyliaemotes_favourite_wave%`. |
| `%exyliaemotes_favorite_<id>%` | La misma respuesta, sin la `u`. |
| `%exyliaemotes_playing%` | `true` mientras está haciendo un emote, `false` si no. |
| `%exyliaemotes_playing_id%` | El id de lo que está haciendo. |
| `%exyliaemotes_playing_name%` | Su nombre. |

## Sobre el servidor

Responden sin jugador, así que funcionan en un holograma.

| Placeholder | Descripción |
|---|---|
| `%exyliaemotes_catalogue_count%` | Cuántos emotes declara el servidor. |
| `%exyliaemotes_total%` | La misma cuenta, con el nombre corto. |
| `%exyliaemotes_playing_count%` | Cuántos emotes se están haciendo ahora mismo. Un dueto cuenta una vez. |

## Sobre un emote

`%exyliaemotes_emote_<id>_<campo>%` responde sobre cualquier emote por id, lo pida quien lo pida — que
es lo que permite al menú de otro plugin dibujar una fila de un emote del que no sabe nada.

| Placeholder | Descripción |
|---|---|
| `%exyliaemotes_emote_<id>_name%` | Su nombre — `%exyliaemotes_emote_wave_name%`. |
| `%exyliaemotes_emote_<id>_id%` | Su id. |
| `%exyliaemotes_emote_<id>_description%` | Su descripción, en una línea. |
| `%exyliaemotes_emote_<id>_material%` | El material con que se dibuja. |
| `%exyliaemotes_emote_<id>_category%` | El id de su pestaña. |
| `%exyliaemotes_emote_<id>_kind%` | `solo` o `duet`. |
| `%exyliaemotes_emote_<id>_tier%` | El id de su rareza. |
| `%exyliaemotes_emote_<id>_tier_name%` | El nombre de la rareza. |
| `%exyliaemotes_emote_<id>_tier_color%` | El color en que se escribe esa rareza. |
| `%exyliaemotes_emote_<id>_tier_colour%` | El mismo color, con la `u`. |

Un id que no nombra ningún emote, o un campo que no está en la tabla, responde
`placeholders.unknown` — `Unknown` por defecto.

<Callout type="warning" title="Los ids con guion bajo no se alcanzan aquí">
El id se lee hasta el primer `_` después de `emote_`, así que `%exyliaemotes_emote_six_seven_name%`
pregunta por un emote llamado `six` y responde `Unknown`. Los trece ids incluidos con guion bajo —
`thumbs_up`, `blow_kiss`, `point_laugh`, `sip_tea`, `slow_clap`, `air_guitar`, `six_seven`,
`robot_walk`, `default_dance`, `take_the_l`, `orange_justice`, `nae_nae`, `chicken_dance` — no tienen un
placeholder `emote_<id>_<campo>` que funcione. `%exyliaemotes_owns_<id>%` y `%exyliaemotes_favourite_<id>%` leen todo el resto del
nombre y no se ven afectados.
</Callout>

## Sin nada que responder

| Caso | Respuesta |
|---|---|
| Un placeholder de jugador pedido sin jugador | `placeholders.none` — `None` por defecto |
| `%exyliaemotes_playing_id%` o `%exyliaemotes_playing_name%` sin nada en marcha | `placeholders.none` |
| `%exyliaemotes_owns_<id>%` para un id que no nombra ningún emote | `false` |
| Cualquier otro nombre que este plugin no conoce | Se deja sin tocar, como hace PlaceholderAPI |
