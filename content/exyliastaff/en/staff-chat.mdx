ExyliaStaff has two chat tools. **Staff chat** is a private channel: what a staff member writes there reaches every staff member on the network and nobody else. **Global chat** lets a staff member read every chat on the server, even the ones other plugins keep isolated (matches, arenas, events), and optionally every other server's chat too.

## Before you start

- Give staff chat to the rank: `exyliastaff.staffchat`. For global chat give `exyliastaff.globalchat`.
- The module switches are `modules.staff-chat` and `modules.global-chat` in `plugins/ExyliaStaff/config.yml`.
- Across servers it needs the same database and Redis on every server, like the rest of ExyliaStaff. With one server and no Redis it works the same.

## Steps

<Steps>
  <Step title="Talk in staff chat">
    Run `/sc` (alias `/staffchat`) to switch it on: everything you type now goes to staff, not to public chat. Run `/sc` again to go back. Or click the **STAFF CHAT** writable book (slot 28) in the [staff mode](/docs/exyliastaff/staff-mode) hotbar.
  </Step>
  <Step title="Send a single line">
    Run `/sc <message>` to send one line without changing the switch. The console can do this too.
  </Step>
  <Step title="Read every chat on the server">
    Run `/globalchat` (alias `/chatbypass`), or click the **GLOBAL CHAT** bell (slot 30). It cycles three modes: off, global, network.
  </Step>
</Steps>

## Check that it works

Switch staff chat on with `/sc`, type a line, and have another staff member (on any server) confirm they see it as `[SC] <server> » <you> » <message>` while a normal player sees nothing. Run `/sc` again and confirm your next line shows in public chat.

## Going further

### How staff chat behaves

There is no prefix character such as `@`: the switch and the command are the two ways in. The switch is saved, so it survives a relog and follows the player to other servers. It turns off when the player leaves staff mode or loses `exyliastaff.staffchat`.

While it is on, what the staff member types is taken out of public chat before any other plugin reads it, a Discord bridge included. Lines are delivered to every online player holding `exyliastaff.staffchat`, and also printed to the console while `console` is on.

### The three global chat modes

| Mode | What you read | Who reads you |
|---|---|---|
| Off | The chat around you, like any player. | Like any player. |
| Global | Every chat on this server, whatever another plugin isolates. | Everyone on the server, past every rule. |
| Network | The same, plus every other server's public chat. | Only your server. What you say never leaves it. |

The mode is saved and restored on join. Unlike staff chat it is **not** turned off when you leave staff mode; losing `exyliastaff.globalchat` resets it to off. Only reading crosses servers. Lines another plugin cancelled (a mute, or staff chat itself) are never relayed.

To keep one server out of the others' network view, set `relay: false` in its globalchat config. Its own staff still read the other servers.

## Commands and permissions

<Commands group="chat" />

<Permissions group="chat" />

<Details title="Configuration and messages">

```yaml title="plugins/ExyliaStaff/modules/staffchat/config.yml"
console: true
```

```yaml title="plugins/ExyliaStaff/modules/globalchat/config.yml"
relay: true
```

| Key | Default | What it does |
|---|---|---|
| `console` (staffchat) | `true` | Also print staff chat lines to this server's console. |
| `relay` (globalchat) | `true` | Publish this server's public chat so staff in network mode elsewhere can read it. |

How a line looks is text, so it lives in `lang/<language>/modules/<module>/messages.yml`, not in the config. Both files have a `format` with `%server%`, `%player%` and `%message%`:

```yaml
format: '{letters_black}[{primary}SC{letters_black}] {muted}%server% {letters_black}» {highlight}%player% {letters_black}» {letters}%message%'
```

`%server%` is the sender's server id from `database.yml`. Staff chat also has `toggled-on`, `toggled-off`, `permission-lost`, `console-needs-message`, `status-on` and `status-off`. Global chat has `toggled-on`, `toggled-network`, `toggled-off`, `permission-lost`, `status-on`, `status-network` and `status-off`, and its `format` uses `[NET]`. See [ExyliaLib messages](/docs/exylialib/messages-and-languages) and [colours](/docs/exylialib/colours).
