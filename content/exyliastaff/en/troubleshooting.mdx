Find your symptom, then follow the fix.

## The plugin does not start

The console names what is missing. ExyliaStaff needs ExyliaLib, which the loader installs when it is absent. PacketEvents is optional. See [Install ExyliaStaff](/docs/exyliastaff/installation).

## Without PacketEvents

Vanish falls back to Bukkit's own hiding and freeze to movement checks. Staff mode, seeing invisible players ([Reveal](/docs/exyliastaff/reveal)) and [x-ray vision](/docs/exyliastaff/xray-vision) stay off.

## `/staff` says I have no permission

Staff mode needs `exyliastaff.staff` and `exyliastaff.staffmode` together. Operators have both. Everyone else needs them in your permission plugin. See [Permissions](/docs/exyliastaff/permissions).

## A command is an unknown command

Its module is off, or the command is listed in `disabled-commands` in `config.yml`. Run `/staffadmin modules` to see which modules run, and `/staffadmin module enable <module>` to turn one on. See [Commands](/docs/exyliastaff/commands).

## `/tp` says "Enable staff mode"

The command gate only lets staff run those commands in staff mode. Enter staff mode with `/staff`, or give the group `exyliastaff.gate.bypass`. See [Configuration](/docs/exyliastaff/configuration#command-gate).

## Staff cannot see vanished players

Seeing them needs `exyliastaff.vanish.see`, and only vanished players of the viewer's level or below are shown. Levels come from `exyliastaff.vanish.level.<n>`. See [Vanish](/docs/exyliastaff/vanish).

## A staff session ended by itself

Losing `exyliastaff.staff` while online ends the session within a few seconds. Check that your permission plugin did not drop it.

## Reports or help requests do not reach staff

Staff receive them with `exyliastaff.reports.manage` and `exyliastaff.helpop.manage`. Players need `exyliastaff.report` and `exyliastaff.helpop`, which everyone has unless you set them to `false`. See [Reports](/docs/exyliastaff/reports) and [Helpop](/docs/exyliastaff/helpop).

## A placeholder shows as text

- PlaceholderAPI is not installed.
- Outside ExyliaStaff's own files the name carries the plugin twice: `%exyliastaff_staff_reports_open%`.
- The module of that placeholder is off.

See [Placeholders](/docs/exyliastaff/placeholders).

## A staff member is locked out by two-factor

Someone with `exyliastaff.2fa.reset` runs `/2fa reset <player>`. See [Two-factor](/docs/exyliastaff/two-factor).
