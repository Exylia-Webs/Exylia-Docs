title: "Commands"
description: "Every command of every module, with its aliases, its arguments and its permission."
---

Commands belong to modules. A module that is off has none of its commands on the server: `/freeze`
with freeze disabled is an unknown command, not a refusal. Toggling a module with `/staffadmin module`
re-registers the set and refreshes every client's command list. A single command or alias can be left
unregistered with [`disabled-commands`](/docs/exyliastaff/configuration#disabled-commands).

`<player>` is required, `[player]` optional. Most commands take anybody the network knows, online on
any server or not, and suggest every name connected to the proxy. The ones that act on somebody in
front of you — freezing them, reporting them, switching their vanish, staff mode or x-ray — need them
online on this server, and say so with "is not online".

## Core

| Command | Permission | What it does |
|---|---|---|
| `/staffadmin` | `exyliastaff.admin` | Lists the modules and their state. Replaces `/exyliastaff` and `/es` since 1.5.0. |
| `/staffadmin reload` | `exyliastaff.admin.reload` | Reloads every file, the modules and the command gate. |
| `/staffadmin modules` | `exyliastaff.admin.modules` | The same list. |
| `/staffadmin module enable <id>` | `exyliastaff.admin.modules` | Switches a module on, and its commands with it. |
| `/staffadmin module disable <id>` | `exyliastaff.admin.modules` | Off, together with every module that depends on it. |
| `/staffadmin redis` | `exyliastaff.admin` | This server's id, whether Redis is connected, and its stats. |
| `/staffadmin info` | `exyliastaff.admin.info` | The plugin version, this server's id, Redis, the web link and how many modules are on. |
| `/staffadmin history clear <player> [reason-id]` | `exyliastaff.admin.history.clear` | Deletes a player's punishment history, or only one reason's. Nothing is lifted. |
| `/staffadmin reports clear <player>` | `exyliastaff.admin.reports.clear` | Deletes every report against a player. |
| `/staffadmin notes clear <player>` | `exyliastaff.admin.notes.clear` | Deletes every note and strike on a staff member's file. |
| `/staffadmin wipe <player> [confirm]` | `exyliastaff.admin.wipe` | History, reports and notes at once. Without `confirm` it only counts what would go. |
| `/staffadmin import <plugin>` | `exyliastaff.admin` | Imports a ban plugin's history once. See [Punishments](/docs/exyliastaff/punishments#importing-a-ban-plugin). |
| `/staffadmin weblink` | `exyliastaff.web.link` | Links the network to [Exylia Staff Web](/docs/exyliastaff/staff-web). |

The root itself needs `exyliastaff.admin`. All of it works from the console. Every clear and wipe is
written to the [audit](/docs/exyliastaff/staff-admin) when that module is on; a module that is off is
left alone.

## Staff mode

| Command | Permission | What it does |
|---|---|---|
| `/staff` | `exyliastaff.staffmode` | Toggles your own staff mode. `/staffmode` and `/mod` are aliases. |
| `/staff toggle [player]`, `/staff on [player]`, `/staff off [player]` | `exyliastaff.staffmode` | Toggles or sets it, for you or somebody else. |
| `/staff spectator` | `exyliastaff.staffmode` | Spectator view. `/staff spec` is the same. |

Another player needs `exyliastaff.staffmode.others`.

## Inspect

| Command | Permission | What it does |
|---|---|---|
| `/inspect <player>` | `exyliastaff.inspect` | Their inventory, live when they are here, from this server's file when they are offline. `/invsee` and `/examine` are aliases. |

## Teleport

| Command | Permission | What it does |
|---|---|---|
| `/tp <player>` | `exyliastaff.teleport` | To a player anywhere on the network. `/teleport`, `/stafftp`, `/tpto`. |
| `/tp <player> <destination>` | `exyliastaff.teleport.here` | Moves one player to another who is here, from another server if needed. |
| `/tpstaff <player>` | `exyliastaff.teleport` | Staff mode and vanish first, then to them. `/staffmodetp`, `/tpduty`. |
| `/tppos <x> <y> <z> [world]` | `exyliastaff.teleport` | To coordinates; `~` for where you are. `/tpcoords`. |
| `/tpworld <world>` | `exyliastaff.teleport` | To the spawn of a world. `/staffworld`. |
| `/tpoffline <player>` | `exyliastaff.teleport` | To where they logged off. `/tpoff`. |
| `/top` | `exyliastaff.teleport` | Up to the surface above you. `/stafftop`. |
| `/stafftphere <player>` | `exyliastaff.teleport.here` | Brings them. `/tphere`. |
| `/staffrtp [reset]` | `exyliastaff.teleport.random` | Random player, or clear the visited list. `/staffrandomtp`. |
| `/phase` | `exyliastaff.teleport.phase` | Through the wall. `/staffphase`. |
| `/jumpto` | `exyliastaff.teleport.phase` | On top of what you look at. `/staffjump`. |
