Find your symptom, then follow the fix. When a core is refused, the chat says why and the core stays in the player's hand.

## The core will not place

Read the chat message, then use the matching fix.

| The chat says | Why | Fix |
|---|---|---|
| "Land cannot be protected in this world." | The world is in `settings.disabled-worlds`. By default that is `world_the_end`. | Remove the world from that list in `config.yml`. |
| "You already own N protection(s), your limit." | The player reached their total limit, 3 by default. | Raise `settings.default-limit`, or give a rank `exyliaprotections.limit.<n>`. See [Permissions](/docs/exyliaprotections/permissions#per-player-limits). |
| "You already own N of this tier." or "...in this world." | The tier's own `limit`, or `settings.world-limits`, is reached. | Raise the tier limit, or grant `exyliaprotections.limit.<tier>.<n>`. |
| "That land overlaps another protection." | The new area touches somebody else's land. | Place the core further away. |
| "Keep at least N blocks from other players' protections." | `settings.min-distance`, 8 by default, applies between different owners. | Move away, or lower the distance. |
| "That land overlaps a protected server area." | A WorldGuard region that is not one of the plugin's own is in the way. | Move the core, or list the region in `settings.allowed-worldguard-regions`. |
| "That land reaches past the world border." | The area would leave the world border. | Place it further inside. |
| "You cannot use this protection tier." | The tier has a `permission` the player lacks. | Grant it, or clear `permission` on the tier. |
| "Protection cores are turned off on this server." | `cores.enabled` is false. | Set it back to `true`, or use the selector. |

See [Create protections](/docs/exyliaprotections/creating-protections) for every rule.

## There is no Shop button

The **Shop** button only shows when `cores.enabled` is true and at least one tier has a `price` above 0. Check the tiers in `config.yml` or run `/protectionsadmin tiers`. Buying also needs an economy: see [Install ExyliaProtections](/docs/exyliaprotections/installation). To give a core without the shop, run `/protectionsadmin give <player> <tier>`.

## There is no Select land button

Three things must hold: `selection.enabled` is `true` (it is off by default), the player has `exyliaprotections.select`, and the PacketEvents plugin is installed. Without PacketEvents the selector cannot be shown and the plugin says selection is not available. Its other features keep working.

## A member cannot build

1. Stand in the land and run `/protections info`. It shows your role. A `visitor` cannot build.
2. Open **People**, then **Members**. If the name is missing, add it with `/protections add <player>`.
3. If the name is there, the member's role may lack `break` or `place`. Check it under **People**, then **Roles**.
4. A locked protection also keeps non-members out, see [People and access](/docs/exyliaprotections/people-and-access).

## An operator cannot break blocks in someone's land

This is intended. `exyliaprotections.bypass` is given to nobody, operators included, so staff can test their own land. Grant it by name to the people who must ignore protections:

```text
/lp user <name> permission set exyliaprotections.bypass true
```

`exyliaprotections.admin` manages protections but does not let the holder build in them. See [Permissions](/docs/exyliaprotections/permissions).

## "Your rank does not include that feature"

The player lacks one of the feature nodes, for example `exyliaprotections.sethome`. Everybody holds them by default, so a permission plugin must be denying it. Grant the node back to that rank. See [Permissions](/docs/exyliaprotections/permissions#feature-nodes).

## "That feature is turned off"

Raids, upkeep, the bank, the market, plots, rent, upgrades, warps, perks and weather are all off by default. Turn one on with `/protectionsadmin feature <name> on`, which writes `config.yml`, or in `/protectionsadmin settings`. See [Configuration](/docs/exyliaprotections/configuration).

## Teleporting home makes me wait

Teleports use a countdown of 3 seconds by default (`teleport.warmup-seconds`), cancelled if you move or take damage. Staff with `exyliaprotections.bypass.warmup` teleport at once. Operators have it by default.

## Raid replays say PacketEvents is needed

Watching a raid replay needs the PacketEvents plugin on the server. Install it and restart.

## A placeholder shows as text or stays empty

- Install PlaceholderAPI and write the full name: `%exyliaprotections_protections_name%`. See [Placeholders](/docs/exyliaprotections/placeholders).
- Placeholders about a protection (name, owner, role, bank) are empty when the player is not standing inside one. The ones for raids, bank, upkeep, sales, plots and warps are also empty while that feature is off.

## `/ps` runs another plugin

ProtectionStones also registers `/ps`. Use `/protections` or `/claims`, and remove ProtectionStones once its regions are imported. See [Commands](/docs/exyliaprotections/commands).
