`ProtectionsService` answers the two questions other plugins ask about land: is this spot inside a
protection, and does that protection stop flight right now.

```java
boolean claimed = ExyliaAPI.get(ProtectionsService.class)
        .map(protections -> protections.protectionAt(location).isPresent())
        .orElse(false);
```

<Callout type="note" title="Adding it to your project">
The artifact, the repository and the `plugin.yml` line are the same for every Exylia plugin and live on
the [public API page](/docs/exylialib/api). The protections contract arrived in the public API **1.9.0**,
shipped with ExyliaLib **1.238.0**, in the package `net.exylia.lib.api.protections`.
</Callout>

An empty `Optional` from `ExyliaAPI.get` means the server has no ExyliaProtections. The service is
registered once the plugin has started and goes away when it disables.

## Methods

| Method | What it does |
|---|---|
| `Optional<String> protectionAt(Location location)` | The id of the protection whose land holds that spot, or empty when none covers it. |
| `boolean deniesFlight(Location location)` | Whether flight must stop at that spot: `submodules.raids` and `effects.no-flight-during-siege` are on and the protection there is under siege or raidable. With raids off it always answers `false`. |

Both read the protections this server has loaded in memory, without touching the database. Right after a
restart, before the protections have finished loading, `protectionAt` finds none.

The id is an opaque string. Keep it to compare two answers; do not parse it or show it to players.

`deniesFlight` is what ExyliaSurvivalCore's `/fly` asks before letting a player fly, and once a second for
everybody already flying. Use it the same way for any flight of your own.

## What is not there

The service is read-only and deliberately small. There is no method to create, delete or edit a protection,
to read its members, roles, flags or bank, or to ask whether a given player may build at a spot; and the
plugin fires no events of its own. Placeholders cover the read-outs most integrations want: see
[Placeholders](/docs/exyliaprotections/placeholders).
