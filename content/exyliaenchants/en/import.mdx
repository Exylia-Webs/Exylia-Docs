The importer maps the enchants of another plugin to ExyliaEnchants, translates the ones it can into new enchants, and converts the items players carry as they load. It never scans the world.

## Before you start

Keep the old plugin's folder in `plugins/` while you import: the importer reads it. These are the supported plugins and the files it reads:

| Source | Command word | Reads |
|---|---|---|
| AdvancedEnchantments | `advancedenchantments` | `plugins/AdvancedEnchantments/enchantments.yml` |
| EcoEnchants | `ecoenchants` | `plugins/EcoEnchants/enchants/` |
| ExcellentEnchants | `excellentenchants` | `plugins/ExcellentEnchants/enchants/` |

You need `exyliaenchants.admin`.

## Steps

<Steps>
  <Step title="Try a dry run">
    Run `/enchantsadmin import advancedenchantments -dry` (or the word for your plugin). It writes only the report.
  </Step>
  <Step title="Read the report">
    Open `plugins/ExyliaEnchants/import-report.yml`. Every enchant of the source is under `mapped` (to one of ours), `translated` (a new enchant of ours) or `skipped`, with the reason.
  </Step>
  <Step title="Run the import">
    Run the same command without `-dry`. Translated enchants are written to `enchants/imported_<source>.yml`, and the mapping to `import/mapping.yml`.
  </Step>
  <Step title="Restart">
    If any enchant was translated, restart: new enchants register on startup. The chat message tells you.
  </Step>
</Steps>

## Check that it works

Join with an item that carries an old enchant. It converts as your inventory loads, at the same level (capped at the new enchant's maximum), and the old marks go. Open `/enchants` and find any translated enchant in its section.

## How items convert

Conversion follows `import/mapping.yml` and happens when:

- a player joins (inventory and ender chest);
- a container opens;
- a player closes their inventory.

An item is marked `exyliaenchants:imported` so it is never converted twice. An item whose target enchant is not registered yet, such as a translated one before the restart, waits for a later load.

<Callout type="warning" title="Convert before you remove the old plugin">
EcoEnchants and ExcellentEnchants enchants only exist on an item while their plugin is installed. Import, let players log in and open their containers, and only then remove the old plugin. AdvancedEnchantments marks on items survive its removal.
</Callout>

## Going further

- Edit the translated enchants freely: they are ordinary files, see [Create or change an enchant](/docs/exyliaenchants/custom-enchants).
- An enchant that cannot be translated is listed as skipped with the reason. Create it yourself if you still want it.
- Run another source later: each import adds to the mapping.

<Details title="Technical details">
`/enchantsadmin import <advancedenchantments|ecoenchants|excellentenchants> [-dry]` runs off the main thread, one import at a time. The report is rewritten on every run. A missing source folder is reported in chat. The command is listed in [Commands](/docs/exyliaenchants/commands).
</Details>
