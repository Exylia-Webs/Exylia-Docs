Wear four armour pieces that each carry an enchant of the same element and you get a set bonus. The element is the enchant's `visuals.element`, so it is a mark of the enchants worn, not of the armour material. An elytra counts as the chest piece.

## The default bonuses

| Element | Set | Bonus |
|---|---|---|
| fire | Emberforged | Burning time reduced by half |
| frost | Glacier | +0.15 knockback resistance |
| earth | Bedrock | +2 armour toughness |
| wind | Gale | +0.06 movement speed and +2 safe fall distance |
| holy | Seraph | +4 maximum health (two hearts) |
| water | Tide | +3 oxygen bonus and +0.25 water movement efficiency |

The bonus is an attribute modifier keyed `exyliaenchants:set_<element>`, applied when the fourth piece goes on and removed when one comes off.

## Change a bonus

Edit `sets.yml` and run `/enchantsadmin reload`. Each set is a list of lines with `attribute`, `amount` and `operation`:

```yaml
fire:
  - { attribute: burning_time, amount: -0.5, operation: multiply_scalar_1 }
```

Operations are `add_number`, `add_scalar` and `multiply_scalar_1`. Only elements the enchants use have an effect: add an element name to an enchant's `visuals.element` to make it part of a set. See [Add your own enchant](/docs/exyliaenchants/custom-enchants).

<Callout type="note" title="Balance">
A set bonus comes on top of the [power budget](/docs/exyliaenchants/power-budget): wearing four pieces does not cost extra power. If one element feels too good, lower its numbers here.
</Callout>
