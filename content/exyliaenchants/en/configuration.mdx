ExyliaEnchants keeps its files in `plugins/ExyliaEnchants/`. Edit them and run `/enchantsadmin reload`, except where a section below says a restart is needed. Most settings an admin tunes also have screens: run `/enchantsadmin` and open **Settings** (Display, Economy, Integrations, Obtaining and Power). How those screens work is in [Settings screens](/docs/exylialib/config-menus).

| File | What it holds |
|---|---|
| `config.yml` | Language, preset, display mode, tooltip, budget, obtaining switches |
| `economy.yml` | Book odds, dust, gems, the enchanter |
| `rules.yml` | Rules by world, region, mode and permission |
| `integrations.yml` | Suite integrations |
| `balance.yml` | Dummy, simulation, metrics, outlier thresholds |
| `menus.yml` | Catalogue previews |
| `sets.yml` | Armour set bonuses |
| `sequences.yml` | The visuals enchants play |
| `enchants/*.yml` | The enchant catalogue |
| `lang/<code>/` | Messages, menus, screens and support items |

## config.yml

| Key | Default | Meaning |
|---|---|---|
| `language` | follows ExyliaLib | Language of messages and menus |
| `debug` | `false` | Extra console output |
| `preset` | `auto` | `auto`, `pvp`, `survival` or `vanilla-plus`. See [Presets and rules](/docs/exyliaenchants/presets-and-rules) |
| `display-mode` | `native` | `native` or `lore`. `lore` writes one line per enchant into the item for Bedrock through Geyser; Java players then see them twice |
| `tooltip.enabled` | `true` | Description and stat lines under each enchant. Needs PacketEvents |
| `tooltip.in-menus` | `true` | The same lines in menus |
| `tooltip.description` / `tooltip.stats` | `true` | Which lines are drawn |
| `tooltip.player-default` | `true` | What a player sees until they choose |
| `budget.enabled` | `true` | The [power budget](/docs/exyliaenchants/power-budget) |
| `budget.rarity-cost` | common 1, rare 2, epic 3, legendary 5, curse 0 | Power per level when an enchant sets no `power-cost` |
| `budget.weapons` / `armour` / `tools` | 12 / 12 / 10 | The limit per item category |
| `economy` | `true` | Books, support items and the enchanter. Off under `vanilla-plus` |
| `purged` | empty | Enchants being purged; written by `/enchantsadmin purge` |
| `disabled-enchants` | empty | Enchants switched off: items keep them, they stop working |
| `obtaining.*` | all `true` | See [Obtain enchants](/docs/exyliaenchants/obtaining) |
| `obtaining.table-share` | `0.35` | Share of the table's offers that are custom enchants |

The first start resolves `preset: auto` once and writes the result.

## economy.yml

| Key | Default |
|---|---|
| `book-mode` | `chance` (the other value is `vanilla`: every book succeeds) |
| `odds.<rarity>` success / destroy | common 80-100 / 0-10, rare 60-90 / 5-20, epic 40-80 / 10-30, legendary 25-60 / 15-40, curse 100 / 0 |
| `curse-on-fail` | `15.0` percent. Survival preset only; `0` is off |
| `dust-bonus` / `dust-cap` | `10` / `100` |
| `gem-power` / `max-gems` | `2` / `3` |
| `enchanter.enabled` | `true` |
| `enchanter.restock` | `10m` |
| `enchanter.books.<rarity>` | `levels` and `stock`: common 8 / 32, rare 16 / 16, epic 28 / 8, legendary 45 / 2 |
| `enchanter.support.<kind>` | `levels` and `stock` per kind, see below |

Support prices are protection 20 (stock `-1`, unlimited), dust 6, transmog 4, disenchant 15 and gem 30 (stock 4). The currency of a price is `levels` (experience levels), an empty value (the server's default currency) or an ExyliaLib currency id. Support items are defined in `lang/<code>/support-items.yml`. Details: [Books and applying](/docs/exyliaenchants/books-and-applying) and [The enchanter](/docs/exyliaenchants/the-enchanter). Currencies are explained in [Economy](/docs/exylialib/economy).

## Other files

- `rules.yml`: [Presets and rules](/docs/exyliaenchants/presets-and-rules).
- `integrations.yml`: `mines.area-break` (default `true`). See [Integrations](/docs/exyliaenchants/integrations).
- `balance.yml`: [Tune and balance](/docs/exyliaenchants/balance-tools).
- `menus.yml`: `preview.mode` (default `MANNEQUIN`) and `preview-effects`, one [ExyliaLib sequence](/docs/exylialib/sequences) per element. `default` covers the rest.
- `sets.yml`: [Armour set bonuses](/docs/exyliaenchants/set-bonuses).

## Enchant file

Enchants live in `enchants/*.yml`: `melee`, `ranged`, `armour`, `mobility`, `tools` and `universal` ship with the plugin. Add your own `*.yml` files in the same folder; they are read in name order and the first file wins on a duplicate id. An id uses `a-z`, `0-9` and `_`, up to 64 characters. Never rename a shipped id.

| Key | Default | Meaning |
|---|---|---|
| `name` | required | Display name |
| `description` | none | One line, shown in the tooltip and the catalogue |
| `rarity` | required | `common`, `rare`, `epic`, `legendary` or `curse` |
| `max-level` | `1` | 1 to 255 |
| `applies-to` | required | Item families, `#tags` or item ids |
| `slots` | from the families | Where it is active: `any`, `mainhand`, `offhand`, `hand`, `head`, `chest`, `legs`, `feet`, `armor`, `body`. Held in any other slot it does nothing |
| `conflicts` | none | Enchants it cannot share an item with |
| `mode` | `both` | `pvp`, `pve` or `both`: who it is meant against |
| `weight` | by rarity | 1 to 1024, the table and loot weight |
| `anvil-cost` | by rarity | Anvil cost of a book |
| `min-cost` / `max-cost` | by rarity | `base` and `per-level` for the table |
| `area` | `false` | Marks an enchant that breaks blocks or hits many entities, so rules can select or switch it off |
| `table`, `trade`, `treasure` | by rarity | In the enchanting table, sold by librarians, or treasure only |
| `loot` | `false` | In random loot chests, fishing treasure and random enchanting. Also needs `obtaining.loot` |
| `mob-equipment` / `traded-equipment` | `false` | On the gear mobs spawn with / villagers sell. The second also needs `obtaining.villager-trades` |
| `grindstone` | `true` (`false` for curses) | Whether the grindstone removes it |
| `enchanter` | `true` | Whether the enchanter can roll it |
| `books` | `true` | Whether `/enchantsadmin give ... -book` hands it out from the console |
| `worlds` | none | `allow` and `deny` lists |
| `regions` | none | `deny` list |
| `permission` | none | Holders need this node for it to work |
| `power-cost` | by rarity | Power per level, -10 to 50 |
| `enabled` | `true` | Switch it off without deleting it |
| `abilities` | none | See [Add your own enchant](/docs/exyliaenchants/custom-enchants) |
| `visuals` | none | `element` and `icon` |

<Callout type="warning" title="What needs a restart">
Keys that are part of the native enchantment the server registers on boot (name, rarity, max-level, applies-to, slots, conflicts, weight, anvil-cost, costs, table, trade, treasure, loot) need a restart, and so does a new enchant. `description`, `power-cost`, `abilities` and `visuals` reload live. Switches under `obtaining` that remove tags need a restart; the anvil, grindstone and `/enchant` switches reload.
</Callout>
