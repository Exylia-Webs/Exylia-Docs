ExyliaEnchants detects the other Exylia plugins and lights up the matching features. Each one is active only when its plugin is installed, and nothing needs enabling except the one switch below.

## What each plugin adds

| Plugin | What happens |
|---|---|
| ExyliaMines | Enchants work inside mines. A player's own swing counts, area breaks go through the mine so it pays the loot and refills the blocks, and drops can be changed or smelted. |
| ExyliaEconomy | Its currencies can be used for [enchanter prices](/docs/exyliaenchants/the-enchanter) and by money effects such as Greed. |
| ExyliaCombat | The `in-combat` condition works in enchant abilities. |
| ExyliaClans | The `allies` and `enemies` filters follow clans: allies are the same or allied clan. |
| ExyliaDuels, ExyliaFFA, ExyliaPracticeCore, ExyliaEvents | Each gives the player a mode that [rules](/docs/exyliaenchants/presets-and-rules) can select. |
| ExyliaMarket | The enchant lines also show on items in market listings (`tooltip.in-menus`). |
| ExyliaCrates, ExyliaRewards | Give a book as an item reward, or as a command reward. See below. |

## Switch off area breaks in mines

In `integrations.yml`, `mines.area-break` is `true` by default. Set it to `false` to switch area-break enchants off in every mine. To switch them off in one mine only, add that mine's id under `regions` in a rule of `rules.yml`.

## Limit enchants by game mode

In `rules.yml`, the `modes` key of a rule takes one of these. The first that applies to the player wins:

| Mode | When |
|---|---|
| any ExyliaLib mode id | A plugin claims the player with it |
| `duels-ranked`, `duels`, `duels-bot` | An ExyliaPracticeCore match: ranked, unranked, against bots |
| `duels` | An ExyliaDuels duel |
| `ffa` | In an ExyliaFFA arena |
| `event` | Playing an ExyliaEvents event |

Kits from PracticeCore and FFA do not carry a list of allowed enchants, so use rules by mode instead. See [Presets and rules](/docs/exyliaenchants/presets-and-rules).

## Conditions for abilities

Two conditions are added to the ability engine, for your own enchants:

- `in-mine: true | false | [mine ids]`: inside an ExyliaMines mine.
- `in-event: true | false | [event ids]`: playing an ExyliaEvents event, by config id or type.

There is also a `MINE_DROP` trigger, fired when a mine's drops are rolled. See [Create or change an enchant](/docs/exyliaenchants/custom-enchants).

## Give books as rewards

ExyliaCrates and ExyliaRewards have no enchant reward type. Use either:

- an **item** reward: the book item itself;
- a **command** reward: `enchantsadmin give %player% <enchant> <level> -book`. The book rolls odds by rarity. Add `-safe` for a guaranteed book.

<Callout type="note" title="Console only for books">
`give ... -book` works from the console. Run by a player it still gives the book, with a warning. Set `books: false` in an enchant's section to stop it being handed out this way.
</Callout>

<Details title="Technical details">
`integrations.yml` has one key, `mines.area-break`. The other integrations work through ExyliaLib's services (Economy, Combat, Clans, Modes, Sessions), so a missing plugin never breaks anything. See [Configuration](/docs/exyliaenchants/configuration).
</Details>
