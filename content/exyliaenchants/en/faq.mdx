## Do players need a resource pack?

No. The enchants are real enchantments registered by the server, so the client shows their names without a pack.

## How many enchants are there and how are they sorted?

188, in six files: melee, ranged, armour, mobility, tools and universal (including curses). Each has a rarity: common, rare, epic, legendary or curse. See [Rarities](/docs/exyliaenchants/rarities).

## Which versions does it run on?

Paper 1.21.4 or newer, and Folia, with Java 21 and ExyliaLib.

## How do I stop an item from having too many enchants?

The [power budget](/docs/exyliaenchants/power-budget) gives each item category a limit, and each enchant a cost per level. Raise or lower both in `config.yml`.

## How do I make the server mostly vanilla?

Set `preset: vanilla-plus` (common and rare enchants only, no books or enchanter) and lower `obtaining.table-share`. See [Presets and rules](/docs/exyliaenchants/presets-and-rules).

## How do I weaken an enchant in one arena or world?

Use a rule in `rules.yml` by world, region or mode. See [Presets and rules](/docs/exyliaenchants/presets-and-rules).

## Which permission do I need?

Players need none. Staff need `exyliaenchants.admin` for `/enchantsadmin`. See [Permissions](/docs/exyliaenchants/permissions).

## Where can players see all enchants?

`/enchants` opens the catalogue with filters by rarity and by item. Clicking an enchant previews it.

## Can I add my own enchants?

Yes, in a YAML file in `plugins/ExyliaEnchants/enchants/`. See [Create or change an enchant](/docs/exyliaenchants/custom-enchants).

## Can I move from AdvancedEnchantments, EcoEnchants or ExcellentEnchants?

Yes: `/enchantsadmin import`. See [Import](/docs/exyliaenchants/import).

## Do Bedrock players see the enchants?

Set `display-mode: lore` in `config.yml`: it writes one line per enchant into the item for Bedrock through Geyser. Java players then see them twice. See [Configuration](/docs/exyliaenchants/configuration).

## Can players hide other people's effects?

Yes, in `/enchants settings`. See [Player settings](/docs/exyliaenchants/player-settings).
