After this page ExyliaEnchants is running and `/enchants` opens the catalogue.

## Before you start

You need a Paper server (1.21.4 or newer) or Folia, running Java 21. ExyliaEnchants will not start without ExyliaLib.

| Plugin | Why |
|---|---|
| ExyliaLib | Required. Menus, messages, abilities, economy and colours. |
| packetevents | Optional here, but ExyliaLib needs it. Draws the description and stat lines under each enchant name. |

Optional plugins that ExyliaEnchants uses when they are present:

- **PlaceholderAPI**, **WorldGuard** (regions in [rules](/docs/exyliaenchants/presets-and-rules)) and **Vault**.
- The Exylia plugins listed in [Integrations](/docs/exyliaenchants/integrations).

## Steps

<Steps>
  <Step title="Add the plugins">
    Copy `ExyliaEnchants.jar` and `ExyliaLib.jar` into the server's `plugins/` folder.
  </Step>
  <Step title="Start the server">
    The first start registers the enchants and creates `config.yml`, `economy.yml`, `rules.yml`, `integrations.yml`, `balance.yml` and `menus.yml`, plus the `enchants/` and `lang/` folders. The full list is in [Configuration](/docs/exyliaenchants/configuration).
  </Step>
  <Step title="Check the console">
    ExyliaEnchants should load without errors. If you set `obtaining.table-share`, the console prints the factors it used, for example `table share 35%: custom weights scaled by 0.19 (swords), ...`.
  </Step>
  <Step title="Open the catalogue">
    Run `/enchants`. A list of enchants opens. Operators can also run `/enchantsadmin` (permission `exyliaenchants.admin`).
  </Step>
</Steps>

## Restart after changes to the registry

The enchants are part of the game's own registry, which is read once at startup. Changing an enchant's rarity, max level, items it applies to, costs or obtaining keys, and adding a new enchant, all need a restart. Descriptions, power cost, abilities and visuals reload with `/enchantsadmin reload`. The [Configuration](/docs/exyliaenchants/configuration) page marks which is which.

## Where things are saved

Everything is in `plugins/ExyliaEnchants/`. Enchants live in `enchants/*.yml`. Messages and menus are in `lang/<language>/`: change them with [Messages and languages](/docs/exylialib/messages-and-languages) and [Edit menus](/docs/exylialib/edit-menus). Each player's own settings are described in [Player settings](/docs/exyliaenchants/player-settings).

## Update the plugin

Replace the jar and restart. Your files are kept.
