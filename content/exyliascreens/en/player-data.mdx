You end up with a menu that remembers each player across restarts: a reward claimed once, a choice made, a counter. Values are stored in the plugin's table `exyliascreens_player_data`, in the database `database.yml` points to (H2 by default), and read before the player joins.

## Before you start

Have a menu with a slot or button to click, and know where the lines go: any interaction line works, in screens, chest and 3D clicks, holograms and NPCs. See [Add actions and requirements](/docs/exyliascreens/actions-and-requirements).

## Steps

<Steps>
  <Step title="Save a value on click">
    ```yaml
    welcome_gift:
      slot: 13
      click: ["[DATA] set welcome_gift true", "[MONEY] give 100"]
    ```
  </Step>
  <Step title="Show a different slot once it is set">
    ```yaml
    welcome_gift:
      slot: 13
      priority: 1
      if: "not data('welcome_gift')"            # the claimed version of the slot shows afterwards
      click: ["[DATA] set welcome_gift true", "[MONEY] give 100"]
    ```
    Give the claimed version the same `slot` with a lower `priority`.
  </Step>
  <Step title="Read it anywhere">
    - `data('key')` in `if`, `require` and `${...}`; `data('key', 'default')` for a default other than 0.
    - `%exyliascreens_data_<key>%` wherever placeholders work. It is empty when the player has no value.
  </Step>
</Steps>

## Check that it works

Click the slot twice: the first click pays and the second shows the claimed version. Restart the server and the claim is still there. A malformed line is reported in the debug log and does nothing.

## The lines

| Line | Does |
|---|---|
| `[DATA] set <key> <value>` | Sets it. Placeholders are allowed: `[DATA] set last_warp %warp%`. |
| `[DATA] add <key> [n]`, `[DATA] take <key> [n]` | Adds or takes a number (1 when left out). A missing value counts as 0. |
| `[DATA] toggle <key>` | Flips a flag between `true` and `false`. |
| `[DATA] remove <key>` | Forgets it (`clear` works too). |

Keys are letters, digits and `_ . -`, up to 64 characters; values are up to 256 characters.

## Resetting

The values are progress data owned by the player: `/exylialib resetplayer` and ExyliaLib's wipes clear them.
