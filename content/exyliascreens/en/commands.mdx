## /screens

`/screens` (aliases `/exyliascreens` and `/screensadmin`). Every subcommand needs `exyliascreens.admin`.

| Command | What it does |
|---|---|
| `/screens list` | Every menu with its command, its form and its fallback (`screen » hub_chest`). |
| `/screens open <id> [player]` | Opens a menu for you or for another player, or its fallback if the client cannot draw it. The console must name a player. |
| `/screens check` | Every problem in the files, with `file:line:col` for screens. |
| `/screens reload` | Reads configuration and every menu file again, reinstalls the commands and hands out the open items. |
| `/screens import deluxemenus [file]` | Imports DeluxeMenus menus. See [Importer](/docs/exyliascreens/importer). |
| `/screens import zmenu [file]` | Imports zMenu menus. |

Files are also read again on their own within two seconds of a change, so `reload` is mostly for configuration.

## Commands your menus install

Every menu's `command` and `aliases` become real commands on load and on reload. They are for players only, check the menu's `permission` and `require`, and take the words listed in `args`.
