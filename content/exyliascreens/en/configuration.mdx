Everything lives in `plugins/ExyliaScreens/`. `config.yml` holds four settings; the menus themselves are files you add and edit.

## Where the files are

| Path | What it is |
|---|---|
| `config.yml` | The four settings below. |
| `screens/` | Screens (`<id>.html`, with `theme.css` and `<id>.css` for their look). See [Screens](/docs/exyliascreens/screens). |
| `menus/` | Chest menus. See [Chest menus](/docs/exyliascreens/chest-menus). |
| `spatial/` | 3D menus. See [3D menus](/docs/exyliascreens/3d-menus). |
| `open-items.yml` | Items that open a menu. See [Open items](/docs/exyliascreens/open-items). |
| `lang/` and `messages.yml` | The plugin's messages and your menus' words. See [Translate your menus](/docs/exyliascreens/translations). |

## How to reload

- **Screens, chest menus and 3D menus** are read again within two seconds of being saved, added or removed. You do not need a command.
- **`config.yml`** is applied with `/screensadmin reload`.
- `/screensadmin check` lists every file that does not read, as `file:line:col`. A screen that no longer reads keeps its last working version.

## The settings you will change

### Open a menu when players join

Set `open-on-join` to the id of a menu, and every player who joins gets it after `open-on-join-delay` ticks (`40` by default, two seconds, so the world has loaded). Leave it empty for none.

### The language of the messages

`language` is `default`, which follows the language set in ExyliaLib. Write `en` or `es` to set this plugin alone. See [messages and languages](/docs/exylialib/messages-and-languages) for how the choice works across plugins.

### Players who prefer chest windows

Players can choose chest windows in `/settings`. With `follow-player-style: true` (the default) they get the chest fallback of any screen or 3D menu that has one. Set it to `false` to show them the form you wrote, as long as their client can draw it. See [Opening and fallbacks](/docs/exyliascreens/opening-and-fallbacks).

### The look of every screen

To restyle every plugin's screens at once, edit `plugins/ExyliaLib/screens/theme.css`. The menu style options players see in `/settings` belong to ExyliaLib's `screens.yml`. See [Styling](/docs/exyliascreens/styling) and [ExyliaLib colours](/docs/exylialib/colours).

<Details title="Every key of config.yml">

| Key | Default | Does |
|---|---|---|
| `language` | `default` | The language of the plugin's messages. `default` follows ExyliaLib's `config.yml`; a code such as `en` or `es` sets this plugin alone, and is a folder under `lang/` you can edit. |
| `follow-player-style` | `true` | Whether a player who chose chest windows in `/settings` gets a screen or 3D menu's fallback when it has one. Off: they get the form the owner wrote, as long as their client can draw it. |
| `open-on-join` | empty | The id of a menu opened for every player who joins, or empty for none. |
| `open-on-join-delay` | `40` | Ticks after joining before it opens (20 = one second), so the world has loaded. At least 1. |

</Details>
