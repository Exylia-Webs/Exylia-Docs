On its first start ExyliaScreens writes six screens into `plugins/ExyliaScreens/screens/`, ready to open. Edit the words, items and commands and they are your server's menus; reading one is the fastest way to learn what a screen can do.

## Make an example yours

<Steps>
  <Step title="Open it">
    Run `/play`, `/rewards`, `/welcome`, `/hub`, `/profile` or `/shop` in game (the commands are below).
  </Step>
  <Step title="Edit the file">
    Open the matching file in `plugins/ExyliaScreens/screens/`, for example `rewards.html`. Each screen has a `<id>.css` next to it, and its words live in the HTML itself. Save it; it reloads within two seconds.
  </Step>
  <Step title="Check it">
    Run `/screensadmin check` to see any line the plugin does not understand, then open the screen again.
  </Step>
</Steps>

<Callout type="note" title="Written once">
Each example is copied once, and `.examples-written` in the plugin folder lists what was written. A file already there is never replaced, and an example added by an update still reaches a server that has the others. To get a deleted one back, delete its line from `.examples-written` and restart. The examples are written in the server's language when the plugin has it, see [Translate your menus](/docs/exyliascreens/translations).
</Callout>

## The six screens

### Server selector: `/play`

`servers.html`, also `/servers` and `/modes`. Three mode cards, each with an icon, a short description, a status block and a button. A card reads its server live from the proxy: `online('survival')` says whether it is up and `players('survival')` how many are on it, refreshed every few seconds. The top right shows the whole network with `players()`. A click sends the player there with `[SERVER] survival`; a server that is down refuses with a shake and a toast. The third card is marked `disabled` and says "Coming soon".

To add a mode, copy a `<card>`, change the server name in `require`, `action` and the `players`/`online` calls, and pick its colour with `style="--tone: {success}"`. Put your own addresses in the Discord and Store toasts.

<Callout type="warning" title="Player counts need the proxy bridge">
`players('name')` and `online('name')` come from ExyliaLib's proxy module, which needs ExyliaProxyUtils 2.2.0 or newer on the proxy. Without it they read 0 and offline, and `players()` counts this server only.
</Callout>

### Daily rewards: `/rewards`

`rewards.html`, also `/daily`. Seven day cards. Today's card glows; claiming it runs its console command, adds one to the streak and starts a 24 hour wait. Claimed days show a tick, later days a dot, and day 7 starts the week again. Under the cards a line counts down to the next reward and a bar fills with the streak.

Each day is one line at the bottom of the file, so changing a reward is changing a line:

```html
<day n="5" item="golden_apple" reward="2 Golden apples" command="give %player_name% golden_apple 2"/>
```

The streak only grows: a missed day does not reset it. It is built from three pieces you can reuse: `data('streak')` kept per player (see [Remember a value per player](/docs/exyliascreens/player-data)), `cooldown="daily 24h"` on the card (a wait of 5 minutes or more survives restarts) with `cooldown('daily')` showing the seconds left through `fmt.time(...)`, and a `<template name="day">`.

### Welcome tour: `/welcome`

`welcome.html`, also `/tour`. Four short pages for new players, each a picture and a paragraph. A and D, the buttons or the dots turn the pages, and the last one closes the tour and remembers it with `[DATA] set welcomed true`, so an [open item](/docs/exyliascreens/open-items) or a join command can skip players who saw it (`data('welcomed')`). Every page is one `<case>` inside the `<switch>`: change its item, title and text. To add a page, copy a case, add a `<tab>` to the dots and raise the `4`s.

### Hub, profile and shop

`hub.html` (`/hub`, `/warps`), `profile.html` (`/profile`, `/me`) and `shop.html` (`/shop`) link to each other.

- **Hub**: the player's face, warps and servers as tiles, and a VIP tile that only opens for a permission and shakes for everyone else.
- **Profile**: the player's turning body and their balance, level, world and rank, all read live.
- **Shop**: four items paid through the server's economy, see [ExyliaLib: Economy](/docs/exylialib/economy). A price turns red when the player cannot afford it, and the sword asks first.

The hub and the shop have chest fallbacks (`menus/hub_chest.yml`, `menus/shop_chest.yml`) for players who chose chest menus; `menus/players.yml` (`/players`) is a chest list of online players. See [Open a menu and set its fallback](/docs/exyliascreens/opening-and-fallbacks).

<Details title="Motion used by each example">

- Selector: the title types itself out, the cards arrive one after another (`stagger`), each icon floats, the "Online" dot beats.
- Rewards: cards drop in with a `bounce`, today's card pulses, day 7's item floats, a claim pops the card and an early click shakes it.
- Welcome: pages slide in and out, the title types itself out and the paragraph rises after it (`stagger` with `text-reveal`), the last button pulses.
- Shop: a purchase pops the card and a click the player cannot pay shakes it.

Every one is explained in [Animate a screen](/docs/exyliascreens/motion).

</Details>
