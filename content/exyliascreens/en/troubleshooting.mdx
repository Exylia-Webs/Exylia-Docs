Find your symptom, then follow the fix. Start by running `/screensadmin check`: it lists mistakes in your files with `file:line:col`.

## The plugin does not start

The console names what is missing. ExyliaLib and packetevents are required. The loader installs ExyliaLib for you and a fresh install needs one more restart; the licence key goes in `loader.yml`, `license_key`. See [Installation](/docs/exyliascreens/installation).

## A menu does not open, or its command does not exist

- Run `/screensadmin list`. If the menu is not there, it is in the wrong folder (`screens/` for `.html`, `menus/` or `spatial/` for `.yml`) or has a mistake: `/screensadmin check` says which.
- Files are read again within two seconds of being saved. Changes to `config.yml` need `/screensadmin reload`.
- The command comes from the menu's `command` and `aliases`, not from the file name.

## Players get a chest menu, not the screen

That is the fallback working. A player gets it when their client cannot draw the screen (Bedrock, or Java older than 1.20.2; 3D menus need 1.21.4), when the menu's `min-client` is newer than their client, or when they chose chest windows in `/settings` and `follow-player-style` is on in `config.yml`. See [Opening and fallbacks](/docs/exyliascreens/opening-and-fallbacks).

## "You cannot open this screen"

The menu has a `permission` the player lacks. See [Permissions](/docs/exyliascreens/permissions).

## The sidebar, HUD or boss bar does not show

- In the shipped `scoreboards.yml` the `main` entry has `enabled: false`. Set it to `true`.
- The HUD design is drawn only for Java 1.20.2 or newer players who keep **Show HUD** on in `/settings`. Everybody else sees the vanilla sidebar or boss bar written under it, so write both.
- Only the entry with the highest `priority` whose `when`, `permission` and `worlds` hold shows.

See [HUD, sidebar and boss bars](/docs/exyliascreens/hud).

## A placeholder shows as text

Install PlaceholderAPI. `%player_...%` placeholders also need its Player expansion. `%exyliascreens_data_<key>%` is empty until a menu saves that key. See [Placeholders](/docs/exyliascreens/placeholders).

## An example menu I deleted does not come back

That is intended. `plugins/ExyliaScreens/.examples-written` lists what was written. Delete a line from it to get that example again.

## `check` says a screen is heavy for players' games

The screen draws many pictures or elements and slows the client. Use fewer or smaller `<img>`, bodies and background pictures. ExyliaScreens already draws it at lower detail when it can.
