You will open an example menu, then write a `/rules` screen of your own and see it open in game. Join as an operator, with ExyliaScreens [installed](/docs/exyliascreens/installation) and a Java 1.20.2 or newer client.

## Steps

<Steps>
  <Step title="Open the hub">
    Run `/hub`. You get a full-screen menu with a mouse cursor, your face and buttons to **Profile** and **Shop**. Move the mouse, click a button, then press Shift to close it.
  </Step>
  <Step title="See what is loaded">
    Run `/screensadmin list`. Each line shows a menu, its command and its form. `hub` appears as `screen » hub_chest`: the form, then the chest menu a client that cannot draw screens gets.
  </Step>
  <Step title="Open the chest version">
    Run `/screensadmin open hub_chest` to see that fallback.
  </Step>
  <Step title="Write your own screen">
    Create `plugins/ExyliaScreens/screens/rules.html` with the file below and save it. It is read again within two seconds, so there is no reload.
  </Step>
  <Step title="Check it">
    Run `/screensadmin check`. It lists anything it does not understand, with `file:line:col`. Run it after every edit.
  </Step>
</Steps>

```html
<screen command="rules" aliases="r">
  <panel>
    <h1>{primary}Rules</h1>
    <p>Be kind. No cheating. Have fun.</p>
    <button action="close">Got it</button>
  </panel>
</screen>
```

## Check that it works

Run `/rules` (or `/r`). The panel opens with the title and the **Got it** button. Click the button or press Shift and it closes. If nothing opens, see [Common problems](/docs/exyliascreens/troubleshooting).
