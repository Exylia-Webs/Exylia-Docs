## Is ExyliaScreens free?

No. It is a premium plugin installed as a loader jar that checks the licence on every start. It is not on BuiltByBit yet; request a key on the [Exylia Discord](https://discord.exylia.net). See [Installation](/docs/exyliascreens/installation).

## Which players can see a screen?

Java clients 1.20.2 or newer, with PacketEvents on the server. Bedrock players cannot. 3D menus need Java 1.21.4 or newer. Give the menu a chest [fallback](/docs/exyliascreens/opening-and-fallbacks) that you write yourself: nothing is generated for them.

## A player sees the chest version of my screen

Their client cannot draw screens, the menu's `min-client` is above their version, or they chose chest windows in `/settings` and `follow-player-style` is `true`. Set it to `false` in [config.yml](/docs/exyliascreens/configuration) to show the screen to anyone who can see it.

## A player with an old client is told the menu does not work on their client

The menu has no fallback. Add `fallback="your_chest_menu"` to it and write that [chest menu](/docs/exyliascreens/chest-menus).

## My edit does nothing

Files are read again within two seconds of being saved. Run `/screensadmin check`: a screen that no longer reads keeps its last working version, and the problem is listed as `file:line:col`. See [Common problems](/docs/exyliascreens/troubleshooting).

## Can I use my DeluxeMenus or zMenu menus?

Yes: `/screensadmin import deluxemenus` and `/screensadmin import zmenu`. Some things do not map; they are listed in the console and at the top of the generated HTML. See [Importer](/docs/exyliascreens/importer).

## The examples came back, or did not come back

Each example is written once. `.examples-written` in `plugins/ExyliaScreens/` lists what was written, so a file you delete stays deleted. Remove its line from that file to get it again; a file that already exists is never replaced.

## Where is the full markup and CSS reference?

In ExyliaLib's repository documentation (`docs/screens.md`). This site covers [Screens](/docs/exyliascreens/screens) for server owners, and `/exylialib screens gallery` shows every element in game.
