## Is ExyliaScreens free?

No. It is a premium plugin installed as a loader jar that checks the licence on every start. It is not on BuiltByBit yet; request a key on the [Exylia Discord](https://discord.exylia.net). See
[Installation](/docs/exyliascreens/installation).

## Which players can see a screen?

Java clients 1.20.2 or newer, with PacketEvents on the server. Bedrock players cannot. Give the menu a [fallback](/docs/exyliascreens/opening-and-fallbacks) you write yourself: nothing is generated for
them. 3D menus need Java 1.21.4 or newer.

## A player sees the chest version of my screen

Either their client cannot draw screens, `min-client` is above their version, or they chose chest windows in `/settings` and `follow-player-style` is `true`. Set it to `false` to show the screen
to anyone who can see it.

## A player with an old client gets "does not work there"

Their menu has no fallback. Add `fallback="your_chest_menu"` and write that chest menu.

## My edit does nothing

Files are read again within two seconds of being saved. Run `/screens check`: a screen that no longer reads keeps its last working version, and the problem is listed with `file:line:col`.

## Can I use my DeluxeMenus menus?

Yes: `/screens import deluxemenus` and `/screens import zmenu`. Some things do not map and are listed in the console and at the top of the HTML. See [Importer](/docs/exyliascreens/importer).

## The examples came back, or did not come back

They are written once; `.examples-written` in `plugins/ExyliaScreens/` stops them returning. Delete the marker to get the missing ones again. Existing files are never replaced.

## Where is the full markup and CSS reference?

In ExyliaLib's repository documentation (`docs/screens.md`). This site covers [Screens](/docs/exyliascreens/screens) for server owners; `/exylialib screens gallery` shows every element in game.
