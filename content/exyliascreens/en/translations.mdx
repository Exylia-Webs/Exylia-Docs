You end up with a screen whose words live in a language file, so one screen serves servers in several languages, and with the plugin's own messages reworded to your taste.

## Before you start

- A server has one language, so a screen is written in it: the examples are installed already in the server's language, with the words in the HTML where you edit them. Skip this page if that is you.
- Keys are for one file shared by servers in different languages. Colour tokens in words are explained in [ExyliaLib colours](/docs/exylialib/colours); the language the server follows is in [messages and languages](/docs/exylialib/messages-and-languages).

## Steps

<Steps>
  <Step title="Give the element a key">
    ```html
    <h1 t="hub.title">{primary}Galaxy {letters}Hub</h1>
    ```
    `t="hub.title"` reads `hub.title` from `plugins/ExyliaScreens/lang/<code>/screens/hub.yml`: the server's language first, then English. The text written in the HTML stays when no file has the key. `t-<attribute>="key"` does the same for an attribute.
  </Step>
  <Step title="Write the words in the language file">
    ```yaml
    # lang/es/screens/hub.yml
    hub:
      title: '{primary}Galaxia {letters}Hub'
    ```
  </Step>
</Steps>

An element with `t` holds only text, since the word replaces its children. Words may hold colour tokens, `%placeholders%` and `${...}`; `t('key', 'fallback')` reads one inside an expression.

## Check that it works

Save both files (they reload within 2 seconds), open the screen and read the title in the server's language. Switch `language` in ExyliaLib's config to see the English fallback appear when a key is missing. `/screensadmin check` lists problems.

## Chest and 3D menus

They hold their own words in the file. The examples are shipped translated: the first start writes them in the server's language (`lang/<code>/examples/`) when the plugin has it, and in the default English otherwise.

## The plugin's messages

`messages.yml` holds the plugin's own lines (reloaded, problems, unknown menu...). The `language` setting of `config.yml` picks them: `default` follows ExyliaLib's language, or name a folder under `lang/`. English, Spanish, French, Portuguese, Russian and Turkish folders ship.
