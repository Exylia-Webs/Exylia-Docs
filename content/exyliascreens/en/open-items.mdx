---
title: "Items that open a menu"
description: "open-items.yml: protected hotbar items, like a lobby compass, that open a menu."
---

`open-items.yml` hands players items that open a menu: a lobby compass, a profile head. They cannot be dropped, moved, placed or lost on death, come back on join, respawn and world change, and
are taken away when the file no longer names them. A slot already holding something of the player's is left alone.

```yaml
items:
  hub:
    menu: hub
    slot: 4                  # 0-8 the hotbar
    material: COMPASS
    name: "{info}Navigator"
    permission: ""           # '' for everybody
    worlds: [lobby]          # empty for every world
```

| Key | Does |
|---|---|
| `menu` | The id of the menu it opens, of any form. Required. |
| `slot` | 0 to 35: 0-8 is the hotbar, 9-35 the rest of the inventory. Required. |
| `permission` | Who gets the item; empty for everybody. |
| `worlds` | The worlds it is given in; empty for all. |
| `enabled` | `false` skips the entry. |

Every key of a menu item works too (`playerhead-`, `nexo:`, `custom-model-data`, `name`, `lore`, `glow`...). The file is read again with the others; `/screensadmin check` lists entries with a bad slot,
a missing menu, or a menu that does not exist. It is also editable in the browser through ExyliaLib's [web editor](/docs/exylialib/web-editor), which refuses a version with problems.
