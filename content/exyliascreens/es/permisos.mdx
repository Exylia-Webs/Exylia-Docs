Los jugadores no necesitan ningún permiso para abrir un menú, salvo que se lo pongas tú. Solo `/screensadmin` está bloqueado, para operadores.

Para dárselo a un rango con LuckPerms: `/lp group admin permission set exyliascreens.admin true`.

## Bloquear un menú tras un rango

El permiso de un menú es el que diga su atributo `permission`, con el nodo que elijas (por ejemplo `servidor.vip`). El plugin no declara esos nodos, así que créalos en tu plugin de permisos. Sin `permission`, todos pueden abrir el menú.

Un jugador sin él recibe un mensaje de falta de permiso. Para comprobaciones más finas dentro de un menú, `require` y `deny` aceptan `perm('nodo')`. Consulta [Acciones y requisitos](/docs/exyliascreens/acciones-y-requisitos).

Lo mismo vale para las entradas de `scoreboards.yml`, `hud.yml` y `bossbars.yml`: su clave `permission` solo las muestra a quien lo tenga.
