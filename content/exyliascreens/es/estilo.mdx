---

Las pantallas se estilizan con un subconjunto de CSS. Las hojas se leen en este orden, y las posteriores ganan:

1. El tema base de ExyliaLib (dentro de la librería).
2. `plugins/ExyliaLib/screens/theme.css`: el tema de la red, que restiliza las pantallas de **todos** los plugins a la vez.
3. `plugins/ExyliaScreens/screens/theme.css`: compartido por todas las pantallas de ExyliaScreens.
4. `plugins/ExyliaScreens/screens/<id>.css`: el de una pantalla.
5. `plugins/ExyliaScreens/screens/custom.css`: el tuyo; el plugin nunca lo trae, así que gana a todo lo anterior.

Dentro de una hoja, las reglas se resuelven por especificidad y luego por orden. Los cambios se ven en las pantallas abiertas en dos segundos.

```css
.tile { width: 80px; height: 64px; padding: 6px; gap: 2px; }
.tile:hover { outline: 1px {secondary}; }
.price-short { color: {error_light}; }
```

Usa tokens de la paleta (`{primary}`, `{success}`, `{error_light}`...) en lugar de colores hexadecimales, para que `colors.yml` lo recolorea todo. Los archivos que trae el plugin hacen lo mismo.

Las propiedades y selectores (`:hover`, `[selected]`, `:nth-child`, propiedades personalizadas con `var(--nombre)`, movimiento con `transition` y `animation`, degradados) son de ExyliaLib: consulta su
referencia de pantallas, y `/exylialib screens gallery` para ver cada elemento y copiarlo.

## Pantallas importadas

Las pantallas del importador usan las clases `.chest`, `.chest-title`, `.chest-row`, `.slot`, `.slot.empty` y `.amount`; el `theme.css` que trae el plugin las estiliza.
