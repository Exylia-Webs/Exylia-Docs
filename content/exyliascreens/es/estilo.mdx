Al terminar tendrás pantallas que combinan con el aspecto de tu servidor: un archivo que las restiliza todas, o un cambio para una sola, sin tocar el HTML de los ejemplos.

## Antes de empezar

Las pantallas usan un subconjunto de CSS. Las propiedades y selectores (`:hover`, `[selected]`, `:nth-child`, `var(--nombre)`, degradados) son de ExyliaLib, mira [ExyliaLib: Pantallas](/docs/exylialib/screens); `/exylialib screens gallery` muestra cada elemento para copiarlo. Usa tokens de la paleta (`{primary}`, `{success}`, `{error_light}`...) en lugar de colores hexadecimales, para que `colors.yml` lo recolorea todo, mira [ExyliaLib: Colores](/docs/exylialib/colours). Los archivos que trae el plugin hacen lo mismo.

## Pasos

<Steps>
  <Step title="Elige dónde va el cambio">
    Una pantalla: `plugins/ExyliaScreens/screens/<id>.css`. Todas las de ExyliaScreens: `plugins/ExyliaScreens/screens/theme.css`. Las pantallas de todos los plugins de Exylia: `plugins/ExyliaLib/screens/theme.css`. Tus cambios que sobreviven a cualquier actualización: `plugins/ExyliaScreens/screens/custom.css`, que el plugin nunca trae.
  </Step>
  <Step title="Escribe la regla">
    ```css
    .tile { width: 80px; height: 64px; padding: 6px; gap: 2px; }
    .tile:hover { outline: 1px {secondary}; }
    .price-short { color: {error_light}; }
    ```
  </Step>
  <Step title="Guarda y mira">
    Los cambios se ven en las pantallas abiertas en menos de dos segundos. `/screensadmin check` avisa de una propiedad que no conoce.
  </Step>
</Steps>

## Comprueba que funciona

Abre una pantalla que use la clase que estilizaste (por ejemplo `/shop`) y el cambio está ahí. Si no, una hoja posterior o un atributo `style` lo está pisando; mira el orden de abajo.

## Qué hoja gana

Las hojas se leen en este orden, y las posteriores ganan:

1. El tema base de ExyliaLib (dentro de la librería).
2. `plugins/ExyliaLib/screens/theme.css`: el tema de la red.
3. `plugins/ExyliaScreens/screens/theme.css`: compartido por todas las pantallas de ExyliaScreens.
4. `plugins/ExyliaScreens/screens/<id>.css`: el de una pantalla.
5. `plugins/ExyliaScreens/screens/custom.css`: el tuyo; gana a todo lo anterior.

Dentro de una hoja, las reglas se resuelven por especificidad y luego por orden.

## Dale estilo a un solo elemento

`style="..."` en cualquier elemento fija declaraciones solo para ese elemento, por encima de todas las reglas de todas las hojas, como en una página web. Los placeholders y `${...}` funcionan dentro.

```html
<card style="width: 120px; background: {success}20">...</card>
<small style="color: ${balance() >= 50 ? '{success}' : '{error_light}'}">50 monedas</small>
```

Su mejor uso es una **propiedad personalizada** que lee la hoja, de modo que una línea recolorea una tarjeta entera y todo lo que lleva dentro. El [selector de servidores](/docs/exyliascreens/ejemplos) lo hace así:

```css
.mode { --tone: {primary}; }
.mode:hover { outline: 1px var(--tone); background: var(--tone)16; }
.mode-name { color: var(--tone); }
```

```html
<card class="mode" style="--tone: {success}">...</card>
<card class="mode" style="--tone: {info}">...</card>
```

`var(--tone)16` es el tono con transparencia, igual que `{success}16`.

<Details title="Movimiento y pantallas importadas">

`transition`, `enter`, `leave`, `animation`, `stagger` y `text-reveal` también son estilo: mira [Anima una pantalla](/docs/exyliascreens/movimiento).

Las pantallas que escribe el [importador](/docs/exyliascreens/importador) usan las clases `.chest`, `.chest-title`, `.chest-row`, `.slot`, `.slot.empty` y `.amount`; el `theme.css` que trae el plugin las estiliza.

</Details>
