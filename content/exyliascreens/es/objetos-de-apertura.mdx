---
title: "Objetos que abren un menú"
description: "open-items.yml: objetos protegidos de la barra rápida, como una brújula de lobby, que abren un menú."
---

`open-items.yml` da a los jugadores objetos que abren un menú: una brújula de lobby, una cabeza de perfil. No se pueden tirar, mover, colocar ni perder al morir, vuelven al entrar, reaparecer y
cambiar de mundo, y se retiran cuando el archivo deja de nombrarlos. Una ranura que ya tiene algo del jugador se deja en paz.

```yaml
items:
  hub:
    menu: hub
    slot: 4                  # 0-8 la barra rápida
    material: COMPASS
    name: "{info}Navegador"
    permission: ""           # '' para todos
    worlds: [lobby]          # vacío para todos los mundos
```

| Clave | Qué hace |
|---|---|
| `menu` | El id del menú que abre, de cualquier forma. Obligatorio. |
| `slot` | De 0 a 35: 0-8 es la barra rápida, 9-35 el resto del inventario. Obligatorio. |
| `permission` | Quién recibe el objeto; vacío para todos. |
| `worlds` | Los mundos en los que se da; vacío para todos. |
| `enabled` | `false` omite la entrada. |

También funciona cualquier clave de un objeto de menú (`playerhead-`, `nexo:`, `custom-model-data`, `name`, `lore`, `glow`...). El archivo se vuelve a leer junto con los demás; `/screensadmin check` lista las
entradas con una ranura incorrecta, sin menú o con un menú que no existe. También se puede editar en el navegador con el [editor web](/docs/exylialib/editor-web) de ExyliaLib, que rechaza una versión con problemas.
