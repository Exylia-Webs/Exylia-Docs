---
title: "Menús 3D"
description: "spatial/<id>.yml: paneles en el mundo, con un bloque menu que guarda lo que contienen."
---

`spatial/<id>.yml` es un menú dibujado como paneles en el mundo frente al jugador. Necesita un cliente **Java 1.21.4 o superior**. El diseño (paneles, cuadrículas, listas, carruseles, tema) es el
formato espacial de ExyliaLib; un bloque `menu` guarda lo que contiene el menú. La primera carga escribe, con comentarios, todas las claves de diseño que el archivo omitió.

```yaml
title: "{primary}&lWARPS"
panels:
  warps:
    at: [0, 0, 0]
    size: [3.6, 1.5]
    title: "{secondary}&l¿ADÓNDE?"
    content: {type: GRID, source: warps, columns: 4, rows: 2}
    footers:
      - {label: "{success}Tienda", action: shop}
      - {label: "{error}Salir", action: leave}   # leave lo cierra
preview: {visible: false}
carousel: {source: ""}
menu:
  command: warps3d
  fallback: warps_chest
  lists:
    warps:                                       # lo que lee source
      entries:
        spawn:
          priority: 1
          if: "perm('warp.spawn')"
          material: COMPASS
          name: "{info}Spawn"
          subtitle: "{letters_black}Zona segura"
          require: "balance() >= 10"
          deny: ["[MESSAGE] {error}Necesitas 10 monedas."]
          click: ["[MONEY] take 10", "[CLOSE]", "[PLAYER] spawn"]
  buttons:
    shop: ["[SCREEN] shop"]                      # lo que lee action
```

## El bloque `menu`

| Clave | Qué hace |
|---|---|
| `command`, `aliases`, `permission`, `require`, `deny`, `fallback`, `min-client`, `args`, `on-open` | Las claves de apertura, aquí bajo `menu:`. Consulta [Apertura y alternativas](/docs/exyliascreens/apertura-y-alternativas). |
| `lists.<nombre>.entries` | Las entradas que lee el `source: <nombre>` de un panel. Cada una admite las claves de una ranura de cofre (`priority`, `if`, `material`, `name`, `require`, `deny`, `click`) y un `subtitle`. |
| `buttons.<nombre>` | Las líneas de interacción que ejecuta el `action: <nombre>` de un panel. |

Una entrada 3D tiene un solo clic, así que los filtros `right:` nunca se ejecutan. Mira una pieza y agáchate para salir. `/screens check` avisa cuando un panel lee una lista que el bloque no tiene.

El ejemplo es `spatial/warps_3d.yml`, que se abre con `/warps3d`; un cliente que no pueda dibujarlo recibe `hub_chest`. Las claves de paneles, anclaje, `freeze` y `hide-others` son del diseño espacial de
ExyliaLib.
