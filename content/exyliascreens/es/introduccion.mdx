ExyliaScreens es un plugin de menús sin Java y sin resource pack. Escribes los menús como archivos en `plugins/ExyliaScreens/` y el plugin los abre con comandos, objetos, clics y entradas al
servidor. Es un reemplazo de DeluxeMenus, más dos formas que DeluxeMenus no sabe dibujar. Está construido sobre los motores de menús, pantallas y espaciales de ExyliaLib.

Es un plugin **premium**, instalado mediante un cargador de licencia. Consulta [Instalación](/docs/exyliascreens/instalacion).

## Tres formas, un id

Un menú es un archivo y la carpeta dice qué es. El nombre del archivo es su id.

| Carpeta | Forma | Cliente necesario |
|---|---|---|
| `screens/<id>.html` | Una **pantalla**: un menú a pantalla completa con cursor de ratón, escrito en HTML y CSS. | Java 1.20.2 o superior |
| `menus/<id>.yml` | Un **menú de cofre**: una ventana de cofre normal. | Cualquier cliente |
| `spatial/<id>.yml` | Un **menú 3D**: paneles en el mundo frente al jugador. | Java 1.21.4 o superior |

Las tres se abren igual (comando, alias, permiso, requisito, argumentos) y ejecutan las mismas líneas de acción. Un menú puede nombrar otro en `fallback`, el que recibe un cliente que no puede
dibujarlo. **La alternativa la escribes tú; no se genera nada.** Consulta [Apertura y alternativas](/docs/exyliascreens/apertura-y-alternativas).

## Requisitos

| Requisito | Detalle |
|---|---|
| Servidor | Paper 1.21.4 o superior (el `api-version` de `paper-plugin.yml`), o Folia (`folia-supported: true`). |
| ExyliaLib | Obligatorio. El README indica 1.539.0 o superior. |
| PacketEvents | Lo necesita ExyliaLib; las pantallas y los menús 3D se dibujan con paquetes. |
| Opcional | PlaceholderAPI. |

Las pantallas y los menús 3D no se dibujan para jugadores de Bedrock ni para clientes Java más antiguos que los números de arriba. Los menús de cofre los ve todo el mundo.

## La referencia de ExyliaLib

La referencia completa de marcado, CSS, expresiones y movimiento de las pantallas es de ExyliaLib (su `docs/screens.md`, con la referencia de marcado y el recetario al lado). No se reproduce aquí: esta
documentación cubre lo que necesita un dueño de servidor y enlaza los conceptos. Las listas, páginas y rellenos de los menús de cofre están en [ExyliaLib: Menús](/docs/exylialib/menus). Ejecuta
`/exylialib screens gallery` en el juego para ver cada elemento de pantalla, listo para copiar.

## Cómo leer esta documentación

Empieza por [Instalación](/docs/exyliascreens/instalacion) y [Primeros pasos](/docs/exyliascreens/primeros-pasos). **Menús** cubre cada forma y todo lo que puede hacer un clic; **Servidor** es el
importador; **Referencia** lista comandos, permisos, placeholders, configuración y las preguntas frecuentes.
