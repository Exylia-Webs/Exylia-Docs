## Is it free?

Yes. ExyliaDisplays is free and open source under the GNU General Public License v3.0. Download it from
[GitHub releases](https://github.com/Exylia-Plugins/ExyliaDisplays/releases); there is no licence key.

## I used ExyliaHolograms. What do I do?

Replace the jar and start the server: `holograms.yml` is copied over on the first start and
`exyliaholograms.admin` keeps working. Remove the old jar, or both plugins draw every hologram. See
[Migration](/docs/exyliadisplays/migration).

## /npc opens Citizens instead

Both plugins register `/npc`. Use `/npcs <name>` or `/exylianpc <name>`; `/npcadmin` never clashes. Once
you have imported your Citizens NPCs, removing Citizens gives `/npc` back.

## %player_name% shows as written

- **In a hologram**: the placeholder must be one PlaceholderAPI or ExyliaLib knows; a hologram with a
  placeholder is drawn per viewer on its own. Check that PlaceholderAPI and the expansion are installed.
- **In an NPC label**: labels are drawn once for everybody, so player placeholders are not filled per
  viewer. Put a hologram above the NPC with `/npc <name> link <hologram>` instead.
- **In a `[SAY]` or other action**: placeholders resolve for the player who clicked.

## A hologram or NPC disappeared after I edited the file

The file probably no longer parses (indentation, an unclosed quote). A file that cannot be read is taken
as empty, so everything in it disappears until it is fixed; the console says so and the admins online get
the mistakes message. Fix the YAML and save again. See
[Editing the files](/docs/exyliadisplays/editing-files#mistakes).

## An NPC does nothing when clicked

Turn `debug: true` on in `config.yml` and click it: the console says whether the click ran, was ignored
(no line answers that click — for example a sneaking click on `left:` lines), was denied (the
`interactions.permission`) or is cooling down. A line the plugin could not understand is reported once,
when the NPC is loaded.

## My linked hologram stopped following its NPC

The hologram was renamed or deleted; the NPC still names the old one. Link it again with
`/npc <name> link <hologram>`. See [NPCs](/docs/exyliadisplays/npcs#a-linked-hologram).

## Do animated NPCs need MineSkin or a resource pack?

No. A performance wears the NPC's skin through real skin pieces (Exylia Skins), so there is nothing to
upload and nothing for players to download. Animations are Blockbench projects saved into
`plugins/ExyliaDisplays/animations`, played as they are; see [Blockbench](/docs/exyliadisplays/npcs#blockbench).

## My continuous idle flashes between loops

The clip does not loop: it plays to its end, the NPC is shown for a moment, and it starts again. Set the
clip to loop in Blockbench (Loop mode **Loop**) or write it `loop:true;anim:<clip>`. `/npcadmin animations` says which
clips loop.

## I switched a module off and it is still running

`modules` needs a restart; `/displays reload` does not start or stop modules.

## Does it work on Folia?

Yes. `folia-supported: true`, and every change is done on the thread that owns the player or entity.

## Do holograms and NPCs cost server performance?

Very little. They are packets: no entity is spawned, nothing is saved in chunks and nothing ticks. A
hologram with no placeholders is drawn once; motion is interpolated by the client. `per-player` costs one
set of packets per viewer, so leave it off unless a line needs it.

## Is there an API?

No ExyliaDisplays API. A plugin that wants holograms or NPCs uses ExyliaLib's own (`Holograms`, `Npcs`),
which is what this plugin draws with; see the [ExyliaLib documentation](/docs/exylialib/displays-and-npcs).
Other plugins can still hook in through `[ACTION] namespace:id` lines.
