---
title: "Permissions"
description: "The nodes plugin.yml declares, what each gates, the ExyliaHolograms name, and the permissions you set on holograms, lines and NPCs."
---

Every node is declared in `plugin.yml`, and every one defaults to **operators**. Players need no node to
see holograms and NPCs or to click them; those are gated by the permissions you set on each one.

## Plugin nodes

| Permission | Default | What it gates |
|---|---|---|
| `exyliadisplays.holograms` | operators | `/holo`, `/holoadmin`, the hologram screens and every button in them, and the message when `holograms.yml` is applied. |
| `exyliadisplays.npcs` | operators | `/npc`, `/npcadmin`, the NPC screens and every button in them, and the message when `npcs.yml` is applied. |
| `exyliadisplays.admin` | operators | `/displays`; includes `exyliadisplays.holograms` and `exyliadisplays.npcs`. |
| `exyliadisplays.*` | operators | Everything; includes `exyliadisplays.admin`. |
| `exyliaholograms.admin` | operators | The ExyliaHolograms name, kept working; includes `exyliadisplays.holograms`. |

There is no split between viewing and editing: whoever can open a hologram's editor can change or delete
it, and the same goes for NPCs.

## Permissions you set

| Where | Set with | Effect |
|---|---|---|
| A hologram's `permission` | `/holo <name> permission <node>` | Only players with it see the hologram. |
| A line's `<perm:node>` / `<perm:!node>` | `/holo <name> line <n> permission <node>` | Only players with (or without) it see that line. |
| An NPC's `permission` | `/npc <name> permission <node>` | Only players with it see the NPC and its label. |
| An NPC's `interactions.permission` | `/npc <name> action permission <node>` | Everyone sees it; only players with the node can use it. The rest get the refusal message. |

These are any node you choose; nothing has to declare them. A hologram's clicks have no permission of their
own: use the hologram's `permission`, or a `<perm>` line, or gate the command the click runs.

## Examples

A staff group that edits holograms but not NPCs:

```text
/lp group builder permission set exyliadisplays.holograms true
```

An NPC only VIPs can use, visible to everyone:

```text
/npc vip_shop action permission group.vip
/npc vip_shop action denymessage {error}This shop is for VIPs.
```
