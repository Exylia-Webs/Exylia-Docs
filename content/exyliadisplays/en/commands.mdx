| Command | Aliases | Permission | |
|---|---|---|---|
| `/displays` | `/exyliadisplays`, `/edisplays` | `exyliadisplays.admin` | The plugin as a whole. |
| `/holoadmin` | `/hologramadmin` | `exyliadisplays.holograms` | Every hologram, and what is not about one. |
| `/holo <name> …` | `/hologram` | `exyliadisplays.holograms` | One hologram. |
| `/npcadmin` | `/npcsadmin` | `exyliadisplays.npcs` | Every NPC, and what is not about one. |
| `/npc <name> …` | `/npcs`, `/exylianpc` | `exyliadisplays.npcs` | One NPC. |

The commands of a module that is switched off do not exist. Name arguments suggest the existing names.
Commands that need a place or a screen (`create`, `movehere`, `tp`, `face`, `adjust`, `near`, `page <n>`,
`lines`, `equipment`) are for players; the rest also run from the console. A name with no setting opens
the editor for a player and prints the details for the console.

## /displays

| Command | Does |
|---|---|
| `/displays` · `/displays help` | The help. |
| `/displays modules` | Each module and whether it runs. |
| `/displays reload` | Reads every file again and redraws everything. See [Editing the files](/docs/exyliadisplays/editing-files#reloads). |

## /holoadmin

| Command | Does |
|---|---|
| `/holoadmin` · `/holoadmin list` | The list screen; one line per hologram for the console. |
| `/holoadmin help` | The help. |
| `/holoadmin create <name> [text]` | A hologram where you stand, with `text` as its line (or its name in bold). |
| `/holoadmin near [radius]` | The holograms around you, nearest first. Default radius `near-radius` (20). |
| `/holoadmin reload` | Reloads everything, then reports `holograms.yml`'s count and mistakes. |
| `/holoadmin import <source> [replace]` | `decentholograms`, `holographicdisplays`, `fancyholograms`. See [Migration](/docs/exyliadisplays/migration). |

## /holo

`/holo <name>` opens the editor. `/holo` and `/holo help` print the help.

### The hologram

| Command | Does |
|---|---|
| `info` | Its details, every line and every click action. |
| `lines` | The lines screen. |
| `rename <new>` · `clone <copy>` | Renames it / copies it in the same place. |
| `enable` · `disable` | Shows it / keeps it without showing it. |
| `delete` | Asks a player first; the console deletes at once. |

### Where it stands

| Command | Does |
|---|---|
| `tp` | Takes you to it. |
| `movehere` | Moves it to you, facing you. |
| `move <x> <y> <z> [world]` | Moves it. |
| `center` | Centres it on its block. |
| `rotate <yaw> [pitch]` | Turns it; pitch -90 to 90. A `center` billboard becomes `fixed`. |
| `face` | Turns it to face you. |
| `adjust` · `adjust save` · `adjust cancel` | [Fine adjust](/docs/exyliadisplays/fine-adjust). |

### Lines

| Command | Does |
|---|---|
| `addline <text>` | Adds a line at the bottom. |
| `insertline <n> <text>` | Inserts a line at `n`. |
| `setline <n> <text>` | Replaces line `n`. |
| `removeline <n>` | Removes line `n`. |
| `moveline <from> <to>` | Moves a line. |
| `line <n> <tag> [value]` | Sets one [tag](/docs/exyliadisplays/line-tags) of line `n`; no value or `reset` takes it off, `on` is the default. Tags: `text`, `size`, `head`, `opacity`, `background`, `shadow`, `glow`, `spin`, `bob`, `pulse`, `typewriter`, `shine`, `flow`, `range`, `permission`, `condition`. |

### Pages

| Command | Does |
|---|---|
| `page add` | Adds an empty page. |
| `page remove <n>` | Removes page `n`. |
| `page <n>` | Opens page `n`'s lines and turns the hologram to it for you. |
| `page <n> addline\|insertline\|setline\|removeline\|moveline\|line …` | A line command on page `n`. |
| `pageinterval <ticks>` | Turns each player's page on its own; `0` never. |

### How it looks

| Command | Values |
|---|---|
| `billboard <mode>` | `center`, `vertical`, `horizontal`, `fixed` |
| `alignment <mode>` | `center`, `left`, `right` |
| `scale <x> [y] [z]` | above 0 |
| `shadow <true\|false>` | |
| `seethrough <true\|false>` | |
| `linewidth <pixels>` | 1+ |
| `spacing <blocks>` | 0+ |
| `opacity <0-255>` | |
| `background <value>` | `#AARRGGBB`, `none`, `default` |
| `brightness <level>` | 0–15, or -1 for the light where it stands |

### Who sees it

| Command | Does |
|---|---|
| `viewdistance <blocks>` | How far away it is seen. |
| `permission [node]` | Only players with it; no node clears it. |
| `perplayer <true\|false>` | A copy per viewer. |
| `refresh <ticks>` | Ticks between placeholder refreshes. |
| `autoupdate <true\|false>` | Whether it refreshes on its own. |
| `visibility <all\|manual>` | Everyone but a list / only a list. |
| `show <player\|@a>` · `hide <player\|@a>` | Puts a player in or out of the list the mode reads. |
| `viewers` · `viewers clear` | Lists / empties that list. |

### What it rides

| Command | Does |
|---|---|
| `attach <player\|uuid\|nearest>` | Rides a player, an entity, or the entity nearest to you (16 blocks). |
| `detach` | Back to its location. |
| `attachoffset <blocks>` | Height above the entity, -16 to 16. |

### Clicks

| Command | Does |
|---|---|
| `click add <line>` | Adds an [interaction line](/docs/exyliadisplays/interactions). |
| `click remove <n>` · `click clear` | Removes one / all. |
| `click width <blocks>` | Width of the click box. |
| `click cooldown <ms>` | Per-player wait between clicks. |
| `click hover <scale>` | Growth while looked at; `1` off. |

## /npcadmin

| Command | Does |
|---|---|
| `/npcadmin` · `/npcadmin list` | The list screen; one line per NPC for the console. |
| `/npcadmin help` | The help. |
| `/npcadmin create <name> [skin]` | An NPC where you stand; skin is an account, `@mirror` or `@none`, your own by default. |
| `/npcadmin near [radius]` | The NPCs around you, nearest first. |
| `/npcadmin reload` | Reloads everything, then reports `npcs.yml`'s count and mistakes. |
| `/npcadmin import <citizens\|fancynpcs> [replace]` | See [Migration](/docs/exyliadisplays/migration). |

## /npc

`/npc <name>` opens the editor. `/npc` and `/npc help` print the help.

| Command | Does |
|---|---|
| `info` | Its details. |
| `equipment` | The equipment screen. |
| `rename <new>` · `clone <copy>` | Renames it / copies it in the same place, without its linked hologram. |
| `enable` · `disable` · `delete` | As for holograms. |
| `tp` · `movehere` · `move <x> <y> <z> [world]` · `center` | Where it stands. |
| `rotate <yaw> [pitch]` · `face` | Which way it faces. |
| `adjust` · `adjust save` · `adjust cancel` | [Fine adjust](/docs/exyliadisplays/fine-adjust). |
| `skin <account\|@mirror\|@none>` | Its skin. |
| `texture <value> [signature]` | An uploaded skin. |
| `pose <pose>` | `standing`, `sneaking`, `lying`, `crawling`, `spinning`. |
| `scale <n>` | `0.0625` to `16`. |
| `glow <#RRGGBB\|none>` | Its outline. |
| `equip <slot> [item]` | The item in your hand, or the one written; `air` empties the slot. |
| `equip clear` | Empties every slot. |
| `look <fixed\|nearest\|each-viewer> [range]` | Where its head turns. |
| `viewdistance <blocks>` · `permission [node]` | Who sees it. |
| `label set <text>` · `label add <text>` · `label remove <n>` · `label clear` | Its label lines. |
| `label height <blocks>` | Gap between its head and the label. |
| `link <hologram>` · `unlink` | A hologram that follows it. |
| `action add <line>` · `action remove <n>` · `action clear` · `action list` | Its click lines. |
| `action permission [node]` · `action cooldown <time>` | Who may click it and how often. |
| `action denymessage [text]` · `action cooldownmessage [text]` | Its own refusals; no text for the defaults. |
| `action faceclicker <true\|false>` | Turn to whoever clicked. |

<Callout type="note" title="Next to Citizens">
Citizens also registers `/npc`, and the two compete for it. Use `/npcs <name>` or `/exylianpc <name>`;
`/npcadmin` does not clash.
</Callout>
