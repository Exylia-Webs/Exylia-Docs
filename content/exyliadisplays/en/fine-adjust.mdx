---
title: "Fine adjust"
description: "Placing a hologram or an NPC with the mouse wheel while you look at it: the axes, the keys, saving and undoing."
---

Fine adjust moves, turns and scales a hologram or an NPC with the mouse wheel while you look at it. It
moves live on every notch; nothing is written to the file until you finish.

| Start | Hologram | NPC |
|---|---|---|
| Command | `/holo <name> adjust` | `/npc <name> adjust` |
| Editor | **FINE ADJUST** | **FINE ADJUST** |

## Keys

| Key | Does |
|---|---|
| Scroll | Changes the value by one step. |
| Sneak + scroll | A bigger or smaller step. |
| F | Next axis; sneak + F goes back. |
| Sneak + click | Snap: block centre, half a block for height, the nearest 15°. |
| Click, or the start command again | Saves and finishes. |
| `/holo <name> adjust cancel` · `/npc <name> adjust cancel` (or **UNDO** in chat) | Puts everything back. |

`/holo <name> adjust save` and `/npc <name> adjust save` also save. Two boss bars show the axis, the
value and the step, and the keys.

## Axes

| Hologram | NPC |
|---|---|
| X, Y, Z | X, Y, Z |
| Forward (where you look) | Forward (where you look) |
| Turn | Turn |
| Tilt | Tilt |
| Scale | Scale (`0.0625` to `16`) |
| Line spacing | Label height (`-2` to `5`) |

For an NPC, its label and its linked hologram follow it live, and both `npcs.yml` and `holograms.yml` are
written once, when you save.

## When it ends on its own

Leaving, dying, changing world or teleporting far saves and finishes. Deleting or renaming what you are
adjusting stops the session with nothing to save, as does a reload that removes it from its file. Stopping
the server saves every running session.

One player adjusts a given hologram or NPC at a time. While somebody adjusts one, a hand edit of the file
or another admin's change to it still shows underneath.
