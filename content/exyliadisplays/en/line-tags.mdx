---
title: "Line tags"
description: "Every tag a hologram line or NPC label line can open with: size and look, items, blocks and heads, motion, colour effects, and lines only some players see."
---

A line can open with tags that style that line alone. They go at the very **start** of the line, before
any text, and work the same in hologram lines, hologram pages and NPC labels:

```yaml
lines:
  - '<block:NETHERITE_BLOCK><spin:45><glow:#ff6b9d>'
  - '<size:2.4><shine>{accent}&lTHE ARENA'
  - '<flow>{secondary}Season II · open now'
  - '<size:0.5> '
  - '<if:"%player_level% >= 10">{success}✔ You qualify'
  - '<if:"%player_level% < 10">{error}Reach level 10 to enter'
  - '<range:5><typewriter><background:#55000000>{letters}Right-click to join the queue'
```

Only these tags, and only at the start, are read. Anything else there, such as `<gradient:...>`, is
text and is drawn by the text parser. A tag whose value does not parse ends the run and stays in the text,
exactly as written.

## Look

| Tag | Effect |
|---|---|
| `<size:2>` | Bigger (or smaller) than the rest; the lines above move to make room. |
| `<opacity:160>` | Text opacity, 0 to 255. |
| `<background:#66000000>` | The line's own background, `#AARRGGBB` (or `#RRGGBB`). |
| `<shadow>` / `<shadow:false>` | Text shadow on or off for this line. |

## Models

| Tag | Effect |
|---|---|
| `<item:DIAMOND>` | A floating item instead of text. |
| `<block:BEACON>` | A floating block instead of text. |
| `<head:Notch>` | A player head: a name, a UUID, a base64 texture or a `textures.minecraft.net` URL. `<size:0.5>` makes it small, `<size:2>` large. |
| `<glow>` / `<glow:#8a51c4>` | A glow outline on an item or block line; bare is the team colour. |

## Motion

The client interpolates between keyframes, so the server sends a couple of packets a second rather than
one every tick.

| Tag | Effect | Bare value |
|---|---|---|
| `<spin>` / `<spin:180>` | Turns, in degrees a second. | 90 |
| `<bob>` / `<bob:0.15>` | Floats up and down, in blocks. | 0.08 |
| `<pulse>` / `<pulse:0.1>` | Grows and shrinks by that fraction of its size. | 0.06 |
| `<typewriter>` / `<typewriter:40>` | Typed in, in characters a second. | 24 |

## Colour effects

| Tag | Effect | Bare value |
|---|---|---|
| `<shine>` / `<shine:#ffd700>` / `<shine:highlight>` | A band of light sweeps over it every few seconds; a hex colour or a palette name. | the default shine |
| `<flow>` / `<flow:8>` | Its colours flow along it, in characters a second. Pair it with a gradient. | 4 |

## Who sees a line

These are checked per viewer, and the stack lays itself out again for each player: a line someone does
not see takes no room for them.

| Tag | Effect |
|---|---|
| `<range:8>` | Only within 8 blocks. |
| `<perm:vip.rank>` | Only with the permission. |
| `<perm:!vip.rank>` | Only **without** it. |
| `<if:"%player_level% >= 10">` | Only while the comparison holds, with placeholders resolved for that viewer. |

A members' door: one line for those with the permission, another for everyone else.

```yaml
lines:
  - '<item:AMETHYST_SHARD><bob><glow:#b48fd9>'
  - '<size:1.6><pulse:0.04>{secondary}&lTHE OBSERVATORY'
  - '<perm:observatory.key>{success}Welcome in'
  - '<perm:!observatory.key><opacity:180>{letters_black}Find the key in the library'
```

## Placeholders in lines

PlaceholderAPI and ExyliaLib placeholders work in any line. A hologram whose lines contain a placeholder
(`%something_like_this%`) is drawn **per viewer** on its own, whatever `per-player` says, so
`%player_name%` shows each player their own name. Its lines refresh every `refresh.update-interval`
ticks (default 20) while `auto-update` is on; lines without placeholders are drawn once.

<Callout type="note" title="NPC labels">
An NPC's label is drawn once for everybody, not per viewer, and nothing in the plugin turns that on. A
player placeholder in a label (`%player_name%`) is not resolved for each viewer. For a label that has to
read differently per player, put a hologram above the NPC with
[link](/docs/exyliadisplays/npcs#a-linked-hologram). The viewer tags above (`<range>`, `<perm>`, `<if>`)
work in labels.
</Callout>

## Editing tags without the notation

The line's style window (right-click it on the lines screen) shows every tag as a field, and
`/holo <name> line <n> <tag> [value]` sets one. Both write the tags back in a fixed order and only the
tags that are set, so a round trip never adds tags you did not ask for. See
[Holograms](/docs/exyliadisplays/holograms#lines).
