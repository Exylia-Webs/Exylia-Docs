title: "Holograms"

A hologram is a stack of lines standing at one place. Its **location** is the bottom of the last line;
the lines stack upwards from there. Each line is text, a floating item, a floating block or a player
head, and each can carry [line tags](/docs/exyliadisplays/line-tags) that style it alone.

## Creating one

| From | How |
|---|---|
| The list | `/holoadmin`, then **CREATE HOLOGRAM**: a window with a name (a free one is suggested) and a preset from `config.yml`. |
| A command | `/holoadmin create <name> [text]`: one line, `text` or `{primary}&l<name>`. |
| The file | A new entry under `holograms:` in `holograms.yml`. |

A hologram created in game stands `spawn-height` blocks (default `2.0`) above your feet, turned to face
you, with the `default-view-distance` of `config.yml` (default `48`). A preset's lines replace
`%hologram%` with the new name. See [Configuration](/docs/exyliadisplays/configuration) to add presets.

The shipped presets:

| Preset | What it is |
|---|---|
| `simple` | A large title and a hint to edit it. |
| `portal` | A spinning, bobbing ender eye with a glow over a flowing title, and a typed hint up close. |
| `lounge` | A shining title and a line that differs for players with and without `lounge.access`. |
| `checkpoint` | A spinning, pulsing gold block over a title. |
| `welcome` | A shining title and a typed line for players within 12 blocks. |

A name is lowercase letters, digits, `_` and `-`, up to 32 characters, and unique among holograms.

## The editor

`/holo <name>` (or a left-click in the list) opens the hologram's editor:

| Button | Click | Does |
|---|---|---|
| Header | left / right | Shows or hides it (`enabled`) / renames it. |
| **LINES** | | The lines screen, one page at a time. |
| **APPEARANCE** | | Billboard, alignment, scale, spacing, line width, opacity, shadow, see-through, background, brightness. |
| **VISIBILITY** | left / right | View distance, permission, per-player, refresh, page interval and the player lists / switches between everyone and chosen players. |
| **CLICK ACTIONS** | | The click lines, box width, cooldown and hover growth. |
| **LOCATION** | left / right / shift-left / shift-right | Exact position and rotation / move here / centre on its block / turn to face me. |
| **ATTACHED TO** | left / right | Choose what it rides / back to its location. |
| **TELEPORT** | | Puts you 2.5 blocks south of it, looking north at it. |
| **DUPLICATE** | | A copy under a new name, in the same place. |
| **FINE ADJUST** | | Moves it with the mouse wheel. |
| **DELETE** | | Asks first. |

The windows are ExyliaLib dialog windows: every field of a section in one window, saved together. On a
client older than 1.21.6, or on Bedrock, the same fields arrive through chat or a form.

## Lines

The lines screen shows the page you are on:

| On a line | Does |
|---|---|
| Left-click | Edits its text; its tags are kept. |
| Right-click | Its style window: size, opacity, shadow, background, glow, spin, bob, pulse, typewriter, shine, flow, range, permission and condition, and the head for a head line. |
| Shift-left / shift-right | Moves it up / down. |
| F | Duplicates it below itself. |
| Q | Removes it, after asking. |

| Button | Adds at the bottom |
|---|---|
| **ADD TEXT** | A text line. |
| **ADD ITEM** / **ADD BLOCK** | A floating item or block, picked from ExyliaLib's icon picker: `<item:DIAMOND>`, `<block:BEACON>`. |
| **ADD HEAD** | A player head: a name, a UUID, a base64 texture or a `textures.minecraft.net` URL. |
| **EDIT ALL AT ONCE** | Every line of the page in one box, one per row. Blank rows at the end are dropped. |

The book in the middle moves between [pages](/docs/exyliadisplays/pages).

From commands, line numbers start at 1:

```text
/holo spawn addline {letters}A new bottom line
/holo spawn insertline 1 <size:2>{primary}&lA new top line
/holo spawn setline 2 {letters}Changed
/holo spawn moveline 3 1
/holo spawn removeline 4
/holo spawn line 1 size 2.4
/holo spawn line 1 shine on
/holo spawn line 1 shine reset
```

`/holo <name> line <n> <tag> [value]` changes one tag and keeps the rest of the line. The tags are
`text`, `size`, `head`, `opacity`, `background`, `shadow`, `glow`, `spin`, `bob`, `pulse`, `typewriter`,
`shine`, `flow`, `range`, `permission` and `condition`. No value, or `reset`, takes the tag off; `on`
gives a motion tag its default; `glow team` is the team colour; `shadow` reads `true/false`, `on/off`,
`yes/no`.

## Appearance

These apply to the whole hologram; a line tag overrides them for one line.

| Setting | Command | Values | Default |
|---|---|---|---|
| Billboard | `billboard` | `center` turns to every viewer; `vertical` and `horizontal` turn on one axis; `fixed` keeps its facing | `center` |
| Alignment | `alignment` | `center`, `left`, `right` | `center` |
| Scale | `scale <x> [y] [z]` | above 0; one number scales evenly | `1` |
| Shadow | `shadow` | `true`, `false` | `true` |
| See-through | `seethrough` | visible through blocks | `false` |
| Line width | `linewidth` | pixels before the client wraps, 1+ | `200` |
| Spacing | `spacing` | blocks between lines, 0+ | `0.25` |
| Opacity | `opacity` | 0 to 255 | `255` |
| Background | `background` | `#AARRGGBB`, `none` (transparent) or `default` (the client's own) | `#00000000` |
| Brightness | `brightness` | 0 to 15, or `-1` for the light where it stands | `-1` |

## Location and facing

| Command | Does |
|---|---|
| `/holo <name> movehere` | Moves it to your feet and turns it to face you. |
| `/holo <name> move <x> <y> <z> [world]` | Moves it, keeping its facing. |
| `/holo <name> center` | Centres it on its block (x and z). |
| `/holo <name> rotate <yaw> [pitch]` | Yaw 0 south, 90 west, 180 north, -90 east; pitch -90 to 90 tilts it. |
| `/holo <name> face` | Turns it to face you without moving it. |
| `/holo <name> tp` | Takes you to it. |
| `/holo <name> adjust` | [Fine adjust](/docs/exyliadisplays/fine-adjust) with the mouse wheel. |

Facing only shows on a `fixed` billboard (or the axis a `vertical` or `horizontal` one keeps). Turning
a `center` hologram — `rotate`, `face`, or a new yaw in the location window — switches it to `fixed`,
since a centred hologram would turn back to every viewer.

A hologram whose world is not loaded waits and appears when the world loads.

## Copies, renames and deletion

- `/holo <name> clone <copy>` makes a copy **at the same place**, on top of the original. Move one of
  them afterwards.
- `/holo <name> rename <new>` keeps its place in the file.
- `/holo <name> delete` asks in a window for a player; from the console it deletes at once.
- `/holo <name> disable` keeps it in the file without showing it; `enable` shows it again.

<Callout type="warning" title="Renaming or deleting a linked hologram">
An NPC that carries a hologram (`linked-hologram`) names it. Renaming or deleting the hologram does not
update the NPC: the link silently points at a name that no longer exists until you link it again. See
[NPCs](/docs/exyliadisplays/npcs#a-linked-hologram).
</Callout>

## Finding holograms

- `/holoadmin` (or `/holoadmin list`) opens the list for a player; the console gets one line each.
- `/holoadmin near [radius]` lists the holograms around you, nearest first, each with a click to edit it
  or go there. The default radius is `near-radius` (20 blocks).
- `/holo <name> info` prints its details and every line, numbered `page.line` when it has pages.
