Most settings are a button, not a file: the **Settings** card of the hologram and NPC lists opens a hub with one page per theme (modules, hologram defaults, NPC defaults, leaderboards). Open this page when you want a file's location, every key or a default.

## Where the files are

Everything sits in `plugins/ExyliaDisplays/`. `config.yml` is the only file about behaviour; the others hold what the plugin shows.

| File | What it holds |
|---|---|
| `config.yml` | Modules, defaults for new holograms and NPCs, presets (this page). |
| `holograms.yml`, `npcs.yml` | Your holograms and NPCs. See the [File reference](/docs/exyliadisplays/file-reference). |
| `leaderboards.yml` | What players are ranked by and when periods start over. See [Leaderboards](/docs/exyliadisplays/leaderboards). |
| `boards.yml` and `boards/` | Leaderboard panels standing in the world and the `.html` / `.css` that draw them. |
| `lang/<code>/` | Messages and menus in one language: `messages.yml`, `messages/holograms.yml`, `messages/npcs.yml`, `messages/leaderboards.yml` and the menus. |

## Reloading

`/displaysadmin reload` reads `config.yml`, the message files and every module file again, then reloads the menus. `holograms.yml` and `npcs.yml` also apply on their own when you save them (`watch-files`); see [Editing the files](/docs/exyliadisplays/editing-files). Switching a module on or off is the one change that needs a restart.

## Modules

Under `modules` in `config.yml`, `holograms`, `leaderboards` and `npcs` are each `true` by default. A module switched off costs nothing; a module the file does not name runs. Restart to apply.

## Holograms

Defaults for new holograms, and the presets offered when you create one from the list:

```yaml title="plugins/ExyliaDisplays/config.yml"
holograms:
  spawn-height: 2.0          # blocks above your feet
  default-view-distance: 48.0
  near-radius: 20.0          # /holoadmin near with no number
  presets:
    simple:
      name: Simple title     # shown in the list
      lines:
        - '<size:1.4>{primary}&l%hologram%'   # %hologram% = the new hologram's name
        - '{letters}Edit me with {highlight}/holo %hologram%'
```

Add your own preset by copying one block under a new id. Shipped: `simple`, `portal`, `lounge`, `checkpoint`, `welcome`, `news`, `landmark`. An empty `presets` map removes the choice, and new holograms get their name in bold.

`holograms.line-presets` are tags a line takes at once: write `<preset:title>` in a line, or run `/holo <name> line <n> preset <name>`. Shipped: `title`, `subtitle`, `highlight`, `subtle`, `ticker`, `button`, `badge`, `whisper`, `glitch`, `live`, `wide`, `left`, `showcase`, `far`. See [Line tags](/docs/exyliadisplays/line-tags).

## NPCs

```yaml title="plugins/ExyliaDisplays/config.yml"
npcs:
  default-view-distance: 48.0
  default-look: each-viewer   # fixed | nearest | each-viewer
  face-creator: true
  say-duration: 5s
  turn-back: 4s
  near-radius: 20.0
  skin-refresh: 30s
  presets:
    guide:
      name: Guide
      skin: ''
      label:
        - '<size:1.2>{primary}&lGUIDE'
      actions:
        - 'right: [SAY] {letters}Welcome, {highlight}%player_name%{letters}!;6s'
```

Presets work as for holograms: `name` is shown in the list, `skin` is an account name, a placeholder or `@mirror` (empty keeps the skin you type), and `%npc%` in a label line becomes the NPC's name. A preset may also set `body`: sitting, outline colour, equipment, look and animations. Shipped: `simple`, `greeter`, `bartender`, `guard`, `merchant`, `statue`, `portal`, `mirror`. See [NPCs](/docs/exyliadisplays/npcs) and [Interactions](/docs/exyliadisplays/interactions).

## Messages and language

The plugin has no language key: it follows ExyliaLib's. It ships English, Spanish (`es`), French (`fr`), Portuguese (`pt`), Russian (`ru`) and Turkish (`tr`) under `lang/<code>/`. To change wording, edit the file for your language; see [Messages and languages](/docs/exylialib/messages-and-languages) and [Colours](/docs/exylialib/colours). Menus are in the same folder: see [Edit menus](/docs/exylialib/edit-menus).

A message may open with `[sound:NAME|volume|pitch]`, which plays a sound and is never shown; `[center]` centres a help line, and `<click:…>` makes it clickable.

<Details title="Every key of config.yml">

### General

| Key | Type | Default | What it does |
|---|---|---|---|
| `debug` | boolean | `false` | Extra console output, for reporting a problem. Every NPC click is logged with what became of it. |
| `watch-files` | boolean | `true` | Apply `holograms.yml` and `npcs.yml` when saved by hand. Off, use `/holoadmin reload` or `/npcadmin reload`. Takes effect on `/displaysadmin reload`. |
| `modules.holograms` | boolean | `true` | The hologram module. Needs a restart. |
| `modules.leaderboards` | boolean | `true` | Leaderboards shown on holograms. Needs a restart. |
| `modules.npcs` | boolean | `true` | The NPC module. Needs a restart. |

### holograms

| Key | Type | Default | What it does |
|---|---|---|---|
| `holograms.spawn-height` | number | `2.0` | How far above your feet a hologram you create stands, in blocks. Below 0 reads as 0. |
| `holograms.default-view-distance` | number | `48.0` | View distance of a new hologram. 0 or less reads as 48. |
| `holograms.near-radius` | number | `20.0` | Radius of `/holoadmin near` when none is typed. 0 or less reads as 20. |
| `holograms.presets` | map | 7 presets | By id: `name` (shown in the list) and `lines`. `%hologram%` in a line becomes the new hologram's name. |
| `holograms.line-presets` | map | 14 presets | By name: a string of tags. The preset's tags replace the line's own of the same kind; its text and other tags stay. |

### npcs

| Key | Type | Default | What it does |
|---|---|---|---|
| `npcs.default-view-distance` | number | `48.0` | View distance of a new NPC. |
| `npcs.default-look` | `fixed` `nearest` `each-viewer` | `each-viewer` | Where a new NPC turns its head. |
| `npcs.face-creator` | boolean | `true` | A new NPC faces whoever created it. Off, it looks the way they were looking, level. |
| `npcs.say-duration` | duration | `5s` | How long a `[SAY]` bubble stays when its line names no time. Reads `5s`, `1m`. |
| `npcs.turn-back` | duration | `4s` | How long an NPC keeps facing whoever clicked it before turning back. |
| `npcs.near-radius` | number | `20.0` | Radius of `/npcadmin near` when none is typed. |
| `npcs.skin-refresh` | duration | `30s` | How often a skin written as a placeholder (a leaderboard's top name) is read again. At least 1s. |
| `npcs.presets` | map | 8 presets | By id: `name`, `skin`, `label` (lines), `actions` (interaction lines) and `body`. `%npc%` in a label line becomes the NPC's name. |

### Message files

| File | Contents |
|---|---|
| `lang/<code>/messages.yml` | `prefix` (put into every `%prefix%`), `reloaded`, `help`, and the `/displaysadmin modules` lines. |
| `lang/<code>/messages/holograms.yml` | Every hologram reply, `/holo help`, the `info` layout, the windows' words, the visibility, attach and fine-adjust lines, and `file-applied` / `file-issues`. |
| `lang/<code>/messages/npcs.yml` | Every NPC reply, `/npc help`, `interaction-denied`, `interaction-cooldown` (`%remaining%` seconds), `say-bubble` (`%text%`), the windows' words, and `file-applied` / `file-issues`. |
| `lang/<code>/messages/leaderboards.yml` | What [leaderboard](/docs/exyliadisplays/leaderboards) holograms and their window say. |

Colours use palette tokens (`{primary}`, `{error}`, `{highlight}`), so recolouring the server through ExyliaLib never means editing these files.
