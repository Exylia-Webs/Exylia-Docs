| Comando | Alias | Permiso | |
|---|---|---|---|
| `/displaysadmin` | `/displays`, `/exyliadisplays`, `/edisplays` | `exyliadisplays.admin` | El plugin en conjunto. |
| `/holoadmin` | `/hologramadmin` | `exyliadisplays.holograms` | Todos los hologramas, y lo que no es de uno solo. |
| `/holo <nombre> …` | `/hologram` | `exyliadisplays.holograms` | Un holograma. |
| `/npcadmin` | `/npcsadmin` | `exyliadisplays.npcs` | Todos los NPCs, y lo que no es de uno solo. |
| `/npc <nombre> …` | `/npcs`, `/exylianpc` | `exyliadisplays.npcs` | Un NPC. |

Los comandos de un módulo desactivado no existen. Los argumentos de nombre sugieren los nombres que existen.
Los comandos que necesitan un sitio o un menú (`create`, `movehere`, `tp`, `face`, `adjust`, `near`,
`page <n>`, `lines`, `equipment`) son para jugadores; el resto también funciona desde la consola. Un nombre
sin ajuste abre el editor a un jugador y muestra los datos a la consola.

## /displaysadmin

| Comando | Hace |
|---|---|
| `/displaysadmin` · `/displaysadmin help` | La ayuda. |
| `/displaysadmin modules` | Cada módulo y si está funcionando. |
| `/displaysadmin editor` | Abre cada archivo de módulo en el [editor web](/docs/exyliadisplays/editar-archivos). |
| `/displaysadmin reload` | Vuelve a leer todos los archivos y lo redibuja todo. Ver [Editar los archivos](/docs/exyliadisplays/editar-archivos). |
| `/displaysadmin demo seed [skins]` | Una muestra de hologramas y NPCs a tu alrededor, para capturas. Necesita ambos módulos; los nombres de cuenta opcionales son las skins de los NPCs, en orden. |
| `/displaysadmin demo clear` | Borra todo holograma y NPC llamado `demo-*`, y nada más. |

## /holoadmin

| Comando | Hace |
|---|---|
| `/holoadmin` · `/holoadmin list` | El menú de la lista; una línea por holograma en la consola. |
| `/holoadmin help` | La ayuda. |
| `/holoadmin create <nombre> [texto]` | Un holograma donde estás, con `texto` como línea (o su nombre en negrita). Añade `--template <nombre>` para partir de una [plantilla](/docs/exyliadisplays/hologramas#plantillas). |
| `/holoadmin templates` | Todas las plantillas, con sus líneas y páginas. |
| `/holoadmin templates delete <nombre>` | Borra una plantilla. |
| `/holoadmin editor` | Abre los archivos del plugin en el editor web. |
| `/holoadmin leaderboard reset <stat> [periodo]` | Reinicia una [clasificación](/docs/exyliadisplays/clasificaciones) en todos los servidores: un periodo, o todos los valores si no se nombra ninguno. |
| `/holoadmin near [radio]` | Los hologramas a tu alrededor, del más cercano al más lejano. Radio por defecto `near-radius` (20). |
| `/holoadmin reload` | Lo recarga todo e informa de la cantidad y los errores de `holograms.yml`. |
| `/holoadmin import <origen> [replace]` | `decentholograms`, `holographicdisplays`, `fancyholograms`. Ver [Migración](/docs/exyliadisplays/migracion). |

## /holo

`/holo <nombre>` abre el editor. `/holo` y `/holo help` muestran la ayuda.

### El holograma

| Comando | Hace |
|---|---|
| `info` | Sus datos, cada línea y cada acción de clic. |
| `lines` | El menú de líneas. |
| `rename <nuevo>` · `clone <copia>` | Lo renombra / lo copia en el mismo sitio. |
| `enable` · `disable` | Lo muestra / lo conserva sin mostrarlo. |
| `delete` | Lo borra al momento, sin confirmación (el botón del editor sí pregunta). |
| `undo` | Lo devuelve a como estaba antes de su último cambio, desde un comando, un menú o el archivo. |
| `savetemplate <plantilla>` | Guarda su aspecto con un nombre, reemplazando una plantilla de ese nombre. |
| `applytemplate <plantilla>` | Lo viste como una plantilla: líneas, páginas, aspecto, refresco y clic. |

### Dónde está

| Comando | Hace |
|---|---|
| `tp` | Te lleva hasta él. |
| `movehere` | Lo trae hasta ti, mirándote. |
| `move <x> <y> <z> [mundo]` | Lo mueve. |
| `center` | Lo centra en su bloque. |
| `rotate <yaw> [pitch]` | Lo gira; pitch de -90 a 90. Un billboard `center` pasa a `fixed`. |
| `face` | Lo gira hacia ti. |
| `adjust` · `adjust save` · `adjust cancel` | [Ajuste fino](/docs/exyliadisplays/ajuste-fino). |

### Líneas

| Comando | Hace |
|---|---|
| `addline <texto>` | Añade una línea abajo del todo. |
| `insertline <n> <texto>` | Inserta una línea en `n`. |
| `setline <n> <texto>` | Sustituye la línea `n`. |
| `removeline <n>` | Quita la línea `n`. |
| `moveline <desde> <hasta>` | Mueve una línea. |
| `line <n> <etiqueta> [valor]` | Cambia una [etiqueta](/docs/exyliadisplays/etiquetas-de-linea) de la línea `n`; sin valor o con `reset` la quita, `on` es el valor por defecto. Etiquetas: `text`, `size`, `head`, `opacity`, `background`, `shadow`, `glow`, `spin`, `bob`, `pulse`, `typewriter`, `shine`, `flow`, `range`, `permission`, `condition`. |

### Páginas

| Comando | Hace |
|---|---|
| `page add` | Añade una página vacía. |
| `page remove <n>` | Quita la página `n`. |
| `page <n>` | Abre las líneas de la página `n` y te pasa el holograma a ella. |
| `page <n> addline\|insertline\|setline\|removeline\|moveline\|line …` | Un comando de línea en la página `n`. |
| `pageinterval <ticks>` | Pasa sola la página de cada jugador; `0` nunca. |

### Aspecto

| Comando | Valores |
|---|---|
| `billboard <modo>` | `center`, `vertical`, `horizontal`, `fixed` |
| `alignment <modo>` | `center`, `left`, `right` |
| `scale <x> [y] [z]` | mayor que 0 |
| `shadow <true\|false>` | |
| `seethrough <true\|false>` | |
| `linewidth <píxeles>` | 1+ |
| `spacing <bloques>` | 0+ |
| `opacity <0-255>` | |
| `background <valor>` | `#AARRGGBB`, `none`, `default` |
| `brightness <nivel>` | 0–15, o -1 para la luz de donde está |
| `distancescale <on\|off\|inicio fin mín máx>` | Crece con la distancia del espectador; cuatro números fijan la curva y lo activan (mín y máx 0.1–10). |

### Quién lo ve

| Comando | Hace |
|---|---|
| `viewdistance <bloques>` | Desde qué distancia se ve. |
| `permission [nodo]` | Solo jugadores con él; sin nodo se quita. |
| `perplayer <true\|false>` | Una copia por espectador. |
| `refresh <ticks>` | Ticks entre refrescos de placeholders. |
| `autoupdate <true\|false>` | Si se refresca solo. |
| `visibility <all\|manual>` | Todos menos una lista / solo una lista. |
| `show <jugador\|@a>` · `hide <jugador\|@a>` | Mete o saca a un jugador de la lista que lee el modo. |
| `viewers` · `viewers clear` | Muestra / vacía esa lista. |

### Qué lleva encima

| Comando | Hace |
|---|---|
| `attach <jugador\|uuid\|nearest>` | Va encima de un jugador, de una entidad, o de la entidad más cercana a ti (16 bloques). |
| `detach` | Vuelve a su ubicación. |
| `attachoffset <bloques>` | Altura sobre la entidad, de -16 a 16. |

### Clics

| Comando | Hace |
|---|---|
| `click add <línea>` | Añade una [línea de interacción](/docs/exyliadisplays/interacciones). |
| `click remove <n>` · `click clear` | Quita una / todas. |
| `click width <bloques>` | Ancho de la caja de clic. |
| `click cooldown <ms>` | Espera por jugador entre clics. |
| `click hover <escala>` | Crecimiento al mirarlo; `1` lo desactiva. |
| `click style <button\|none>` | `button` dibuja un panel tras lo que se puede pulsar; `none` solo lo hace crecer. |
| `click color <color>` · `click hovercolor <color>` | El color del panel, y su color al mirarlo. |
| `click sound [sonido]` | Un sonido en cada clic; sin valor lo quita. |
| `button <id> <acción>` · `button <id> remove` | Añade una acción a un botón que ejecuta una línea con `<button:id>`; `remove` lo borra. |

### Clasificación

| Comando | Hace |
|---|---|
| `leaderboard` | Abre su ventana de [clasificación](/docs/exyliadisplays/clasificaciones). |
| `leaderboard on` · `off` · `flatten` | La activa o desactiva / conserva sus líneas y suelta la clasificación en vivo. |
| `leaderboard stats` · `spans` · `rows` | Qué clasifica, en qué periodos y cuántas filas. |

## /npcadmin

| Comando | Hace |
|---|---|
| `/npcadmin` · `/npcadmin list` | El menú de la lista; una línea por NPC en la consola. |
| `/npcadmin help` | La ayuda. |
| `/npcadmin create <nombre> [skin]` | Un NPC donde estás; la skin es una cuenta, `@mirror` o `@none`, la tuya por defecto. |
| `/npcadmin near [radio]` | Los NPCs a tu alrededor, del más cercano al más lejano. |
| `/npcadmin editor` | Abre los archivos del plugin en el editor web. |
| `/npcadmin reload` | Lo recarga todo e informa de la cantidad y los errores de `npcs.yml`. |
| `/npcadmin import <citizens\|fancynpcs> [replace]` | Ver [Migración](/docs/exyliadisplays/migracion). |
| `/npcadmin group` · `/npcadmin group list` | Cada [grupo](/docs/exyliadisplays/npcs#grupos) con sus miembros. |
| `/npcadmin group play <grupo> <animación>` | La reproduce en todos los miembros a la vez, al mismo tempo; dice cuántos empezaron y cuántos se omitieron. |
| `/npcadmin group stop <grupo>` | Termina lo que reproduce cada miembro. |
| `/npcadmin group pause <grupo>` · `/npcadmin group resume <grupo>` | Pausa o reanuda a todos los miembros. |
| `/npcadmin animations [archivo]` | Los archivos de animación y sus clips (bucle, duración); clic en un clip para copiar su nombre `anim:`. |

## /npc

`/npc <nombre>` abre el editor. `/npc` y `/npc help` muestran la ayuda.

| Comando | Hace |
|---|---|
| `info` | Sus datos. |
| `equipment` | El menú de equipo. |
| `rename <nuevo>` · `clone <copia>` | Lo renombra / lo copia en el mismo sitio, sin su holograma enlazado. |
| `enable` · `disable` · `delete` · `undo` | Como en los hologramas: `delete` es al momento, `undo` revierte el último cambio. |
| `tp` · `movehere` · `move <x> <y> <z> [mundo]` · `center` | Dónde está. |
| `rotate <yaw> [pitch]` · `face` | Hacia dónde está orientado. |
| `adjust` · `adjust save` · `adjust cancel` | [Ajuste fino](/docs/exyliadisplays/ajuste-fino). |
| `skin <cuenta\|@mirror\|@none>` | Su skin. |
| `texture <valor> [firma]` | Una skin subida. |
| `pose <pose>` | `standing`, `sneaking`, `lying`, `crawling`, `spinning`. |
| `scale <n>` | `0.0625` a `16`. |
| `glow <#RRGGBB\|none>` | Su contorno. |
| `equip <hueco> [ítem]` | El ítem de tu mano, o el escrito; `air` vacía el hueco. |
| `equip clear` | Vacía todos los huecos. |
| `look <fixed\|nearest\|each-viewer> [alcance]` | Hacia dónde gira la cabeza. |
| `viewdistance <bloques>` · `permission [nodo]` | Quién lo ve. |
| `label set <texto>` · `label add <texto>` · `label remove <n>` · `label clear` | Las líneas de su etiqueta. |
| `label height <bloques>` | Hueco entre su cabeza y la etiqueta. |
| `link <holograma>` · `unlink` | Un holograma que lo sigue. |
| `action add <línea>` · `action set <n> <línea>` · `action remove <n>` · `action clear` · `action list` | Sus líneas de clic; `set` reemplaza la línea `n`. |
| `action permission [nodo]` · `action cooldown <tiempo>` | Quién puede pulsarlo y cada cuánto. |
| `action denymessage [texto]` · `action cooldownmessage [texto]` | Sus propios rechazos; sin texto, los de por defecto. |
| `action faceclicker <true\|false>` | Girarse hacia quien hace clic. |
| `animation <left-click\|right-click\|idle\|greet> [animación]` | Lo que reproduce un disparador; `none` lo quita. Ver [Animaciones](/docs/exyliadisplays/npcs#animaciones). |
| `animation idle-every\|greet-cooldown <tiempo>` · `animation greet-range\|perform-range <bloques>` | Cuándo y para quién. |
| `animation idle-continuous <on\|off>` | El idle se repite mientras haya alguien cerca. |
| `animation idle-group <clave\|none>` · `group <clave\|none>` | Su grupo: un solo ajuste. |
| `play <animación>` | Reproduce una ahora, para probarla. |
| `stop` | Termina lo que reproduce ahora. |
| `pause` · `resume` | Deja de actuar por su cuenta, hasta reanudarlo o reiniciar. |
| `sit <on\|off>` | Se sienta en un asiento invisible. |

<Callout type="note" title="Junto a Citizens">
Citizens también registra `/npc`, y los dos compiten por él. Usa `/npcs <nombre>` o `/exylianpc <nombre>`;
`/npcadmin` no choca.
</Callout>
