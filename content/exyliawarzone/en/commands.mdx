Almost everything in ExyliaWarzone is done in game from menus; the commands below open them, and `/supplydropsadmin` also starts and stops drops by hand. A module's commands exist only while that module is switched on in `config.yml`.

## Hub

Needs `exyliawarzone.admin`. See [Permissions](/docs/exyliawarzone/permissions).

## Supply drops

<Commands group="supplydrops" />

`announce` is how long the drop is announced before it falls, written `10s`, `2m` or `1m30s`. Left out, the tier's own time is used. It goes after the tier, so to set it you name a tier too. A tier named in a command drops even if it is switched off in the editor.

The old spellings `/supplydrop start`, `here`, `envoy` and `stop` (and `/drop ...`, `/envoysadmin ...`) still work. See [Supply drops](/docs/exyliawarzone/supply-drops).

## Editors

Each opens one module's editor. The same editors open from the cards of the hub.

## ExyliaLib commands that help

| Command | What for |
|---|---|
| `/settings` | Players mute supply drop and duel announcements. |
| `/exylialib logs` | The staff log: crates opened and looted, zones, chests and rooms created and deleted. |
| `/exylialib pendingrewards` | Rewards kept for players whose inventory was full. |
| `/exylialib export ExyliaWarzone` | A copy of everything the plugin stores. |
