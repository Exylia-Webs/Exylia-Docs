Almost everything is done in game from the editors; the commands open them, and `/supplydrop` handles drops by hand.
A module's commands exist only while that module is switched on.

## Hub

Needs `exyliawarzone.admin`.

| Command | Console | What it does |
|---|---|---|
| `/warzoneadmin` (`/wzadmin`) | | Opens the admin hub: one card per module, each showing whether it runs, and **Settings**. |
| `/warzoneadmin settings` | | Opens every setting of every module in a menu. |
| `/warzoneadmin reload` | yes | Reads `config.yml`, every module's `config.yml` and messages, and the admin screens again. Switching a module on or off still needs a restart. |

## Supply drops

| Command | Permission | Console | What it does |
|---|---|---|---|
| `/supplydrop` (`/drop`, `/supplydrops`) | `exyliawarzone.supplydrops.use` | yes | Shows the tier and coordinates of the crate that is out, or how long until the next envoy falls. |
| `/supplydropsadmin start [tier] [announce]` | `exyliawarzone.supplydrops.admin` | yes | Drops one crate in a random enabled envoy's area. Without a tier it rolls one from that envoy's tiers. It does not count as the envoy's run. |
| `/supplydropsadmin here [tier] [announce]` | `exyliawarzone.supplydrops.admin` | | Drops one crate on the block you stand on. Without a tier it rolls from every enabled tier. |
| `/supplydropsadmin envoy <envoy>` | `exyliawarzone.supplydrops.admin` | yes | Runs that envoy now, as if its timetable had fired. |
| `/supplydropsadmin stop` | `exyliawarzone.supplydrops.admin` | yes | Takes every crate away at once, falling ones included. |
| `/supplydropsadmin` (`/envoysadmin`) | `exyliawarzone.supplydrops.admin` | | Opens the supply drops editor: tiers and envoys. |

The old spelling `/supplydrop start`, `here`, `envoy` and `stop` (and `/drop`, `/envoysadmin ...`) still works.

`announce` is how long the drop is announced before it falls, written `10s`, `2m` or `1m30s`; left out, the tier's
own time is used. It goes after the tier, so to set it you name a tier too. A tier named in a command drops even if it
is switched off in the editor.

## Editors

Players only. Each opens the module's editor; the same editors open from the hub's cards.

| Command | Permission | Opens |
|---|---|---|
| `/powerupsadmin` | `exyliawarzone.powerups.admin` | The power-up zone list. See [Power-ups](/docs/exyliawarzone/power-ups). |
| `/lootchestsadmin` | `exyliawarzone.lootchests.admin` | The loot chests placed on this server, and their templates. See [Loot chests](/docs/exyliawarzone/loot-chests). |
| `/regenzonesadmin` | `exyliawarzone.regenzones.admin` | The regen zone list. See [Regen zones](/docs/exyliawarzone/regen-zones). |
| `/duelroomsadmin` | `exyliawarzone.duelrooms.admin` | The duel room list. See [Duel rooms](/docs/exyliawarzone/duel-rooms). |

## Banned items

| Command | Permission | Console | What it does |
|---|---|---|---|
| `/banneditemsadmin` (`/banitemsadmin`) | `exyliawarzone.banneditems.admin` | | The banned-item rule list. See [Banned items](/docs/exyliawarzone/banned-items). |

## ExyliaLib commands that help

| Command | What for |
|---|---|
| `/settings` | Players mute supply drop and duel announcements. |
| `/exylialib logs` | The staff log: crates opened and looted, zones, chests and rooms created and deleted. |
| `/exylialib pendingrewards` | Rewards kept for players whose inventory was full. |
| `/exylialib export ExyliaWarzone` | A copy of everything the plugin stores. |
