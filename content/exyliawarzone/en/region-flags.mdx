A [regen zone](/docs/exyliawarzone/regen-zones) and a [duel room](/docs/exyliawarzone/duel-rooms) are both areas
of the world, and each one can carry **flags**: rules that hold for players inside it, such as no building, no
item drops or keeping the inventory on death. The plugin applies them itself through ExyliaLib's region module, so
no WorldGuard region is needed.

## Editing the flags

A zone's setup screen has a **Region flags** card and a room's a **Room flags** card. Each opens ExyliaLib's flag editor over that
area, one row per flag:

| Row | Click | Right-click |
|---|---|---|
| A flag | Cycles **Default** → **Allow** → **Deny** → **Default** | Back to **Default** |
| **BLOCK LIST** | Opens a list of materials; adding asks the material picker | Back to **Default** |
| **BLOCK LIFETIME** | Asks for a whole number of seconds | Back to **Default** |

Nothing is written until you save. Closing the window, cancelling or leaving discards the changes and takes you back
to the setup screen.

**Default** means the area says nothing about that flag, so the flag's own default applies (the column below). Only
the flags you set to Allow or Deny are stored.

## The flags

| Flag | Default | When set to Deny, inside the area |
|---|---|---|
| `PVP` | Allow | Players cannot hurt players, directly or through arrows, TNT, crystals, harmful potions or tamed pets. |
| `BUILD` | Allow | Blocks cannot be placed (both halves of a door or bed) and buckets cannot be emptied. |
| `BREAK` | Allow | Blocks cannot be broken and buckets cannot be filled from them. |
| `INTERACT` | Allow | Clicked blocks cannot be used, pressure plates and farmland do nothing, and entities other than players (armour stands, frames, villagers, mounts) cannot be right-clicked. The item in hand still works, so eating, pearls and bows go through. |
| `ITEM_DROP` | Allow | Items cannot be dropped. |
| `ITEM_PICKUP` | Allow | Items cannot be picked up. |
| `FALL_DAMAGE` | Allow | Nobody takes fall damage. |

These flags do something when set to **Allow**:

| Flag | Default | When set to Allow, inside the area |
|---|---|---|
| `PLAYER_BUILD_ONLY` | Deny | Only blocks a player placed can be broken; the map itself stays. |
| `ALLOWED_BLOCKS_ONLY` | Deny | Only the materials on the block list can be placed. A bucket counts as its item, such as `WATER_BUCKET`. |
| `BREAKABLE_BLOCKS_ONLY` | Deny | Only the materials on the block list can be broken, even where `BREAK` is denied. |
| `TEMPORARY_BLOCKS` | Deny | Every block a player places disappears again after the temporary block time. |
| `RE_GIVE_BLOCKS` | Deny | A temporary block goes back to the player's inventory when it disappears. |
| `KEEP_INVENTORY` | Deny | A player who dies inside keeps their items and levels: nothing drops and no experience is left behind. |

In the editor each row reads as plain words: **PLAYER BLOCKS ONLY** is `PLAYER_BUILD_ONLY`, **RETURN BLOCKS** is
`RE_GIVE_BLOCKS`, and the others are their name with spaces.

<Callout type="note" title="One block list for both">
`ALLOWED_BLOCKS_ONLY` and `BREAKABLE_BLOCKS_ONLY` share the same block list. With both on, players can place and
break exactly the listed materials, which is what a bridging or building area needs.
</Callout>

### Temporary blocks

With `TEMPORARY_BLOCKS` allowed, each block a player places is removed after **30 seconds** unless you set another
number on the **BLOCK LIFETIME** row. Add `RE_GIVE_BLOCKS` to hand each block back as it goes, so players
never run out while they build.

Saving the flags, or selecting the area again, registers the area anew, and the record of which blocks players have
placed so far starts over: from then on `PLAYER_BUILD_ONLY` treats the earlier ones as part of the map.

### Keep inventory

`KEEP_INVENTORY` is the plugin's own flag. It acts when a player dies inside the area and another plugin has not
already kept the inventory. It runs early, so a plugin that decides a death's drops later, such as a combat or
graves plugin, still has the last word.

## Who the rules hold

- **Everybody in survival or adventure.** Players in **creative mode** are never held by these flags, so staff can
  build and fix an area without changing anything.
- **Only Warzone's own areas.** The flags of a zone or a room decide only inside it. A WorldGuard region, a claim or
  another Exylia plugin's area at the same place keeps its own rules: the action is refused when any of them refuses
  it.
- **Explosions are not covered.** The flags judge what a player does; creepers and TNT going off on their own are not
  stopped by them.

Old rows imported from ExyliaSurvivalCore may still name `ENTRY`, `EXIT` or `REGION_MEMBERS_ONLY`. Nothing applies
those three, so the editor does not show them and they are dropped the next time the area is saved.
