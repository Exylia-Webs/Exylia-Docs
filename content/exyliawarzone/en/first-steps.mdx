At the end of this page one crate falls by parachute inside an area you chose, and players can find it with `/supplydrop`. You only use the admin hub and chat.

An **envoy** is an area plus a set of crates: each run drops a few crates inside the area. A new envoy is enabled and uses every enabled tier, and ExyliaWarzone creates three tiers (`common`, `rare` and `legendary`) with their loot the first time it starts, so only the area is missing.

## Before you start

Install ExyliaWarzone and ExyliaLib, and have `exyliawarzone.admin` (operators have it). See [Install ExyliaWarzone](/docs/exyliawarzone/installation).

## Steps

<Steps>
  <Step title="Open the hub">
    Run `/warzoneadmin`. The **Supply drops** card must read **ENABLED**. If it reads **DISABLED**, switch the module on in `config.yml` under `modules:` and restart.
  </Step>
  <Step title="Create an envoy">
    Click the **Supply drops** card, then **Envoys**, then **Create ▸ Envoy**. Type a short id in chat, for example `spawn-ring`. The envoy's menu opens.
  </Step>
  <Step title="Mark its area">
    Click **Area** with the left button. Take the golden axe you are given: left-click one corner, right-click the opposite corner, then Shift + left-click to confirm. Click one corner at ground level and the other well above it: the corners also set the heights a crate can land at.
  </Step>
  <Step title="Run it">
    Click **Run it now**. The drop is announced, the crate falls about a minute later, and it unlocks 20 seconds after landing.
  </Step>
</Steps>

## Check that it works

Run `/supplydrop`: it shows the tier, the world and the coordinates of the crate, or how long until the next envoy. Walk to the crate, wait for it to unlock and open it to take the loot. If the chat says "No free spot found", see [Common problems](/docs/exyliawarzone/troubleshooting).

## Make it run by itself

Back in the envoy's menu, click **Timetable** to add the times it runs on its own. Without a timetable it only runs when you click **Run it now** or run `/supplydropsadmin envoy <envoy>`. See [Supply drops](/docs/exyliawarzone/supply-drops).

<Details title="Technical details">
Defaults for a new envoy: 4 crates per run, at least 24 blocks apart. A tier's announce time is 60 seconds, the unlock time 20 seconds and a landed crate vanishes after 300 seconds, all set in `modules/supply-drops/config.yml` and per tier or envoy. At most 16 crates can be out on a server at once (`max-active`). `/supplydropsadmin start` and `here` drop a single crate without an envoy run.
</Details>
