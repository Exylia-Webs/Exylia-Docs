Names and icons help players tell vaults apart. Search finds the vault that holds an item.

## Before you start

Names and icons need `exyliaplayervaults.customize.name` and `exyliaplayervaults.customize.icon`; search needs `exyliaplayervaults.search`. All four are granted to everyone by default, so to turn one off, set it to false for a group.

## Steps

<Steps>
  <Step title="Set the default name length">
    `customization.name-max-length` in `config.yml` (24). Names hold letters, digits, spaces and `- _ ' . ! ? # ( )` only.
  </Step>
  <Step title="Give a rank longer names">
    `/lp group vip permission set exyliaplayervaults.namelength.40 true`. The largest number wins.
  </Step>
  <Step title="Pick the starting icon">
    `customization.default-icon` (`BARREL`) is what a vault looks like until its owner chooses. It accepts a material such as `CHEST`, `playerhead-<name>` or `basehead-<texture>`.
  </Step>
  <Step title="Reload">
    `/pvadmin reload`.
  </Step>
</Steps>

## How players use it

| Action | How |
|---|---|
| Rename | Right-click a vault in `/pv`, then type the name in chat. Typing `-` resets it to `#<number>`. |
| Change the icon | Shift-right-click a vault in `/pv`, then pick the icon. |
| Search | The **Search** button in `/pv`, or `/pv search <item>` to type it straight away. |

Search matches an item's material, written the way a player says it (`diamond sword`), or its display name, ignoring case. It looks inside shulker boxes and bundles too, and lists the vaults that hold a match with the number of items found. Searching again within a few seconds is refused, with the cooldown message. With no match, the player is told none of their vaults hold it. Search reads the last saved copy, so an item put in a vault open right now shows once it is saved.

## Check that it works

Rename a vault, then see the new name in the list header of that vault. Put a named item in a vault, close it and search for part of its name.

<Details title="Technical details">
Staff use the same buttons on a player's list: renaming and icons need the customize permissions, and search needs `exyliaplayervaults.admin.view`. The words are `rename-prompt`, `name-invalid`, `renamed`, `rename-reset`, `icon-prompt`, `icon-changed`, `search-prompt` and `search-none` in `messages.yml`. The results screen is `menus/user/search.yml`.
</Details>
