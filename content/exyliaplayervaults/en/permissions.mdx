Players can use ExyliaPlayerVaults without any setup: opening, searching, buying, renaming and choosing icons are allowed by default. Staff tools and the bypasses are for operators. Use this page to give ranks more, or to hand staff only the tools they need.

## Numbered permissions by rank

These four are not in the list above because you choose the number. Give a player the node with any number you like. They are not declared in `plugin.yml`, so grant them by name in your permissions plugin.

| Permission | What it sets | Without one |
|---|---|---|
| `exyliaplayervaults.amount.<number>` | How many vaults the player has. The largest number they hold wins. Never above `vaults.max-amount`, bought vaults included. | `vaults.default-amount` (1) |
| `exyliaplayervaults.rows.<1-6>` | How many rows each of their vaults has. The largest number wins. | `vaults.default-rows` (6) |
| `exyliaplayervaults.cooldown.<seconds>` | How long they wait between opening two vaults. The smallest number wins, and never longer than the server setting. | `restrictions.open-cooldown` (500 ms) |
| `exyliaplayervaults.namelength.<n>` | The longest name they may give a vault. The largest number wins. | `customization.name-max-length` (24) |

With LuckPerms, three vaults of six rows for VIPs and one of three rows for everybody else:

```text
/lp group default permission set exyliaplayervaults.rows.3 true
/lp group vip permission set exyliaplayervaults.amount.3 true
/lp group vip permission set exyliaplayervaults.rows.6 true
```

See [Give ranks more and bigger vaults](/docs/exyliaplayervaults/vaults).

## Staff

Moderators who may look but not touch:

```text
/lp group mod permission set exyliaplayervaults.admin.view true
/lp group mod permission set exyliaplayervaults.admin.history true
```

`admin.edit` and `admin.history` already include `admin.view`. Putting a history copy back needs both `admin.history` and `admin.edit`, because a copy can bring back what the owner has taken out since.

## Take a feature away from a rank

```text
/lp group default permission set exyliaplayervaults.customize.name false
```

A player without the permission who clicks the button sees "You do not have permission to do that." You can change that text in `lang/<code>/messages.yml`, see [Configuration](/docs/exyliaplayervaults/configuration).

<Callout type="warning" title="bypass.blocked is never granted for you">
A blocked-items list is the owner's decision, so `exyliaplayervaults.bypass.blocked` is for nobody by default, operators included, and `exyliaplayervaults.*` leaves it out. Grant it by name to whoever should have it. Staff editing with `/pvadmin edit` are not held to the list anyway.
</Callout>
