ExyliaPlayerVaults gives every player personal vaults: real chests they open from anywhere with `/pv`,
kept in the database and open in exactly one window at a time across a whole network. It is free and open
source, published under the GNU General Public License v3.0 on
[GitHub](https://github.com/Exylia-Plugins/ExyliaPlayerVaults/releases).

It is built so a vault can never duplicate an item: not with two windows, not across a server switch, not
after a crash. A rank decides how many vaults a player has and how big they are; players can buy more,
name them, give them an icon and search them; staff can look inside anybody's, change them, empty them and
put an earlier copy back.

It used to be the `vaults` module of ExyliaSurvivalCore. It is its own plugin now and keeps the vaults in
the same table, so a server whose vaults were in a shared database finds every one of them — see
[Network](/docs/exyliaplayervaults/network#coming-from-exyliasurvivalcore) for what carries over and what
does not.

  </Card>

    One lock per vault shared by every server, writes that never land over a newer row, and Redis to close
    a vault open somewhere else.
  </Card>

## Requirements

| Requirement | Detail |
|---|---|
| Server | Paper 1.21 or newer. Folia supported. |
| Java | 21 |
| Required dependency | `ExyliaLib` — installed automatically when missing |
| Optional dependencies | `PlaceholderAPI`, and whatever economy plugin sells the vaults (`ExyliaEconomy`, `Vault`…) |

<Callout type="note" title="About ExyliaLib">
The configuration, the menus, the database and its locks, Redis, the placeholders, the text and icon
prompts, the economy that charges a purchase and the audit log all come from ExyliaLib.
ExyliaPlayerVaults is the part that decides what a vault is and who may open it.
</Callout>

## Conventions

- Values marked as **default** are what the plugin writes the first time it starts. If the file already
  exists, your value is kept.
- Identifiers between `<` and `>` are variables. `/pv <number>` means `/pv 2`.
- A vault is named by its **number**, counted from 1. Its name and icon are only how it is drawn.
- Colours use ExyliaLib palette tokens (`{primary}`, `{error}`, `{highlight}`), so recolouring the
  network never means editing these files.
