Los jugadores pueden usar ExyliaPlayerVaults sin configurar nada: abrir, buscar, comprar, renombrar y elegir iconos está permitido por defecto. Las herramientas de staff y los bypass son para operadores. Usa esta página para dar más a un rango, o para dar al staff solo las herramientas que necesita.

## Permisos numerados por rango

Estos cuatro no salen en la lista de arriba porque el número lo eliges tú. Da al jugador el permiso con el número que quieras. No están declarados en `plugin.yml`, así que concédelos por su nombre en tu plugin de permisos.

| Permiso | Qué fija | Sin él |
|---|---|---|
| `exyliaplayervaults.amount.<number>` | Cuántos baúles tiene el jugador. Gana el número más alto que tenga. Nunca más que `vaults.max-amount`, comprados incluidos. | `vaults.default-amount` (1) |
| `exyliaplayervaults.rows.<1-6>` | Cuántas filas tiene cada uno de sus baúles. Gana el número más alto. | `vaults.default-rows` (6) |
| `exyliaplayervaults.cooldown.<seconds>` | Cuánto espera entre abrir dos baúles. Gana el número más bajo, y nunca más que el ajuste del servidor. | `restrictions.open-cooldown` (500 ms) |
| `exyliaplayervaults.namelength.<n>` | El nombre más largo que puede poner a un baúl. Gana el número más alto. | `customization.name-max-length` (24) |

Con LuckPerms, tres baúles de seis filas para los VIP y uno de tres filas para todos los demás:

```text
/lp group default permission set exyliaplayervaults.rows.3 true
/lp group vip permission set exyliaplayervaults.amount.3 true
/lp group vip permission set exyliaplayervaults.rows.6 true
```

Mira [Da más baúles y más grandes a un rango](/docs/exyliaplayervaults/cofres).

## Staff

Moderadores que pueden mirar pero no tocar:

```text
/lp group mod permission set exyliaplayervaults.admin.view true
/lp group mod permission set exyliaplayervaults.admin.history true
```

`admin.edit` y `admin.history` ya incluyen `admin.view`. Restaurar una copia del historial necesita `admin.history` y `admin.edit`, porque una copia puede devolver lo que el dueño ha sacado desde entonces.

## Quitar una función a un rango

```text
/lp group default permission set exyliaplayervaults.customize.name false
```

Un jugador sin el permiso que pulse el botón ve "No tienes permiso para hacer eso." Puedes cambiar ese texto en `lang/<code>/messages.yml`, mira [Configuración](/docs/exyliaplayervaults/configuracion).

<Callout type="warning" title="bypass.blocked nunca se da solo">
La lista de objetos bloqueados es decisión del dueño del servidor, así que `exyliaplayervaults.bypass.blocked` no es para nadie por defecto, ni siquiera para los operadores, y `exyliaplayervaults.*` lo deja fuera. Dalo por su nombre a quien deba tenerlo. El staff que edita con `/pvadmin edit` no está sujeto a la lista de todos modos.
</Callout>
