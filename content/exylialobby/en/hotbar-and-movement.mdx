You choose which buttons players get in the lobby hotbar, switch the double jump, place launch pads, set who sees whom and add buttons or areas that run commands.

## Before you start

Players must be inside a [lobby area](/docs/exylialobby/areas). The hotbar needs PacketEvents (buttons are drawn, never put in the real inventory). If ExyliaPracticeCore is installed, its hotbar is in charge unless you set `force: true`.

## Steps

<Steps>
  <Step title="Edit the buttons">
    Open `modules/hotbar/config.yml`. Under `sets`, the `lobby` set has one entry per button: `slot` (0-8), `material`, `name`, `lore` and what it runs. Run `/lobbyadmin reload`. The defaults are Servers (slot 0), Games (1), Parkour (2), Players (6), Gadgets (7) and Settings (8).
  </Step>
  <Step title="Tune the double jump">
    Run `/lobbyadmin`, click **Settings**, then **Movement**. Switch **Double jump** and set the forward push, the upward push and the cooldown.
  </Step>
  <Step title="Place a launch pad">
    In `/lobbyadmin` click **Modules**, right-click **Movement**, then click **Launch pad** (click the block; it throws players the way they look) or **Aimed pad** (stand on the block, face where it should throw, sneak-click).
  </Step>
  <Step title="Choose the default view of players">
    **Settings**, **Visibility**: pick the default view (everyone, friends or nobody), the cooldown between switches and whether clanmates count as friends.
  </Step>
  <Step title="Add a trigger">
    In **Modules**, right-click **Triggers**, then click **Block trigger** (a button, lever, plate or any block) or **Area trigger** (runs when entering and leaving). Left-click the new trigger to add an action line such as `[SERVER] games`.
  </Step>
</Steps>

## Check that it works

Join as a player: your buttons are in the slots you set and a click does what the button says. Jump twice in the air for the double jump. Step on a pad to be thrown. Click the visibility button to cycle everyone, friends and nobody.

## Going further

- **Edit a pad.** In the Movement list: left-click sets its power, right-click its height, Shift-left-click aims it or frees its direction, Shift-right-click removes it (it asks for confirmation), Q edits its blocks.
- **A trigger's clicks.** Left-click adds an action, right-click edits the cooldown, Shift-left-click removes the last action, Shift-right-click removes it.
- **A button for a VIP.** Give the button a `permission`, or `requires: parkour` to draw it only while that module is on.
- **Combat gear is never a button.** The slot `sword-slot` (4) is left free for the [lobby PvP](/docs/exylialobby/lobby-pvp) sword.

<Details title="Hotbar (`hotbar`)">

The hotbar is a named **set** of buttons. Each button is **drawn**, not held: nothing is written into the
real inventory, so a button can never leak out or be dropped. Combat gear must be a real item, never a button.

| Key | Default | What it does |
|---|---|---|
| `set` | `lobby` | The set worn in the lobby: a key of `sets`. |
| `force` | `false` | Show this hotbar even when ExyliaPracticeCore is installed. Without it, PracticeCore's lobby hotbar stays in charge and this module draws nothing. |
| `hide-rest` | `false` | Blank every slot the set does not draw. Keep it off when lobby PvP hands out a real sword. |
| `sword-slot` | `4` | The slot (0-8) reserved for the lobby PvP sword: no button is drawn there. |
| `sets` | `lobby` | The sets, each a map of button id to button. |

A button:

| Key | What it does |
|---|---|
| `slot` | Inventory slot, 0-8. |
| `material`, `name`, `lore` | Anything an item accepts: a material, `basehead-...`, `nexo:id`. |
| `requires` | A module id such as `parkour`: the button is drawn only while that module is on. |
| `permission` | Drawn only for holders. Empty is everyone. |
| `cooldown` | Time between two presses. Default `250ms`; `0` for a button whose action keeps its own cooldown (the visibility switch). |
| `actions` | Click-prefixed action lines, for example `right: exylialobby:selector_open`. No prefix is every click. |
| `commands` | Click-prefixed command lines, for example `right: player: parkour`. |

The default set: Servers (slot 0), Games (1), Parkour (2), Visibility (6), Gadgets (7) and Settings (8).
Actions the plugin registers for buttons and menus:

| Action | Does |
|---|---|
| `exylialobby:selector_open`, `selector_lobbies` | Opens the server or lobby selector. |
| `exylialobby:games_open` | Opens the games screen. |
| `exylialobby:visibility_toggle` | Cycles the player's visibility choice. |
| `exylialobby:hotbar_settings` | Opens the player's settings (ExyliaLib `/settings`). |
| `exylialobby:gadgets_equip`, `gadgets_off` | Equips a gadget or puts it away. |
| `exylialobby:pvp_top` | Opens the kills top. |

</Details>

<Details title="Movement (`movement`)">

| Key | Default | What it does |
|---|---|---|
| `double-jump.enabled` | `true` | Press jump again in the air to jump a second time. |
| `double-jump.forward` / `vertical` | `0.9` / `0.75` | Push in the direction the player looks, and upward. |
| `double-jump.cooldown` | `400ms` | Re-armed on landing. |
| `double-jump.permission` | empty | Permission needed. Empty is everyone. |
| `double-jump.effect` | bat takeoff sound | Title, action bar, boss bar, sound, particle for the jumper. |
| `pads.enabled` | `true` | Turn launch pads on. |
| `pads.cooldown` | `500ms` | Time before the same player can be thrown again, shared by every pad. |
| `pads.effect` | bat takeoff sound | What the player hears and sees when thrown. |
| `pads.list` | none | The pads, placed in game from `/lobbyadmin` → Movement. |

A pad is the block it sits on (`world`, `x`, `y`, `z`) with `power` (horizontal, default 1.6), `vertical`
(0.9), and either the direction the player looks or, with `fixed: true`, the `yaw` you set (0 south, 90 west,
180 north, -90 east).

Pads are added with a wizard. **Pad** asks you to click the block; **Aimed pad** asks you to stand on the block
looking where it should throw (sneak-click to keep the facing). The aim button on an existing pad asks for the
facing the same way.

</Details>

<Details title="Visibility (`visibility`)">

Players choose to see **everyone**, **friends** (staff and, with `clan-friends`, clanmates) or **nobody**.
The choice is a player setting under `/settings` and on the hotbar button. Needs PacketEvents; without it
everyone sees everyone.

| Key | Default | What it does |
|---|---|---|
| `default-mode` | `EVERYONE` | What a player who never chose sees: `EVERYONE`, `FRIENDS` or `NOBODY`. |
| `cooldown` | `500ms` | Time between two switches from the hotbar button. |
| `staff-permission` | `exylialobby.visibility.staff` | Holders are seen by everybody, whatever they chose. |
| `clan-friends` | `true` | Count clanmates as friends (needs a clan plugin ExyliaLib supports). |

Parkour runners hidden from each other use the same rule: a viewer sees a player only when every rule agrees.

</Details>

<Details title="Triggers (`triggers`)">

Blocks and areas that run actions, stored by id in `modules/triggers/config.yml` and placed from `/lobbyadmin` →
Triggers with a wizard. A **block** trigger runs when the block is clicked or stepped on: a button, lever,
pressure plate, tripwire or any block. An **area** trigger runs `actions` when a player walks in and
`leave-actions` when they walk out.

| Key | Default | What it does |
|---|---|---|
| `world` | `world` | The world it stands in. |
| `min` / `max` | `0 64 0` | The corners, as `x y z`. A block trigger has both equal. |
| `area` | `false` | `true` for an area, `false` for a block. |
| `permission` | empty | Permission needed to set it off. Empty is everyone. |
| `cooldown` | `1s` | Time before the same player can set it off again. `0` for none. |
| `actions` | none | Interaction lines run on use or on entering: `console: say hi`, `[MESSAGE] ...`, `[SOUND] ...`, `[SERVER] games`, `[TELEPORT] world;0;64;0`. A `right:` prefix limits a line to a right-click. |
| `leave-actions` | none | Lines run when leaving an area. |

The parkour and PvP leaderboard boards are drawn with ExyliaLib's holograms and need no module of their own.

</Details>
