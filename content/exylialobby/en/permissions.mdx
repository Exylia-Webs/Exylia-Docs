Players can use the lobby without any setup: everything a player does is allowed by default except flying, two gadgets and the staff tools. Use this page to open more or to restrict.

## All permissions

<Permissions />

## Give a gadget to a rank

The grappling hook, paint blaster, knockback stick, leap feather and snowball cannon are on for everyone. The **ender ride** and the **trampoline** default to nobody, so grant them to a rank:

```text
/lp group vip permission set exylialobby.gadget.ender true
/lp group vip permission set exylialobby.gadget.trampoline true
```

## Let a rank fly

Flying needs `exylialobby.fly` and the state module's fly option. See [Set up spawn, state and protection](/docs/exylialobby/core).

```text
/lp group vip permission set exylialobby.fly true
```

## Staff

`exylialobby.admin` opens everything, so there is no narrower node for the chat commands. A helper who only needs to talk through a locked chat gets `exylialobby.chat.bypass` instead.

```text
/lp group helper permission set exylialobby.chat.bypass true
/lp group helper permission set exylialobby.visibility.staff true
```

## Change a permission name

Several permissions are settings of their module and can be renamed there: `fly-permission` (state), `silent-permission` (join), `bypass-permission` (chat), `staff-permission` (visibility), the PvP `permission`, a gadget's `permission`, the double jump's `permission` and a catalogue server's `permission`.
