Players pick a server or a lobby from a menu (or walk into a portal), see every game your plugins offer, and get a tab list header, footer and chat announcements. Counts and status are live from your proxy.

## Before you start

ExyliaLib must be linked to your proxy; player counts come from it. Know the server ids your proxy uses. Everyone using the selector needs `exylialobby.selector` (on by default).

## Steps

<Steps>
  <Step title="List your servers">
    Open `modules/selector/config.yml`. Under `servers`, add one entry per server with `name`, `icon`, `order`, `description` and `server` (the id your proxy knows). The key of the entry is only a name. Run `/lobbyadmin reload`.
  </Step>
  <Step title="List your lobbies (optional)">
    Under `lobbies`, list the proxy ids of the lobbies of your network. `/lobbies` shows them emptiest first.
  </Step>
  <Step title="Add a portal (optional)">
    Run `/lobbyadmin`, click **Modules**, right-click **Server selector**, click **Portal**, mark the two corners of the box and pick the server. Walking into the box sends the player there.
  </Step>
  <Step title="Set the tab list and announcements">
    Open **Settings**, then **HUD**: switch **Player list** and **Announcements** and set the gap between announcements (every 5 minutes by default). The texts are in `modules/hud/config.yml` under `tab` and `announcements`.
  </Step>
</Steps>

## Check that it works

Run `/servers` as a player: your servers appear with their live player count. A server the player lacks the `permission` for shows as locked. `/games` opens the list of games the Exylia plugins offer; if none is installed it says so in chat. Wait for an announcement or look at the tab list.

## Going further

- **Lock a server to a rank.** Set `permission` on its entry.
- **Server NPCs.** Use [ExyliaDisplays](/docs/exyliadisplays): an NPC with the action `[SERVER] <name>` and the label `%network_players_<server>% playing`.
- **Mute announcements.** Players do it themselves in `/settings`, **Announcements**.
- **Portal clicks.** In the portal list: left-click changes the server, right-click shows its outline, Shift-right-click removes it.

<Details title="Server selector (`selector`)">

Player counts and online status are read live from the proxy through ExyliaLib; a click hands the player to
the proxy. Two screens: the **server catalogue** and the **lobby selector**.

| Key | Default | What it does |
|---|---|---|
| `command` | `[servers]` | Labels of the command that opens the server selector. Empty removes it. |
| `lobby-command` | `[lobbies]` | Labels of the command that opens the lobby selector. |
| `lobbies` | none | Server ids (as the proxy names them) that are lobbies of this network: the lobby selector lists them, emptiest first, with the player's own glowing. |
| `servers` | Survival, Minigames examples | The catalogue. The key is only a name. |
| `portals` | none | Boxes between two corners, placed in game. Walking in sends the player to the server. |

A catalogue entry: `name` (colours allowed), `icon` (a material, `basehead-...`, `nexo:id`), `order` (lowest
first), `description` (up to three short lines), `server` (the proxy id) and `permission` (empty is
everyone; without it the card shows as locked).

Server NPCs are no longer part of the module: place them with ExyliaDisplays, an NPC with the action
`[SERVER] <name>` and the label `%network_players_<server>% playing`. Everyone using the selector needs
`exylialobby.selector` (on by default).

</Details>

<Details title="Games (`games`)">

One screen with every game the Exylia plugins register with ExyliaLib's mode list. It says so in chat when
none is registered.

| Key | Default | What it does |
|---|---|---|
| `command` | `[games]` | Labels of the command that opens the screen. Empty removes it. |

</Details>

<Details title="HUD (`hud`)">

Every part switches on its own. Placeholders work everywhere, including [`%lobby_hud_here%`](/docs/exylialobby/placeholders).
The sidebar and the boss bars are ExyliaScreens' `scoreboards.yml` and `bossbars.yml`, no longer part of this module.

| Part | Keys | Default |
|---|---|---|
| Tab list | `tab.enabled`, `header`, `footer`, `interval` | on; placeholders re-read every `5s` |
| Announcements | `announcements.enabled`, `messages`, `interval` | on; one line every `5m` |

Players can mute the announcements in
`/settings` → Announcements. A reload redraws every part for everybody inside.

</Details>
