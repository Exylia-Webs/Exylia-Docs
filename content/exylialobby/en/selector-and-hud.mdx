## Server selector (`selector`)

Player counts and online status are read live from the proxy through ExyliaLib; a click hands the player to
the proxy. Two screens: the **server catalogue** and the **lobby selector**.

| Key | Default | What it does |
|---|---|---|
| `command` | `[servers]` | Labels of the command that opens the server selector. Empty removes it. |
| `lobby-command` | `[lobbies]` | Labels of the command that opens the lobby selector. |
| `lobbies` | none | Server ids (as the proxy names them) that are lobbies of this network: the lobby selector lists them, emptiest first, with the player's own glowing. |
| `servers` | Survival, Minigames examples | The catalogue. The key is only a name. |
| `portals` | none | Boxes between two corners, placed in game. Walking in sends the player to the server. |

A catalogue entry: `name` (colours allowed), `icon` (a material, `basehead-...`, `nexo:id`), `order` (lowest
first), `description` (up to three short lines), `server` (the proxy id) and `permission` (empty is
everyone; without it the card shows as locked).

Server NPCs are no longer part of the module: place them with ExyliaDisplays, an NPC with the action
`[SERVER] <name>` and the label `%network_players_<server>% playing`. Everyone using the selector needs
`exylialobby.selector` (on by default).

## Games (`games`)

One screen with every game the Exylia plugins register with ExyliaLib's mode list. It says so in chat when
none is registered.

| Key | Default | What it does |
|---|---|---|
| `command` | `[games]` | Labels of the command that opens the screen. Empty removes it. |

## HUD (`hud`)

Every part switches on its own. Placeholders work everywhere, including [`%lobby_hud_here%`](/docs/exylialobby/placeholders).
The sidebar and the boss bars are ExyliaScreens' `scoreboards.yml` and `bossbars.yml`, no longer part of this module.

| Part | Keys | Default |
|---|---|---|
| Tab list | `tab.enabled`, `header`, `footer`, `interval` | on; placeholders re-read every `5s` |
| Announcements | `announcements.enabled`, `messages`, `interval` | on; one line every `5m` |

Players can mute the announcements in
`/settings` → Announcements. A reload redraws every part for everybody inside.
