You pick the language of the whole lobby, edit any message or menu text, or add a language of your own. ExyliaLobby ships English (`en`), Spanish (`es`), French (`fr`), Portuguese (`pt`), Russian (`ru`), Turkish (`tr`) and German (`de`).

## Before you start

Find `plugins/ExyliaLobby/lang/` on your server. Each language is a folder you can edit.

## Steps

<Steps>
  <Step title="Choose the language">
    Open `config.yml` and set `language`. `default` follows the language in ExyliaLib's `config.yml`; `en`, `es`, `fr`, `pt`, `ru`, `tr` or `de` makes this plugin alone use that language.
  </Step>
  <Step title="Reload">
    Run `/lobbyadmin reload`, or click **Reload** in `/lobbyadmin`.
  </Step>
  <Step title="Edit a text">
    Open the file in `lang/<code>/` that holds it (table below), change the text and reload. Missing keys are added again on every start.
  </Step>
</Steps>

## Check that it works

Set `language: es`, reload and run `/lobbyadmin`: the cards read **Módulos**, **Áreas**, **Ajustes** and **Recargar**.

## Going further

- **Add a language.** Copy `lang/en` to `lang/<code>`, translate it and set `language` to that code.
- **Your edits are safe.** Admin menus follow the jar. A changed default in a player menu waits in `/exylialib updates` instead of overwriting your edit.
- **Not everything is a language file.** Hotbar buttons, server names, join messages and announcements live in each module's `config.yml`, so write them in the language you want.
- **Colours and shared messages.** See [Messages and languages](/docs/exylialib/messages-and-languages).

<Details title="Where each text lives">

| Path | Contents |
|---|---|
| `messages.yml` | The plugin's own lines. |
| `modules.yml` | The name and description on each module's card in `/lobbyadmin`. |
| `modules/<module>/messages.yml` | The chat lines, titles and card texts of each module. |
| `menus/` | The menus. |

</Details>
