title: "Translations"
description: "The six shipped languages, how to choose one, and how to edit or add your own."
---

ExyliaLobby ships six languages: **English** (`en`), **Spanish** (`es`), **French** (`fr`), **Portuguese**
(`pt`), **Russian** (`ru`) and **Turkish** (`tr`).

## Choosing one

`language` in `config.yml`:

| Value | Result |
|---|---|
| `default` | Follows the language in ExyliaLib's `config.yml`. |
| `en`, `es`, `fr`, `pt`, `ru`, `tr` | This plugin alone uses that language. |

## Where the text lives

Everything players read is in `plugins/ExyliaLobby/lang/<code>/`:

| Path | Contents |
|---|---|
| `messages.yml` | The plugin's own lines. |
| `modules.yml` | The name and description on each module's card in `/lobbyadmin`. |
| `modules/<module>/messages.yml` | The chat lines, titles and card texts of each module. |
| `menus/` | The menus. |

Each language is a folder you can edit. To add another one, copy `lang/en` to `lang/<code>` and translate it.
Missing keys are added on every start. Admin menus follow the jar; a changed default in a player menu waits in
`/exylialib updates` instead of overwriting your edit.

Settings such as hotbar buttons, server names and join messages live in the module's `config.yml`, not in the
language files, so write them in the language you want.
