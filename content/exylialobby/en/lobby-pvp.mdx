Players fight each other in the lobby by choice. A player holds a sword, a short countdown runs and the fighting kit goes on; only two players in that state can hurt each other. Their own things are kept safe and come back exactly when they stop.

## Before you start

The PvP module is on by default and players need `exylialobby.pvp` (everyone has it). Players must be inside a [lobby area](/docs/exylialobby/areas). Items are kept in an ExyliaLib stay, so they return after putting the sword away, death, quitting, leaving the lobby, switching the module off, or a crash.

## Steps

<Steps>
  <Step title="Set where fighters respawn">
    Stand at the spot and run `/lobbyadmin pvp setspawn`. If you set none, fighters respawn at the lobby spawn.
  </Step>
  <Step title="Add a fighting zone (optional)">
    Run `/lobbyadmin`, click **Modules**, right-click **Lobby PvP**, click **Zone** and mark the two corners. The kit goes on when a player walks in and off when they walk out, with no sword needed.
  </Step>
  <Step title="Set the timers">
    Click **Settings**, then **Lobby PvP**: **Equip time** (3 seconds), **Unequip time** (3), **Combat tag** (10) and **Quitting counts**.
  </Step>
  <Step title="Place the kills top">
    Stand where the hologram goes and run `/lobbyadmin pvp setboard`. Players open the top with `/pvptop`.
  </Step>
</Steps>

## Check that it works

With two accounts, hold the sword in the fifth hotbar slot (`sword-slot` 4): a boss bar counts down three seconds and the iron kit goes on. Hit each other. Putting the sword away is refused while the 10 second combat tag runs. After a death the fighter respawns at the spot you set and gets their things back.

## Going further

- **Reward kill streaks.** In `modules/pvp/config.yml`, `streak-rewards` takes a console command (`%player_name%` works) or `item:MATERIAL:amount` per streak. Items go to ExyliaLib's reward queue when the inventory is full.
- **Stop kill farming.** Killing the same player again within `repeat-kill-window` (5 minutes) counts no kill, no streak and no reward. Quitting in combat never pays a streak reward.
- **Change the kit or sword.** `kit` and `sword-material` in the same file; `kit` takes any item a menu accepts.
- **Limit fights to a rank.** Set `permission` in the same file to a node you grant only to some players. Empty means everyone.
- **Stats.** Kills, deaths and streak are stored in the database (`lobby_pvp_stats`) and covered by `/exylialib wipe`. Placeholders: [`%lobby_pvp_...%`](/docs/exylialobby/placeholders).

<Details title="Reference: every key and default">

| Key | Default | What it does |
|---|---|---|
| `top-command` | `[pvptop]` | Labels of the command that opens the kills top. |
| `permission` | empty | Permission needed to fight. Empty is everyone. `exylialobby.pvp` in `plugin.yml` is also declared, default true. |
| `equip-seconds` / `unequip-seconds` / `tag-seconds` | `3` / `3` / `10` | The three timers above. The first two take decimals (`0.5`); `0` is at once. |
| `countdown-sounds` | tick, finish, cancel | Sounds of the countdown, heard by that player only, as `NAME\|volume\|pitch`. Blank plays nothing. |
| `sword-slot` | `4` | Sword slot when the hotbar module is off; with it on, its `sword-slot` is used. |
| `sword-material` | `WOODEN_SWORD` | The sword every player holds. |
| `quit-counts` | `true` | Quitting in combat counts as a death for the quitter and a kill for their opponent. |
| `kit` | iron armor and sword | `helmet`, `chestplate`, `leggings`, `boots`, `weapon`; any item a menu accepts. Empty leaves a slot free. |
| `respawn` | unset | Where a fighter respawns. |
| `top-refresh-seconds` / `board-rows` | `30` / `5` | Refresh of the tops and rows of the hologram board. |
| `board` | unset | Where the top hologram stands . |
| `streak-rewards` | none | Rewards by kill streak: a console command (`%player_name%` works) or `item:MATERIAL:amount`. Items go to ExyliaLib's reward queue when the inventory is full. |
| `zones` | none | The boxes described above. |
| `repeat-kill-window` | `5m` | See below. |

</Details>
