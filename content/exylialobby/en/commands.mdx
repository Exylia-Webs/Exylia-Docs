Every command with the permission it needs. A command whose module is off is not available.

Player command labels are settings of their module, so the ones below are the defaults. An empty list in the module removes the command. `/parkour` also answers to `/pk`, and the staff command also answers to `/hubadmin` (`admin-command` in `config.yml`).

<Commands />

<Callout type="tip" title="Most staff work has a screen">
`/lobbyadmin` opens the admin hub: modules, areas, spawn, hotbar buttons, launch pads, parkour courses, servers and triggers are all edited there. The sub-commands above are shortcuts, and the only way to do some things from the console (`module`, `reload`).
</Callout>
