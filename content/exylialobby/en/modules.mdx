You turn each ExyliaLobby feature on or off from one screen, live, without a restart. By default fourteen of the sixteen modules are on; **Chat** and **Onboarding** are off.

## Before you start

You need the `exylialobby.admin` permission (operators have it). Switching a module off hands every player inside their things back first, so it is safe to do while people are online.

## Steps

<Steps>
  <Step title="Open the module list">
    Run `/lobbyadmin` and click **Modules**. Each module is a card showing its name, what it does and whether it is on.
  </Step>
  <Step title="Switch it">
    Left-click a card to turn that module on or off. The choice is written to `config.yml` straight away.
  </Step>
  <Step title="Change its settings">
    Right-click a card to open that module's settings. Spawn, Selector, Movement, Triggers, Parkour and Lobby PvP open their own screen with the things you place in game (portals, pads, zones, courses); the other modules open their entry in **Settings**.
  </Step>
  <Step title="From the console">
    Run `/lobbyadmin module <id>` to toggle, or `/lobbyadmin module <id> on` / `off` to set it. Ids are in the table below.
  </Step>
</Steps>

## Check that it works

Switch **Gadgets** off, then try `/gadgets` as a player: the command is gone and the Gadgets button leaves the hotbar. Switch it on again and both return. A module that is off registers no commands, listeners or placeholders, so it costs nothing and its labels are free for other plugins.

## Going further

- **Edit by file.** Change `modules` in `config.yml`, then run `/lobbyadmin reload` (or click **Reload** in `/lobbyadmin`).
- **A switch is refused.** If another module it needs is off, the message names that module.
- **Each module has its own files.** Settings in `modules/<id>/config.yml`, text in `lang/<code>/modules/<id>/messages.yml`. Open the page for each group of modules below.

<Details title="Technical details">

Switching off stops modules in the reverse order they start. If a module is switched on again while it is still handing players back, the switch waits for it.

</Details>

<Details title="The sixteen modules">

Every feature is a module. The switches live in `config.yml` under `modules`, and `/lobbyadmin` →
**Modules** flips them live and writes the file, so the two always agree.

| Id | Module | What it does | Default | Page |
|---|---|---|---|---|
| `spawn` | Spawn | Spawn point, `/spawn`, spawn on join, void return, respawn at spawn. | on | [Spawn, state and protection](/docs/exylialobby/core) |
| `state` | Player state | Game mode, health, hunger, effects, flight, time, weather and the experience bar. | on | [Spawn, state and protection](/docs/exylialobby/core) |
| `protection` | Protection | No building, damage, drops, hunger, mobs, fire or explosions. | on | [Spawn, state and protection](/docs/exylialobby/core) |
| `join` | Join and leave | Join and leave messages by permission, welcome commands. | on | [Spawn, state and protection](/docs/exylialobby/core) |
| `chat` | Chat | Chat lock, slow mode and clear chat. No formatting. | **off** | [Spawn, state and protection](/docs/exylialobby/core) |
| `onboarding` | Onboarding | Hands first-join players to ExyliaJourney. | **off** | [Spawn, state and protection](/docs/exylialobby/core) |
| `hotbar` | Hotbar | Buttons that open menus, send to servers or run commands. | on | [Hotbar and movement](/docs/exylialobby/hotbar-and-movement) |
| `movement` | Movement | Double jump and launch pads. | on | [Hotbar and movement](/docs/exylialobby/hotbar-and-movement) |
| `visibility` | Visibility | Players choose to see everyone, friends or nobody. | on | [Hotbar and movement](/docs/exylialobby/hotbar-and-movement) |
| `triggers` | Triggers | Buttons, plates, blocks and areas that run actions. | on | [Hotbar and movement](/docs/exylialobby/hotbar-and-movement) |
| `selector` | Server selector | Servers and lobbies with live counts and portals. | on | [Servers and HUD](/docs/exylialobby/selector-and-hud) |
| `games` | Games | One screen with every game the Exylia plugins offer. | on | [Servers and HUD](/docs/exylialobby/selector-and-hud) |
| `hud` | HUD | Tab list header and footer, and announcements. | on | [Servers and HUD](/docs/exylialobby/selector-and-hud) |
| `gadgets` | Gadgets | Grappling hook, ender ride, paint blaster and more. | on | [Gadgets](/docs/exylialobby/gadgets) |
| `parkour` | Parkour | Courses, endless, sprint and daily modes, leaderboards. | on | [Parkour](/docs/exylialobby/parkour) |
| `pvp` | Lobby PvP | Hold the sword to fight players who opted in. | on | [Lobby PvP](/docs/exylialobby/lobby-pvp) |

</Details>

<Details title="What each module owns">

Each module has its own settings file, `modules/<id>/config.yml`, and its text in
`lang/<code>/modules/<id>/messages.yml`. Both are editable in game from the module's card. A module that is
off registers no commands, listeners, placeholders or actions, so its labels are free for other plugins.

</Details>
