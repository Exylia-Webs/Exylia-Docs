## How the name is written

The placeholders are registered through ExyliaLib as one group, `lobby`. Inside an Exylia plugin's own files
(menus, messages, holograms, scoreboards) they are written `%lobby_hud_here%`. Through PlaceholderAPI the
plugin goes in front: `%exylialobby_lobby_hud_here%`. No expansion needs downloading.

A placeholder exists only while its module is on. The ones marked *viewer* are about the player reading
them.

## Placeholders

| Placeholder | Module | Returns |
|---|---|---|
| `%lobby_hud_here%` | hud | Players inside the lobby areas now. |
| `%lobby_hud_network%` | hud | Players on the network (the larger of the proxy's count and the server's). |
| `%lobby_visibility_state%` | visibility | The viewer's choice: everyone, friends or nobody, in the language's words. |
| `%lobby_pvp_kills%`, `%lobby_pvp_deaths%`, `%lobby_pvp_streak%` | pvp | The viewer's lobby PvP kills, deaths and current streak. |
| `%lobby_pvp_top_<place>_name%` | pvp | The name at that place of the kills top. |
| `%lobby_pvp_top_<place>_value%` | pvp | Its kills. |
| `%lobby_parkour_best_<board>%` | parkour | The viewer's best on a [board](/docs/exylialobby/parkour#leaderboards-and-holograms): a time for a course, a score for a mode, `-` when none. |
| `%lobby_parkour_endless_best%` | parkour | The viewer's all-time endless score, `0` when none. |
| `%lobby_parkour_top_<board>_<place>_name%` | parkour | The name at that place of a board, `-` past the end. |
| `%lobby_parkour_top_<board>_<place>_value%` | parkour | Its time or score. |

`<board>` is a course id or a mode, with an optional period, written as in [Parkour](/docs/exylialobby/parkour):
`tower`, `tower-weekly`, `endless-monthly`, `daily`. `<place>` starts at 1.

```text
%lobby_parkour_top_tower_1_name%   %lobby_parkour_top_tower_1_value%
%lobby_pvp_top_1_name%
```

Everything else a line asks for (`%player_name%`, `%server_name%`...) is resolved by PlaceholderAPI or
ExyliaLib as usual.
