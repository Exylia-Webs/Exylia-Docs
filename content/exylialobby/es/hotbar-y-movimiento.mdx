## Hotbar (`hotbar`)

The hotbar is a named **set** of buttons. Each button is **drawn**, not held: nothing is written into the
real inventory, so a button can never leak out or be dropped. Combat gear must be a real item, never a button.

| Key | Default | What it does |
|---|---|---|
| `set` | `lobby` | The set worn in the lobby: a key of `sets`. |
| `force` | `false` | Show this hotbar even when ExyliaPracticeCore is installed. Without it, PracticeCore's lobby hotbar stays in charge and this module draws nothing. |
| `hide-rest` | `false` | Blank every slot the set does not draw. Keep it off when lobby PvP hands out a real sword. |
| `sword-slot` | `4` | The slot (0-8) reserved for the lobby PvP sword: no button is drawn there. |
| `sets` | `lobby` | The sets, each a map of button id to button. |

A button:

| Key | What it does |
|---|---|
| `slot` | Inventory slot, 0-8. |
| `material`, `name`, `lore` | Anything an item accepts: a material, `basehead-...`, `nexo:id`. |
| `requires` | A module id such as `parkour`: the button is drawn only while that module is on. |
| `permission` | Drawn only for holders. Empty is everyone. |
| `cooldown` | Time between two presses. Default `500ms`. |
| `actions` | Click-prefixed action lines, for example `right: exylialobby:selector_open`. No prefix is every click. |
| `commands` | Click-prefixed command lines, for example `right: player: parkour`. |

The default set: Servers (slot 0), Games (1), Parkour (2), Visibility (6), Gadgets (7) and Settings (8).
Actions the plugin registers for buttons and menus:

| Action | Does |
|---|---|
| `exylialobby:selector_open`, `selector_lobbies` | Opens the server or lobby selector. |
| `exylialobby:games_open` | Opens the games screen. |
| `exylialobby:visibility_toggle` | Cycles the player's visibility choice. |
| `exylialobby:hotbar_settings` | Opens the player's settings (ExyliaLib `/settings`). |
| `exylialobby:gadgets_equip`, `gadgets_off` | Equips a gadget or puts it away. |
| `exylialobby:pvp_top` | Opens the kills top. |

## Movement (`movement`)

| Key | Default | What it does |
|---|---|---|
| `double-jump.enabled` | `true` | Press jump again in the air to jump a second time. |
| `double-jump.forward` / `vertical` | `0.9` / `0.75` | Push in the direction the player looks, and upward. |
| `double-jump.cooldown` | `1s` | Re-armed on landing. |
| `double-jump.permission` | empty | Permission needed. Empty is everyone. |
| `double-jump.effect` | bat takeoff sound | Title, action bar, boss bar, sound, particle for the jumper. |
| `pads.enabled` | `true` | Turn launch pads on. |
| `pads.cooldown` | `800ms` | Time before the same player can be thrown again, shared by every pad. |
| `pads.effect` | bat takeoff sound | What the player hears and sees when thrown. |
| `pads.list` | none | The pads, placed in game from `/lobbyadmin` → Movement. |

A pad is the block it sits on (`world`, `x`, `y`, `z`) with `power` (horizontal, default 1.6), `vertical`
(0.9), and either the direction the player looks or, with `fixed: true`, the `yaw` you set (0 south, 90 west,
180 north, -90 east).

## Visibility (`visibility`)

Players choose to see **everyone**, **friends** (staff and, with `clan-friends`, clanmates) or **nobody**.
The choice is a player setting under `/settings` and on the hotbar button. Needs PacketEvents; without it
everyone sees everyone.

| Key | Default | What it does |
|---|---|---|
| `default-mode` | `EVERYONE` | What a player who never chose sees: `EVERYONE`, `FRIENDS` or `NOBODY`. |
| `cooldown` | `3s` | Time between two switches from the hotbar button. |
| `staff-permission` | `exylialobby.visibility.staff` | Holders are seen by everybody, whatever they chose. |
| `clan-friends` | `true` | Count clanmates as friends (needs a clan plugin ExyliaLib supports). |

Parkour runners hidden from each other use the same rule: a viewer sees a player only when every rule agrees.

## Holograms (`holograms`)

Text boards placed in game from `/lobbyadmin` → Holograms, stored by name in `modules/holograms/config.yml`.

| Key | What it does |
|---|---|
| `lines` | The text, one entry per line. Palette tokens, hologram tags and any placeholder, for example `%lobby_hud_here%`. |
| `world`, `x`, `y`, `z` | Where it stands. |
| `view-distance` | How close a player has to be to see it. Default 48. |

The parkour and PvP leaderboard boards are drawn by this module, so it must be on for them.
