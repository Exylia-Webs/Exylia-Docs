Las etiquetas de los comandos de jugador son ajustes de su módulo (una lista vacía elimina el comando), así
que las de abajo son las predeterminadas. El comando de staff es `/lobbyadmin`, con el alias `/hubadmin`
(`admin-command` en `config.yml`; la primera etiqueta es la principal).

## Comandos de jugador

| Comando | Módulo | Permiso | Qué hace |
|---|---|---|---|
| `/spawn` | spawn | `exylialobby.spawn` | Teletransporta al spawn, tras `warmup` segundos quieto. |
| `/servers` | selector | `exylialobby.selector` | Abre el selector de servidores. |
| `/lobbies` | selector | `exylialobby.selector` | Abre el selector de lobbies. |
| `/games` | games | ninguno | Abre la pantalla de juegos. |
| `/gadgets` | gadgets | ninguno | Abre el menú de gadgets. Cada gadget tiene su propio permiso. |
| `/parkour`, `/pk` | parkour | `exylialobby.parkour` | Abre la lista de recorridos. |
| `/parkour <course>` | parkour | `exylialobby.parkour` | Inicia un recorrido. |
| `/parkour endless\|sprint\|daily` | parkour | `exylialobby.parkour` | Inicia ese modo. |
| `/parkour top [board]` | parkour | `exylialobby.parkour` | Abre una clasificación. |
| `/parkour leave` | parkour | `exylialobby.parkour` | Abandona la carrera. |
| `/pvptop` | pvp | ninguno | Abre el top de asesinatos del PvP del lobby. |

## Comandos de staff

Todos requieren `exylialobby.admin` salvo que se indique lo contrario. Un comando cuyo módulo está
desactivado no está disponible.

| Comando | Qué hace |
|---|---|
| `/lobbyadmin` | Abre el hub de administración (solo jugadores). |
| `/lobbyadmin modules` | Abre la pantalla de módulos. |
| `/lobbyadmin module <id> [on\|off]` | Alterna o fija un módulo. Funciona desde la consola. |
| `/lobbyadmin reload` | Recarga la configuración. |
| `/lobbyadmin build` | Activa o desactiva tu modo construcción, ignorando la protección. Requiere `exylialobby.build`. |
| `/lobbyadmin chat lock` | Bloquea o desbloquea el chat. |
| `/lobbyadmin chat slow <seconds>` | Fija el modo lento. |
| `/lobbyadmin chat clear` | Envía líneas en blanco. |
| `/lobbyadmin pvp setspawn`, `setboard` | Fija la reaparición de los combatientes y el holograma del top donde estás. |
| `/lobbyadmin parkour create <id>` | Crea un recorrido. |
| `/lobbyadmin parkour setstart\|addcheckpoint\|setfinish\|addkill <course>` | Coloca un punto donde estás (`addkill` toma el bloque que miras). |
| `/lobbyadmin parkour medals <course> <gold> <silver> <bronze>` | Fija los tiempos de las medallas en segundos. |
| `/lobbyadmin parkour delete <course>` | Elimina un recorrido. |
| `/lobbyadmin parkour board <board>` | Coloca un holograma de clasificación. |
| `/lobbyadmin parkour endlessarea <name>` | Guarda un área infinita a partir de tu selección. |

Las áreas, los puntos de spawn, las plataformas de lanzamiento, los NPC y portales de servidores, los
hologramas y las zonas de PvP se colocan desde las pantallas de `/lobbyadmin`, que también contienen los
ajustes de los módulos.
