---
title: "Commands"
description: "Player commands and the /lobbyadmin staff command, with their labels, permissions and who may run them."
---

Player command labels are settings of their module (an empty list removes the command), so the labels below
are the defaults. The staff command is `/lobbyadmin`, with the alias `/hubadmin` (`admin-command` in
`config.yml`; the first label is the main one).

## Player commands

| Command | Module | Permission | What it does |
|---|---|---|---|
| `/spawn` | spawn | `exylialobby.spawn` | Teleports to spawn, after `warmup` seconds standing still. |
| `/servers` | selector | `exylialobby.selector` | Opens the server selector. |
| `/lobbies` | selector | `exylialobby.selector` | Opens the lobby selector. |
| `/games` | games | none | Opens the games screen. |
| `/gadgets` | gadgets | none | Opens the gadgets menu. Each gadget has its own permission. |
| `/parkour`, `/pk` | parkour | `exylialobby.parkour` | Opens the course list. |
| `/parkour <course>` | parkour | `exylialobby.parkour` | Starts a course. |
| `/parkour endless\|sprint\|daily` | parkour | `exylialobby.parkour` | Starts that mode. |
| `/parkour top [board]` | parkour | `exylialobby.parkour` | Opens a leaderboard. |
| `/parkour leave` | parkour | `exylialobby.parkour` | Leaves the run. |
| `/pvptop` | pvp | none | Opens the lobby PvP kills top. |

## Staff commands

All of them need `exylialobby.admin` unless noted. A command whose module is off is not available.

| Command | What it does |
|---|---|
| `/lobbyadmin` | Opens the admin hub (players only). |
| `/lobbyadmin modules` | Opens the Modules screen. |
| `/lobbyadmin module <id> [on\|off]` | Toggles or sets a module. Works from the console. |
| `/lobbyadmin reload` | Reloads the configuration. |
| `/lobbyadmin build` | Switches your build mode on or off, ignoring the protection. Needs `exylialobby.build`. |
| `/lobbyadmin chat lock` | Locks or unlocks the chat. |
| `/lobbyadmin chat slow <seconds>` | Sets slow mode. |
| `/lobbyadmin chat clear` | Sends blank lines. |
| `/lobbyadmin pvp setspawn`, `setboard` | Sets the fighters' respawn and the top hologram where you stand. |
| `/lobbyadmin parkour create <id>` | Creates a course. |
| `/lobbyadmin parkour setstart\|addcheckpoint\|setfinish\|addkill <course>` | Places a point where you stand (`addkill` takes the block you look at). |
| `/lobbyadmin parkour medals <course> <gold> <silver> <bronze>` | Sets the medal times in seconds. |
| `/lobbyadmin parkour delete <course>` | Deletes a course. |
| `/lobbyadmin parkour board <board>` | Places a leaderboard hologram. |
| `/lobbyadmin parkour endlessarea <name>` | Saves an endless area from your selection. |

Areas, spawn points, launch pads, server NPCs and portals, holograms and PvP zones are placed from the
screens of `/lobbyadmin`, which hold the module settings too.
