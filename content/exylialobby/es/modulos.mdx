Every feature is a module. The switches live in `config.yml` under `modules`, and `/lobbyadmin` →
**Modules** flips them live and writes the file, so the two always agree.

## Switching a module

- **In game:** `/lobbyadmin` → **Modules**. Each card shows the module's name and description and opens its
  settings.
- **By command:** `/lobbyadmin module <id>` toggles, `/lobbyadmin module <id> on` or `off` sets it. It works
  from the console.
- **By file:** edit `config.yml` and run `/lobbyadmin reload`.

Switching off hands every player inside their things back first (the modules are stopped in the reverse order
they start). If a module is switched on again while it is still handing players back, the switch waits for it.
A module whose switch is refused because another one it needs is off says which one.

## What a module owns

Each module has its own settings file, `modules/<id>/config.yml`, and its text in
`lang/<code>/modules/<id>/messages.yml`. Both are editable in game from the module's card. A module that is
off registers no commands, listeners, placeholders or actions, so its labels are free for other plugins.
