---
title: "Permissions"
description: "Every node the plugin declares, what each one gates, and their defaults."
---

Every node below is declared in `plugin.yml`.

| Permission | Default | What it gates |
|---|---|---|
| `exylialobby.admin` | operators | `/lobbyadmin` and every staff screen. Includes `exylialobby.build`. |
| `exylialobby.build` | operators | `/lobbyadmin build`: build, break and use everything inside lobby areas while it is on. |
| `exylialobby.fly` | nobody | Flying in the lobby while the state module allows it (`fly-permission`). |
| `exylialobby.join.vip` | nobody | Example permission for a join message group. |
| `exylialobby.join.silent` | nobody | Joining and leaving without a message or commands. |
| `exylialobby.chat.bypass` | operators | Talking while chat is locked or slowed; keeping chat when it is cleared. |
| `exylialobby.visibility.staff` | nobody | Always being seen, whatever others chose. |
| `exylialobby.selector` | everyone | The selectors, server NPCs and portals. |
| `exylialobby.pvp` | everyone | Fighting in the lobby PvP. |
| `exylialobby.gadget.<id>` | see below | Equipping and using a gadget. |
| `exylialobby.spawn` | everyone | `/spawn`. |
| `exylialobby.parkour` | everyone | `/parkour`, the courses, the modes and the tops. |

Gadget nodes: `grapple`, `paint`, `knockback`, `leap` and `snowball` are on for everyone; `ender` and
`trampoline` default to nobody, so grant them to a rank to hand them out.

Several permissions are also named in settings and can be changed there: `fly-permission` (state),
`silent-permission` (join), `bypass-permission` (chat), `staff-permission` (visibility), the PvP `permission`,
a gadget's `permission`, the double jump's `permission` and a catalogue server's `permission`.

## Examples

Giving the ender gadget to a rank:

```text
/lp group vip permission set exylialobby.gadget.ender true
```

Letting a helper lock the chat without the rest of the admin tools:

```text
/lp group helper permission set exylialobby.admin true
```

`exylialobby.admin` opens everything, so there is no narrower node for the chat commands.
