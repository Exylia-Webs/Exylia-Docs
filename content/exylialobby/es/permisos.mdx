Los jugadores pueden usar el lobby sin configurar nada: todo lo que hace un jugador está permitido por defecto, salvo volar, dos gadgets y las herramientas de staff. Usa esta página para abrir más o para restringir.

## Dar un gadget a un rango

El gancho, la pistola de pintura, el palo de empuje, la pluma de salto y el cañón de bolas de nieve están activos para todos. El **viaje ender** y el **trampolín** no los tiene nadie por defecto, así que dáselos a un rango:

```text
/lp group vip permission set exylialobby.gadget.ender true
/lp group vip permission set exylialobby.gadget.trampoline true
```

## Dejar volar a un rango

Volar necesita `exylialobby.fly` y la opción de vuelo del módulo de estado. Mira [Configura spawn, estado y protección](/docs/exylialobby/base).

```text
/lp group vip permission set exylialobby.fly true
```

## Staff

`exylialobby.admin` abre todo, así que no hay un permiso más estrecho para los comandos del chat. Un ayudante que solo necesita hablar con el chat bloqueado recibe `exylialobby.chat.bypass`.

```text
/lp group helper permission set exylialobby.chat.bypass true
/lp group helper permission set exylialobby.visibility.staff true
```

## Cambiar el nombre de un permiso

Varios permisos son ajustes de su módulo y se pueden renombrar ahí: `fly-permission` (estado), `silent-permission` (entrada), `bypass-permission` (chat), `staff-permission` (visibilidad), el `permission` del PvP, el `permission` de un gadget, el del doble salto y el `permission` de un servidor del catálogo.
