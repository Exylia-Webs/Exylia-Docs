ExyliaLobby no tiene un artefacto de API publicado. Sus dos eventos están en el jar del plugin, en el paquete
`net.exylia.exyliaLobby.area`. Compila contra el jar de las
[releases de GitHub](https://github.com/Exylia-Plugins/ExyliaLobby/releases) como `compileOnly`, y añade
`ExyliaLobby` en `softdepend` dentro de tu `plugin.yml`.

## Eventos

Ambos se lanzan en el hilo del propio jugador, una vez por cada cruce y después de que los módulos ya hayan
gestionado el cambio. Son eventos asíncronos cuando se lanzan fuera del hilo principal, como en Folia.

| Evento | Cuándo | Métodos |
|---|---|---|
| `LobbyEnterEvent` | Un jugador acaba de entrar en un área del lobby. | `getPlayer()`, `getCause()` |
| `LobbyLeaveEvent` | Un jugador ya no está dentro de una. | `getPlayer()`, `getCause()` |

### AreaCause

| Valor | Significado |
|---|---|
| `JOIN` | Entró al servidor dentro de un área del lobby. |
| `MOVE` | Caminó, se teletransportó, reapareció o cambió de mundo cruzando el borde. |
| `QUIT` | Salió del servidor estando dentro. |
| `CHANGE` | Las áreas cambiaron bajo sus pies: un admin las editó, o hubo una recarga. |
| `MODULE` | Se activó un módulo mientras estaba dentro, así que se pone al día. Se envía solo a ese módulo. |
| `DISABLE` | El plugin se está deteniendo. |

## Ejemplo

```java
@EventHandler
void onEnter(LobbyEnterEvent event) {
    if (event.getCause() == AreaCause.JOIN) {
        event.getPlayer().sendMessage("Welcome to the lobby!");
    }
}
```
