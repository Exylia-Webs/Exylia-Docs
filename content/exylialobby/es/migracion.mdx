---
title: "Replacing PhoenixLobby or AxLobby"
description: "Which ExyliaLobby module covers each feature a lobby plugin usually provides, and what to rebuild by hand."
---

There is no automatic importer: ExyliaLobby has its own files and menus, and every setting is edited in game.
Switch the old plugin off, install ExyliaLobby, and rebuild each feature from the table. The settings
themselves are on the [module pages](/docs/exylialobby/modulos).

## Feature by feature

| A lobby plugin's feature | ExyliaLobby | Where |
|---|---|---|
| Spawn point, `/spawn`, teleport on join | `spawn` module | `on-join`, `points`, `warmup` |
| Void teleport, respawn at spawn | `spawn` module | `void-return`, `void-y`, `respawn` |
| Which worlds or regions are the lobby | Lobby areas | `config.yml` → `areas` |
| Adventure mode, full health and hunger, fixed time and weather, permanent effects, fly | `state` module | `game-mode`, `full-hunger`, `time`, `weather`, `effects`, `fly` |
| World protection (build, break, damage, mobs, fire, containers) | `protection` module | one switch per rule; `/lobbyadmin build` to bypass |
| Join and leave messages by rank, join commands | `join` module | `groups`, `commands` |
| Chat lock, slow mode, clear chat | `chat` module (off by default) | `/lobbyadmin chat ...` |
| Hotbar items running commands, menus or server moves | `hotbar` module | `sets` → buttons with `actions` and `commands` |
| Compass or server selector, server NPCs, portals | `selector` module | `servers`, `npcs`, `portals` |
| Double jump, launch pads | `movement` module | `double-jump`, `pads` |
| Player visibility toggle | `visibility` module | the `exylialobby:visibility_toggle` button |
| Scoreboard, tab header and footer, boss bar, announcements | `hud` module | `sidebar`, `tab`, `boss-bars`, `announcements` |
| Holograms and leaderboard boards | `holograms` module | `/lobbyadmin` → Holograms |
| Lobby PvP with a stat top | `pvp` module | opt-in sword, kit, zones, streak rewards |
| Parkour with checkpoints and times | `parkour` module | courses, medals, tops |
| Cosmetic toys | `gadgets` module | seven gadgets |
| New-player tutorial | `onboarding` module (off by default) | hands off to ExyliaJourney |

## What stays elsewhere

- **Chat formatting** and ranks in the tab list names are not handled. `chat` only controls the flow of
  messages; keep your chat plugin for the rest.
- **Menus** other than the ones listed (a custom menu behind a hotbar button) are built with ExyliaLib
  menus or ExyliaScreens, and opened with a button's `actions`.

## Steps

<Steps>
  <Step title="Note what you had">
    Copy out the spawn, the join messages, the servers and the hotbar items.
  </Step>
  <Step title="Swap the plugins">
    Remove the old lobby plugin's jar, install ExyliaLobby and start the server.
  </Step>
  <Step title="Rebuild">
    Follow [First steps](/docs/exylialobby/primeros-pasos), then the module pages for what you used.
  </Step>
  <Step title="Check from a fresh account">
    Join as a non-operator, then leave the lobby area and confirm you get your own things back.
  </Step>
</Steps>
