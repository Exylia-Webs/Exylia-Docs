Every node below is declared in `plugin.yml`, in the plugin and in the loader alike, so a permissions plugin
shows each one with its default.

## Player nodes

All of these are on for everybody by default, except autosell and the default shop's perks.

| Permission | Default | What it gates |
|---|---|---|
| `exyliamarket.auctionhouse` | everyone | `/ah` and its screens: browsing, your listings, history, the watchlist. |
| `exyliamarket.auctionhouse.sell` | everyone | Listing on the auction house, from `/ah sell` or the screen. |
| `exyliamarket.auctionhouse.buy` | everyone | Buying a listing. |
| `exyliamarket.auctions` | everyone | `/auction` and its screens. |
| `exyliamarket.auctions.sell` | everyone | Opening an auction. |
| `exyliamarket.auctions.bid` | everyone | Bidding, a custom bid, setting an auto-bid and buying an auction out. |
| `exyliamarket.orders` | everyone | `/orders`: browsing the buy orders and your own. |
| `exyliamarket.orders.create` | everyone | Placing a buy order. |
| `exyliamarket.orders.fill` | everyone | Selling items into other players' buy orders. |
| `exyliamarket.bazaar` | everyone | `/bazaar` and its screens. |
| `exyliamarket.bazaar.create` | everyone | Placing bazaar buy orders and sell offers. |
| `exyliamarket.bazaar.instant` | everyone | Instant-buy and instant-sell on the bazaar. |
| `exyliamarket.trade` | everyone | `/trade <player>`, `/trade accept` and the sneak-click request. |
| `exyliamarket.shop` | everyone | `/shop`, and every command that opens one shop (`/blocks`, `/store`…). |
| `exyliamarket.shop.sell` | everyone | Selling to the shop from its screens, and `/sell` in every form. |
| `exyliamarket.shop.gift` | everyone | Buying something from the shop for another player. |
| `exyliamarket.shop.cart` | everyone | Opening the shop cart, adding to it and checking it out. |
| `exyliamarket.worth` | everyone | `/worth`. |
| `exyliamarket.sellwands.use` | everyone | Using a sell wand on a container. |
| `exyliamarket.sellwands.autosell` | **operators** | `/autosell`, the autosell switch in `/settings`, and autosell itself. The switch starts on, so the node alone turns autosell on. |
| `exyliamarket.shop.perks` | **operators** | The **Perks** shop of the default catalogue and its command products. |

### Making a feature a rank perk

The feature nodes (`auctionhouse.buy`, `auctions.bid`, `orders.fill`, `bazaar.create`, `bazaar.instant`,
`shop.gift`, `shop.cart`) are held by everybody, so a feature becomes a perk by **denying** its node to the
default group and granting it to the rank: `exyliamarket.bazaar.instant` set to `false` on `default` and
`true` on `vip`.

A button the player can see answers a denied click with the usual "no permission" line. Taking things back
never needs a node: cancelling your own listing, auction or order, `/collect`, `/trade deny` and emptying
the cart keep working after a rank runs out.

`/collect` has no node: anybody may claim what they are owed.

## Numbered nodes

These are read by prefix, so any number works, and a node whose tail is not a number is ignored. Since each
number is its own node, `plugin.yml` lists them as comments rather than declaring them.

### Limits: the highest wins

| Node | Sets | Default without it |
|---|---|---|
| `exyliamarket.auctionhouse.listings.<n>` | Listings up at once on the auction house. | `max-listings-per-player`, 5 |
| `exyliamarket.auctions.limit.<n>` | Auctions running at once. | `max-auctions-per-player`, 3 |
| `exyliamarket.orders.limit.<n>` | Open buy orders. | `max-orders-per-player`, 5 |
| `exyliamarket.bazaar.limit.<n>` | Open bazaar buy orders and sell offers together. | `max-offers-per-player`, 14 |
| `exyliamarket.bazaar.volume.<n>` | Money traded on the bazaar per day, bought and sold together. | `daily-volume`, -1 (no limit) |
| `exyliamarket.shop.sell.<multiplier>` | What everything sold to the server pays; decimals allowed (`shop.sell.1.5`). See [Selling](/docs/exyliamarket/selling#sell-bonus). | no bonus |

A limit node of `0` counts as not having one: the default applies. The node **replaces** the setting rather
than adding to it, so `exyliamarket.auctionhouse.listings.2` gives a player 2 listings even though the
default is 5.

### Fees and taxes: the lowest wins

Whole percents. The lowest one a player holds is their rate; without any, the module's setting applies. A
node of `0` is no fee or no tax at all.

| Node | Sets | Default without it |
|---|---|---|
| `exyliamarket.auctionhouse.fee.<n>` | The auction house listing fee. | `listing-fee-percent`, 2 |
| `exyliamarket.auctionhouse.tax.<n>` | The auction house sales tax. | `sales-tax-percent`, 5 |
| `exyliamarket.auctions.fee.<n>` | The auction listing fee. | `listing-fee-percent`, 2 |
| `exyliamarket.auctions.tax.<n>` | The auction sales tax. | `sales-tax-percent`, 5 |
| `exyliamarket.orders.fee.<n>` | The buy order creation fee. | `creation-fee-percent`, 1 |
| `exyliamarket.orders.tax.<n>` | The tax on selling into an order. | `sales-tax-percent`, 5 |
| `exyliamarket.bazaar.tax.<n>` | The bazaar sales tax. The flat `fee` is not affected. | `tax-percent`, 1.25 |

A sales tax is read from the **seller** when the sale happens. A seller who is offline by then (a listing
selling overnight, an auction ending, a bazaar offer filling) pays the configured rate.

## Staff nodes

All default to operators.

| Permission | What it gates |
|---|---|
| `exyliamarket.admin.reload` | `/marketadmin reload` and the reload button of the panel. |
| `exyliamarket.admin.logs` | `/marketadmin log`, `/marketadmin stats` and their screens; with it, `/shopadmin log` in game opens the market log. |
| `exyliamarket.admin.demo` | `/marketadmin demo seed` and `demo clear`: fake market activity for screenshots, on test servers only. |
| `exyliamarket.auctionhouse.admin` | `/ahadmin`: removing any listing, clearing a player's. The auction house settings screen. |
| `exyliamarket.auctions.admin` | `/auctionadmin`: removing any auction, clearing a player's. The auctions settings screen. |
| `exyliamarket.orders.admin` | `/ordersadmin`: cancelling any order. The orders settings screen. |
| `exyliamarket.bazaar.admin` | `/bazaaradmin`: the products editor and cancelling any order or offer. The bazaar settings screen. |
| `exyliamarket.shop.admin` | `/shopadmin`: the shop editor, coupons, sales, the default catalogue and a player's shop log. Opens every shop whatever its permission. |
| `exyliamarket.sell.admin` | `/selladmin audit` and the price audit screen, and hearing about price problems on join. The `/sell` settings screen. |
| `exyliamarket.worth.admin` | `/setworth` and the worth editor. |
| `exyliamarket.sellwands.admin` | `/sellwandadmin give` and the sell wand settings screen. |
| `exyliamarket.trade.admin` | The trade settings screen. |
| `exyliamarket.prices.admin` | The price-check settings screen, and how long history and the market log are kept. |

`/marketadmin` itself opens for anybody holding **any one** of the staff nodes above; each card and
settings page inside it asks for its own. See [Administration](/docs/exyliamarket/administration).

Wiping the market's data or resetting one player is done with ExyliaLib's `/exylialib wipe` and
`/exylialib resetplayer`, under its own permissions: see [ExyliaLib commands](/docs/exylialib/commands).
