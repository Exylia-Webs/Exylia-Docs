Most settings are a button, not a file: run `/marketadmin` and change them in game, which writes the same files. Open this page when you want a file's location, a default or the network groups.

Everything is generated in `plugins/ExyliaMarket/` on the first start, with comments on every key. After editing a file, run `/marketadmin reload`. The catalogues (the shop, the bazaar's products, listings, orders) live in the database, not in any file.

## config.yml

The plugin's own file is short: the language, a debug switch, one switch per module and a few groups of settings. Every section below says what it is for; the full key tables are folded under each.

### language and debug

`language: default` follows the language set in ExyliaLib; `en`, `es`, `pt`, `fr`, `ru` or `tr` set this plugin alone. Each is a folder under `lang/`. See [Messages and languages](/docs/exylialib/messages-and-languages).

<Details title="Keys">
| Key | Default | What it does |
|---|---|---|
| `language` | `default` | Language of this plugin's menus and messages. `custom` holds files adopted from a server that had its own. |
| `debug` | `false` | Extra console detail. |
</Details>

### modules

One switch per module, all on. A module switched off registers nothing at all (no commands, listeners, menus, placeholders or tables) and its own file is left alone. **A restart applies a change**; a reload only names the modules waiting for one.

`sell-wands` needs `sell`: with `sell` off it stays off, with a line in the console.

<Details title="Keys">
All under `modules:`, all `true` by default: `auction-house`, `auctions`, `orders`, `bazaar`, `shop`, `sell`, `worth`, `sell-wands`, `trade`.
</Details>

### network

Which servers of a network share each module's data. Servers on the same database share everything unless they are put in groups here: `survival-1` and `survival-2` set `group: survival` and trade on one auction house, while a full-PvP server sets `group: fullpvp` and keeps its own. **Restart to apply.**

Each module's value is `default` (follow `group`), `global` (share with every server on the database), `server` (keep it to this server) or the name of a group of its own. A group keeps its rows in tables of its own, named with the group in front (`survival_sc_auctions`). Data written before a module changed group stays with the old group: move it yourself, or empty it first. An invalid name is warned about in the console and shares with every server until it is fixed. The market log and players' history are always shared.

<Details title="Keys">
| Key | Default | What it does |
|---|---|---|
| `group` | `''` | This server's group: letters, digits, `-` and `_`, up to 24. Blank follows `network-group` in ExyliaLib's `config.yml`, which every Exylia plugin reads (set it there); with neither, it shares with every server. |
| `modules.auction-house` | `default` | Auction house listings and watchlists. |
| `modules.auctions` | `default` | Auctions. |
| `modules.orders` | `default` | Buy orders. |
| `modules.bazaar` | `default` | The bazaar's products, order books and daily volume. |
| `modules.shop` | `global` | The shops, their stock, limits, coupons and log. Global so one shop can serve the whole network and still be offered on some servers only, which each shop sets in the editor. |
| `modules.prices` | `default` | The price index behind suggestions and charts. |
| `modules.deliveries` | `default` | What players are owed in `/collect`, so what survival owes is collected on survival. |
| `modules.sell` | `default` | Sales to the server: what each player sold today, the rested pool and the market index. |
</Details>

### feedback

Toasts, floating labels, particles, action bars and countdowns. Every key is described on [Collect and notices](/docs/exyliamarket/collect#feedback).

### categories

The categories the auction house board and the worth menu filter by. `shown` lists them in order (`blocks`, `tools`, `armour`, `food`, `redstone`, `enchanted-books`, `potions`, `misc`; leave one out to hide it). Their names are in `messages.yml` under `categories`. The bazaar has categories of its own, in its file.

<Details title="Keys">
| Key | Default | What it does |
|---|---|---|
| `shown` | all eight | The categories the filter steps through, in order. |
| `overrides` | `TOTEM_OF_UNDYING: misc` | A material filed somewhere other than its own category, as `MATERIAL: category`. |
</Details>

### prices

Warnings and history for the [price index](/docs/exyliamarket/prices). By default the plugin asks before a player lists below 50% or buys above 200% of the 7-day average, once an item has 3 sales.

<Details title="Keys">
| Key | Default | What it does |
|---|---|---|
| `refresh-seconds` | `60` | How often each server writes its trades and reads every server's back. Restart to apply. |
| `min-sales` | `3` | Sales in the last 7 days before a price is suggested or a deal questioned. |
| `warn-below-percent` | `50` | Ask before listing below this % of the 7-day average. `0` never. |
| `warn-above-percent` | `200` | Ask before buying above this % of it. `0` never. |
| `keep-history-days` | `90` | Days each player's market history is kept. `0` forever. |
| `keep-daily-days` | `365` | Days the daily figures behind the charts are kept. `0` forever. |
</Details>

### logs

The market log behind `/marketadmin log` and the stats screen is kept 30 days by default.

<Details title="Keys">
| Key | Default | What it does |
|---|---|---|
| `keep-days` | `30` | Days each line of the market log is kept. `0` forever. |
| `stats-refresh-seconds` | `60` | How often the stats screen's figures are worked out again. |
</Details>

## Messages and menus

Everything a player reads lives under `lang/<code>/`, where `<code>` is the `language` above. Colours use the ExyliaLib palette: see [Colours](/docs/exylialib/colours). To change what a menu looks like, see [Edit menus](/docs/exylialib/edit-menus).

<Details title="Files under lang/">
| File | What it holds |
|---|---|
| `messages.yml` | The prefix, errors, notices and the join summary, `/collect`, feedback, menu labels, category names, history words, price words, the settings screens and the market log. |
| `modules/<module>/messages.yml` | Each module's lines. |
| `menus/collect.yml`, `menus/currency_select.yml`, `menus/price_history.yml` | `/collect`, the currency picker, the price chart. |
| `menus/admin/*.yml` | The staff screens. **Rewritten from the jar on every start.** |
| `modules/<module>/menus/*.yml` | Each module's player screens. |
| `modules/trade/window.yml` | The trade window. |

A message may start with `[sound:NAME|volume|pitch]`, which plays a sound and never reaches the screen. `%prefix%` is the `prefix` of the core `messages.yml`, used by every module's file too.
</Details>

<Callout type="note" title="Updating menus">
A release updates a player screen only while it is untouched; an edited one is kept and the new version is offered next to it. The staff screens are the plugin's and are replaced on every start.
</Callout>
