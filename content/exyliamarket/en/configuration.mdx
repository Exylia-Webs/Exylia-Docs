Everything is generated in `plugins/ExyliaMarket/` on first start, with comments. Edit the files there and
run `/marketadmin reload`; most module settings can also be changed in game from `/marketadmin`, which
writes the same files. The catalogues — the shop, the bazaar's products, listings, orders — live in the
database, not in any file.

## config.yml

```yaml
language: default
debug: false
modules:
  auction-house: true
  auctions: true
  orders: true
  bazaar: true
  shop: true
  sell: true
  worth: true
  sell-wands: true
  trade: true
feedback:
  toasts:
    auction-house-sold: GOAL
    auctions-won: CHALLENGE
    auctions-sold: GOAL
    orders-filled: TASK
    orders-completed: GOAL
  sell-indicators: true
  wand-particles: HAPPY_VILLAGER|12|0.4|0.4|0.4|0
  autosell-report: ACTION_BAR
  auction-countdown-seconds: 60
  outbid-action-bar: true
  trade-countdown: BOSS_BAR
categories:
  shown: [blocks, tools, armour, food, redstone, enchanted-books, potions, misc]
  overrides:
    TOTEM_OF_UNDYING: misc
prices:
  refresh-seconds: 60
  min-sales: 3
  warn-below-percent: 50
  warn-above-percent: 200
  keep-history-days: 90
  keep-daily-days: 365
logs:
  keep-days: 30
  stats-refresh-seconds: 60
```

### language and debug

| Key | Default | What it does |
|---|---|---|
| `language` | `default` | Language of this plugin's menus and messages. `default` follows ExyliaLib's; `en`, `es`, `pt`, `fr` or `ru` set this plugin alone. Each is a folder under `lang/`; `custom` holds files adopted from a server that had its own. |
| `debug` | `false` | Extra console detail. |

### modules

One switch per module, all on. A module switched off registers nothing at all — no commands, listeners,
menus, placeholders or tables — and its own file is left alone. **A restart applies a change**; a reload
only names the modules waiting for one.

`sell-wands` needs `sell`: with `sell` off it stays off, with a line in the console.

### feedback

Toasts, floating labels, particles, action bars and countdowns. Every key is described on
[Collect and notices](/docs/exyliamarket/collect#feedback).

### categories

The categories the auction house board and the worth menu filter by.

| Key | Default | What it does |
|---|---|---|
| `shown` | all eight | The categories the filter steps through, in order: `blocks`, `tools`, `armour`, `food`, `redstone`, `enchanted-books`, `potions`, `misc`. Leave one out to hide it. |
| `overrides` | `TOTEM_OF_UNDYING: misc` | A material filed somewhere other than its own category, as `MATERIAL: category`. |

Their names are in `messages.yml` under `categories`. The bazaar has categories of its own, in its file.

### prices

The [price index](/docs/exyliamarket/prices).

| Key | Default | What it does |
|---|---|---|
| `refresh-seconds` | `60` | How often each server writes its trades and reads every server's back. Restart to apply. |
| `min-sales` | `3` | Sales in the last 7 days before a price is suggested or a deal questioned. |
| `warn-below-percent` | `50` | Ask before listing below this % of the 7-day average. `0` never. |
| `warn-above-percent` | `200` | Ask before buying above this % of it. `0` never. |
| `keep-history-days` | `90` | Days each player's market history is kept. `0` forever. |
| `keep-daily-days` | `365` | Days the daily figures behind the charts are kept. `0` forever. |

### logs

| Key | Default | What it does |
|---|---|---|
| `keep-days` | `30` | Days each line of the market log is kept. `0` forever. |
| `stats-refresh-seconds` | `60` | How often the stats screen's figures are worked out again. |

## Messages and menus

All under `lang/<code>/`, where `<code>` is the `language` above.

| File | What it holds |
|---|---|
| `messages.yml` | The prefix, errors, notices and the join summary, `/collect`, feedback, menu labels, category names, history words, price words, the settings screens and the market log. |
| `modules/<module>/messages.yml` | Each module's lines. |
| `menus/collect.yml`, `menus/currency_select.yml`, `menus/price_history.yml` | `/collect`, the currency picker, the price chart. |
| `menus/admin/*.yml` | The staff screens. **Rewritten from the jar on every start.** |
| `modules/<module>/menus/*.yml` | Each module's player screens. |
| `modules/trade/window.yml` | The trade window. |

Colours use ExyliaLib palette tokens such as `{primary}`, `{error}` or `{highlight}`. A message may start with
`[sound:NAME|volume|pitch]`, which plays a sound and never reaches the screen. `%prefix%` is the `prefix` of
the core `messages.yml`, used by every module's file too.

<Callout type="note" title="Updating menus">
A release updates a player screen only while it is untouched; an edited one is kept and the new version is
offered next to it. The staff screens are the plugin's and are replaced on every start.
</Callout>
