Find the symptom, then follow the fix. If none matches, ask on the [Exylia Discord](https://discord.exylia.net).

## Nothing can be listed or bought

ExyliaMarket has no economy to move money with. Install ExyliaEconomy, or Vault with an economy plugin. On every start the console says which module is waiting for one. See [ExyliaLib economy](/docs/exylialib/economy).

## A player says an item disappeared

Run `/collect` as that player. Anything the market could not hand over waits there and is never dropped: an expired listing, an auction won while away, an item bought with a full inventory, a trade called off while they were offline. Items delivered into a buy order wait on the order, in `/orders mine`.

To trace a deal, staff run `/marketadmin log <player>`. See [Administration](/docs/exyliamarket/administration#the-market-log).

## A command says the feature is disabled

That module is switched off. Under `modules` in `plugins/ExyliaMarket/config.yml`, set the module to `true` (for example `auctions: true`) and restart. A module that is off registers no commands of its own. See [Configuration](/docs/exyliamarket/configuration).

## A command says I have no permission

Every player feature is on for everybody by default, so a denial means a permissions plugin removed it, often to make it a rank perk. Check the node on [Permissions](/docs/exyliamarket/permissions). Staff commands need their own `admin` node.

## An item sells for less than worth.yml says

Three things hold a sale price down. The shop wins when it also buys that item, at its own price. Nothing sells for as much as the shop charges for it, or as much as crafting it from shop items costs. And the shop's sell limit may be used up. Run `/selladmin` to see where the shop and the worth list disagree. See [Selling and worth](/docs/exyliamarket/selling#the-price-audit).

## Players got autosell without running /autosell

Autosell's switch starts on. Giving a rank `exyliamarket.sellwands.autosell` turns it on for them at once. Each player can turn it off with `/autosell` or in `/settings`.

## Shop edits on one server do not show on another

Turn Redis on in `database.yml` on every server. Without it the other servers only read the catalogue again when they restart. Stock and limits are safe either way.

## A rare shop item never runs out

A product whose stock is full when its restock is due is skipped without moving its next restock, so after the first quiet period every purchase is refilled within a minute. Until that is fixed, use per-player limits for rare items. See [Shop](/docs/exyliamarket/shop#known-issues).
