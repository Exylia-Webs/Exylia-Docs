---
title: "Commands"
description: "Every command of every module, its aliases, the permission it asks for and what it does."
---

Each module registers its own commands, and only while it is switched on: a module that is off has none.
A command of a module that is on but not running answers that the module is disabled.

Arguments in `<>` are required, in `[]` optional. Money is typed as a number; `NaN` and infinity are refused.

## Players

| Command | Permission | What it does |
|---|---|---|
| `/collect` | — | Everything the market owes you, on one screen. See [Collect](/docs/exyliamarket/collect). |
| `/ah` (`/auctionhouse`) | `exyliamarket.auctionhouse` | Opens the auction house. |
| `/ah sell <price> [currency]` | `exyliamarket.auctionhouse.sell` | Lists the stack in your hand, through the review screen. |
| `/ah mine` (`/ah listings`) | `exyliamarket.auctionhouse` | Your listings. |
| `/auction` (`/auctions`) | `exyliamarket.auctions` | Opens the running auctions. |
| `/auction sell <start> [hours] [buyout] [currency]` | `exyliamarket.auctions.sell` | Auctions the stack in your hand. A buyout of `0` is none. |
| `/auction mine` (`/auction selling`) | `exyliamarket.auctions` | Your auctions. |
| `/auction view <id>` | `exyliamarket.auctions` | One auction's bid screen: where **[BID AGAIN]** leads. |
| `/orders` (`/order`) | `exyliamarket.orders` | Opens the buy orders. |
| `/orders create <amount> <price> [currency]` | `exyliamarket.orders.create` | Orders `<amount>` of exactly what you hold at `<price>` **each**, through the review screen. |
| `/orders mine` | `exyliamarket.orders` | Your orders and what they collected. |
| `/bazaar [item]` (`/bz`) | `exyliamarket.bazaar` | Opens the bazaar, or one product. |
| `/bazaar mine` | `exyliamarket.bazaar` | Your open orders and offers. |
| `/shop [shop]` | `exyliamarket.shop` | Opens the shop, or one shop by id. With a single shop on the server, opens that one. |
| `/shop cart` | `exyliamarket.shop` | Your cart. Adding and checking out need `exyliamarket.shop.cart`. |
| `/shop history` | `exyliamarket.shop` | What you bought and sold in the shop. |
| `/<shop command>` | `exyliamarket.shop` | The commands each shop sets in its editor, such as `/blocks` or `/store`: open that shop. |
| `/sell` | `exyliamarket.shop.sell` | The sell window. |
| `/sell hand` | `exyliamarket.shop.sell` | Sells the stack in your hand. |
| `/sell all` | `exyliamarket.shop.sell` | Sells everything sellable you carry. |
| `/sell sales` | `exyliamarket.shop.sell` | What you sold to the server today, what each item pays now and when the amounts start over. See [balancing](/docs/exyliamarket/selling#balancing-sales-to-the-server). |
| `/worth [material]` | `exyliamarket.worth` | What the item in hand, or a material, sells for. |
| `/worth inventory` (`inv`) | `exyliamarket.worth` | What everything you carry adds up to. |
| `/worth menu` (`list`, `browse`) | `exyliamarket.worth` | Every price, browsable. |
| `/worth history [material]` | `exyliamarket.worth` | The 7-day price chart. |
| `/autosell` | `exyliamarket.sellwands.autosell` | Turns autosell on or off. |
| `/trade <player>` | `exyliamarket.trade` | Asks a player to trade. |
| `/trade accept [player]` | `exyliamarket.trade` | Accepts a request, the newest without a name. |
| `/trade deny` | — | Denies the newest request. Needs no node, so a player whose rank lost trading can still say no. |

Every player command runs for players only. Buying, bidding and the other actions inside the screens have
nodes of their own: see [Permissions](/docs/exyliamarket/permissions).

## Staff

| Command | Permission | What it does |
|---|---|---|
| `/marketadmin` (`/exyliamarket`) | any staff node | The admin panel. From the console, the usage. |
| `/marketadmin log [player]` | `exyliamarket.admin.logs` | The market log, of everybody or one player. |
| `/marketadmin stats` | `exyliamarket.admin.logs` | The stats screen. |
| `/marketadmin reload` | `exyliamarket.admin.reload` | Re-reads every file and menu. Also from the console. |
| `/marketadmin demo seed` | `exyliamarket.admin.demo` | Fills the market with fake activity for screenshots. Test servers only. |
| `/marketadmin demo clear` | `exyliamarket.admin.demo` | Removes everything the demo added, refunding nobody. |
| `/ahadmin` (`/auctionhouseadmin`) | `exyliamarket.auctionhouse.admin` | Every listing. |
| `/ahadmin remove <id>` | `exyliamarket.auctionhouse.admin` | Takes one listing down after a confirmation; the item goes back to the seller. |
| `/ahadmin clear <player>` | `exyliamarket.auctionhouse.admin` | Takes down everything a player has listed, after a confirmation. |
| `/auctionadmin` (`/auctionsadmin`) | `exyliamarket.auctions.admin` | Every running auction. |
| `/auctionadmin remove <id>` | `exyliamarket.auctions.admin` | Removes an auction after a confirmation; the top bid is refunded. |
| `/auctionadmin clear <player>` | `exyliamarket.auctions.admin` | Removes every auction a player runs, after a confirmation. |
| `/ordersadmin` (`/ordersa`) | `exyliamarket.orders.admin` | Every open order. |
| `/ordersadmin cancel <id>` | `exyliamarket.orders.admin` | Cancels an order and refunds the buyer. |
| `/bazaaradmin` (`/bzadmin`) | `exyliamarket.bazaar.admin` | The products editor and every open order and offer. |
| `/bazaaradmin cancel <id>` | `exyliamarket.bazaar.admin` | Cancels an order or offer; what it held goes back. |
| `/shopadmin` (`/shopa`) | `exyliamarket.shop.admin` | The shop editor. |
| `/shopadmin defaults add` | `exyliamarket.shop.admin` | Adds what is missing of the default shop and worth list. |
| `/shopadmin defaults replace` | `exyliamarket.shop.admin` | Backs up, then replaces the shop and worth list with the defaults. |
| `/shopadmin log <player> [rows]` | `exyliamarket.shop.admin` | A player's shop purchases and sales; in game with `exyliamarket.admin.logs`, their market log. Otherwise 10 rows, up to 50. |
| `/shopadmin coupon create <code> <percent> [uses] [duration] [shop]` | `exyliamarket.shop.admin` | A new coupon. See [Shop](/docs/exyliamarket/shop#coupons-and-sales). |
| `/shopadmin coupon delete <code>` | `exyliamarket.shop.admin` | Deletes a coupon. |
| `/shopadmin coupon list` | `exyliamarket.shop.admin` | Every coupon: a screen in game, lines from the console. |
| `/shopadmin sale <shop\|all> <percent> <duration> [starts-in]` | `exyliamarket.shop.admin` | A sale on one shop or all of them, now or later. `0` percent ends it. |
| `/selladmin [audit]` | `exyliamarket.sell.admin` | The price audit: a screen in game, lines from the console. |
| `/marketadmin setworth <price> [material]` (`/setworth`) | `exyliamarket.worth.admin` | Prices the item in hand or a material in the worth list. `0` removes it. |
| `/sellwandadmin give <player> <multiplier> <uses>` (`/sellwanda`) | `exyliamarket.sellwands.admin` | Gives a sell wand: multiplier 0.1 to 10, uses `-1` for unlimited. |

<Callout type="note" title="What runs from the console">
`/marketadmin reload`, `/marketadmin demo`, `/shopadmin defaults add|replace`, `/shopadmin log`,
`/shopadmin coupon`, `/shopadmin sale`, `/selladmin`, `/marketadmin setworth` with a material, and `/sellwandadmin give`
run from the console. `/ahadmin remove|clear` and
`/auctionadmin remove|clear` take a player sender, so they only run in game, although the root commands print
their usage to the console. The panel and every editor are screens, for players only.
</Callout>
