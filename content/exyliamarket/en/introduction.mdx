ExyliaMarket is everything players buy and sell on an Exylia server, in one plugin: between each other
through the auction house, auctions, buy orders, the bazaar and face-to-face trades, and with the server
through its shop, `/sell`, the worth list, sell wands and autosell. Each is a module with its own switch,
its own file and its own commands.

It is a **premium** plugin, sold through the [Exylia store](https://link.exylia.net/@services) and installed
through a licence loader.

## The modules

<Cards>
  <Card title="Auction house" href="/docs/exyliamarket/auction-house">
    Fixed-price listings with a review of fee and tax, a suggested price, boxes you can look inside,
    sorts, categories, search and a watchlist.
  </Card>
  <Card title="Auctions" href="/docs/exyliamarket/auctions">
    Timed auctions in any currency, bids held until beaten, auto-bids up to a ceiling, buy-it-now and
    anti-snipe.
  </Card>
  <Card title="Buy orders" href="/docs/exyliamarket/orders">
    Pay up front for an amount of an item; anybody fills it and is paid at once.
  </Card>
  <Card title="Bazaar" href="/docs/exyliamarket/bazaar">
    An order book per product: instant buys and sells, buy orders and sell offers, 227 products shipped.
  </Card>
  <Card title="Trade" href="/docs/exyliamarket/trade">
    Two grids, money, two accepts and a countdown: the end of "you drop yours first".
  </Card>
  <Card title="Shop" href="/docs/exyliamarket/shop">
    Categories and products edited in game, fixed, demand or random prices, stock, limits, sales and
    rotations, with a 402-product default shop.
  </Card>
  <Card title="Selling and worth" href="/docs/exyliamarket/selling">
    `/sell`, its window, the worth list, what each item is worth drawn under it, and an audit of prices
    that would print money.
  </Card>
  <Card title="Sell wands" href="/docs/exyliamarket/sell-wands">
    Wands that empty a container into money, and autosell for what players break.
  </Card>
</Cards>

Around them: one [`/collect`](/docs/exyliamarket/collect) inbox for everything a player is owed, notices that
find a player on any server, a [price index](/docs/exyliamarket/prices) built from what players actually
paid, a market log and stats for staff, settings edited in game, and Discord webhooks. See
[Administration](/docs/exyliamarket/administration).

Every module is on after a fresh install. Switch any of them off in `config.yml`; a module that is off
registers nothing at all.

## Requirements

| Requirement | Detail |
|---|---|
| Server | Paper 1.21 or newer, or a fork of it. Folia supported. |
| Java | 21 |
| Required dependencies | `packetevents`, and `ExyliaLib` 1.296.0 or newer — installed for you if it is missing |
| An economy | `ExyliaEconomy`, or `Vault` with an economy plugin. Without one, nothing can be priced. |
| Optional | `PlaceholderAPI`, `ExyliaSurvivalCore`, `ExyliaAnalytics` |

<Callout type="note" title="About ExyliaLib">
Configuration, menus and prompts, the database, the economy facade, notices, deliveries, `/settings`,
boosters, placeholders and the cross-server channels all come from ExyliaLib. ExyliaMarket is written on top
of it and does not run without it, which is why the loader installs it on a server that lacks it.
</Callout>

## A network

Every server pointed at the same database shares one market: the same listings, auctions, orders, bazaar
book and shop, and a player hears about their deals wherever they are. With Redis configured, changes reach
the other servers at once. See [Installation](/docs/exyliamarket/installation#a-network).

## Conventions

- Values marked as **default** are what the plugin writes the first time it starts. If the file already
  exists, your value is kept.
- Identifiers between `<` and `>` are variables: `/ah sell <price>` means `/ah sell 500`.
- **The default currency** is the server's main one: ExyliaEconomy's default, or Vault's. Thresholds
  written as plain numbers are amounts of it.
- Colours use ExyliaLib palette tokens (`{primary}`, `{highlight}`, `{letters}`).
