---
title: "Comandos"
description: "Cada comando de cada módulo, sus alias, el permiso que pide y qué hace."
---

Cada módulo registra sus propios comandos, y solo mientras está encendido: un módulo apagado no tiene ninguno.
Un comando de un módulo encendido pero que no está en marcha responde que el módulo está desactivado.

Los argumentos entre `<>` son obligatorios, entre `[]` opcionales. El dinero se escribe como un número; `NaN` e infinito se rechazan.

## Jugadores

| Comando | Permiso | Qué hace |
|---|---|---|
| `/collect` | — | Todo lo que el mercado te debe, en una sola pantalla. Ver [Recoger](/docs/exyliamarket/recoger). |
| `/ah` (`/auctionhouse`) | `exyliamarket.auctionhouse` | Abre la casa de subastas. |
| `/ah sell <price> [currency]` | `exyliamarket.auctionhouse.sell` | Publica el stack que tienes en la mano, pasando por la pantalla de revisión. |
| `/ah mine` (`/ah listings`) | `exyliamarket.auctionhouse` | Tus publicaciones. |
| `/auction` (`/auctions`) | `exyliamarket.auctions` | Abre las subastas en curso. |
| `/auction sell <start> [hours] [buyout] [currency]` | `exyliamarket.auctions.sell` | Subasta el stack que tienes en la mano. Una compra inmediata de `0` es ninguna. |
| `/auction mine` (`/auction selling`) | `exyliamarket.auctions` | Tus subastas. |
| `/auction view <id>` | `exyliamarket.auctions` | La pantalla de pujas de una subasta: adonde lleva **[PUJAR DE NUEVO]**. |
| `/orders` (`/order`) | `exyliamarket.orders` | Abre los pedidos de compra. |
| `/orders create <amount> <price> [currency]` | `exyliamarket.orders.create` | Pide `<amount>` de exactamente lo que tienes en la mano a `<price>` **cada uno**, pasando por la pantalla de revisión. |
| `/orders mine` | `exyliamarket.orders` | Tus pedidos y lo que han recogido. |
| `/bazaar [item]` (`/bz`) | `exyliamarket.bazaar` | Abre el bazar, o un producto. |
| `/bazaar mine` | `exyliamarket.bazaar` | Tus pedidos y ofertas abiertos. |
| `/shop [category]` | `exyliamarket.shop` | Abre la tienda, o una categoría por su id. |
| `/sell` | `exyliamarket.shop.sell` | La ventana de venta. |
| `/sell hand` | `exyliamarket.shop.sell` | Vende el stack que tienes en la mano. |
| `/sell all` | `exyliamarket.shop.sell` | Vende todo lo vendible que llevas encima. |
| `/worth [material]` | `exyliamarket.worth` | Por cuánto se vende el objeto de la mano, o un material. |
| `/worth inventory` (`inv`) | `exyliamarket.worth` | Cuánto suma todo lo que llevas encima. |
| `/worth menu` (`list`, `browse`) | `exyliamarket.worth` | Todos los precios, para explorarlos. |
| `/worth history [material]` | `exyliamarket.worth` | El gráfico de precios de 7 días. |
| `/autosell` | `exyliamarket.sellwands.autosell` | Activa o desactiva la autoventa. |
| `/trade <player>` | `exyliamarket.trade` | Pide a un jugador un intercambio. |
| `/trade accept [player]` | `exyliamarket.trade` | Acepta una solicitud; sin nombre, la más reciente. |
| `/trade deny` | `exyliamarket.trade` | Rechaza la solicitud más reciente. |

Todos los comandos de jugador son solo para jugadores.

## Staff

| Comando | Permiso | Qué hace |
|---|---|---|
| `/marketadmin` (`/exyliamarket`) | cualquier nodo de staff | El panel de administración. Desde la consola, el uso. |
| `/marketadmin log [player]` | `exyliamarket.admin.logs` | El registro del mercado, de todos o de un jugador. |
| `/marketadmin stats` | `exyliamarket.admin.logs` | La pantalla de estadísticas. |
| `/marketadmin reload` | `exyliamarket.admin.reload` | Vuelve a leer todos los archivos y menús. También desde la consola. |
| `/ahadmin` (`/auctionhouseadmin`) | `exyliamarket.auctionhouse.admin` | Todas las publicaciones. |
| `/ahadmin remove <id>` | `exyliamarket.auctionhouse.admin` | Retira una publicación; el objeto vuelve al vendedor. |
| `/ahadmin clear <player>` | `exyliamarket.auctionhouse.admin` | Retira todo lo que un jugador tiene publicado. |
| `/auctionadmin` (`/auctionsadmin`) | `exyliamarket.auctions.admin` | Todas las subastas en curso. |
| `/auctionadmin remove <id>` | `exyliamarket.auctions.admin` | Elimina una subasta; se devuelve la puja más alta. |
| `/auctionadmin clear <player>` | `exyliamarket.auctions.admin` | Elimina todas las subastas de un jugador. |
| `/ordersadmin` (`/ordersa`) | `exyliamarket.orders.admin` | Todos los pedidos abiertos. |
| `/ordersadmin cancel <id>` | `exyliamarket.orders.admin` | Cancela un pedido y devuelve el dinero al comprador. |
| `/bazaaradmin` (`/bzadmin`) | `exyliamarket.bazaar.admin` | El editor de productos y todos los pedidos y ofertas abiertos. |
| `/bazaaradmin cancel <id>` | `exyliamarket.bazaar.admin` | Cancela un pedido u oferta; lo que retenía se devuelve. |
| `/shopadmin` (`/shopa`) | `exyliamarket.shop.admin` | El editor de la tienda. |
| `/shopadmin defaults add` | `exyliamarket.shop.admin` | Añade lo que falte de la tienda y la lista de valores por defecto. |
| `/shopadmin defaults replace` | `exyliamarket.shop.admin` | Hace una copia de seguridad y sustituye la tienda y la lista de valores por las de por defecto. |
| `/shopadmin log <player> [rows]` | `exyliamarket.shop.admin` | Las compras y ventas de un jugador en la tienda; 10 filas, hasta 50. |
| `/selladmin [audit]` | `exyliamarket.sell.admin` | La auditoría de precios. |
| `/setworth <price> [material]` | `exyliamarket.worth.admin` | Pone precio al objeto de la mano o a un material en la lista de valores. `0` lo quita. |
| `/sellwandadmin give <player> <multiplier> <uses>` (`/sellwanda`) | `exyliamarket.sellwands.admin` | Da una varita de venta: multiplicador de 0.1 a 10, usos `-1` para ilimitados. |

<Callout type="note" title="Qué funciona desde la consola">
`/marketadmin reload`, `/shopadmin defaults add|replace`, `/shopadmin log`, `/selladmin`, `/setworth` con un
material y `/sellwandadmin give` funcionan desde la consola. `/ahadmin remove|clear` y
`/auctionadmin remove|clear` necesitan un jugador como emisor, así que solo funcionan dentro del juego, aunque
los comandos raíz muestran su uso en la consola. El panel y todos los editores son pantallas, solo para jugadores.
</Callout>
