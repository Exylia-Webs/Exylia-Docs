Todo se genera en `plugins/ExyliaMarket/` en el primer arranque, con comentarios. Edita ahí los archivos y
ejecuta `/marketadmin reload`; la mayoría de los ajustes de los módulos también se pueden cambiar dentro del
juego desde `/marketadmin`, que escribe los mismos archivos. Los catálogos — la tienda, los productos del
bazar, las publicaciones, los pedidos — viven en la base de datos, no en ningún archivo.

## config.yml

```yaml
language: default
debug: false
modules:
  auction-house: true
  auctions: true
  orders: true
  bazaar: true
  shop: true
  sell: true
  worth: true
  sell-wands: true
  trade: true
feedback:
  toasts:
    auction-house-sold: GOAL
    auctions-won: CHALLENGE
    auctions-sold: GOAL
    orders-filled: TASK
    orders-completed: GOAL
  sell-indicators: true
  wand-particles: HAPPY_VILLAGER|12|0.4|0.4|0.4|0
  autosell-report: ACTION_BAR
  auction-countdown-seconds: 60
  outbid-action-bar: true
  trade-countdown: BOSS_BAR
categories:
  shown: [blocks, tools, armour, food, redstone, enchanted-books, potions, misc]
  overrides:
    TOTEM_OF_UNDYING: misc
prices:
  refresh-seconds: 60
  min-sales: 3
  warn-below-percent: 50
  warn-above-percent: 200
  keep-history-days: 90
  keep-daily-days: 365
logs:
  keep-days: 30
  stats-refresh-seconds: 60
```

### language y debug

| Clave | Por defecto | Qué hace |
|---|---|---|
| `language` | `default` | Idioma de los menús y mensajes de este plugin. `default` sigue el de ExyliaLib; `en`, `es`, `pt`, `fr` o `ru` lo fijan solo para este plugin. Cada uno es una carpeta dentro de `lang/`; `custom` guarda los archivos adoptados de un servidor que tenía los suyos propios. |
| `debug` | `false` | Más detalle en la consola. |

### modules

Un interruptor por módulo, todos encendidos. Un módulo apagado no registra absolutamente nada — ni comandos,
listeners, menús, placeholders ni tablas — y su propio archivo no se toca. **Un cambio se aplica al
reiniciar**; una recarga solo nombra los módulos que esperan a uno.

`sell-wands` necesita `sell`: con `sell` apagado sigue apagado, con una línea en la consola.

### feedback

Notificaciones, etiquetas flotantes, partículas, action bars y cuentas atrás. Cada clave se describe en
[Recoger y avisos](/docs/exyliamarket/recoger#indicadores).

### categories

Las categorías por las que filtran el tablón de la casa de subastas y el menú de valores.

| Clave | Por defecto | Qué hace |
|---|---|---|
| `shown` | las ocho | Las categorías que recorre el filtro, en orden: `blocks`, `tools`, `armour`, `food`, `redstone`, `enchanted-books`, `potions`, `misc`. Quita una para ocultarla. |
| `overrides` | `TOTEM_OF_UNDYING: misc` | Un material archivado en otra categoría distinta de la suya, como `MATERIAL: category`. |

Sus nombres están en `messages.yml` bajo `categories`. El bazar tiene sus propias categorías, en su archivo.

### prices

El [índice de precios](/docs/exyliamarket/precios).

| Clave | Por defecto | Qué hace |
|---|---|---|
| `refresh-seconds` | `60` | Cada cuánto escribe cada servidor sus operaciones y vuelve a leer las de todos los servidores. Reinicia para aplicarlo. |
| `min-sales` | `3` | Ventas en los últimos 7 días antes de que se sugiera un precio o se cuestione un trato. |
| `warn-below-percent` | `50` | Pregunta antes de publicar por debajo de este % de la media de 7 días. `0` nunca. |
| `warn-above-percent` | `200` | Pregunta antes de comprar por encima de este % de ella. `0` nunca. |
| `keep-history-days` | `90` | Días que se guarda el historial de mercado de cada jugador. `0` para siempre. |
| `keep-daily-days` | `365` | Días que se guardan las cifras diarias detrás de los gráficos. `0` para siempre. |

### logs

| Clave | Por defecto | Qué hace |
|---|---|---|
| `keep-days` | `30` | Días que se guarda cada línea del registro del mercado. `0` para siempre. |
| `stats-refresh-seconds` | `60` | Cada cuánto se recalculan las cifras de la pantalla de estadísticas. |

## Mensajes y menús

Todo dentro de `lang/<code>/`, donde `<code>` es el `language` de arriba.

| Archivo | Qué contiene |
|---|---|
| `messages.yml` | El prefijo, los errores, los avisos y el resumen al entrar, `/collect`, los indicadores, las etiquetas de los menús, los nombres de las categorías, las palabras del historial, las palabras de precios, las pantallas de ajustes y el registro del mercado. |
| `modules/<module>/messages.yml` | Las líneas de cada módulo. |
| `menus/collect.yml`, `menus/currency_select.yml`, `menus/price_history.yml` | `/collect`, el selector de moneda, el gráfico de precios. |
| `menus/admin/*.yml` | Las pantallas de staff. **Se reescriben desde el jar en cada arranque.** |
| `modules/<module>/menus/*.yml` | Las pantallas de jugador de cada módulo. |
| `modules/trade/window.yml` | La ventana de intercambio. |

Los colores usan tokens de la paleta de ExyliaLib como `{primary}`, `{error}` o `{highlight}`. Un mensaje
puede empezar por `[sound:NAME|volume|pitch]`, que reproduce un sonido y nunca llega a la pantalla.
`%prefix%` es el `prefix` del `messages.yml` principal, que también usan los archivos de cada módulo.

<Callout type="note" title="Actualizar los menús">
Una nueva versión actualiza una pantalla de jugador solo mientras no se haya tocado; una editada se conserva y
la versión nueva se ofrece a su lado. Las pantallas de staff son del plugin y se sustituyen en cada arranque.
</Callout>
