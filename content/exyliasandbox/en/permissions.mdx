Players can use ExyliaSandBox without any setup: every player feature is allowed by default, and only admins get `/sandboxadmin`. Use this page to restrict things or to give ranks more.

## All permissions

<Permissions />

## Make a feature a rank perk

A command and the menu button that does the same thing check the same permission. To turn a feature into a perk, deny it to your default group and grant it to the rank. With LuckPerms:

```text
/lp group default permission set exyliasandbox.command.rtpqueuefast false
/lp group vip permission set exyliasandbox.command.rtpqueuefast true
```

A player without the permission gets the `general.no-permission` message from `messages.yml`. Leaving a sandbox, leaving a queue, denying a teleport request and `/kitsave` never need a permission, so a player can always back out.

## Kit slots per rank

Every player gets one kit slot. A rank gets more with `exyliasandbox.max_kits.<n>`, where `<n>` is the number of slots:

```text
/lp group vip permission set exyliasandbox.max_kits.3 true
/lp group mvp permission set exyliasandbox.max_kits.5 true
```

If a player holds several, the highest counts, so `.3` and `.5` together give five. Grant one per group to keep it readable.

## Shorter `/rekit` cooldown

Everyone waits 30 seconds between two `/rekit` uses (`rekit.cooldown-seconds` in `config.yml`). Give a rank `exyliasandbox.rekit.cooldown.<seconds>` to shorten it; when a player holds several, the lowest wins:

```text
/lp group vip permission set exyliasandbox.rekit.cooldown.10 true
```

<Callout type="note" title="Two permissions are kept only for old setups">
`exyliasandbox.command.leavesandbox` and `exyliasandbox.command.leavertpqueue` are still declared so existing permission files keep loading, but nothing checks them any more.
</Callout>
