---
title: "Permissions"
description: "Every node the plugin checks, the tier that decides how many kits a player gets, and the one bypass."
---

Every node is declared in `plugin.yml`, so each shows in a permission plugin's tab completion. The two
administration nodes default to operators; every player node defaults to **everyone**. A server turns a
feature into a rank perk by denying its node to the default group (`exyliasandbox.command.rtpqueuefast:
false`) and granting it to the rank. A command and the menu button that does the same thing check the
same node, and a player without it gets the `general.no-permission` line.

## Administration

| Permission | Description |
|---|---|
| `exyliasandbox.admin` | `/sandboxadmin` (alias `/sandbox`) and every button in every admin screen |

There is no finer-grained admin node. The same one covers creating worlds, deleting them, editing kit
templates, moving the lobby and reloading.

## Playing

| Permission | Description |
|---|---|
| `exyliasandbox.command.rtp` | `/rtp`, with or without a world |
| `exyliasandbox.command.rtpqueue` | `/rtpqueue` |
| `exyliasandbox.command.rtpqueuefast` | `/rtpqueuefast` |
| `exyliasandbox.command.tpa` | `/tpa` and `/tpaccept` |
| `exyliasandbox.join.nokit` | Joining a queue without a kit from the world selector |
| `exyliasandbox.command.back` | `/back` |
| `exyliasandbox.command.rekit` | `/rekit` |
| `exyliasandbox.rekit.cooldown.<seconds>` | Seconds between two `/rekit` uses for this rank; the lowest granted wins, and `rekit.cooldown-seconds` applies without one |

`/leavesandbox`, `/leavertpqueue`, `/tpdeny` and `/kitsave` need no node. `exyliasandbox.command.leavesandbox` and `exyliasandbox.command.leavertpqueue` are still declared so old permission setups keep loading, but nothing checks them.

## Kits

| Permission | Description |
|---|---|
| `exyliasandbox.command.kitroom` | `/kitroom` |
| `exyliasandbox.command.kitcreator` | `/kitcreator` and the kit creator's menu buttons |
| `exyliasandbox.command.predefinedkits` | `/predefinedkits`, `/predefinedkit`, `/pkits` |
| `exyliasandbox.max_kits.<n>` | How many kit slots the player gets |

### How `max_kits` resolves

The highest `exyliasandbox.max_kits.<n>` node the player holds is the one that counts, so `.3` and `.5`
together give five. A player with no node at all gets **one** slot. Grant exactly one node per group.

## Bypass

| Permission | Description |
|---|---|
| `exyliasandbox.bypass.blocked-commands` | Run any command inside a sandbox world or a queue, ignoring the whitelist |

## A group that can play

```text
exyliasandbox.command.rtp
exyliasandbox.command.rtpqueue
exyliasandbox.command.rtpqueuefast
exyliasandbox.command.tpa
exyliasandbox.command.back
exyliasandbox.command.rekit
exyliasandbox.command.kitroom
exyliasandbox.command.kitcreator
exyliasandbox.command.predefinedkits
exyliasandbox.max_kits.3
```
