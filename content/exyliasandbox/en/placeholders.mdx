Use these to show live ExyliaSandBox data in other plugins that support PlaceholderAPI, such as holograms, tab lists and chat. Click a placeholder to copy it.

<Placeholders />

`<world>` is the world's id as shown in `/sandboxadmin` → **Worlds**, not the Bukkit world name. The stats and playtime placeholders need a player, so they show nothing where no player is attached (for example in the console). Playtime includes the session the player is in right now.

<Callout type="warning" title="`queue_world` is a name, not a count">
`%exyliasandbox_queue_world_<world>%` answers with the name of the player who has waited longest, so a lobby board can say who is looking for an opponent. There is no per-world queue count; `%exyliasandbox_queue_total%` is the only number.
</Callout>

## The sidebar names are different

The lines in `scoreboards.yml` are filled from the board's own data, not from the placeholders above. Inside that file use:

| Name | Shows |
|---|---|
| `%world%` | The display name of the world the player is in |
| `%players%` | Players in that world |
| `%border%` | The border radius of that world |
| `%kills%`, `%deaths%`, `%kdr%` | The player's stats |
| `%sandbox_playtime%` | The player's playtime, written without the plugin prefix |

Writing `%playtime%` there shows the text as it is: the name is `sandbox_playtime`.

## Placeholder shows as text

- PlaceholderAPI is not installed on the server.
- The world id is misspelled. Check it in `/sandboxadmin` → **Worlds**.
- You wrote a sidebar name (`%kills%`) outside `scoreboards.yml`, or a placeholder name inside it.

For a fallback when a placeholder has no answer, PlaceholderAPI plugins that support it accept `%exyliasandbox_queue_world_plains|nobody%`.
