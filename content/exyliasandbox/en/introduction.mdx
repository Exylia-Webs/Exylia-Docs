ExyliaSandBox turns a Paper or Folia server into a set of disposable PvP worlds. Players type `/rtp`, land at a random safe spot in a generated world wearing a kit they saved earlier, fight, and go back to the lobby the moment they die. Nothing in a sandbox world is meant to last: chunks are not saved and death is cancelled, so there is no respawn screen and nothing drops.

In about ten minutes you can have the lobby set, five ready-made worlds and your first kit. Start with [Install ExyliaSandBox](/docs/exyliasandbox/installation), then follow [Your first sandbox](/docs/exyliasandbox/first-steps).

## What you need

- A Paper, Spigot or Folia server on Minecraft 1.21.4 or newer.
- **Chunky**, which pre-generates each world out to its border before anybody is let in. The server will not load the plugin without it.
- **ExyliaLib**, which provides the menus, database and everything else the plugin is built on.
- Optional: PlaceholderAPI for the [placeholders](/docs/exyliasandbox/placeholders), ExyliaPracticeCore to let a template borrow its kits, and the `Worlds` plugin on Folia.

The full list, with what each one changes, is in [Install ExyliaSandBox](/docs/exyliasandbox/installation).

## What a session looks like

1. **A kit first.** `/kitcreator` opens the player's slots. They build a kit from the kit room and run `/kitsave`.
2. **In.** `/rtp`, `/rtpqueue` or a teleport pad. Their inventory is stored and the kit goes on.
3. **Fighting.** PvP is forced on, a sidebar shows kills, deaths and the border, and only the commands in your whitelist work.
4. **Out.** Death, `/leavesandbox` or a disconnect all end the same way: back to the lobby with their own inventory.

## What you set up as an admin

Everything lives in one menu, `/sandboxadmin`: worlds, predefined kits, kit-room categories, teleport pads, the lobby and the plugin settings. See [Admin panel](/docs/exyliasandbox/admin-panel). There is no world list to edit by hand.
