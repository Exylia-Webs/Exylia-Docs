Find your symptom, then follow the fix.

## The server shut down after I created a world

This is on purpose. When the pre-generation of a new world finishes, the plugin stops the server (the console says `All worlds pregenerated. Restarting server...`) so the world loads clean. It happens on the first boot, when the five seeded worlds are generated, and also when you create one world from the panel. Create worlds in a quiet moment and run the server under something that starts it again. See [Worlds](/docs/exyliasandbox/worlds).

## Players land in the wrong place when they leave

The lobby is not set. Run `/sandboxadmin`, click **Set lobby**, walk to where you want players to arrive and sneak-click. Players go there on death, on `/leavesandbox` and when they disconnect.

## A world is stuck on `UNAVAILABLE`

The world could not be loaded. On Folia this usually means the `Worlds` plugin is missing. On Paper, read the console at startup for the error. While a world is not ready, `/rtp <world>` refuses it. See [Install ExyliaSandBox](/docs/exyliasandbox/installation).

## A player cannot enter a sandbox because they have no kit

A player needs a saved kit with items in it. Tell them to run `/kitcreator`, click **Create Kit**, take gear from the kit room and run `/kitsave`. Or run `/predefinedkits` to copy a template you built. See [First steps](/docs/exyliasandbox/first-steps).

## A player can only save one kit

Without a `exyliasandbox.max_kits.<n>` permission a player gets one slot. Give the rank one node, for example `exyliasandbox.max_kits.5` for five. See [Permissions](/docs/exyliasandbox/permissions).

## A command does not work inside a sandbox

Only the commands in `config.yml` under `command-whitelist.commands` work inside a sandbox world or while waiting in a queue. Add the command and run `/sandboxadmin reload`, or give staff `exyliasandbox.bypass.blocked-commands`. See [Commands](/docs/exyliasandbox/commands).

## A teleport pad does nothing for a player

A pad uses the player's favourite kit and shows no kit menu. A player with kits but no favourite is told so and stays where they are. In **Kit options**, the **Favorite** star toggles it, so clicking the current favourite removes it.

## Nothing players build is kept

On purpose: sandbox worlds do not save chunks, and a world is rebuilt from its generator when it loads again. If you want a fixed arena, import an existing world instead; the plugin never changes the terrain of an imported world. See [Worlds](/docs/exyliasandbox/worlds).

## Kit room edits disappear

Edit the kit room from `/sandboxadmin` → **Kit room**. The kit room players open with `/kitroom` only hands out copies. If you empty a category completely, the shipped items come back at the next start. See [Kit room](/docs/exyliasandbox/kit-room).

## A placeholder shows as text

PlaceholderAPI is missing, or the world id is wrong. See [Placeholders](/docs/exyliasandbox/placeholders).
