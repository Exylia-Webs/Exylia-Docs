Quick answers. For step-by-step fixes see [Common problems](/docs/exyliasandbox/troubleshooting).

## Why did my server shut down after creating a world?

Because that is what the plugin does when the pre-generation queue drains after a world has finished generating (a queue emptied by pausing, cancelling or deleting worlds does not shut it down). It calls `Bukkit.shutdown()` and logs `All worlds pregenerated. Restarting server...`. It is meant for the first boot, where every seeded world is generated at once; it fires just the same when you create one world from the panel on a live server. Create worlds in a maintenance window, and run the server under something that brings it back up. See [Worlds](/docs/exyliasandbox/worlds).

## Nothing works and everybody lands in the wrong place

The lobby is not set. Run `/sandboxadmin`, click **Set lobby**, walk to the spot and sneak-click. That is where every player goes on death, on `/leavesandbox` and on a disconnect.

## A world is stuck on `UNAVAILABLE`

The world could not be loaded. On Folia, this usually means the `Worlds` plugin is missing: Folia cannot create a world the ordinary way, and ExyliaLib routes around it through that plugin. On Spigot or Paper, check the console for the failure at startup.

## `/rtp` says the player has no kit

They have no saved kit with anything in it. They run `/kitcreator`, click **Create Kit**, take gear from the kit room and run `/kitsave`. Or they run `/predefinedkits` to copy a template an admin built. See [Kits](/docs/exyliasandbox/kits).

## A teleport pad ignores somebody

A pad uses the player's **Favorite** kit and nothing else. Somebody with kits but no favourite is told so and left standing. The **Favorite** button in the kit options toggles, so clicking it on the current favourite leaves the player with none. See [TP regions](/docs/exyliasandbox/tp-regions).

## Why can a player only save one kit?

They hold no `exyliasandbox.max_kits.<n>` node, and the fallback is one slot. Grant a single node: `exyliasandbox.max_kits.5` for five. The highest node a player holds is the one that counts. See [Permissions](/docs/exyliasandbox/permissions).

## My kit-room edits disappear

They should not: a category's items are saved when its window closes, however it closes. Edit it from `/sandboxadmin` → **Kit room**; the kit room players open with `/kitroom` only hands out copies. An admin who empties the room gets the shipped catalogue again on the next start. See [Stock the kit room](/docs/exyliasandbox/kit-room).

## Why are the kit room ids in Spanish?

The five seeded categories ship with Spanish ids (`armaduras`, `consumibles`, `explosivos`, `pociones`, `flechas`) and English display names; a server seeded before 1.1.0 keeps its Spanish names. Rename the display names whenever you like. The ids are what `/kitroom <category>` takes and a rename does not change them.

## A player kept their sandbox kit in the lobby

ExyliaPracticeCore was installed or removed between their entry and their exit. When it is present this plugin never saves or restores the inventory, because the practice lobby dresses the player; when it is absent this plugin does. Changing that mid-session leaves nobody holding the snapshot.

## Why does a command not work inside a sandbox?

The command whitelist. Only what is listed in `config.yml` under `command-whitelist.commands` runs inside a sandbox world or while queued; everything else is refused. Add the command to the list, or give the player `exyliasandbox.bypass.blocked-commands`. See [Configuration](/docs/exyliasandbox/configuration).

## Nothing a player builds survives

Chunk saving is off in every sandbox world, on purpose. A world is rebuilt from its generator whenever it is loaded fresh. If you want a fixed arena, import a world with **Import World**: the plugin never touches an imported world's terrain. See [Worlds](/docs/exyliasandbox/worlds).

## I deleted a teleport pad by accident

Once the confirmation is accepted there is no undo. Rebuild it: **TP regions** → **Create TP region**, name, wand, target world, interval, spread radius, **Save**.

## Where are the statistics?

In the `sandbox_player_stats` table and on the sidebar. `%exyliasandbox_sandbox_kills%`, `%exyliasandbox_sandbox_deaths%`, `%exyliasandbox_sandbox_kdr%` and `%exyliasandbox_sandbox_playtime%` put them anywhere PlaceholderAPI reaches. Kills only count when both players are inside a sandbox world. See [Placeholders](/docs/exyliasandbox/placeholders).

## Can two servers share this?

Yes: point them at the same database and they share worlds, kits, templates, the kit room and the pads. Nothing is pushed live between servers: a world created on one is picked up by another the next time it reads. See [Database](/docs/exyliasandbox/database).
